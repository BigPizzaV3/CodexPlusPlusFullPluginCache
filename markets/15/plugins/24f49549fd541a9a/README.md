# Calibry for ChatGPT & Codex

Find current job openings from employer career sites in any profession.

## What it does
- Search openings by role, skills, company, location and remote preference, optionally ranked against a short summary of your background.
- Read the full text of a posting and compare it to the experience you share.
- Optionally save your background on Calibry, with your consent, to continue to a tailored resume. Privacy: https://clbry.com/privacy. Terms: https://clbry.com/terms.

## MCP Server
- Remote Endpoint: `https://clbry.com/api/mcp`
- Transport: Streamable HTTP (JSON-RPC 2.0), no authentication
