# LUT Builder

Build one portable17/33-point .cube creative look, validate a real supplied CUBE, or test it on an actual still. Explicit controls grid_size17/33, gain0.5–2, contrast0.5–1.5, saturation0–2, gamma0.5–2; identity defaults. Plain ASCII title1–60characters. Gain is an encoded-RGB multiplier, not photographic exposure stops. Formula clamps gain/contrast then saturates around encoded Rec709-weighted luma, clamps and applies power1/gamma. The actual exported grid is rounded8decimals with red index fastest; preview uses parsed grid trilinear interpolation, not the analytic formula. This is display-referred normalized RGB creative processing, not camera-log/HDR/ICC/ACES conversion, display calibration or exact reference matching. Clipping is irreversible. No spatial effects, masks, blur or grain can be encoded. Other apps and interpolation/color management may differ; do not claim verified Resolve/Photoshop import. CUBE intake is actual UTF8 up to3MB, grid17/33, normalized domain0–1 and finite output0–1. Reject1D/shapers, duplicate/unknown headers, unsupported titles/domains, malformed or wrong row counts. Inspection reads actual values without uploading. Apply requires both actual CUBE and JPEG/PNG/WebP image references, up to20MB and4MP; auto-orient and normalize to8-bit sRGB, preserve normalized alpha and export actual PNG without source metadata. Sources are downloaded without rehosting; derived exports are public. Generated ZIP includes actual CUBE, parameters, synthetic before/after chart and readme. Chart top is synthetic input and bottom actual parsed-LUT result, not a customer image. Preserve ZIP/document if optional saves fail. Reopen exact saved URLs without rebuilding. Never invent output links or present local evidence as online/host verification.
