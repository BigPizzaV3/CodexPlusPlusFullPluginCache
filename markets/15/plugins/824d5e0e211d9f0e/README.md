# LUT Builder

By Imagineers Studio Inc · NebulaCafe

Build portable17/33-point normalized RGB .cube creative looks from explicit gain, contrast, saturation and gamma. Validate supplied CUBE grid/domain/rows/corner values and test it on an actual still with trilinear interpolation. Export CUBE, parameters and a synthetic before/after chart in a ZIP, or the actual transformed PNG. Creative encoded-RGB processing only: no camera-log/HDR/ICC/ACES conversion, calibration, exact reference matching or spatial effects. CUBE limits3MB, normalized0–1, grid17/33; image limits20MB/4MP JPEG/PNG/WebP. Requires a connected account; derived exports are public.
