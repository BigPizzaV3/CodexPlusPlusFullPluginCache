# ToolJet

Version 1.0.0.

The MCP URL is https://mcp-oauth.tooljet.com/mcp. Authorize through OAuth, sign in to ToolJet Cloud, and choose the workspace in the browser flow. Do not append a workspace ID or substitute a placeholder. Changing the active browser workspace does not change this connection; authorize a new connection to use another workspace. This ZIP includes the skill and remote MCP configuration. Installing it does not deploy or upgrade the hosted MCP, ToolJet backend, or agent. The shared endpoint requires the compatible production server deployment.

Both packages include the same App Builder skill. Enable only the package for the intended connection in a test chat to avoid ambiguous tools.
