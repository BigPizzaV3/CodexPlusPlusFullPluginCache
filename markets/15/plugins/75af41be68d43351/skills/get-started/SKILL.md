# Get started with Caybl

Caybl connects ChatGPT to the user's Google marketing data.

1. If the user has not connected yet, ask them to sign in with Google when prompted and approve Google's consent screen.
2. If their account can reach more than one GA4 property or Google Ads account, ask which one they mean instead of guessing.
3. Fetch only the data the question needs, and say which property or account the answer comes from.
4. Google Ads write tools change a live account. Always run a validateOnly preview first and get the user's confirmation before applying anything. New campaigns, ad groups and ads are created paused.

Example questions: "How many sessions did my site get last month, by channel?", "Which Google Ads search terms are wasting money?", "Which pages lost Google search clicks recently?", "Is /pricing indexed?"
