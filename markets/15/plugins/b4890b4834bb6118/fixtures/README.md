# Synthetic review documents

Fictional single-column CVs with reserved example.invalid contact addresses. Use cv-fr.pdf for positive case 1 and cv-en.docx for case 2; text equivalents support paste/fallback. No published engine scores are attached. UI fixtures in lib/chatgpt/fixtures.ts use illustrative, unverified numbers and invented record IDs; never use those IDs as reviewer account records. Generate real analysis/import results in the configured preview and dedicated reviewer account. Do not put account credentials or bearer tokens in this package.
