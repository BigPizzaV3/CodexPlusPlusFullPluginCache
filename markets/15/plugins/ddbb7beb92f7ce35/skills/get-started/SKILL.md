---
name: get-started
description: Explains what the PugBase plugin can do and suggests a first request, for people who have just connected their PugBase workspace.
---

PugBase is a shared workspace where a team keeps specs, decisions, plans and
test results as notes. The PugBase tools work on the one workspace the user
chose when they signed in.

What the user can ask for:

- Find notes by keyword and read them, including tables, checklists and diagrams.
- See an image that is embedded in a note.
- Read the comments the team left on a note.
- Read the team's plan and see how far each task has progressed.
- Write a new note, add a section to the end of a note, or replace a note's content.
- Upload an image and embed it in a note.

Writes change the team's workspace, so confirm the target note and the content
with the user before creating, appending to or replacing a note.

A good first request is "What notes are in my PugBase workspace?" or
"Find the release checklist in PugBase."
