# Palette Extractor

By Imagineers Studio Inc · NebulaCafe

Extract sampled sRGB palettes from supplied JPEG, PNG or WebP images, inspect decoded pixels at explicit coordinates, and export CSS variables, GIMP GPL, JSON and a swatch PNG in a ZIP.

Choose 2–12 colors and an alpha threshold from 1–255. Swatches are approximate quantized cluster means; percentages describe included samples. Exported swatches are opaque RGB. Flat black/white contrast ratios do not certify whole-site accessibility, Pantone or official brand identity. Actual source images are required.

A connected NebulaCafe account is required. Source images are processed without rehosting; derived export links are public.
