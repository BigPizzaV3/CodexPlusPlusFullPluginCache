# Focus Stack

By Imagineers Studio Inc · NebulaCafe

Blend2–4 supplied already pixel-aligned focus-bracket stills using measured local contrast and feathered source selection. Explicit same-scene/alignment confirmation required; equal dimensions do not prove registration. Export actual composite PNG, pre-feather source-index PNG and provenance report in ZIP. Limits: opaque JPEG/PNG/WebP,20MB each/32MB combined,32–1024px per side,identical oriented dimensions. No automatic alignment, deghosting, physical depth or new detail. Noise/exposure/sharpening may win focus scores; halos/seams/ghosts can remain. Requires a connected account; derived exports are public.
