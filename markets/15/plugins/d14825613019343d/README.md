# DevSwat public plugin

Existing server: https://www.dev-swat.com/api/mcp/user
OAuth with PKCE and Dynamic Client Registration; scope read.

Current tools: list_services, scope_project, submit_project, list_my_projects, get_project_status, send_project_message, list_project_messages, request_project_addon, open_ticket, list_my_tickets, get_ticket_thread, reply_ticket, list_available_slots, book_slot, book_consultation.

Review demo covers quotation, one unpaid owner-authorized demo project, and retrieval. No payment was made. Reviewer account access instructions are saved only in secure Platform fields. Final review readiness depends on the current 15-tool scan and required attestations.
