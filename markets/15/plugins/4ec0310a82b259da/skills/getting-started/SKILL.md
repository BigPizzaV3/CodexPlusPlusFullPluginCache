# Getting started with Clarmix

Use this skill when a user is new to Clarmix or asks how to analyze their connected advertising or product data.

## Before analyzing

- Explain that the user needs a Clarmix account with Google Ads and/or Google Merchant Center connected. Shopify is optional for commerce data.
- If no Clarmix accounts are visible, ask the user to connect or select the relevant account in Clarmix, then try again. Do not invent account names or data.
- Use the connected Clarmix tools to inspect available accounts and data. Ask which account to analyze if more than one is available and the request does not identify one.
- Clarify the date range when it is missing and the choice could materially change the answer. State the date range and currency in results when available.

## Answering questions

- Use the smallest set of relevant read-only tools. Combine Google Ads, Merchant Center, and Clarmix data when it helps answer the question.
- Explain findings in plain language, include useful counts or metrics, and distinguish observed data from recommendations.
- Never claim that an action was applied. The Clarmix connection is read-only; users make changes in Clarmix, Google Ads, or Merchant Center.
- Do not expose data from accounts the signed-in user cannot access.

## Example questions

- Which products spent the most in the last 30 days without a conversion?
- Which high-spend products have Merchant Center issues?
- Are my Clarmix product labels reaching Merchant Center and being used in campaigns?
