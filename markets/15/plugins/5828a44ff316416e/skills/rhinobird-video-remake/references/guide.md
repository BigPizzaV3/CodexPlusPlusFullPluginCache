# 视频复刻实操指南

## 一、什么样的参考视频最好复刻

复刻的本质是「**把参考视频的动作结构搬过来，把主体换掉**」。参考视频的结构越清晰，成片越稳。

### 优先选这类

| 特征 | 为什么 |
|---|---|
| **主体单一、全程只有一个产品** | 换主体最干净，不会出现"另一个产品还在画面里" |
| **镜头稳定**（固定机位、缓慢推拉、缓慢环绕） | 运镜简单 → 生成可控，不容易糊 |
| **镜头切换 2-5 次** | 有节奏但不碎，最适合 15 秒内的短视频 |
| **手部/产品特写为主，少露脸** | 产品保真度高，也避开了肖像问题 |
| **光线均匀、背景干净** | 生成时不会把杂乱背景一起"复刻"过来 |
| **原片就有字幕/字卡** | 说明节奏点明确，新文案容易对上 |

### 尽量避开

| 特征 | 问题 |
|---|---|
| 镜头切得极碎（1 秒 3 切） | 模型跟不上，成片节奏会乱 |
| 大量真人面部特写 | 换产品没意义，且涉及肖像权 |
| 快速甩镜、手持剧烈晃动 | 生成画面容易糊、产品变形 |
| 画面里同时出现多个品牌产品 | 换不干净，容易串 |
| 大幅特效、转场动画 | 复刻成"特效模仿"，产品反而被弱化 |
| 前后两段完全不同的场景 | 15 秒内讲不完，成片容易只抓到一段 |

### 时长怎么选

上限是 **15.2 秒**（模型固定 Seedance 2.0）。

- **8-12 秒最稳**：够讲一个卖点 + 一个使用动作，节奏不赶。
- **3-5 秒**：只适合单一特写（质地拉丝、上脸一抹），信息量太少。
- **13-15.2 秒**：能塞 3-4 个镜头，但对参考视频结构要求高，容易后半段散掉。
- 用户手里素材超 15.2 秒时，**只陈述限制**「参考视频不能超过 15.2 秒」，让他换一条。不要建议他裁剪，也不要替他剪。

## 二、比例与平台对照

| 比例 | 适用平台/位置 | 备注 |
|---|---|---|
| `adaptive` | 通用 | **默认推荐**，跟参考视频一致，构图最不容易崩 |
| `9:16` | 抖音、快手、视频号、小红书视频、TikTok、Reels、Shorts | 竖屏短视频主战场 |
| `3:4` | 小红书图文/视频混排、部分电商内容位 | 介于竖屏和方图之间 |
| `1:1` | 朋友圈、信息流广告、部分电商主图视频位 | 上下留白多，信息密度低 |
| `4:3` | 淘宝/京东主图视频、部分站内推荐位 | 电商站内常见 |
| `16:9` | YouTube、B 站、PC 端官网、站外投放 | 横屏 |

**两个判断口径：**

1. **参考视频是什么比例，就优先 `adaptive`。** 用户拿一条竖屏爆款却要 16:9，等于重新构图，人物/产品位置全变，成片大概率不像。
2. **投什么平台就出什么比例。** 用户说「要发抖音」→ 9:16；「要放淘宝主图」→ 4:3 或 1:1；「YouTube 前贴片」→ 16:9。用户只说了平台没说比例时，按这张表替他定，并在复述里报出来。

**参考视频自带黑边时**（上下或左右有黑条），`adaptive` 会把黑边一起学过去，成片也带黑边。这种情况改用固定比例（9:16 或 16:9），让平台重新裁。

## 三、产品图怎么挑

平台收 1-4 张，**质量比数量重要**。按这个优先级挑：

| 优先级 | 图 | 作用 |
|---|---|---|
| 1 | 正面主图，产品占画面 50% 以上，背景干净 | 定外观、定颜色、定 logo |
| 2 | 带包装/瓶身的图 | 定材质、定质感、定标签文字 |
| 3 | 细节特写（质地、瓶口、纹理、接口） | 让特写镜头有依据 |
| 4 | 手持/使用中实拍 | 定尺寸感，避免生成时比例失真 |

**不要用**：带大片水印的图、九宫格拼图、带价格标签的详情页截图、多产品混在一张的图、严重偏色或磨皮过度的图。这些会让生成结果"学到"错误信息。

用户只给 1 张也能跑，但**特写镜头容易凭空发挥**。图少的时候在复述里提一句「图少的话特写镜头会自由发挥，介意就再补一张细节图」。

## 四、产品介绍怎么写（`productIntroduction`）

这段文字是**成片文案的原料**：口播字幕、卖点字卡、画面重点都从这里来。写得好，成片直接能投；留空，就只能拿到一条"没说话"的视频。

**结构（压成一段，分号连接，120 字内）：**

```
核心卖点：xxx、xxx；质地/成分：xxx；功效：xxx；使用方法：xxx；目标人群：xxx
```

**写法要点：**

- **只写画面能表达的东西。** "不黏腻"能拍出来（拉丝、吸收），"性价比高"拍不出来。
- **一个视频只讲一个主卖点。** 15 秒塞 5 个卖点等于没有卖点。
- **动词优先。** "一抹化水" > "质地清爽"；"3 秒起泡" > "起泡丰富"。
- **不编造。** 成分名、专利号、检测数据、认证、临床结果、销量排名、排名类表述，用户没给就不写。
- **中国市场避开《广告法》风险词**：最、第一、国家级、顶级、根治、无副作用、永久、100% 等。
- **语言跟随 `language`**，不是跟随对话语言。投美国就写英文介绍，哪怕用户在用中文聊。

## 五、成本与时间

| 环节 | 量级 |
|---|---|
| 素材体检 + 上传 | 10-60 秒（视频越大越慢） |
| 生成 | 通常 1-3 分钟，排队高峰可到 5-10 分钟 |
| 下载 | 几秒 |

- 一次调用出 **1 条**视频。要多个版本 = 多次调用 = 多次消耗。
- 常见做法：**先跑一条验证方向**（比例、构图、产品像不像），确认没问题再换产品图/比例跑第二版。不要一上来批量跑 10 条。
- 轮询失败或超时**不要自动重试**——可能已经在扣积分。

## 六、合规注意

- **参考视频的版权**：用户应当对自己上传的参考视频有使用权。复刻他人原创视频的运镜与创意，商用前建议确认授权。这一句提醒到位即可，不要反复说教。
- **肖像权**：参考视频含真人出镜时，成片可能出现类似人物。商用需自行确认肖像授权。
- **广告法**：见第四节，禁用词不要写进 `productIntroduction`。
- **平台规则**：抖音/视频号等对"AI 生成"内容有标识要求，投放前提醒用户按平台规则自行标注。

## 七、常见需求怎么答

| 用户说 | 怎么答 |
|---|---|
| 「能不能做 30 秒？」 | 时长跟着参考视频走，参考视频不能超过 15.2 秒，所以成片也在 15 秒量级。 |
| 「能不能指定画面里出现什么动作？」 | 动作来自参考视频，本工具不接受动作描述。想控制动作 = 换一条动作符合预期的参考视频。 |
| 「能不能换背景音乐？」 | 成片音频不保证可用，后期自行替换 BGM、配口播。 |
| 「能不能同时复刻 3 条视频？」 | 一次一条。3 条 = 3 次调用，建议先跑一条确认效果。 |
| 「能不能让视频里的人换成我？」 | 本工具是换**产品**，不是换人。人脸替换属于另一类能力。 |
| 「生成的不像我的产品」 | 换更清晰的产品主图（正面、占比大、无遮挡），并确认没有水印/拼图。 |
| 「节奏跟原视频不像」 | 换一条镜头更稳定、切换更少的参考视频（见第一节）。 |
