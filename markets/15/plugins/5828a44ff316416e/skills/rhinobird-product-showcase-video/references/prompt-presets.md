# `productIntroduction`（平台「创作要求」）提示词模板库

产品展示只有 `productIntroduction` 一个风格入口，它对应网页端的**「创作要求」**栏。下面的模板可以直接抄，**把 `<>` 里的占位符换成用户的实际信息**，其余原样保留。

写法规律：**产品介绍 → 核心卖点 → 使用方式 → 画面要求（背景 → 产品位置 → 镜头动作 → 光 → 质感 → 收尾 → 负面约束）**。这个顺序出来的成片最稳。

---

## 使用说明

1. 先按品类挑一条（第一~三节），再把用户的具体要求拼上去（第四节）。
2. **负面约束那一段不要删**，除非用户明确要真人。
3. **模板里默认没有画面文字**（结尾是「画面不出现额外文字」）。只有用户明确说「视频里要出现 xx 这几个字」时，才按第五节加一段，**不要自作主张配卖点字幕**。
4. 一条 `productIntroduction` 控制在 **200 字以内**，太长模型会漏掉后半段。
5. **画面描述用中文写没问题**（那是给模型看的指令）；只有用户点名要画面文字时，那几个字才必须用 `language` 的语言。
6. 下面两个 JSON 示例里的 `"country": "中国"` / `"language": "中文"` 只是中文对话下的取值；实际按 SKILL.md 的推断表替换。

## 一、白底 / 电商主图向（最稳，转化导向）

### 1.1 通用白底旋转（任何品类）

```
画面：纯白无影棚背景，<产品>居中置于亚克力台面，占画面 60%，静止 1 秒后缓慢匀速旋转 120 度；镜头固定平视，缓慢推近至<标签/瓶口>微距，柔光从左上方 45 度打亮，右侧补光，无硬阴影，浅景深背景虚化；最后一帧回到完整产品正面。运镜平稳，单一轨道推进，无转场无闪白。不要真人出镜，不要手部入画，不要手持晃动，不要文字水印。画面不出现额外文字。
```

### 1.2 白底 + 微距质地（护肤 / 食品）

```
画面：纯白无缝背景，<产品>正面居中静止 1 秒，镜头缓慢推近至开盖后的<膏体/内容物>微距，浅景深，焦点从边缘缓慢移到中心，膏体细腻有光泽、表面柔光流动；随后拉回到完整瓶身正面。大面积柔光箱左上方主光，底部反光板消除阴影。不要真人出镜，不要手部入画，不要手持晃动。画面不出现额外文字。
```

### 1.3 浅灰渐变升级版（比纯白有层次）

```
画面：浅灰到白的渐变背景，<产品>居中置于浅灰亚克力台面，下方极浅软阴影，产品占画面 55%；缓慢旋转 90 度后镜头推近至<细节部位>，柔光从左上方扫过表面形成一道高光；收尾回到正面。干净克制的商业布光，无强对比，无彩色光。不要真人出镜，不要手部入画，不要手持晃动。画面不出现额外文字。
```

## 二、质感 / 高级感向（独立站、详情页头图、TVC 短版）

### 2.1 石台柔光（护肤 / 香氛 / 家居）

```
画面：米白洞石台面，背景同色系材质虚化，<产品>居中偏左，右侧留白；缓慢旋转 60 度，镜头轻微推近，一道柔光从左上扫过<瓶身/表面>，材质纹理清晰、反光柔和；最后静置于画面中央。低饱和暖调，柔光罩布光，单一运镜。不要真人出镜，不要手部入画，不要手持晃动，不要快速转场。画面不出现额外文字。
```

### 2.2 光带扫过 + 悬浮（3C / 香水 / 酒）

```
画面：深灰哑光背景，<产品>悬浮于画面中央缓慢自转，一道锐利光带从左至右扫过<金属/玻璃>表面，高光沿边缘流动；镜头固定，仅轻微推近，产品下方极浅倒影；收尾静止在 45 度角。硬朗单侧光，冷调，强对比，金属反射清晰。不要真人出镜，不要手部入画，不要手持晃动，不要爆炸分解。画面不出现额外文字。
```

### 2.3 丝绒聚光（珠宝 / 香水 / 礼盒）

```
画面：深色丝绒垂坠背景，单点聚光打在<产品>上，四周压暗；产品缓慢旋转 90 度，镜头推近至<宝石/瓶盖/纹理>微距，光在切面上闪烁；收尾回到完整正面，倒影落在丝绒上。低色温暖光，明暗对比强，背景完全不抢。不要真人出镜，不要手部入画，不要手持晃动。画面不出现额外文字。
```

### 2.4 水波光影（饮料 / 护肤 / 香水）

```
画面：浅水底或透明玻璃台面，水面折射光斑缓慢流动打在<产品>上，产品居中静止 1 秒后缓慢旋转 90 度；镜头推近至<瓶身水珠/液体>微距，逆光让液体透亮；收尾回到完整正面。清爽通透的冷白光，水波动态自然，无人工感。不要真人出镜，不要手部入画，不要手持晃动。画面不出现额外文字。
```

### 2.5 自然窗光木桌（食品 / 咖啡 / 家居）

```
画面：原木台面，侧逆自然窗光，窗外绿植虚化，<产品>置于台面中央，旁边<少量同色系道具>；镜头从正面缓慢横移 15 度并轻微推近，光斑在台面上缓慢移动；收尾静止。暖调、柔和、有生活气息但不出现人。不要真人出镜，不要手部入画，不要手持晃动。画面不出现额外文字。
```

## 三、动作向（开盖 / 液体 / 结构）

### 3.1 开盖展示

```
画面：纯白背景，<产品>正面居中，镜头对准<瓶盖>，盖子缓慢旋开露出<膏体/内容物>，随后镜头推近至内容物微距，柔光打亮表面；收尾回到完整产品与打开的盖子并置。结构清晰，动作缓慢自然，无穿模。不要真人出镜，不要手部入画，不要手持晃动。画面不出现额外文字。
```

### 3.2 液体倾倒 / 拉丝

```
画面：<产品>在画面左侧，液体缓慢倾倒进右侧透明容器，形成连续拉丝并缓慢滴落，逆光让液体透亮有折射；镜头固定平视，微距浅景深；收尾回到完整瓶身。流速缓慢自然，液体质感真实，背景纯色不抢。不要真人出镜，不要手部入画，不要手持晃动。画面不出现额外文字。
```

### 3.3 组合陈列（套装 / 多色号）

```
画面：浅灰渐变背景，<主品>居中，<配件1>、<配件2>左右两侧稍后，三者并排；镜头缓慢横移 20 度，产品依次进入实焦，最后整体静止。统一柔光，投影方向一致，画面不超过 4 个产品。不要真人出镜，不要手部入画，不要手持晃动。画面不出现额外文字。
```

## 四、按用户要求叠加的补丁片段

把下面这段**拼到模板最后**（负面约束之前）：

| 用户说 | 拼上这段 |
|---|---|
| 「要更高级 / 大牌感」 | `低饱和莫兰迪色调，明暗对比克制，柔光为主，构图大量留白，无任何彩色光效。` |
| 「要干净 / 白底」 | `纯白无缝背景，无投影，产品边缘干净锐利，背景不出现任何道具。` |
| 「要科技感」 | `冷调蓝灰背景，硬光边缘勾轮廓，产品表面金属反射清晰，轻微体积雾。` |
| 「要温暖 / 生活感」 | `暖调低色温，自然窗光，木质台面，背景柔和虚化，画面有呼吸感但不出现人。` |
| 「要快节奏」 | `镜头切换干脆，每个镜头 1.5 秒，产品始终居中，无过渡特效。` |
| 「要慢 / 要优雅」 | `运镜极缓，单一长镜头为主，产品动作缓慢，节奏舒缓。` |
| 「不要转圈」 | `不要转台旋转，改为固定机位 + 缓慢推近 + 微距细节。` |
| 「要突出 logo / 包装文字」 | `镜头在<标签位置>停留 1.5 秒，正面平视，文字区域清晰对焦，不倾斜不遮挡。` |
| 「要适合竖屏」 | `产品置于画面中上部，下部三分之一留空，避免被平台 UI 遮挡。` |

## 五、画面文字：默认不写，用户点名才加

**模板默认全部不带画面文字**，结尾统一是「画面不出现额外文字」。这是刻意的——产品展示靠镜头讲卖点，不靠字幕。

只有用户**自己明确说**「视频里要出现『xx』这几个字」「加一句 xx 文案」时，才在 `productIntroduction` 末尾追加：

```
画面文字：<第一条>；<第二条>（最多 3 条、每条不超过 8 字，白色细体，居下三分之一，无花字特效）
```

| 用户怎么说 | 怎么处理 |
|---|---|
| 「视频里要出现『屏障修护』」 | 原样用他那几个字，不要改写、不要扩写 |
| 「帮我加几个卖点字幕」 | **先问一句要哪几个字**，不要自己编三条 |
| 「随便加两句」 | 给 3 条候选让他挑，选定后只写选中的 |
| 没说 | **一个字都不加**，把结尾的「画面不出现额外文字」留着 |

三条硬约束：最多 3 条、每条 4-8 字、语言跟随 `language`（投美国就写英文）。

## 六、负面约束清单（默认必带）

```
不要真人出镜，不要手部入画，不要手持晃动，不要快速转场，不要闪白，不要字幕花字特效，不要出现文字水印，画面不出现额外文字，不要多产品混叠，不要产品变形
```

> ⚠️ 清单里的「**画面不出现额外文字**」是默认常驻项，别删。它挡的是模型自己冒出来的乱码字，**不影响包装上本来就有的品牌名和成分表**——那些是产品本体，照实拍图渲染是对的。

按需追加：

| 场景 | 追加 |
|---|---|
| 结构复杂的产品 | `不要爆炸分解，不要展示内部结构` |
| 玻璃 / 金属 | `不要出现脏反光，不要过曝高光` |
| 有品牌名的包装 | `不要生成包装上无法辨认的乱码文字` |
| 竖屏投放 | `不要在下部三分之一放置产品主体` |
