# 产品展示短视频实操指南

产品展示（product showcase / packshot video）的本质：**没有人在说话，全靠画面说服人。** 观众 3 秒内要看清"这是什么、什么质感、凭什么值这个价"，做不到就划走。

---

## 一、什么样的产品展示视频能卖货

三条判断标准，按重要性排序：

| 标准 | 说明 | 做不到的后果 |
|---|---|---|
| **1. 三秒认得出是什么** | 第一帧就是完整产品正面，占比够大 | 观众不知道在看什么，直接划走 |
| **2. 质感可信** | 材质、光泽、纹理、液体状态要像实物 | 看起来像 3D 渲染图 / 塑料感，掉信任 |
| **3. 卖点不用字幕也能看懂** | 靠镜头、构图、质感本身传达一个明确卖点 | 得靠加字解释，说明画面没讲清 |

**最常犯的三个错：**

1. **镜头堆太多。** 8 秒塞 6 个镜头，每个镜头 1.3 秒，观众什么都看不清。**8 秒 = 3-4 个镜头，这是上限。**
2. **让产品一直转。** 全程 360° 旋转是最偷懒也最无效的做法——观众想看的是细节，不是转圈。转一圈给 1.5-2 秒就够，剩下时间给微距。
3. **拿字幕当主干。** 画面没讲清就加一行字补，观众静音刷的时候根本看不到。**默认干脆不加字**，逼自己用镜头把卖点讲明白；真要加，也是用户点名要，不是我们替他配。

## 二、镜头语言库（写进 `productIntroduction` 的弹药）

每个镜头给出：**怎么写 + 适合什么 + 常见坑**。一条 8 秒视频挑 3-4 个，12 秒挑 5-6 个。

| # | 镜头 | 怎么写 | 适合 | 坑 |
|---|---|---|---|---|
| 1 | **正面定帧** | 产品居中正面平视，占比 60%，背景纯净，静止 1 秒 | 所有品类，**永远放第一帧** | 别一上来就动，先让人看清 |
| 2 | **转台旋转** | 产品置于亚克力/石质台面，缓慢匀速旋转 90-180 度 | 瓶装、罐装、有包装盒的 3C | 转速快会糊；转 360° 浪费时长 |
| 3 | **轨道推近** | 固定机位，镜头沿直线缓慢推近至瓶身标签 | 需要突出包装文字/logo | 推太快像撞上去 |
| 4 | **微距细节** | 微距镜头贴近膏体/纹理/按键/缝线，浅景深，焦点缓慢移动 | 护肤、食品、服饰、3C | 产品图没有细节图时容易凭空发挥 |
| 5 | **光带扫过** | 一道柔光从左至右扫过产品表面，金属/玻璃/膏体出现高光流动 | 高客单、香水、酒、金属外壳 | 光太硬会出现脏反光 |
| 6 | **悬浮漂浮** | 产品离台面悬浮 2-3cm，缓慢自转，背景虚化 | 3C、香水、保健品 | 容易失重感过强像 CG |
| 7 | **开盖 / 开盒** | 镜头对准瓶盖，盖子缓慢旋开，露出膏体/液体 | 护肤、彩妆、食品 | 结构复杂的盖子容易穿模 |
| 8 | **液体 / 拉丝** | 液体缓慢倾倒、拉丝、滴落，逆光透亮 | 精华、洗发水、饮料、蜂蜜 | 流速过快像水龙头 |
| 9 | **材质对比** | 前景产品实焦，背景同色系材质虚焦（石、木、丝绒） | 家居、香氛、服饰 | 背景太抢会分散注意力 |
| 10 | **场景静置** | 产品静置于生活台面（大理石、木桌、水波），环境光自然 | 家居、食品、咖啡 | **注意：这已经接近种草，别加人** |
| 11 | **组合陈列** | 主品 + 2-3 个配件/同系列并排，缓慢横移 | 套装、礼盒、多色号 | 超过 4 个产品画面会乱 |
| 12 | **爆炸分解**（慎用） | 产品分层分解悬浮，展示内部结构 | 3C、小家电 | 极易变形，产品图信息不足时别用 |

### 2.1 黄金组合（直接抄）

| 时长 | 组合 | 写法 |
|---|---|---|
| **6 秒** | 正面定帧 → 转台旋转 → 微距细节 | 最稳的商品卡视频，几乎不会翻车 |
| **8 秒** | 正面定帧 → 转台旋转 → 光带扫过 → 微距细节 | **默认推荐**，质感与信息量平衡 |
| **12 秒** | 正面定帧 → 推近标签 → 开盖 → 微距质地 → 光带扫过 → 回到完整正面 | 详情页头图 / 信息流，讲得完材质 |
| **15 秒** | 场景静置 → 推近 → 开盖 → 液体拉丝 → 微距 → 组合陈列 → 完整正面 | TVC 短版，必须有明确分镜节奏 |

### 2.2 分句技巧

`productIntroduction` 里**一个分号 ≈ 一个镜头**。想让节奏慢就写长句，想快就写 4-6 字短句连排。

## 三、时长怎么选（4-15 秒）

| 时长 | 适合 | 镜头数 | 注意 |
|---|---|---|---|
| **4-5 秒** | 商品卡自动播放、详情页顶部小视频 | 1-2 | 只够"看清 + 转一圈"，不要指望讲卖点 |
| **6-7 秒** | 最短可用，只做外观 | 2-3 | 只够"转一圈 + 一个细节"，讲不了用法和场景 |
| **8-9 秒** | **默认推荐**，通用长度 | 3-4 | 能讲清外观 + 一个细节 + 一句卖点 |
| **10-12 秒** | 详情页头图、独立站 hero、信息流素材 | 5-6 | 能讲材质 + 用法 + 场景 |
| **13-15 秒** | 品牌 TVC 短版 | 6-7 | 必须拆成 6-7 个短句，否则后半段会散 |

**用户要 30 秒 / 1 分钟时**：只陈述「单条最长 15 秒」，让他改口。不要说"帮你拼一下"或"分两段"，本工具一次只出一条。

## 四、比例 × 平台对照

平台目前只提供 3 种比例，**按投放位置定，不要凭感觉**：

| 比例 | 适用平台 / 位置 | 备注 |
|---|---|---|
| `9:16` | 抖音、快手、小红书视频、TikTok Shop、视频号、Reels | **默认**，竖屏信息流主战场；产品要占画面中上部（下部会被 UI 遮挡） |
| `1:1` | 淘宝、天猫、京东、拼多多、抖店商品卡、1688 主图视频 | 电商主图视频位，绝大多数是方形 |
| `16:9` | 独立站 hero、官网、YouTube、B 站、Amazon A+、站外投放 | 横屏，构图留白要够 |

**判断口径**：用户说了平台就按上表替他定，并在复述里报出来；只说"做条产品视频"就按 **9:16**。

> 🔴 **3:4 和 4:3 已下线**（平台侧取消）。MCP schema 的 enum 还没同步、仍列着这两个值，但传了会被平台拒。用户点名要时只陈述「现在只支持 9:16 / 1:1 / 16:9」，让他在三个里选；**不要说"帮你转一下""后期裁一下"**。要发小红书竖版就建议 9:16，要发淘宝主图视频就建议 1:1。

## 五、灯光与背景风格库（决定"高级感"的部分）

这是 `productIntroduction` 里最值钱的一段。**用户说"要高级""要大牌感""要干净"，翻译成下面这些具体词，不要写形容词。**

### 5.1 背景

| 风格 | 怎么写 | 适合 | 观感 |
|---|---|---|---|
| **白底无影** | 纯白无缝背景，无投影，产品边缘干净 | 电商主图、平台合规要求 | 最稳，转化导向 |
| **浅灰渐变** | 浅灰到白渐变背景，产品下方极浅软阴影 | 主图升级版、独立站 | 比纯白有层次 |
| **高级灰 / 莫兰迪** | 中灰哑光背景，低饱和，产品单侧投影 | 3C、家居、香氛 | 冷淡、克制 |
| **石台 + 柔光** | 米白洞石台面，背景同色系虚化，柔光罩打光 | 护肤、香氛、家居 | 高级、有质感 |
| **水波光影** | 浅水底或玻璃台面，水面折射光斑打在产品上 | 饮料、护肤、香水 | 清爽、通透 |
| **丝绒 / 布艺** | 深色丝绒垂坠背景，单点聚光 | 珠宝、香水、礼盒 | 昂贵感 |
| **金属反射** | 拉丝金属台面，产品倒影清晰 | 3C、腕表、酒 | 硬朗、科技 |
| **自然窗光木桌** | 原木台面，侧逆自然窗光，暖调 | 食品、咖啡、家居 | 温暖、真实 |

### 5.2 灯光

| 写法 | 效果 |
|---|---|
| 大面积柔光箱，左上方 45 度主光 + 右侧补光 | 通用商业布光，最稳 |
| 顶部柔光 + 底部反光板，无硬阴影 | 白底无影棚拍 |
| 单侧硬光，制造明确投影 | 高级灰、冷淡风 |
| 逆光轮廓光，产品边缘透亮 | 液体、玻璃、香水 |
| 一道移动光带扫过表面 | 金属、玻璃、膏体高光流动 |
| 暖色低色温，营造黄昏/居家 | 食品、家居 |

### 5.3 运镜

| 写法 | 效果 |
|---|---|
| 固定机位，轻微推轨（最稳） | 干净、专业 |
| 缓慢匀速旋转（转台） | 展示全貌 |
| 微距镜头焦点缓慢移动 | 强调质感 |
| 横移横摇（slider） | 组合陈列、多产品 |
| **不要**：手持晃动、快速转场、变焦拉伸、闪白 | 产品展示要稳，晃动=廉价 |

### 5.4 必须写进 `productIntroduction` 的"不要"

```
不要真人出镜，不要手部入画，不要手持晃动，不要快速转场，不要闪白，不要字幕花字特效，不要出现文字水印
```

**这四句几乎能避免 80% 的翻车。** 只有用户明确要人手/模特时才去掉。

### 5.5 一段完整示例（可直接抄）

> 画面：纯白无影棚背景，产品居中置于亚克力台面，占比 60%，静止 1 秒后缓慢匀速旋转 120 度；镜头固定平视，缓慢推近至瓶身标签微距，柔光从左上方扫过膏体表面，膏体细腻有光泽，浅景深背景虚化；最后一帧回到完整瓶身正面。运镜平稳，单一轨道推进，无转场无闪白。不要真人出镜，不要手部入画，不要手持晃动，画面不出现额外文字。

## 六、创作要求怎么写（`productIntroduction`）

`productIntroduction` 就是平台上的**「创作要求」**栏——写给模型看的指令，观众一个字都看不到。

按四段写，分号连接，**200 字以内**：

```
产品介绍：是什么 + 品类定位；核心卖点：1-2 个能被画面证明的点；使用方式：怎么用、什么时候用；画面要求：镜头 + 灯光 + 背景 + 不要什么
```

### 6.1 四段各自写什么

| 段 | 写什么 | 例 |
|---|---|---|
| **产品介绍** | 品类 + 一句话定位 | 修护型面霜，主打屏障养护 |
| **核心卖点** | 1-2 个**画面能证明**的点 | 膏体细腻易推开、上脸不黏腻 |
| **使用方式** | 怎么用、什么时候用 | 洁面爽肤后取适量按压全脸，早晚可用 |
| **画面要求** | 镜头、灯光、背景、运镜 + 负面约束 | 白底无影棚，转台旋转 180 度，柔光左上 45 度…不要真人出镜、画面不出现额外文字 |

**「不要什么」必须写在最后**，它是最容易被模型忽略的一段。

### 6.2 画面文字：默认不写

**默认一个字都不加。** 产品展示靠镜头和质感说服人，不靠字幕。

只有**用户自己明确说**「视频里要出现『xx』这几个字」时，才在创作要求末尾加一段：

```
画面文字：xxx（最多 3 条、每条不超过 8 字，白色细体，居下三分之一，无花字特效）
```

注意三条：

- **不要自作主张配卖点字幕**——用户没提就是不要；
- **包装自带的字不算**（品牌名、成分表是产品的一部分，模型会照实拍图渲染，这是对的）；
- 模型偶尔会自己冒无意义字符，所以负面约束里常驻「**画面不出现额外文字**」。

### 6.3 用户点名要画面文字时的三条结构

```
第 1 条（0-3s）：这是什么 / 核心身份   —— 例：氨基酸洁面
第 2 条（3-7s）：强在哪（可被画面证明） —— 例：绵密泡沫
第 3 条（7s-）：规格 / 用法 / 收尾      —— 例：150ml · 早晚用
```

**硬约束**：最多 3 条，每条 4-8 字。

### 6.4 能写 vs 不能写

| ✅ 能写（画面能证明） | ❌ 不能写（画面证明不了 / 有风险） |
|---|---|
| 质地：一抹化水、绵密泡沫、哑光、丝绒 | 最好用、第一、顶级、国家级 |
| 规格：50ml、300g、三色可选 | 根治、无副作用、100%、永久 |
| 成分（用户给了才写）：氨基酸、烟酰胺 | 专利号、检测数据、临床结果、认证 |
| 用法：早晚用、洁面后、一次 2 泵 | 销量第一、全网爆款、明星同款 |
| 场景：通勤、睡前、办公室 | 治疗、消炎、祛疾（医疗宣称） |

### 6.5 品牌名要不要放

**默认不放。** 中文品牌名、生僻字、英文长词在画面里容易被写错字，写错比不写更伤。用户坚持要放：放一次，并提醒「品牌名有概率写错字，介意建议后期加」。

## 七、产品图怎么挑（比种草更苛刻）

产品展示的成片质量**直接由产品图决定**，因为画面里只有产品，没有任何东西能掩盖失真。

| 优先级 | 图 | 作用 |
|---|---|---|
| 1 | **白底正面主图**，产品占画面 50% 以上，无投影无遮挡 | 定外观、定颜色、定 logo、定比例 |
| 2 | 45° 侧面或背面 | 定厚度、定结构 |
| 3 | 细节特写（质地、瓶口、纹理、按键、缝线） | 让微距镜头有依据 |
| 4 | 开盖 / 内容物图 | 让开盖镜头有依据 |

**不要用**：带大片水印的图、九宫格拼图、带价格标签的详情页截图、多产品混在一张、严重偏色、磨皮过度的图。

**关键取舍：图多不等于好。** 同一产品的 2 张**同角度**图，比 4 张角度杂乱的图更稳——角度太杂模型会把不同视角"揉"成一个变形的产品。**推荐 2-3 张：正面 + 侧面 + 细节。**

## 九、成本与时间

| 环节 | 量级 |
|---|---|
| 素材体检 + 上传 | 5-20 秒 |
| 生成 | 通常 1-3 分钟，排队高峰可到 5-10 分钟 |
| 下载 | 几秒 |

- 一次调用出 **1 条**视频。要多个版本 = 多次调用 = 多次消耗积分。
- 常见做法：**先跑一条验证方向**（比例、构图、产品像不像、画面节奏），确认没问题再换风格跑第二版。不要一上来批量跑 10 条。
- 轮询失败或超时**不要自动重试**——可能已经在扣积分。

## 十、合规注意

- **AI 生成标识**：抖音、视频号、小红书等平台对 AI 生成内容有标识要求，投放前按平台规则自行标注。一句提醒即可，不反复说教。
- **电商平台素材规范**：部分平台对主图视频有额外要求（不得出现边框、不得出现竞品 logo、时长上限、无字幕遮挡产品等），投放前对照平台规则自查。
- **广告法**：绝对化用语（最、第一、顶级、国家级、100%、永久）不要写进创作要求里的任何文案，包括用户点名要的画面文字。
- **功效宣称**：化妆品不得宣称医疗作用；食品不得宣称治疗功效；保健品需符合保健食品广告规定。
- **肖像权**：产品展示默认不出真人，天然规避；用户要求加人手/模特时提醒一句商用授权需自行确认。

## 十一、常见需求怎么答

| 用户说 | 怎么答 |
|---|---|
| 「能不能做 30 秒 / 1 分钟？」 | 单条最长 15 秒。要更长的内容建议拆成多条，或去网页端看有没有更长档位。 |
| 「我要真人出镜 / 要模特拿着产品」 | 产品展示是纯产品画面。要真人出镜、口播种草请换到种草通道（`rhinobird-product-ugc-video`）。 |
| 「能不能对口型 / 自动配音？」 | 成片音频不保证可用，BGM 和配音建议后期加。产品展示本来就不需要口播。 |
| 「能不能加我的 logo / 水印？」 | 不做。后期自己加，也能避免 logo 生成错字。 |
| 「能不能一次出 5 条？」 | 一次一条，5 条 = 5 次调用。建议先跑一条确认效果。 |
| 「生成的产品不像 / 变形了」 | 换成白底正面主图（产品占比大、无遮挡、无水印），图从 4 张减到 2-3 张同角度。 |
| 「logo / 包装上的字写错了」 | 让产品在画面里占比更大、正面对焦；品牌名交给后期加。**不要靠加画面文字来补救**，只会多错一处。 |
| 「画面里凭空出现文字 / 字幕」 | 创作要求里被加了字卡段，或模型自己发挥。删掉字卡段，并明确写「画面不出现额外文字」重跑。 |
| 「画面里出现了手 / 人」 | 在 `productIntroduction` 里补「不要真人出镜、不要手部入画」重跑。 |
| 「太素了，像商品图在动」 | 按第五节补灯光、背景、材质描述；加"光带扫过""微距质地"这类具体镜头。 |
| 「太花了，像广告片」 | 砍到 3-4 个镜头，加"固定机位、单一运镜、无转场无闪白"。 |
| 「能不能换成 3:4 / 4:3？」 | 现在只支持 9:16 / 1:1 / 16:9 三种。要发小红书竖版建议 9:16，要发淘宝主图视频建议 1:1。 |
| 「白底做不出来，背景总是灰的」 | 明确写「纯白无缝背景、无投影、产品边缘干净」，并去掉"高级灰""石台"等背景描述。 |
