# UGC 种草短视频实操指南

> 本文件所有中文话术、答法、模板都是**语义参考**，不是给用户看的字面量。用户用什么语言聊，就用那个语言把意思重写一遍（见 SKILL.md「语言规则」）。

## 一、什么样的 UGC 种草视频容易跑起来

UGC（User Generated Content）的核心不是"拍得好看"，而是**"像一个真实的人在用这个产品"**。观众要的是可信度，不是广告片质感。

### 通用结构（10-15 秒最完整的版本）

| 时间 | 段落 | 作用 | 画面 |
|---|---|---|---|
| 0-2s | **钩子** | 一句话抓住同类人（"熬夜党必看"） | 人物/手部 + 产品入镜，或问题场景 |
| 2-4s | **痛点/场景** | 说出观众的真实处境 | 生活场景，不需要产品 |
| 4-8s | **产品出现 + 卖点** | 产品首次清晰出镜，讲一个卖点 | 产品特写、质地、包装 |
| 8-12s | **使用/效果** | 演示怎么用、用完什么感觉 | 上手、涂抹、对比 |
| 12-15s | **收尾** | 一句行动号召（"链接在左下角"） | 产品 + 人物/手部 |

**短版本就是砍段落**：8 秒砍掉痛点段，5 秒只留"产品 + 一句口号"。

### 三条硬道理

1. **一条只讲一个卖点。** 15 秒塞 5 个卖点等于没有卖点。文案里出现第二个"而且"就该删。
2. **前 2 秒决定完播率。** 钩子必须是"说给某一类人听的话"，不是"介绍一下这款产品"。
3. **画面能表达的才写。** "不黏腻"能拍（拉丝、吸收、翻手不掉），"性价比高"拍不出来。

## 二、时长怎么选（4-15 秒）

| 时长 | 适合 | 镜头数 | 注意 |
|---|---|---|---|
| **4-6 秒** | 单品特写、质地演示、一句口号 | 1-2 | 信息量极少，只适合已经有认知的产品 |
| **7-9 秒** | 钩子 + 产品 + 一个卖点 | 2-3 | 信息流投放的主力长度 |
| **10-12 秒** | **完整种草叙事（默认推荐）** | 3-4 | 讲得完一个卖点 + 一个使用动作，节奏不赶 |
| **13-15 秒** | 多镜头讲透，接近上限 | 4-5 | 必须把文案拆成 4-5 个短句，否则后半段会散 |

**分句技巧**：`productIntroduction` 里用分号切句，**一个分号 ≈ 一句字幕 ≈ 一个镜头**。想让节奏慢一点就写长句，想快就写 4-6 字的短句连排。

**用户要 30 秒 / 1 分钟时**：只陈述「单条最长 15 秒」，让他改口。不要说"帮你拼一下"或"分两段"，本工具一次只出一条。

## 三、比例与平台对照

**UGC 种草目前只有 3 个比例**（莱诺鸟平台侧已不再提供 3:4 和 4:3，别再往参数里传）：

| 比例 | 适用平台 / 位置 | 备注 |
|---|---|---|
| `9:16` | 抖音、快手、视频号、小红书视频、TikTok、Reels、Shorts | **种草默认**，竖屏短视频主战场 |
| `1:1` | 朋友圈、信息流广告、部分电商主图视频位 | 上下留白多，信息密度低 |
| `16:9` | YouTube、B 站、PC 官网、站外投放 | 横屏 |

**判断口径**：用户说了平台就按表替他定，并在复述里报出来；只说"发短视频"就按 9:16。

用户点名要 3:4 / 4:3 时：只陈述「种草视频现在只支持 9:16、1:1、16:9 三种比例」，让他在这三个里选；**不要说"帮你转一下""后期裁一下"**。要发小红书图文混排就建议 9:16 或 1:1，要发淘宝主图视频就建议 1:1。

## 四、文案与风格提示词怎么写（`productIntroduction`）

这是**唯一能控制画面风格和口播内容的输入**，工具本身没有"风格"参数。所以用户所有关于"要更真实""要有测评感""要像闺蜜推荐"的要求，都得翻译成具体描述写进这一段。

### 4.1 文案骨架（120 字内，分号连接）

```
开场钩子：xxx；痛点/场景：xxx；产品与卖点：xxx；效果/用法：xxx；收尾行动号召：xxx
```

**正例**（精华液，12 秒）：

> 开场钩子：熬夜脸第二天真的能救；痛点/场景：上妆卡粉、暗沉没气色；产品与卖点：一滴推开、不黏腻、第二天起来脸是软的；效果/用法：洁面爽肤后取2-3滴按压全脸；收尾：链接在左下角

**反例**（写了等于没写）：

> 这款精华液非常好用，质地清爽不黏腻，适合各种肤质，值得购买。

反例的问题：没有钩子（前 2 秒留不住人）、没有具体动作（画面不知道拍什么）、"非常好用"拍不出来。

### 4.2 风格提示词清单（按需挑，不要全堆）

把下面几组各挑 1-2 个写进 `productIntroduction` 末尾，用「画面风格：……」起头。

> ⚠️ **这张表是中文语义，不是要照抄的字面量**：`productIntroduction` 的语言必须跟 `language` 参数走。投英文市场就写成 `Visual style: first-person handheld selfie POV, bathroom mirror, natural window light, ...`；投日文市场就写日文。**中文风格描述塞进英文文案里，成片字幕会中英混排。**

| 维度 | 可选的写法 |
|---|---|
| **视角** | 第一人称手持自拍视角 / 手机前置镜头视角 / 桌面俯拍 / 镜前自拍 / 手部特写不露脸 |
| **人物** | 素颜、居家睡衣、刚洗完脸、上班族通勤、学生党、只露手和下颌线 |
| **场景** | 卫生间镜前 / 卧室床边 / 办公桌 / 厨房台面 / 车内 / 玄关出门前 |
| **光线** | 自然窗光 / 浴室暖光 / 夜晚台灯 / 不开美颜、保留真实皮肤质感 |
| **运镜** | 轻微手持晃动、缓慢推近、固定机位，不要花哨转场 |
| **字幕** | 口播字幕居中偏下、白色描边、口语化短句，不要花字特效 |
| **要避开的** | 广告片质感、专业打光、模特摆拍、精修皮肤、影棚背景、品牌 TVC 风格 |

**示例**（接在上面那段文案后面）：

> 画面风格：第一人称手持自拍视角，卫生间镜前，自然窗光，轻微手持晃动，素颜、只露手和下颌线，口播字幕居中偏下白色描边，不要广告片质感和专业打光。

### 4.3 三种常见 UGC 结构，按品类挑

| 结构 | 适合品类 | 文案重点 |
|---|---|---|
| **痛点 → 解决** | 护肤、个护、家清、保健品 | 开头直击问题（"卡粉""油头""厨房油污"） |
| **过程实录 / 质地演示** | 彩妆、食品、饮品、香氛 | 边用边说，强调手感、声音、质地变化 |
| **前后对比 / 测评感** | 护肤、清洁、工具类、小家电 | 强调"用了多久、变化在哪"，但**不许编造数据** |

### 4.4 不许写的

- **编造信息**：成分名（用户没给）、专利号、检测数据、临床结果、认证、销量、排名、"全网第一"。
- **《广告法》风险词**（中国市场）：最、第一、顶级、国家级、根治、无副作用、永久、100%、包治。
- **医疗功效宣称**：治疗、消炎、祛疾——化妆品/食品类一律不写。
- **别人的品牌名**：文案里不要出现竞品名，容易引战也容易生成错字。

## 五、产品图怎么挑

平台收 1-4 张，**质量比数量重要**。按这个优先级挑：

| 优先级 | 图 | 作用 |
|---|---|---|
| 1 | 正面主图，产品占画面 50% 以上，背景干净 | 定外观、定颜色、定 logo |
| 2 | 带包装/瓶身的图 | 定材质、定质感、定标签文字 |
| 3 | 细节特写（质地、瓶口、纹理、按键） | 让特写镜头有依据 |
| 4 | 手持/使用中实拍 | 定尺寸感，避免生成时比例失真 |

**不要用**：带大片水印的图、九宫格拼图、带价格标签的详情页截图、多产品混在一张的图、严重偏色或磨皮过度的图。这些会让模型"学到"错误信息。

只给 1 张也能跑，但**特写镜头容易凭空发挥**。图少的时候在复述里提一句「图少的话特写镜头会自由发挥，介意就再补一张细节图」。

## 六、品类 × 场景搭配参考

| 品类 | 推荐场景 | 推荐时长 | 推荐比例 |
|---|---|---|---|
| 精华液 / 面霜 | 卫生间镜前、卧室床边 | 12s | 9:16 |
| 彩妆（口红/粉底） | 镜前自拍、手背试色 | 9-12s | 9:16 |
| 洗护 / 家清 | 浴室、厨房台面 | 10-12s | 9:16 |
| 食品 / 饮品 | 桌面俯拍、开袋开瓶 | 8-12s | 9:16 或 1:1 |
| 3C / 小家电 | 办公桌、客厅 | 12-15s | 9:16 |
| 服饰 / 配饰 | 玄关出门前、全身镜 | 10-15s | 9:16 或 1:1 |

## 七、成本与时间

| 环节 | 量级 |
|---|---|
| 素材体检 + 上传 | 5-20 秒 |
| 生成 | 通常 1-3 分钟，排队高峰可到 5-10 分钟 |
| 下载 | 几秒 |

- 一次调用出 **1 条**视频。要多个版本 = 多次调用 = 多次消耗积分。
- 常见做法：**先跑一条验证方向**（比例、构图、产品像不像、文案节奏），确认没问题再换文案/比例跑第二版。不要一上来批量跑 10 条。
- 轮询失败或超时**不要自动重试**——可能已经在扣积分。

## 八、合规注意

- **AI 生成标识**：抖音、视频号、小红书等平台对 AI 生成内容有标识要求，投放前按平台规则自行标注。一句提醒即可，不反复说教。
- **肖像权**：成片可能出现类真人形象，商用前自行确认。想要规避就选「只露手、不露脸」的写法。
- **广告法**：见第四节 4.4，禁用词不要写进 `productIntroduction`。
- **功效宣称**：化妆品不得宣称医疗作用；食品不得宣称治疗功效。

## 九、常见需求怎么答

| 用户说 | 怎么答 |
|---|---|
| 「能不能做 30 秒？」 | 单条最长 15 秒。要更长的内容建议拆成多条短视频，或去网页端看有没有更长档位。 |
| 「我要 3:4 / 4:3」 | 种草视频现在只支持 9:16 / 1:1 / 16:9。小红书建议 9:16 或 1:1，淘宝主图视频建议 1:1。 |
| 「能不能指定视频里是谁 / 换成我本人？」 | 只能给风格描述（素颜、居家、只露手），**不能指定具体人脸**。人脸替换属于另一类能力。 |
| 「能不能对口型 / 自动配音？」 | 成片音频不保证可用，口播建议后期自己配，BGM 也后期加。 |
| 「能不能加我的 logo / 水印？」 | 不做。后期自己加。 |
| 「能不能一次出 5 条？」 | 一次一条，5 条 = 5 次调用。建议先跑一条确认效果。 |
| 「我要开箱 / 产品展示 / 痛点解决」 | 同一条通道换个模式，确认一句模式名就跑。 |
| 「生成的不像我的产品」 | 换更清晰的产品主图（正面、占比大、无遮挡），确认没有水印/拼图。 |
| 「字幕有错字 / 品牌名写错了」 | 品牌名、生僻词容易被写错。把品牌名换成拼音或去掉，或缩短文案重跑。 |
| 「画面太像广告了」 | 按第四节 4.2 补风格提示词：第一人称手持、自然窗光、素颜、不要专业打光。 |
| 「节奏太慢 / 太快」 | 用分号切句控制镜头数；15 秒塞 5 个镜头会赶，8 秒塞 3 个会挤。 |
