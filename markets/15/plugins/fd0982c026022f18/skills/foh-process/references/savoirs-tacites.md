# Capture complète des savoirs tacites

<a id="b0001"></a>

# **FOH\_TACIT\_KNOWLEDGE\_CAPTURE**

<a id="b0002"></a>

## **Purpose**

<a id="b0003"></a>

Most organizational knowledge is not written.

<a id="b0004"></a>

It exists in:

<a id="b0005"></a>

* Habits  
* Experience  
* Judgement  
* Informal practices  
* Collective memory

<a id="b0006"></a>

The objective of this document is to systematically identify and formalize tacit knowledge.

<a id="b0007"></a>

---

<a id="b0008"></a>

# **PRINCIPLE**

<a id="b0009"></a>

The difference between prescribed work and real work is valuable information.

<a id="b0010"></a>

It is not a deviation to eliminate.

<a id="b0011"></a>

It is knowledge to understand.

<a id="b0012"></a>

---

<a id="b0013"></a>

# **TACIT KNOWLEDGE CATEGORIES**

<a id="b0014"></a>

## **Category 1 — Hidden Actions**

<a id="b0015"></a>

Actions performed routinely but never documented.

<a id="b0016"></a>

Questions:

<a id="b0017"></a>

* What do experienced workers do that is not written?  
* What steps are skipped in documentation but always performed?

<a id="b0018"></a>

---

<a id="b0019"></a>

## **Category 2 — Intuitive Checks**

<a id="b0020"></a>

Controls performed automatically.

<a id="b0021"></a>

Questions:

<a id="b0022"></a>

* What do experts look at before acting?  
* What tells them something is wrong?

<a id="b0023"></a>

---

<a id="b0024"></a>

## **Category 3 — Field Adaptations**

<a id="b0025"></a>

Adjustments made when reality differs from procedure.

<a id="b0026"></a>

Questions:

<a id="b0027"></a>

* What happens when the situation does not match the procedure?  
* What adaptations are considered acceptable?

<a id="b0028"></a>

---

<a id="b0029"></a>

## **Category 4 — Failure Prevention**

<a id="b0030"></a>

Actions performed to avoid known failures.

<a id="b0031"></a>

Questions:

<a id="b0032"></a>

* What mistakes occur repeatedly?  
* What prevents those mistakes?

<a id="b0033"></a>

---

<a id="b0034"></a>

## **Category 5 — Weak Signals**

<a id="b0035"></a>

Indicators detected before a problem occurs.

<a id="b0036"></a>

Questions:

<a id="b0037"></a>

* What early warning signs do experts recognize?  
* How do they detect degradation?

<a id="b0038"></a>

---

<a id="b0039"></a>

## **Category 6 — Decision Heuristics**

<a id="b0040"></a>

Rules of thumb used by experienced personnel.

<a id="b0041"></a>

Questions:

<a id="b0042"></a>

* How do experts decide?  
* What criteria are used in practice?

<a id="b0043"></a>

---

<a id="b0044"></a>

## **Category 7 — Organizational Knowledge**

<a id="b0045"></a>

Knowledge embedded in teams.

<a id="b0046"></a>

Questions:

<a id="b0047"></a>

* Who knows what?  
* Who is consulted before difficult decisions?  
* Where does critical knowledge reside?

<a id="b0048"></a>

---
