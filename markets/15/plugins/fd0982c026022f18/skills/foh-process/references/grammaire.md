# Grammaire universelle du travail — douze blocs

<a id="b0001"></a>

# **FOH\_UNIVERSAL\_WORK\_GRAMMAR**

<a id="b0002"></a>

## **Purpose**

<a id="b0003"></a>

This document defines the universal structure of work.

<a id="b0004"></a>

It is independent of industry, trade, organization, technology, or profession.

<a id="b0005"></a>

Its purpose is to enable:

<a id="b0006"></a>

* Human execution  
* Supervision  
* Continuous improvement  
* Knowledge capitalization  
* AI-assisted execution

<a id="b0007"></a>

The grammar describes how work is structured.

<a id="b0008"></a>

FOH (Human and Organizational Factors) describes how work is understood.

<a id="b0009"></a>

Together they create a reliable representation of real work.
