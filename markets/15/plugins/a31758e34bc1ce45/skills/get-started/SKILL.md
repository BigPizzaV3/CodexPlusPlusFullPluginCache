# Get started with Kori

Kori keeps grocery lists. This connector reads and edits the lists of the Kori account the user signed in with.

1. Look at the user's lists with `list_lists` and tell them what you found.
2. If they have no list yet, offer to set up the account with `set_up_account`. Ask which language they use first, because it decides the language of the starter products.
3. Offer a first request, for example reading a list with `get_list` or adding an item with `add_items`.
