# Perspective Fix

By Imagineers Studio Inc · NebulaCafe

Rectify a photographed flat artwork/page region using explicit TL/TR/BR/BL source pixel corners and a chosen output width/height. Actual supplied pixels are projectively resampled into a PNG; an annotated source preview and exact transform JSON show the geometry used. Output dimensions are 64–2048 pixels per side. No curved-page/lens correction, missing-detail recovery or physical calibration. Wrong chosen ratio can stretch the subject; magnification adds pixels, not restored detail. Inputs: JPEG/PNG/WebP up to 20 MB and 16 megapixels. Requires a connected account; both derived previews/outputs are public.
