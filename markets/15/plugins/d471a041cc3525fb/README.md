# Resume/CV Builder

A ChatGPT plugin package by **AI EVERYDAY LIMITED**.

Version: **1.4.2**

## Description

Create or improve your CV / Resume for ATS checks and job applications in seconds, with job search and cover letter support. (by AIEveryDay.net)

## Conversation starters

- Create a CV / Resume
- Upload my CV / Resume to get started
- Help me search jobs

## Connected MCP server

OAuth endpoint: `https://aieveryday.net/wp-json/aieveryday-jobs/v1/mcp`

Authentication: OAuth Dynamic Client Registration (DCR).

Tool: `create_resume_edit_link` — accepts `resume_text` and returns `url` and `expires_at`.
