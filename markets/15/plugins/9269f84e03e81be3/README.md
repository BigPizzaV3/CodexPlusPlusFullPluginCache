# Presentr Practice for ChatGPT

Ask ChatGPT for a practice interview for your job, and Presentr Practice prepares a spoken mock interview for that role and returns a link to start it.

- MCP server: `https://practice.presentr.me/api/mcp/practice/chatgpt` (Streamable HTTP, no authentication)
- One tool: `create_practice_interview` (`job_title`, optional `company`, optional `job_posting`)
- Skill: `use-presentr-practice`
- Docs: https://practice.presentr.me/chatgpt
- Privacy: https://practice.presentr.me/privacy#chat-apps
- Support: hello@presentr.app
