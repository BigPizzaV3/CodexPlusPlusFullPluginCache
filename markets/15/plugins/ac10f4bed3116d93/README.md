# Ideagents Workbench

Develop ideas, challenge proposals and prepare scoped handoffs in the host conversation. Ideation Lab, Corp. provides this MCP-enabled package; the current local candidate is version 1.2.1. Private testing and directory review are separate from publication; this package does not claim approval.

Choose six profiles or custom perspectives, guided or quick mode, and independent documentation/diagram settings. All perspectives are generated by the host assistant. Its model, reasoning effort, voice and usage limits remain under host controls. No separate model API key, local executable or Ideagents account is required.

Three stateless tools at https://ideagents.ai/mcp provide the versioned profile catalog, atomic typed record changes, and matching Markdown/Mermaid/outline/capsule exports. Calls transmit only necessary bounded current record fields and the minimum user direction for a selected choice to Ideation Lab, Corp. State is returned to the chat, not stored as a session. Do not send transcripts, credentials, secrets or unnecessary personal data. Hosting may process ordinary request metadata; see the privacy policy. Structural checks are not factual verification, approval authentication or proof that planned tests passed.

Use [Develop an idea](skills/develop-idea/SKILL.md), [Challenge a proposal](skills/challenge-proposal/SKILL.md), or [Prepare a handoff](skills/prepare-handoff/SKILL.md). Their shared [backend guide](skills/develop-idea/assets/backend-guide.md) defines tool use and honest text fallback if the service is unavailable. An unavailable backend does not make a draft structurally checked.

Exports return copyable content. Native host artifacts may be used when available and authorized; no hosted file, save, publication, email or background job is implied. A portable capsule must be supplied again to continue in another chat. Keep caller-supplied facts and user choices distinct from model proposals.
