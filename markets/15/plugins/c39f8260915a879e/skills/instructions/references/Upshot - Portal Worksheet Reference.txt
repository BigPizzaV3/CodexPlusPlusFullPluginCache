IMPORTANT SOURCE-HYGIENE RULE
Some placeholder examples inside this graduation worksheet simplify or drift from the canonical module language.

Examples:
- A Three R’s placeholder says “Revenue, Relationship, Respect.” This is NOT the canonical Three R’s framework.
- Some positioning and Genius placeholders use shorthand that is not the canonical teaching for those modules.

Treat these as illustrative text-entry examples only.

For framework teaching, always defer to the relevant current module / Portal worksheet reference:
- Genius = Love + Energy + Big Results.
- Three R’s = Reel + Relationship + Reward.
- Three D’s = Deadline + Dollars + Decision Maker, followed by The Shift.
- Positioning work routes to Positioning Copilot™.
- Expand the Budget uses SALES and three options anchored high.
- Next-Level Negotiation uses posture, leverage, policies, clean edges, and willingness to walk away.

PURPOSE
Close Jumpstart by helping the founder:
- Name where they started.
- Identify a concrete commitment.
- Compare their “then” and “now” posture from order-taker to expert.
- Translate each module into a next habit.
- Prioritize one or two habits.
- Reflect on who they / their studio have become.
- Define the next 90 days.
- Lock the graduation reflection with a dated timestamp.

This is not another teaching module.
It is a reflection, integration, and forward-commitment exercise.

SCORING
The live worksheet calculates the average of the member’s selected NOW values on a 0–4 scale.

Score interpretation is based on the rounded average:

0:
“You are just getting started. That is the point.”

1:
“You see the problems clearly. Now comes the work.”

2:
“You have the tools. Now make them habitual.”

3:
“You are implementing. Most people never get here.”

4:
“Solved across the board. Rare.”

If both THEN and NOW scores exist and NOW is higher, the interface displays the positive change:
“+X.X since you started”

IMPORTANT LIVE STATE DETAIL
- NOW values initialize to 0 for all eight rows.
- THEN values initialize as unmarked.
- The member can change or deselect individual marks.
- The interface does not require all THEN or NOW marks to be intentionally completed before advancing.

Do not interpret untouched defaults as a deeply considered self-assessment.

PLACEHOLDER EXAMPLES
Each habit row includes illustrative placeholder text.

These placeholders are prompts, NOT canonical framework definitions.
Do not use them to override the current module references.

Examples of the kind of thinking the placeholders encourage:

Diagnose / Lead:
- Old obstacle: simply giving clients what they ask for.
- Concept: diagnose before prescribing.
- Decision: ask diagnostic questions before presenting a solution.
- Action: surface the real cost of the problem.

Expand Budget:
- Old obstacle: fear of going higher.
- Concept: anchor high and present three tiers.
- Decision: establish a pricing floor.
- Action: present multiple ways to work together.

Three D’s:
- Old obstacle: saying yes to keep the pipeline moving.
- Concept: confirm all Three D’s.
- Decision: do not send a proposal until qualification is complete.
- Action: surface who needs to approve.

Three R’s:
- Old obstacle: taking whatever comes in to stay busy.
- Use the canonical Three R’s: Reel, Relationship, Reward.
- Do NOT use the placeholder’s non-canonical “Revenue, Relationship, Respect” wording.

Positioning:
- Old obstacle: sounding interchangeable.
- Substantive positioning work belongs in Positioning Copilot™.
- Do not treat the worksheet’s shorthand placeholder as the canonical positioning method.

Genius:
- Old obstacle: spending too much time on work others could own.
- Use the canonical Genius test: Love + Energy + Big Results.
- Do not replace the Genius framework with the worksheet placeholder shorthand.

HOW JUMPSTART® COPILOT SHOULD USE THIS WORKSHEET

1. TREAT UPSHOT AS INTEGRATION, NOT NEW TEACHING
Use the member’s work across Jumpstart to help them see the overall shift from order-taker to expert.

2. HELP THEM SCORE FROM BEHAVIOR
When discussing the progress grid, ask for evidence.
Do not confuse awareness with implementation.

Useful distinction:
- Aware of the solution = “I know the framework.”
- Implementing = “I am using it in real situations.”
- Solved = “This is now reliably how we operate.”

3. DO NOT OVER-INTERPRET DEFAULT SCORES
The live worksheet initializes NOW scores at 0.
If a member has not deliberately marked a row, do not treat the default as a meaningful judgment.

4. USE CANONICAL MODULE LANGUAGE
When a graduation habit touches a framework, use the current module / Portal reference for that framework.

Especially:
- Three R’s = Reel, Relationship, Reward.
- Three D’s = Deadline, Dollars, Decision Maker + The Shift.
- Genius = Love + Energy + Big Results.

5. ROUTE POSITIONING WORK
If reflection reveals a positioning problem or the member wants to develop/rewrite positioning, route substantive work to Positioning Copilot™.

6. TURN INSIGHT INTO A DECISION
For each habit, move from:
Obstacle → Framework → Decision → Action

The decision should create a boundary or behavioral rule.
The action should be something the founder can actually do in the wild.

7. PRIORITIZE
The worksheet asks the member to star 1–2 habits first.
Help them avoid turning graduation into six simultaneous initiatives.

Ask:
Which one or two changes would create the most leverage now?

8. MAKE THE 90-DAY SENTENCE CONCRETE
A useful 90-day statement should point to a small number of observable changes rather than a vague ambition.

9. USE THE SUMMARY AS A LAUNCH POINT
The meaning of “Jumpstart complete” is not “the work is done.”
The live worksheet itself reinforces:
“The work does not stop here. It starts here.”

10. SEND THE USER BACK TO THE PORTAL
Do not recreate a replacement graduation worksheet in chat when the live Portal worksheet is available.
Use chat for reflection, challenge, prioritization, and application.
Encourage the member to record/refine final answers in the Portal.

11. IF THE USER SHARES SAVED ANSWERS
Work directly from the answers they provide.
Do not assume access to persisted Portal data that has not been surfaced in the conversation.

USEFUL COACHING QUESTIONS
- What was the actual friction when you began Jumpstart?
- What are you doing differently now—not just thinking differently?
- Which progress rows are truly “implementing” because you have evidence?
- Which row have you intellectually understood but not made habitual?
- What old obstacle still shows up under pressure?
- Which Jumpstart framework is the right response to that obstacle?
- What decision creates a line in the sand?
- What will you actually say or do the next time the situation appears?
- Which one or two habits deserve priority first?
- What would make the next 90 days meaningfully different from the last 90?
- If you fall back into order-taking, where is it most likely to happen?
- What would “expert” behavior look like in that exact moment?

KEY DISTINCTION
Graduation is not framework mastery by declaration.

The Upshot is a snapshot of:
THEN → NOW → NEXT.

THEN:
Where the founder began.

NOW:
What has actually changed.

NEXT:
Which behaviors will make the expert posture habitual.

END OF REFERENCE
