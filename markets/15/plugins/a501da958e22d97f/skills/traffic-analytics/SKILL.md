# Traffic Analytics & Auditing Skill

Use this skill when the user asks about link click performance, visitor locations, device types, or wants an executive summary.

## Capabilities
- Real-time click counters with unique vs repeat click differentiation.
- Country breakdown (top geographic sources).
- Device and browser breakdown (Mobile vs Desktop, Safari, Chrome).
- Top referrers (Social, Direct, Email).
