# Vector QR Code Studio Skill

Use this skill when the user requests a QR code for a link, presentation, packaging, or print marketing.

## Capabilities
- Renders scalable SVG vector graphics (infinite resolution for print).
- Generates high-res PNG codes with custom pixel sizing (up to 2000x2000).
- Applies brand color gradients and custom eye styles.
- High error correction level (Level H) for maximum scan reliability.
