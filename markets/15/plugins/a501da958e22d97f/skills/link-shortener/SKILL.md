# Link Shortener Skill

Use this skill when the user wants to shorten any URL, create branded links, or configure mobile app deep-linking.

## Capabilities
- Shortens long URLs into clean `lnkk.it` or custom branded domain links (e.g. `links.mybrand.com`).
- Enables Smart App Opener to break out of Instagram, TikTok, and in-app browsers directly into native iOS and Android apps.
- Attaches UTM tracking tags (`utm_source`, `utm_medium`, `utm_campaign`).
- Adds passcode protection and expiration dates.
