# Relief3D

By Imagineers Studio Inc · NebulaCafe

Turn an actual supplied opaque height map into a closed rectangular relief mesh with explicit width, height, base, amplitude, grid and optional inversion. Export STL with millimeter scale assumptions, meter-scaled self-contained GLB and exact parameter JSON, then inspect the actual 3D result. Image luminance is a chosen height signal, not measured geometry; this tool does not estimate depth from a photograph. No certified printability, CAD accuracy, physical calibration or machine toolpaths. Inputs: JPEG/PNG/WebP up to 20 MB and 16 megapixels. Requires a connected account; mesh export links are public.
