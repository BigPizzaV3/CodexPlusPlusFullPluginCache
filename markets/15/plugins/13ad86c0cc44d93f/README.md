# Folder plugin

ChatGPT upload package, Wander's layout (wander.md/plugin/). Generated by scripts/gen-plugin.mjs from ops-registry.json, the design system's brand tokens and apps/AppIcon/icon-1024.png. Requires Node 23.6+ and macOS sips.

From the repository root:

```sh
node --no-warnings folder.dev/scripts/gen-plugin.mjs
bash folder.dev/scripts/check-plugin.sh
```

The check rejects unexpected placeholders, unknown review tools, wrong icon sizes, a wrong MCP URL and any drift from the generator, extra files included. Change the generator, then regenerate.

- plugin.json: the OpenAI listing, the onboarding skill, five positive and three negative review cases; commerce is false. Published everywhere ChatGPT serves, never Russia or Belarus (common/lib/mcp/plugin.ts CHATGPT_COUNTRIES).
- mcp.json: https://mcp.folder.dev/mcp, remote streamable HTTP. OAuth 2.1 with PKCE at https://id.folder.dev; discovery at https://mcp.folder.dev/.well-known/oauth-protected-resource/mcp. Dynamic registration and client metadata documents both work. The person picks folders on the consent page.
- skills/: first use and the file workflows. The 11-tool catalog and which tools ask first come from ops-registry.json.
- assets/: logo.png at 512 × 512 and composer-icon.png at 128 × 128, resized with sips from the app icon.
- Brand: light #103DFF, dark #7B9AFF, the design system's.

The review cases assume the reviewer's Sample folder (docs/CHATGPT_PLUGIN.md): plan.md with the launch on Thursday and at least two versions, Invoices/September invoice.pdf, and an empty notes/. They are review scenarios, not a claim that a reviewer run has passed.

Still anton's: the demo video, in brackets until he records it. The listing words follow the App Store listing and the tools (store words are ours, feedback 2026-10-15).

Upload plugin.zip with plugin.json, mcp.json, README.md, skills/ and assets/ at the archive root, no enclosing folder and no __MACOSX entries.
