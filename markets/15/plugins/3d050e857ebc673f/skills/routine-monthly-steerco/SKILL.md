# Routine: monthly SteerCo prep (optional)

**Default schedule:** first Monday of the month, 08:00. Scheduled tasks may only support daily or weekly timing. If so, schedule it for Mondays, and the run skips unless it is the first Monday.

## Run instruction

> Run my Delegent monthly SteerCo prep. Use Delegent. Skip unless today is the first Monday of the month.
> For each active engagement: get the firm's status pack instructions and template from Delegent, collect evidence for the past month, and draft the pack outline (executive decision, performance against plan, workstream status, milestones, risks, decisions needed, next 14 days, sources).
> Mark every gap as "Needs confirmation". Save nothing. List what I must confirm under "Needs you".

## How to run it

Follow `draft-the-deliverable` with deliverable `status_pack`, one engagement at a time. Build full files only when the user replies asking for them. Save them with `delegent_save_file` only on request.
