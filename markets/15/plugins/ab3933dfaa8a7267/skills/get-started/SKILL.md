# Get started with Glimmerglass

1. If they ask why it goes wrong or what to do, call `get_transparent_animation_help` and answer from it.
2. If they want to see it working, call `show_animation` with a sample from `list_animations`.
3. If they have a file, call `convert_animation` with it. The first time, they sign in on a Glimmerglass page. Never ask for a license key in chat.
4. When it is done, give them the links and the embed code. Pass a Playback setting only when they ask for it.

Glimmerglass does not create animation or remove backgrounds. Say so if that is what they need.
