The companion archive contains the editable source, build inputs, tests,
and complete pinned Anatomy tree for this release. It is not needed to run the plugin.
Distribute it alongside the plugin with equivalent access for recipients under AGPLv3.
A private repository link is not a substitute for providing the source archive.

To rebuild: extract it, enter wandeo-source, install Node.js 22 or newer,
run npm ci, then npm run package:plugin or npm run package:account.
