# Connecting your personal AI

Version: 3.1.0.

1. Open your own FCC AI office at https://forevercard.club/partner/office and choose the guided connection for Claude or ChatGPT. Complete the original FCC sign in and review the requested permissions. This package contains only reusable instructions and public connection metadata.
2. Use the original account connection interface provided by your AI. The public FCC MCP endpoint is https://forevercard.club/fcc-office/mcp. Never paste a password, access token, refresh token or API key into a conversation or this package.
3. After connection, ask a small FCC question and verify that the answer came from a successful current FCC read. A copied context file and an installed skill are not proof of an active connection.
4. Ask an unrelated ordinary question separately. FCC instructions should remain inactive for that question. Your ordinary AI use, memories and chosen model do not need to change.
5. Select a first task such as a morning brief, the current programme step or one owned contact followup. Workspace permissions are requested only when needed and require current server eligibility and an active FCC PRO plan. Important changes wait for your personal review in FCC.
6. Calendar, email and a daily schedule are separate optional choices in your AI. This package does not connect them, create a schedule or change an existing one.

Claude accepts a custom skill folder in a ZIP through its Skills interface. The existing fcc-office-skill.zip keeps that folder structure. A Claude skill ZIP is not a ChatGPT plugin installer.

The separate ChatGPT package follows the portable Agent Plugins layout. It is a portable package for a supported plugin authoring or distribution flow. Attaching its ZIP to an ordinary conversation does not install a plugin or finish OAuth. Availability of a private installation path depends on the current host and account. Follow the official package guide or the existing FCC guided connection rather than assuming a ZIP upload button exists.
