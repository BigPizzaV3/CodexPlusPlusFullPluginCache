# NewsPass PR by Sitetrail

Connect your existing NewsPass account to support SEO, digital PR, media presence, brand credibility and discoverability in AI answers.

This package references the hosted NewsPass MCP server at https://connect.sitetrail.com/mcp. It includes directory metadata and the public logo, with no account credentials or private service code. The OpenAI directory listing is not yet approved.

## Connect

Start the connection in a compatible ChatGPT custom-app setup or the eventual approved directory listing. Sign in on Sitetrail and approve the requested access. Do not put your password, OAuth tokens or API keys in a chat or package file. An existing NewsPass account is required; preparing and submitting articles also require the appropriate existing entitlement and permission.

## Use

Choose a publication and read its requirements and examples before drafting. Provide article text directly or import an accessible Google Doc. A featured image is mandatory. If your AI client cannot send an image, follow the secure upload handoff returned by preparation. Check the prepared article before asking for submission; submission uses the account's existing allowance.

You can retrieve account information, publication requirements, article history, editorial feedback, live results and status notifications. Keep operation and case references after timeouts; retry the same operation rather than creating a duplicate article. Preparation does not spend a credit. Publication turnaround depends on the destination and is not guaranteed across the network.

Use Sitetrail My Account → AI Connections to manage or disconnect access. You can use your normal Sitetrail dashboard directly at any time. Disconnecting does not cancel your account or delete submitted articles.
