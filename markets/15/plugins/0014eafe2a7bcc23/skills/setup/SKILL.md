# EduChat setup

1. Call the EduChat tools `app_guide` and `app_sitemap` to check the connection. If authentication fails, ask the user to sign in to EduChat on the consent page that opens.
2. Explain the two permission levels on the consent page:
   - **View only**: ChatGPT can only read classes, submissions, feedback and the Library.
   - **View and draft actions**: ChatGPT can also create Smart Content, Library folders, and draft proposals (assign tasks, send messages). A proposal is only carried out after the user taps Confirm in EduChat (Profile → Proposals from AI apps).
3. Remind the user they can revoke the connection at any time at https://educhat.edion.app/me/ai-connections.
4. Suggest 2–3 things to try, e.g. "Any new submissions in my class?" or "Create a quiz about fractions".
