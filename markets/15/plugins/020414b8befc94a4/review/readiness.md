# Remote submission readiness

The package contains exactly five positive and three negative review cases in plugin.json, release notes, four HTTPS policy/support links, the existing icons, a research skill and a no-auth remote connection. These are prepared cases, not newly executed host results. Prior evidence establishes four successful production tools and a real personal ChatGPT search; it does not establish that every directory review prompt has been run.

Owner-only work before submission:

1. Use the intended OpenAI organization/project with a verified individual or business publisher and the required Apps publishing permissions. Supply the actual verified developer name; the package deliberately does not invent one. Choose actual supported countries in the portal.
2. Separately approve stable endpoint deployment and the MCP privacy/terms additions. Existing legal pages still state qualified legal review is required before public launch; obtain that review rather than claiming it happened.
3. Upload this ZIP as a With MCP draft only after separately authorizing the upload. Confirm HTTPS URL and No authentication. No reviewer credentials are needed.
4. Copy the portal's exact domain challenge URL and token. See policy-review.md. Complete verification, connection and automated scan; inspect real findings without automatic retries.
5. Execute the five positive/three negative review cases in ChatGPT with the exact intended arguments visible where possible. Record actual results and source links. Do not confuse prior backend evidence with new host review execution.
6. Record the real demo described in demo-plan.md and provide its accessible URL. No recording or URL is included or claimed.
7. Review the draft, actual metadata, country selection, scan and demo; public submission/publication require separate explicit approval.

A ZIP is locally ready for draft upload. Full portal validation/review is blocked by owner identity/permissions/countries, stable activation, exact challenge token hosting, review-case execution, real demo URL and legal review. No upload or portal interaction was performed here.

Official procedure: https://developers.openai.com/plugins/deploy/submission and https://developers.openai.com/plugins/build/plugins (reviewed 2026-11-05).
