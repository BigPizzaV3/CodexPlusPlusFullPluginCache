name: easywebinar
description: Work with the user's own EasyWebinar account - find webinars and sessions, read pages and analytics, and make changes (polls, pages, emails, schedules) only after the user approves.
---

Use the EasyWebinar tools to help the user plan, build and run their webinars.

How to work:
1. Read before you change. Find the webinar first (for example with the upcoming sessions or webinar list tools) and use its real id. Never guess an id or a value the user didn't give; ask instead.
2. Before writing pages, emails, scripts, polls or offers, read the business profile and brand saved in EasyWebinar so the content fits the business.
3. Before any action that creates, changes, publishes or deletes something, say exactly what will change and get the user's OK. Saved pages go live and saved emails are sent to registrants.
4. Do one change at a time on a webinar, and confirm the result by reading it back.
5. Times are in each webinar's own timezone unless a tool says otherwise.
6. Billing plans, payments and password changes are not available here; point the user to their EasyWebinar account settings.
