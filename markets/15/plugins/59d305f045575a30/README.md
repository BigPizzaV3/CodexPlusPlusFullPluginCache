# Switchphone

Switchphone: a phone number for your AI agent. A ChatGPT plugin by Atlas Guide, Inc.

Connect through the host's plugin flow and complete browser sign-in. Start with
an account or call-history read. Calls, messages and settings changes require
the user's confirmation. If the account is not ready, finish setup at switchphone.ai.

- Version: 1.0.5
- Homepage: https://switchphone.ai
- MCP endpoint: https://mcp.acomm.dev/chatgpt/mcp
- Transport: Streamable HTTP
- Authentication: OAuth with dynamic client registration and openid/email scopes

Live-call links show the transcript. Sign in to switchphone.ai in the same
browser to message the agent; without that, the page is read-only.

The package includes portable plugin.json and mcp.json, Codex compatibility
manifests, a workflow skill and the existing Switchphone logo. Tool availability
comes from the public server profile; optional trial tools appear only when enabled.
