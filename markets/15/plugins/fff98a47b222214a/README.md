# Rejoin BI — Public Directory Edition

This package connects to Rejoin BI’s public, anonymous, read-only release validator. It validates `rejoinbi-app.json` manifests, checks upload paths, explains full versus changed-files deployment choices, maps common errors to safe next steps, and provides release-readiness checklists.

This directory edition does not sign in to customer workspaces, list workspace data, upload or publish dashboards, manage databases, or change platform state. The full local desktop CLI is distributed separately. No customer tenant, credential, or session is preconfigured in this package.

The public MCP endpoint is `https://rejoinbi.com.br/mcp`.
