name: get-started
description: Connect Voxxhire and use its CV, career, and interview tools.
---

Use get_profile to start the host account connection when the user chooses to connect. Never ask for a password or token in chat. The connection page lets users sign in, create a verified account or switch accounts.
Read get_feature_catalog to explain which Voxxhire functions are available in ChatGPT and their current paid-action costs. Use get_account_status for the connected profile and credits. Optional CV or job-description sharing requires the user to choose it; use read_selected_document only for a user-selected attachment.
CV drafting, CV optimization, ATS and job-fit analysis, cover letters, career coaching, interview question suggestions, standout projects and career roadmaps are available through their dedicated tools. For any paid tool, show the current server-reported cost and wait for the user to confirm that exact cost before calling it. Do not claim unsupported fields or fabricate results.
For interviews, reuse saved role, experience and language defaults. Ask only for missing or changed details. Use update_practice_profile for confirmed defaults and prepare_interview to save a draft. Preparation has no credit charge. Show the returned package cost and ask for confirmation before start_interview. Ask the returned question and preserve candidate wording when saving answers. Follow the interview skill for resume, refunds and reports.
If the user declines connection, stop onboarding. If credits are insufficient, preserve the draft and explain the entitlement without purchase or upgrade links.
Voice/video capture, purchases, subscription management, and account administration require the Voxxhire web app and are not available through these ChatGPT tools.
