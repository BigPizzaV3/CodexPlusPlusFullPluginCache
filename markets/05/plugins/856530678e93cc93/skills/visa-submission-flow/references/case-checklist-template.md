# Personalized visa case checklist

Use one copy per application. Keep the checklist beside the case folder and update it after every artifact change.

## Header

```text
Applicant:
Current passport reference (redacted; do not paste the full number):
Nationality/residence:
Destination/mission:
Visa category/purpose:
Travel period:
Appointment:
Checklist source/retrieved:
Last verified:
```

## Status vocabulary

- `[x] VERIFIED_CURRENT` — content, identity, dates, validity, and source checked.
- `[x] VERIFIED_SIGNED` — current and signed/stamped where required.
- `[ ] PENDING` — expected but not yet received or checked.
- `[ ] WRONG_IDENTITY` / `[ ] WRONG_DATES` — do not submit until corrected or formally explained.
- `[ ] STALE` — superseded by a newer artifact.
- `[ ] CANCELLED` — never use as current proof.
- `[ ] PHYSICAL_ONLY` — user must bring the original/copy/photo.
- `[ ] OPTIONAL` — strengthening evidence, not a blocker unless the official list says otherwise.
- `[ ] UNVERIFIED` — do not claim completion from a filename or screenshot.

## Required evidence blocks

### Application and appointment

- [ ] Current official form/version and generated receipt
- [ ] Form validation/barcode/QR checked
- [ ] Required signatures, dates, photo placement, and handwritten fields checked
- [ ] Personalized official document list attached or printed
- [ ] Appointment confirmation, centre, category, date, time, and fee checked
- [ ] Centre consent/optional-service form completed only where required

### Identity and travel history

- [ ] Current passport identity fields checked; notes use redacted identifiers only
- [ ] Passport validity and blank pages checked physically
- [ ] Required passport copies prepared
- [ ] Prior visas/passports/stamps included when required or strategically useful
- [ ] Historic identity variants explained with linking evidence

### Purpose and status

- [ ] Invitation/admission/host evidence matches category and dates
- [ ] Employer/company/school/family evidence matches the applicant’s role
- [ ] Cover/introduction letter is signed and claims only enclosed documents
- [ ] Sponsor undertaking states the required costs and period

### Money and stay

- [ ] Personal/company funds separated and explained
- [ ] Required bank-statement period and source checked
- [ ] Tax/income/status records selected for the correct person/entity
- [ ] Accommodation covers required nights or has an accepted alternative
- [ ] Cancelled/partial/unpaid/temporary accommodation status understood

### Route and insurance

- [ ] Itinerary/reservation shows required route and dates
- [ ] Live reservation/PNR or provider validity checked where possible
- [ ] Departure, arrival, transit, first entry, and final exit reconciled
- [ ] Insurance uses current passport details
- [ ] Insurance covers the required territory, period, amount, emergency care, hospital care, and repatriation wording
