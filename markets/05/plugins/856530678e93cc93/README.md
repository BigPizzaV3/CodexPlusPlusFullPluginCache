# Visa Submission Flow

Made by Thoughtseed Labs. The OpenAI plugin-directory publication step remains subject to publisher verification and review.

Visa Submission Flow is a skills-only ChatGPT and Codex plugin for evidence-led visa preparation.

It helps users:

- identify the correct official requirements for a destination, mission, residence, and visa category;
- reconcile passport identity, travel dates, route, purpose, funding, accommodation, transport, and insurance;
- classify evidence as current, stale, cancelled, superseded, mismatched, optional, or unverified;
- triage submission blockers and appointment-day logistics; and
- prepare a safe print-packet plan without submitting, purchasing, uploading, or sending anything.

The bundled workflow is country-neutral. It does not provide legal advice, guarantee approval, or replace the destination authority, visa centre, or a qualified immigration professional.

## Package contents

- `skills/visa-submission-flow/SKILL.md` — the reusable workflow;
- `skills/visa-submission-flow/references/country-overlay-template.md` — destination-specific requirements template; and
- `skills/visa-submission-flow/references/case-checklist-template.md` — per-application checklist template.

The plugin has no MCP server, app connection, credentials, or external write action.
