# Maintain Character Consistency
1. Establish canonical identity, biography, motives, relationships, appearance, wardrobe, voice, movement, prohibitions, and permitted evolution.
2. Create reusable positive anchors, negative constraints, reference assets, naming, and version rules.
3. Track episode facts, state changes, props, locations, injuries, knowledge, and timeline in a canon ledger.
4. Compare new outputs against semantic, visual, vocal, and behavioral anchors; classify intentional evolution versus drift.
5. Repair conflicts at the earliest source asset or prompt component and propagate approved changes.
6. Return character bible, prompt kit, continuity ledger, drift report, repair instructions, and approval gate.
