# Build Content Engine
1. Define audience, business objective, platforms, voice, resources, cadence, constraints, and success metrics.
2. Research current platform behavior when recommendations depend on it.
3. Create content pillars, jobs, format portfolio, series engines, funnel roles, and differentiation.
4. Design idea intake, briefing, creation, review, repurposing, packaging, scheduling, publishing, measurement, and archive.
5. Build experiment backlog with hypothesis, variable, metric, guardrail, duration, and decision rule.
6. Return strategy, format bible, calendar system, workflow, templates, KPI tree, tests, and 30-day launch batch.
