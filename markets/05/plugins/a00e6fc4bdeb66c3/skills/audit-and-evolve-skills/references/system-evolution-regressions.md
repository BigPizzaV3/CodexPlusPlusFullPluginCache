# Small system-evolution regression set

Use only for changes to shared routing, context or authority. These are synthetic fixtures, not facts about the user's companies. Run read-only unless separately authorized. Preserve actual responses, runtime/date, loaded resources, result and failure reason separately from this rubric. Do not treat expected answers as observed execution. Structural tests cannot prove behavioral uplift, tool integration or perceptual quality. Keep additional independently authored cases held out from implementation.
