# Automate Any Workflow
1. Capture current process, volume, actors, systems, inputs, outputs, exceptions, delays, cost, and failure impact.
2. Remove unnecessary work before automating; identify deterministic versus judgment-heavy steps.
3. Design trigger, state, transformations, integrations, permissions, approvals, retries, deduplication, logs, and rollback.
4. Treat external writes, messages, purchases, publication, deletion, and sensitive data as explicit authorization boundaries.
5. Estimate setup cost, operating cost, time saved, error reduction, and maintenance burden.
6. Return current/future workflow, automation specification, tool requirements, exception matrix, controls, pilot, metrics, and rollout gates.
