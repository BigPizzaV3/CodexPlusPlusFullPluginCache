# Workflow extraction schema

Capture: observable outcome, triggering situations and phrases, non-trigger neighbors, actors, prerequisites, inputs, source of truth, ordered stages, branch conditions, tools, permissions, external effects, validation, exceptions, retry rules, recovery, outputs, completion evidence, frequency, cost, variability, privacy classification, owner, and review cadence.

Prefer a skill when judgment and reusable procedural knowledge are central. Prefer an SOP for human execution, automation for deterministic repeated actions, an agent for autonomous stateful loops, a connector for live external access, and a hook for mechanical enforcement.

If the captured workflow produces artifacts consumed by another person, agent, or stage, extract and preserve: stable identity, version, lifecycle status, owner, source lineage, usage boundary, precedence, dependencies, acceptance evidence, replacement history, permission boundary, and completion proof. Add a clean-room evaluation in which the next consumer receives only the declared artifact package and must proceed without hidden chat context.
