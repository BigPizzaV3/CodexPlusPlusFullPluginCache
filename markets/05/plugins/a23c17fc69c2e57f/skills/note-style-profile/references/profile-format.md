# 文体プロフィール形式

次の見出しを使い、一般の利用者が自分で直せる日本語で作る。YAMLやJSONを利用者へ強制しない。

```text
# note文体プロフィール

## 基本の語り口
[読者との距離、敬体・常体、温度]

## 文のリズム
[一文の長さ、短文と長文の混ぜ方、読点、改行]

## 導入
[始め方、避ける始め方]

## 見出しと構成
[見出しの調子、節の長さ、まとめ方]

## 具体性
[場面、会話、数字、感情の扱い]

## 好む表現
[残したい言葉や癖]

## 避ける表現
[本人が避けたい語、AI定型句、過剰な記号]

## 記事ごとに選ぶこと
[トーン、長さ、ユーモア、画像表現など固定しない項目]

## 絶対に作らないもの
[架空の経験、感情、成果、引用など]
```

各項目は短く、実行可能な文章にする。「人間らしく」「自然に」だけで終えず、文の長さ、読点、語尾、具体例の置き方まで書く。

元記事の本文、固有名詞、個人的な事実は含めない。短い言い回しを例示する場合も、利用者が残したいと確認した表現だけにする。
