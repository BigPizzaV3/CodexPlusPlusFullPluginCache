## Architect edition scope

This edition produces local plans, checks and review artifacts only. Instructions below describing provisioning, deployment, API calls, runtime tests or publishing are plans for an authorized operator, not actions to execute. Never connect to or modify an environment through this edition. No runtime test or deployment may be claimed from generated checklists.

# Reusable Component Catalog

Create `component-catalog.json` and add entries only after design, security, accessibility, and ALM review. Catalog tables, columns, relationships, form patterns, views, roles, flows, contracts, and custom components with owner, version, dependencies, and support state. Search for compatible standard or catalog components before rebuilding. Approved component changes require a version strategy and impact analysis.
