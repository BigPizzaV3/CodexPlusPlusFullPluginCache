## Architect edition scope

This edition produces local plans, checks and review artifacts only. Instructions below describing provisioning, deployment, API calls, runtime tests or publishing are plans for an authorized operator, not actions to execute. Never connect to or modify an environment through this edition. No runtime test or deployment may be claimed from generated checklists.

# Governance Portal Builder

Use the governance backlog as the blueprint for a separate role-based model-driven app. Include change requests, approvals, evidence packs, component catalog, deployment history, drift/capacity alerts, and audit. Enforce audit and permissions server-side; do not use the portal as a substitute for platform audit or compliance features. Build in its own solution, never the Default Solution.
