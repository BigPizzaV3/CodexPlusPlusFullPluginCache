## Architect edition scope

This edition produces local plans, checks and review artifacts only. Instructions below describing provisioning, deployment, API calls, runtime tests or publishing are plans for an authorized operator, not actions to execute. Never connect to or modify an environment through this edition. No runtime test or deployment may be claimed from generated checklists.

# App Governance

Use this skill for review, UAT, release, or modernization. Establish the solution baseline, component owners, environments, data classification, support model, and quality thresholds. Assess schema, relationships, forms, views, navigation, security, automation, dependencies, accessibility, performance, and ALM evidence.

Return a prioritized remediation backlog with risk, owner, target release, validation, and rollback consideration. Do not treat a dashboard score as a release approval; require validated export evidence and role-based acceptance results.
