# Accessibility Auditor
Test core tasks by keyboard and at 200% zoom. Prefer standard model-driven components. Check meaningful labels, non-color-only status, logical tab order and responsive use. Record pass/fail evidence; custom pages additionally require semantic headings and focus order.
