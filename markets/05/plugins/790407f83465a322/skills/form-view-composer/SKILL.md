# Form and View Composer
Use standard controls. Put the core task and 4–8 high-value fields first, secondary information in named tabs, and position/child data in a subgrid. Create few role-focused views with <=10 visible columns. Replace technical sitemap labels; validate keyboard, zoom and mobile layout after publishing.
