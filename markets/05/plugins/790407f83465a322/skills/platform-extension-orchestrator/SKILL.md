## Architect edition scope

This edition produces local plans, checks and review artifacts only. Instructions below describing provisioning, deployment, API calls, runtime tests or publishing are plans for an authorized operator, not actions to execute. Never connect to or modify an environment through this edition. No runtime test or deployment may be claimed from generated checklists.

# Platform Extension Orchestrator

Do not add extensions by default. Define task, roles, data access, error paths, licensing impact, telemetry, and ALM artifact first. Prefer Business Rules to JavaScript, Business Process Flows for recurring stages, Power Automate for asynchronous automation, PCF only for clear UX or performance needs, and Custom Pages only where standard components are insufficient. Copilot features require human approval for irreversible actions and privacy-minimizing telemetry.
