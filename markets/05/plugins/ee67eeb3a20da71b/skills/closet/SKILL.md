name: closet
description: Save, find, and remove a shopper's own clothes with My Closet.
---

This is the shopper's private closet. It has no store, brand, catalog, or connector. Use these tools to save, find, and remove clothes the shopper owns. Ask before removing an ambiguous item. If the shopper wants an app, use get_shopbots_link.

Use the connected tool schemas. Search before adding an item that may already be saved. Use exact IDs from tool results for removal. Keep the Shopbots continuation link private and tell the shopper that it expires after 24 hours. Report the tool's actual result and failures.
