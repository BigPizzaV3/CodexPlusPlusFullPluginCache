## 1. 근거 원칙

자기소개서의 모든 핵심 주장을 다음 셋 중 하나로 분류한다.

| 구분 | 의미 | 사용 방법 |
|---|---|---|
| 확인된 사실 | 문서, 기록, 공식 자료, 사용자의 명시적 진술로 확인 | 그대로 사용하되 날짜·역할·범위를 정확히 씀 |
| 근거 있는 해석 | 여러 사실에서 합리적으로 도출 | 사실과 구분되는 판단어를 사용 |
| 제안 문구 | 설득을 위해 새로 구성한 표현 | 사실을 바꾸지 않는 범위에서만 사용 |

다음은 생성하지 않는다.

- 확인되지 않은 활동 기간, 횟수, 참여 인원, 성적, 수상, 만족도
- 실제로 듣지 않은 칭찬, 별명, 대화
- 대상자·팀·조직의 변화를 지원자 개인의 성과로 단정하는 문장
- 지원자가 느꼈다고 말하지 않은 감정이나 깨달음
- 기관이 공개하지 않은 선발 기준을 공식 기준처럼 표현하는 문장

공식 기준이 없으면 `활동 구조상 중요해 보이는 평가축`이라는 분석으로만 다룬다.

## 2. 기관·역할 분석

현재 모집이나 제도는 공식 공고와 기관 홈페이지를 우선 확인한다. 뉴스·SNS 팁은 보조 자료로만 쓴다.

다음 표를 내부적으로 채운다.

| 질문 | 답 |
|---|---|
| 기관이 해결하려는 실제 문제는 무엇인가? | |
| 지원 역할이 반복해서 수행할 행동은 무엇인가? | |
| 지켜야 할 시간·안전·윤리·협업 조건은 무엇인가? | |
| 공고가 직접 요구하는 역량은 무엇인가? | |
| 활동 구조상 평가자가 걱정할 위험은 무엇인가? | |
| 지원자의 어떤 사실이 그 걱정을 낮추는가? | |

기관의 연혁·성과·가치를 많이 아는 것은 지원 적합성의 증거가 아니다. 기관 정보는 지원자의 선택 기준과 행동 계획을 설명하는 데 필요한 만큼만 사용한다.

## 3. 증거표

초안 전에 핵심 주장별로 다음 표를 만든다.

| 보여 줄 역량·기준 | 상황·문제 | 지원자의 판단 | 실제 행동 | 결과·외부 증거 | 배움·현재 행동 | 역할 전이 | 출처·확신도 |
|---|---|---|---|---|---|---|---|
| | | | | | | | |

각 문단에는 최소 하나의 `실제 행동`이 있어야 한다. `결과·외부 증거`가 없다면 결과를 만들지 말고 다음 중 확인 가능한 것을 사용한다.

- 완성한 산출물
- 지속 기간이나 반복 횟수
- 맡은 역할과 책임 범위
- 재요청, 선발, 공식 기록, 피드백
- 이후에 달라진 구체적인 행동

근거의 힘은 대체로 `외부 기록·검수·재요청 → 구체적 산출물 → 관찰 가능한 상대 반응 → 반복 수행·공식 역할 → 이후 달라진 행동 → 본인의 배움 선언` 순서다. 큰 성과가 없어도 괜찮지만, 핵심 경험에는 최소한 산출물·관찰 가능한 반응·반복 기록 중 하나가 있어야 한다. `배웠다`, `느꼈다`, `앞으로 하겠다`만 남으면 핵심 경험으로 쓰지 않는다.

한 문단에 여러 경험을 넣기보다, 하나의 경험을 깊게 설명한다. 보조 경험은 핵심 경험과 다른 역량을 증명할 때만 사용한다.

### 증거 준비도 판정

초안 전에 아래를 판정한다.

- **충분:** 기관 고유 근거와 핵심 경험의 판단·행동·결과가 모두 확인됨
- **보완 필요:** 논지는 세울 수 있지만 결과·역할 범위·사용 계획 같은 한 요소가 비어 있음
- **핵심 결손:** 기관·문항·핵심 경험 중 하나가 없어서 다른 글과 구별할 수 없음

`보완 필요`나 `핵심 결손`이면 현재 대화에서 제공된 첨부 자료와 사용자가 이 지원서에 사용하도록 명시적으로 지정한 과거 대화·작업 범위에서 먼저 찾는다. 지정되지 않은 대화나 접근 가능한 전체 기록은 탐색하지 않는다. 그래도 없으면 가장 점수를 크게 바꿀 사실만 1~3개 질문한다. 질문 없이 진행할 때는 확인된 사실로 임시본을 만들 수 있지만, 다음을 지킨다.

- 임시본을 `최종본`, `합격권`, `제출 완료`라고 부르지 않는다.
- 빈 결과를 미래 계획이나 감정으로 채우지 않는다.
- 기관 고유 사실이 없는데 가상의 기관 특징을 쓰지 않는다.
- 필요한 사실과 그 사실이 들어갈 문단을 짧게 명시한다.

## 4. 경험 문단 설계

STAR를 그대로 채우는 데서 멈추지 말고 판단과 역할 전이를 포함한다.

1. **상황·과제(약 15%)**: 처음 읽는 사람이 이해할 만큼만 설명한다.
2. **판단·선택(약 20%)**: 무엇을 중요하게 보고 왜 그 행동을 골랐는지 밝힌다.
3. **행동(약 35%)**: 본인이 실제로 한 일을 동사 중심으로 쓴다.
4. **결과·증거(약 15%)**: 확인 가능한 변화, 산출물, 외부 기록을 쓴다.
5. **배움·역할 전이(약 15%)**: 이후 행동이 어떻게 바뀌었고 지원 역할에서 무엇을 재현할지 쓴다.

결과보다 지원자의 판단과 행동이 선발을 좌우한다. 성과가 크지 않아도 역할과 직접 관련된 구체적 행동이 있으면 사용한다.

## 5. 수치와 결과 사용

수치는 크기보다 검증 가능성과 관련성이 중요하다.

수치를 쓸 때 다음을 확인한다.

- 무엇을 센 숫자인가?
- 기간과 기준 시점은 무엇인가?
- 개인 성과인가, 팀 전체 결과인가?
- 지원자의 기여 범위는 어디까지인가?
- 지원 역할과 어떤 관련이 있는가?

숫자가 없으면 만들지 않는다. `여러 차례`, `많은 사람` 같은 모호한 표현 대신 정확한 활동명, 역할, 반복 행동, 산출물을 쓴다. 자극적인 숫자를 소제목에 쓰려면 본문이 산출 근거와 의미를 반드시 증명해야 한다.

## 6. 치명적 오류

다음 중 하나라도 있으면 점수와 관계없이 수정한다.

- 질문에 답하지 않음
- 기관·프로그램·역할·날짜를 잘못 씀
- 확인되지 않은 사실이나 숫자를 생성함
- 글자 수·페이지·제출 형식을 어김
- 팀 성과를 개인 성과로 과장함
- 의료·교육·상담 등에서 지원자의 권한을 넘는 역할을 약속함
- 과거 글, 활동표, 면접 답변과 사실이 충돌함
- 다른 기관 이름이나 이전 지원서의 흔적이 남음
- 민감한 개인정보를 불필요하게 노출함
- 필수 근거가 비어 있는데도 추상어와 미래 계획으로 채워 제출용 최종본으로 제시함

## 7. 100점 루브릭

| 평가 항목 | 배점 | 만점 기준 |
|---|---:|---|
| 문항 적합성과 핵심 답 | 15 | 첫 문단부터 질문에 답하고 하나의 논지가 유지됨 |
| 기관·역할 맞춤성 | 15 | 기관 고유의 활동과 지원 역할에 연결되며 치환이 어려움 |
| 증거의 구체성과 소유권 | 20 | 주장마다 확인된 행동·결과가 있고 본인 기여 범위가 명확함 |
| 판단과 행동의 깊이 | 15 | 배경 나열보다 선택 이유와 실제 행동이 충분함 |
| 기여·계획의 현실성 | 10 | 선발 후 맡을 행동, 일정, 협업 방식이 실행 가능함 |
| 말투와 자연스러움 | 10 | 사용자의 진심은 남고 과도한 홍보문·모범답안 느낌은 없음 |
| 차별성과 기억점 | 5 | 자극적 표현 없이 지원자의 고유한 판단·행동이 하나 이상 남음 |
| 사실·윤리·권한 정확성 | 5 | 모든 사실이 방어 가능하고 역할 경계를 지킴 |
| 구조·문장·분량 | 5 | 문단 기능, 맞춤법, 호흡, 제한을 모두 지킴 |
| **합계** | **100** | |

85점 이상이고 치명적 오류가 없을 때 최종 후보로 본다. 동시에 기관·역할 맞춤성 12/15 이상, 증거의 구체성과 소유권 16/20 이상, 판단과 행동의 깊이 12/15 이상, 사실·윤리·권한 정확성 5/5를 각각 충족해야 한다. 기관 맞춤이 본질이 아닌 문항은 기관 점수 대신 해당 역할 맞춤성을 같은 기준으로 본다. 점수는 합격 확률을 보장하는 수치가 아니라, 재작성할 약점을 찾는 내부 도구다. 근거가 비어 있으면 문장 완성도를 이유로 후하게 채점하지 않는다.

## 8. 최종 스트레스 테스트

### 기관명 치환 테스트

기관명을 다른 곳으로 바꾸어도 문장이 성립하면 기관 고유의 활동·운영 방식·역할 근거를 보강한다.

### 지원자 치환 테스트

다른 지원자가 그대로 말할 수 있는 문장은 실제 행동, 기간, 판단, 산출물로 바꾼다.

### 면접 추적 테스트

각 문장에 `언제`, `어디서`, `본인이 무엇을`, `왜`, `결과는`, `증거는`을 물어본다. 사실대로 답할 수 없으면 삭제하거나 범위를 낮춘다.

### 문단 기여 테스트

각 문단 옆에 `이 문단 때문에 평가자가 믿게 되는 한 가지`를 적는다. 답이 없거나 다른 문단과 같으면 합치거나 삭제한다.

### 첫인상·마지막 인상 테스트

- 첫 문단 뒤에 지원자의 선택 기준과 지원 이유가 남는가?
- 마지막 문단 뒤에 선발 후 맡길 수 있는 행동이 남는가?
- 기관 소개나 감동적인 사연만 기억되지는 않는가?

### 반대 증거 테스트

평가자가 가질 수 있는 걱정을 찾는다. 예를 들어 장기 참여, 직접 경험 부족, 일정 충돌, 안전, 팀 협업이다. 걱정을 감정적 다짐으로 덮지 말고 확인된 행동이나 관리 방법으로 낮춘다.

### 다문항 문장 지문 테스트

같은 지원서의 답변이나 같은 지원자의 여러 지원서를 나란히 놓는다. `A보다 B`, `~에서 그치지 않고`, `단순히`, `먼저 살피다`, `다시 확인하다`, `성장하겠습니다`가 여러 글에서 반복되면 AI식 공통 틀처럼 읽힐 수 있다. 핵심 경험마다 고유한 사물·상황·행동 동사를 남기고, 같은 결론 구조를 두 번 이상 쓰지 않는다. 일관된 가치관은 유지하되 증명 장면과 문장 리듬은 달라야 한다.
