# Typography and layout guide

Use this guide only after seeing the current design.

## Choose a type direction

- Friendly illustrated or travel poster: rounded sans or warm humanist sans.
- Formal church, mission, or institutional poster: clean Korean sans with firm medium/bold weight.
- Hand-drawn tropical border: restrained rounded display face for the main title, neutral sans for supporting text.
- Do not use two expressive display faces together.

Search the live MiriCanvas font list and confirm availability before promising a font. Prefer a close available family over inserting a decorative text preset.

## Default hierarchy

When the user has a large central name and a smaller event line above it:

- Supporting line: about 35-50% of the main title's visual height.
- Gap between lines: about 20-35% of the main title's cap height.
- Main title: highest contrast and weight; keep within the open center area.
- Optional English name: 22-35% of the main title's visual height with slightly increased tracking.

Treat these as starting ratios, not fixed values. Adjust for Hangul density, the chosen font, and the illustration's open space.

## Color and effects

- Sample a dark color already present in the artwork before adding a new hue.
- On a white or pale center, use a dark saturated title; reserve bright accent colors for one small line or mark.
- Use one subtle shadow or outline only when contrast requires it.
- Avoid thick strokes that close Hangul counters or make small English text muddy.

## Optical checks

- Center the visible ink, not merely the text box.
- Account for asymmetric Hangul syllables and punctuation.
- Check at fit-to-page view and at a closer zoom.
- Keep comfortable air between text and illustrated borders on every side.
