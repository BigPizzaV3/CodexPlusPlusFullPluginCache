# 지원자별 판정 프레임

## 1. 완전 진단에 필요한 입력

다음이 없으면 먼저 가진 자료로 예비 진단하고, 누락 항목의 영향만 명시한다.

| 묶음 | 필요한 내용 |
|---|---|
| 기준 | 목표 학년도, 현재 학년 또는 졸업연도, 2015·2022 개정 교육과정 구분 |
| 학생부 | 전 학년·전 영역, 과목명·학점/단위·등급/성취도·원점수·과목평균·표준편차·수강자수/성취도 분포, 세특, 창체, 행동특성, 출결 |
| 학교 맥락 | 일반고·자사고·특목고·특성화고 등 학교 유형, 개설 과목과 공동교육과정 등 실제 선택 가능 범위; 학교명은 필수가 아님 |
| 수능 | 시험일이 표시된 최근 모의평가의 영역·선택과목별 표준점수, 백분위, 등급과 수능최저 충족 이력 |
| 목표 | 희망 진로·전공군, 선호 대학·지역·캠퍼스, 통학·등록금 제약, 재수 허용 여부와 위험 선호 |
| 자격 | 학교장추천 가능 여부, 지역인재·농어촌·기회균형 등 필요한 재학·거주·신분 요건, 검정고시·졸업생 여부 |
| 전형별 | 논술·면접·실기 준비도, 추천 인원, 전형일 중복 가능성 |

학생 이름, 생년월일, 학생번호, 주민등록번호, 상세 주소, 전화번호, 이메일, 사진, 바코드·QR, 보호자·교사 이름과 직업 등 판정에 불필요한 개인정보는 가리고 받는다. 특별전형 자격은 필요한 범주와 기간만 확인하고 증명서 원본은 받지 않는다. 학교명은 자격이나 실제 개설과목 확인에 꼭 필요할 때만 최소한으로 사용하며, 고교 평판 계수를 만들지 않는다.

## 2. 사실 장부

먼저 내부 장부를 만든다.

| 구분 | 기록 방식 |
|---|---|
| 확인 사실 | 학생부 페이지·영역·학기 또는 공식 문서명·쪽과 연결 |
| 근거 있는 해석 | 어떤 사실들로부터 도출했는지 함께 기록 |
| 미확인 | OCR 불명확, 페이지 누락, 최신 모집요강 미발표 등을 표시 |
| 제안 | 앞으로 할 행동이며 기존 사실처럼 쓰지 않음 |

OCR이 깨졌거나 표 셀이 모호하면 추측하지 말고 원본 페이지를 다시 확인한다. 과목명, 등급, 학기, 숫자, 대학·학과·전형명은 특히 교차 검증한다.

## 3. 자격 게이트

판정보다 먼저 아래를 확인한다.

- 지원 가능한 졸업연도·고교 유형과 전형별 추천 자격
- 지역인재·농어촌·기회균형 등의 재학, 거주, 신분 및 증빙 기간
- 모집단위별 필수 또는 권장 이수과목과 수능 응시영역
- 수능최저와 탐구 과목 수, 한국사, 영어 등급 조건
- 면접·실기·논술 일정, 단계별 선발 배수, 캠퍼스
- 학교폭력 조치사항의 해당 대학·전형 반영 방식
- 수시 지원 횟수, 복수지원·이중등록·수시 합격 후 정시 지원 제한 등 해당 학년도 규칙

하나라도 미충족이면 `지원 불가`, 확인 자료가 없으면 `자격 확인 필요`다. 이를 `상향`으로 완화하지 않는다.

## 4. 대학별 증거 벡터

범용 합산점수 대신 대학이 공개한 평가요소에 다음 증거를 매핑한다. 각 축은 `강함 / 경쟁권 / 경계 / 약함 / 미확인`으로 두고, 대학이 공개한 비중·관점을 우선한다.

### 학업 위치

- 전 과목 평균 하나보다 전공 관련 핵심 교과, 학기별 변화, 과목 난도와 이수 맥락을 본다.
- 등급·성취도뿐 아니라 원점수, 평균, 표준편차, 수강자수 또는 성취도 분포, 학점/단위를 함께 본다.
- 어려운 과목을 선택한 결과와 학교에서 실제 선택할 수 있었던 범위를 함께 해석한다.
- 성적 상승은 원인과 수업 증거가 있을 때 강점이다. 단순한 마지막 학기 한 번의 상승을 과대평가하지 않는다.

### 학업역량·탐구력

- 세특에서 `질문 또는 문제 → 교과 개념 → 탐구 방법·자료 → 결과 → 한계·성찰 → 후속 확장`의 실제 흔적을 찾는다.
- 교사의 관찰이 드러나는 수업 참여, 피드백 반영, 문제 해결, 설명·토론, 산출물의 수준을 본다.
- 주제명과 전문용어의 화려함보다 사고 과정, 정확성, 깊이, 학생의 선택과 변화가 중요하다.

### 교과이수·진로역량

- 대학·모집단위의 반영과목 또는 권장과목과 실제 이수를 대조한다.
- 관련 교과의 선택 노력, 성취, 세특이 서로 뒷받침되는지 본다.
- 여러 과목과 학년에 걸친 탐색의 발전을 찾되, 억지로 하나의 전공 서사를 만들지 않는다.
- 희망 전공이 바뀐 경우 변화의 이유와 이후 탐색이 합리적이면 그 자체를 감점하지 않는다.

### 공동체역량

- 직책 수보다 협업 과정, 소통, 책임 이행, 갈등 조정, 배려, 규칙 준수와 구체적 영향을 본다.
- 출결과 행동특성, 여러 활동의 관찰이 일관되는지 확인한다.

### 전형 고유 요소

- 학생부교과: 해당 대학의 실제 환산식, 진로선택과목·출결·가산점·추천 조건을 계산한다.
- 학생부종합: 대학의 정성평가 요소, 서류와 면접 비중, 면접 유형을 그대로 적용한다.
- 논술: 수능최저 충족 가능성과 대학별 출제 유형·최근 실전 성취를 분리해 본다.
- 정시: 해당 학년도 영역별 반영비율, 가산점, 선택과목, 영어·한국사 처리, 모집군을 적용한다.
- 실기·특기·특별전형: 실적 인정 범위와 자격 증빙을 모집요강 원문으로 확인한다.

한 활동은 여러 역량의 증거가 될 수 있다. 항목별 키워드를 세거나 모든 세부항목을 따로 점수화하지 않는다.

같은 대학도 전형에 따라 학업·탐구·진로·공동체 비중과 면접 유무가 달라질 수 있다. 한 전형에서 만든 점수나 판정을 같은 대학의 다른 전형에 복사하지 않는다.

면접은 서류와 분리해 평가한다. 서류확인형은 사실성·깊이·일관성, 제시문형은 독해·논리·적용, 수학·과학 교과형은 개념과 문제해결, MMI는 윤리·공감·상황판단을 중심으로 준비도와 변동성을 따로 표시한다. 공개된 개인 단위 자료가 없으면 단계별 통과확률을 숫자로 만들어 곱하지 않는다.

## 5. 입시결과 보정

1. 반드시 같은 대학, 캠퍼스, 모집단위, 전형을 맞춘다.
2. 현재 대학별 환산식으로 지원자 점수를 먼저 산출한다.
3. 가능하면 최근 3개 학년의 모집인원, 경쟁률, 충원, 최종등록자 50%·70% cut을 나란히 본다. 충원 자료는 공식 지표명과 단위가 `충원인원`, `충원율`, `마지막 예비번호`, `누적 충원차수` 중 무엇인지 구분하고, 분모·예비번호 부여 방식·연도·전형까지 확인하기 전에는 해석하지 않는다.
4. 전형방법, 수능최저, 모집단위 통합·분리, 인원, 추천 조건, 교과 반영식이 바뀐 연도는 비연속으로 표시하고 직접 비교하지 않는다.
5. 50%·70% cut은 최종등록자를 해당 지표 순서로 세운 위치값이지 최초합격선이나 합격확률이 아니다. 모집인원이 적으면 값이 같거나 공개되지 않을 수 있다.
6. 경쟁률은 허수 지원, 수능최저, 충원 규모의 영향을 받으므로 단독 난이도 지표로 쓰지 않는다.
7. 대학별 환산점수와 평균등급은 산출법이 다르므로 대학 간 직접 서열화하지 않는다.
8. 2028학년도는 내신 5등급제·2022 개정 교육과정·통합형 수능의 첫 적용 해다. 이전 9등급제 컷은 방향 참고만 하고 신뢰도를 낮추며, 대학이 공개한 2028 평가·환산법과 과목 정보를 우선한다.

수능최저는 최근 한 번의 최고점이 아니라 반복 충족 여부를 본다. 최근 5회 자료가 있다면 `4회 이상이며 최근 2회 모두 충족 / 2~3회 / 0~1회`를 안정·경계·위험의 상담용 보조지표로 쓸 수 있으나 공식 확률로 표현하지 않는다.

## 6. 판정 규칙

자격 게이트를 통과한 후보만 분류한다.

| 판정 | 기준 |
|---|---|
| 초상향 | 핵심 축 여러 개가 해당 전형의 최근 경쟁권보다 뚜렷하게 약하고 보완 증거도 부족하지만 지원 자체는 가능한 경우 |
| 상향 | 정량 위치가 최근 중심 구간 밖이거나 중요한 한 축이 약하나, 대학이 실제 평가하는 강한 보완 증거가 있어 합격 경로가 설명되는 경우 |
| 적정 | 정량 위치가 비교 가능한 최근 분포와 겹치고 핵심 정성 축도 경쟁권이며, 중대한 게이트 위험이 없는 경우 |
| 안정(하향) | 비교 가능한 복수 연도 결과보다 분명한 여유가 있고 정성 축과 수능최저·면접 등에도 큰 구멍이 없는 경우. `합격 보장`이라는 뜻은 아님 |
| 판정보류 | 최종 요강, 환산식, 핵심 성적·학생부 페이지 또는 자격 자료가 없어 방향 자체가 달라질 수 있는 경우 |

정량전형에서는 비교 가능한 복수 연도 모두 50% cut보다 유리하면 `안정 후보`, 50~70% 구간 또는 연도별 엇갈림이면 `적정 후보`, 다수 연도에서 70% cut보다 불리하면 `상향`을 첫 앵커로 삼을 수 있다. 이는 최종 판정이 아니며 학종에는 평균등급 하나로 적용하지 않는다.

사용자가 세 구간만 원하면 초상향은 상향 안에서 따로 경고하고, 판정보류는 그대로 남긴다. 학종·면접형, 신설 모집단위, 5명 이하 소수 선발, 2028 첫 적용처럼 변동성이 큰 경우 `안정` 대신 `상대적 안정`을 쓴다.

### 신뢰도

- `높음`: 최신 최종 모집요강, 완전한 학생 자료, 현재 환산식, 비교 가능한 3개년 이상 공식 결과가 모두 있음
- `중간`: 결론을 뒤집지 않을 일부 누락, 2개년 자료 또는 정성평가·면접 변동성이 있음
- `낮음`: 시행계획만 있음, 자료 누락, 1개년 이하, 신설·소수 모집, 전형 대폭 변경, 2028 제도 단절 등 핵심 불확실성이 있음
- `판정불가`: 학년도·전형명·지원자격처럼 분석 방향을 정하는 정보가 없음

검증·보정된 개인 단위 결과모형이 없으면 단일 숫자와 숫자 범위의 합격확률을 모두 제시하지 않는다. 확률을 요청받으면 `통계적 확률 산출 불가`라고 밝히고, 가정별 상대 판정·신뢰도와 결론을 바꾸는 조건만 제시한다. 70% cut을 70% 합격률로 바꾸거나 여러 원서의 가능성을 독립사건처럼 곱하지 않는다.

## 7. 포트폴리오와 결과 형식

희망 전공의 실제 교육과정·진로와 학생 증거를 확인한다. 단지 컷이 낮다는 이유로 이름이 비슷한 학과를 추천하지 않는다. 필요하면 인접 전공을 제안하되 차이를 설명한다.

수시 6장은 최대치이며 모두 합격 시 실제 진학할 의향이 있어야 한다. 위험 선호가 없을 때는 `상향 2 / 적정 2 / 안정 2`를 균형형 시작안으로 제시한다. 정시 경쟁력이 강하거나 합격 우선 성향이면 비율을 조정하되 수능최저·면접일·추천 제한·수시 합격 후 정시 제한까지 점검한다.

같은 약점 때문에 여섯 장이 동시에 실패하지 않도록 수능최저 유무와 교과·서류·면접형을 합리적으로 분산한다. 정시에서는 가·나·다군, 수시 이월과 대학별 환산식을 확인한다.

후보표에는 최소한 다음 열을 둔다.

`대학 | 캠퍼스 | 모집단위 | 전형 | 판정 | 정량 근거 | 정성 근거 | 핵심 위험 | 판정 변경 조건 | 자료 연도 | 신뢰도`

마지막에는 가장 큰 약점 세 개보다 적은 핵심 보완 행동만 우선순위와 기한으로 제시한다. 이미 마감된 학생부 활동을 새로 만든 것처럼 제안하지 않는다.
