# Lecture and Exam Study Route

## Source hierarchy

Use:

1. the professor's transcript or recording for explanation flow, emphasis, examples, and caveats;
2. the exam-range slides for scope and terminology;
3. prior exams or question images for observed question style;
4. external sources only to resolve missing background, never to overwrite the course framing without explanation.

## Prepare before explaining

- Align transcript segments to slide topics.
- Mark slide content that the transcript does not explicitly cover.
- Identify repeated professor phrases, contrasts, examples, and warnings.
- Identify facts that appear likely to be testable because the professor emphasized or contrasted them.
- Keep `observed emphasis` separate from `predicted exam relevance`.

## Explain

- Follow the professor's sequence unless the user requests another order.
- Explain each concept simply, then connect it to the professor's example.
- Emphasize distinctions, criteria, steps, limitations, and cause-effect relationships.
- If the transcript lacks an explanation, infer only when requested and label it as an inferred explanation.
- Never present a predicted exam item as certain.
- Honor any user-defined start phrase before beginning the lesson.

## Verify

- Match terminology and scope to the slides.
- Check dates, policies, statistics, and other time-sensitive claims against current authoritative sources when accuracy depends on recency.
- Confirm that every highlighted test point has evidence from emphasis, slide structure, or prior-question style.
