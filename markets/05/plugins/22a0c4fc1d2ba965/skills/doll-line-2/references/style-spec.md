# ドールラインβ 画風仕様

## 参照の役割

- Subject写真: 本人、髪、肌、体形、衣装、装飾、ネイル、小物、配色の唯一の根拠。
- 主Style `../assets/style_refs/style_06_flat_line_primary.jpeg`: 線、形の省略、塗り、目の濃淡、余白の視覚文法だけの根拠。

主Styleの人物や固有内容は採用しない。作者名、署名、既存作品の複製にも使わない。

## 目標の視覚文法

- **線**: 暖白色の紙面に、細く意図的な黒〜濃灰線。全域を同じ密度で描かない。
- **形**: 正しい解剖を維持しつつ、目幅、瞼角度、輪郭、配置に機械的でない僅かな差を許す。無根拠な歪みは加えない。
- **顔**: 大きな目を少数の形で構成し、鼻は短い印、口は簡潔にする。本人の眼間、視線、識別アンカーを維持する。
- **目**: 低彩度の二〜三段の面と限定した艶。完全な平面円や多重のガラス光沢にしない。生命感を残す。
- **髪**: 大きな色面を優先し、線は選択した毛束だけ。一本ごとの光沢描写を避ける。
- **衣装**: 構造と主要な折れを線で示し、色は二〜三段の面でまとめる。レースは線で読ませ、写実材質にしない。
- **肌**: 淡い一色を基礎に、目周辺と頬へ広い低彩度の赤みを限定する。エアブラシ状の美容肌にしない。
- **余白**: 暖白色を広く残す。文字指定時は低彩度の手書き文字を一度だけ置く。

## 保持と変換の境界

保持: 本人識別アンカー、眼間、視線、髪型・前髪・髪色、衣装の構造・重なり・色、アクセサリー、ネイル、タトゥー、小物、指定文字。

変換可: 写真構図（構図自由指定時）、写真的な陰影・質感・レンズ歪み、背景・UI・画面枠、線画としての形の整理と情報量。

## 最終判定

完成作は「上手いAI絵を汚した画像」ではなく、「細い線で丁寧に描き、淡い少数の面で彩色したイラスト」として成立させる。下手さを保証しない。全面的に整いすぎても、意図的に壊しすぎてもFail。
