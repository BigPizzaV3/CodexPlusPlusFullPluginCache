Read these resources only when relevant to the current PartnerProf task.

- `knowledge_map.json`: current machine-readable bootstrap map; read first for any PartnerProf workflow when live tools are unavailable.
- `task_manifest.json`: authoritative task input schema and RCS vocabulary.
- `result_interpretation_contract.json`: result-event meanings, determinism limits, feedback semantics and progress interpretation.
- `matrix_text_contract.json`: line-oriented Reality Matrix grammar.
- `large_inputs_contract.json`, `npz_input_contract.json`, `dimacs_control_sample.json`: DIMACS/NPZ large-input contracts and example.
- `composer_catalog.json`: public composer catalog and operator manifest.
- `public_knowledge_map.md`, `manual_en.md`, `task_manifest_api.md`: human-readable guidance.
- `chatgpt_app_submission.json`, `mcp.json`, `plugin_manifest.json`, `portal_fields.md`: plugin publication metadata.
- `emosophistic_public_ai_knowledge_maps.json`: reviewed public AI knowledge maps. Use as explanatory context only; cite map/node when relying on it.
- `emosophistic_public_manual_review.json`: reviewed public-purpose projections, including PartnerProf finance boundary material.
- `emosophistic_reality_field_v3_readme.md`, `emosophistic_reality_field_v3_answer_policy.json`, `emosophistic_reality_field_v3_agent_bootstrap.md`: public-safe Reality/EMO/QChronon answer boundaries. Use them to distinguish reality, record, model, interpretation, fiction, evidence and decision.
- `emosophistic_reality_field_v3_topic_index.tsv`, `emosophistic_reality_field_v3_nodes.jsonl`, `emosophistic_reality_field_v3_edges.tsv`: deeper public-safe knowledge graph. Search these only when a PartnerProf explanation needs broader conceptual grounding.

Do not treat these references as permission to run computation. Preparation and execution still require the live service/tool workflow and explicit user confirmation for runs.
