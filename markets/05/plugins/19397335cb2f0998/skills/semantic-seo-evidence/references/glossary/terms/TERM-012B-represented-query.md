# Represented Query

**Engelse term of afkorting:** Represented Query  
**Term-ID:** `TERM-012B`  
**Hoofdcategorie:** 2 Zoekintentie en queryverwerking  
**Type en context:** Frameworkterm / queryclustering  
**Bewijsbasis:** D, E en F  
**Laatst gecontroleerd:** 25 juli 2026

## Kerndefinitie

Represented Query is in deze begrippenlijst een frameworklabel voor een query die als lid van een cluster door een gekozen representative query wordt vertegenwoordigd. De term is geen algemeen gestandaardiseerde tegenhanger binnen Information Retrieval. In technische documentatie kan daarom vaak het duidelijkere woord clusterlid worden gebruikt.

## Belangrijke begrenzing

Een represented query hoeft niet per definitie langer, specifieker of smaller te zijn. Een cluster kan spellingsvarianten, synoniemen, verschillende woordvolgorden, verfijningen of queries met vergelijkbare resultaten bevatten. Welke relatie bestaat, moet afzonderlijk worden vastgelegd.

| Relatietype | Voorbeeld | Opmerking |
| --- | --- | --- |
| Parafrase | hoe ver rijdt een scootmobiel; praktische actieradius scootmobiel | Vergelijkbare taak met andere woorden. |
| Specificatie | scootmobiel bereik; scootmobiel bereik met lithiumaccu | De tweede query voegt een voorwaarde toe. |
| Variant | On Four bereik; On Four Duo bereik | Andere productentiteiten, mogelijk ander antwoord en eigen pagina. |
| Probleemverfijning | scootmobiel accu; scootmobiel accu laadt niet | De tweede query is een probleemtaak, niet alleen een smallere vorm. |
| Woordvolgorde | vision board; board vision | Woordvolgorde kan betekenis en intentie veranderen; niet automatisch hetzelfde cluster. |

## Wat is bevestigd?

- Queryclusters bestaan uit individuele queryleden die door een gekozen clusterrepresentant kunnen worden samengevat. [SRC-020]

- Queryverfijningen kunnen op waarschijnlijke intentie worden gegroepeerd. [SRC-021]

- Binnen Koray’s framework wordt represented gebruikt als tegenhanger van representative. [SRC-007]

## Wat is niet bevestigd?

- Dat Represented Query een universeel en eenduidig gedefinieerd technisch begrip is.

- Dat represented queries altijd specifieker zijn dan de representative query.

- Dat zoekmachines hun relevantie uitsluitend of hoofdzakelijk afleiden via deze specifieke tweedeling.

- Dat alle represented queries op dezelfde pagina moeten worden verwerkt.

## Praktische toepassing

1. Gebruik represented query alleen wanneer het frameworkteam de term consequent definieert.

2. Leg per clusterlid het relatietype vast, zoals parafrase, refinement, variant, probleem of vergelijking.

3. Beoordeel of de query een eigen entiteit, risico, dataset, handeling of bewijsbehoefte introduceert.

4. Gebruik in technische rapporten bij voorkeur clusterlid wanneer geen frameworkcontext nodig is.

## Veelgemaakte misvatting

“Represented betekent automatisch long-tail.” Long-tail gaat doorgaans over vraagverdeling of zoekfrequentie, terwijl represented hier gaat over de rol van een query binnen een cluster. Dat zijn verschillende dimensies.
