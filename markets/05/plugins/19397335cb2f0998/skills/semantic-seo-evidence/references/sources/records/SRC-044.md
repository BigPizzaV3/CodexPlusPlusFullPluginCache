# SRC-044 — SKOS Simple Knowledge Organization System Reference

**Attributie:** W3C (2009)  
**Bewijslabel:** A  
**Bronsoort:** W3C Recommendation  
**Publicatiestatus:** Geverifieerd  
**Laatst gecontroleerd:** 2026-07-25

## Ondersteunt

Semantische relaties zoals broader, narrower en related; taxonomieën, thesauri, concept schemes, labels en broader/narrower/related-relaties.

## Beperking

Definieert geen universele afstandsmaat; SKOS is een licht kennisorganisatiemodel en geen volledige logische ontologietaal.
