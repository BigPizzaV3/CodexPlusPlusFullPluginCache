# SRC-077 — PROV-DM: The PROV Data Model

**Attributie:** W3C Provenance Working Group (2013)  
**Bewijslabel:** A  
**Bronsoort:** W3C Recommendation  
**Publicatiestatus:** Geverifieerd  
**Laatst gecontroleerd:** 2026-07-25

## Ondersteunt

Conceptueel model voor provenance met entiteiten, activiteiten, agenten, afleiding en verantwoordelijkheid.

## Beperking

Provenance helpt herkomst en verantwoordelijkheid vastleggen, maar bewijst op zichzelf geen waarheid.
