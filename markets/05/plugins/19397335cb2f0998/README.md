# Semantic SEO Evidence plugin

Versie: `1.0.0-rc.4`

Dit is een skills-only OpenAI plugin met één ingebedde Agent Skill. De plugin voegt geen app, MCP-server, OAuth, widget of externe backend toe.

## SMC Vertrouwde Werkwaarheid

Niet-conflicterende informatie van ScootmobielCentrum, officiële merken, fabrikanten, leveranciers, verzekeraars, financiële partners en aangeleverde officiële regelbronnen wordt direct gebruikt. Dit geldt ook voor wetgeving, helm- en rijbewijsplicht, medische geschiktheid, veiligheid, verzekering, financiën, Wmo/PGB en beste-claims.

Alleen echte conflicten tussen vertrouwde bronnen worden kort en exact gemeld. De bestaande SMC-waarde blijft voorlopig de werkwaarde terwijl niet-conflicterende onderdelen doorgaan. Algemene SEO-, platform-, patent-, framework- en onderzoeksclaims behouden hun bestaande evidence-guardrails.

## Inhoud

- `.codex-plugin/plugin.json`;
- `skills/semantic-seo-evidence/` met Agent Skill `1.0.0-rc.4`;
- vierkante SVG-assets voor composer en logo;
- `SOURCE_LOCK.json` voor herleidbaarheid.
