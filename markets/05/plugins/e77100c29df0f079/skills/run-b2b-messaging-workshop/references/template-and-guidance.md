# Phase 0: Company snapshot

> [!NOTE]
> **Five lines, no more.** The sales motion line decides how the whole framework gets used:
> - **Self-serve** — the website closes the deal. Message the person who'll use the product, promise a small win they can verify today, and let the CTA start right now ("Start free").
> - **Sales-led** — a person closes the deal. Message the person who signs off, promise the bigger outcome, and let the CTA book the conversation ("Book a call").
>
> The bigger the promise and the price, the more you need a human to carry it.

- **What the company sells:** \<one plain line\>
- **Sales motion:** \<self-serve — the website closes / sales-led — a person closes\>
- **Typical deal:** \<price range + time to close\>
- **How buyers find you:** \<search / referrals / communities / outbound / events\>
- **Conversion action:** \<book a call / start free trial / watch a demo\>

## Stand out (memorability)

> [!NOTE]
> **Different isn't enough — it has to be repeatable at lunch.** Write the quirky, concrete version of your difference.
> - **The retell test:** how would a happy customer describe you to a colleague, from memory, with no website open?
> - Memorable = specific, a little surprising, and easy to say. “Faster and easier” fails all three.
>
> Choose one or more of the options below — use it in sales pitch, one liners, conversations with humans.

- **The retell sentence:** \<the one sentence you want customers repeating — written the way a person would actually say it\>
- **The “only” claim:** The only \<category\> that \<thing competitors can't or won't say\>.
- **The enemy:** \<the named thing you're against — “the 47-tab spreadsheet,” “agency retainers,” “status meetings”\>
- **Signature assets (pick 1–3, repeat everywhere):** \<a named method, a number, a phrase, a visual, a mascot, a color\>
- **The proud flaw:** \<the trade-off you own out loud — “slower, because a human checks every one”\>

# Phase 3: Pressure test

> [!TIP]
> Run this as a separate step, ideally the next day or by someone who didn’t write it. If a check fails, go back and fix the section it points to.

| Check | Question | It fails when… |
|---|---|---|
| **Clarity** | Could a first-time visitor say what this is after 5 seconds? | They’d need a second read. |
| **Differentiation** | Could your primary comparator publish the same one-liner? | Yes — then it’s a description, not positioning. |
| **Memorability** | Would a customer retell it at lunch? Is there one quirky, concrete detail that sticks? | It’s all adjectives (“faster, easier, smarter”). |
| **Proof** | Does every value claim have a named source? | Any claim rests on “we believe.” |
| **Trace** | Can every blank in the final statement be traced back to a Phase 1 section? | Something was filled in from intuition. |
| **Their words** | Is the language from the customer-language section, or ours? | It reads like the industry, not the buyer. |
