# Entrega, precio y sostenibilidad

## Entrega

Comprobar:

- Horas.
- Sesiones.
- Soporte.
- Acceso.
- Número de clientes.
- Equipo.
- Duración.
- Capacidad máxima.
- Dependencia.
- Renovación.
- Responsabilidad del cliente.

Principios:

```text
CERCANÍA ≠ ACCESO ILIMITADO
ACOMPAÑAR ≠ EJECUTAR
MÁS COSAS ≠ MÁS VALOR
```

## Entregable y bonus

### Entregable
Necesario para producir el resultado.

### Bonus
Acelera, complementa o resuelve una objeción, pero no sostiene por sí solo la promesa.

## Precio

Valorar:

- Transformación.
- Especialización.
- Duración.
- Acceso.
- Intervención.
- Evidencia.
- Alternativas.
- Precio histórico.
- Capacidad.
- Margen.
- Etapa de validación.

Separar:

- Histórico.
- Propuesto.
- Test.
- Validado.

No usar cuotas para esconder un cliente sin capacidad económica.
