# Patrones de los ocho casos

## Pilar
Trabajo interno correcto, puerta comercial abstracta.

```text
CULPA
→ PATRÓN RELACIONAL
→ ESCENA DESEADA
```

## Fran
Oferta validada que no debe reconstruirse.

```text
INFORMACIÓN FRAGMENTADA
→ COMPRENSIÓN
→ EXPRESIÓN
```

## Blinda tu Codo
Diferencial como certeza visible frente a alternativa real.

```text
ALTERNATIVA
→ OBJECIÓN DE CONFIANZA
→ ACTIVO / PRUEBA
```

## Juanjo
Separar conocimiento profundo y método reconocido.

```text
HERIDAS
→ CUELLO DE BOTELLA
→ MARCA PERSONAL
→ RESULTADO ECONÓMICO
```

## Antoni
Separar consumidor, distribuidor, proveedor y oferta propia.

```text
PRODUCTO DE TERCEROS
→ COMPRADOR CORRECTO
→ CAPA DE IMPLEMENTACIÓN
```

## Soraya
La personalidad vende en caliente; la razón permite escalar.

```text
ENTREGA REAL
→ EXPLICACIÓN RACIONAL
→ DIFERENCIAL
```

## Aida
Diferencial extraído de resultados históricos y cliente ejecutor.

```text
CAOS
→ MONETIZACIÓN
→ LANZAMIENTO
→ FORTALEZA DEMOSTRADA
```

## David
Oferta validada, problema de distribución.

```text
AUTORIDAD PRESENCIAL
→ DOCUMENTACIÓN
→ SISTEMA DIGITAL
```

## Uso

No copiar:

- Precios.
- Plazos.
- Nombres.
- Garantías.
- Mecanismos.
- Funnels.
- Tecnologías.

Aplicar únicamente el patrón cuando las condiciones sean equivalentes.
