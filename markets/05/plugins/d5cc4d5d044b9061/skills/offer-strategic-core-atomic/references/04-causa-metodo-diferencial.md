# Causa, método y diferencial

## Causa correcta

```text
ALTERNATIVA
→ EXPECTATIVA
→ RESULTADO INSUFICIENTE
→ LIMITACIÓN ESTRUCTURAL
→ NUEVA OPORTUNIDAD
```

La causa correcta debe:

- Explicar lo anterior.
- No culpar injustamente al cliente.
- Ser lógica.
- Conducir al método.
- Poder sostenerse.

## Método reconocido

Categoría que el mercado entiende:

- Psicología.
- Coaching.
- Lanzamiento.
- Marca personal.
- Nutrición.
- Hipnosis.
- Software.
- Entrenamiento.
- Mentoring.

## Nombre comercial

Identifica el programa, pero no sustituye el vehículo.

## Diferencial

Pregunta:

```text
¿Por qué esta aplicación del método
es mejor o más adecuada para este cliente?
```

Fuentes válidas:

- Especialización.
- Diagnóstico.
- Personalización real.
- Tecnología.
- Implementación.
- Evidencia.
- Menor fricción.
- Secuencia.
- Integración.
- Replicabilidad.
- Adecuación al nivel.
- Resultados históricos.
- Modalidad de entrega.

## Test de copia

```text
¿Un competidor podría copiar la frase
sin cambiar su servicio?
```

Si puede, todavía no hay un diferencial estructural.
