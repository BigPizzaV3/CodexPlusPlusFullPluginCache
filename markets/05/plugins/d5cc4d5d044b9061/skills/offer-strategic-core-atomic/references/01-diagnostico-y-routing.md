# Diagnóstico y routing

## Paso 1 — Varias líneas

Elegir una sola según:

1. Prioridad.
2. Validación.
3. Resultados.
4. Autoridad.
5. Capacidad.
6. Potencial económico.
7. Sostenibilidad.

## Paso 2 — Clasificación

### A — Oferta no definida
Faltan cliente, deseo o vehículo.

### B — Definida pero débil
Existe producto, pero promesa o diferencial son genéricos.

### C — Validada con cuello comercial
Vende y entrega; falla mensaje, precio, autoridad, funnel o distribución.

### D — Vende pero no es sostenible
El acceso, soporte, margen o perfil de cliente colapsan la entrega.

### E — Validada y escalable
Núcleo y operación sólidos; procede optimizar distribución y valor de vida.

## Paso 3 — Cuatro pilares

Diagnosticar por separado:

- Marketing.
- Ventas.
- Servicio.
- Operativa.

## Árbol resumido

```text
¿Hay ventas?
├─ No → Construir hipótesis de núcleo.
└─ Sí
   ├─ ¿Hay resultados y satisfacción?
   │  ├─ No → Revisar cliente, promesa y entrega.
   │  └─ Sí
   │     ├─ ¿Retiene y es sostenible?
   │     │  ├─ No → Rediseñar acceso, precio o cliente.
   │     │  └─ Sí → Conservar núcleo y revisar distribución.
```

## No confundir

- Falta de ventas con falta de demanda.
- Baja agenda con falta de dolor.
- Saturación con falta de precio.
- Autoridad no comunicada con autoridad inexistente.
