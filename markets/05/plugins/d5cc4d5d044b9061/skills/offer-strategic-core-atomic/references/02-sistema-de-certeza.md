# Sistema de certeza

## CONFIRMADO
Afirmado por el negocio o respaldado por evidencia.

## INFERENCIA SÓLIDA
Conclusión directa a partir de varios hechos.

## DECISIÓN ESTRATÉGICA
Dirección seleccionada para construir la oferta.

## HIPÓTESIS
Idea coherente pendiente de validación.

## PENDIENTE
Dato crítico todavía desconocido.

## NO UTILIZABLE
Dato contradictorio, sensible, no demostrable o fuera del control del negocio.

# Tipos de cifras

Separar siempre:

- Resultado histórico.
- Objetivo estratégico.
- Proyección.
- Ejemplo matemático.
- Precio propuesto.
- Precio validado.
- Garantía.

# Reglas

- Una cifra mencionada como ejemplo no se convierte en promesa.
- Una recomendación de precio no se convierte en precio validado.
- Un caso de la red no se convierte en caso propio.
- Una explicación persuasiva no se convierte en evidencia científica.
- Una escena deseada no se convierte en garantía.
