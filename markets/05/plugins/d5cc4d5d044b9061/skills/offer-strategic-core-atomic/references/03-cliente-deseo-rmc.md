# Cliente, deseo y RMC

## Cliente en dos capas

```text
CATEGORÍA RECONOCIBLE
+
SITUACIÓN ESPECÍFICA
```

Investigar:

- Nivel de evolución.
- Qué sabe.
- Qué ha probado.
- Dinero y tiempo invertidos.
- Qué repite.
- Qué no consigue.
- Capacidad de ejecución.
- Capacidad económica.
- Razón para actuar.

## Test

```text
¿Se reconoce?
¿Comparte deseo?
¿Comparte causa?
¿Puede ejecutar?
¿Puede pagar?
¿Puede conseguir el resultado?
```

## Deseo dibujable

Formas válidas:

- Cifra.
- Escena.
- Conducta.
- Capacidad.
- Evento.
- Evidencia.

Transformación:

```text
INTANGIBLE
→ MANIFESTACIÓN
→ CONSECUENCIA
→ ESCENA DESEADA
```

## RMC

Puede ser:

- Numérico.
- Hito verificable.
- Conductual.
- Antes/después.
- Frecuencia.
- Capacidad demostrable.
- Combinación de evidencia y experiencia.

## Test del check

```text
¿Un tercero razonable puede verificarlo?
```

## Datos insuficientes

Entregar:

- `RMC PROPUESTO PARA VALIDAR`.
- Razón estratégica.
- Métrica o evidencia necesaria.
- Plazo pendiente, cuando corresponda.
