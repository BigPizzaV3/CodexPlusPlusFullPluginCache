# Principios nucleares Atomic

```text
CLIENTE RECONOCIBLE Y PROFUNDO.
DESEO EN UN DIBUJO.
RMC CON UN CHECK.
CAUSA QUE EXPLICA EL FRACASO.
MÉTODO QUE EL MERCADO ENTIENDE.
DIFERENCIAL QUE EXPLICA SUPERIORIDAD.
MECANISMO DE EXACTAMENTE TRES HITOS.
```

## Distinciones obligatorias

```text
LO QUE QUIERE ≠ LO QUE NECESITA TRABAJAR
MÉTODO ≠ NOMBRE COMERCIAL
DIFERENCIAL ≠ AUTORIDAD
MECANISMO ≠ MÓDULOS
OBJETIVO ≠ RESULTADO HISTÓRICO
HIPÓTESIS ≠ GARANTÍA
CERCANÍA ≠ ACCESO ILIMITADO
```

## Orden estratégico

```text
DIAGNÓSTICO
→ FOCO

→ RMC
→ CAUSA
→ MÉTODO
→ DIFERENCIAL
→ MECANISMO
→ OBJECIONES
→ CERTEZA
→ SOSTENIBILIDAD
```

## Regla de conservación

No reconstruir una oferta con ventas, resultados y retención hasta localizar el cuello de botella real.

## Regla de creatividad

La Skill puede proponer una estrategia nueva, pero debe etiquetarla como hipótesis cuando no exista evidencia.

## Regla de salida

La respuesta debe sonar específica para el negocio. Una salida que podría servir a veinte negocios distintos no está aprobada.
