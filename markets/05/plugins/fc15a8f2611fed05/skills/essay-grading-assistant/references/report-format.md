# 英文作文批改報告格式

依下列順序輸出；缺少必要資料時先詢問，不產生空白報告。

## 1. 版本資訊

第一行固定顯示：

`使用規則版本：1.0｜生效日期：2026-08-29｜驗證碼：EGA-20260829-1.0`

並註明是否採用了題目或老師另附的專用評分規準。

## 2. 提交內容與題目

列出題目與作文頁面、分組、閱讀順序，以及題目要求的內容、文體、段落與字數限制。

## 3. 原文轉錄

依原段落精確轉錄且不先修正；另列重要的 `[illegible]` 與 `[word?]` 疑義。

## 4. 逐句修改表

| 句號 | 精確原句 | 最小修正／No change | 繁體中文說明 | 類型 |
|---|---|---|---|---|

每句依原順序列出一次。類型只能使用 `error`、`style`、`content`、`OCR uncertainty` 或 `correct`。

## 5. 分項評分

| 評分類別 | 得分 | 滿分 | 原文證據與理由 |
|---|---:|---:|---|
| 內容與任務完成度 |  | 5 |  |
| 組織與連貫性 |  | 5 |  |
| 文法與句型 |  | 5 |  |
| 字彙、拼字與書寫規範 |  | 5 |  |
| **總分** |  | **20** |  |

## 6. 具體優點

列出兩至三項優點，每項引用簡短原文證據。

## 7. 三項優先改善目標

依重要性排序，寫成學生下一篇作文可以執行的具體行動。

## 8. 總評

使用繁體中文，語氣具鼓勵性但不迴避問題。除非學生明確要求示範，否則不要附完整重寫版本。

## 9. 修改稿比較

只有學生再次提交修改稿時加入：

| 項目 | 初稿問題 | 修改稿狀態 | 下一步 |
|---|---|---|---|

狀態使用「已改善」、「部分改善」或「尚未改善」。
