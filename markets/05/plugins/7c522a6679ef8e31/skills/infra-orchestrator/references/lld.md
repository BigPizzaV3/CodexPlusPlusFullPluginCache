# LLD Module

Turn verified project evidence into a controlled technical design.

## Rules
- Reconcile project sources before designing.
- Keep customer/project boundaries strict.
- Do not invent missing IPs, VLANs, WWPNs, ports, firmware, hostnames, credentials or object names.
- Mark unresolved values as TBD.
- Separate current state, target state, decisions, assumptions, constraints, and acceptance criteria.
- Vendor-sensitive choices require current verification.

## Typical output
Scope, requirements, source hierarchy, architecture, component inventory, IP/VLAN/VSAN tables, SAN zoning and WWPN mapping, storage mapping, backup policies/plans/copies, dependencies, implementation considerations, monitoring, validation/acceptance, risks, rollback assumptions, TBD register.
