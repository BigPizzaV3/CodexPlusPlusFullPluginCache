# Customer Readiness and TBD Module

Generate only inputs actually needed for the project.

## Ownership buckets
- Customer to provide
- Coordinate jointly
- Implementation team responsibility

## Priority buckets
- Required before work
- Recommended / useful
- Can be collected during implementation

Prefer existing reports/exports over asking the customer to manually type information already available elsewhere. Do not ask speculative questions simply to make the list longer.

For access readiness, ask whether approved access is available through the customer's secure mechanism. Never ask the customer to send passwords, private keys, API keys, tokens, recovery codes, or other secret values in chat, email, or project artifacts.

Typical areas: approved access availability, management IP, subnet/gateway, DNS/NTP, VLAN/VSAN, rack/RU, power, cabling, maintenance window, restart restrictions, application owners, vendor support access, reports/config exports, backup/rollback prerequisites.
