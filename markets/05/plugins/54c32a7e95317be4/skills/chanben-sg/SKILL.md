# ちゃんべん　情報セキュリティマネジメント試験

## 対象と根拠資料

- 対象はIPAの「情報セキュリティマネジメント試験（SG）」である。公式略号はSG。
- 現行の正式資料を毎回IPA公式で確認する。作成時点（2026年8月29日）の正式な現行シラバスは「情報セキュリティマネジメント試験（レベル2）シラバス Ver.4.1」（2025年4月17日）である。
- 現行シラバス一覧: https://www.ipa.go.jp/shiken/syllabus/gaiyou.html
- 現行シラバスPDF: https://www.ipa.go.jp/shiken/syllabus/nl10bi0000007tch-att/syllabus_sg_ver4_1.pdf
- 試験区分ページ: https://www.ipa.go.jp/shiken/kubun/sg.html
- 2026年新制度の変更案ページ: https://www.ipa.go.jp/shiken/syllabus/henkou/2026/20260630.html
- 新制度ページでSGが「準備中」の間は、準備中の案を確定基準として扱わず、現行の正式版を使用する。新しい正式版が公開・施行されたら、実行時に適用時期を確認して切り替える。
- `references/syllabus-map.md` は検索補助であり、公式最新版と差があれば必ず公式資料を優先する。

## 毎回の最新版確認

1. IPAのシラバス一覧、SG試験区分ページ、新制度の変更案ページを実行時に確認する。
2. ユーザーが試験時期を指定した場合は、その時期に適用される正式版を選ぶ。指定がなければ実行時点の現行正式版を基準にする。
3. Ver.4.1など版番号・公開日・適用時期を記録する。将来版が公開された場合は、古い固定版を使い続けない。
4. 準備中・案・施行前の資料を現行試験の確定基準として扱わない。
5. 問題の根拠にしたPDF、最新版確認ページ、定義補足の一次資料を実際に参照し、回答後に全リンクを示す。

## 入力と対話

- 用語指定なら、適用シラバス内の分類・項目・近縁語を特定する。分野指定なら代表語を一つ選び、その理由を示す。
- 指定語が適用資料にない場合は、非掲載であることと近い掲載語を伝え、勝手に出題しない。
- 問題数の指定がなければ1問。生成問題を過去問やIPA公式問題と呼ばない。
- 出題時は問題文と四択だけを示し、正解・解説・出典を伏せて1〜4の回答を待つ。
- 回答後に判定、正解、四つすべての正誤理由、誤答が表す本来の概念、根拠資料と実際に参照した全サイトを示す。

## 4択問題の設計

1. 正答は一つだけにする。定義、識別、攻撃・防御の状況設定、ログや運用判断を使う。
2. 誤答は原則「別の近縁用語なら正しい説明」にする。同じ領域・隣接領域から選び、架空語や明らかな誤りを避ける。
3. 近縁概念の例: リスクアセスメント／リスク対応／リスク受容、脅威／脆弱性、認証／認可、IDS／IPS／WAF、EDR／SIEM、ハッシュ／MAC／電子署名／暗号化、XSS／CSRF／SQLインジェクション、インシデント／問題管理、RTO／RPO、可用性／完全性／機密性、個人情報保護法／不正アクセス禁止法／不正競争防止法／情報流通プラットフォーム対処法、SPF／DKIM／DMARC、ISMS／PDCAなど。
4. 選択肢の文体・長さ・具体性をそろえ、対象と観点を混ぜない。正答が複数成立しないことを確認する。
5. 法令・脆弱性・プロトコル仕様は更新され得るため、IPAその他の一次資料で最新内容を確認する。

## 出力形式

出題時は「ちゃんべん　情報セキュリティマネジメント試験」「使用資料」「【問題】」「1〜4」「1〜4の番号で回答してください。」を示す。

回答後は次を必ず含める。

- 【判定】と【正解】
- 【選択肢別解説】: 四つすべてに「正解／不正解」を付け、不正解は本来の概念名と正しい意味まで説明
- 【根拠となったシラバス】: 使用した正式名称、版、公開日、該当箇所、IPA公式PDFの直接リンク
- 【参考にしたサイト】: 最新版・適用時期確認ページを含め、実際に参照した全ページの名称・用途・リンク

正解位置は連続して偏らないよう変える。原文の長い転載は避ける。

## 完了前チェック

- 実行時にIPA公式の現行版と適用時期を確認したか。
- 指定語が使用資料に掲載されているか。
- 正答は一つで、三つの誤答に本来の概念名があるか。
- 回答後に全選択肢、根拠資料、実際に参照した全サイトを示すか。
