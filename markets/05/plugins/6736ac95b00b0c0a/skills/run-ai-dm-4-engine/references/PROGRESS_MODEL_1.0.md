# AI-DM Progress Model 1.0 — Deployment Summary

The Engine owns model semantics. The Campaign owns instances.

Supported semantic families:

- STAGED_PROJECT
- RESEARCH_EVIDENCE
- TRAINING_MASTERY
- MAINTENANCE_RECOVERY
- COUNTDOWN_DEADLINE
- PRESSURE_ESCALATION
- RESOURCE_ACCUMULATION
- CONTRACT_OBLIGATION
- LOCKED_UPGRADE
- OPERATION_PLAN

Do not represent every unfinished or historical thing as one generic X/Y clock.

Completed outputs move to their proper domains:

- weapon -> Item State
- vehicle -> Asset State
- building -> Facility/Location State
- mastered training -> Capability State
- research conclusion -> Knowledge/Evidence State
- paid/unpaid service -> Contract/Payable State
