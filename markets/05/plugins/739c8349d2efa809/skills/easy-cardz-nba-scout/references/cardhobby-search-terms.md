# CardHobby search terms

Use CardHobby's visible search controls and ordinary navigation. Combine one player-name variant with one or two attribute terms at a time; avoid broad automated collection.

## Search sequence

1. Search the player's full English name.
2. Repeat with the player's common hobby alias or surname when results are sparse.
3. Use the Chinese name when it is known from a reliable source or visible CardHobby results. Do not invent a transliteration.
4. Add one relevant attribute term, then try the English equivalent if needed.
5. Open plausible results and verify attributes on the individual detail page; search text alone is not proof.

## Attribute vocabulary

| Attribute | Useful terms |
|---|---|
| Serial-numbered | `编`, `/99`, `/49`, `/25`, `/10` |
| Autograph | `签字`, `卡签`, `auto` |
| Patch or memorabilia | `球衣`, `物料`, `patch` |
| Rookie | `RC`, `新秀`, `RPA` |
| Graded | `PSA10`, `PSA 10`, `BGS`, `SGC` |
| Popular sets | `Prizm`, `Select`, `Noir`, `Immaculate`, `Flawless`, `National Treasures`, `One and One` |

Treat abbreviations carefully. Confirm serial numbering, autograph type, patch or memorabilia wording, grader and grade, rookie status, and exact set from the listing detail page.

## URL verification record

For each retained candidate, capture:

- Exact post-load URL.
- Visible listing number or auction ID.
- Full listing title and player.
- Active status and end time.
- Current price and visible shipping.
- Seller name only as needed to distinguish the listing.
- Exact card attributes.
- Reopen result: Match or Fail.

Only a reopened exact match may be labeled Verified.
