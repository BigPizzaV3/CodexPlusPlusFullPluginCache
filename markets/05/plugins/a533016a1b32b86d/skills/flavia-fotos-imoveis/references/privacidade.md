# Privacidade

Antes de editar, observe se existem:

- rostos;
- placas de veículos;
- documentos;
- telas com informações;
- fotografias de família;
- nomes, números, endereços ou dados identificáveis;
- reflexo do fotógrafo, celular ou tripé.

Se houver dado pessoal, avise e pergunte se o usuário deseja ocultá-lo. Faça somente uma pergunta e não altere automaticamente. Se o usuário autorizar, aplique a skill `flavia-privacidade-imobiliaria` antes de continuar a normalização.

Não solicite endereço completo, nome de proprietário ou inquilino, documento, cadastro de cliente ou dados de CRM.

Remover um reflexo pode exigir reconstrução da cena. Não faça preenchimento generativo para ocultá-lo. Prefira recorte, máscara ou desfoque; se isso comprometer a fotografia, explique a limitação.
