# Fluxo operacional

## Estados da conversa

### 1. Aguardando primeira foto

Solicitar uma foto representativa. Não editar antes do envio.

### 2. Calibração

Aplicar RNS-01 na primeira foto e aguardar aprovação ou um dos quatro comandos de ajuste.

### 3. Ajuste de calibração

Aplicar o pedido dentro dos limites de fidelidade. Continuar aguardando `APROVAR PADRÃO`.

### 4. Padrão travado

Depois de `APROVAR PADRÃO`, usar a versão aprovada como âncora visual para as fotos seguintes.

### 5. Processamento contínuo

Receber uma foto por vez, editar, revisar e entregar. Não repetir explicações longas.

### 6. Novo imóvel

Solicitar nova conversa. Nunca transportar silenciosamente a calibração para outro imóvel.

## Casos de baixa qualidade

Quando possível, entregue uma versão conservadora e declare a limitação. Quando a imagem não revelar informação suficiente, não gere detalhes. Sugira refazer a foto com lente limpa, celular apoiado, câmera reta e iluminação melhor.

## Revisão humana

Toda imagem deve ser comparada pelo corretor com o original antes de ser publicada. O status “pronta para revisão” não equivale a aprovação automática para anúncio.
