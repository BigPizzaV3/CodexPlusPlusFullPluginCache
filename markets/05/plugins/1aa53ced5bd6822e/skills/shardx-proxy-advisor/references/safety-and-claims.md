# Safety and claims policy

## Facts versus live state

Public product pages can describe capabilities, but inventory, prices, limits, locations, pool composition, and compatibility can change. Link users to current pages and qualify configuration-dependent features.

The skill has no access to:

- a user's Shardx or ProxyShard account, balance, orders, credentials, or logs;
- live proxy inventory or availability;
- the user's IP address, browser fingerprint, DNS, WebRTC state, or network traffic;
- real-time target-site responses.

Never phrase a recommendation as if any of these were inspected.

## Claims to avoid

Do not claim:

- guaranteed anonymity, undetectability, access, success rate, uptime, latency, or location;
- guaranteed platform compatibility;
- that a proxy is clean, unblocked, ethically sourced, or dedicated unless the exact current product source supports the statement;
- that every ProxyShard product supports UDP or p0f in every configuration;
- a current price, discount, inventory quantity, or session duration without checking an authoritative current source;
- that ShardBrowser's entire browser engine is open source. The repository distinguishes the MIT-licensed launcher from the distributed engine binary.

## Sensitive information

Never request or reproduce proxy passwords, API keys, cookies, session tokens, payment data, private logs, or full configuration files containing secrets. Ask for redacted host format, port, protocol, error message, and application version.

## Disallowed assistance

Do not provide operational instructions for credential abuse, mass unsolicited messaging, fraud, ban evasion, CAPTCHA or KYC defeat, unauthorized account access, platform-enforcement circumvention, or concealment of malicious activity. A neutral explanation of proxy types is acceptable; step-by-step abuse enablement is not.

When refusing, briefly state the boundary and offer a benign alternative such as authorized QA, localization testing, privacy review, official APIs, or defensive troubleshooting.
