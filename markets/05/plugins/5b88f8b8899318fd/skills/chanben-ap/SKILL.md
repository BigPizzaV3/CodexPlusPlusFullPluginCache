# ちゃんべん　応用情報技術者試験

## 対象と根拠資料

- 対象はIPAの「応用情報技術者試験（AP）」である。
- 各実行の基準は、その時点でIPA公式サイトに掲載されている最新シラバスとする。同梱資料を固定基準にしない。
- 最新版の確認起点: https://www.ipa.go.jp/shiken/syllabus/gaiyou.html
- 試験区分ページ: https://www.ipa.go.jp/shiken/kubun/ap.html
- 作成時点（2026年8月29日）の最新版は「応用情報技術者試験（レベル3）シラバス Ver.7.2」。PDFは2026年7月6日に科目表記が更新されている。
- 作成時点のPDF: https://www.ipa.go.jp/shiken/syllabus/omgdg50000005kq5-att/syllabus_ap_ver7_2.pdf
- [シラバス対応表](references/syllabus-map.md) は検索補助であり、最新版と差があれば最新版を優先する。

## 毎回の最新版確認

1. IPA公式のシラバス掲載ページとAP試験区分ページを確認する。
2. 資料名、版番号、掲載日・更新日、試験制度の移行情報を比較し、その時点で適用される最新シラバス本文を読む。
3. 最新版の分類、用語、科目構成を反映する。更新版があればVer.7.2や同梱対応表を優先しない。
4. 掲載ページ、シラバスPDF、定義を補った一次資料を記録し、回答後に実際に参照した全ページを示す。
5. 最新版を確認できない場合はその事実を明示し、過去版を最新版と呼ばない。

ブログ、まとめサイト、市販教材は最新版判定の根拠にしない。定義補足は規格制定機関、政府機関、標準文書、技術提供元など信頼できる一次資料を優先する。

## 入力と対話

- 用語指定ならシラバス内の分類・項目・近縁語を特定する。分野指定なら理解を分ける代表語を一つ選んで明示する。
- 問題数の指定がなければ1問。指定語が最新版にない場合は非掲載であることと近い掲載語を伝える。
- 生成問題を過去問やIPA公式問題と呼ばない。
- 通常は二段階で進める。出題時は問題文と選択肢だけを示して1〜4の回答を待つ。回答後に判定、正解、四つすべての正誤理由、根拠シラバス、実際に参照した全サイトを示す。
- 複数問でも、指定がなければ一問ずつ解説を完了してから次へ進む。

## 4択問題の設計

1. 正答は一つだけ。定義、識別、計算、状況設定、設計判断を分野に応じて使う。
2. 誤答は原則「別の近縁用語なら正しい説明」にし、同じ項目、同じ小分類、隣接項目の順で選ぶ。
3. 三つの誤答を実在する別概念へ一対一で対応させる。架空語、単なる否定、意味の通らない置換は使わない。
4. 選択肢の長さ、文体、具体性をそろえ、正答だけが目立つ手掛かりを避ける。
5. 計算は再計算し、単位と丸め条件を明示する。正答が複数成立しないことを確認する。

## 出力形式

出題時は「ちゃんべん　応用情報技術者試験」「使用シラバス」「【問題】」「1〜4の選択肢」「1〜4の番号で回答してください。」を示す。回答後は次を必ず含める。

- 【判定】と【正解】
- 【選択肢別解説】: 四つすべてに「正解／不正解」を明記し、不正解は本来の概念名と正しい意味まで説明
- 【根拠となったシラバス】: 正式資料名・版、該当分類・項目・ページ、IPA公式PDFの直接リンク
- 【参考にしたサイト】: 最新版確認ページを含め、実際に参照した全ページの名称・用途・リンク

正解位置は偏らないよう変える。長い原文転載は避ける。

## 完了前チェック

- IPA公式で実行時の最新版と試験制度を確認したか。
- 指定語がその版に掲載されているか。
- 出題時に正解を伏せたか。
- 正答は一つ、三つの誤答には本来の概念名があるか。
- 回答後に全選択肢、根拠シラバス、実参照サイトを漏れなく説明したか。
