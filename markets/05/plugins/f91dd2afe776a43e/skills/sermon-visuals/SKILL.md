# Sermon Visuals

Create reverent, legible visual communication that represents the sermon faithfully rather than decorating it with new claims.

Before planning content, read [the shared fidelity and style standard](../../references/fidelity-and-style.md). If the source is still a noisy transcript and faithful visual condensation depends on reconstruction, first derive a source-grounded working outline; do not silently invent missing context.

## Select the format

Honor the requested dimensions, platform, language, number of images, and brand guidance. When these are unspecified:

- Use a single infographic for one central idea with three to five supporting points.
- Use a carousel when the message needs sequencing, several distinct movements, or more text than one image can carry.
- For a social carousel, default to a square 1:1 series with a cover, concise content cards, and a closing takeaway or source-supported appeal. Choose the smallest slide count that communicates the message without crowding or repetition.

For a one-page infographic, default to an editorial sermon-poster composition. Read and apply [the one-page editorial infographic guide](references/one-page-editorial-infographic.md). This guide applies only to one-page infographics; do not impose its dense modular layout on carousels.

Do not ask a follow-up question when a sensible default is available. If image-generation capability is available and the user asks to create the images, generate them rather than stopping at a content brief.

## Execute a one-page infographic request

Treat commands such as `@Sermon Scribe create one-page infographic`, `INFOGRAPHIC`, and equivalent natural-language requests as an instruction to produce the finished single-page visual, not merely an outline or prompt. Use this deterministic sequence:

1. Establish the evidence base from the supplied sermon, transcript, notes, or approved sermon record. If no sermon source is available, request it; do not invent a sermon from a title or Scripture reference alone.
2. Read and apply [the one-page editorial infographic guide](references/one-page-editorial-infographic.md).
3. Prepare and lock the exact source-supported copy before visual production: title, Scripture reference and any quoted wording, central theme, three to five supporting movements, and a closing takeaway, appeal, or prayer line when present.
4. Choose a portrait composition, palette, hero imagery, and modules that arise from the sermon. Use the guide's defaults wherever the user has not specified dimensions, branding, language, or style.
5. Generate or compose the complete infographic when suitable image or layout capability is available. Prefer deterministic text composition for exact copy; use generated imagery separately when practical.
6. Inspect the rendered result against the source and the guide's production checklist. Correct fidelity, spelling, pseudo-text, hierarchy, clipping, contrast, and phone-size legibility problems before delivery.
7. Deliver the finished visual. Fall back to a polished content-and-layout specification only when final image production or reliable exact-text composition is unavailable, and state that limitation plainly.

User-supplied visual references guide style only. Never carry their factual content, quotations, theology, or sermon-specific structure into the new visual unless the current sermon independently supports it.

## Build the content plan

Extract only source-supported elements:

- a restrained sermon title or theme;
- the Scripture reference and only source-supported verse wording;
- three to five key ideas for a single infographic, or a non-overlapping narrative sequence for a carousel;
- a central takeaway, quotation, appeal, or prayer line that is genuinely present in the source.

Never manufacture a quote. Label a paraphrased takeaway as a takeaway, not as the preacher's direct words. Preserve important qualifications when shortening. Avoid reducing the sermon to generic inspiration.

For a carousel, give each card one job. A typical sequence is cover, Scripture/context, exposition movements, application, and closing takeaway, but follow the sermon's own logic. Do not repeat the same point on multiple cards merely to fill the series.

## Visual direction

Use a minimal, reverent, calm design with strong hierarchy, generous spacing, and high contrast. Keep text readable at phone size. Maintain typography, palette, illustration style, margins, and recurring elements consistently across a series. Religious imagery must support the sermon and should not imply a doctrine or historical scene absent from it.

Avoid sensational imagery, promotional aesthetics, decorative clutter, tiny body text, and visual metaphors that distort the message. For multilingual or parallel versions, adapt layout to text expansion and script rather than shrinking type excessively.

## Generate and verify

When producing image assets, define the complete series and consistency rules before generation. Generate all requested images. Then verify:

- every theological claim and quotation against the sermon;
- Scripture references, spelling, and language accuracy;
- sequence, non-overlap, and completeness;
- legibility, safe margins, visual consistency, and absence of clipped text.

Correct substantive or rendering errors before delivery. Provide the finished images with a concise identification of format and language. Do not append a command menu or mandatory closing prompt.
