# Sermon Translate

Produce a faithful target-language sermon that reads naturally to its intended church audience without becoming a theological rewrite.

Before translating, read [the shared fidelity and style standard](../../references/fidelity-and-style.md). Apply it to both the source interpretation and target text.

## Establish the translation brief

Use the target language, script, locale, audience, Bible version, and parallel-text format given by the user. If only the language is specified, use its broadly understood contemporary written form and preserve the source structure. Ask a narrow question only when an unresolved choice would materially change meaning—for example, Traditional versus Simplified Chinese or a required Bible translation for newly quoted verse text.

Translate the approved or most complete sermon record when one exists. If the only available source is a raw transcript, translate it faithfully as-is unless the user also asks for reconstruction; do not silently perform a major editorial rewrite.

## Translation priorities

1. Preserve theological meaning, logical relationships, qualifications, and degree of certainty.
2. Preserve pastoral warmth, humility, reverence, and the preacher's emotional register.
3. Use natural target-language syntax rather than word-for-word calques.
4. Keep names, events, testimonies, and applications aligned with the source.
5. Preserve headings, paragraph relationships, and Scripture references unless the user requests another layout.

Use established target-language Christian terminology when it conveys the same meaning. When a doctrinal term has several plausible renderings and context does not settle it, choose the least interpretive standard term and briefly note the ambiguity only if it matters.

## Scripture and quotations

Translate sermon prose and source quotations faithfully. For quoted Scripture, retain the source wording when it is already in the target language. Use a named target-language Bible version only when the user specifies it or provides its text. Otherwise translate the supplied wording without falsely labeling it as an official version, or preserve the reference without adding missing verse text.

Preserve exact quotation status: do not turn paraphrase into a direct quote. If a memorable phrase cannot retain both literal wording and rhetorical force, prioritize theological meaning and pastoral intent.

## Quality check and delivery

Check terminology consistency, pronoun and speaker references, negation, modality, Scripture citations, numbers, names, and paragraph omissions. Ensure the translation does not add explanation or remove a difficult claim.

Return the translated sermon directly in the requested format. Include translator notes only for material ambiguities, not routine choices. Do not append a command menu or mandatory follow-up prompt.
