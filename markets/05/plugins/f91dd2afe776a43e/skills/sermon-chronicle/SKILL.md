# Sermon Chronicle

Create a coherent pastoral record for readers who were not present while remaining answerable to the supplied sermon material.

Before writing, read [the shared fidelity and style standard](../../references/fidelity-and-style.md) and apply it throughout.

## Interpret the request naturally

Infer the intended mode from ordinary language; commands are optional aliases, not prerequisites.

- **Reconstruct / WRITE:** turn fragmented source material into a complete narrative.
- **Expand / EXPAND:** deepen clarity, continuity, and source-supported development without adding content.
- **Condense / SUMMARISE:** create a shorter but still pastoral and theologically substantive account.
- **Publish / PUBLISH:** edit the record for a church website, newsletter, archive, or ministry publication while retaining a narrative form.

If more than one source is supplied, treat all relevant files as the sermon evidence base. Do not ask for confirmation merely because a file was provided. If the requested mode or length is not stated, default to a full reconstruction proportionate to the source.

## Reconstruct the sermon

1. Identify the preacher's actual movement: opening, Scripture engagement, exposition, illustrations or testimony, application, closing appeal, and prayer where present.
2. Separate transcription noise and verbal repetition from meaningful emphasis. Preserve repetitions that perform a pastoral or rhetorical function.
3. Restore complete sentences, clear antecedents, natural transitions, and readable paragraphs.
4. Preserve the preacher's order unless reordering is necessary for intelligibility and does not alter emphasis or causality.
5. Make the result one connected sermon account, not an analytical outline or commentary on preaching technique.

## Default full-record structure

For a full reconstruction or publication-ready record, use these Markdown headings in order:

1. Title / Theme
2. Scripture Basis
3. Opening Reflection
4. Main Exposition and Key Points
5. Illustrations and Personal Testimonies
6. Practical Applications
7. Closing Appeal and Prayer

Write full paragraphs rather than bullets. A heading may state that the source contains no distinct material for that section, but do not fabricate content to fill it. If the source genuinely combines sections, preserve the required heading order while avoiding repetition. For a user-requested summary, excerpt, or house format, adapt the structure to the requested deliverable rather than forcing all seven headings.

Use a source-supported title or a restrained descriptive title. Do not create a sensational or marketing-oriented title.

## Deliver

Return the finished record directly. Add a short source note only when gaps, contradictions, or uncertain quotations materially affect reliability. Do not append a command menu, `HELP` reminder, or mandatory closing question.
