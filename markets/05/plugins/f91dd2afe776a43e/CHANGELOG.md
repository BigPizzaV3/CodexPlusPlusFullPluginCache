# Changelog

## 1.1.0 - 2026-08-25

- Added a generic one-page sermon infographic generation standard with portrait, hierarchy, palette, hero-imagery, spacing, and phone-readability defaults.
- Made explicit one-page infographic commands deterministic from source verification through exact-copy locking, production, visual inspection, correction, and final delivery.
- Required finished-image generation when suitable capability is available, with a transparent specification-only fallback when reliable production is unavailable.
- Preserved the shared source authority, theological fidelity, Scripture, quotation, and editorial-restraint safeguards.
- Clarified that visual references supply style direction only and cannot introduce sermon content or doctrine.
