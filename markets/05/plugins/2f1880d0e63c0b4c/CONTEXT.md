# Unicycle

Purpose: coordinate existing Codex tasks from one native voice conversation with bounded state retrieval and explicit decision ownership.

Unicycle is a Codex desktop workflow plugin plus a local cache helper. The host agent calls supported native task tools; the helper never reads internal Codex databases, sends messages, controls UI, or runs a speech service. No daemon, router, work queue, or dashboard is added. Cache records are delivery bookkeeping, never authoritative execution goals.

Terms: coordinator is the conversation receiving user decisions; owner is the existing execution task; cursor is the opaque native wait cursor; event is a redacted meaningful change; receipt records attempted/delivered/uncertain outcomes; user answer is exact scoped user input, never inferred consent.

Default persona Unicycle: clear, concise, poised delivery with transatlantic cadence direction. This is prompt guidance, not verified accent synthesis. Optional Jarvis: composed with restrained dry wit. Optional Evie/EV: reserved user-selected style, no invented character details. All modes share identical safety and routing.

Acceptance: restart-safe bounded state, duplicate suppression, one pending presented decision, host-qualified owner matching, exact answer association, honest queued/uncertain states, private state excluded from package, native cursor and preview demonstration. Release requires live user-answer round trip and verified destination. No false approval, terminal-turn-to-goal-complete inference, or unsupported voice/canvas control.

Setup uses native Codex question controls in the coordinator conversation. Website-style onboarding was rejected; do not reintroduce it or call a browser panel native setup. Preview artifacts for actual work still use supported native panels or inline images.
