# GcpAdcAuth

Configuration for Google Application Default Credentials (ADC).

- `scopes` (`Array<string> | null`, optional): Additional OAuth scopes. Empty list falls back to the default cloud-platform scope.
- `quotaProjectId` (`string | null`, optional): Optional quota project used for billing
