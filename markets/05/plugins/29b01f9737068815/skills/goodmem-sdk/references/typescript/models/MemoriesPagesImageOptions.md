# MemoriesPagesImageOptions

- `dpi` (`number`, optional): Optional rendition filter. If omitted, the unique page-image rendition for the page is returned; if multiple renditions exist, specify dpi and/or contentType.
- `contentType` (`string`, optional): Optional rendition filter. MIME type of the desired page image, such as image/png.
