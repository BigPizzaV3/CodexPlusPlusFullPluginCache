# MemoriesPagesOptions

- `startPageIndex` (`number`, optional): Optional lower bound for returned page indices, inclusive.
- `endPageIndex` (`number`, optional): Optional upper bound for returned page indices, inclusive.
- `dpi` (`number`, optional): Optional rendition filter for page-image DPI.
- `contentType` (`string`, optional): Optional rendition filter for page-image MIME type, such as image/png.
- `maxResults` (`number`, optional): Maximum number of results per page.
- `nextToken` (`string`, optional): Opaque pagination token for the next page. Do not parse or construct it.
