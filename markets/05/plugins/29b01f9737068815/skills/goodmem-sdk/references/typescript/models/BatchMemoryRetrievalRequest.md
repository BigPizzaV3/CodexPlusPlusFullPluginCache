# BatchMemoryRetrievalRequest

Request body for retrieving multiple memories by their IDs

- `memoryIds` (`Array<string>`, required): Array of memory IDs to retrieve
- `includeContent` (`boolean | null`, optional): Whether to include the original content in the response
- `includeProcessingHistory` (`boolean | null`, optional): Whether to include background job processing history for each memory
