# BatchDeleteMemorySelectorRequest

A single delete selector: either memoryId or filterSelector

- `memoryId` (`string | null`, optional): Deletes one specific memory by UUID
- `filterSelector` (`FilteredDeleteMemorySelectorRequest | null`, optional): Deletes a filtered set of memories within a specific space
