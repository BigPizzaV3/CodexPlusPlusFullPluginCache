# CreateServiceIdentityRequest

Creates a service identity owned by the authenticated human. It does not create credentials, roles, or grants.

- `serviceIdentityId` (`string | null`, optional): Optional client-provided UUID; generated by the server when omitted.
- `displayName` (`string`, required): Globally unique, nonblank operator-facing name.
- `description` (`string | null`, optional): Optional operator description.
- `labels` (`Record<string, string> | null`, optional): Optional labels for organization and filtering. At most 20 entries; keys and values contain at most 255 characters; keys use [a-z0-9._-].
