# FilteredDeleteMemorySelectorRequest

Filtered selector scoped to a specific space

- `spaceId` (`string`, required): Space ID scope for the filtered delete
- `statusFilter` (`"PENDING" | "PROCESSING" | "COMPLETED" | "FAILED" | null`, optional): Optional processing status filter (PENDING, PROCESSING, COMPLETED, FAILED)
- `filter` (`string | null`, optional): Optional metadata filter expression
