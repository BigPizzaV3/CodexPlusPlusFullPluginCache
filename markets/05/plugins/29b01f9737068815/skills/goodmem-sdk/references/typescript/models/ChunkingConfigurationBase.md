# ChunkingConfigurationBase

- `none` (`NoChunkingConfiguration | null`, optional): No chunking strategy - preserve original content as single unit
- `recursive` (`RecursiveChunkingConfiguration | null`, optional): Recursive hierarchical chunking strategy with configurable separators
- `sentence` (`SentenceChunkingConfiguration | null`, optional): Sentence-based chunking strategy with language detection
