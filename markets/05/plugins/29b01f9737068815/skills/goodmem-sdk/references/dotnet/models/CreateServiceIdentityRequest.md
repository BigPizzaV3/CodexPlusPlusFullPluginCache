# CreateServiceIdentityRequest

Creates a service identity owned by the authenticated human. It does not create credentials, roles, or grants.

`Goodmem.Client.Models.CreateServiceIdentityRequest`

- `Description` (`string?`): Optional operator description. JSON: `description`.
- `DisplayName` (`string`, required): Globally unique, nonblank operator-facing name. JSON: `displayName`.
- `Labels` (`IReadOnlyDictionary<string, string>?`): Optional labels for organization and filtering. At most 20 entries; keys and values contain at most 255 characters; keys use [a-z0-9._-]. JSON: `labels`.
- `ServiceIdentityId` (`string?`): Optional client-provided UUID; generated by the server when omitted. JSON: `serviceIdentityId`.
