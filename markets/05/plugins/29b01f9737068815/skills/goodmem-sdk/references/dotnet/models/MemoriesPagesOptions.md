# MemoriesPagesOptions

Query options for Memories.PagesAsync. Every property is optional.

`Goodmem.Client.Api.MemoriesPagesOptions`

- `ContentType` (`string?`): Optional rendition filter for page-image MIME type, such as image/png.
- `Dpi` (`int?`): Optional rendition filter for page-image DPI.
- `EndPageIndex` (`int?`): Optional upper bound for returned page indices, inclusive.
- `MaxResults` (`int?`): Maximum number of results per page.
- `NextToken` (`string?`): Opaque pagination token for the next page.
- `StartPageIndex` (`int?`): Optional lower bound for returned page indices, inclusive.
