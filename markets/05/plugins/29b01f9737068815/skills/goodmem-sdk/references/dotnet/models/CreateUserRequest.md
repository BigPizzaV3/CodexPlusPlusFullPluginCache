# CreateUserRequest

Creates a human user without creating a credential, role assignment, grant, or external authentication mapping.

`Goodmem.Client.Models.CreateUserRequest`

- `DisplayName` (`string?`): Optional human-facing display name. JSON: `displayName`.
- `Email` (`string`, required): Unique, nonempty email address. JSON: `email`.
- `Labels` (`IReadOnlyDictionary<string, string>?`): Optional labels for organization and filtering. At most 20 entries; keys and values contain at most 255 characters; keys use [a-z0-9._-]. JSON: `labels`.
- `UserId` (`string?`): Optional client-provided user UUID; generated by the server when omitted. JSON: `userId`.
- `Username` (`string?`): Optional unique username. JSON: `username`.
