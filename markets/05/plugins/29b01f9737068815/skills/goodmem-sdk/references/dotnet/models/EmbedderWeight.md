# EmbedderWeight

Per-embedder weight override for retrieval operations.

`Goodmem.Client.Models.EmbedderWeight`

- `EmbedderId` (`string`, required): The UUID for the embedder. JSON: `embedderId`.
- `Weight` (`double`, required): The weight to apply to this embedder's results. Can be positive, negative, or zero. JSON: `weight`.
