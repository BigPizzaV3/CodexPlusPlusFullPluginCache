# GcpAdcAuth

Configuration for Google Application Default Credentials (ADC).

`Goodmem.Client.Models.GcpAdcAuth`

- `QuotaProjectId` (`string?`): Optional quota project used for billing JSON: `quotaProjectId`.
- `Scopes` (`IReadOnlyList<string>?`): Additional OAuth scopes. Empty list falls back to the default cloud-platform scope. JSON: `scopes`.
