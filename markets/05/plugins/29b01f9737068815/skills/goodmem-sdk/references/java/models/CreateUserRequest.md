# CreateUserRequest

Creates a human user without creating a credential, role assignment, grant, or external authentication mapping.

Prefer `builder()` to the canonical record constructor.
 Builder-based call sites remain source-compatible when optional fields are added in later SDK versions.

- `userId` (`UserId`): Optional client-provided user UUID; generated by the server when omitted. Typed wrapper `UserId`; build from a raw string with `UserId.from(String)`.
- `email` (`String`): Unique, nonempty email address.
- `username` (`String`): Optional unique username.
- `displayName` (`String`): Optional human-facing display name.
- `labels` (`java.util.Map<String, String>`): Optional labels for organization and filtering. At most 20 entries; keys and values contain at most 255 characters; keys use [a-z0-9._-].
