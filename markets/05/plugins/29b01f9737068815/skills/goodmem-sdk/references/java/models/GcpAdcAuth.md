# GcpAdcAuth

Configuration for Google Application Default Credentials (ADC).

- `scopes` (`java.util.List<String>`): Additional OAuth scopes. Empty list falls back to the default cloud-platform scope.
- `quotaProjectId` (`String`): Optional quota project used for billing
