# CreateServiceIdentityRequest

Creates a service identity owned by the authenticated human. It does not create credentials, roles, or grants.

Prefer `builder()` to the canonical record constructor.
 Builder-based call sites remain source-compatible when optional fields are added in later SDK versions.

- `serviceIdentityId` (`ServiceIdentityId`): Optional client-provided UUID; generated by the server when omitted. Typed wrapper `ServiceIdentityId`; build from a raw string with `ServiceIdentityId.from(String)`.
- `displayName` (`String`): Globally unique, nonblank operator-facing name.
- `description` (`String`): Optional operator description.
- `labels` (`java.util.Map<String, String>`): Optional labels for organization and filtering. At most 20 entries; keys and values contain at most 255 characters; keys use [a-z0-9._-].
