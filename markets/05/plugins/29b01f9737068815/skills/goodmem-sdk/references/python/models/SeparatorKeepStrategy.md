# SeparatorKeepStrategy

Strategy for handling separators after text splitting. KEEP_NONE is deprecated and treated as KEEP_END.

```python
from goodmem.models import SeparatorKeepStrategy
```

- `KEEP_NONE`: 'KEEP_NONE'
- `KEEP_START`: 'KEEP_START'
- `KEEP_END`: 'KEEP_END'
