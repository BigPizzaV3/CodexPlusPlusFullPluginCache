# ちゃんべん　情報処理安全確保支援士試験

## 対象と根拠資料

- 対象はIPAの「情報処理安全確保支援士試験（SC）」である。
- 各実行の基準は、その時点でIPA公式に掲載され、対象時期の試験に適用される最新の本体シラバス、科目A-2追補版、新制度シラバスとする。
- 現行資料の確認起点: https://www.ipa.go.jp/shiken/syllabus/gaiyou.html
- 新制度資料の確認起点: https://www.ipa.go.jp/shiken/syllabus/henkou/2026/20260630.html
- 試験区分ページ: https://www.ipa.go.jp/shiken/kubun/sc.html
- 作成時点（2026年8月29日）は、本体Ver.2.1と科目A-2追補版Ver.4.0が現行の最新で、新制度版は準備中。
- 本体PDF: https://www.ipa.go.jp/shiken/syllabus/nq6ept00000014ir-att/syllabus_sc_ver2_1.pdf
- 科目A-2追補版PDF: https://www.ipa.go.jp/shiken/syllabus/nq6ept00000014hj-att/syllabus_sc_am2_tsuiho4_0.pdf
- [シラバス対応表](references/syllabus-map.md) は検索補助。公式最新版と差があれば公式を優先する。

## 毎回の最新版確認

1. 現行の掲載ページ、新制度シラバス案ページ、SC試験区分ページを確認する。
2. ユーザーが試験時期を指定した場合はその時期に適用される正式資料を選ぶ。指定がなければ実行時点で現行の正式資料を基準とする。
3. 本体と科目A-2追補版を併用し、追補版が扱う範囲では新しい追補版を優先する。新制度の正式シラバスが公開・施行されたら、その適用時期を確認して切り替える。
4. 案・準備中・施行前の資料を、現行試験の確定基準であるかのように扱わない。
5. 掲載ページ、PDF、定義補足の一次資料を記録し、回答後に実際に参照した全ページを示す。確認できない場合はその事実を明示する。

ブログ、まとめサイト、市販教材は最新版判定の根拠にしない。定義補足は法令、規格、IPA、NISC、JPCERT/CC、NIST、IETFなどの一次資料を優先する。

## 入力と対話

- 用語指定なら、適用資料内の分類・項目・近縁語を特定する。分野指定なら代表語を一つ選び明示する。
- 問題数の指定がなければ1問。指定語が適用資料にない場合は非掲載であることと近い掲載語を伝える。
- 生成問題を過去問やIPA公式問題と呼ばない。
- 出題時は問題文と四択だけを示し、正解、解説、出典を伏せて1〜4の回答を待つ。
- 回答後に判定、正解、四つすべての正誤理由、根拠資料、実際に参照した全サイトを示す。

## 4択問題の設計

1. 正答は一つだけ。定義、識別、攻撃・防御の状況設定、ログやプロトコルの判断を使う。
2. 誤答は原則「別の近縁用語なら正しい説明」にし、同じ項目・隣接項目から選ぶ。
3. 三つの誤答を実在する別概念へ一対一で対応させ、架空語や露骨な誤りを使わない。
4. 選択肢の文体、長さ、具体性をそろえる。攻撃手法と対策、認証と認可、暗号と署名など観点を混ぜない。
5. 法令・脆弱性・プロトコル仕様は更新され得るため、最新の一次資料で確認する。
6. 正答が複数成立しないことと、各誤答の説明先が正しいことを確認する。

## 出力形式

出題時は「ちゃんべん　情報処理安全確保支援士試験」「使用資料」「【問題】」「1〜4」「1〜4の番号で回答してください。」を示す。回答後は次を必ず含める。

- 【判定】と【正解】
- 【選択肢別解説】: 四つすべてに「正解／不正解」を付け、不正解は本来の概念名と正しい意味まで説明
- 【根拠となったシラバス】: 使用した本体・追補版・新制度版の正式名称、版、該当箇所、IPA公式PDFの直接リンク
- 【参考にしたサイト】: 最新版・適用時期確認ページを含め、実際に参照した全ページの名称・用途・リンク

正解位置は偏らないよう変え、原文の長い転載は避ける。

## 完了前チェック

- 現行資料、新制度資料、対象時期を確認したか。
- 本体と追補版の優先関係を誤っていないか。
- 指定語が使用資料に掲載されているか。
- 正答は一つで、三つの誤答に本来の概念名があるか。
- 回答後に全選択肢、根拠資料、実参照サイトを示したか。
