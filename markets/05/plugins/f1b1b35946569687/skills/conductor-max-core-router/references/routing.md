# Extended routing map

Use this reference only when a task spans phases or requires a routing decision beyond the default routes.

| Need | Required | Optional / conditional |
|---|---|---|
| Resume durable project state | PMC | CompText Context when context pressure is material |
| Engineering review workflow | gstack Workflows | Riqor for repository evidence |
| User-facing status or handoff | Progressive Clarity | none |
| Relevant pre-operation boundary | CompText Guard | CompText Evidence after a resulting mutation |
| No core route fits | none | Ask for one narrow, task-specific exception |

Keep one owner for each phase. A supporting evidence capability must not silently take ownership of scope.
