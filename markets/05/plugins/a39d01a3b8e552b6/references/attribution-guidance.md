# Attribution Guidance

Use the strongest attribution the source supports, no stronger.

- Named and clearly labeled: use the speaker's supplied name and role.
- Named but role unclear: use the name without inventing a title.
- Role or turn identifiable but unnamed: use a neutral label such as “the moderator,” “a panellist,” or “one participant.”
- Speaker boundary uncertain: attribute to “the discussion” or describe the point without a person-level claim.
- Conflicting labels: note the conflict once and use stable neutral labels thereafter.

Do not infer identity from voice, writing style, viewpoint, biography, or external knowledge. Preserve distinctions between a speaker's own position, a position they report, a question they pose, and a hypothetical example.

Use quotation marks only for wording that is sufficiently clear in the source. Clean obvious fillers or false starts only when doing so does not alter meaning; otherwise paraphrase. Never merge separate remarks into a composite quotation.
