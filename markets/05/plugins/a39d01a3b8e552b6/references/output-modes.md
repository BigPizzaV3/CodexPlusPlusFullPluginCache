# Output Modes

Commands may be plain or slash-prefixed and are case-insensitive. Natural-language requests take priority over a bare alias when they provide clearer intent.

## EXPAND

Develop an existing outline, summary, or chronicle into fuller prose using only the source material. Restore supported context, reasoning, examples, transitions, and qualifications; never pad with invented detail.

## SUMMARISE / SUMMARIZE

Condense to the requested scale while retaining purpose, principal themes, important positions, material disagreements, conclusions, and stated actions. If no length is given, provide a concise executive summary.

## PUBLISH

Create a polished, stand-alone article, proceedings entry, newsletter feature, or web-ready record appropriate to the user's requested channel. Supply a factual title and lead; avoid promotional claims absent from the source.

## HIGHLIGHTS

Extract a scannable set of major takeaways, notable supported remarks, decisions, questions, and next steps. Do not use quotation marks unless the transcript supports exact wording.

## HELP

Briefly explain that the plugin can chronicle by default, outline, expand, summarise, publish, extract highlights, compare sessions, and create INFOGRAPHIC or other visual records. Invite the user to provide a transcript or state one of those outcomes. Do not produce a long manual.
