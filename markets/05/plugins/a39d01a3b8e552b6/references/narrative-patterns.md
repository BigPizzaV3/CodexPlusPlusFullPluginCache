# Narrative Patterns

Choose headings that reflect the actual session; these are patterns, not mandatory templates.

## Presentation

Opening context → central proposition → supporting arguments or demonstrations → implications → closing message → audience questions, if present.

## Panel or Roundtable

Session framing → participant perspectives → major themes in discussion order → convergence and divergence → questions or challenges → closing observations.

## Moderated Q&A or Interview

Context and participants → clusters of related questions and responses → follow-ups and clarifications → conclusions or unresolved issues.

## Workshop

Purpose and approach → concepts or instructions → activities and participant contributions → lessons or outputs → next steps stated in the source.

## Mixed Format

Preserve the major phase changes explicitly. Do not force presentation remarks and interactive discussion into one undifferentiated summary.

Default chronicles should be detailed and readable, using descriptive headings and connected prose. Include concise lists only when the source itself presents enumerated items, recommendations, or actions that benefit from scanning.
