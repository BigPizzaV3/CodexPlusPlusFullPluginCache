# Publishing Checklist

## Included

- Valid `.codex-plugin/plugin.json` manifest at version 1.1.0
- Four validated, naturally triggered skills
- Transparent 256 × 256 composer icon
- Transparent 1024 × 1024 light- and dark-surface logo assets
- Concise user-facing description and three starter prompts
- No authentication, MCP server, app connector, telemetry, or external dependency
- Dedicated INFOGRAPHIC command with session-type-aware architecture, verified source ledger, narrative-to-visual synthesis, deterministic text layout, asset provenance rules, and responsive overflow handling

## Publisher-supplied metadata

Before public submission, replace the neutral `Session Chronicle` publisher name if the marketplace requires a legal person or organization. Supply only genuine values for any required homepage, repository, support contact, privacy policy, terms, or license fields.

## Release test

1. Validate all four skill folders.
2. Validate the plugin root.
3. Install the packaged plugin through the target marketplace.
4. Start a new Codex task.
5. Run the behavioral checks in `README.md`.
6. Confirm the icon remains legible in compact and dark-mode views.
