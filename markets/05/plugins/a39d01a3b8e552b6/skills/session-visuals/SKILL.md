# Session Visuals

Translate the session into a coherent visual chronicle while keeping every factual element traceable to the supplied source.

## Visual modes

- `INFOGRAPHIC` or `EDITORIAL INFOGRAPHIC`: a professional visual chronicle whose structure reflects the session type and verified content. Read [editorial infographic patterns](../../references/editorial-infographic-patterns.md) before planning or generating it.
- `CAROUSEL`: a sequence with one principal message per card.
- `QUOTE CARD`: one verified quotation with restrained context.
- `VISUAL SUMMARY`: a lighter overview built around a small number of themes.
- `VISUAL BRIEF`: approved copy and production instructions without rendering.

Infer the mode from the request and supplied references. When the user supplies a visual reference, derive its hierarchy, density, section rhythm, palette logic, and image treatment without copying protected branding or proprietary graphics.

## Workflow

1. Identify the mode, audience, platform, dimensions, and panel count when provided. Otherwise choose a restrained, readable default without intake questions.
2. Classify the session as a leadership/keynote speech, government/policy address, technical presentation, panel discussion, roundtable, or another source-supported format.
3. Build a source ledger containing the session title or theme; speaker name, role, and organization; central message; major themes and arguments; figures; initiatives and frameworks; examples and case studies; timelines; agreements and disagreements; implications; future priorities; and quotation candidates. Mark each item as exact, paraphrased, uncertain, or externally supplied. Omit unclear details or disclose the uncertainty.
4. Establish the information hierarchy before choosing imagery. Make the session, speaker, and central message immediately legible; feature roughly four to seven principal insights when the source supports them; place statistics, examples, milestones, initiatives, and short quotations at the supporting level.
5. Convert narrative into visual language: concise headings, icons, timelines, process arrows, pillars, numbered frameworks, comparison panels, statistic blocks, callouts, quote panels, and takeaway banners. Do not put the prose chronicle into decorative boxes.
6. Choose the production method. Use deterministic layout for text-heavy designs; use image generation for supporting illustrations, backgrounds, or authorized visual assets. If a generative tool is used for a complete visual, keep exact text independently controlled or verify every rendered word. If suitable rendering tools are unavailable, deliver a production-ready brief and approved copy.
7. Apply user-supplied branding and authorized assets. Use a restrained professional conference system—navy, teal, green, white, light neutrals, clean sans-serif type, and consistent iconography—when no brand direction is supplied.
8. Proofread every visible name, role, organization, date, number, acronym, program name, label, and quotation against the source. Inspect the result at full size and thumbnail size for hierarchy, clipping, contrast, and legibility.

## INFOGRAPHIC default behavior

When a user supplies source material and simply asks to create an infographic:

1. Analyze the source and classify the session.
2. Extract and verify the source ledger.
3. Select the strongest source-responsive visual narrative.
4. Condense prose into infographic-ready language without losing important qualifications.
5. Construct a production or image-generation prompt containing the purpose, title, supported speaker details, hierarchy, exact sections, verified figures, required labels, visual style, color direction, layout, accuracy constraints, and text-density limits.
6. Generate the infographic directly when an appropriate rendering capability is available; otherwise provide the production-ready visual brief and exact approved copy.
7. Complete factual and visual quality control before delivery.

Combined commands use the named textual mode as the content basis: `OUTLINE → INFOGRAPHIC` uses the outline as information architecture; `HIGHLIGHTS → INFOGRAPHIC` produces a concise high-impact visual; `SUMMARISE/SUMMARIZE → INFOGRAPHIC` produces an executive-level visual; `EXPAND → INFOGRAPHIC` permits a detailed poster with evidence and context; `COMPARE → INFOGRAPHIC` visualizes speakers, themes, convergence, divergence, and conclusions; and `PUBLISH → INFOGRAPHIC` produces a polished public-facing visual.

If approved content cannot fit legibly, remove repetition, shorten secondary explanations, enlarge the canvas where appropriate, or convert the design into a carousel. Do not omit a material disagreement, qualification, or safety caveat merely to preserve the layout.

Never invent statistics, quotations, speaker identities, event branding, logos, photographs, outcomes, or consensus. Preserve the speaker's stated context and strength when featuring a number. Use quotations sparingly and only when exact wording is reliable; otherwise paraphrase without quotation marks. Use portraits, logos, venue photographs, and organizational branding only when supplied or obtained from an authorized source. Place supplied speaker portraits primarily in the header or speaker-profile area. Do not generate a real speaker's likeness as a substitute for an unavailable portrait or substitute an unrelated person's image. Do not present illustrative imagery as documentary evidence of the actual session, facility, incident, or participant. Label uncertain or representative material where confusion is possible. Visual polish never overrides fidelity.
