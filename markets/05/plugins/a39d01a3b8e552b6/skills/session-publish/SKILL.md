# Session Publish

Produce the requested derivative without adding unsupported substance. Read [output modes](../../references/output-modes.md) for the selected mode and [attribution guidance](../../references/attribution-guidance.md) when speaker identity or quotation is uncertain.

## Workflow

1. Identify the source artifact and requested mode. Plain or slash-prefixed commands are case-insensitive.
2. Preserve the source's factual boundaries, speaker positions, qualifications, and uncertainty.
3. Select information by importance to the requested audience and length; do not equate brevity with flattening nuance.
4. Draft in a self-contained form suited to the mode and user-specified audience, channel, tone, and length.
5. Verify that headlines, leads, highlights, and conclusions do not overclaim.

If no audience or length is given, choose a broadly professional audience and a proportionate length without asking. If the input is a raw transcript, first reconstruct enough structure to publish it faithfully.
