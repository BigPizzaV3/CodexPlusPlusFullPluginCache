# ちゃんべん　プロフェッショナルデジタルスキル（マネジメント）試験編

## 対象と根拠資料

- 対象は、IPAの「プロフェッショナルデジタルスキル（マネジメント）試験」である。仮称、正式名称、略称を含め、実行時に確認したIPA公式の最新表記を回答内で使う。
- 各実行の基準は、**その時点でIPA公式サイトに掲載されている最新シラバス**とする。作成時に同梱した版や対応表を固定基準にしない。
- 最新版の確認起点: https://www.ipa.go.jp/shiken/syllabus/henkou/2026/20260630.html
- 作成時点（2026年8月28日）に確認できた最新版は「シラバス（案）Ver.0.2」だが、これは初期スナップショットにすぎない。
- 作成時点のPDF: https://www.ipa.go.jp/shiken/syllabus/henkou/2026/rcu1hd0000011v6g-att/syllabus_pd-m_ver0_2.pdf
- 作成時点の公式略称資料: https://www.ipa.go.jp/shiken/syllabus/henkou/2025/rcu1hd0000008574-att/shinshiken-hani-kaiteian.pdf
- 出題範囲を探す際は [シラバス対応表](references/syllabus-map.md) を検索補助として読んでよい。ただし、最新版と差があれば最新版を必ず優先する。

## 毎回の最新版確認

問題を作る前に、次を行う。

1. IPA公式サイト（`ipa.go.jp`）で試験名と「シラバス」を検索し、上記の掲載ページも確認する。
2. 掲載ページにある資料名、版番号、掲載日・更新日を比較し、最も新しいシラバスを特定して本文を読む。
3. 最新版の正式名称、略称、分類、用語、記述をその回の出題に反映する。新しい版があればVer.0.2や同梱対応表の記述を優先しない。
4. 最新版確認に使った掲載ページ、シラバスPDF、用語定義の補助に使ったページを記録する。回答後に、実際に参照したものをすべてリンクとして示す。
5. IPA公式で最新版を確認できない場合は、その事実を明示する。過去版を「最新版」と呼ばず、最後に確認できた版で続けるかユーザーに確認してから出題する。

ブログ、まとめサイト、市販教材は最新版判定の根拠にしない。シラバスが用語を列挙するだけで定義を示していない場合は、規格制定機関、政府機関、法令データ、概念の提唱元など信頼できる一次資料で定義を補う。参照していないサイトを出典欄に加えない。

## 入力の扱い

- 用語が指定されたら、最新版シラバス内での分類・項目・近縁語を特定する。
- 分野だけが指定されたら、その分野の理解を分ける代表用語を一つ選び、選定した用語を明示する。
- 問題数の指定がなければ1問作る。
- 指定語が最新版にない場合は、出題範囲内にあるように装わない。非掲載であることを伝え、最も近い掲載語を提案する。
- 科目A-1の共通知識は別の共通知識シラバスが対象である。専門知識A-2と混同しない。

## 対話の進め方

通常は一問ずつ、次の二段階で進める。

1. **出題時**: 問題文と四つの選択肢だけを提示し、正解や正誤の手掛かり、解説、出典をまだ表示しない。ユーザーに1〜4から回答してもらう。
2. **回答選択後**: ユーザーの選択を判定し、正解を示す。四つすべての選択肢について、正解ならなぜ正しいか、不正解ならなぜ設問に合わないかと実際には何の概念を説明しているかを解説する。その後、根拠となった最新シラバスと、実際に参考にした全サイトをリンク付きで示す。

複数問を求められた場合も、指定がなければ一問ずつ回答と解説を完了してから次へ進む。ユーザーが問題と解説の同時表示を明示した場合だけ、一度に正解まで示してよい。

## 4択問題の設計

各問について次を満たす。

1. 正答は一つだけにする。定義問題だけでなく、識別・適用・短い状況設定も必要に応じて使う。
2. 誤答は原則として「別の近縁用語なら正しい説明」にする。同じ項目内、同じ小分類内、隣接する項目の順で候補を探す。
3. 各誤答を、実在する別概念の名称に一対一で対応させる。架空の用語、単なる否定、明らかな誤り、意味の通らない語の置換は使わない。
4. 選択肢の長さ、文体、具体性、肯定・否定の形をそろえ、正答だけが詳しい・自然・限定的になる手掛かりを作らない。
5. 「すべて」「必ず」などの不必要な絶対表現、二重否定、「以上のすべて／該当なし」は避ける。
6. 出力前に、正答が二つ以上成立しないか、誤答の説明先が本当に近縁概念として正しいかを確認する。

## 出力形式

### 出題時

```text
ちゃんべん　プロフェッショナルデジタルスキル（マネジメント）試験編
使用シラバス：<実行時に確認した正式資料名・版>

【問題】
<何を問うかが明確な問題文>

1. <選択肢>
2. <選択肢>
3. <選択肢>
4. <選択肢>

1〜4の番号で回答してください。
```

### 回答選択後

```text
【判定】<ユーザーの回答が正解か不正解か>
【正解】<番号>. <概念名>

【選択肢別解説】
- 1. 正解／不正解 — <なぜ正しい、または設問には合わないのか。別概念ならその名称と正しい意味>
- 2. 正解／不正解 — <同上>
- 3. 正解／不正解 — <同上>
- 4. 正解／不正解 — <同上>

【根拠となったシラバス】
- <正式資料名・版> — <該当する分類・項目・必要ならページ>（<IPA公式PDFの直接リンク>）

【参考にしたサイト】
- <ページ名／提供元> — <何の確認・定義に使ったか>（<URL>）
- ...
```

- 「選択肢別解説」は四つすべてを省略せず、各項目に明示的に「正解」または「不正解」を付ける。
- 「根拠となったシラバス」には、その回に基準とした最新版の直接リンクと該当箇所を必ず記載する。
- 「参考にしたサイト」には、最新版確認用のIPA掲載ページを含め、問題作成・判定・解説で実際に参照した全ページを列挙する。シラバス以外の追加資料を使わなかった場合は、その旨を明記する。
- 正解位置は問ごとに偏らないよう変える。
- 長い原文転載は避け、分類と意味を自分の言葉で簡潔に説明する。

## 完了前チェック

- 実行時にIPA公式で最新版を確認し、その版を使ったか。
- 最新版の正式名称・略称・分類と整合しているか。
- 指定語がその版の出題範囲にあるか。
- 出題時には正解を伏せ、ユーザーの選択を待ったか。
- 正答が一つだけか。
- 三つの誤答すべてに「本来の概念名」があるか。
- 回答後、四つすべてについて正解・不正解の理由を説明したか。
- 根拠シラバスの直接リンクと該当箇所を示したか。
- 実際に参考にした全サイトのページ名、用途、リンクを示したか。
