# AI Meta Ads by Coach Adam

Plugin ini membantu business owner menyediakan Meta Ads daripada brief sehingga launch berapproval.

## Apa yang plugin lakukan

- Memilih antara Conversion, WhatsApp Leads, dan Awareness.
- Menulis copy menggunakan framework Coach Adam.
- Menghasilkan poster photograph-first yang mewarisi angle copy.
- Menggunakan Meta MCP yang user telah sambungkan.
- Menggunakan Cloudinary atau Netlify hanya jika URL media awam diperlukan.
- Memeriksa setup dan meminta `APPROVE LAUNCH` sebelum publish atau spend.

## Cara guna

Selepas plugin dipasang, buka chat baru dan tulis arahan biasa:

> Launch ads untuk bisnes saya.

User tidak perlu menaip nama skill atau simbol `$`.

## Sebelum launch

Sambungkan Meta MCP yang akan digunakan. Cloudinary atau Netlify hanya diperlukan jika Meta MCP tidak boleh menerima upload creative secara terus.

Jangan masukkan token, password, access key, atau credential ke dalam fail plugin atau chat.
