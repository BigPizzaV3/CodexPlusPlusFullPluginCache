Use only needed fields: workflow version, source revision, step, draft output, evidence references, approval record, attempts, deadline, budget, cancellation flag, provider operation ID, and confirmed/failed/unknown outcome. Do not fill unknown live IDs with realistic-looking samples.

Limits must be supplied or clearly proposed. Describe bounded retries, deduplication, restart, rejection, missing data, injection handling, invalid output, partial failure, unknown write outcome, and human escalation as relevant.
