# Dossiê da iniciativa

## Sequência recomendada

Visão → A3 → Briefing → OKR → Backlog 2D → Kanban → Plano do Ciclo → Status → Review → Retro → Resumo.

Nem toda frente precisa de tudo. A régua depende do risco e da duração.

## Réguas

- **Leve:** briefing, backlog curto, plano, review e resumo.
- **Intermediária:** visão curta, A3, briefing, OKR, backlog, ciclos, status, review e retro.
- **Robusta:** cadeia completa, gates formais, histórico de decisões, riscos e versões.

## Registro por documento

| Campo | Pergunta |
|---|---|
| Nome canônico | como o arquivo é encontrado? |
| Local | onde vive a fonte da verdade? |
| Dono | quem mantém? |
| Consumidor | quem usa para decidir ou executar? |
| Momento | quando nasce e quando atualiza? |
| Evidência | o que prova que está vivo? |

## Regras

Um documento não pode disputar com outro a mesma decisão. Status aponta para a fonte, não copia
o projeto inteiro. Resumo fecha o ciclo; não apaga histórico.
