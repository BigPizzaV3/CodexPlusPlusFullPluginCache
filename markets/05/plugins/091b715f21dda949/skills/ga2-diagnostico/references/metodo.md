# Diagnóstico — situação atual, desejada e gap

## Objetivo

O diagnóstico forma o lado esquerdo do A3. Ele entende o problema antes de resolver.

Saída esperada: contexto, situação atual, linha de base, situação desejada e gap. Depois vem a
investigação de causa raiz.

Regra de ouro: **segure a solução e entenda primeiro**.

## 0. Refine o caso

Registre:

| Campo | Pergunta |
|---|---|
| Caso | Qual problema cabe em uma frase? |
| Entra | O que será tratado neste ciclo? |
| Fica fora | O que não será tratado agora? |
| Responsável | Qual pessoa responde pelo A3? |
| Resultado desejado | O que deve estar diferente no final? |

Recuse caso sem recorte. Se houver dois efeitos independentes, abra dois A3.

## 1. Contexto

Responda em duas ou três frases:

- Por que este caso importa agora?
- Em qual resultado ele bate?
- Quem é afetado?
- Que restrição existe?

Ligue o contexto a receita, cliente, custo, prazo, risco ou reputação.

Não coloque causa nem solução neste campo.

## 2. Situação atual

Descreva o que acontece hoje com fato, número, fonte e data.

| Fato | Número e unidade | Período | Fonte | Data | Quem verificou |
|---|---|---|---|---|---|
| | | | | | |

Recuse:

- “está ruim”;
- “demora muito”;
- “a equipe sente”;
- “deve estar em torno de” sem premissa;
- número sem período;
- fonte que não pode ser reaberta.

Quando o usuário não tiver o número, marque `em aberto` e monte um plano de medição. Não avance
como se o número existisse.

## Vá e veja

Observe a fonte real do trabalho: painel, planilha, sistema, arquivo, log, entrevista ou local
onde o processo acontece.

Uma descrição do que o sistema deveria fazer não prova o que aconteceu.

## Mapa atual do fluxo

Use somente quando o problema envolve fluxo, espera, repasse ou retrabalho.

| Etapa | Dono | Entrada | Saída | Tempo de execução | Espera | Trava ou retorno |
|---|---|---|---|---|---|---|
| | | | | | | |

Mapeie de quatro a oito etapas. Marque onde o trabalho para e onde volta.

O mapa atual é um `(acréscimo do laboratório)`. Ele deriva do mapeamento de fluxo Lean e ajuda
a encontrar a linha de base.

## Linha de base

A linha de base é o número de partida escrito antes da mudança.

| Métrica | Valor atual | Unidade | Período | Fonte | Frequência | Quem lê |
|---|---|---|---|---|---|---|
| | | | | | | |

O Check do PDCA deve comparar a mesma métrica na mesma fonte.

Se a linha de base for reconstruída depois da mudança, declare isso e mostre como foi
recalculada.

## 3. Situação desejada

Escreva “de X para Y até uma data”.

Uma meta exige:

- mesma métrica da situação atual;
- mesma unidade;
- escopo comparável;
- valor desejado;
- prazo;
- critério de sucesso.

Atividade não é meta. “Fazer dez reuniões” descreve esforço. “Reduzir o prazo de 72 para 24
horas até 30/11” descreve resultado.

## 4. Gap

Calcule a diferença entre atual e desejado.

| Métrica | Atual | Desejado | Gap | Leitura |
|---|---:|---:|---:|---|
| | | | | |

Cuidados:

- 62% para 85% = 23 pontos percentuais;
- variação relativa = `(85 − 62) ÷ 62`, somente se isso ajudar a decisão;
- dinheiro deve manter moeda e período;
- tempo deve manter unidade;
- não compare mês incompleto com mês completo sem ajuste explícito.

## Vale um A3?

Pergunte se o gap muda dinheiro, número, reputação ou decisão.

Se não mudar, execute uma ação direta. Registre por que o A3 completo seria excesso.

Isso evita repetir contramedida que já falhou.

## Gate de saída

O diagnóstico está pronto para causa raiz quando:

- o caso tem recorte;
- o contexto explica por que importa;
- a situação atual tem fato medido;
- a linha de base está escrita;
- a meta tem número e prazo;
- o gap foi calculado;
- atual e desejado usam a mesma medida;
- nenhuma solução foi antecipada.
