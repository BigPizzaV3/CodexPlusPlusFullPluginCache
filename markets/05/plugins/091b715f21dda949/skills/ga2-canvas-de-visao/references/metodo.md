# Canvas de Visão

## Quando usar

Use para empresa, área, projeto ou frente que precisa de norte antes de priorizar trabalho.

## Campos

1. **Escopo:** de que organização ou frente estamos falando.
2. **Passado:** decisões e fatos que explicam o ponto de partida.
3. **Hoje:** números, comportamentos e restrições atuais.
4. **Tendências:** mudanças externas ou internas com fonte.
5. **Futuro desejado:** situação observável numa data ou horizonte.
6. **Caminho:** escolhas principais para atravessar o gap.
7. **Visão:** uma frase que orienta decisão.
8. **Não faremos:** escolhas recusadas neste horizonte.

## Perguntas de facilitação

- O que existe hoje que uma pessoa de fora conseguiria verificar?
- Qual mudança já está acontecendo, com qual evidência?
- O que clientes e equipe fariam diferente no futuro desejado?
- Qual escolha precisa permanecer verdadeira quando houver pressão?
- O que vamos recusar para proteger o foco?

## Forma curta

Hoje → mudança que importa → futuro desejado → frase de visão → não faremos.

## Critério de qualidade

A frase de visão deve ser específica o bastante para ajudar a dizer “não”. Ela não contém uma
lista de projetos nem adjetivos vazios. Tendência sem fonte fica como hipótese.
