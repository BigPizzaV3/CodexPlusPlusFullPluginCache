# Kanban Canvas

## Descoberta

Defina serviço, demanda, cliente, entrada, saída e principais classes. Observe cartões reais para
descobrir os estados; não comece por um quadro genérico.

## Colunas

Cada coluna representa um estado verificável. Separe fila de execução. Coluna “fazendo” muito
larga esconde gargalos; coluna para cada pessoa cria handoffs artificiais.

## Raias

Use raia quando existe política diferente, como data fixa ou urgência. Não use raia por área se o
trabalho segue o mesmo fluxo.

## Cartão padrão

Item · resultado · dono · aceitante · entrada · data · “pronto é” · dependência · bloqueio · prova.

## Políticas

Escreva critérios de entrada/saída, WIP, bloqueio, urgência, prioridade e aceite. A política fica
visível junto do quadro.

## Bloqueio

O cartão permanece no estado em que travou, recebe marcador, data, motivo, responsável pela ação
e próxima cobrança. Mover para trás apaga história e distorce tempo de fluxo.
