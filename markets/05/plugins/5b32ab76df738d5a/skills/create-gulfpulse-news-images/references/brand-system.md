# GulfPulse visual system

## Identity

- Brand: **GulfPulse News / Gulf Pulse**
- Positioning: **Verified GCC Intelligence**
- Supporting line when appropriate: **GULF NEWS, IN REAL TIME**
- Website: `gulfpulsenews.com`
- Tone: trustworthy, fast, modern, premium, precise, GCC-focused, and editorial.

## Coverage labels

Use the most specific label supported by the story: Kuwait, Saudi Arabia, UAE, Qatar, Bahrain, Oman, or GCC. Global stories belong only when they have a direct Gulf impact.

## Palette

- Core navy: `#0B1F4D`
- Pulse blue: `#1E88FF`
- Sky blue: `#5AAEFF`
- White: `#FFFFFF`
- Light neutral: `#F3F6FA`
- Sand/gold accent: use sparingly for section markers, rules, or verified highlights.

Avoid unrelated bright colors. Reserve red for genuinely urgent breaking-news treatment; never make black/red the default brand identity.

## Typography

- Headlines: Manrope Bold.
- Body and labels: Inter.
- Breaking-news accent: Bebas Neue, used sparingly.
- Data/time/source details: JetBrains Mono.

Use approved installed equivalents only when a font is unavailable. Never stretch, outline excessively, or distort type.

## Composition

- Establish one clear focal subject.
- Keep layouts clean with generous negative space.
- Use rounded editorial cards, crisp rules, subtle regional map motifs, and restrained depth.
- Make the country/section label visible but subordinate to the headline.
- Keep source and timestamp small but readable.
- Use the real GulfPulse logo when supplied. Do not redraw or hallucinate it. If unavailable, use a clean text wordmark and ask Seenu for the logo only when the exact logo is essential.
- Treat flags, official seals, maps, and national emblems as factual elements; reproduce them only when accurate and necessary.

## Avoid

- crowded TV-news graphics;
- generic stock-news templates;
- excessive gradients, glow, glass effects, or ticker clutter;
- sensational disaster imagery;
- fake screenshots, fake documents, invented data, or copied competitor layouts;
- copied headlines, watermarks, logos, or identifiable creative work from references.
