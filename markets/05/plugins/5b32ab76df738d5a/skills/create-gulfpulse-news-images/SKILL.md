# Create GulfPulse News Images

Produce a coherent, premium news-image package for **GulfPulse News — Verified GCC Intelligence**. Treat the work as editorial publishing, not generic promotional design.

## Load the required references

Read all three references before generating the first image for a request:

- `references/brand-system.md` for identity, layout, and typography.
- `references/output-specs.md` for deliverables and platform formats.
- `references/editorial-integrity.md` for verification and safety rules.

## Start from a story brief

Extract or obtain:

1. Exact approved headline.
2. Country or GCC-wide label.
3. Content type: article hero, breaking news, data card, quote card, explainer, or feature.
4. Primary source, source URL, and relevant publication/update time.
5. Key fact the visual must communicate.
6. Requested language: English by default; create Modern Standard Arabic as a separate version only when requested.

If the user provides a URL or the story is current, browse and verify the source before designing. Ask only for a missing fact that materially blocks accurate work. Never invent a quote, number, place, logo, person, source, or event detail.

## Choose an editorial visual mode

- **Verified event photo available:** use or edit it only when usage rights and attribution are suitable. Preserve factual context.
- **No safe source photo:** generate an original editorial illustration or symbolic scene. Label it `AI illustration` in the supplied credit/caption metadata.
- **Developing or sensitive event:** prefer maps, skylines, infrastructure, objects, documents, or restrained abstract/data visuals over a fabricated photorealistic scene.
- **Named public figure:** do not generate a realistic depiction implying the person attended, said, endorsed, or did something unless the supplied visual is an authentic source image. Prefer an approved source photo or a non-deceptive symbolic composition.

Use the image-generation tool for original raster imagery and image edits. Keep essential headline, source, timestamp, logo, and labels in a high-contrast safe area. Verify every rendered word visually; correct misspellings before delivery.

## Build the coordinated package

Unless the user requests one format only, create:

1. Website article hero.
2. Instagram portrait post.
3. X landscape post.

Keep the same story identity across all three while recomposing for each crop. Do not merely crop a desktop graphic into portrait. Use short on-image copy; move context into the caption rather than crowding the card.

For every asset, include:

- concise filename;
- platform and pixel dimensions;
- final caption/cutline;
- source line;
- image credit (`Source photo`, `GulfPulse graphic`, or `AI illustration`);
- accessible alt text;
- reuse status and any restriction;
- source timestamp when the card represents breaking or time-sensitive news.

## Apply visual quality checks

Before delivery, inspect each image and confirm:

- GulfPulse identity is recognizable at thumbnail size.
- The logo/wordmark remains legible and undistorted.
- Headline, country label, source, and timestamp are accurate.
- No accidental flags, emblems, uniforms, maps, faces, text, watermarks, or third-party logos appear.
- No AI artifacts appear in hands, architecture, Arabic text, signage, vehicles, or national symbols.
- The focal subject is not hidden by platform cropping or interface overlays.
- Contrast and text size remain readable on a phone.
- The result looks like a clean premium publication, not a crowded TV-news lower-third.

If text rendering is unreliable, generate the visual background first and add exact typography through a deterministic layout/compositing method. Never deliver garbled text.

## Preserve editorial control

Return drafts for Seenu's review. Do not post, schedule, email, or publish without an explicit separate request. Do not auto-send drafts or access the GulfPulse Command Centre.

## Default response package

Deliver the images first, then a compact production note containing:

- story slug;
- formats created;
- source and verification time;
- captions and alt text;
- credit/reuse status;
- any factual or rights caveat requiring human review.
