# Wander plugin

ChatGPT upload package, mirroring the Agent Plugins layout in superclock/plugin/.
Generated by scripts/gen-plugin.mjs from ops-registry.json, Wander's inherited CSS brand tokens, and src/www/public/icon-1024.png. Requires Node 23.6+ and macOS sips.

From the repository root:

```sh
node --no-warnings wander.md/scripts/gen-plugin.mjs
bash wander.md/scripts/check-plugin.sh
```

The check rejects unexpected placeholders, unknown review tools, incorrect icon sizes, an incorrect MCP URL and generated-file drift, including extra files. Change the generator for listing copy and review metadata, then regenerate.

- plugin.json: OpenAI listing, onboarding skill, five positive and three negative review cases; commerce is false. Publication: every country ChatGPT serves, never Russia or Belarus (0.1.1, the West only, was published 2026-10-21).
- mcp.json: https://mcp.wander.md/mcp, remote streamable HTTP. OAuth 2.1 with PKCE; discovery at https://mcp.wander.md/.well-known/oauth-authorization-server. Dynamic registration and client metadata documents are supported by the server.
- skills/: first-use onboarding and note workflows. The 16-tool catalog and approval levels come from ops-registry.json.
- assets/: logo.png at 512 × 512 and composer-icon.png at 128 × 128, resized with sips from Wander's existing icon.
- Brand: light #103DFF, dark #7B9AFF; wander.css inherits these from common/lib/ui/styles/tokens.css.

Current behavior: search and read notes and folders, see history, create and edit whole notes or individual sections, append, add images from HTTPS URLs or uploads, move, delete, undo, restore an old version and publish a note or vault. Edits land directly as versions that can be undone. There are no suggestions awaiting acceptance and no ChatGPT side panel.

The review cases assume the dedicated account has a demo vault containing Inbox/, Trips/Lisbon.md (with a to-do section) and Work/Pricing.md. Preserve the owner prefix returned by Wander when calling tools. These are review scenarios, not a claim that live reviewer testing has passed.

The listing descriptions, three starter prompts and the demo video (unlisted, on capncap) are filled in. The reviewer account is reviewer@wander.md (docs/CHATGPT_PLUGIN.md); its password goes only into the dashboard's Review details form, never into this package. scripts/create-review-account.mjs sets a new one.

Upload plugin.zip with plugin.json, mcp.json, README.md, skills/ and assets/ at the archive root, with no enclosing plugin directory or __MACOSX entries.

Submission field reference: https://developers.openai.com/plugins/deploy/submission
