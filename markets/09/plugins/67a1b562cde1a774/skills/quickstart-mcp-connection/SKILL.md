# QuickStart MCP connection

If the QuickStart MCP server cannot be reached, ask the user to make sure the QuickStart MCP server is enabled in QuickStart UI settings.

Consult the [Enable the MCP server, documentation](https://docs.oracle.com/en/cloud/saas/netsuite-quickstart/help/article_2026082104.html#subsect_2026082101_enable) and guide the user.
