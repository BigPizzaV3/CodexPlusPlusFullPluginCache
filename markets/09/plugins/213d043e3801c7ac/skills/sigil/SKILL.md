# Sigil

Use Sigil when the user wants feedback on an existing brand, positioning, visual identity, voice or website. Ask for a public website if the user has not supplied one. If they provide a public document URL, pass it as document_url. Call start_read once, then check_read with its ID until the result is ready. Summarize the requested part of the actual report and provide its returned link. Reuse an existing review ID for follow-up questions; do not start duplicate work.

Do not fabricate a score or report. Handle server refusals in plain language. Sigil’s tools cannot generate logos, complete brand briefs, access private network websites or charge users. Do not advertise digital purchases or paid offers in this plugin.
