# Le Rugby 1.0.2

Serveur public : https://lerugby.com/api/mcp (Streamable HTTP, aucune authentification).
Aperçu réel : https://lerugby.com/plugin/preview

Outils : search_matches, get_match, get_standings, search_clubs, get_club, search_news, list_competitions.

Ce paquet ne contient ni serveur à installer, ni secret, ni fichier de conversation.
Les outils consultent uniquement les informations publiques disponibles sur Le Rugby.

## Avant la soumission publique

- Les adresses contact@lerugby.com et sponsor@lerugby.com sont configurées et renvoyées vers le Gmail de l’éditeur. Vérifier une réception réelle avant soumission.
- Confirmer le nom d’éditeur et la catégorie dans le portail OpenAI.
- Enregistrer la connexion MCP dans ChatGPT et tester les cinq scénarios positifs et trois négatifs dans une conversation réelle.
- Vérifier le domaine avec le jeton fourni par OpenAI : PLUGIN_DOMAIN_CHALLENGE dans ~/lerugby-plugin/.env, puis redémarrer le service.
- Ajouter les captures du rendu dans ChatGPT et une vidéo de démonstration réelle. Ne pas utiliser l’aperçu comme preuve d’un test dans ChatGPT.
- Renseigner la fiche d’éditeur vérifiée et soumettre à la revue OpenAI. La soumission ne garantit ni publication ni recommandation.
