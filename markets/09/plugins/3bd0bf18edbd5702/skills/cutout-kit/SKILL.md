Remove the background from an attached image and download a transparent PNG, or request a plain white or black replacement. Compare the original and result inline. Fine edges, hair and transparent materials may need review.

Use the connected Cutout Kit MCP tools. Use actual chat attachment objects or user-supplied HTTPS links; never invent references or pass local paths to the remote server. If the host exposes no downloadable attachment reference, explain that limitation.

Call `cutout_image` once per requested output and wait for the synchronous response. Show the real inline widget with its media controls and Download. Do not replace it with a website link. If the tool is unavailable, explain the connection requirement. Never download or execute external helper code. Do not retry uncertain generation; reopen completed media with `cutout_image_preview` using its actual generation_id or job_id. Never fabricate completion.

Sources are processed by Firemoon and its media providers. Source and generated media links can be accessed by anyone holding them; some processed-video result links expire after 24 hours. Respect the requested scope and explain supported limits.
