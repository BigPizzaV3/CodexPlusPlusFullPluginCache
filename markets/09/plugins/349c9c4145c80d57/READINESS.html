| --- | --- | --- |

| Actual ChatGPT tests | Headed Chrome reaches login successfully; HTTP 403 isolated to headless | A signed-in account is still needed for the actual host tests |

The public directory requires a complete service; the bounded hosted review is
not a final public service. The Practice-specific 13+ terms supersede the general
developer-platform age requirement for this service only. The published retention
notice distinguishes one-hour integration records from upstream records that have
no configured automatic maximum; final policy attestations remain outstanding.
No policy attestations, legal changes, organization verification or public
submission are performed by generating this package.

Use `npm run submission:build -- --origin https://YOUR-HOST` to generate the draft
bundle and local validation report. `--release` fails closed until the release
evidence checklist has been completed and the MCP origin is stable. Never mark a
portal approval or host test passed based only on local/API evidence.

Version 0.3.0 uses the package identity `realtime-avatar` and display name
Realtime Avatar. It adds general conversation and a bounded optional topic. The
older practice-oriented modes remain compatible presets. The MCP origin, resource
URI and Durable Object bindings are retained to preserve verification and sessions.
The old walkthrough and call recordings are historical transport/media evidence;
they do not prove the new conversation mode or the actual ChatGPT host. Current
screenshots use the 0.3.0 interface. Follow the portal's package-name rules when
uploading: an update to `realtime-avatar-practice` cannot assume a renamed package
identity will be accepted. Create a new draft for the generic package as needed.
