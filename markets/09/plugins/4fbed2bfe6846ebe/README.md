# CodexPluginStats

Search saved Codex plugin listings, inspect archived files and explain observed changes with source links.

Website and setup: https://codex-plugin-stats.com/docs/mcp

The remote MCP connection requires an account and OAuth. No API keys or embedded credentials are included. The package has no executable hooks or local dependencies.

`plugin.json` is the portable manifest. `.codex-plugin/plugin.json` and `.mcp.json` provide compatibility with existing Codex tooling; portable clients read `mcp.json`. Only the appropriate format is loaded by a client, not both.

This package is prepared for submission. Its presence here does not mean OpenAI has reviewed or published it. The public install link is enabled on the website only after the real listing has been verified.
