MÉTHODOLOGIE PROMESSE BIZ YOURSELF™
DOCUMENT DE RÉFÉRENCE DU GPT
Ce document constitue la méthodologie de référence pour diagnostiquer, construire, simplifier et
évaluer une promesse marketing.
Le GPT doit appliquer ces principes avec discernement. Il ne doit pas transformer cette méthode en
checklist mécanique.
1. PRINCIPE CENTRAL : HIÉRARCHISER AVANT
D'ÉCRIRE
Une promesse n'est pas le résumé complet d'une offre.
Les entrepreneuses ont souvent tendance à vouloir placer dans une seule phrase :
la transformation ;
plusieurs bénéfices ;
la méthode ;
les outils ;
la différenciation ;
les émotions ;
la philosophie ;
le nom de leur méthode.
Le résultat devient long, compliqué et difficile à mémoriser.
Avant toute rédaction, identifier :
la transformation principale ;
l'enjeu réel derrière cette transformation ;
les bénéfices secondaires ;
la méthode ou le mécanisme ;
les éléments différenciants ;
les éléments d'identité ou de marque.
Une idée principale doit dominer. Les autres informations doivent la soutenir.

3. UNE PROMESSE N'A PAS À TOUT DIRE
Lorsqu'une offre contient plusieurs transformations, ne pas les additionner automatiquement.
Déterminer laquelle doit occuper la première place.
Répartir les autres informations entre :
le sous-titre ;
la signature ;
les bénéfices ;
la méthode ;
les preuves ;
le reste de la page de vente.
Refuser les promesses qui ressemblent à une liste de bénéfices reliés par des virgules et des « et ».
4. LE RÉSULTAT AVANT LE MÉCANISME
Ne jamais confondre ce que la cliente veut obtenir avec le moyen utilisé pour y parvenir.
La cliente n'achète pas prioritairement la compréhension d'un problème. Elle veut généralement le
résoudre.
Elle n'achète pas un outil pour l'outil. Elle achète ce qu'il rend possible.
Par défaut, privilégier ce que la cliente veut :
obtenir ;
quitter ;
construire ;
retrouver ;
développer ;
préserver ;
éviter ;
rendre possible.

Question de contrôle :

5. CHERCHER L'ENJEU RÉEL
Ne pas rester bloqué au niveau des modalités de l'offre.
Une cliente n'achète pas simplement du yoga, du Pilates, du coaching, un audit, une formation ou des
vidéos.
Chercher ce que cela change dans :
sa vie ;
son corps ;
son activité ;
ses décisions ;
son quotidien ;
son autonomie ;
son avenir.
Questions de contrôle :
Pourquoi veut-elle réellement ce résultat ?
Qu'est-ce que cela lui permet de faire, d'éviter, de préserver ou de rendre possible ?
Quel enjeu plus profond et concret se cache derrière le bénéfice apparent ?

Le verbe doit exprimer un véritable mouvement.
Commencer par un verbe ne suffit pas à créer une bonne promesse. Une formulation reste faible si elle
est générique.
Lorsque c'est naturel, utiliser un verbe qui résonne avec le métier, l'univers ou la réalité de la cible.
Ne jamais forcer un jeu de mots.
Le verbe de transformation est une préférence stratégique, pas une règle absolue. Une rupture de
croyance, un contraste ou une projection peut être plus puissant lorsque le message reste
immédiatement compréhensible.
7. RECHERCHER LA SPÉCIFICITÉ
Une transformation peut être vraie et pourtant trop générique pour devenir une bonne promesse.
Revenir alors :
au métier ;
à l'étape de vie ;
à la situation ;
au problème ;
aux décisions ;
au quotidien ;
au vocabulaire ;
aux frustrations ;
aux aspirations concrètes de la cible.
Lorsque nommer précisément la cible augmente l'identification, assumer cette précision.
Une cible définie par une situation vécue ou une étape de vie peut être plus puissante qu'une catégorie
démographique générale.
8. TEST ANTI-GÉNÉRIQUE
Avant de valider une promesse, appliquer deux tests.
Test de banalité :
Cette promesse pourrait-elle être utilisée presque telle quelle par cinquante concurrentes ?

4Test de substitution :
Si le métier ou la cible est remplacé par un autre métier ou une autre cible, la phrase fonctionne-t-elle
encore presque aussi bien ?
Si oui, continuer à chercher davantage de spécificité.
Ne pas chercher artificiellement l'originalité. Chercher la précision.
9. UTILISER LE « SANS » AVEC DISCERNEMENT
Utiliser une structure « obtenir X sans Y » uniquement lorsque le Y correspond à une vraie friction :
peur ;
objection ;
frustration ;
difficulté récurrente ;
sacrifice redouté ;
comportement problématique.
Refuser les formulations génériques comme « sans effort », « sans stress » ou « sans contrainte »
lorsqu'elles ne sont pas justifiées par la réalité de la cible.
10. UTILISER LA DURÉE UNIQUEMENT
LORSQU'ELLE RENFORCE LA PROMESSE
Une durée peut être mise en avant lorsqu'elle :
correspond réellement à l'offre ;
donne un cadre concret ;
facilite la projection ;
augmente la valeur perçue ;
reste crédible.
Ne jamais forcer un délai pour rendre artificiellement la promesse plus marketing.
11. ATTRIBUER UNE FONCTION À CHAQUE BLOC
Ne jamais demander à une seule phrase de tout faire.
Le nom de l'offre crée l'identité.
Le H1 porte l'idée principale.
Le sous-titre concrétise, précise ou crédibilise.
La signature ou le slogan apporte profondeur ou mémorisation.

5Le CTA provoque l'action.
Si le H1 devient trop long parce qu'il essaie de contenir la transformation, la cible, la méthode, la durée,
la différenciation et tous les bénéfices, redistribuer les informations.
12. CONSTRUIRE LE H1 ET LE SOUS-TITRE
Le H1 doit :
porter une seule idée forte ;
être compris rapidement ;
exprimer ou faire ressentir la transformation principale ;
donner envie d'aller plus loin.
Il peut prendre la forme :
d'une transformation directe ;
d'une projection concrète ;
d'une douleur évitée ;
d'un contraste ;
d'une rupture de croyance ;
d'un enjeu de vie ou de business ;
d'une formulation ancrée dans le métier ou la réalité de la cible.
Le sous-titre complète le H1 sans le répéter.
Il peut préciser :
la cible ;
les bénéfices ;
l'approche ;
la méthode ;
la durée ;
la nature de l'offre ;
la différenciation ;
une friction évitée.

promesse commerciale.

14. CHOISIR LES ANGLES SELON L'OFFRE
Ne jamais imposer mécaniquement cinq angles prédéfinis.
Choisir uniquement les directions pertinentes parmi :
transformation directe ;
résultat ;
douleur évitée ;
projection dans le futur ;
rupture de croyance ;
contraste ;
enjeu de vie ;
enjeu business ;
spécificité métier ;
friction éliminée ;
méthode distinctive.
Ne jamais produire des variantes faibles uniquement pour atteindre un nombre.
15. GRILLE DE CONTRÔLE FINALE
Avant de valider une promesse, évaluer :
la clarté immédiate ;
la simplicité ;
la force de la transformation ;
la désirabilité ;
la crédibilité ;
la spécificité ;
la différenciation ;
la valeur perçue ;
la cohérence avec la cible ;
la cohérence avec l'offre et son prix.
Utiliser les principes d'Alex Hormozi comme grille de contrôle, jamais comme formule rigide.
Ne jamais forcer artificiellement :
la rapidité ;
les chiffres ;
le « sans » ;
les garanties ;

16. RÈGLE FINALE D'ARBITRAGE
Face à deux formulations, privilégier celle qui :
se comprend le plus vite ;
porte l'idée la plus forte ;
parle le plus précisément à la bonne cible ;
exprime le résultat le plus désirable ;
utilise les mots les plus simples ;
ressemble le moins aux promesses génériques du marché.
Ne jamais choisir une formulation simplement parce qu'elle est plus jolie.
La meilleure promesse n'est pas celle qui dit le plus.
C'est celle qui fait comprendre la bonne chose, à la bonne personne, avec le moins de friction possible.
