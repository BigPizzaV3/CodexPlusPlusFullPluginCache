# Connected classroom resources

Privacy boundary: this public plugin is for adult educators and creators. Never
transmit personal information about children under 13 to OpenAI. Use anonymous
or synthetic inputs only; do not request, send or retrieve pupil names, pupil
ids, rosters, photographs, scripts, individual answers or individual results.
Apply this boundary whenever ages or identifiability are uncertain. Do not
open, screenshot, upload or read back private pupil records through a browser
or another connector. Give the exact native link and hand the sensitive step
to the adult user to complete independently. Do not read a record first merely
to decide whether it contains personal information.

Call `get_planit_catalog` and use the current `projectWorkflows`. The recipes
connect vocabulary practice, multiplication/division practice and mounted
pupil-work planning. Their exact tool slugs and settings come from the live
registry; this file intentionally does not repeat a tool list.

Agree the learning purpose and the smallest useful set of outputs. Check the
age, language and curriculum context when relevant. The recipe's examples are
examples, not teacher measurements or facts. Ask for missing inputs needed by
the next step; do not make the teacher complete the whole recipe form first.

Read each step's exact `operations.detail` and call its `operations.prepare`
for a real preview. The catalogue row also exposes `detailTool`, `previewTool`
and `exportTool`. Use only names individually present in the connected MCP
tool list, with their own fixed input schemas; never invent a name or send a
`tool_slug` selector to preview/export. A recipe describes those operations,
not a dynamic executor. If an operation is unavailable, use the exact native
editor and report that a reviewed server refresh is needed. A shared word
list does not guarantee that every generator includes every word: respect
their limits and inspect the actual previews. Preserve an individual seed and
complete snapshot for each file. Carry numeric utility results using their
exact `calculation.rows[].key` and declared units. Apply a declared conversion
once; do not infer units from a displayed number.

For printing estimates, use the actual `pageCount` of each prepared file,
including answer pages and card backs only when they will be printed. Duplex
rounding happens per file before totals are added. Distinguish copies for
pupils from teacher answer copies. Obtain the teacher's per-side printing rate
and describe costs as estimates from that rate. Do not call printing services
or invent a live quote.

For a display, use measured board/item sizes, include the physical mount and
respect the recipe's edge allowance. A regular grid is one candidate layout;
check a second orientation when acceptable. A calculation report or schematic
is not a life-size cutting template. Pouch fitting uses actual pouch dimensions
and manufacturer clearance; convert centimetres to millimetres only where the
mapping says to.

Return the useful classroom outputs first, with their purpose, page counts and
exact source or saved-resource links. Download only the files requested, using
the matching snapshots and a linked free account. A saved snapshot remains an
editable record; its old PDF does not update after an edit. Offer one relevant
next step when useful, without unrequested bulk generation or account upsells.
