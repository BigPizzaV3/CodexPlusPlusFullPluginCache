# JotScout

A quiet place for notes, ideas, and things to do. Write with Markdown, organize notes into files, and save locally on your device. Published by FancyDino LLC. Support: support@fancydino.com.

The plugin's open_notepad tool opens the editor. Create a file with + and switch files using the drawer. Markdown shortcuts render headings and lists as you type; select text to format or color it. Delete finished items as ordinary text.

Notes save locally in the browser or app on the device. The chat tool cannot read, edit, or synchronize notes or discover ChatGPT projects. Export Markdown or a JSON backup from Files & backups; use the copy fallback when the host cannot download files. Import a file or paste backup JSON, then confirm replacement.

Website: https://jotscout.com
Web editor: https://jotscout.com/notepad/
Hosted app: https://app.jotscout.com
Demo: https://jotscout.com/review/

The package includes the listing, logo, custom-domain MCP endpoint, five positive cases, three negative cases, and release notes. No reviewer credentials or private App bindings are included.

The endpoint is https://app.jotscout.com/api/mcp. It exposes only open_notepad and the static editor resource; notes stay on the device and are not available through server tools. The public opener does not require an additional plugin sign-in. The original Sites-managed /mcp connection remains separate and authenticated.

The owner-approved custom-domain endpoint is deployed. Public HTTPS initialization, tool discovery, open_notepad, and UI resource retrieval have passed. ChatGPT connected with No authentication and rendered Notepad from the new endpoint. Domain verification and publisher policy attestations are completed in the OpenAI dashboard using the fresh draft's token. The endpoint does not require OAuth. This package creates a new draft; it must not be used to change the immutable endpoint on an existing submission.
