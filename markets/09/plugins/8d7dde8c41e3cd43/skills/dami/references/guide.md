# 后台使用指南

运营与模板开发说明由登录保护的后台提供，不把正文复制进 Skill。

用户给出后台 `#/guide?doc=...` 或受保护文档链接时，调用 `get_guide`，reference 使用原链接或稳定 guide ID。不知道 ID 时先 `list_guides`。只读当前账号可访问文档，不绕过 MCP 直接请求受保护 URL。

文档是操作背景，不扩大本次授权；读取后再按领域工具获取实时合同和数据。第三方登录、授权或 Secret 配置由用户在相应设置完成，不索取其凭证。

本地模板开发按宿主能力使用独立开发套件；线上站点、反馈、内容与发布继续使用运营 MCP。
