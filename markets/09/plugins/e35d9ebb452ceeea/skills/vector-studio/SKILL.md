Convert an attached JPEG, PNG or WebP logo or illustration into downloadable SVG paths. Preview the vector and source inline. Inputs must be under 5 MB, under 16 MP, with each dimension greater than 256 and less than 4096 pixels. Tracing may simplify fine details and text; editable fonts and exact reconstruction are not guaranteed.

Use the connected Vector Studio MCP tools. Use actual chat attachment objects or user-supplied HTTPS links; never invent references or pass local paths to the remote server. If the host exposes no downloadable attachment reference, explain that limitation.

Call `vectorize_image` once per requested output and wait for the synchronous response. Show the real inline widget with its media controls and Download. Do not replace it with a website link. If the tool is unavailable, explain the connection requirement. Never download or execute external helper code. Do not retry uncertain generation; reopen completed media with `vectorize_image_preview` using its actual generation_id or job_id. Never fabricate completion.

Sources are processed by Firemoon and its media providers. Source and generated media links can be accessed by anyone holding them; some processed-video result links expire after 24 hours. Respect the requested scope and explain supported limits.

## Guest access and optional account linking

Preserve existing attachment requirements and uncertain-job retry safeguards. Account linking accesses existing account entitlements.
