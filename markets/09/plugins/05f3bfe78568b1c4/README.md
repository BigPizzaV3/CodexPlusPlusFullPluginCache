# Flowforth plugin

Initial release: connect your Flowforth account to analyze email campaign
performance, explore audience data, create and edit draft emails and templates,
and preview drafts. Sending and scheduling are completed in Flowforth.

The package uses Flowforth's existing MCP endpoint and OAuth flow.

Upload this ZIP to the existing Flowforth draft in the OpenAI Platform dashboard.
The upload updates the draft; submission for review and publication are separate steps.
Complete the dashboard's remaining MCP setup and review information before submitting.

Version 1.0.2 includes five positive review cases, three negative review cases,
and the supplied video walkthrough URL. The cases use the Flow Church demo
organization. Run the draft-creation case before the edit case in the same
conversation. Reviewer credentials and sign-in instructions stay in the
dashboard's private reviewer-access fields.
