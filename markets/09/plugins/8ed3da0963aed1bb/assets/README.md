# Existing VedPatrika branding

Source: https://vedpatrika.in/brand-mark.png, the live website header/footer logo. No new logo was designed. All four declared icons are byte-identical copies of the original 256 x 256 PNG. The original has an opaque warm background, so the same asset remains visible in dark mode without recoloring.

Current packaged branding rules: square, PNG/JPEG/WebP/SVG; minimum 48 x 48; raster maximum 4096 x 4096; maximum 5 MiB each. The supplied PNGs meet these limits. No unsupported claim that a particular larger size is mandatory is made.
