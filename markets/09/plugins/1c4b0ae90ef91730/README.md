# Conveo for ChatGPT

Connects ChatGPT to your Conveo workspace through Conveo's MCP server at
`https://app.conveo.ai/api/mcp`. Sign in with your Conveo account when
prompted; ChatGPT only sees the studies that account can already access.

Docs: https://conveo.ai/docs/api-reference/mcp
Support: support@conveo.ai
