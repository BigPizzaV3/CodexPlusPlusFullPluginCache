# autoprint ChatGPT plugin

The package source is in this folder. Zip plugin.json, mcp.json, skills/ and assets/ at the ZIP root, then upload to the existing OpenAI plugin.

The reviewer video is hosted at https://autoprint.auto-units.com/review/plugin-walkthrough.mp4. It shows recorded public MCP requests and outputs, not the ChatGPT interface. Timing is edited. Its source, evidence and critiques are in the local Launch video lab, artifacts/plugin-review-2026-10-04. The video manifest records hashes and format.

OpenAI validates domain ownership through the storefront's public/.well-known/openai-apps-challenge file. Keep existing plugin identities and verification tokens. Public tool access does not expose subscriber accounts or SMS. Portal submission and approval are separate from deployment.
