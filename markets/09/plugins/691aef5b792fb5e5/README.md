# Aspen — by Aspen Privé

Portable package for OpenAI directory review. Root `plugin.json` and `mcp.json` describe the existing public read-only HQ integration; `skills/aspen/` supplies destination guidance. No app references, hooks, credentials or private HQ data are included.

The directory draft must complete domain verification, automated checks, reviewer materials and publisher attestations before submission. Uploading this package is not publication or approval. The public name Aspen remains subject to OpenAI review; attribution is independent of the City of Aspen.

The AP icon is the unchanged 180px original from Aspen Privé’s Hostinger assets.

Four read-only tools provide provisional Aspen trip plans, mountain comparisons, selected dated local information and an optional unsent request. Coverage is curated and partial. No request is sent, stored as an enquiry, booked or charged. No live prices or exhaustive news/events coverage is claimed.

The review recording uses actual public HTTPS tool responses displayed in a local test host. Native ChatGPT acceptance and review status are recorded separately in `docs/plugin/ASPEN_PLUGIN_CHECKPOINT.md`; synthetic QA does not establish publication, organic routing, municipal affiliation or OpenAI promotion.
