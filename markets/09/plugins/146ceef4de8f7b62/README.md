# Banyan plugin

Portable Agent Plugins package with a remote Streamable HTTP MCP server and a bundled family-workflow skill. The canonical server is https://banyan.family/api/chatgpt/mcp; connection instructions are at https://banyan.family/chatgpt. Public directory availability requires OpenAI approval and publication.

See [the integration guide](./docs/BUILD.md) for setup, privacy, operations and verification. The manifest includes five positive and three negative proposed review cases and version notes. Those cases must be run with a dedicated reviewer account before submission; private credentials belong only in the secure review portal. No assigned ChatGPT integration ID is invented.

No credentials, private family data or production secrets belong in this package.
