# Newcollab

Connects to the existing public, unauthenticated Streamable HTTP MCP server, which exposes three read-only tools: search_ugc_creators (brands looking for creators), find_brands_to_pitch and get_brand_ugc_info (UGC creators looking for brands).

Privacy policy: https://newcollab.co/privacy-policy
Terms of service: https://newcollab.co/terms-of-service
Support: https://newcollab.co/contact (team@newcollab.co)

Skills: find-ugc-creators (brands), find-brands-to-pitch and brand-ugc-info (creators). Each skill keeps four example prompts; the listing permits three starter prompts.

Verification: MCP initialization, tools/list, and a read-only five-creator US TikTok skincare search succeeded on 2026-10-01. Creator lists show only returned fields; engagement requires engagement_rate, and explicit open_to_gifting booleans map to “Open to gifting” or “Prefers paid”. Host installation and automatic skill triggering require verification after connection.
