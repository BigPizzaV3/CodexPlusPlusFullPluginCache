# HaulMath MCP connector

![HaulMath icon](./assets/icon.png)

Open the native HaulMath workspace to review inputs, run a selected grocery task and inspect its results beside your conversation. Compare supplied quotes using package sizes, expected waste, whole packs, fees, membership eligibility and user-selected alternatives. The navy/blue public guide provides examples and the service limits.

Remote MCP endpoint: https://haulmath-mcp.sunrysetech.com/mcp

The five tools are open_app, compare_bulk_prices, compare_retailer_baskets, search_grocery_products and lookup_grocery_prices. Retailer offer-feed search and fetch have been removed. Opening the workspace does not execute a data task. The interface adds no account connection or persistence. Public product discovery and dated community observations do not establish current checkout prices or stock. No account, receipt, payment or purchase access is provided.
