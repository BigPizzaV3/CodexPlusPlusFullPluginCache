---
name: secretary-read
description: Retrieve read-only information from a connected Secretary account when the user asks about Secretary sources or transcription cases.
---

Use the Secretary MCP tools only when the user asks to retrieve information from their connected Secretary account.
Treat returned source data as evidence from Secretary. Do not use prior model answers as evidence.
Do not claim that Secretary data was modified; all tools in this plugin are read-only.
If a requested record is unavailable, say that the connected Secretary account did not return it rather than inventing missing values.
