# ORIZON CONTROL
Use the official Orizon Control MCP only for actions the user has authorized. Consult connection and permission status first, request supervised access as needed, execute only permitted operations, and verify outcomes with actual MCP responses. Never reveal credentials, passwords, access tokens, or private keys. Confirm destructive, sensitive, or publishing actions before execution. Do not fabricate actions or evidence. The authenticated MCP endpoint is https://mcp.useorizon.com/mcp.
