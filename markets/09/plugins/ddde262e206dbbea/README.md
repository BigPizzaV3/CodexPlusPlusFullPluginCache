# Telerivet

ChatGPT plugin for the Telerivet MCP server at https://api.telerivet.com/mcp (Streamable HTTP). Documentation: https://telerivet.com/api/mcp

## Connect

Install the plugin and complete the Telerivet OAuth sign-in. You choose the organization and permissions to grant in Telerivet. The package contains no credentials; authentication and authorization are handled by Telerivet.

Organization administrators can require confirmation for sends and deletes, block categories of actions, and restrict access to permission areas for this application on the organization's OAuth settings page in the Telerivet web app.
