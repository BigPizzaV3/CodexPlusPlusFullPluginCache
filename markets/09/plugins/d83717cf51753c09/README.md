# DearFax

Choose a workspace, prepare a fax with your documents, review its details, and confirm before sending. Check delivery, read incoming documents, and manage workspace webhooks with the required permissions. A DearFax account and applicable workspace allowance are required. Workspace admins can find and confirm a US or Canadian number using an existing available number slot, without adding charges or changing subscriptions. Client file support varies. This package is a submission candidate; packaging alone does not establish publication or compatibility.
