# PulseLake Simulations plugin

The MCP endpoint and browser workspace are available at
`simulations.pulselake.co`. Marketplace availability depends on host review
and approval.

Connect using the host's OAuth flow. Ask “Open the Simulation Research workspace”
or “Help me choose a simulation.” UI-capable MCP Apps hosts can show the workspace;
other hosts use the same typed guided tools. Host permission prompts are controlled
by the host and cannot be bypassed by this plugin.

The plugin uses your existing PulseLake account. Review the participants, question
set, simulation volume, deliverables and maximum credit cost before explicitly
approving a run. History and report retrieval do not rerun paid work.

This marketplace surface intentionally does not offer credit purchases, plans,
billing emails or checkout links. It can show existing credit entitlement. Browser
account billing is a separate, independently accessed surface of the same service.

Support, privacy, and service terms are linked in the plugin listing. No
credentials belong in this package.
