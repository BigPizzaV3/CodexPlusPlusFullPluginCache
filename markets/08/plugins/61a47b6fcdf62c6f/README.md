# Open Calls 0.10.0

The ChatGPT directory version **0.7.1 is approved and published**. [Install Open Calls in ChatGPT](https://chatgpt.com/plugins/plugin_asdk_app_6aa7a4ba0dd08191ad726b2951f8b0be), connect your Open Calls account and ask for a quote. The directory path needs no Developer mode or copied connection key. Public signup is open; calls still require the current agreement, available balance or an eligible welcome minute, and approval of the recipient and maximum charge. The portable package version below is a separate artifact from that published directory version.

A portable plugin containing a small calling skill, public Streamable HTTP MCP connection and icons. It contains no credentials. Results are text and structured data.

Website: https://opencalls.dev · Support: https://opencalls.dev/support

Connect an account through the host's OAuth flow. Use existing credit only. The fictional `preview_call` demonstration makes no phone call and incurs no charge. Never use `make_call` as an unapproved demonstration.

Directory submission, review approval and publication are separate from this package. Reviewer credentials belong only in the secure submission form.
