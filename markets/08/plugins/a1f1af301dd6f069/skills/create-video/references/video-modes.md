# Video modes

Use the model-specific schema returned by `get_capabilities` for the chosen asset, project and model. These are routing hints, not permission to substitute a model or hard-code its availability.

- **Illustrated narration:** `autocontent-narrated-video-v1`, when offered for `short_video` or `explainer_video`, makes faceless illustrated narration and explanatory animation without music. Retain an explicitly chosen compatible voice. Discover voice IDs instead of deriving them from names.
- **Real website journey:** `autocontent-recorded-demo-v1`, when offered for `product_demo_video`, `launch_video` or `ad_video`, records actual browser actions. Supply the authorized public HTTPS `options.website_url` and describe the journey in instructions. Use browse mode by default. Demo interactions require the user's confirmation of a test environment without real purchases, messages or destructive effects; never infer that confirmation. Private access uses an existing project `recording_access_id`, not credentials pasted into prompts. SSO, MFA and CAPTCHA are not supported by that recording flow. This mode composes its own narration and does not accept an exact narration script or avatar.
- **Instrumental motion graphics:** `autocontent-motion-design-v1`, when offered for `launch_video` or `ad_video`, uses an original instrumental and has no narration or avatar. Omit voice, avatar, narration-script and caption styling fields. Use the returned schema for music direction, resolution, aspect ratio and duration; do not apply narrated-video defaults to it.
- **Exact narration or avatars:** Check `supports_narration_script` and `narration_script_schema`. Exact speaker text belongs in ordered script segments; voice/avatar IDs belong inside declared speakers rather than at the asset root. `options.presentation_mode` must match the request. Use only ready, compatible, already-authorized resources. The duration is a target; do not promise exact runtime or padding when speech ends sooner.
- **Product footage:** Use actual ready Product Visual sources when a model supports them. Put their IDs in the selected model's advertised field, not an invented common field. Product photos and style references have distinct roles. Do not use an unrelated image or a logo as proof of a product's appearance.

For edits, the preview determines which existing footage, narration and music are retained. Request fresh recording or music only when the user asks for that change and approves the resulting quote. Never silently rerecord browser interactions.
