# Kazna Codex / ChatGPT plugin (v1.1.0)

Portable Agent Plugins package + Codex compatibility overlay.

- MCP: `https://kazna.online/mcp/` (OAuth for ChatGPT/Codex; PAT `fp_mcp_*` also accepted)
- Skills: overview, channels, billing, orders, subscribers
- Policy: read-only author insights — no digital product sales/pricing tools

## Upload ZIP

Use `dist/kazna-1.1.0.zip`. The archive root contains the `kazna/` folder with `plugin.json` inside.

## Local marketplace (optional)

Point `source.path` at `./plugins/kazna` from a marketplace whose root is the Kazna repo.
