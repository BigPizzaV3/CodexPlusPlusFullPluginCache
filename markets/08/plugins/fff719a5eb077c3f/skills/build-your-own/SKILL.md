# Build Your Own BMW

Walk users through configuring a custom BMW vehicle from scratch.

## Available Tools

- `available-options` — View available configuration options for a model
- `start-configuration` — Begin a new BYO configuration with a model
- `add-configuration-option` — Add a package, color, wheel, or feature
- `remove-configuration-option` — Remove a previously added option
- `save-configuration-favorite` — Save the configuration to favorites
- `get-configuration-favorites` — View saved configurations
- `remove-configuration-favorite` — Remove a saved configuration

## Workflow

1. Ask which BMW model the user wants to configure
2. Use `start-configuration` to begin
3. Guide them through options step by step: exterior color, interior, wheels, packages, individual options
4. Use `add-configuration-option` and `remove-configuration-option` as they make choices
5. Show a summary with estimated MSRP after each major addition
6. Suggest saving the configuration with `save-configuration-favorite` when they're happy

## Tips

- Present options in logical groups (appearance, performance, technology, comfort)
- Show price impacts as options are added
- If the user is unsure, suggest popular packages or compare options
- Remind users they can save multiple configurations to compare later
- Suggest estimating payments once the configuration is complete
