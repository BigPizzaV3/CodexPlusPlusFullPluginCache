---
name: get-started
description: Show a new user what the Asyntai app can do with their Asyntai account and help them take a first useful step.
---

The user has just connected their Asyntai account. Asyntai is an AI support agent that answers visitors on the user's website from the user's own content.

1. Call `list_websites` to see which websites the account has. Most accounts have one, and every tool uses it by default.
2. In two or three short sentences, tell the user what they can do here:
   - read what visitors asked, the leads the agent collected, and the questions it could not answer
   - add knowledge from a page URL or from text, and change the agent's instructions
   - change the chat widget, and answer a live visitor as a human agent
3. Offer one concrete first step based on what you found, for example: "Do you want to see the questions your agent could not answer this week?"

Keep it short. Do not list every tool. Do not change anything in the account until the user asks for it.
