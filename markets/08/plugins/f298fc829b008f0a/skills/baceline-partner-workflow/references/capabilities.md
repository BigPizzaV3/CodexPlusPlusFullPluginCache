# 현재 연결 범위

이 표는 패키지 1.3.9의 스킬 지침과 현재 배포 도구를 대조하기 위한 것이다. 실제 실행에서는 현재 도구 정의와 서버 권한이 우선한다. 이 문서는 도구를 추가하거나 scope를 부여하지 않는다.

| 단계 | 현재 연결 | 처리 |
|---|---|---|
| 공개 대회 검색과 상세 | search_tournaments, get_tournament | 공개 정보만 조회 |
| 본인 경기 기록 | get_my_match_results | 인증한 본인의 공개 대회 경기만 조회 |
| 대회 생성 질문·이미지·미리보기 | ask_tournament_questions, attach_tournament_image, preview_tournament_event | 실제 파트너 자격과 scope 검사 후 진행 |
| 비공개 대회 draft 저장 | create_tournament_event | app-only, 사용자 확인 카드 클릭 전용 |
| 참가자와 결제 조회 | 공개 관리 도구 미연결 | 완료로 설명하지 않고 기존 관리 경로 안내 |
| 시드 생성·조편성 | 공개 관리 도구 미연결 | 기존 운영 규칙 연결 설계 중, 임의 배치나 저장 금지 |
| 조별 경기장·대회 코트 | 공개 관리 도구 미연결 | 시설 예약 도구로 대신하지 않음 |
| 본선 bracket_setup 설정 | 공개 관리 도구 미연결 | 조 배정과 구분, 설정 저장 완료로 설명하지 않음 |
| 경기 진행·결과 입력·잠금 변경 | 공개 관리 도구 미연결 | 운영 변경 실행 금지 |
| 참가비 결제·환불·정산 | 공개 실행 도구 미연결 | 금융 실행이나 완료 주장 금지 |

향후 도구를 공개하면 실제 tool name, input schema, 권한, 미리보기·저장·재조회 계약과 검증 결과에 맞춰 이 표와 스킬을 함께 갱신한다. 도구가 보이지 않는 현재 상태에서 신규 운영 도구 이름을 가정해 호출하지 않는다.
