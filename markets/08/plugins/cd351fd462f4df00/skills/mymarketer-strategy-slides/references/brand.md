# 標準の色・文字・版面

2026-09-05のユーザー指定: **ゴシック体を基本に、濃紺を主色とし、MyMarketerのゴールドロゴを全ページに常設する。** 顧客のブランドやロゴ省略について明示の指示がある場合は、その指定を優先する。

| 用途 | 色 | 使い方 |
| --- | --- | --- |
| 主色 | `#142B49` | 見出し、表の軸、強調グラフ、主要な罫線 |
| 本文 | `#182D49` | 白地の本文。主色と同じ濃紺系 |
| 補助色 | `#A9B9CE` | 補助の図形や比較系列 |
| 中立・補足 | `#617084` | 説明、出典 |
| 淡い背景 | `#EDF2F7` | 必要な範囲の補助面 |
| 基本背景 | `#FFFFFF` | 本文ページ |

2026-09-05追加指定：ゴールドは公式ロゴに加え、各ページの重要な判断・キーワードにも限定して使う。構造や主要な面は濃紺を保つ。白地の強調文字は #967021、濃紺地では #D8B968。長文全体や全見出しをゴールドにせず、1〜2の注目箇所、または意味が共通する一群に絞る。`blue` / `cyan` は元エンジンの役割名で、濃紺／淡い青灰色に対応する。赤や緑の意味色は保持し、色だけで実績／目標や勝敗を区別しない。

## 書体

**タイトル・本文・表・グラフ・ページ番号をYu Gothicで統一する。** 明朝体は使わない。見出しは太字、本文は標準の太さ。英語資料の既定はArial。Yu Gothicがない環境ではHiragino SansやNoto Sans CJK JP等の利用可能な和文ゴシックへ揃えて置換し、改行を再確認する。フォントの同梱・埋め込みはしていない。

元エンジン内の `FONT_SERIF` は互換性のため残る役割名であり、本スキルでは本文と同じゴシック体を指す。別の生成機能を使う場合も全テキストをゴシック体へ統一する。

## 常設ロゴ

[公式横長ロゴ・ゴールド版](../assets/logo/horizontal-gold.png)を全ページ左上に置く。表紙・章扉・裏表紙も対象。白地ではゴールド版、濃色面で使う場合は[白版](../assets/logo/horizontal-white.png)。元画像をそのまま使い、独自の再描画や文字列への置換、色変更、縦横比の変更はしない。

16:9の基準位置は左0.63in・上0.32in、幅1.60in・高さ約0.354in。ロゴの右に資料名、右上に章ラベルを置く。ロゴと資料名の間に0.30inの余白を取り、本文へ重ねない。同梱エンジンの標準ヘッダーは白地を前提とする。

同梱ビルダーはMyMarketerロゴを常設する。ユーザーが省略や顧客ロゴへの差し替えを明示した場合は、対応する生成経路でその指示を反映する。

## レイアウト

16:9、左右余白は約16mm、タイトルは22ptの太字を目安に1〜2行。本文は11.5〜15ptを起点とし、投影中心なら情報を減らして大きくする。文字を縮めて詰め込まない。角丸、グラデーション、影、下部の結論帯は標準に含めない。

表・図・見出し・出典の位置を揃える。6枚の見本は本文の構成比較用なので、表紙・章扉・裏表紙は付けない。
