# マーケティング図解の選び方

顧客・競合・価値の関係が一目で伝わる図を選ぶ。以下は見せ方の引き出しであり、全種類を使う固定構成ではない。案件の結論と根拠から必要な図を選び、説明する関係がない図は加えない。詳細な比較条件や数値一覧は表で補う。

## 基本の戦略図解

| 見本 | 図で伝えること | 作成時に守る意味 |
| --- | --- | --- |
| [3C・P1](../assets/examples/frameworks.pdf) | 顧客・自社・競合のベン図と勝ち筋 | ハイグラウンドは **（顧客が求める価値 ∩ 自社が提供できる価値）− 競合が提供できる価値**。3者共通の中央を強調しない。競合の未充足を確認できなければ「候補・仮説」とする。円の面積を市場規模として読ませない。 |
| STP・P2 | 顧客を分け、対象を選び、選ばれる理由を結ぶ分岐図 | 分けた条件・優先する理由・優先しない対象を残す。根拠のない点数や2軸ポジショニングは作らない。 |
| KPI・P3 | 成果指標から行動指標への掛け算ツリー | 各率の分母・期間・流入経路を揃える。費用÷有効申込数の費目範囲、有効条件と重複除外を示す。 |

## 顧客・競合・価値を深掘りする図解

以下のページは[追加14枚の見本](../assets/examples/marketing.pdf)に対応する。

| ページ・構成 | 図の形 | 判断に必要な情報 |
| --- | --- | --- |
| 1・WHOの解像度 | 対象集合の入れ子 | 戦略ターゲット → コアターゲット → 今動く場面。属性に加え、課題が切実になる状況まで絞る。面積で人数を表さない。 |
| 2・顧客インサイト | 願いと恐れがぶつかる対向図 | 観測した行動、実現したいこと、避けたいこと、葛藤を解釈した仮説。発言の言い換えを本音と断定しない。 |
| 3・購買関与者 | 役割と情報の流れの関係図 | 利用者・推進者・決裁者・導入条件の確認者。それぞれの判断材料を示し、役割違いを別ターゲットと混同しない。 |
| 4・競合と代替手段 | 顧客の目的から伸びる分岐図 | 同じ目的に対する直接競合、間接競合、内製・現状維持を含む代替手段。分類の基準を説明する。 |
| 5・真なる競合 | 比較と見送りの選択図 | 実際に比較した手段・最後に選んだ手段・理由。同業他社や現状維持を自動的に真なる競合と決めない。 |
| 6・乗り換えの力学 | 切り替え判断に向かう対向矢印 | 現状への不満、新しい価値への期待、導入への不安、現状への慣れ。力の大きさを測っていなければ矢印の太さで優劣を付けない。 |
| 7・顧客価値と根拠 | 願い → 便益 → 根拠の対応図 | 各便益に対応する根拠。確認済みの証拠と、これから確かめる条件を区別する。 |
| 8・行動のきっかけ | 出来事から検索・相談までの時間軸 | 顧客が方法を探し始める場面、その接点、検証したい行動。未観測なら想定と明示する。 |
| 9・顧客が達成したい変化 | 現在と望む状態の対比 | 業務、気持ち、周囲との関係。同じ行の左右を同じ観点で揃える。 |
| 10・WHOとWHATの対応 | 顧客の期待と提供価値の接続図 | 対応する価値と、その提供範囲。約束できない期待も明記し、破線などを併用する。 |
| 11・現在と将来の価値 | 顧客・価値・成立条件の対比 | 今の顧客に届ける価値と、将来狙う顧客への別の価値構想。将来価値を単なる追加機能や今の便益の補足と混同しない。 |
| 12・成果を止める中心課題 | 原因候補が合流する因果図 | 流入・訴求などのずれと成果への影響。仮説の因果は破線と注記で示し、相関を原因と断定しない。 |
| 13・顧客に届く経路 | 相手と接点を結ぶ経路図 | 直販・取引先・紹介などの経路。提携や紹介は実現済みか候補かを示す。 |
| 14・戦略仮説の検証 | 仮説 → 観測 → 判断の分岐 | 期間・経路・有効条件・費用範囲・継続／修正条件。0件という観測と計測不足を区別する。 |

## 強調と編集

- 色の正本は[ブランド設定](brand.md)。濃紺の面を活かし、重要なキーワード・数値・注目領域だけにゴールドを使う。全見出しを金色にすると優先度が失われる。
- 図形・線・文字を編集可能なまま保ち、図全体を画像に置換しない。ロゴは公式画像を使う。
- 見本の文章・数値は架空案件専用。実案件では選んだレイアウトの制作用コピーを作り、本文・図中ラベル・見出し・出典・強調対象をすべて案件の根拠に対応させる。欠けた情報は未確認と示す。
- 同梱PPTXを直接編集するか、[再生成手順](production.md#図解見本の再生成)でソースから組み直す。文章だけを差し替えた後も、図の関係と改行を全ページ確認する。
