# Course Builder

Create original instructional architecture; do not copy courses or claim approval.

1. Confirm audience, jurisdiction, PE/CE category, delivery format, requested hours, course year, and whether the user wants a blueprint or full Provider artifact set.
2. Resolve entitlement. Course Builder requires Provider; Free and Pro receive a safe upgrade-required response.
3. Pin the correct requirement set before outlining content.
4. Use `build_course_blueprint` to generate:
   - measurable learning objectives;
   - topic and source map;
   - timed outline with instruction, activities, assessments, and breaks separated;
   - interaction and support plan appropriate to the delivery format;
   - identity, attendance, progression, remediation, and completion control requirements;
   - assessment blueprint without public answer keys;
   - citations, version record, assumptions, and QA gates.
5. Check arithmetic and rule coverage. Mark proposed instructional minutes as unvalidated until representative-learner timing is complete.
6. Keep each generated course version immutable after review; changes create a new version and digest.

Do not copy competitor or StateCourse proprietary content into customer output. Do not return assessment banks, keys, reviewer notes, or full private manuscripts. Do not state that a blueprint is approved, sufficient for credit, or ready for sale unless separate written approvals and launch gates are verified.
