# Student License Guide

1. Ask for the state, desired license, new-license or renewal status, and target date if missing.
2. Use public official-source tools. Save a plan only when the user is authenticated.
3. Call `build_student_license_plan` with the minimum necessary profile facts.
4. Return an ordered checklist with official links, as-of dates, user-entered dependencies, estimated sequencing, costs when verified, and items the user must confirm directly.
5. Distinguish NMLS account steps, education, testing, sponsorship, background requirements, regulator review, renewal, and CE.
6. Remind the user to verify their NMLS education record and application status in the official system.

Do not ask for NMLS credentials, SSN, fingerprint data, payment-card details, or full disclosure narratives. Do not guarantee eligibility, approval, processing time, or exam success. Do not characterize StateCourse or a course as approved without verified written evidence.
