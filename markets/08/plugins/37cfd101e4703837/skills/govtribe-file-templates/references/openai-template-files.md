Use a verified mounted skill root and the existing resolver when available. Keep required buyer forms and selected working drafts as the starting files. This transport supplies original blank library masters when the client's filesystem does not mount the library files.

1. Read the [template file directory](openai-template-files/index.md), select the requested template by ID or display name, then read only its selection resource. The selection carries the frozen catalog revision, exact entry projection, domain owner, completion guide and master index. Its example/preview metadata supplies optional layout context, not business evidence; their binary transport is not required or generated here. Mounted installations retain the original examples and previews.
2. Use native code and a fresh task-local directory. Verify the complete selection against the directory's resource length/hash, then its catalog-entry digest and source-catalog identity. Match the selected master index to that entry's ID, original path, byte length and checksum. This validates the selected projection, not the whole original catalog. The [transport code](openai-template-files/codec.md) uses Python's standard library; equivalent native code must make the same checks. The exact catalog bootstrap is optional and is not a prerequisite for selecting a master.
3. Read only the selected master's index and required groups/parts. For grouped indexes, verify and save each complete group before the next read. Read parts in order, one resource at a time. Verify each resource and payload length/hash; save each payload and verify its saved bytes before continuing. Missing, truncated, duplicate, reordered or mismatched text leaves that master unavailable; do not infer omitted text or substitute a different revision or example.
4. Assemble verified saved parts, verify the full encoded length/hash, decode strictly once, and verify the decoded length/hash and saved-file readback. Preserve the catalog-selected relative path below the task directory and use that exact master with normal native format tools. Keep originals separate from adapted outputs. Follow the selected completion guide and its saved-file checks.

Do not fetch another template, example, preview or the full catalog merely to complete the selected master. A partial task-local master copy is not a mounted installation and must not be passed to the unchanged resolver's full three-asset check. If native code, complete resources or verified bytes are unavailable, identify the file work that remains and provide the useful text or table supported by the domain guide.
