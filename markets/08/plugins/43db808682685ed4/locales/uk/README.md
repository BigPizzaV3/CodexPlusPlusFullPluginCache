# ReMCP — підключені комп’ютери

Безпечне керування комп’ютерами, які ви явно під’єднали до ReMCP.

## MCP / OAuth
Підключення використовує OAuth та https://remcp.site/mcp; окремий статичний MCP-ключ не потрібен.

## Tools
Використовуйте лише інструменти, доступні в поточному сеансі, і перевіряйте дозволи вибраного пристрою.

pdf_info лише читає метадані PDF; pdf_annotations лише читає наявні анотації.

## Review / Branding
У Plugins перевірте статус Configured / Authorized та повторно виконайте виявлення інструментів. Логотип зареєстрованого App налаштовується окремо від ZIP.
