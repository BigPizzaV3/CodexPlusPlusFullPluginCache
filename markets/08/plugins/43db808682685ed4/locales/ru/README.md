# ReMCP — подключённые компьютеры

Безопасное управление компьютерами, которые вы явно подключили к ReMCP.

## MCP / OAuth
Подключение использует OAuth и https://remcp.site/mcp; отдельный статический MCP-ключ не требуется.

## Tools
Используйте только инструменты, опубликованные в текущем сеансе, и проверьте разрешения выбранного устройства.

pdf_info только читает метаданные PDF; pdf_annotations только читает существующие аннотации.

## Review / Branding
Проверьте в Plugins статус Configured / Authorized и запустите повторное обнаружение инструментов. Логотип зарегистрированного App настраивается отдельно от ZIP.
