# ReMCP — sparowane komputery

Bezpieczne sterowanie komputerami, które zostały jawnie sparowane z ReMCP.

## MCP / OAuth
Połączenie korzysta z OAuth oraz https://remcp.site/mcp; osobny statyczny klucz MCP nie jest wymagany.

## Tools
Używaj tylko narzędzi udostępnionych w bieżącej sesji i sprawdzaj uprawnienia wybranego urządzenia.

pdf_info wyłącznie odczytuje metadane PDF; pdf_annotations wyłącznie odczytuje istniejące adnotacje.

## Review / Branding
W Plugins sprawdź status Configured / Authorized i ponownie wykryj narzędzia. Logo zarejestrowanej aplikacji jest zarządzane oddzielnie od ZIP.
