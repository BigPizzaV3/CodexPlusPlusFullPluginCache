# ReMCP — paired computers

Securely operate only computers that you explicitly paired with ReMCP.

## MCP / OAuth
The connection uses OAuth and https://remcp.site/mcp; no extra static MCP key is required.

## Tools
Call only tools advertised in this session and verify the chosen device’s permissions.

pdf_info reads PDF metadata only; pdf_annotations reads existing annotations only.

## Review / Branding
In Plugins, verify Configured / Authorized and refresh tool discovery. The registered App logo is controlled separately from the ZIP.
