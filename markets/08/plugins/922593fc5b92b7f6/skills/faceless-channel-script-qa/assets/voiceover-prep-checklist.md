# Voiceover prep checklist

Run through this after the script fixes are applied, before sending the script to a narrator or a text-to-speech voice.

## Read it for the ear

- [ ] No sentence longer than one comfortable breath (roughly 25 to 30 words); split longer ones.
- [ ] Numbers written the way they should be spoken ("two thousand and eight" versus "20 08"), with units spelled out where a voice might misread them.
- [ ] Names, places and technical terms have a pronunciation note in brackets the first time they appear, or a phonetic spelling for text-to-speech.
- [ ] Abbreviations either expanded or marked as letters ("N A S A" versus "NASA") according to how they should sound.
- [ ] No visual-only references ("as you can see in this chart") unless the edit will show the chart at that moment; add a `[VISUAL: ...]` note for the editor.
- [ ] Parentheses, footnotes and "see above" style asides removed or rewritten as spoken lines.

## Emphasis and pacing

- [ ] The key line of each section is short and placed at the end of its sentence, where a voice naturally lands.
- [ ] Section transitions say where the story is going next, in one line.
- [ ] The opening does not start with a greeting or channel housekeeping unless that is a deliberate channel ritual.

## Final checks

- [ ] Spoken runtime checked with `script_runtime` against the target length.
- [ ] Any claim stated as fact has a source the creator can point to.
- [ ] Every `[your example]` style placeholder has been replaced or removed.
