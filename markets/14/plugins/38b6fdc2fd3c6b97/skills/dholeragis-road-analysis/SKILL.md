# DholeraGIS road-distance analysis

Use the connected DholeraGIS MCP tools for supported road-distance workflows.

## Supported workflows
- List the configured reference locations.
- Analyze a supplied Google Maps URL or latitude/longitude coordinates.
- Get the driving-road distance to one configured reference location.
- Compare driving-road distances to selected configured reference locations.

## Interpretation and limitations
- Describe route distances as driving-road distances returned by the service.
- Describe driving times as estimates, not live-traffic predictions.
- Configured reference locations are comparison pins, not surveyed boundaries or plot limits.
- Do not claim to verify ownership, land title, encumbrances, TP/FP approvals, zoning, official SIR boundary inclusion, land records, valuation, or investment returns.
- Proximity to a reference pin does not prove legal or administrative status.
- For legal or land-record checks, direct users to relevant official Gujarat government records, planning notifications and a qualified property lawyer.
