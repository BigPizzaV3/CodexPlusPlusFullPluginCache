# Original Single-Point Success Criteria Tool Example

This reference preserves the structure and interaction pattern of the original tool.

## Original intake sequence
1. Grade level
2. Learning Target or standard
3. Task
4. Optional evidence of learning

The tool asked each question one at a time.

## Example input
Grade: 6th
Standard: 6.T.SS.2.b Use figurative language or literary devices for intentional effects when creating texts to achieve specific purposes or appeal to the target audience.
Task: Revise a piece of writing to add figurative language.
Optional evidence: skipped.

## Example Learning Target
I can revise my writing by adding figurative language that creates an intentional effect for my audience and purpose.

## Original three-column structure
WHAT I GOT | WHAT SUCCESS LOOKS LIKE | WHAT I NEED

The center column contained qualities of success such as:
1. The revision includes figurative language.
2. The figurative language fits the purpose and audience.
3. The figurative language makes the writing clearer or more vivid.

For each quality, the WHAT I GOT column offered ways to deepen or strengthen the same learning, while the WHAT I NEED column offered usable supports such as models, prompts, checklists, peer feedback, and targeted teacher support.

## What to preserve
- One-question-at-a-time intake.
- Learning Target and task before generating criteria.
- Three-column structure.
- Center column as the single anchor describing quality.
- Extensions that deepen the same learning.
- Scaffolds that preserve the target while increasing access.
- Feedback stems tied to the criteria.
