# Lukka On-chain Data MCP

OpenAI display name: Lukka On-chain Data

Read blockchain address balances, token holdings, transaction history, blocks and supported validator observations through Lukka's Universal Data API. Requires a connected Lukka account with Onchain Data API entitlement. Chain coverage and available detail vary. Use bounded transaction previews and preserve returned blockchain units and timestamps. The connector does not transfer assets, modify ledger records or establish a private wallet owner's identity.
