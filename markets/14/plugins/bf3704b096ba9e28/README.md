# AllRatesToday public plugin package

This package connects to the existing AllRatesToday remote MCP server at `https://allratestoday.com/api/mcp/public` using Streamable HTTP and no authentication, as advertised by that endpoint.

## Contents
- `plugin.json`: Agent Plugins 1.0 listing metadata and initial review cases
- `mcp.json`: remote MCP server configuration
- `skills/allratestoday-fx/SKILL.md`: instructions for sourced, date-aware rate answers
- `assets/allratestoday-icon.png`: listing/composer icon
- `DEMO-WALKTHROUGH.md`: recording script for the required public-review demo

## Public submission status
This is a prepared package, not a submitted or approved listing. Initial public review still requires a real, verified demo recording URL, portal validation/connection and test execution, and completion of the publisher's applicable legal and policy attestations. The test cases are drafted but have not been run through the submission portal.
