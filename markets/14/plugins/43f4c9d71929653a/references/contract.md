# Wildcards contract

Wildcards by ArkheOS is an authored power with a holder, pinned terms and one use in explicitly consenting works. This release supports Storm in harbor and music templates. An editable design, issued card and target work have separate identities. It does not run arbitrary code or act in arbitrary external apps.

Use all available connected tools according to their live schemas. This package's [capability map](capabilities.json) routes every exposed tool; it is not a permission whitelist. No dynamic hidden API catalog is claimed. Server authorization enforces owner/holder boundaries. MCP uses OAuth wildcards:use; creator entitlement reads the existing ArkheOS membership. Public works are readable; private works require owner or matching card holder. Guests claim/play free through the website. Private invitation, transfer and wallet return links grant access; keep them out of public messages, evidence and logs.

Read first, preserve returned IDs and use expected_revision on changes. Use fresh request IDs for distinct create/issue/play actions, and reuse them only to recover the identical action. Never retry an uncertain write under a new identity. There are 200 designs, 100 works, 100 issues/day, 200 cards/work and ten transfers/card; the server enforces limits. Retain stopped/failed checks separately from observed success.

Native visual controls, saved work and exports are available. Sound is opt-in; no automatic chat messages are sent. Unsupported requests should be explained without invoking unrelated tools. This is an initial release; no OpenAI approval or public directory availability is claimed.
