# College Financial GPS

College Azimuth’s educational college-affordability workflow, published by Azimuth Analysis LLC. This package combines eight read-only tools with the Financial GPS skill. U.S. undergraduate programs only; no payments or account required.

Ask about student borrowing, Parent PLUS, family funding, award-letter amounts or a comparison of two to four schools. Financial GPS uses a 10-year payment yardstick; it does not choose a school, lender or repayment plan.

Only relevant tool inputs are sent to https://mcp.collegeazimuth.com/mcp. Inputs are used for the calculation and discarded; operational logs without amounts, incomes, ages or award-letter lines are kept for 30 days. Omit personal identifiers from award letters.
