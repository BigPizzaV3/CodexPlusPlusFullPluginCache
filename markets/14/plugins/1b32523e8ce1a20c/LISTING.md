# Game Maker AI

Short description: Design and balance your game

## Long description
AI game maker to design your game, balance its difficulty and get a build-ready brief. Create a portable one-page game design document with keyboard and touch controls, suggested assets and acceptance checks. Calculate a wave-by-wave difficulty curve with transparent formulas, assumptions and warnings about conflicting numbers. Use these artifacts with any developer or builder, without opening an affiliate link. Define controls, game rules, win and lose states, screens, style and observable acceptance tests. Check missing requirements before opening an online AI app builder through an optional prefilled link. Keep the first prototype small, test it in preview and refine one issue at a time. This plugin prepares briefs and links; it does not create, run or publish games. Builds may require further iteration. The link includes the plugin creator's affiliate code. This is an independent plugin and is not sponsored or endorsed by that builder.

## Capabilities
- Create a portable game design document and control map
- Calculate difficulty curves and explain numeric conflicts
- Check game briefs and acceptance tests
- Open an optional prefilled online AI app builder link

## Starter prompts
- Design a small original platform game with working jump controls.
- Calculate a fair difficulty curve for my space shooter.
- Check my game brief before I start building.
