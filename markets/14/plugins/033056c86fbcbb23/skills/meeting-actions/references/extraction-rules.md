# Extraction rules — Kaus

## Strong commitment signals (usually include)

- “[Name] will / is going to / owns / take point on …”
- “Action item: …” / “AI: …” / “TODO for …”
- “Please send / share / draft … by [date]” with acceptance or no objection in context
- Explicit round-up: “So Alex has the proposal by Thursday”

## Weak signals (flag, don’t invent)

- “Someone should …”
- “We might want to …”
- “It’d be nice if …”
- Unanswered suggestions

## Relative dates

If meeting date + timezone are known, resolve “tomorrow”, “Friday”, “EOD”, “next week” to calendar dates and state the assumption briefly.

If not known, keep the relative phrase and ask once for meeting date/timezone.

## Follow-up drafts

- One draft per owner who has ≥1 table row
- List that owner’s actions as bullets inside the draft
- Match channel (email subject line vs Slack brevity)
- Never claim the message was sent
