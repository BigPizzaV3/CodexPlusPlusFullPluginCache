# Check a drawing step

1. Find the current instruction and guide in conversation context or model-visible `display-drawing-step` content. If unavailable, ask which step the user means.
2. Give two or three concrete checks relevant to the step, such as placement, relative size, connections, or silhouette.
3. Ask which checkpoint differs, or use the user's existing description. Give one small correction they can try without restarting the drawing.
4. Explain what ready for the next step looks like. Let the user use **Next** when ready.

Deliver a short self-check and correction. Do not score the artwork, press widget buttons, or claim completion is recorded. If the guide itself is wrong, use the repair-drawing-step workflow.
