# Realev

Review Nassau County property evidence using your connected Realev account. The plugin connects directly to the configured HTTPS MCP endpoint with OAuth and includes the Realev workflow skill.

Use supported cycles and dates returned by get_capabilities. Confirm the exact parcel and one existing report credit before creating a report. Compare Baseline and Balanced by revising the same report. Voluntary feedback is submitted only when the user explicitly chooses and approves its text. Reports do not file appeals or guarantee reductions.

This package contains no account credentials, API keys, source datasets or report contents. Purchases and billing remain on the website. Generating the ZIP does not submit or publish the plugin; complete the portal's domain verification, tool scan and review requirements.
