# Terraform Academy Brand System

This skill is the single source of truth for how Terraform Academy content looks and sounds. Apply it to every quiz, lab, dashboard, widget, or message you create.

## Visual principles
- Simple, clean, functional, and professional first.
- Fun and immersive where it helps: celebrate wins, show progress, keep it light.
- Never let decoration slow the user down or hide the content.

## Brand voice
- Friendly, direct, confident. Short sentences, no em dashes. No decorative emoji; the single 💡 hint icon is the one permitted functional glyph.
- Encourage progress without hype.

## Colors (authoritative)

| Surface | Hex | Notes |
|---------|-----|-------|
| Terraform Academy chrome (plugin shell, non-quiz, non-lab) | `#FF6B00` | Primary brand orange |
| Terraform / HashiCorp courses and quizzes | `#7B42BC` | HashiCorp purple |
| Azure labs and courses | `#0078D4` | Azure blue |
| GCP labs and courses | `#4285F4` `#EA4335` `#FBBC05` `#34A853` | Google multi-color |
| AWS labs and courses | `#FF9900` | AWS orange |
| Security and IAM | `#B91C1C` | Deep red |
| Hint affordance (💡) | `#FFB020` | Warm amber accent for hints and hint panels |
| Foundations courses | Keep current branding | Do not re-skin |

## Color rules
- Quizzes keep whatever branding they already carry. Never re-skin a quiz to the plugin chrome orange.
- Use Terraform Academy orange only for plugin chrome and primary actions that are not quiz or lab content.
- One content type uses one provider palette. Do not mix provider colors inside a single quiz or lab.
- Dark panels use `#0B1020`, matching the MAX design system.
- On light surfaces, use ChatGPT system backgrounds and text. Reserve brand colors for accents, badges, and primary buttons.
- When in doubt, choose the plain, clean option.

## Typography
- Use ChatGPT and system typography. No custom fonts.
- Use markdown structure: short headings, tight bullets, one idea per line.
