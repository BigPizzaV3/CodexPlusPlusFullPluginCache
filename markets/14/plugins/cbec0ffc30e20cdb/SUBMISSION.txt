AveryGPT OpenAI directory package

This portable Agent Plugins package connects to the hosted public gateway at
https://mcp.averygpt.com/mcp. The /mcp path comes from mcp_gateway/app.py.
The Python backend is deployed separately and is not included in the ZIP.
Tool descriptions and the /docs page are served by that backend. Deploy the
gateway updates separately, then refresh tools in the AI assistant.

Open https://platform.openai.com/plugins and upload the ZIP. Select the verified
publishing identity for AVERYGPT LLC. In MCP setup, configure OAuth, complete the
domain challenge shown by the portal, connect, and inspect the tool scan.
Login is required for every tool; MCP hints do not change authentication.
Enter OAuth secrets and reviewer credentials in the portal, never in this package.

Before submitting for review:
- Verify the production MCP URL, OAuth connection, and advertised tools in the portal.
- Prepare a dedicated test account with paid-feature access, an active sample deal
  with a lender-list entry, and the property/lender data described in the test cases.
- The package includes five positive and three negative cases under
  extensions.com.openai.review.test_cases in plugin.json. Positive case 4 tests
  lending-profile matching instead of document reading. Run all cases with the
  demo account before submitting; case 5 creates and updates sample records.
- Provide a reviewer-accessible video walkthrough URL in the portal or add it as
  extensions.com.openai.review.demo_recording_url in plugin.json before rebuilding.
  No video URL or successful end-to-end execution is claimed by this package.
- Deploy the gateway changes and confirm that the public /mcp surface returns
  neutral entitlement messages without membership-upgrade promotions.
- Resolve the portal's package, connection, and tool-scan findings.

Approval and publication are separate steps. Publish the approved version in the
portal when ready. No upload, deployment, submission, or publication was performed
when creating this package.

Assets use the existing Avery house-circle symbol from Avery-Chat's
client/public/assets/avery-logo-white.svg. The wordmark was omitted and the vector
canvas made square for directory icons. Light and dark backgrounds are provided.

Rebuild from the repository root after changing the source package:
python3 - <<'PY'
from pathlib import Path
from zipfile import ZIP_DEFLATED, ZipFile

source = Path("plugins/averygpt")
output = Path("temp/artifacts/averygpt-plugin-1.0.6.zip")
output.parent.mkdir(parents=True, exist_ok=True)
with ZipFile(output, "x", compression=ZIP_DEFLATED) as archive:
    for relative in (
        "plugin.json", "mcp.json", "SUBMISSION.txt",
        "assets/logo.svg", "assets/logo-dark.svg",
    ):
        archive.write(source / relative, f"averygpt/{relative}")
PY
