# Accepted revenue values

Send the id in `revenue` on company search only. Do not send the dollar label.

| Send this | Meaning |
| --- | --- |
| `0-1000000` | $0 - $1M |
| `1000000-10000000` | $1M - $10M |
| `10000000-50000000` | $10M - $50M |
| `50000000-100000000` | $50M - $100M |
| `100000000-500000000` | $100M - $500M |
| `500000000-1000000000` | $500M - $1B |
| `1000000000+` | $1B+ |
