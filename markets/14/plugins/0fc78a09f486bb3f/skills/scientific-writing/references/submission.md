# Submission

Read the target journal's current official instructions when preparing submission. Check article type, template, engine, length, figures, references, highlights and required declarations. Journal constraints take precedence over house layout preferences.

Do not invent funding, author contributions, data availability, conflicts or AI-use declarations. Ask for missing author decisions.

Prepare a reviewable submission bundle using the system's file rules. Preserve source files and exclude backups or private notes. Compile the bundle and check its output. Uploading or submitting requires an explicit user instruction.
