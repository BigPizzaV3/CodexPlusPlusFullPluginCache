# Tables and figures

Every object must add information and contain the comparison claimed in the text. Identify dataset, aggregation, sample counts and uncertainty where relevant. Never juxtapose incomparable conditions without explaining them.

Use readable numeric alignment, units in headers, consistent rounding and booktabs where supported. Keep small tables only when comparison is clearer than prose.

Regenerate changed figures from their actual data and script. Explain every symbol, band and panel; verify axis units and agreement with the text. Captions must describe every element accurately and contain enough context to interpret it; sentence counts are not quotas.

Follow the journal template for caption placement, typography and float rules. Preserve useful citations and fix source order instead of deleting a reference to conceal layout problems.
