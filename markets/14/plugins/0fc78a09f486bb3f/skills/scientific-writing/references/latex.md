# LaTeX

Kosmico provides `latex.compile` on desktop and web. Use its returned errors, warnings and PDF evidence; never invent a successful compile. Discover additional LaTeX/PDF tools when needed.

Preserve the project's engine, class, bibliography and macros. Use existing unit conventions (prefer siunitx when installed and compatible); never add a package or float override blindly.

After applying source changes, compile the entry document. Resolve introduced errors and undefined references. Inspect changed PDF passages and float placement. Distinguish pre-existing warnings from new ones; report remaining warnings instead of demanding an impossible zero-warning template.

Number floats by first main-text citation and keep them close to that citation within template constraints. Prefer uncluttered pages and top placement where compatible. Inspect the final page during full layout review. Do not trim scientific content merely to hit a cosmetic page target.
