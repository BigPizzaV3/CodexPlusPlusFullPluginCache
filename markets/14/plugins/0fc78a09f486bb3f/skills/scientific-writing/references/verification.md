# Verification

For a local prose edit, check meaning, terminology and surrounding argument. For changed scientific claims or values, trace evidence and check connected text, tables, captions and conclusions within scope. Recompute derived numbers from unrounded inputs.

Distinguish source-checked, manuscript-only and unverified claims. Use “lower on this split” for an observation; claim superiority or causation only at the strength supported by the design and uncertainty. Do not treat a significance threshold as the only possible scientific evidence.

Maintain a short unresolved-points list in the response with issue, proposed resolution and author input needed. Update existing points as resolved. Create a project file only when the user asks for a persistent checklist.

After application, verify actual saved content; use LaTeX/PDF checks for source or layout changes. A proposal alone is not a modified or compiled manuscript.
