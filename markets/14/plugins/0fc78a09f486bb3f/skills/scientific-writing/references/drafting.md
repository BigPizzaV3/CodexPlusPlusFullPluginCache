# Draft a new manuscript or section

Read the brief, target section, evidence and surrounding text. Establish the section's purpose before writing; ask only for missing information that blocks a sound draft. Use explicit placeholders for missing results or citations.

Build an argument suited to the discipline and journal. Typical order: problem and gap; method; protocol and valid comparisons; results; interpretation and limitations; conclusion. This is a starting point, not a mandatory section template.

Deliver the requested draft. Creating a requested new file is authorized; replacing existing manuscript text follows the revision workflow. Keep unsupported claims out, preserve cross-references, and avoid duplicating content already present. Load verification for complete manuscript work and LaTeX for source/layout changes.
