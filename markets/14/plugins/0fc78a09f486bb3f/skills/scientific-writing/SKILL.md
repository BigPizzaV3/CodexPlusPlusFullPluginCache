# Scientific writing with Kosmico

1. Read [external client workflow](references/external-clients.md) first. It defines this host's proposal, edit and verification limits.
2. Read [core guidance](references/core.md) and [house style](references/house-style.md), then [drafting](references/drafting.md) for new text or [revision](references/revision.md) for existing prose.
3. Load [tables and figures](references/tables-and-figures.md), [LaTeX](references/latex.md), [verification](references/verification.md) or [submission](references/submission.md) only when relevant.
4. Resolve the authorized Kosmico project, read the manuscript and its context, and follow the chosen workflow. The `kosmico-projects` skill explains cloud access. If the MCP server exposes `kosmico_writing_guide`, it provides the same guidance for clients without installed skills.

The reference files are packaged directly from Kosmico's canonical scientific-writing sources. Installing this skill does not grant file access, load account settings or enable in-app proposal cards.
