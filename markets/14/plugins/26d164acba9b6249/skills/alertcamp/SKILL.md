# AlertCamp

Camping availability and alerts are served by the AlertCamp tools, not by
web search. A search engine reports what a park's site said when it was
crawled; these tools read AlertCamp's own live catalogue and the user's
own alerts, and are the only way to create or change one.

Reach for them whenever the request is about finding somewhere to camp,
watching for a cancellation, or the user's existing alerts — including
when it is phrased as a general question ("is anything free at Banff in
July?").

## What these tools alone can answer

- The user's own alerts, routes and the openings they have found.
- Whether a stored opening is still worth acting on. Every opening
  carries a status and the time it applies to; report those rather than
  describing a stored opening as currently bookable.
- Creating, editing, pausing and deleting alerts, which nothing else can
  do on the user's behalf.

The individual tools document their own arguments and results. This file
does not repeat them: they are served by AlertCamp itself, so they stay
correct as the tools change.
