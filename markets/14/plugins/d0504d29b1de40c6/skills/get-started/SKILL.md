# Get started with Comptabilities

Use this skill right after the user connects Comptabilities, or when they ask what the plugin can do.

1. Read the overview of the connected organizations: companies, bank accounts, current balances and main currency. If several organizations are connected, ask which one the user wants to look at, and never add up figures from different organizations without saying so.
2. Summarize in two or three sentences what you see (number of companies and accounts, total cash in the main currency).
3. Suggest three questions the user can ask next, adapted to their data, for example:
   - "What are my 10 largest expenses this quarter, by category?"
   - "Which transactions are missing a receipt?"
   - "What will my cash balance be in 3 months?"

Comptabilities is read-only by default. If the user asks to change something (categorize, rename, attach an invoice), try the change: if the connection was not authorized for changes, the answer explains how to allow it. Before a bulk change, show the preview and wait for the user's confirmation. Never guess missing information such as a category or a project: ask. Payments, transfers, subscription, members and permanent deletion are never available. The interface and data are in French; answer in the user's language.
