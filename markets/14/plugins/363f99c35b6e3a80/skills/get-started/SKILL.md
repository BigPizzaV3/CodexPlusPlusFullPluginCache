---
name: get-started
description: Use when setting up the ProWebLook plugin, connecting an account, or checking which ProWebLook workflow fits a request.
---

Connect through the plugin's OAuth sign-in flow to the user's own ProWebLook account. Never ask for an API key, password or token in chat. Use `get_account` for connection status and authoritative balances; explain authentication errors and let the user reconnect through the host.

For contact or reputation lists, use the bundled [verify-lists workflow](../verify-lists/SKILL.md). For single lookups, web research, public social content, search or AI audits, use [research-and-lookup](../research-and-lookup/SKILL.md). Discover the connected tools and follow their actual schemas.

List jobs support one of WhatsApp, email, phone, caller ID, IP geolocation or blacklist per job. Pasted text, CSV and XLSX are supported up to 10,000 input rows, 100 columns, 10 MiB uploaded and 50 MiB expanded. Preview, select the file mapping, show the estimate and wait for explicit confirmation before starting. Existing account credits apply. Inputs and results expire after seven days.

The optional widget can preview, confirm and browse a job. Every workflow also works through text tools. Do not promise a future notification when the user leaves the conversation; retain the job ID so they can request status later.

Use [support](https://proweblook.com/contact) for account assistance and [privacy](https://proweblook.com/privacy-policy) for the published policy. Purchases, checkout and upgrades are outside this plugin.
