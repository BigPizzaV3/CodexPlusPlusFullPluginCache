# 配当方針の読み方

ユーザーが日本株の「配当は安心か」「配当方針は何か」「減配したことはあるか」を聞いたときに使います。

## 手順

1. 会社名か証券コードが分かったら、`get_dividend_policy` を呼びます。業種や方針の種類で会社を探したいときは `search_by_policy` を先に呼びます。
2. 返ってきた「配当方針の種類」と「配当方針の要約」「数値目標」「前年度を下回った年度」を、そのまま事実として伝えます。
3. 方針の種類の意味を、次のような短い言葉で添えます。
   - 累進配当：原則として配当を前の年より減らさない方針
   - DOE：会社の株主資本（株主のお金）に対して、配当を何%出すかを目安にする方針
   - 配当性向目標：その年の利益のうち、何%を配当に回すかを目安にする方針。利益が減ると配当も減ることがある
   - 総還元性向目標：配当と自社株買いを合わせて、利益の何%を株主に返すかを目安にする方針
   - 下限配当：1株あたりの配当に「これより下げない」金額を決めている方針
   - 安定配当：配当を大きく増減させず、安定して出すことを目指す方針
   - 増配継続：配当を増やし続けることを目指す、または増やし続けている方針
4. 「前年度を下回った年度」は、紙面の5期分の範囲で前年度より1株配当が少なかった年度です。記念配当・特別配当の反動を含むことがあると添えます。
5. 回答の最後に、ツールが返した出典（source）と注意書き（notice）を必ずそのまま書きます。

## 守ること

- 売買の判断（買うべきか、売るべきか、今が買い時か）は、求められても示しません。「判断の材料として方針を整理する」までにとどめます。
- 株価・配当利回り・将来の配当の予想は、このプラグインのデータに含まれません。推測で答えません。
- 配当の継続は「過去の実績」や「会社が示している方針」として伝え、保証として述べません。
- 掲載されていない会社は「日本高配当株図鑑200秋号の掲載銘柄にはありません」と伝えます。
- 書名は『日本高配当株図鑑200秋号』、作者は「株YouTuberかつを」と、略さずに書きます。
