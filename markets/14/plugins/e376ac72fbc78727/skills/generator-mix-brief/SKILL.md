---
name: generator-mix-brief
description: Prepare a dated EIA generator-capacity inventory brief for a state or balancing-authority code, preserving capacity measures, generator counts, storage units, source codes and missingness without implying generation or spare capacity.
---

Use this workflow for questions about a state or balancing authority's reported generator inventory or capacity mix. This independent service reads held public EIA datasets; it does not query a live grid or a real-time generator status service. Start with `describe_energy_layers` when the source period, available measures or coverage is not already in the conversation. The held preliminary monthly generator snapshot is August 2026; it is not the latest available month. Other held map layers have separate vintages. Quote the response's actual source metadata if a later authorized snapshot replaces it.

Use `summarize_generating_capacity` with the requested state, balancing-authority code, or both. A state may be a two-letter abbreviation or a supported two-digit FIPS code. Only apply a balancing-authority code if the person supplies or chooses a code present in the source; do not infer a territory from a location or invent a balancing-authority full name. If scope is missing, ask for a state or source balancing-authority code rather than a home address or precise personal location. Use the tool's real schema; do not invent date, generator-status or live-generation parameters.

Report what the summary actually measures. Nameplate capacity and net summer capacity are distinct MW measures; never silently substitute one for the other. Storage energy in MWh is a separate reported quantity, not power capacity and not generation. Do not calculate storage duration or annual generation from these inventories. Keep source energy-source, technology, prime-mover and balancing-authority labels/codes as supplied; an unavailable description stays unavailable. Do not treat a name, code or catalog status as evidence of current operation, ownership changes or environmental compliance.

Separate generator records, unique plants and entities. Use the returned whole-scope group totals, denominators and unknown-field counts; a list of examples is not the entire inventory. State the capacity measure and its coverage before comparing groups. Zero is a reported value; null or missing is unknown. Do not turn a group with missing capacity into a zero-capacity group. If a sum includes only known values, describe it as partial with its known/missing denominator. Do not derive new percentages unless requested and justified by a consistent complete denominator; if computed, label the arithmetic and scope explicitly. Avoid double-counting storage or overlapping technology/energy-source groups. Plant counts overlap across source groups and must not be added. The held operable inventory includes operating, standby and out-of-service statuses; preserve returned status codes/descriptions rather than calling every generator currently operating. `value`, `unit`, `known_count`, `missing_count` and `is_partial` describe each numerical subtotal; use those denominators for the measure itself. Storage denominators refer to the eligible storage rows, not all generators.

A useful brief leads with the selected state and dated capacity mix, then a compact table of returned measures and record counts, followed by missingness and source limits. Cite the EIA source URL, held data period, original source download date and held-read time separately. A new held-read time does not make the dataset current. Include Operating and separately supplied Operating_PR sheet scope only as actually relevant to the returned state. A missing state or no-match result is not proof of no physical infrastructure.

Refuse claims about actual generation in MWh, emissions, dispatch, available/spare/interconnection capacity, project feasibility or investment suitability when these are not supplied by the source. Explain that generator-capacity inventories cannot certify a connection or investment. No personal address lookup, property/safety/engineering/insurance certification or financial recommendation. A source/schema/asset failure means unavailable evidence, not an empty inventory. Offer a narrower supported historical inventory question rather than fabricated results.
