# GovBot Energy Infrastructure for OpenAI

The independent, read-only research service is live at https://energy-api.govbot.ai/mcp without an account or API key. The portable plugin is prepared for owner review after private ChatGPT testing; public directory availability, approval, publication and final submission are not claimed. Canonical product-page address: https://govbot.ai/plugins/energy-infrastructure.html.

Three skills prepare generator-capacity mix, nearby energy-record and generalized pipeline/transmission briefs. Six operations are find_power_plants_near_point, summarize_generating_capacity, find_fuel_facilities_near_point, find_pipelines_in_area, find_transmission_lines_in_area and describe_energy_layers. The independent runtime reads held public EIA and DOE NETL/HIFLD assets, with no user key, runtime agency fetch or GovBot upstream dependency. The preliminary generator snapshot is August 2026, not the latest available month; Operating and separate Operating_PR coverage and each map-layer vintage remain explicit.

Nameplate MW, net summer MW and storage energy MWh are different measures. Capacity is not generation, dispatch or spare/interconnection capacity. Mapped facilities and generalized pipeline records are not surveys or proof of current operation, exact field route, excavation safety, connection feasibility or investment suitability. Missing data is unknown and query failure is not zero infrastructure. Public research points, states or source balancing-authority codes only; no address/device location workflow.

Sources: EIA monthly generator inventory https://www.eia.gov/electricity/data/eia860m/ and EIA mapping https://www.eia.gov/maps/. Runtime source catalog supplies individual asset source URLs, periods, download/read dates and scope. MIT applies to this package's own software/skills; agency and constituent source attribution/terms remain separate. No blanket third-party rights attestation.

Reviewer walkthrough: https://govbot.ai/plugins/energy-infrastructure-demo.mp4. The silent video uses actual private ChatGPT screenshots with reading holds and hard cuts; it is not a continuous real-time recording. The plugin has not been publicly submitted or published.

The portable ZIP contains the manifest, MCP connection, README, LICENSE, logo and three skills. Runtime code, data assets, credentials and local evidence are not included. Package validation alone does not establish hosted, actual-client, video, publication or submission acceptance.
