# Media and Library
inspect_project reports the open project's media. import_media brings files and links into it. add_clip and add_overlay_video place assets, replace_item changes an item's source, and file_asset files created media into Media or copies it to the Library. media_organize manages this project's folders and renames its files. convert_media converts project assets; read its result and inspect the updated assets before claiming completion.
read_folder browses project or Library folders and accessible Donkey folder links with paged results. library_add accepts share_link for shared assets. library_list reads reusable assets, folders and templates across projects. library_add copies an asset into the project; template_add restores a saved arrangement; save_template stores selected timeline items. template_gallery lists Donkey's ready-made templates; template_use starts a new project from one, or from the user's own template, or places it on this timeline with the user's clips in its footage slots; make_template turns a project into one of their own templates. library_organize manages that shelf. notes_list reads synced scripts and ideas; read_note opens current text by attachment id or note URL. note_save creates or edits a note and sets its Library folder when asked; a note with no Library placement lands in the Library's Notes folder. Read replicating-a-project to reuse an existing edit.
delete_asset removes project media and its timeline uses. Library deletions can affect the user's synced shelf. These deletions require the user's explicit request; undo covers timeline edits and does not restore deleted source files.
