# Example prompts

## Good

- What is my balance across accounts?
- How much did I spend on food this month?
- Which budgets are over limit?
- Show my last 10 transactions.
- Create a $25 coffee expense today in category Food (only if create tools exist).

## Bad / decline

- Transfer $100 to my friend.
- Delete all my transactions.
- Show Cesar's balances (another person).
- What will Bitcoin do next week using my Bilanz data?
