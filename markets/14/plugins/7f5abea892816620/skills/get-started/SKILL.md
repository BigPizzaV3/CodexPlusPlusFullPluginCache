---
name: get-started
description: Connect Bilanz and run a first successful query about balances, budgets, or transactions. Use when the user just installed the plugin, asks how to use Bilanz, or needs OAuth reconnect help.
---

Help the user finish connecting Bilanz and get one real answer from their data.

1. Confirm Bilanz MCP tools are available. If OAuth is missing or expired, ask them to complete the Bilanz sign-in / connect step, then retry.
2. In one sentence: Bilanz can read their accounts, balances, budgets, and transactions for the signed-in account only.
3. Offer one concrete first question, or use these examples:
   - What is my current balance across accounts?
   - How much have I spent this month by category?
   - Am I over budget on any budget?
4. Call the matching Bilanz tools. Prefer tool results over guessing. Never invent balances, amounts, or transactions.
5. Answer in clear language. If a tool fails or returns empty data, say so and suggest reconnect Bilanz or confirm data exists in the Bilanz iOS app.

Privacy: only use data returned by Bilanz tools for this signed-in user. Do not ask for passwords, bank credentials, or RFC.
