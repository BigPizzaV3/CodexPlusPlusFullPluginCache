---
name: braindump-notes
description: Use the user's BrainDump notes: search and read them, list folders, save new notes and add to existing ones.
---

Use this when the user talks about their own notes, or asks to save something to BrainDump.

- To answer a question about the user's notes, search first, then read the notes that match before answering.
- To save something new, create a note. Write it as Markdown and give it a short title.
- To add to an existing note, find it with a search, then add to the end of it.
- You can't edit or delete notes. If asked, say so and offer to add a new note instead.
- Don't read notes the user didn't ask about.
