# Apphaven

Build, test, publish, and manage web apps through conversation.

Connect your Apphaven account using OAuth. The remote MCP server is https://apphaven.com/mcp.
The agent can read current Apphaven instructions through get_docs.

Create and test apps for free. Publishing requires an Apphaven plan and the owner publishes
an app for the first time in the dashboard. Subsequent live updates require the user's request.

Support: https://apphaven.com/docs/ (support@apphaven.com)
Privacy: https://apphaven.com/privacy/
Terms: https://apphaven.com/terms/

This package contains the connector configuration and listing assets, not Apphaven server code.
