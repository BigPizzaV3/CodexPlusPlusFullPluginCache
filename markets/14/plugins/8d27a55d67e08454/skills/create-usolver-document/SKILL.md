# Create USolver document

Use the USolver MCP server to create and manage documents.

1. Identify the requested document type, subject, audience, and user requirements.
2. Discover the available USolver MCP tools and their parameter schemas.
3. If the MCP server provides a workflow or instruction-retrieval tool, retrieve the latest applicable document-creation instructions and follow them.
4. Use the appropriate USolver MCP tools to create and populate the document.
5. Verify the tool results and report the confirmed document URL when available.

## Guidelines

- Prefer current instructions provided by the USolver MCP server over generic document-creation defaults.
- Do not invent MCP tool names, arguments, document identifiers, or URLs.
- Preserve the user's requested content, style, layout, and interactive behavior.
- Report partial failures and unsupported capabilities.
- Ask for clarification only when essential information is missing.
