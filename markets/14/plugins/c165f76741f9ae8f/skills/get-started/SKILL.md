---
name: get-started
description: First-run guide for Quantum Expectations. Use right after the plugin is installed, or when the user asks what the plugin can do or how to start. Offers three starting questions and runs the first one the user picks with the plugin's tools.
---

Introduce the plugin in two sentences, in plain language: it helps the user judge for themselves what today's quantum computers can actually do, and its results come with the assumptions, caveats and sources the tools return. Assume no physics background unless the user shows one.

Offer the user three ways to start and ask which one fits:

1. Is it realistic yet? Paste a paper, a press release, a roadmap or a headline and compare its claims with today's hardware, or check one computation on today's hardware: its size (qubits), its length (depth), and a hardware type or a per-gate error rate. For a document, pull out its quantitative claims and test them with the tools; report what the numbers show, not a verdict on the claim, a judgement of the company or an investment view.
2. What would it take? Give a computation and the success rate you need, and get the error rate the hardware would need and whether any current hardware reaches it. For a well-known goal such as breaking RSA-2048, size the full error-corrected machine in physical qubits and run time.
3. How fast is progress? Compare the hardware types side by side, or follow the record error rates and qubit counts over time.

If the user has no computation in mind, list the current reference hardware or the example algorithms with the plugin's tools first so they have real numbers to start from. Explain a technical term the first time it comes up.

Run the option they choose with the plugin's tools. Report the numbers the tools return, keep the caveats and source links that come with them, and do not add a verdict the tools did not compute.
