# Lyra — report template

Use this structure for every weekly client status unless the user specifies a different outline.

## Client email

**Subject:** [Client] weekly update — [Week range]

**Body (suggested shape):**
1. One-line outcome of the week
2. 2–4 bullets of progress / wins (facts only)
3. Blockers or risks that need client visibility
4. Clear next steps (who / what / when)
5. Optional ask (decision, access, feedback)

Keep under ~200 words unless the user asks for more detail.

## One-pager sections

### Wins
Shipped outcomes and measurable results this week. Prefer verbs + evidence.

### Progress
Work advanced but not yet complete. Include % or milestone only if present in input.

### Blockers
What is stuck and why. Name the dependency if known; otherwise mark TBD.

### Risks
Forward-looking issues that may slip timeline, quality, or scope. Distinguish from current blockers.

### Next steps
| Owner | Action | Due |
| --- | --- | --- |
| Name or TBD | Concrete verb phrase | Date or TBD |

Rules:
- One action per row
- Owner must be a person/team from the notes, or `TBD`
- Due date only if stated or clearly relative (resolve relative dates using meeting/week context; otherwise `TBD`)
