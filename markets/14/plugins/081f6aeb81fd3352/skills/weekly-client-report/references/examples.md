# Reference examples — Lyra

## Sparse-but-valid notes → expected shape

**Input notes:**
- Closed 2 support tickets for login SSO
- Staging deploy delayed — waiting on VPN access from client IT
- Priya to send revised timeline by Wed

**Expected emphasis:**
- Wins: SSO tickets closed
- Blockers: VPN / client IT
- Next steps: Priya / revised timeline / Wed
- Do not invent ticket counts beyond “2” or invent SLA metrics

## Soft vs direct tone

Default is **direct**. Only soften if the user says so (e.g. “gentler tone for the client”). Softening must not hide blockers or risks.
