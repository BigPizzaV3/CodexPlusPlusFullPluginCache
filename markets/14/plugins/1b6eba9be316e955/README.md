# Peerbound for ChatGPT and Codex

Search your company's customer proof library for quotes, stories, G2 reviews,
account details, and lookalike customers, with source attribution.

## Requirements and Setup

Your company must have a Peerbound subscription and MCP access enabled.
Contact your Peerbound CSM if access has not been enabled.

Install the Peerbound plugin in ChatGPT or Codex and authenticate with
your own Peerbound account when prompted. Access follows Peerbound permissions.
The plugin connects to `https://mcp.peerbound.com/api/mcp` over HTTP.
No credentials are stored in this package. Tools are supplied by the server.

## Example Requests

- Find customer proof for a financial services prospect concerned about
  implementation time. Include sources.
- Look up an account by name or domain and find its stories and reviews.
- Find customers similar to my target by industry, size, and region.
- Draft a follow-up using approved quotes and link to the originals.

Check approval status before using evidence externally, and preserve anonymity
and attribution returned by Peerbound. Do not infer anonymous source identities.
