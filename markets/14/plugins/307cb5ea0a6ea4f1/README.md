# Lukka Reference Data MCP

OpenAI display name: Lukka Reference Data

Research digital asset identities, classifications, asset and market scores, entities, VASPs, exchange mappings, derivative reference data and crypto actions using Lukka Reference Data. Resolve exchange-facing ticker symbols to canonical Lukka identifiers using returned mappings. Requires a connected Lukka account with Reference Data entitlement; availability varies by dataset. Provides reference observations and does not edit asset records, identify private wallet owners or supply live trading prices.
