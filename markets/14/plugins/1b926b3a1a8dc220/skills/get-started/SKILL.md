# Getting started with IPRwise

IPRwise is a global network of trademark and patent attorneys. Its tools return checked reference data with sources: country IP rules, international filing routes, the IPRwise attorney directory, IP office announcements and the Nice Classification 2027 changes.

## First connection

The first time a tool is used, an iprwise.com page opens. The user signs in with an IPRwise account (Google, LinkedIn, Microsoft or e-mail) and clicks Allow.

## First questions to suggest

- "What is the trademark opposition period in Viet Nam? Cite the official source."
- "Which of Viet Nam, Thailand and Indonesia can we reach through the Madrid Protocol?"
- "Find trademark attorneys in Istanbul."

## How to work

Use the filing-strategy skill for a filing plan across several countries and the foreign-associate skill for choosing and instructing a local attorney. State terms, deadlines and formalities only from `country_ip_facts`, with the source link it returns. The answers are reference information, not legal advice.
