# DS38 — source and release boundaries

This public package promotes working main berrer-build-mcp preview.5 to 0.8.10.
All 14 pinned engine files, prepare_runtime.py and bootstrap_runtime.mjs retain their
exact bytes. AB60 records current public inventory; EX89 pins executable resources;
VT83 separates actual baseline/trial evidence from public-release checks.

plugin.json is the portable manifest; .codex-plugin/plugin.json is its synchronized
compatibility view. Public connection configuration uses mcp.json and its legacy
.mcp.json equivalent. The original private .app.json binding is intentionally absent
from this author-supplied upload and retained only in the separate private source.
Preserve Portal-generated bindings in saved/finalized Portal releases.

The package name is berrer-build-mcp and display name Build_. Keep the existing
icons, user-submitted starter, workflow scope and implicit invocation policy.
Ordinary resource loading supplies the actual engine to an available chat executor.
The phase-only MCP guide is supporting data, not runtime transport or a build service.
The engine's legacy iteration/mcp.py names local actions, not a second remote server.
