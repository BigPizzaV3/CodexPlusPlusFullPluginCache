**Using Build_**

**Make something:** describe the Windows app you want and anything that must stay
unchanged. If you want to agree on a prototype first, say so. When you ask to build
it, Build_ creates the next complete ZIP.

**Run and test:** extract the ZIP and double-click **run.bat**. Follow the Python or
dependency requirements stated with that build. The reply explains which checks ran
and which still need your Windows test.

**Improve it:** attach **LogReport.zip** from beside run.bat and describe what worked,
what failed or what should change. Ask for a review when you only want the report
explained. Nothing uploads automatically.

**Continue in a new chat:** select this same Build_ plugin and attach the latest
program ZIP so its source and project context can be recovered. Logs do not replace
that ZIP or your data backup.

A help request does not start a build. Describe your idea whenever you are ready.
