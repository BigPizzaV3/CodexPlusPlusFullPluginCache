# RA89 — Establish the executable runtime with a bounded resource bridge

Package: `berrer-build-mcp`, release `0.8.10`. Use the resources returned
for this selected plugin throughout runtime preparation.

## Boundary

A skill:// URI is a resource address, not an operating-system path. Reading source,
transferring its exact bytes and executing Python are separate host capabilities.
A missing mount alone does not establish that the engine is unavailable.

Customer builds must not require Plugin Creator, owner/editor permissions, release-
archive downloads, public plugin IDs, Cloudflare credentials or an MCP build service.
Do not search conversation files or Library for installed skill scripts. Do not ask
the customer to download, upload, copy or assemble the engine.

Use installed resources and the tools already available in this chat. The optional
installed-bundle download transfers only published skill code; the direct-reader
bridge needs no executor network access. Neither route adds a service, external AI
call or customer-PC process. Run it only for an
authorized build/repair or an authorized artifact review that needs the engine parser.
Welcome, exploration and help do not need executable setup.

## Choose the actual host capability once

1. Check the resource reader, execution tool and writable sandbox advertised in this
   host. Use their real schemas; do not infer a mount from a URI or display title.
2. If an actual skill_root or another explicit authorized directory is supplied,
   verify it and use the mounted-source procedure below.
3. Otherwise request the ordinary installed cloud-skill bundle, when advertised, and
   use the bounded Python adapter below if the executor permits that download.
   This transfers the installed package without owner permissions or model retyping.
4. If bundle retrieval/download is unavailable but the host can pass reader results
   programmatically to Python, use scripts/bootstrap_runtime.mjs with the documented
   adapters. Its execution/write check precedes the complete engine inventory reads.
5. If none of these routes is available, name the specific missing capability once.
   Do not keep probing guessed paths, unrelated Files APIs or owner-only services.

The installed bundle and direct bridge are alternative transports for the same pinned
engine. A separate Python tool can use a fresh bundle URL when downloads are permitted;
it cannot automatically inspect another tool's internal variables. The functions.exec
fallback is supported only in hosts exposing its actual orchestration tools.

## Mounted source

Resolve the real scripts directory from the host-supplied directory. Read EX89.json
and verify the materializer's bytes before running it. Create a session-owned scratch
parent, then run the unchanged helper with the current Python executable:

    python /actual/scripts/prepare_runtime.py --copy-from /actual/scripts --destination /actual/session/runtime --probe

The destination must not exist. Use an argument list when invoking this command from
Python. SOURCE is the directory containing iteration_cli.py, deliver.py, release_check.py
and iteration/. The helper copies only the 14 pinned engine files.

## Installed cloud-skill bundle: preferred text-only route

The ordinary installed-skill reader supports a bundle resource. It is distinct from
Plugin Creator's owner-only release archive. Use the SAME selected cloud skill package
and replace the final /SKILL.md in its actual returned resource URI with /bundle.
Do not construct a download URL or use a public plugin ID as a substitute.

For example, in an advertised functions.exec host, retain buildPackage and mainRead
from the selected main-skill read:

~~~javascript
const bundleRead = await tools.skills__read({
  package: buildPackage,
  resource: mainRead.resource.replace(/\/SKILL\.md$/, "/bundle")
});
const bundleUrl = bundleRead.contents.trim(); // Private data; do not print it.
~~~

The reader returns a short-lived download URL, which may already be expired if the
host cached it. Consume it immediately; an ordinary repeat read does not guarantee a
fresh URL. Pass the actual returned URL as the bundle_url data variable to the Python
adapter below. This also works with a Python-only execution
tool when that tool permits the download; it does not require code-mode callbacks or
a shell. Respect the host's network permissions. If the download is unavailable, use
the direct-reader bridge below when that capability exists. Do not infer that every
Python environment has network access, and do not send customer content anywhere.

The adapter accepts only the currently advertised OpenAI content-host destination,
bounds compressed and expanded data to 20 MiB, rejects unsafe paths, duplicates, links,
special entries and excessive members, and copies ONLY the verified materializer and
14 EX89 runtime files. It never uses tar.extractall. The URL stays in memory and is
excluded from results and saved files. The materializer is outside the final runtime.

~~~python
import gzip, hashlib, io, json, pathlib, re, shutil, subprocess
import sys, tarfile, tempfile, time, urllib.error, urllib.parse, urllib.request

LIMIT = 20 * 1024 * 1024
HELPER_SHA = "40294949b00b3328fbb692ec844e83921c891986bdd378a230c5d4e52b36f199"
NAMES = {
    "deliver.py", "iteration_cli.py", "release_check.py",
    "iteration/__init__.py", "iteration/engine.py", "iteration/layout.py",
    "iteration/lifecycle_template.py", "iteration/logs.py", "iteration/mcp.py",
    "iteration/records.py", "iteration/release_contract.py",
    "iteration/runner_template.py", "iteration/safety.py", "iteration/store.py",
}

class BundleBlocked(Exception):
    def __init__(self, code, **details):
        self.code, self.details = code, details

def require(ok, code, **details):
    if not ok:
        raise BundleBlocked(code, **details)

def check_url(value):
    require(isinstance(value, str) and len(value) <= 8192
            and not any(ord(c) < 32 or ord(c) == 127 for c in value),
            "invalid_bundle_url")
    parsed = urllib.parse.urlsplit(value)
    host = (parsed.hostname or "").lower()
    require(parsed.scheme == "https" and not parsed.username and not parsed.password
            and parsed.port in (None, 443) and not parsed.fragment
            and (host == "oaiusercontent.com" or host.endswith(".oaiusercontent.com")),
            "untrusted_bundle_destination")

class BundleRedirects(urllib.request.HTTPRedirectHandler):
    count = 0
    def redirect_request(self, req, fp, code, msg, headers, newurl):
        self.count += 1
        require(self.count <= 3, "bundle_redirect_limit")
        check_url(newurl)
        return super().redirect_request(req, fp, code, msg, headers, newurl)

def bootstrap_bundle(bundle_url):
    root = None
    stage = "capability"
    base = {"schema": "build.runtime-bundle/1", "route": "installed_skill_bundle",
            "owner_api_used": False, "download_url_saved": False,
            "customer_code_executed": False, "application_qualified": False}
    try:
        require(sys.version_info >= (3, 10), "python_version_unsupported")
        stage = "download"
        check_url(bundle_url)
        opener = urllib.request.build_opener(BundleRedirects())
        deadline = time.monotonic() + 60
        data = bytearray()
        with opener.open(bundle_url, timeout=20) as response:
            require(response.status == 200, "bundle_http_status")
            while True:
                require(time.monotonic() <= deadline, "bundle_download_timeout")
                chunk = response.read(min(65536, LIMIT + 1 - len(data)))
                if not chunk:
                    break
                data.extend(chunk)
                require(len(data) <= LIMIT, "bundle_download_too_large")
        stage = "archive"
        with gzip.GzipFile(fileobj=io.BytesIO(data)) as packed:
            expanded = packed.read(LIMIT + 1)
        require(len(expanded) <= LIMIT, "bundle_expansion_too_large")
        with tarfile.open(fileobj=io.BytesIO(expanded), mode="r:") as archive:
            members = {}
            seen = set()
            for number, member in enumerate(archive, 1):
                require(number <= 256, "bundle_member_limit")
                name = member.name
                while name.startswith("./"):
                    name = name[2:]
                if name in ("", ".") and member.isdir():
                    continue
                path = pathlib.PurePosixPath(name)
                require(name and not path.is_absolute() and ".." not in path.parts
                        and "\\" not in name and ":" not in name
                        and not any(ord(c) < 32 or ord(c) == 127 for c in name)
                        and path.as_posix() == name.rstrip("/"),
                        "unsafe_bundle_member")
                name = path.as_posix()
                require(member.isdir() or member.isfile(), "linked_or_special_bundle_member")
                require(0 <= member.size <= 2 * 1024 * 1024, "bundle_member_too_large")
                require(name.casefold() not in seen, "duplicate_bundle_member")
                seen.add(name.casefold())
                if member.isfile():
                    members[name] = member

            def read_member(name):
                require(name in members, "missing_bundle_resource", resource=name)
                stream = archive.extractfile(members[name])
                require(stream is not None, "unreadable_bundle_resource", resource=name)
                with stream:
                    return stream.read(members[name].size + 1)

            stage = "verify"
            manifest_raw = read_member("Automation/EX89.json")
            require(len(manifest_raw) <= 65536, "inventory_too_large")
            manifest = json.loads(manifest_raw)
            records = manifest.get("runtime_files")
            helper = manifest.get("materializer", {})
            require(manifest.get("schema") == "build.runtime-resources/1"
                    and helper.get("skill_path") == "scripts/prepare_runtime.py"
                    and helper.get("sha256") == HELPER_SHA and helper.get("bytes") == 11458
                    and isinstance(records, list) and len(records) == 14
                    and {item.get("path") for item in records} == NAMES, "inventory_invalid")
            verified = {}
            for record in [helper] + records:
                name = record["skill_path"]
                if record is not helper:
                    require(name == "scripts/" + record["path"], "inventory_invalid")
                expected_bytes, expected_hash = record["bytes"], record["sha256"]
                require(type(expected_bytes) is int and 0 < expected_bytes <= 262144
                        and isinstance(expected_hash, str)
                        and re.fullmatch("[0-9a-f]{64}", expected_hash), "inventory_invalid")
                raw = read_member(name)
                digest = hashlib.sha256(raw).hexdigest()
                require(len(raw) == expected_bytes and digest == expected_hash,
                        "resource_hash_mismatch", resource=name,
                        expected_bytes=expected_bytes, actual_bytes=len(raw),
                        expected_sha256=expected_hash, actual_sha256=digest)
                verified[name] = raw

        stage = "write"
        root = pathlib.Path(tempfile.mkdtemp(prefix="build-runtime-bundle-"))
        source = root / "source"
        source.mkdir()
        helper_path = root / "prepare_runtime.py"
        helper_path.write_bytes(verified["scripts/prepare_runtime.py"])
        for record in records:
            target = source / record["path"]
            target.parent.mkdir(parents=True, exist_ok=True)
            target.write_bytes(verified[record["skill_path"]])
        stage = "runtime_probe"
        process = subprocess.run(
            [sys.executable, "-B", "-E", "-s", str(helper_path), "--copy-from", str(source),
             "--destination", str(root / "runtime"), "--probe"],
            cwd=root, capture_output=True, timeout=55, check=False)
        require(len(process.stdout) <= 65536, "runtime_probe_output_too_large")
        result = json.loads(process.stdout)
        require(process.returncode == 0 and result.get("status") == "passed"
                and result.get("runtime_executable") is True and result.get("files_verified") == 14,
                "runtime_probe_failed", exit_code=process.returncode)
        return {**base, "status": "passed", "error_code": None,
                "workspace_root": str(root), "source_root": str(source),
                "helper_path": str(helper_path), "runtime_root": result["runtime_root"],
                "entrypoints": result["entrypoints"], "files_verified": 14,
                "command_probes": [{k: item.get(k) for k in ("entrypoint", "status", "exit_code")}
                                   for item in result["command_probes"]]}
    except Exception as error:
        cleanup = "not_needed"
        if root is not None:
            try:
                shutil.rmtree(root)
                cleanup = "completed"
            except OSError:
                cleanup = "unconfirmed"
        code, details = stage + "_failed", {}
        if isinstance(error, BundleBlocked):
            code, details = error.code, error.details
        elif isinstance(error, urllib.error.HTTPError):
            code, details = "bundle_http_error", {"http_status": error.code}
        elif isinstance(error, urllib.error.URLError):
            code, details = "bundle_download_unavailable", {"reason_type": type(error.reason).__name__}
        elif isinstance(error, subprocess.TimeoutExpired):
            code = "runtime_probe_timeout"
        elif isinstance(error, TimeoutError):
            code = stage + "_timeout"
        return {**base, "status": "blocked", "error_code": code, "stage": stage,
                "cleanup": cleanup, **details}

# Set bundle_url from the actual fresh /bundle reader result; never print that URL.
print(json.dumps(bootstrap_bundle(bundle_url)))
~~~

A blocked download may reflect permissions, expiry or network availability; it does not
prove the engine is absent. After HTTP 403 or an observed expired validity period, make
at most one ordinary /bundle read from the same selected package. Retry downloading
only if that read returns a different URL that is not already known to be expired.
An identical or still-expired result goes directly to the supported reader bridge;
do not loop or claim the repeat read refreshed it. Never invent a cache-busting URL,
query parameter or resource URI, alter a signed URL, or switch to owner-only APIs.
Do not log or publish download URLs. A blocked route is not permission to bypass access
controls. If the direct bridge is unavailable too, report that precise capability limit.

## Direct-reader fallback: deterministic bootstrap

Read the installed scripts/bootstrap_runtime.mjs as code, preserving complete pages.
It exports:

    bootstrapRuntime({readResource, runPython, notify?})

The host adapters have this contract:

- readResource(relativePath, cursor) returns the reader's exact contents string and
  next_cursor when another page exists. Paths are relative to this selected build
  skill, for example Automation/EX89.json and scripts/iteration/engine.py.
- runPython(code, inputObject) executes that Python code in the chat sandbox, sends
  JSON input on stdin, and returns its parsed JSON stdout. Nonzero execution or
  malformed output is an error, never an inferred success.
- notify is optional and receives bounded progress; do not dump source text.

The bridge transfers the materializer and all 14 pinned resources directly from
returned strings. It does not ask the model to rewrite or reproduce them. Pagination,
UTF-8 encoding, byte lengths and SHA-256 checks are part of the transfer. Data is sent
in bounded chunks; do not combine the entire engine into one large shell argument.

The materializer remains at SESSION/prepare_runtime.py; source files are staged under
SESSION/source; the final directory is SESSION/runtime. The helper always uses
--copy-from SESSION/source --destination SESSION/runtime --probe. Do not place the
helper inside the final runtime or use an initial direct --check on a mixed folder:
the final inventory must contain exactly the 14 engine files.

### functions.exec adapter example

Before running this example, bind buildPackage to the exact package value for the
selected main Build_ skill from this turn's catalog. This is a host-provided value,
not a plugin display name or a guessed URI. The code derives the resource prefix from
the actual main-skill read. It uses only the advertised skills__read, exec_command
and write_stdin tools and a POSIX shell. Adapt it only when another host documents
equivalent capabilities; never invent these APIs on a Python-only host.

~~~javascript
// buildPackage is the exact selected skill package from the current catalog.
const mainRead = await tools.skills__read({package: buildPackage});
if (!mainRead.resource.endsWith("/SKILL.md")) {
  throw new Error("unexpected_main_skill_resource");
}
const resourceBase = mainRead.resource.slice(0, -"SKILL.md".length);

const discovery = await tools.exec_command({
  cmd: "python3 -c 'import sys; print(sys.executable)'",
  yield_time_ms: 1000,
  max_output_tokens: 1000
});
if (discovery.session_id || discovery.exit_code !== 0) {
  throw new Error("python_executor_not_confirmed");
}
const pythonExecutable = discovery.output.trim();
if (!pythonExecutable.startsWith("/")) {
  throw new Error("python_executable_not_confirmed");
}
const shellQuote = value => "'" + String(value).replace(/'/g, "'\\''") + "'";

const readResource = async (relativePath, cursor) =>
  await tools.skills__read({
    package: buildPackage,
    resource: resourceBase + relativePath,
    ...(cursor == null ? {} : {cursor})
  });

const runPython = async (code, inputObject) => {
  const input = JSON.stringify(inputObject);
  // JSON is stdin data. The quoted heredoc prevents shell expansion.
  // The bridge bounds each chunk; JSON.stringify is not shell escaping.
  const cmd = shellQuote(pythonExecutable) + " -c " + shellQuote(code) +
    " <<'BUILD_RUNTIME_INPUT_JSON'\n" + input + "\nBUILD_RUNTIME_INPUT_JSON";
  if (cmd.length > 60000) throw new Error("python_transfer_command_too_large");
  let result = await tools.exec_command({
    cmd, yield_time_ms: 1000, max_output_tokens: 6000
  });
  let output = result.output;
  const deadline = Date.now() + 90000;
  while (result.session_id) {
    if (Date.now() >= deadline) throw new Error("python_executor_wait_timeout");
    result = await tools.write_stdin({
      session_id: result.session_id,
      chars: "",
      yield_time_ms: 1000,
      max_output_tokens: 6000
    });
    output += result.output;
  }
  if (result.exit_code !== 0) {
    throw new Error("python_executor_failed: " + output.slice(-1500));
  }
  return JSON.parse(output);
};

let moduleSource = "";
let cursor;
for (let pageNumber = 0; ; pageNumber++) {
  if (pageNumber >= 32) throw new Error("bootstrap_resource_page_limit");
  const page = await readResource("scripts/bootstrap_runtime.mjs", cursor);
  if (typeof page.contents !== "string") {
    throw new Error("bootstrap_resource_missing_contents");
  }
  moduleSource += page.contents;
  if (moduleSource.length > 131072) throw new Error("bootstrap_resource_too_large");
  cursor = page.next_cursor;
  if (cursor == null) break;
}
const moduleText = moduleSource.trimEnd();
const footer = "export { bootstrapRuntime };";
if (!moduleText.endsWith(footer)) throw new Error("unexpected_bootstrap_module");
const moduleBody = moduleText.slice(0, -footer.length);
const bootstrapRuntime = Function(moduleBody + "\nreturn bootstrapRuntime;")();
const result = await bootstrapRuntime({
  readResource,
  runPython,
  notify: progress => notify(progress)
});
text(result); // Compact status and actual runtime paths; never source strings.
~~~

This wrapper evaluates the installed bootstrap module in the orchestration runtime,
where it can call the supplied adapters. It does not execute the module in Python or
assume Node.js imports are available in functions.exec. Its Python actions are bounded
setup/verification operations, not customer application execution.

Do not feed rendered tool text, citation wrappers, line numbers, Markdown fences,
summaries or ellipses into the bridge. Use the actual structured contents field.
Do not print complete engine resources into model context and then regenerate them.
Verbatim tool-result transport is authorized copying of existing code; it does not
permit replacement engine logic or changed expected hashes.

## Bounded failures

- Resource missing/unreadable: retain the exact relative path and reader error.
- Truncated content or hash mismatch: retain expected/observed byte count and hash;
  at most one complete re-read of that affected resource is allowed.
- No reader-to-executor bridge: report that transfer capability, not a missing engine.
- No Python execution/writable sandbox: report that specific host capability.
- Helper/probe failure: retain the bounded actual exit/timeout diagnostic and stop
  before application production.
- Missing GUI display: record the actual unavailable host check and continue to
  Windows-testable delivery; do not install/retry a graphics stack in a loop.
- Missing a target application dependency: include the real required files or clearly
  state the supported prerequisite. Never call a missing required artifact complete.

Do not turn a source mismatch into a new expected hash. Do not use retries to switch
to owner downloads, customer uploads, cloud builds or a handmade packager. Preserve the
agreed app specification. The customer should not have to troubleshoot resource loading.
