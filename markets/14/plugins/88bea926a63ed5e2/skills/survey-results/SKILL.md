name: survey-results
description: Answer general questions about the user's Attest Measure studies by finding the study and reading its published survey results, boards and key findings. For change over time or splitting results by group, the tracker-trends and compare-audiences skills go further.
---

Use this when the user asks about their Attest research: a study, a survey, a tracker, a wave, or how an audience answered a question.

1. Find the study the user means by searching their studies. If several match, ask which one rather than picking.
2. Read the study's structure before any results. It tells you the surveys (one per wave and audience), the questions and their answer options, and the IDs the other tools need.
3. Read results one survey at a time. To compare waves, markets or audiences, request each survey separately and compare the answers yourself.
4. To slice by a group of respondents, prefer a segment the user has already saved. Build your own filter only when no saved segment matches, using the fields and values the connection reports as valid.
5. When the user asks what a study found, check its boards and key findings before working it out from raw results.

Report the numbers the tools return, with the base (how many people answered) alongside percentages, and say when a base is small. Name waves by their published date.

If the user asks for something the connection's tools can't do, say so plainly and point them to the Attest dashboard rather than attempting it.
