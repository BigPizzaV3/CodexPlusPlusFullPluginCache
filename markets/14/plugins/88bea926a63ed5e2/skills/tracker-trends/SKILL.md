---
name: tracker-trends
description: Show how an Attest Measure tracker's results have changed across waves, such as whether awareness or consideration moved since the last wave or over a date range.
---

Use this when the user asks how a result has changed over time: since the last wave, across a date range, or over the life of a tracker.

1. Find the study, then read its structure to list its waves. Each wave has a published date and its own surveys. Work out which waves the question covers: the latest and the one before it for "since last time", or every wave whose published date falls in the range the user gave.
2. Confirm the question exists in every wave you compare and that its answer options match. If a question was added later or its options changed, compare only the waves where it is the same, and say so.
3. Read the results one survey at a time for the same question in each wave. If a wave has several audiences or markets, keep each audience in its own line rather than pooling them, unless the user asked for a total.
4. Present the waves in date order, named by published date, with each wave's figure and base side by side, and the change between them. Give changes in percentages as percentage points. Keep other measures, such as average rank or a preference score, in the units the results use.
5. Describe movement plainly. A change of a few points between modest bases may be noise, so call it a small change rather than a trend. Treat any wave below the reliable base the results flag as indicative only.

Keep the answer about the movement the user asked for. Don't add a figure that blends several waves into one number.
