## 七、Notion 模板怎么复制

1. 先登录自己的 Notion 账号。
2. 打开俱乐部提供的模板链接。
3. 点击右上角“复制”或“Duplicate”。
4. 选择自己的工作区。
5. 等待复制完成，再从左侧边栏进入副本。

复制后的页面属于你自己的空间，可以按课程要求修改。不要在原模板页面直接编辑。

### 看不到“复制”按钮

2. 用 Chrome 或 Edge 打开。
3. 刷新页面。

## 十、Notion 常用功能速查

### 页面与区块

- **页面**是承载内容的容器；**区块**是页面中的文字、标题、图片、清单、数据库等单个内容单元。
- 新增区块：在空行输入 `/`，选择文字、标题、待办、图片或数据库。
- 常见问题：内容删不掉或拖不动，先点区块左侧六点菜单；误删可用撤销或页面历史恢复。

### 数据库、属性与视图

- **数据库**是一组结构一致的页面记录，例如“内容库”中的每一条内容。
- **属性**描述每条记录，例如标题、状态、平台、发布日期、标签、数字、人员或关联。
- **视图**只是同一批数据的不同看法，例如表格、看板、日历、列表；切换视图不会复制数据。
- 新增属性：数据库右上角属性 / Properties → 新建属性 → 选择类型。
- 新增视图：点击视图名称旁的 `+` → 选择布局 → 命名。

### 筛选、排序与分组

- **筛选**决定只看哪些记录，例如“平台是朋友圈、状态是待发布”。
- **排序**决定显示顺序，例如发布日期从新到旧。
- **分组**按某个属性把记录分区，例如按内容层或发布状态分组。
- 操作：打开数据库视图 → Filter / Sort / Group → 选择属性、条件和值。找不到记录时，先检查是否被筛选条件隐藏。

### 数据库模板

- 模板用于让每条新记录自动带上固定页面结构和默认属性。
- 操作：数据库“新建 / New”右侧下拉 → 新建模板 → 设置内容与默认值 → 保存。
- 复制整套俱乐部模板仍使用页面右上角 Duplicate，不要把“数据库模板”和“复制页面”混为一谈。

### Relation 与 Rollup

- **Relation**连接两个数据库，例如把“内容”关联到“产品”。
- **Rollup**从已关联的记录中汇总属性，例如统计一个产品关联了多少内容。
- 操作：新建 Relation 属性 → 选择目标数据库 → 建立关联；再新建 Rollup → 选择关联、目标属性和汇总方式。
- 新手只在课程 SOP 真正需要关联时学习，不必作为第一天前置。

### 分享与权限

- 页面右上角 Share / 分享，可邀请指定邮箱或开启网页分享。
- 发布到网页不等于允许编辑；按需要设置只读、评论或编辑权限。
- 发给 Emily 或群内排查前，先确认链接是否有访问权限；涉及个人或客户数据时不要公开发布。

### 同步块与 Notion AI

- **同步块**让同一段内容在多个页面保持一致；编辑任一同步副本，其他位置同步变化。
- **Notion AI**可辅助总结、改写、抽取信息和填写数据库属性，但不会自动理解你的真实业务边界。
- 使用 AI 前提供目标、材料和输出要求，结果必须人工检查；不要上传不必要的客户敏感信息。

## 十一、把工具接到当前真实任务

1. 先确认当前要做访谈、服务设计、内容、咨询还是交付。
2. 只补完成该任务需要的 Notion 基础，可安排一个短学习窗口；不是固定两三小时必须学完。
3. 从鹅圈子领取一个对应 SOP/智能体，提供真实输入。
4. 生成初稿后亲自核对，实际执行或使用。
5. 保存原材料、修改与真实反馈；稳定后再更新 SOP、知识库和岗位。
6. 不要求第一场景一定是朋友圈，不把复制系统当业务验证。

## 十二、ChatGPT 智能体怎么用

1. 打开 <https://chatgpt.com>。
2. 登录自己的 ChatGPT 账号。
3. 在小鹅通顶部进入相应智能体分区。
4. 复制智能体链接到浏览器打开。
5. 先说明自己的背景、阶段、问题和已有资料，再按智能体提示进行。

### 免费版能不能用

能否打开和使用、文件上传与消息额度，取决于当前账号、工作区和产品界面。本知识包没有实时额度数据；请以账号提示和官方说明为准，无法确认时联系运营核对。

### 能不能用其他 AI 替代

课程既有智能体按原平台和知识资料搭建，换平台需要重新配置并测试。一般方法和表单可先在文档或其他工具中使用；不能保证原智能体的检索、权限、工具和对话行为自动迁移。

### 智能体打不开

1. 确认已登录 ChatGPT。
2. 把链接复制到浏览器地址栏，不要只在微信内置页面打开。
3. 刷新或换 Chrome / Edge。
4. 检查链接是否来自小鹅通最新动态。
5. 涉及网络访问问题，不在学员群展开，联系 Emily。

## 十三、社群答疑边界

- 课程提供学员群答疑，有问题可以在群里提问。
- 不提供私聊一对一答疑承诺。助教回复不及时，可直接在群里提出结构化问题。
- 最终定位、产品定价、发售策略和复杂个案，优先进入 RAY 1V1、直播答疑或群内深度答疑。
- 网络工具、翻墙等问题不在公开群内讨论，联系 Emily 或查看课程对应资料。
