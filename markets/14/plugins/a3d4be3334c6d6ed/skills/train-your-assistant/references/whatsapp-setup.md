# Guided WhatsApp setup and templates

ChatGPT Codex — CODEX-V2-008. Branch implementation; not deployed automatically.

1. Read `get_profile` and `get_whatsapp_setup` under the separately reviewed
   `whatsapp_setup` permission. Verify the intended business. Describe saved
   configuration and plan status without claiming live delivery.
2. Use `prepare_whatsapp_connection` for a ten-minute browser link. Endelir
   requires the browser to be signed into the same owner account. The receipt
   cannot authenticate as that owner. Complete Meta sign-in, business/number
   selection and verification in the existing Endelir/Meta flow. Never collect
   passwords, access tokens, PINs or verification codes in chat. Demo workspaces
   remain protected from real credential connection; never refresh/reseed them.
3. Return to the saved setup check. Read dashboard diagnostics and have the owner
   verify inbound/outbound messages from their own phone. Do not activate customer
   traffic or call a successful credential save a completed delivery test.
4. Templates require the separate `whatsapp_templates` grant. Prepare against the
   exact approved business revision and currently saved WhatsApp account. This
   first workflow supports text header/body/footer, MARKETING or UTILITY, and up
   to ten contiguous numbered body variables with fictional example values.
   Use the existing editor for authentication, media, carousel or button layouts.
5. Show the entire template, language, category, examples and business. The owner
   approves submission to Meta for review, not customer messaging. Explain that
   Meta decides category and approval and later sending has normal pricing.
6. Submit once with the exact preview receipt, then read saved status. An unknown
   response or interrupted attempt may have created the template: never silently
   retry or change request IDs/names to bypass that protection. Resolve in
   Endelir/Meta. Optional status refresh uses the existing sync endpoint, whose
   first response is not guaranteed to cover a complete paginated account.
7. Removing private draft history does not delete an Endelir/Meta template.
   APPROVED is template review status, not permission to send customers messages.
