The earlier source training documents are not bundled. The prose and examples in the new guide are teaching aids, not findings about the user's organisation.

## Workbook navigation and conventions

All workbook inputs start blank. The workbook contains no calculation formulas or viability score. Its dropdowns support entry, not an automated assessment of organisational design.

| Sheet and range | Meaning |
|---|---|
| `Context!C7:C16` | System in focus, purpose, recursion, environment, boundary and review inputs |
| `Context!C21:D26` | Names and mandates for Role1-Role6 |
| `Context!B30:D37` | RASIC legend and blank/no-involvement distinction |
| `Context!B41:D47` | S1, S2, S3, S3*, S4 and S5 explanations |
| `Context!B51:D59` | Completion, allocation and review conventions |
| `Tasks!A9:D28` | Unique task ID, SCT, VSM function and priority |
| `Tasks!E9:G28` | Contributions of contained units, the system in focus and the containing system |
| `Tasks!H9:J28` | Central/decentral/shared allocation, decision authority and rationale |
| `Tasks!K9:L28` | Measures and required evidence or artifacts |
| `RASIC!A9:G28` | Task ID and six-role allocation matrix |
| `RASIC!H9:I28` | Separate approval authority and acceptance criteria |
| `RASIC!J9:L28` | Review status, review date and open issue or next step |

R means responsible for delivery, A means accountable for the outcome, S supports, I is informed, and C is consulted. R/A combines delivery and accountability. The workbook uses one clear A per active task as a local convention to agree with participants. Approval authority has a separate field and is not silently inferred from A. A blank cell means unassigned or unreviewed; `-` means reviewed with no involvement.

Use the same unique task ID across sheets. Row position alone does not link records. The twenty supplied blank rows are a starting capacity, not a limit. Copy complete blank table rows when extending the workbook so formatting and dropdowns remain consistent.

## Interpretation and attribution

Choose the system in focus and recursion level before mapping functions. Interpret S3 as internal cohesion and resource/accountability decisions, with S3* as a complementary route to direct operational evidence. Map each activity by its function. A department can contribute to more than one function.

The neutral guide attributes the VSM to Stafford Beer, requisite-variety concepts to W. Ross Ashby, and the seven-step application method to Martin Pfiffner. The source page distinguishes those intellectual foundations from the newly written teaching text, templates and fictional case. Read the cited original publication when an exact quotation or a claim about the author's precise wording is needed.

If a host cannot open a particular file, use the searchable guide where suitable and state the limitation when it affects the answer. Do not claim to inspect a diagram or workbook cell that was not accessible.
