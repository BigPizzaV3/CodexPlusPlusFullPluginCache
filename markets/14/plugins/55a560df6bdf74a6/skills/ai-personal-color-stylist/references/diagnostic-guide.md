# 설문 및 12유형 기준

## 필수 설문 6문항

Q1. 얼굴이 생기 있어 보이는 옷 색상은?
A 아이보리·코랄·피치 / B 화이트·로즈핑크·블루 / C 카멜·올리브·브라운 / D 블랙·선명한 레드·푸시아 / E 잘 모르겠어요

Q2. 더 잘 어울리는 액세서리 색상은?
A 옐로 골드 / B 실버 / C 로즈 골드 / D 둘 다 비슷함 / E 잘 모르겠어요

Q3. 얼굴 가까이에 대었을 때 어울리는 색상은?
A 밝고 선명한 색 / B 부드럽고 연한 색 / C 차분하고 탁한 색 / D 진하고 강렬한 색 / E 잘 모르겠어요

Q4. 잘 어울린다는 말을 들은 립스틱 색상은?
A 피치·코랄 / B 쿨핑크·로즈 / C 브릭·테라코타 / D 체리레드·베리 / E 모르겠어요 / 사용하지 않음

Q5. 얼굴이 더 또렷해 보이는 옷 색상 조합은?
A 밝고 부드러운 색 조합 / B 중간 밝기의 차분한 색 조합 / C 어둡고 깊은 색 조합 / D 밝고 어두운 색의 강한 대비 / E 잘 모르겠어요

Q6. 얼굴 아래에 여러 색상을 대어 보았을 때 가장 자연스러운 색상은?
A 피치·크림 / B 쿨핑크·라벤더 / C 올리브·카멜 / D 푸시아·로열블루 / E 비교한 적 없음 / 모르겠어요

## 12유형 기준

| 계절 | 유형 | 특징 | 대표색 |
|---|---|---|---|
| 봄 웜 | 봄 라이트 | 따뜻하고 밝으며 비교적 부드러움 | 피치, 라이트 코랄, 크림, 애프리콧 |
| 봄 웜 | 봄 브라이트 | 따뜻하고 밝고 선명함 | 비비드 코랄, 애플그린, 터쿼이즈 |
| 봄 웜 | 봄 웜 | 따뜻한 색온도 중심 | 골든 옐로, 살몬, 웜 코랄, 크림 |
| 여름 쿨 | 여름 라이트 | 차갑고 밝고 부드러움 | 베이비블루, 라벤더, 라이트핑크 |
| 여름 쿨 | 여름 뮤트 | 차갑거나 중성, 차분한 저채도 | 더스티로즈, 모브, 소프트블루 |
| 여름 쿨 | 여름 쿨 | 차가운 색온도 중심 | 로즈핑크, 라즈베리, 쿨블루 |
| 가을 웜 | 가을 뮤트 | 따뜻하거나 중성, 부드러운 저채도 | 세이지, 카멜, 소프트 테라코타 |
| 가을 웜 | 가을 웜 | 따뜻한 색온도 중심 | 머스터드, 러스트, 올리브 |
| 가을 웜 | 가을 딥 | 따뜻하고 어둡고 깊음 | 초콜릿브라운, 딥올리브, 다크브라운 |
| 겨울 쿨 | 겨울 브라이트 | 차갑고 선명한 고채도 | 푸시아, 일렉트릭블루, 체리레드 |
| 겨울 쿨 | 겨울 쿨 | 차가운 색온도 중심 | 블루레드, 로열블루, 아이시핑크 |
| 겨울 쿨 | 겨울 딥 | 차갑거나 중성, 어두운 색 | 블랙, 딥네이비, 와인, 에메랄드 |

12유형의 명칭과 경계는 체계에 따라 달라질 수 있다. 위 표는 추천 탐색 기준이지 피부색만으로 확정할 수 있는 진단표가 아니다.
