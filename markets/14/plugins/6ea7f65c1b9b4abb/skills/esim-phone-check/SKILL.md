# SimVoro eSIM device compatibility

1. Use the connected read-only `check_esim_device_compatibility` MCP tool with the exact device model. It returns public device matches, not an absolute technical guarantee.
2. If the tool is unavailable, say the public list could not be checked and point to https://simvoro.com/esim/compatible-devices; use general device information only with appropriate uncertainty.
3. Clarify variant, country of purchase, carrier unlock and any known exceptions. Similar phone model names can have different SIM/eSIM hardware. Where appropriate, an EID on the device is a useful compatibility signal.
4. Do not request IMEI, ICCID, account credentials, activation QR code, security codes or other sensitive details.
5. Refer to https://simvoro.com/help if the user needs device-specific support before buying.
