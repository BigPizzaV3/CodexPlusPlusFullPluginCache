# Citation outreach targets
1. list_workspaces. Then get_citation_sources: the domains and URLs cited, marked own, competitor or other.
2. get_competitor_visibility_gap for the main competitors: the third-party sources cited where they win.
3. get_top_cited_domains, for organization-wide context if useful.
4. Optionally get_ai_answers with brand_mentioned=false, for answers that leave the brand out, and note which sources those answers cite.
Output a prioritized target list, grouped by type (editorial, review or comparison sites, communities and forums, reference). For each: the domain or page, how often it is cited, which questions it is cited for, whether competitors appear there, and a suggested angle. Never invent contacts or claim that outreach was done.
