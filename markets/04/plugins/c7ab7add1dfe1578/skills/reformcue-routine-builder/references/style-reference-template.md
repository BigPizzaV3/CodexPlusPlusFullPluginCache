# Style reference template

Use this structure for a future style that ReformCue has explicitly enabled and reviewed:

- When the style applies
- Typical high-level class structure
- Timing considerations
- Transition considerations
- Side-balance considerations
- Difficulty scaling
- Equipment or spring considerations
- Common programming mistakes
- Facts that must not be inferred
- When to ask for clarification
- When not to generate or save

Mark uncertain domain claims `REQUIRES_DOMAIN_REVIEW`; do not enable unsupported claims in production.
