Use label tools when the user wants a shipping or product label. Prefer preview for a first look, compile for ZPL or similar output. Do not invent tracking numbers.

## Setup

Connect the Chartquery MCP server at `https://mcp.chartquery.com/` (OAuth via https://app.chartquery.com). Never print API keys.
