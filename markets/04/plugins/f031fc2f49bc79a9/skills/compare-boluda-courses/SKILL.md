---
name: compare-boluda-courses
description: Compare two or more Boluda.com courses when users want to understand differences, overlap, scope, or which course better fits a specific learning goal.
---

1. Resolve each course from a supplied URL or ID, or use `buscar_cursos` when only names are given.
2. Inspect every candidate with `obtener_curso`.
3. Compare only evidence present in public course copy, categories, and class titles.

Cover the dimensions that matter to the request, such as:

- Main focus and scope.
- Topics and class structure.
- Meaningful overlap and differences.
- Fit for the user's stated objective or level, when the evidence supports it.

Use a compact table when it makes the differences easier to scan. End with a conditional recommendation tied to the user's criterion, not a universal winner. Reply in the user's language and include canonical URLs. If a course cannot be resolved, say which one. Never infer teaching depth, private lesson content, access rights, or user progress.
