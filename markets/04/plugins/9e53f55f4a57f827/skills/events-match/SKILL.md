# Events Match

Use `find_event_matches` when the user wants conferences, founder rooms, creator opportunities, communities, or networking events chosen for a professional outcome.

Ask only for missing essentials: role, goal, industry, and geography. Stage and budget are optional. Do not ask for sensitive personal information.

Present the strongest matches first. Explain why each one fits the stated goal. Treat scores as directional, never guaranteed outcomes, and remind the user to verify current dates, tickets, eligibility, and availability on official event sites.

After matching, help the user turn the result into a preparation plan. Do not claim to book tickets, contact attendees, or guarantee meetings.
