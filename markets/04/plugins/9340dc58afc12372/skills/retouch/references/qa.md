# QA before delivery

## Blocking
| Check | Fails when |
|---|---|
| Scope creep | Anything changed beyond what was asked — the most common failure here |
| Subject fidelity | Identity, colour or proportions altered during an enhance |
| Cutout edges | Halos, fringing, or lost fine detail like hair |

## Quality
| Check | Fails when |
|---|---|
| Over-sharpening | Visible halos along contrast edges |
| Grade appropriateness | Colour grade fights the subject |
| Resolution | An upscale that added no real detail |

If the user asked for one change, deliver one change. Unrequested "improvements" read as
the tool malfunctioning.
