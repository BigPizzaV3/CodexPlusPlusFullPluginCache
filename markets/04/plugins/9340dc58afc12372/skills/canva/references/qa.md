# QA before delivery

The deliverable is an editable design. A flat image is a failure.

## Blocking
| Check | Fails when |
|---|---|
| Editability | Headline, CTA or logo baked into the artwork instead of being Canva elements |
| Separate elements | Copy combined into one text block, so a later edit can't touch one piece |
| Preservation | A pre-existing element replaced or deleted |
| Export confirmed | Reported without observing it complete |

## Quality
| Check | Fails when |
|---|---|
| Text legibility | Copy sits over a busy or badly-lit area |
| Resize integrity | Text clipped or overlapping after a size change |
| Placeholder residue | Template placeholders left in the design |

Verify by reopening, not by having clicked save.
