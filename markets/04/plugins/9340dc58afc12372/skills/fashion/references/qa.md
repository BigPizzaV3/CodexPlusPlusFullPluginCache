# QA before delivery

Inspect the actual frames. Fashion buyers return garments that don't match the imagery.

## Blocking
| Check | Fails when |
|---|---|
| Garment fidelity | Print, logo, texture, colour or cut differ from the source |
| Model consistency | The face or body changed between shots in one shoot |
| Shoot type | Catalogue output that looks editorial, or the reverse |
| Anatomy | Extra or missing fingers, limbs, distorted hands |

## Quality
| Check | Fails when |
|---|---|
| Fabric behaviour | Drape and weight read wrong for the material |
| Lighting consistency | Shots in one set are lit differently |
| Pose variety | Every frame is the same stance |
| Background continuity | The set changes between shots of one look |

## Report
Name the shoot type, how many looks were produced, and anything you could not verify.
