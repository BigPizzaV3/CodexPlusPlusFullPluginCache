# Contexta Learning

Keep useful English you find in chat connected to your learning. Create a project from selected text or supported files, or add new material to an existing project. Review and approve the plan first. Additions inherit project settings and keep all existing practice unchanged; use new packs by default or explicitly select an existing pack. Save expressions with context, revisit your Phrase Bank and try short measured audio practice.

## Six focused skills

- Add to Project: plan sessions only for newly selected material, keeping all existing practice unchanged.
- Create Project: prepare and approve an ordinary interview, presentation/meeting or work/study project, with AI adaptation by default for interviews and only on request for other scenarios.
- Save to Phrase Bank: keep an expression and its original, chat or clearly labeled generated context.
- Phrase Review: return today's, due or explicitly random saved expression, with its saved context and actual selection reason.
- Pronunciation Practice: practise the expression itself with measured sound and letter colors, read its saved context aloud, or use it in your own spoken answer.
- Practice Progress: summarize saved evidence and link to the next full website session.

Connect your Contexta account before accessing its learner tools. Only material you select for these actions is sent; both creation and addition need approval of the actual returned plan. Website sign-in is separate from the plugin connection. Full sessions and detailed history stay on the Contexta website.

Recording depends on the host's microphone support. Audio practice offers recording only; when recording is unavailable, continue on the actual Contexta website. Scores require real submitted audio; chat suggestions, generated examples and viewing a phrase are not saved assessments or mastery. Actual allowances and any preparation delays come from the connected service; no price, certified proficiency or improvement promise is implied.

Phrase cards keep original, chat and generated contexts clearly labeled. Practise phrase is the primary action; Read aloud trains a short saved context, and Speak with this phrase trains using the expression in your own answer. Matching unsubmitted practice can resume. An unused audio task can expire after 30 minutes; accepted recordings and measured history stay saved.
