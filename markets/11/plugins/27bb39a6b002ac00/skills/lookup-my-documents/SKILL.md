# Lookup my quotation / invoice / project

1. Prefer `list-my-projects-tool` if they are unsure of the number.
2. Use `lookup-my-quotation-tool` or `lookup-my-sales-invoice-tool` with their number.
3. Use `get-my-project-status-tool` with `project_uuid` for production/delivery/installation steps.
4. Summarize only tool results. If access is denied or nothing found, say so.
