# Muziek maken met AI: plugin for ChatGPT and Codex

Make original songs in the chat with your own [muziekmakenmetai.nl](https://muziekmakenmetai.nl/ai-assistent/) account.

- MCP server: `https://muziekmakenmetai.nl/mcp` (Streamable HTTP, OAuth 2.1 with PKCE, DCR and CIMD)
- Tools: `get_account`, `create_song`, `get_song`, `list_songs`
- One song uses 1 credit from your account after explicit confirmation and returns two versions.

Claude users: add the same URL as a custom connector (Settings, Connectors, Add custom connector).

Privacy: https://muziekmakenmetai.nl/privacy/#ai-assistent
