# Analyse new strategy material

1. Preserve the heading, stated provenance and best available page, slide, section, sheet/range, paragraph or timestamp locator.
2. For KPI, result, variance or operating-data diagnosis, use Outside Chair — Performance first and return only quantified evidence for strategic interpretation.
3. Prefer an exact current item. Treat an unmatched material claim as a blind spot; never create a loose relationship.
4. Choose the smallest fitting evidence, record, deliberation or decision proposal. Include source accessibility and uncertainty without copying private source content.
5. Produce the First Strategy Brief from supplied material before resolving a workspace. Use saved context only when the user asks for comparison, inspection or persistence.
