# First save

1. No task: main invitation, no MCP. One sentence suffices.
2. Give the complete First Strategy Brief before setup: situation, evidence, uncertainty, decision-changers, next move.
3. Offer ONE neutral priority/observation. More only on request. No inferred relationships or decisions.
4. Read `get_profile` and `list_workspaces` once. Check limits/permission. Select by name or propose a private company/project. Hide IDs.
5. effectiveAt: ISO UTC Z. Payload fields: priority(title,description,status); assumption(statement,significance,horizon,assessment); observation(period,value,classification; optional note). No significance on observations or horizon on priorities. Preview assumption significance/horizon or start with another type.
6. Preview workspace, complete records/statuses/dates, sources/relationships; omit empty categories. Suggest evidence for next time, no invented reminder. Ask “Save this as our starting point for the next review?” Respect a decline.
7. On approval, retain agreed details; create if needed, save using its ID, then read back and give the canonical workspace link.
8. Report partial success. Repair formatting, retry the approved meaning there; never duplicate a workspace. New facts need approval. Missing workspace means setup, not reconnection; see `connection-recovery.md` for access failures.
