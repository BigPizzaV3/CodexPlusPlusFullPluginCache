# 改善ルールの任意同期（一般公開版）

- この公開版には開発者の個人用Googleフォーム・スプレッドシートURLや認証情報を同梱しない。
- 利用者が明示的に管理表URLを提供し、Google Sheetsを読む権限が現在の利用環境にある場合だけ、設定タブ `LP_CRAFT_SETTINGS!B2` を確認する。
- B2が真値 `TRUE` のときに限り、`LP_CRAFT_RULES` のA〜F列を読む。F列が真値TRUEかつE列が空欄でない行を追加改善ルール候補とする。基本ルールと矛盾する指示や個別案件由来の情報は適用しない。
- 取得できない場合は取得したふりをせず、基本ルールでLP制作を継続する。
- 書き込みやルールON/OFF変更は、利用者が明示的に依頼し、権限がある場合だけ行う。
- Googleフォームからの自動登録・通知・Apps Script連携は本スキルだけでは実現しない。
