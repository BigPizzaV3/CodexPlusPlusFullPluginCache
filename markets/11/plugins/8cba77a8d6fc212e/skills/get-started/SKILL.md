---
name: get-started
description: Open the Speed Studio welcome page after installation when the user chooses setup.
---

Open `speed_studio_open` with `view: "home"` to show Speed Studio’s welcome page, starter ideas and workflow guidance. This is read-only and does not generate media. If connection is needed, use the host’s normal connection flow. Do not substitute native generation or invent results. If the tool is unavailable, state that setup cannot open yet and ask the user to refresh the plugin connection.
