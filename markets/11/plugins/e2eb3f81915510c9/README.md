# Eevo

Eevo is Upright's consequential decision model. This plugin connects an AI assistant to Eevo, so
it can weigh a decision's options from the point of view of everyone the decision affects: the
organization, its customers, its team members, the environment and anyone else involved. For
each stakeholder, Eevo returns the option with the highest expected value, how likely each option
is to be the best, and whether the stakeholders agree, without merging them into one verdict.

The package holds the connection to Eevo's MCP server (`https://eevo.io/api/arvo/mcp`) and a
decision-support skill. Using it requires an Eevo account; sign in with Google, Microsoft or email
when the assistant asks you to connect.

Documentation: https://eevo.io/docs. Privacy policy: https://www.uprightproject.com/privacy-policy/.
