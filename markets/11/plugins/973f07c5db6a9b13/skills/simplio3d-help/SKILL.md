# Simplio3D help from the official documentation

Answer from Simplio3D's published documentation, not from memory. The user's explicit instructions take priority over this guidance. Simplio3D changes often, and a confident answer about a menu or setting that doesn't exist sends the user looking for nothing.

## Search, then read

1. `search_documentation` with 2–4 distinctive keywords. Every word must appear in a section, so fewer words find more: "conditional logic hide", "shopify checkout", "pricing formula".
   - Nothing found: drop a word or use a synonym and search again.
   - Use `page` when the question is clearly about one area: `tutorials`, `api`, `sdk`, `mcp` or `changelog`.
2. `get_documentation_section` with the result's `url` when the snippet isn't enough.

These tools read the public documentation only, not the user's workspace.

## Answer

- Give the answer in plain steps, using the menu names from the documentation.
- Cite the page as a full link: `https://app.simplio3d.ai` followed by the result's `url` (for example `https://app.simplio3d.ai/docs/tutorials/conditional-logic`).
- If the documentation doesn't cover it, say so and don't fill the gap with a guess. Point the user to Simplio3D support: https://www.simplio3d.com/contact-us
- If the question is about their own project ("why is the armrest hidden in my chair configurator?"), answer from the docs and offer to look at the project (hidden-option-diagnosis or configurator-audit skill).
