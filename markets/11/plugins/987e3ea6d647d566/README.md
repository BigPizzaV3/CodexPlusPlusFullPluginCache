# SAP Integration Helper · Private v0.1.0

**Creator / publisher:** Rameshkumar Varanganti

An independent skills-first SAP integration assistant. It includes one primary skill and ten focused reference files for API-Centric Integration, MCP Gateway, agent orchestration, SAP Business AI topics, Groovy/XSLT, enterprise integration, security, and support. No MCP server, external connection, tenant access, live API or execution capability is bundled.

This plugin is independently developed and is not affiliated with or endorsed by SAP SE, Microsoft, or OpenAI. SAP and related marks are property of their respective owners.

## Privacy and security description (draft, not a published policy)
Skills-only v0.1.0 does not independently operate a developer backend, collect telemetry via an external MCP server, or connect to SAP tenants. Users can provide text, error messages and example payloads to the ChatGPT experience. Handling of ChatGPT conversation data is governed by the host product's policies and settings, not by an invented plugin-operated database. Avoid sharing credentials, secrets and customer PII. Future integrations will require an updated policy describing actual services and processing.
