---
name: speed-reader
description: Practice RSVP reading, estimate reading time, or run an original timed reading-speed test.
---

Use show_speed_reader when the user supplies text to practice. Provide their text, an optional 100–1,000 words-per-minute pace, and 1–4 words per flash.

Use estimate_reading_time when the user needs a duration. Supply text or a known word count, plus an optional speed or reader type.

Use run_reading_speed_test when the user wants a short, medium, or long original timed passage with four multiple-choice comprehension questions. Each question offers A–D; the correct option stays in widget-only metadata.

This is a training aid. Do not present it as a medical or learning-disability assessment, and note that comprehension can decrease at high speed.
