# Use ChatGPT capabilities with G2X

G2X supplies records, documents and permitted account actions. ChatGPT can add
web research, analysis of user-selected files and finished documents when those
capabilities are actually available in the current host, mode and account.
Inspect available capabilities instead of inventing a tool or assuming support.
Keep the result in ordinary chat or a native file, without a custom G2X widget.

## Research beyond the record

Use available web search or deep research when the user asks for current public
context, comparison or corroboration. Establish the exact entity and G2X record
first, then investigate the relevant public agency, company or source. Keep web
claims, G2X evidence and your inference distinguishable, cite each source, and
report conflicts or missing evidence. Do not copy private CRM notes, uploaded
capability statements or other account data into public search queries. An
additional connected source is used only within the user's requested scope and
its existing access; do not connect a new service or send messages silently.

## Work with selected files

When the user supplies a spreadsheet, capability statement or solicitation,
inspect its actual contents with the available file-analysis capability. Preserve
identifiers, units, formulas and source rows. Match G2X entities using returned
identifiers; resolve ambiguous matches instead of merging namesakes. Use a
bounded set of record lookups appropriate to the request. A local file is not a
G2X import and does not authorize account writes or paid enrichment.

## Deliver a useful artifact

For an explicitly requested brief, matrix, workbook or presentation, use the
host's available document, spreadsheet or file-generation tools. Keep citations
and record links in the output. Separate source facts, analysis, assumptions and
open questions; make matrices usable as tables and spreadsheets rather than
flattened paragraphs. Inspect the generated file before giving its actual
usable download link. If the capability is absent, return the complete content
in chat and state that a downloadable file was not created. Do not claim a file
was saved to G2X, Drive, an email or another destination without the corresponding
authorized action and readback.

## Recurring work

Use the recurring-briefing skill when the user explicitly requests a future or
repeated G2X check. ChatGPT scheduled tasks and Codex automations are separate
features. Use the actual scheduling capability of the requested host; a written
schedule is not a created task. Task access to G2X must be verified in that mode.
See https://help.openai.com/en/articles/10291617-scheduled-tasks-in-chatgpt and
https://help.openai.com/en/articles/11487775-connected-apps-in-chatgpt .
