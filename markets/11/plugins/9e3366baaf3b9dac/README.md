# Sidequest

A quick sliding-block puzzle to keep your mind engaged while AI works.

## Play

1. Install Sidequest using your app's plugin directory and enable its connection.
2. Ask **“Open Sidequest”** at any time, or start a clearly long writing, research or coding task.
3. Slide the blue block to the right-hand exit. Choose **Easy**, **Medium**, **Hard** or **Impossible**.

Use **Hint** for a suggested move, **Undo** to step back, and **Reset** to restart. **Share** creates a public challenge link. **Minimize** collapses the game; reopen it to continue.

## What to expect

- Long-task opening is on by default when the plugin is enabled. Sidequest may appear once near the start of a clearly long task. It stays out of quick tasks and requests that say **“no games”** or **“no breaks.”**
- Say **“Stop opening Sidequest during my work”** to turn it off for that chat. To turn it off across chats, disable the plugin or add that instruction to your personal instructions.
- Opening is a judgment made when your prompt arrives, not a timer. It may not trigger on every long request.
- Internet access and a host that supports interactive MCP Apps are required. Terminal-only clients do not show the inline game.
- No Sidequest account, API key, payment or local Node installation is needed.
- Progress depends on your host retaining the game state; it is not an account-backed save.

## Privacy and support

The connector receives puzzle requests, puzzle IDs and completed move histories to validate solves in memory. It does not request conversation text, source code or device files, and does not save leaderboard scores. The game counts openings, validated solves and approximate distinct browsers; you can turn usage counting off in Settings. Hosting providers may retain technical request logs. The host/browser may retain puzzle progress and display choices.
