# BhumiBoss project API field guide

Observed from one `GET /api/project/<uuid>` response for ASBL Spectra, with `modifiedAt` 2026-09-28. Treat this as a field guide, not a fixed schema: inspect each actual response before using a path. Values can be null or absent. Use the page URL `/project/<uuid>` as the reader-facing link.

| Buyer question | Observed JSON path | Interpretation and checks |
| --- | --- | --- |
| Identity | `uuid`, `projectName`, `alias`, `developerName`, `reraNumber` | Match the suggestion UUID and name. A null RERA number does not mean unregistered. |
| Location | `locationName`, `location.lat`, `location.lng`, `fileDetails.projectAddress` | Project location. `fileDetails.address` appears to be the promoter's office address in this sample; do not use it as the project site. |
| Project scale | `buildingSummary.apartments`, `.buildings`, `.maxFloors`, `.types` | Homes, towers, top floor count, configurations. Check the phase represented. |
| Site area | `landDetails.projectArea`, `.projectAreaNet`, `.projectAreaAffected` | Square metres in this sample. Divide by 4,046.8564224 for acres. Compare gross vs net only when the distinction matters. Density = apartments / gross acres, if the scopes match. |
| Home sizes | `buildingSummary.minSize`, `.maxSize`; `floorplanConfigurations[].area` | Square metres in this sample. Multiply by 10.7639104167 for sq ft. The sample converts to about 1,980–2,217 sq ft. Do not call this carpet area without explicit evidence. |
| Floorplans | `floorplanConfigurations[].id`, `.name`, `.facing`, `.rooms`, `.review` | Match BHK, size, facing and room counts. `/project/<uuid>/floorplan/<id>` is a reader-facing link when the page confirms it. Observations in `.review` are analysis, not measured dimensions. |
| Proposed completion | `fileDetails.projectDetails.proposedDateOfCompletion` | A DD/MM/YYYY date, not possession/occupancy. Compare with the public page and RERA documents; the sample API and public page differ. |
| Regulatory / builder | `fileDetails.projectDetails.approvedDate`, `.authorityName`, `.litigationsRelated`, `fileDetails.promoterDetails`, `developerHistory[]`, `fileDetails.promoterHistory[]` | Attribute litigation and history fields to BhumiBoss/RERA-derived data rather than independently verified legal findings. The two history arrays can disagree on completion dates; flag discrepancies. |
| Amenities | `amenities.totalArea`, `.features`, `.commonTypes`, `.specialTypes` | Total area is square metres in this sample; convert to sq ft before comparing. A true type indicates listed availability, not measured capacity or delivery status. `amenities.totalArea / buildingSummary.apartments` gives allocation per home after converting units. |
| Open space | `areaStatement.hasOpenArea` | Boolean only. Do not turn it into an open-area percentage. A percentage in `review` may be an estimate; label it as such. |
| Neighborhood prices | `hoodPricing.avg_price_per_sqm`, `.median_price_per_sqm`, `.lower_bound`, `.upper_bound`, `.count` | Area price context, not a quote for this project's available units. Divide INR/m² by 10.7639104167 for INR/sq ft. No explicit date in this object. |
| Project price observations | `projectPrices[].pricePerSqm`, `.area`, `.scrapedAt`, `priceSummary.minPrice`, `.medianPrice`, `.mostCommonPrice` | Listing-derived observations. `pricePerSqm` is INR/m²; summary totals appear to be INR in the sample. Check each `scrapedAt`; the sample's latest price observation was September 2025 despite the 2026 `modifiedAt`. Do not present as a live builder quote or inventory. |
| Buildings | `buildingDetails[]` in the supplied sample; the owner also identifies `fileDetails.buildingDetails[]` in other responses | An array of project buildings, which may represent towers, villas, or clubhouses. Inspect each actual response for the path and `buildingInfo` rather than assuming every entry is an apartment tower. Do not equate this array's length with the count of residential towers. |
| Floor inventory | `buildingDetails[].floors[]` or `fileDetails.buildingDetails[].floors[]` | Each row groups apartments by floor (`floorId`) and `apartmentType`. `saleableArea` is the total square metres for the `numberOfApartments` in that row. Divide area by apartment count for the **average saleable area per apartment** in that row; multiply by 10.7639104167 for sq ft. For example, `saleableArea: 1605.36` and `numberOfApartments: 2` yields 802.68 m² (about 8,640 sq ft) per apartment. Do not present this as carpet area or claim identical sizes without unit-level evidence. If a floor has multiple rows or types, keep them separate. Skip division when count is zero or missing. |
| Bookings and construction | `buildingDetails[].floors[].numberOfBookedApartments`, `.progress[]`; `fileDetails.developmentWork[]` | A row with `numberOfBookedApartments: 2` and `numberOfApartments: 2` reports that both apartments are booked in that source record. Label it as a reported booked count, not confirmed completed sales or live inventory. Check the record date; do not infer `numberOfApartments - numberOfBookedApartments` is currently available for purchase. Progress may also be stale. |
| Review | `reviewPreview`, `review` | `reviewPreview` is suitable for public summary. The full `review` object may represent a subscriber feature; do not reveal gated text merely because an API response includes it. |

## Freshness and contradictions

- State the project response's `modifiedAt` separately from nested `projectPrices[].scrapedAt`. Other nested values may have their own effective dates or no date at all.
- Prefer structured numeric fields for calculations, but compare against the public page and label discrepancies. For example, the sample's 32,071.337 m² is about 7.925 acres and 1,182 homes imply about 149 homes/acre; the public page rounds its figures.
- Keep public page handover dates and `fileDetails.projectDetails.proposedDateOfCompletion` separate when they differ. A recent API modification timestamp does not explain which date governs.
- Preserve nulls and missing keys. Never interpret `false`, `0`, or an empty array as a verified negative without understanding the field's source and update cadence.
