# JobSpidey for AI agents

Search supported jobs, prepare tailored resumes and cover letters, retrieve PDFs,
and track applications in your connected JobSpidey account. Your agent handles
employer websites and external submission.

Endpoint: **https://mcp.jobspidey.com/mcp**

This is a local standalone Codex-format plugin review candidate, version 0.1.1.
It is separate from the frozen 0.1.0 review package and public preview. Actual-client
checks for this updated candidate are pending. Historical public-endpoint, direct
SDK/native default-CIMD workflow and fresh signup return acceptance passed. Portal authentication, installed-plugin/model-host acceptance
and public plugin-directory publication are **pending**.

Read [setup](docs/setup.md), [tool contract](docs/tool-contract.md), and
[review walkthrough](docs/review-walkthrough.md). The safe
[acceptance summary](docs/acceptance-summary.json) separates direct-client facts
from plugin checks. This bundle contains documentation, brand assets, a setup
skill and a remote connection configuration; it contains no app implementation.
