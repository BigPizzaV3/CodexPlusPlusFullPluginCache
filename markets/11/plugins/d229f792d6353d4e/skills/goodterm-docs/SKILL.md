# Goodterm bedienen

Lade für eine konkrete Bedienfrage die passende Referenz. Erkläre in der Sprache der Person, was sie in der App tun kann. Verlinke bei Einstellungen die dort angegebene absolute URL mit der passenden Bezeichnung. [Einstellungen](https://app.goodterm.net/settings)

| Referenz                                                 | Wann sie weiterhilft                                                                                   |
| -------------------------------------------------------- | ------------------------------------------------------------------------------------------------------ |
| [Oberfläche](references/interface.md)                    | Panels, Anzeige, Sprache und Tastenkürzel.                                                             |
| [Records bearbeiten](references/records-editing.md)      | Record-Markdown, Verweise, Formeln, Code, Speichern, Konflikte, Versionsverlauf und lokales Undo/Redo. |
| [Records organisieren](references/records-organizing.md) | Suche, direkte Record-Links, Filter, Autoren, Favoriten, Pins und Papierkorb.                          |
| [Chat](references/chat.md)                               | Offener Record, Bearbeitungen im Chat, Modellauswahl, Recherche und Quellen.                           |
| [Spracheingabe](references/voice.md)                     | Aufnahme, Transkription, Einfügen und Wiederherstellung.                                               |
| [Zugriff](references/access.md)                          | KI-Schutz, Berechtigungen und Verbindungen zu externen Assistenten.                                    |
| [Konto und Daten](references/account-data.md)            | Kontowechsel, Anmeldung, Geräte, Budgets, Benachrichtigungen und Export.                               |

Besprich den Inhalt eines Records, sobald er im Kontext oder als Werkzeugergebnis vorliegt. Verwende extern die zurückgegebene Record-URL als Markdown-Link, im eingebauten Chat die tatsächliche Record-Referenz im Fließtext. Bestätige eine Aktion erst nach erfolgreicher Ausführung. Für Goodterms Zweck und mögliche Arbeitsweisen nutze `about-goodterm`.
