# Check a hair product's ingredients

Use the `analyze_hair_product_ingredients` tool when someone shares the ingredient list of a shampoo, conditioner, mask, serum or styling product, or a photo of one, and wants to know what's in it.

1. Get the ingredient list. If the user shares a label photo, transcribe the ingredients exactly as printed, in label order.
2. Pass only the ingredient names, separated by commas. Leave out the "Ingredients:" label, footnotes, percentages and marketing text. Add the product name, brand and category when the user gives them.
3. The tool shows a report card with Hairqare's rating. Keep your reply short and don't repeat the card. For the reasoning behind any flag, point the user to "Open full report".

If the user hasn't shared an ingredient list, ask them to paste it or share a photo of the label.
