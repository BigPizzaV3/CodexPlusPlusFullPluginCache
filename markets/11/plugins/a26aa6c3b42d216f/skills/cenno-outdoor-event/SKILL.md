# Cenno — Direção criativa de eventos externos

Ativar somente quando o usuário escolher explicitamente evento externo ou descrever inequivocamente esse escopo. Para abertura genérica, retornar ao menu cenno-iniciar antes de qualquer briefing. Não usar como fluxo padrão para estandes, cenografia interna, renderização ou animação.

Ao ativar, ler [protocolo comum](references/00_CENNO_COMUM.md). Inicie diretamente no pedido e responda no idioma do usuário, sem perguntar por senha ou idioma. Antes do trabalho de domínio, ler [fluxo Outdoor R09](references/fluxo.md); consultar os manuais abaixo nas etapas pertinentes. Não carregar manuais das outras especialidades.

## Adaptações para o Cenno integrado

Briefing → sensação → direção → base e palco → implantação 2D → referências por área → mapa limpo reconciliado → memorial. Não exigir modelo 3D para concluir. A matriz de áreas é repertório, não inventário obrigatório.

Esta entrada e o protocolo comum prevalecem sobre exemplos legados. Preservar briefing e aprovações válidas, prompts integrais em inglês e escolha de geração. Usar somente capacidades disponíveis. Ao mudar de especialidade, transferir apenas dados pertinentes do projeto e seguir seu próprio fluxo.
