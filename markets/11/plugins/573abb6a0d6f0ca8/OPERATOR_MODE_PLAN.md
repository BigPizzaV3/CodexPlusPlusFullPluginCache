# Withdrawn draft: operator-mode classification

The earlier draft of this document preselected an operator and a conclusion. It has been withdrawn. The current plugin must not classify or highlight any account based on that draft.

If SignalAF later publishes an operating-mode field, its meaning, source, correction path, and use in comparisons should be designed and reviewed as a separate product decision. Until then, the analyst may use a category supplied by the user for that conversation, with attribution, and must not infer one from token metrics or names. General board analysis should remain open to whichever relationships the live data supports.
