# Website Builder

Short description: Plan and build your website

## Long description
Website builder for planning and writing a small-business website or web app, then starting the build in an online AI builder.

What you can do:
- Turn a rough idea into a structured plan with pages, sections, navigation and one clear call to action.
- Write homepage, services, About, FAQ, pricing and contact copy from the details you provide.
- Review pasted page HTML or text for SEO, content, conversion, accessibility and mobile basics, with scores and a prioritized list of fixes.
- Write the code for a first version of a page or site, or edit code you already have.
- Prepare titles, metadata, local search guidance, brand kits and launch checklists.
- Open a prefilled link to an online AI website builder, then review the brief and start the build yourself.

Every planning result is usable without opening a link.

This plugin prepares briefs, content and links. It does not build, host, deploy or publish a website, open live pages or guarantee search rankings, and it stores no pages. A short build link keeps your brief on a server operated by the publisher for up to 14 days so that the link can open the builder, then deletes it; nothing else from the conversation is stored. Builds may need further iteration. The link includes the plugin creator's affiliate code. This is an independent plugin and is not sponsored or endorsed by that builder. Responses may end with a short footer containing an affiliate link and a disclosure.

## Capabilities
- Plan website structure and pages
- Write homepage and service copy
- Audit pasted pages for SEO
- Draft FAQ, pricing and contact pages
- Write and edit website code
- Prepare metadata and local SEO
- Open a prefilled website builder link

## Starter prompts
- Plan a five-page website for my dental clinic and prepare the build link.
- Audit this homepage HTML for SEO, conversion and accessibility.
- Write a services page for my consulting business using only the details I give you.
