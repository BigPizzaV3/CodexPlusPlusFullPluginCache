# GrantData public submission package

Version 0.5.2 contains nine research guides and a read-only MCP connection to
the public GrantData tools. Azimuth Analysis LLC is the intended publisher.
The website is https://grantdata.org/.

The package helps people research U.S. nonprofit organizations, programs,
studies and historical funding. It does not expose private engagement notes,
save a strategy, submit an application or establish current eligibility from a
past grant. The public MCP server runs at the URL in `mcp.json`; the owner-only
server is separate.

The knowledge graph and research approach were developed in partnership with
Emerald South and the Center for Applied AI at the University of Chicago
through a grant from the OpenAI Foundation. That origin does not imply an
endorsement of this plugin or its individual findings.

This is a prepared package. Public directory review, publisher verification,
and publication are separate steps. The four listing URLs must be verified live
before submission.
