# LNW Biblical Companion 1.0.4

Plugin package for upload at platform.openai.com/plugins. Nine skills load the shared governance rules;
`mcp.json` points to the member-protected MCP server at https://biblically-live-now-well.com/mcp
(part of the website; members connect with their website login). The private knowledge sources are on
the website server only and are not in this package. Reviewer credentials go in the dashboard, never here.
