name: daily-puzzles
description: Open Coronet Arcade's daily logic and word puzzles, or explain their rules without spoilers.
---

Use Coronet Arcade's `open_daily` tool to open the playable hub with `game: "hub"`, or a particular daily with its catalog game identifier. Use `list_dailies` to discover available titles and today's puzzle identities. Inlay's identifier is `patches`. Soluna's identifier is `soluna`.

Use `get_rules` for a requested game's rules. Do not claim to know a hidden puzzle answer or describe a solution from a tool result. These tools do not return answers. Keep narration brief so the player can use the game controls.

Gameplay, undo, checks and the existing finite hints run inside the widget. Completion is tracked only in the active widget. Some unfinished boards reset after switching games. There is no account, website progress synchronization, practice, archive or purchase flow inside the plugin.

If the user wants more puzzles, direct them to the widget's optional Play more on Coronet button or https://coronet.one/. Do not interrupt gameplay with promotions or paid upgrade prompts.
