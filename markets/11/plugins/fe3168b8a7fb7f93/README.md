# OmniRoom — ChatGPT plugin

Furniture & home-decor visualization for sellers. Stage a product photo in a
styled room, recolour it, create white-background catalog shots, six product or
room angles, and matching sets. Powered by OmniRoom's hosted models.

- Website: https://www.omniroom.ai
- MCP server: https://www.omniroom.ai/api/mcp (no authentication)
- Support: info@omniroom.ai

No login is required to try it. Results are shown as watermarked previews.
