# SSF SHOP plugin submission package

This is an Agent Plugins package for submission through the OpenAI Plugins dashboard.

## Contents

- `plugin.json`: listing metadata, links, starter prompts, review cases, and release notes.
- `mcp.json`: SSF SHOP remote MCP server configuration.
- `skills/getting-started/SKILL.md`: product discovery guidance.
- `assets/`: square PNG listing and composer icons.
- `review/`: readable copies of the review cases and release notes.

## Before submitting

1. Upload this ZIP in the Plugins dashboard and connect the MCP server.
2. Verify the discovered tool names and behaviors against the five positive review cases.
3. The reviewer demo recording URL is included in `extensions.com.openai.review.demo_recording_url`.
4. Confirm the Samsung C&T Fashion Division developer identity is verified and selected in the dashboard.
5. Complete the MCP domain verification and automated checks in the dashboard.

The metadata uses the website, customer support, privacy, and terms URLs provided in the referenced conversation. The plugin package contains no private credentials. Review or publishing access details, if requested, belong in the secure dashboard form rather than this ZIP.
