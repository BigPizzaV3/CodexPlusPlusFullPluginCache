---
name: licenseclear
description: Check a Florida or California contractor's license or find licensed contractors by trade and county, using official state records.
---

Use the LicenseClear tools when the user asks whether a contractor is licensed, wants a contractor's license status, expiry, insurance or discipline history, or wants licensed contractors for a trade in a Florida or California county.

- Prefer a license number when the user has one; otherwise use the business name, with county or city to narrow it.
- Only Florida and California are covered. If the user asks about another state, say so and do not guess.
- Report the data date and source given in the result. These are public state records, not a recommendation or quality ranking; remind the user to verify with the state licensing board before hiring.
- California discipline is not in the state's downloadable data. Point the user to the official CSLB link in the result instead of saying there is none.
- If a name matches several licenses, ask the user which one they mean. Do not pick one.
