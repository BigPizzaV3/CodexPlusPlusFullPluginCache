# Asking Zonori what's on

Zonori answers with the public events listed on Zonori in a place over the coming week. Each event has its local start time, venue and area, who runs it and a link to its page on Zonori.

Name a place, and add an activity or a day if you like:

- "What's on in Bangkok this weekend?"
- "Any yoga in London this week?"
- "Any board games in Bangkok this week?"
- "Which places does Zonori have events for?"

If a place isn't covered, Zonori says so; ask which places it has events for. To RSVP or see more, open the event's link on Zonori.
