# Recorded MCP walkthrough

The English recording is available at https://feidawang.github.io/Token-Weather/mcp-walkthrough-20261011.html.
It contains about 2 minutes 27 seconds of actual protocol-client interactions with the deployed Cloudflare MCP, English synthesised narration and English subtitles. Only synthetic numeric fixtures are shown.

The recording covers connection/tool discovery, five numeric scenarios, unknown-reference handling and a server rejection of an unsupported synthetic messages field. The client is a recording aid, not a shipped ChatGPT widget. It does not establish natural-language prompt routing in ChatGPT/Codex or replace the five positive and three negative host review cases. Those host routing checks remain separate.

The recording contains no real transcripts, private local readings, credentials or identity documents. The page and media were checked for anonymous HTTPS access and browser playback before their URL was added.
