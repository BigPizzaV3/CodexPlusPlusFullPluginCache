# HR Omni ChatGPT Plugin

Public submission source for HR Omni.

- Production MCP: `https://mcp.hromni.com/mcp`
- Product knowledge: customer-safe, indexed references under `skills/hr-omni-product/`
- Assistant behaviour: intent-driven Explore, Plan/Report and Change workflows under `skills/hr-omni-assistant/`

Reviewer credentials are supplied separately through the submission portal.
