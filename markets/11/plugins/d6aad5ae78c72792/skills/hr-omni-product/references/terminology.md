# Terminology

Use plain customer language first. Use product names when they help precision.

Preferred English:
- HR Omni
- HR software
- User Management
- Employee Records / Employment Management
- Leave Management
- Worklogs
- Assets and Inventory
- Documents
- access control or role-based access control when technical precision is needed
- Single Sign-On (SSO)
- Calendar Feeds
- working schedule
- direct manager

Use UK English: organisation, centralise, authorised and licence as a noun.

Avoid exposing raw access-role identifiers unless the user asks for technical detail.

For Bulgarian, use natural professional Bulgarian rather than literal English phrasing. Check current product UI wording before procedural instructions.
