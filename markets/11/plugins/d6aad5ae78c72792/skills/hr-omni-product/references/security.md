# Security

Verified 2026-09-10. Recheck current official sources before procurement or publication use.

Verified controls include:
- AWS hosting in Dublin, Ireland
- encryption at rest
- strict TLS for data in transit
- Cloudflare Web Application Firewall
- company-aware tenant isolation
- least-privilege access control evaluated for the selected company
- backups and operational monitoring
- Stripe processing payment details rather than HR Omni storing card details

Documents files use AWS S3 encryption at rest and authenticated access with company/access checks.

Do not claim GDPR certification/compliance guarantees, ISO, SOC 2, Cyber Essentials, published penetration-test assurance, malware scanning, universal data residency guarantees, zero risk or prevention of all unauthorised access unless current authoritative evidence supports the claim.

HR Omni features can support a customer's security and governance processes, but customers remain responsible for configuration, policy, access review, lawful basis, retention choices and legal advice.
