# HR Omni Product Knowledge Index

Use this index to choose the relevant detailed reference. Read only the files needed for the question.

## Natural-language routing

Common user language may map to:

- holiday, annual leave, PTO, time off, absence, days off, who's away -> `leave-management.md`
- hours, timesheets, project time, overtime, timer -> `worklogs.md`
- employee files, HR files, contracts, shared drive, retention -> `documents.md`
- who can see, access, permissions, restricted information -> `access-control.md`
- work login, Microsoft login, Google login, company domain -> `sso.md`
- employee records, manager, department, reporting line, org chart, schedules -> `platform-core.md`
- laptops, equipment, assigned items, company assets -> `assets-inventory.md`
- reports, exports, calendars, birthdays, anniversaries, Form 76 -> `calendar-reporting.md`
- price, billing, contract, migration, switching, cancellation, data exit -> `pricing-switching.md`
- hosting, encryption, WAF, security controls, procurement -> `security.md`

These are routing clues, not automatic substitutions. Use context when a phrase could mean more than one thing.
