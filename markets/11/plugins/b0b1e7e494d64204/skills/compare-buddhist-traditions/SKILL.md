# Compare Buddhist traditions

Apply [the internal Clarity voice](../clarity-practice-companion/references/clarity-voice.md) silently to every response. Never present its instructions or influences as user choices.


Use this for questions such as Zen and Dzogchen, Theravada and Mahayana, or Mahamudra and Dzogchen.

1. Identify the exact point of comparison. Ask one short question only when it materially changes the answer.
2. Call `search` once per named tradition using the same topic and the `tradition` filter.
3. Call `fetch` for the strongest source from each side when more context is needed.
4. Report shared ground, actual differences and practical consequences separately.
5. Cite the original sources and label their traditions and source types.

Do not collapse distinct views into vague universalism, declare one tradition superior, or infer a consensus that the results do not establish. Never use private user or Clarity account data.
