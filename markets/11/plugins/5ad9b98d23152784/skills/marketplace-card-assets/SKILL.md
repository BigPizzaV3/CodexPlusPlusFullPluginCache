# Planning marketplace card images

Determine the set from the request, the placement goal and the available materials. The result is
a list of specific images to prepare, each with a clear purpose. A single slide is a set of one.

## Possible image roles

- a cover or main frame;
- an additional angle or a close-up detail;
- the product in use or in a setting;
- the package contents;
- an infographic with the content the user specified;
- a rich/A+ module or another page block.

This is professional vocabulary for describing the result. The current task decides the set;
name the chosen roles in words the user understands.

## Planning result

For each image, record its purpose, its content, the references it uses and the marketplace
requirements that matter. For a series, add a shared visual direction only as far as coherence
needs it. Choose the model, format and parameters by the current catalog and schema.

## One slide with this method alone

For one slide with a short headline or offer, this method is enough:

- Decide what the buyer should notice first and scale the product, the text and the free space
  around that priority.
- Put the lettering on a clean, calm field: text on a busy or occupied part of the photo gets
  lost.
- Place the text and labels around the product, not over its key details (logo, shape, texture).
- Keep a safe margin from the frame edges, because the marketplace may crop the image or overlay
  its own UI.
- Put the in-frame text in quotes exactly as it should appear and check its spelling.
- For text in the frame, choose the model by the current catalog and its confirmed ability to
  reproduce lettering.
- When micro-parameters are missing, choose a consistent style from the product, the niche and
  the brand, and state the decisions you made.

## When to load another method

- `selling-slide-composition` — only for a set of two or more slides that must share a palette,
  lettering character, label rhythm and grid.
- `card-text-in-image` — only for in-frame text beyond one short headline: several lines,
  bullets, property labels or badges with icons.

Otherwise do not load them. Apply `image-prompt-craft` for the chosen image model.
