# Vertical script and mini-series

The result matches exactly the scale the user asked for: from a set of hooks or one finished
episode to a connected mini-season arc. If the user asks for a script right away, don't make
them choose from a list of themes first. Use the two-stage "ideas → script" mode for a broad
request where the direction really hasn't been chosen yet.

## Building an episode

- Make the stakes or the intrigue clear in the first 1–2 seconds, unless the genre calls for
  something else.
- Every 2–3 seconds give a micro-turn: a new shot, fact, object, line or caption changes the
  understanding or the action.
- Keep the exact action the user described, the hero's canon and the important visual anchors.
- Match the number of events to the given duration and pace; fit the timing grid to the specific
  video.
- Use at least three concrete functional details in a finished script.
- For a video without speech, build the meaning only through shots, actions, ambient sound and
  captions.

Choose the pattern by the stakes and the stage of the path, not by a matching word. In a
finished script, name the pattern explicitly and explain the choice in one sentence. By
default, give the goal, a script by seconds, the on-screen text, a visual brief, three versions
of the post caption, a soft CTA and a hook into the next episode; if the user set a different
result contract, follow theirs.

Read the full [library of viral script patterns](references/vertical-story-patterns.md): it is
required for choosing the episode's engine, structure, retention and mini-season. Don't promise
virality as a fact: patterns strengthen contrast, stakes, truth, specifics and serialization,
but they don't guarantee reach.
