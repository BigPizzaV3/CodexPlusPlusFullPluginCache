# Model Prompting Index

Select a live model and read its detailed schema before loading one matching family reference.
The schema owns parameters, media fields, reference slots, quality, size, duration, audio,
aspect ratio, variants and limits. Family references shape only the prompt or exact text.

Apply official vendor guidance directly after filtering it through the live schema. Use partner or
tested third-party guidance only for transferable prompt shape when official guidance is thin.
For an uncovered model, use its current label, description, prompting guidance and the generic
image/video rules in [prompt-craft.md](prompt-craft.md).
