## Seedream

- Use coherent natural language with subject, action and environment.
- State the application scenario when it changes the result.
- Quote exact rendered text and use precise style language.
- For edits, name the target, requested change and important fixed elements.
- For references, state what to retain from each source and describe the generated result.

## Seedance

- Build the prompt around subject/action, scene, camera, lighting and audio intent as relevant.
- Assign image, video and audio references only through supported fields and state their roles.
- Keep the requested event achievable within the selected duration.
- For image-to-video, focus the prompt on motion and camera development from the source frame.

Use native Chinese rewriting only when the selected route or user requests it; preserve aliases,
names, numbers and exact dialogue.
