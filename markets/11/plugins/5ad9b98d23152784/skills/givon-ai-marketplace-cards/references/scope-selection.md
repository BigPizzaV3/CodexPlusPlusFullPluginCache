# Marketplace Asset Planning

Choose assets from the user's requested set and listing goal. The labels below provide common
visual-role vocabulary; the requested outcome determines the actual set.

## Common roles

- **Main image:** product-first listing cover.
- **Angle or detail:** another view, material, mechanism, label or distinctive feature.
- **Lifestyle:** product in a useful or believable context.
- **What's included:** contents and accessories shown clearly.
- **Infographic:** concise user-supplied facts, benefits, specs or steps.
- **Brand or A+ module:** a page section with one message, such as hero, features, use,
  ingredients/materials or story.

For a multi-image set, select complementary roles so every asset answers a different buyer
question. Keep the requested marketplace and current placement requirements in view when they
change composition or text density.

Ask only for information required to make the requested set executable when it cannot be inferred
from the current context. Collect the blocking missing inputs together: which assets are needed,
what product/reference to use, or which exact supplied facts must appear.
