# 6OS判定辞書

> この辞書の非公開部分は、保護Knowledge（genko_os_navi.os_dictionary_private）として別に提供されます。両方を合わせて、1つの「6OS判定辞書」として扱ってください。

## 最重要原則
原稿OSは【キーワードだけで決定しない】。

同じ主軸検索語でも、

- 選択された読者
- 選択された本の方向性
- 読後の中心変化

によって使用するOSは変わる。

判定対象は、

【その本を読んだ結果、読者の何が最も中心的に変わるのか】

である。

OSはジャンル分類ではない。

「ギター＝習得成長」「不安＝自己理解・反応変容」「副業＝実戦突破」のような固定判定は禁止する。

# 6OS一覧

## 1. 実戦突破OS

### 一言
完成するOS。

### 中心変化
具体的な成果・行動・作業・プロジェクトが完成・実現する。

### 判定質問
「この本の最終ゴールは、何か具体的なものを完成・実行することか？」

YESなら有力候補。

### 中心単位
現実操作 → 前進 → 完成

### 向く本の例
- 副業を1つ始める
- 初めての商品を作る
- 1冊出版する
- 部屋を片づけ終える
- 旅行計画を完成させる
- 自宅でワイン会を開催する

### 境界
能力そのものが上がる → 習得成長OS  
何を選ぶか決める → 判断基準OS  
知識の見え方が変わる → 理解深化OS  
他者との相互作用が変わる → 関係変容OS  
自分の反応を選び直す → 自己理解・反応変容OS

---

## 2. 習得成長OS

### 一言
できるようになるOS。

### 中心変化
技能・能力が段階的に高まり、以前できなかったことが再現できるようになる。

### 判定質問
「この本の中心成果は、読者自身の能力・技能が高まることか？」

YESなら有力候補。

### 中心単位
できない → 練習・修正 → できる → 安定 → 応用

### 向く本の例
- ギターコードを弾けるようになる
- 英会話力を高める
- 文章を書けるようになる
- プレゼン技能を身につける
- テイスティング技能を身につける
- ランニングフォームを習得する

### 境界
1つの具体的成果を完成する → 実戦突破OS  
違いや仕組みを理解する → 理解深化OS  
何を選ぶか決める → 判断基準OS  
関係の相互作用が変わる → 関係変容OS  
自分の反応パターンが変わる → 自己理解・反応変容OS

---

## 3. 判断基準OS

### 一言
選べるようになるOS。

### 中心変化
読者が自分の条件・判断軸を持ち、選択肢から自分の場合の答えを決められる。

### 判定質問
「この本の最終ゴールは、自分の場合どれを選ぶか判断できることか？」

YESなら有力候補。

### 中心単位
選択肢 → 条件 → 判断軸 → 比較 → 除外・保留 → 決定

### 向く本の例
- 自分に合う副業を選ぶ
- ETFと投資信託のどちらを選ぶか決める
- 転職するか残るか判断する
- 自分に合う学習方法を選ぶ
- ワインを条件から選べるようになる
- サービスを比較して選ぶ

### 固有ルール
ランキングや人気順で結論を代行しない。

「全員これを選べばよい」という一律結論にしない。

保留・撤退・選ばない、も正当な判断結果として扱う。

### 境界
違いや仕組みを理解するだけ → 理解深化OS  
選んだ後に実際に完成・実行する → 実戦突破OS  
技能そのものが高まる → 習得成長OS  
関係のやり取りを変える → 関係変容OS  
自分の反応を扱う → 自己理解・反応変容OS

---

## 4. 関係変容OS

### 一言
やり取りが変わるOS。

### 中心変化
読者自身の働きかけが変わり、他者との会話・距離・役割・相互作用のパターンが変わる。

### 判定質問
「この本の中心は、自分と相手のやり取りそのものを変えることか？」

YESなら有力候補。

### 中心単位
自分の働きかけ → 相手の反応 → 自分の次の対応

### 向く本の例
- 夫婦の会話を変える
- 親子のやり取りを変える
- 職場の人との距離を調整する
- 家事分担の話し合いを変える
- 子どもへの声かけを変える

### 固有ルール
相手を操作・支配することを目的にしない。

「こう言えば相手は必ず変わる」など、相手の反応を保証しない。

読者が変えられるのは、自分の言葉・行動・タイミング・距離・境界・役割・対応である。

### 境界
相手が一切変わらなくても、自分の反応の扱い方が変われば目的達成 → 自己理解・反応変容OS  
一般的な会話技能そのものを習得 → 習得成長OS  
関係を続けるか離れるかを決める → 判断基準OS  
1回の話し合い等を完了することだけがゴール → 実戦突破OS  
関係の構造を知識として理解する → 理解深化OS

---

## 5. 自己理解・反応変容OS

### 一言
反応を選び直すOS。

### 中心変化
刺激に対して自動的に起きている自分の認知・感情・身体反応・行動のパターンを捉え、別の反応を選べるようになる。

### 判定質問
「相手や外部状況が変わらなくても、自分自身の反応の扱い方が変われば目的を達成できるか？」

YESなら有力候補。

### 中心単位
刺激・出来事  
→ 解釈・注意  
→ 感情・身体反応  
→ 自動反応・行動  
→ 次に選べる反応

### 向く本の例
- 不安が出た後の反応を選び直す
- イライラした瞬間の行動を変える
- 比較して落ち込むパターンを扱う
- 考えすぎへの反応を変える
- 指摘された後の自己否定を扱う
- 人目が気になるときの自分の反応を扱う

### 固有ルール
他者が登場する場面を扱ってよい。

ただし、他者の発言・行動・反応は【読者の反応を起こす刺激・出来事】として扱う。

他者を変える対象にしない。

感情そのものの完全消失をゴールにしない。

### 境界
自分→相手→自分という相互作用を変える → 関係変容OS  
心理・脳・感情の仕組みを理解するだけ → 理解深化OS  
感情調整技法そのものを技能として高める → 習得成長OS  
外部の選択肢を選ぶ → 判断基準OS  
具体的な成果・行動を完成する → 実戦突破OS

---

## 6. 理解深化OS

### 一言
見え方が変わるOS。

### 中心変化
断片的な情報がつながり、対象の位置・関係・構造・因果・背景・文脈・意味が見えるようになる。

### 判定質問
「読後の中心成果は、知識がつながって対象の見え方そのものが変わることか？」

YESなら有力候補。

### 中心単位
断片情報  
→ 位置づけ  
→ 関係  
→ 構造・因果・文脈  
→ 新しい視点  
→ 転用・鑑賞

### 向く本の例
- 世界史の出来事を前後関係で理解する
- AI・機械学習・生成AI・LLMの位置関係を理解する
- ワインの産地・品種・気候と味のつながりを理解する
- 音楽をリズム・編成・音色から聴ける視点を得る
- 哲学思想同士の関係を理解する
- 宗教・文化・歴史の背景をつなげて理解する

### 到達状態の代表例
1. 全体像把握
2. 因果・メカニズム理解
3. 視点獲得
4. 鑑賞・味わい深化

### 固有ルール
単なる用語集・百科事典・Wikipedia型解説にしない。

新しい情報量ではなく【何と何がつながったか】を評価する。

比較しても「どちらを選ぶか」へ進めない。

鑑賞系では「正しく当てる技能」ではなく「以前より深く味わえる見方」を作る。

### 境界
実際にできるようになる → 習得成長OS  
自分に合うものを選ぶ → 判断基準OS  
具体的成果を完成する → 実戦突破OS  
他者とのやり取りを変える → 関係変容OS  
自分自身の反応を扱い直す → 自己理解・反応変容OS

---

# 境界判定ルール

## 実戦突破OS vs 習得成長OS
1つの具体的成果・作業・行動を完成する  
→ 実戦突破OS

能力・技能そのものが高まる  
→ 習得成長OS

## 実戦突破OS vs 判断基準OS
何を選ぶか決めること自体がゴール  
→ 判断基準OS

選んだ後に実際に実行・完成することがゴール  
→ 実戦突破OS

## 習得成長OS vs 理解深化OS
できるようになる  
→ 習得成長OS

分かる・見える・つながる  
→ 理解深化OS

## 判断基準OS vs 理解深化OS
自分の場合どれを選ぶか決める  
→ 判断基準OS

違い・仕組み・関係が分かる  
→ 理解深化OS

## 関係変容OS vs 自己理解・反応変容OS
自分→相手→自分という相互作用が変わる  
→ 関係変容OS

相手が変わらなくても、自分自身の反応の扱い方が変われば成立する  
→ 自己理解・反応変容OS

## 自己理解・反応変容OS vs 理解深化OS
自分自身の反応を扱い直す  
→ 自己理解・反応変容OS

心理・感情・脳などの仕組みを理解する  
→ 理解深化OS

## 習得成長OS vs 関係変容OS
一般的な会話・傾聴・質問などの能力を高める  
→ 習得成長OS

特定の相手との実際のやり取りを変える  
→ 関係変容OS

# 同じキーワードで複数OSが成立する例

## ワイン
### 実戦突破OS
自宅でワイン会を企画し、開催まで進める。

### 習得成長OS
香り・味・特徴を捉えるテイスティング技能を身につける。

### 判断基準OS
自分の予算・食事・好みからワインを選べるようになる。

### 理解深化OS
産地・品種・気候・製法と味のつながりを理解する。

※関係変容・自己理解・反応変容は、読者と方向性によって自然に成立する場合のみ使用する。無理に6案を作らない。

---

## 不安
### 自己理解・反応変容OS
不安が出た後の自分の反応パターンを捉え、別の反応を選ぶ。

### 関係変容OS
不安から確認・追及を繰り返す対人パターンを変える。

### 理解深化OS
不安という反応の仕組み・背景を理解する。

### 習得成長OS
特定の状況で使う呼吸・注意・セルフモニタリング等の技能そのものを習得する場合のみ成立。

---

## 副業
### 実戦突破OS
副業を1つ決め、開始状態まで進める。

### 習得成長OS
副業に必要な文章・営業・制作などの技能を身につける。

### 判断基準OS
自分の時間・資金・経験から副業を選ぶ。

### 自己理解・反応変容OS
失敗不安や比較によって動けなくなる自分の反応を扱う。

### 理解深化OS
副業市場・収益構造・働き方の違いを理解する。

---

# 禁止事項
- キーワードだけでOSを固定しない
- 1つのキーワードに1つのOSしか成立しないと考えない
- 6OSすべてを毎回候補へ入れようとしない
- 不自然な方向性を作ってOS数を埋めない
- 市場規模・売上予測・おすすめ度でOSを決めない
- OSをジャンル分類として使わない
- 存在しない第7のOSを作らない
- OS名を変更しない
