# Evidence ledger

Build this before drafting. It makes the document auditable and prevents a
polished sentence from laundering an unsupported inference into a fact.

| ID | Claim or decision-relevant observation | Source | Tier | Opened? | Support | Contradiction / caveat | Use in draft |
| --- | --- | --- | --- | --- | --- | --- | --- |
| F-01 |  | primary document, data, or workspace record | primary | yes/no | direct / partial |  |  |
| A-01 |  | n/a | assumption | n/a | consequence if false |  |  |
| C-01 |  | source IDs | conflict | yes/no | competing readings | resolve / expose |  |
| G-01 |  | n/a | gap | n/a | evidence needed | owner / next step |  |

## Rules

- `primary` means the original source, official data, or directly relevant
  workspace artifact. An opened primary source can support a material claim.
- `secondary` can explain or triangulate but does not replace a primary source
  when the primary is available.
- A search result, preview, social snippet, or un-opened URL is a lead. Put it
  in a gap or follow-up, not in a citation.
- A conclusion may synthesize several facts, but label it as analysis and link
  each supporting fact ID.
- Record contradictions rather than averaging them away. State what would
  resolve the conflict and who owns that work.
- Do not publish private workspace metadata in a page intended for external or
  public sharing. Redact, aggregate, or keep the page private.
