# Aircover.ai brand assets

These files use Aircover's official square mark from the public website:

- Source: `https://www.aircover.ai/assets/apple-touch-icon.png`
- Retrieved: 2026-10-08
- Source dimensions: 256 by 256 pixels, RGBA PNG
- Source SHA-256: `c7e42bd5de4e580681f11656fe491792cc0cbd19c63519d4909de79548a3a8fd`

The mark's artwork and colors are unchanged. The source was resized with a
high-quality Lanczos filter to 512 by 512 pixels for `aircover-logo.png` and 128
by 128 pixels for `aircover-composer.png`. A circular transparency mask was
applied outside the original cyan icon background so both files remain legible
on light and dark surfaces.

Do not replace these files with generated artwork. Any future brand change must
come from an Aircover-approved source and update this provenance record.
