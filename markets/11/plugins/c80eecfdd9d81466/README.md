# Aircover.ai

Aircover.ai gives ChatGPT the context behind every deal by connecting authorized
Aircover meetings, transcripts, CRM context, qualification, reports, and indexed
content through the Aircover MCP server.

This portable package also includes four workflows that can create call-prep
briefs, mutual action plans, path-to-quota strategies, and product sentiment
reports. An Aircover account is required. Access is limited by the signed-in
user's Aircover role and organization permissions.
