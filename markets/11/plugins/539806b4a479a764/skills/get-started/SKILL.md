# Get started with Spellar

Use this when the user has just connected Spellar or asks what the plugin can do.

1. Call `get_account` to confirm which Spellar account is connected and which permissions it has.
2. Tell the user, briefly, what they can ask for:
   - what was decided in a meeting, or which meeting covered a topic;
   - exact wording from a transcript, by speaker;
   - open action items and where each came from;
   - a recap of a week or month;
   - what is coming up on their calendar.
3. If the connection includes edit permissions, mention that they can also ask to mark an action item done, add a note, or rename, tag or file a meeting. Nothing can be deleted.
4. Offer one concrete first step, such as listing this week's meetings.
