# FilmLA form behavior

Use these notes when working in MyFilmLA. Reinspect the current UI; labels and required fields may change. These are observed form behaviors, not a statement of current permit rules.

- Resume the intended saved draft rather than creating another production title. Match project title, location purpose, address, and LA ID. Multiple similar project titles can exist.
- Select the correct purpose: Production, Base Camp, or Crew Parking. Separate off-site parking from filming/base camp even if all locations serve one shoot. Verify the association when the portal offers it; separate saved drafts are not automatically proof of association.
- The address map may be inside an iframe. Search, verify the returned address, provide location details, and choose **Use this location**. Typing an address without accepting the location is insufficient.
- Location type and public access are separate inputs. Do not assume a hospital garage is unrestricted public parking or available for film crews.
- On Location Dates, select the schedule type before **Add**. Even a single visible choice such as Crew may need selection. Choose time options from the dropdown; free text such as `7:00 AM` can be visible without committing the underlying time. Verify actual rows for both dates, including start/end time and overnight state.
- Activities and Equipment & Personnel are separate sections. Checking **Static Picture Vehicle** as an activity does not add a picture car to equipment. Likewise, **Camera on Sticks** or **Handheld Equipment** does not populate the equipment list.
- The equipment section can reject **Next** with `'Equipment Data Repeater' should contain at least one item` and `Must have equipment to continue!`. This means the equipment list lacks a committed row. Add the real equipment category, quantity, and description, then verify it in the right-hand list and summary. Do not insert a fictitious item to satisfy validation.
- Prefer dedicated categories for Van, Utility Van, Cast/Crew Vehicles, Static Picture Vehicle, carts, tables, tents, and other actual inventory. Use Other for equipment lacking a suitable category, with a specific description. Avoid listing both Van and Utility Van for the same vehicle.
- Custom quantity controls can retain or concatenate digits. Verify the value after focus leaves the control and after the row saves. If necessary, select all and replace the value using supported UI input. Verify personnel totals rather than trusting the typing action.
- The form can return a snapshot of the previous step while navigation is still rendering. Verify the new step before another action. Read an error in the context of the current section; stale error text can persist after a correction. Confirm that the blocking requirement is actually resolved before proceeding.
- Crew Parking Notes and Base Camp Notes can be different fields in different drafts. Preserve useful existing text, identify proposed versus confirmed logistics, and keep the house/base camp and garage parking roles explicit. Do not describe an unbooked garage as secured parking.
- **Save & Quit** saves a draft; **Submit** is a different action. After saving, refresh Saved Drafts if its list is stale, reopen the exact LA ID, and verify the saved note and rows. Do not confuse a dashboard timestamp with proof that all fields persisted.
