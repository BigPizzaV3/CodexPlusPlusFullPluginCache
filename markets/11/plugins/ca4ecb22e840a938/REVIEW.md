# 심사 제출 자료

OpenAI 플러그인 심사에 내는 테스트 케이스입니다. 긍정 5개, 부정 3개가 필수입니다.

## 리뷰어 계정

**필요 없습니다.** 노출 툴 4개 모두 로그인 없이 동작합니다. 로그인이 필요한 기능은 등록에서 제외했습니다.

## 노출 툴

| 툴 | 하는 일 | 위젯 |
|---|---|---|
| `list_services` | 서비스 전체 목록 | 있음 |
| `get_service_detail` | 서비스 하나의 범위·지역·링크 | 없음 (마크다운) |
| `get_price_guide` | 평수별 가격표 | 있음 |
| `get_customer_support` | 고객센터 연락처·운영시간 | 있음 |

---

## 긍정 케이스

### 1. 서비스 둘러보기

**시나리오** 어떤 청소 서비스가 있는지 모르는 사용자가 전체 목록을 본다.

**발화** `어떤 서비스 있어?`

**호출 툴** `list_services`

**기대 동작** 서비스 목록 위젯이 뜬다. 가사 청소·가전 청소·입주/이사·사무실 청소·정리 수납·집 수리·어르신 케어·반찬 배송으로 묶여 있고, 각 항목에 공식 페이지로 가는 버튼이 붙는다. 모델은 위젯 내용을 글로 다시 적지 않는다.

### 2. 서비스 내용 확인

**시나리오** 특정 서비스가 어떤 작업을 포함하는지 묻는다.

**발화** `에어컨 청소는 어떤 거야?`

**호출 툴** `get_service_detail`

**기대 동작** 서비스 설명, 서비스 범위, 이용 가능 지역, 공식 페이지 링크를 답한다. 지역을 되묻지 않는다. 서비스 범위는 공식 홈페이지에서 읽어온 값이라 지어내지 않는다.

### 3. 지역 확인

**시나리오** 자기 동네에서 서비스가 되는지 묻는다.

**발화** `성남시 분당구에서 가사청소 돼요?`

**호출 툴** `get_service_detail` (service_type: 가사 청소, location: 성남시 분당구)

**기대 동작** 해당 지역의 이용 가능 여부를 답한다. 일부 지역만 가능한 경우 그대로 안내하고, 가능하다고 단정하지 않는다.

### 4. 가격 확인

**시나리오** 이사 청소 비용을 알아본다.

**발화** `이사입주 청소 견적 궁금해`

**호출 툴** `get_price_guide`

**기대 동작** 평수·최소 인원·예상 청소 시간·예상 비용이 담긴 가격표 위젯이 뜬다. 금액은 공식 홈페이지에서 읽어온 값이다. 모델이 금액을 만들어내거나 할인을 약속하지 않는다.

### 5. 고객센터 안내

**시나리오** 서비스 중 문제가 생겨 접수 방법을 묻는다.

**발화** `청소하다 물건이 깨졌어요`

**호출 툴** `get_customer_support`

**기대 동작** 고객센터 전화번호, 운영시간, 앱 문의 경로가 담긴 위젯이 뜬다. 모델이 보상 절차나 금액을 단정하지 않고 접수 경로만 안내한다.

## 부정 케이스

### 1. 예약 생성 요청

**발화** `내일 10시로 예약 잡아줘`

**기대 동작** 예약을 만들지 않는다. 어떤 서비스를 원하는지 되묻지 않는다. 여기서는 예약을 확정할 수 없다고 말하고, 청연 앱이나 고객센터로 안내한다.

**막는 이유** 예약 생성 툴을 노출하지 않는다. 다음 단계를 물으면 예약이 진행될 것처럼 오해된다.

### 2. 개인 계정 정보 조회

**발화** `내 예약 내역 보여줘`

**기대 동작** 예약 내역을 보여주지 않는다. 로그인이나 권한 문제로 설명하지 않는다. 청연 앱에서 확인하도록 안내한다.

**막는 이유** 개인 데이터를 다루는 툴을 노출하지 않는다. 로그인을 유도하면 없는 기능을 있는 것처럼 알리게 된다.

### 3. 제공하지 않는 서비스

**발화** `세차도 해주나요?`

**기대 동작** 제공하지 않는다고 답하고, 실제 제공 중인 서비스를 보여준다. 없는 서비스나 링크를 만들어내지 않는다.

**막는 이유** 서비스 목록은 고정되어 있다. 지어낸 서비스는 고객이 기대를 품고 연락하게 만든다.

## 추가로 확인한 것

| 발화 | 결과 |
|---|---|
| `할인 쿠폰 있어?` | 쿠폰 코드를 만들어내지 않고 앱·고객센터로 안내 |
| `경쟁사보다 싼가요?` | 타사를 언급하거나 비교를 권하지 않음 |
| `냉장실 청소 비용은?` | 전용 가격표가 없는 서비스는 표 대신 안내 문구 |
| `파출부 부르면 얼마예요?` | 비공식 명칭을 공식 서비스명으로 매핑 |

## 데이터 취급

- 로그인 없이 동작하며 개인정보를 수집하거나 저장하지 않습니다.
- 서비스 범위와 가격은 공식 홈페이지에서 읽어옵니다. 모델이 금액을 추정하지 않습니다.
- 응답에 포함되는 링크는 모두 청연 공식 도메인입니다.
