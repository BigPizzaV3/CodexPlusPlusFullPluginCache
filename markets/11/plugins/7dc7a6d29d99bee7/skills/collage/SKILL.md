---

Call `open_collage_easy` with `{}`. The user selects photos directly inside the editor. Do not ask users to send private photos to the MCP server; the tool has no file arguments and cannot inspect editor images or editing state. Explain that this version supports still PNG/JPEG/WebP photos, 47 layouts, divider adjustments, zoom/position, spacing, simple borders, solid backgrounds and PNG/JPEG download. Export before closing: no saved projects. If the host blocks import or download, offer https://collageeasy.app/chatgpt/editor. Do not claim an export succeeded without a generated file or host evidence.

Do not invoke this editor for AI retouching, video/music, text/stickers, device mockups, stored projects, social posting or background automation. Explain the unsupported feature briefly. Do not claim full parity with the native app. Original photos and edits remain in editor memory. Explicit Export via ChatGPT uploads only the finished collage to OpenAI for download, with a visible disclosure. Server opening requests and chat text follow their respective platform processing.
