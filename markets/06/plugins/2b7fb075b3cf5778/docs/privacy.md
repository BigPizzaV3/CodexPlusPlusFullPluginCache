# Privacy

Whitespace Reentry is a local, read-oriented skill. It does not make network requests and has no account connection, external connector, telemetry, daemon, scheduler, MCP server, or background monitor.

The skill uses only evidence available in the current host interaction, such as user-provided material, workspace instructions, current status, recent changes, and bounded artifacts that are relevant to the request. It does not claim access to a live Whitespace service or Context Graph. The host may apply its own conversation and workspace retention rules; this plugin does not add a separate storage service.

The normal result is a concise reentry brief. If the user explicitly asks to save or share the result, the skill can prepare a portable Reentry Capsule using the included template. The skill does not publish, send, deploy, purchase, delete, or accept a proposal merely to make context feel complete.

Public release files contain synthetic workflow examples and documentation only. Do not place credentials, tokens, private records, raw connector payloads, exact private paths, or unredacted project data in a prompt, eval, issue, or publication artifact.
