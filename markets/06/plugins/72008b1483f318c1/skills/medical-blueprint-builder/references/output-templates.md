# Output Templates

Use the smallest template that fully solves the task.

## A. Standard clinical blueprint

### Learner and context
### Overall goal
### Core clinical questions
### Must know / Should know / Nice to know
### Recognition and interpretation
### Diagnostic reasoning
### Investigation strategy
### Severity / risk
### Management decisions
### Reassessment / treatment failure / escalation
### Must-not-miss
### Competency matrix
### Teaching and assessment alignment

Do not force headings that add no value.

## B. Compact high-yield blueprint

| Domain | Learner should be able to… | Priority | Why it matters |
|---|---|---|---|

Then add:
- **Must-not-miss**
- **Decisive investigations**
- **Management pivots**
- **Reassessment / escalation**

## C. Course / module blueprint

1. Learner and context
2. Overall goal
3. CLOs
4. Topic / domain map
5. Priority map
6. LO / competency matrix
7. Learning sequence
8. Teaching-learning methods
9. Assessment strategy
10. Proposed weighting
11. Must-not-miss competencies
12. Constructive alignment check
13. Feedback, remediation, reassessment
14. Feasibility notes

## D. Competency matrix

| Domain | Learner should be able to… | Priority | Cognitive demand | Performance level | Learning activity | Assessment |
|---|---|---|---|---|---|---|

Keep the table readable. Remove columns that would be empty or repetitive.

## E. Clinical reasoning map

**Presentation**  
→ **Problem representation**  
→ **Working diagnosis**  
→ **Prioritized differential**  
→ **Investigation: what question does it answer?**  
→ **Severity / risk**  
→ **Management decision**  
→ **Response**  
→ **Reassessment / continue / modify / escalate / reconsider**

## F. Constructive alignment map

| Outcome / competency | Practice / learning activity | Assessment | Feedback / reassessment | Alignment issue |
|---|---|---|---|---|

## G. Document-derived blueprint

### Source scope
### Learner
### Source-derived priorities
### Clinical reasoning / decisions supported by the source
### Competencies
### Assessment implications
### Source limitations
### External update, if explicitly added and verified

Clearly label the last section as external.
