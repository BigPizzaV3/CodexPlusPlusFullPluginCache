# Тестирование перед публикацией

Положительные сценарии:

1. Пользователь прикрепляет только Excel; создаются DOCX на основе встроенного полного шаблона и копия XLSX.
2. В Excel есть лист с выбранными работами и отдельный прайс-лист; выбирается лист с работами.
3. Номера этапов восстановимы из сводного блока Excel; этапы корректно переносятся в Word.
4. Пользователь просит сохранить недели при сроках в месяцах; срок переводится по явному правилу и отображается последовательно.
5. Во входном Word есть данные старого клиента; в результате не остаётся старого клиента, проекта, этапов или логотипа.
6. В полной таблице этапов заполнены отдельный номер, название, сумма и срок; условие начала остаётся пустым, если оно не подтверждено входными данными.
7. Для одного этапа с несколькими выбранными работами в полной таблице результатов созданы отдельные строки с результатом, дополнительными данными, примечанием и номером этапа.
8. В Excel нет этапов: в таблице этапов есть только «Предпроект» (1) и «Этап 2» (2) с подтверждённой суммой Этапа 2; другие этапы, срок и итог не добавлены.
9. В файле есть несколько прайс-листов и представлений расчёта: используется один лист с выбранными работами, без дублирования строк результатов.
10. В сводке этапов есть внутренние коды `0`, `1`, `2`: в первой таблице отображаются этапы `1`, `2`, `3`, а в последней колонке результатов — только соответствующие отображаемые номера.
11. Выбранная строка содержит многострочные дополнительные данные, комментарии и ограничения: весь подтверждённый текст переносится в «Примечание» без сокращения.
12. В Excel нет цен подписки: блок подписки отсутствует из итогового документа, а значения прошлых клиентов не попадают в него.
13. В итоговом DOCX сохранены все постоянные разделы полного шаблона, а маркеры в квадратных скобках отсутствуют.
14. В шапке есть логотип ФинГрада и пустое место под логотип клиента; логотипы прежних клиентов отсутствуют.
15. Длительности `1,17`, `8,98` и `0,92` месяцев отображаются как `1,5`, `9` и `1`; этап с пустыми работами и нулевыми показателями отсутствует.
16. Для Предпроекта и следующего этапа заполнены стандартные условия начала; для следующих этапов условия не выдумываются.
17. При количестве `3` в Excel в «Доп. данные» добавлено `Количество: 3`; значимое значение `1` также перенесено.
18. «Администрирование проекта» находится отдельным блоком после основной матрицы и относится к этапам `2–N`.
19. Пять невыбранных демонстрационных работ из шаблона отсутствуют; отсутствующее число юридических лиц в черновике отмечено красным маркером уточнения.
20. Два расчёта разных клиентов формируют разные названия, цели, этапы и результаты; в каждом документе отсутствуют факты другого клиента.
21. В расчёте без ДиректБанка, подписок и банков эти блоки, строки и сноски отсутствуют в DOCX.
22. В расчёте с несколькими подтверждёнными направлениями проекта название и цель содержат только эти направления; при одном направлении остальные не добавляются.
23. Титульная страница содержит дату запуска в формате `ДД.ММ.ГГГГ`, логотип ФинГрада и не содержит даты или логотипа прошлого клиента.
24. В первой таблице на всех добавленных строках видны внешние и внутренние границы.
25. Список баз, присутствующий в результате и дополнительных данных источника, появляется в итоговой строке только в «Доп. данных».
26. Подтверждённые администрирование, обучение и документация собраны в один нижний блок с диапазоном этапов `2–N`.
27. Между группами результатов последовательных этапов присутствует пустая объединённая строка с толстой верхней границей.
28. Без явного клиента в Excel название `Расчет тарифа Клиент А.xlsx` даёт `Клиент А` на титуле, выделенное жёлтым.
29. При создании 30.09.2026 дата старта по умолчанию — `01.10.2026`, а условия оплаты — `50% предоплата / 50% после завершения работ`; оба значения выделены жёлтым.
30. Текст КП не содержит правила округления сроков, примеров и внутренней служебной логики.
31. Нижний блок общих работ — таблица без поясняющих абзацев; строка `Итого`, условия оплаты и ссылки набраны 12 кеглем.

Негативные сценарии:

1. Прикреплён только Excel: использовать встроенный шаблон, не запрашивая Word-файл.
2. В расчёте нет выбранных работ: сообщить об этом и не создавать фиктивные строки или результаты из каталога работ.
3. В Excel нет этапов и сумму Этапа 2 нельзя найти однозначно: запросить только сумму Этапа 2 либо по явной просьбе создать черновик с точечным маркером.
4. В обязательном поле есть `TBD` или `Указать ...`: запросить данные либо по явной просьбе создать черновик с маркером уточнения.
5. В Excel нет подтверждённого примечания этапа: не придумывать текст для ячейки примечания.
6. У выбранной работы пустой «Образ результата», но есть название работы: использовать это точное название вместо молчаливого исключения строки.
