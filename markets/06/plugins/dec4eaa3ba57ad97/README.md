# FinGrad Appendix Generator

Публичная skills-only сборка для подготовки полного Приложения №1 к коммерческому предложению.

Пользователь прикрепляет к текущему чату Excel-файл с расчётом тарифа. Плагин заполняет встроенный полный чистый шаблон Приложения №1: постоянный текст, блоки цели, состава проекта, оплаты, подписки, результатов, организации и поддержки сохраняются. Собственный Word-шаблон можно прикрепить дополнительно, если нужно сохранить именно его оформление.

Плагин использует только явно прикреплённые к текущему чату материалы и встроенный пустой шаблон. В пакет не включены клиентские расчёты или заполненные приложения.

Перед генерацией плагин выделяет профиль текущего клиента и проекта из Excel: юридическое лицо, направления проекта, этапы, результаты, источники данных, условия и специальные требования. Блоки, которые не подтверждены текущим расчётом — например ДиректБанк, подписки, банки, интеграции и логотип клиента — не переносятся из прошлых приложений и не добавляются по умолчанию.

В таблице этапов есть отдельная колонка с отображаемыми номерами `1…N`; в последней колонке таблицы результатов — только соответствующий номер этапа. Пустые этапы с нулевыми показателями не выводятся, а продолжительность в месяцах округляется вверх до 0,5 месяца. Для выбранной работы переносятся полный результат, дополнительные данные, количество, комментарии, ограничения и требования из Excel без сокращения. «Администрирование проекта» выносится в отдельный нижний блок для этапов 2…N. Когда этапы не определяются, используются только «Предпроект» (этап 1) и «Этап 2» (этап 2) с подтверждённой суммой второго этапа.

Титульная страница получает один большой логотип ФинГрада и место для логотипа клиента; компактный логотип в шапке начинается со второй страницы. Если в Excel нет клиента, даты старта или условий оплаты, плагин не запрашивает их: извлекает клиента из имени Excel-файла, ставит первый день следующего месяца и условия `50% предоплата / 50% после завершения работ`. Эти автоматически подставленные значения выделяются жёлтым для проверки. Первая таблица сохраняет видимую сетку; в матрице результатов одинаковые сведения не дублируются между результатом и дополнительными данными. Администрирование, обучение и документация при наличии собираются в отдельную общую таблицу для этапов 2…N, а этапы в основной матрице разделяются толстой линией.
