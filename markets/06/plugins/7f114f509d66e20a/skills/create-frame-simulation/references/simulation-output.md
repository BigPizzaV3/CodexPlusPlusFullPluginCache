# Printable simulation worksheet

Produce a clean, logo-free A4 portrait PDF with three pages.

## Page 1 — Learning notes

- Example title, laterality and learning objective.
- Teaching notes about circular-fixation principles and construct geometry.
- Exact simulated construct in proximal-to-distal order.
- The required educational disclaimer.

## Page 2 — 2D construct simulation

- Use generic anatomy by default. If supplied, use the de-identified teaching AP radiograph as an underlay and the lateral view for orientation context.
- Show only requested supports, wires, half-pins, Rancho posts and connectors.
- Fine wires visibly cross the generic bone. Half-pins visibly engage it.
- Draw each 2/3 ring as a true approximately 240° open arc with no chord, band or plate across the open sector.
- Draw Ilizarov rods longitudinally, trauma struts as a separate oblique class, and a hexapod interval with six oblique struts.
- Label supports R1 onward from proximal to distal, including 2/3-ring rotation and connector class.

## Page 3 — 3D simulation view

- Include the verified interactive 3D simulation view and a concise construct table.
- Invite comparison of frame clearance, fixation divergence, opening orientation and connector geometry.
- State that the model is schematic.
- Include the required educational disclaimer.

## Learning checks

- Keep questions and observations separate from the applied construct.
- Prefix unresolved geometry or measurements with `CHECK`.
- Record alternatives as comparisons, not recommended actions.
