# LexMount 云浏览器 1.1.19

使用 LexMount 云端浏览器完成网页浏览、信息提取、点击交互、表单填写和登录后的自动化任务；按需截图、导出 PDF 或下载文件。

通过官方 browser-cli 1.2.1 使用 LexMount 云浏览器。支持 macOS arm64、
Linux x86_64、Windows x64；包内不含二进制、凭据或网站 Cookie。

修复 ChatGPT Work 的启动目录兼容性：Linux 依赖安装在用户缓存目录，
通过共享入口运行，不在插件/config 目录执行 CLI。保留 macOS、Windows 的
既有本地登录方式。不会修改系统挂载或执行策略。

云端首次使用需要独立授权。本版提供 PKCE 授权助手：用户下载后在本机
用 Python 3 运行并确认授权，再上传一次性授权结果文件。它不复制本地已有
凭据，也不是点击插件即可完成的原生 MCP OAuth。暂不保证跨任务持久化。

使用示例：“打开 https://example.com，告诉我主要内容，并列出页面上的链接。”

交互示例：“打开 Selenium 演示表单，把 Text input 填成‘浏览器测试’，核对填写结果，先不要提交。”

根据任务交付文字、结构化信息、操作结果或文件。截图是可选能力，不作为所有任务的默认产物。

安装格式校验、真实云端验收与市场发布状态分别记录在包外验收报告中。
