Research date: 2026-09-23

## OpenAI plugin packaging

- Build skills:
  https://developers.openai.com/plugins/build/skills
- Package plugins:
  https://developers.openai.com/plugins/build/plugins
- Submit plugins:
  https://developers.openai.com/plugins/deploy/submission
- Submission validation:
  https://developers.openai.com/plugins/deploy/submission-errors

Current public-directory rules include:
- display name up to 30 characters;
- short description up to 30 characters;
- long description up to 4,000 characters;
- up to 20 capabilities, each up to 120 characters;
- up to 3 starter prompts, each up to 128 characters;
- skill frontmatter with `name` and `description`;
- combined plugin/skill identity up to 64 characters.

## Google Technical Writing

- Technical Writing:
  https://developers.google.com/tech-writing
- Technical Writing One summary:
  https://developers.google.com/tech-writing/course-summaries/one
- Active voice:
  https://developers.google.com/tech-writing/one/active-voice
- Lists and tables:
  https://developers.google.com/tech-writing/one/lists-and-tables

Durable guidance:
- know the audience;
- state key points early;
- use terms consistently;
- prefer active voice where appropriate;
- focus sentences/paragraphs;
- remove unneeded words;
- use lists/tables when they improve structure.
