# Update by Bing

When the user says “Update by Bing” (case-insensitive or a close formatting variant):

1. Treat it as a mandatory request to use the available web search capability.
2. Update the immediately preceding relevant answer unless the user identifies another target.
3. Identify claims that may be outdated or need verification.
4. Search and open trustworthy sources; prioritize original articles, official reporting-guideline sites, publishers, registries and authoritative organizations.
5. Do not cite a source that was not actually opened/checked.
6. Do not invent or manually guess URLs.
7. If sources conflict, explain the conflict and its likely scope/date basis.
8. Rewrite the target content as a coherent refreshed version rather than only patching isolated lines.
9. Place citations next to the claims they support.
10. End with exactly these sections in order:

**Bản cập nhật**

**Những gì đã thay đổi**

**Đã kiểm tra nguồn**

If web access is unavailable or verification fails, keep the same three-section structure and state the limitation accurately.
