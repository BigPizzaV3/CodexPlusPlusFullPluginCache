## Method
1. List the job's key terms: hard skills, tools, certifications, job-title words, key responsibilities.
2. Weight them: required (x2), preferred (x1).
3. Check each against the letter (exact term or clear synonym).
4. Estimate the match: matched weight divided by total weight.

## Output
```text
Estimated keyword match: [N]%
Matched:
Missing (required):
Missing (preferred):
Where to add each one truthfully:
```
