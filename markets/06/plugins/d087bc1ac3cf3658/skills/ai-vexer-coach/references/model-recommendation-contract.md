# 작업 전 모델·추론강도 추천 계약

모델 판정표와 호스트 선택지 연결은 SKILL.md 한 곳에서 정의한다. 이 참조는 확장 경계이며 첫 추천 전에 읽지 않는다. 인사·단순 사실·일반 설명에는 활성화하지 않는다.

## 순서와 정보의 출처

`안전 → 질문·충돌 해소 → 모델 판정 → 작업`을 한 번 수행한다. 다른 실행 스킬을 사용할 때도 작업공간 조사·파일 읽기 전에 모델 판정을 먼저 끝낸다. 현재 후보 SKILL.md 진입점 발견·로드는 판정에 필요한 정상 경로다.

- 사용자의 현재 모델 지정·강도 지정·진행 선택을 먼저 반영한다. 이전 선택은 같은 범위에 한해서 유지한다.
- 호스트의 가용 목록은 그 목록이 적용되는 대상에서만 사용한다. 다른 작업 생성 도구의 모델 목록으로 현재 작업의 선택 가능 여부나 현재 모델을 확정하지 않는다.
- 공개 모델 문서는 일반 기능 설명이며 특정 계정의 접근 증거가 아니다. 런타임에 인터넷을 조회해 목록·가격을 자동 갱신하지 않는다. 호스트가 제공한 모델 ID·표시명·지원 강도를 그대로 사용한다.
- 목록과 현재 설정을 구분한다. 현재 설정을 모르면 추측하지 않으며 자동 전환·실제 적용·비용 절감을 주장하지 않는다.

## 표시와 진행 선택

일반 / medium은 조용한 기본값이다. 확인된 비기본 조합만 작업 전에 한 문장으로 추천하며 이후 현재 작업을 계속한다. 후속 행동에는 기본 수준도 설명하지만 실제 모델·강도가 미확인이면 필요한 수준과 설정 미확인 상태만 표시한다.

심층 수준에서만 SKILL.md의 정지 조건을 적용한다. `추천 설정으로 바꾼 뒤 계속`과 `현재 설정으로 계속`은 모델명이 확인된 경우에 쓰고, 가용 목록이 없으면 설정 확인 선택지로 바꾼다. 모델을 바꿀 수 없다는 사실만으로 경량·일반 업무를 중단하지 않는다. 사용자의 명시적 모델 선택이나 현재 설정 진행 선택이 있으면 같은 추천을 반복하지 않는다. `모델 추천 없이 진행`이라는 사용자 지시도 따른다.

최초 사용자 선택 전에는 참조 읽기·도구 호출·파일 분석·변경·완성 답변·Plan을 만들지 않는다. 이 제한은 정지 조건에 해당하는 심층 작업에만 적용한다. 호스트가 필요한 설정을 명시했거나 사용자가 현재 설정 진행을 선택한 뒤에는 실행을 이어간다.

호스트의 상위 정책·현재 사용자 선택은 제품 추천 기본값보다 우선한다. 지원하지 않는 추론강도를 임의 보정하거나 모델 세대 숫자로 성능·이용 가능성을 추정하지 않는다. `none`·`max`·`ultra`는 자동 추천하지 않는다. 후속 제안은 실행 승인이나 모델 자동 전환이 아니며 완료 후 모델 선택을 다시 평가하지 않는다.

## 확인 경계

이 계약은 추천과 진행 결정을 위한 지침이며 모델을 실제 변경하는 코드가 아니다. 서로 다른 모델에서의 품질 동등성·속도·사용량 절감은 별도 통제된 비교 없이는 확인되지 않는다. 후속 행동은 [next-action-contract.md](next-action-contract.md), 실행은 [host-execution-contract.md](host-execution-contract.md)를 따른다.
