# 다음 행동의 모델 계약

현재 결과에서 필요한 다음 행동을 제안할 때만 적용한다. 다음 행동을 만들기 위한 추가 질문이나 새 업무는 만들지 않는다.

- AI가 할 후속 작업은 `행동 — 기대 결과 — 권장 모델 / 추론강도`의 의미를 한 문장 또는 항목 안에 연결한다. 표현 형식은 고정하지 않는다.
- 모델은 SKILL.md의 같은 판정표로 후속 작업 자체의 범위·위험·검증 부담을 평가한다. 현재 작업의 모델을 그대로 붙이지 않는다.
- 후속 AI 작업에는 조용한 기본값인 일반 / medium도 표시한다. 현재 작업의 사전 기본 추천 생략과 후속 표시를 구분한다.
- 사람의 승인·확인·자료 제공에는 모델을 붙이지 않는다. 사람과 AI 작업이 모두 필요한 경우 책임과 행동을 분리한다. 후속 작업이 없거나 사용자가 원하지 않으면 다음 행동을 생략한다.
- 다음 행동 제안은 자동 실행·자동 전환이 아니다. 후속 심층 작업을 제안하는 것만으로 현재 결과 전달을 멈추지 않는다. 사용자가 해당 실행을 요청하면 범위를 대조하고 실제 심층 게이트를 적용한다.
- 같은 작업과 같은 추천은 반복하지 않는다. 실질 범위 변경으로 권장 설정이 달라지면 작업 전에 재판정한다. 앞서 받은 현재 설정 진행 선택은 같은 범위에서 유지한다.
- 사용자가 해당 업무에서 모델 추천을 원하지 않으면 후속 모델 표시도 생략한다. 사람이 실행할 행동은 계속 설명할 수 있다.
- 권장 모델의 계정별 이용 가능 여부나 현재 설정을 추측하지 않는다. 호스트가 해당 대상에 대해 명시한 선택지에서만 모델·지원 강도를 명명한다. 미확인이면 필요한 작업 수준과 설정 미확인 상태를 표시한다. 사용할 수 없는 모델을 자동 대체·상향하지 않는다.

## 효율의 의미

경량·일반의 비기본 설정은 추천 후 계속하므로 현재 작업의 모델 변경이나 절약을 보장하지 않는다. 관찰 가능한 사용량이 없는 경우 절감률을 말하지 않는다. 품질·질문 왕복·재작업과 사용량을 함께 보는 통제된 검증으로만 효율을 평가한다.
