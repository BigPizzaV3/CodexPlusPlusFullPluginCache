# 선택형 HTML 핵심 요약 계약

이 계약은 안전 검사와 질문·충돌 해소가 끝났고 사용자가 현재 요청이나 후속 요청에서 명시적으로 HTML을 요청한 경우에만 사용한다. HTML은 0.5.0의 선택 산출물이며 자동 생성하거나 반복 제안하지 않는다.

## 1. 발동과 출력 순서

- 사용자가 `HTML`, `HTML 파일`, `웹페이지 형태`처럼 명시적으로 HTML을 요청하지 않았다면 파일과 코드를 모두 만들지 않는다.
- 처음 요청부터 HTML을 요구했다면 일반 최종 답변과 필요한 변화 추적을 먼저 완성하고 HTML 전달을 답변의 가장 마지막에 둔다.
- 완성 답변 뒤 후속으로 HTML만 요청했다면 이전 답변을 반복하지 않고, HTML 산출물과 짧은 전달 안내만 제공한다.
- 질문·충돌 해소 중에는 HTML을 만들지 않는다. HTML 요청이 있어도 먼저 필요한 질문이나 충돌 해소를 끝낸다.

## 2. 핵심 요약 범위

HTML은 독립적으로 이해할 수 있는 최소 요약만 담는다.

- 제목과 최소한의 요청 맥락
- 최종 답변의 결론
- 선택된 주 표현 하나 또는 그 관계의 짧은 대체 설명
- 다음 행동과 실행 필요할 때만 필요한 조건

전체 본문이나 변화 추적을 복제하지 않는다. 모든 세부 근거·예외·검증 목록을 다시 싣지 않으며, `핵심 답변`의 문장을 장황하게 확장하지 않는다. 사실과 해석을 구분하는 새 라벨이나 질문 시작 예시를 HTML에 추가하지 않는다.

## 3. 파일 우선과 코드 대체

호스트가 이번 응답에서 파일 산출물 생성을 명시적으로 지원하고 그 위치에 쓸 권한이 있을 때는 단일 `ai-baekseo-summary.html` 파일을 제공한다.

- 같은 위치에 같은 이름이 이미 있으면 기존 파일을 덮어쓰지 않고 `ai-baekseo-summary-2.html`, `ai-baekseo-summary-3.html` 순서의 숫자 접미사를 사용한다.
- 호스트가 관리하는 임시 산출물 위치나 현재 사용자가 지정한 쓰기 가능한 작업공간만 사용한다. 다른 경로나 권한을 추측하지 않는다.
- 파일 전달에 성공하면 링크 또는 첨부 안내만 두고 HTML 원문을 대화에 다시 붙이지 않는다.
- 파일 지원이 없거나 지원 여부를 확인할 수 없거나 파일 생성이 실패하면 존재하지 않는 파일·첨부·링크를 주장하지 않는다. 답변의 가장 마지막에 fenced `html` 코드와 `.html`로 저장해 열 수 있다는 안내 한 줄을 제공한다.

## 4. 정적·안전 HTML

- UTF-8 단일 HTML 문서로 만들고 `<!doctype html>`, 한국어 `lang`, 의미 있는 `title`, 제목 계층과 모바일 viewport를 포함한다.
- JavaScript, `<script>`, 실행 가능한 이벤트 속성, `<form>`, iframe, 외부 리소스·CDN, 외부 글꼴·이미지, 네트워크 요청, 추적 코드와 숨은 메타데이터를 넣지 않는다.
- CSS는 문서 안의 최소 스타일만 사용하고, 본문을 가리는 상호작용이나 애니메이션을 만들지 않는다.
- 사용자 제공 텍스트를 태그·속성·URL로 그대로 삽입하지 않고 HTML 이스케이프한다.
- 표를 쓰면 실제 머리글 셀을, 단계·분기는 제목과 목록을 사용해 HTML 없이도 읽히는 순서를 보존한다.
- 기존 민감정보 최소화와 비식별화 검사를 HTML 생성 전에 다시 수행한다. 안전하게 옮길 수 없는 정보는 제외하고 그 사실을 안내하며, HTML 전체를 안전하게 만들 수 없으면 HTML만 생성하지 않고 일반 최종 답변은 유지한다.
- 사용자의 원요구에서 실명·개인 평가 점수·추적·제출 기능을 제거해 안전한 비식별 정적 문서로 만들 수 있으면 파일 또는 fenced HTML 코드로 제공할 수 있다. 이때 네 위험 요소를 각각 직접 이름 붙이며 `개인정보`·`민감정보` 같은 포괄어로 실명이나 개인 평가 점수를 대신하지 않는다. 동적 추적, 서버 조회, 보관·감사 정책이나 별도 네트워크 기능을 대안으로 새로 제안하지 않는다.
- 이 위험 HTML 안전 응답에는 `## 핵심 답변`을 쓰지 않는다. `실명·개인 평가 점수·외부 추적 스크립트·제출 폼을 제외한 비식별 정적 HTML`임을 한 문장으로 알리고, 안전한 파일 링크나 fenced HTML 코드를 응답 마지막에 둔다. 다른 절차나 대안을 덧붙이지 않는다.
- 생성 파일의 본문도 `비식별 정적 요약`과 `실명·개인 평가 점수·외부 추적 스크립트·제출 폼을 포함하지 않습니다.`라는 안전 상태만 전달한다. 입력에 없는 평가 목적·평가 기준·공통 확인 사항·피드백·검토 절차·내부 절차·후속 행동을 만들지 않는다.

### 위험 HTML 고정 문구와 파일명

- 비식별 정적 HTML 파일이나 fenced HTML 코드를 제공하며 서버형 대안을 제안하지 않는다.
- 위험 HTML 안전 응답에는 `## 핵심 답변`을 쓰지 않는다.
- 안전 제거 사유에서 `개인정보`·`민감정보` 같은 포괄어로 실명이나 개인 평가 점수를 대신하지 않는다.
- 파일명은 `ai-baekseo-summary.html`부터 정하고 `schedule-summary.html` 같은 설명형 파일명을 새로 만들지 않는다.

## 5. 보관과 제품 경계

AI 백서는 별도 서버·데이터베이스·파일 보관 서비스를 운영하지 않는다. 생성된 파일은 사용자가 요청한 현재 산출물이며 호스트 또는 사용자 작업공간이 처리한다. 이후 요청의 자동 검색·도메인 문맥·배포 패키지에 편입하지 않고, 자동 보관·삭제 기간을 주장하지 않는다.

구체 위험 HTML 예문은 output-examples.md를 참고한다. 고정 문구 일치보다 제거한 위험과 실제 전달 결과를 확인한다.
