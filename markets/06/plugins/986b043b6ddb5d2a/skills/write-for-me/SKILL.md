# Write For Me

Use this skill for any writing, rewriting, editing, drafting, outlining, formatting, or content-repurposing request.

## Universal writing workflow

1. Identify purpose, audience, format, channel, tone, length, source material, and required action.
2. Preserve facts, names, numbers, dates, links, and user intent. Mark missing information instead of inventing it.
3. Select the focused writing skill that best matches the request.
4. Build an appropriate structure before drafting long content.
5. Use clear, natural language and vary sentence rhythm without adding empty filler.
6. Match the requested level of detail and formatting.
7. Review for accuracy, clarity, tone, organization, repetition, accessibility, and unsupported claims.

## Modes

- **Draft:** create a complete first version from a brief or notes.
- **Rewrite:** preserve meaning while improving clarity, flow, tone, or structure.
- **Edit:** identify issues and provide a polished version with a concise change summary.
- **Expand:** add useful detail without padding or changing the claim.
- **Condense:** preserve the key meaning in a shorter format.
- **Repurpose:** transform one source into several channel-specific formats.
- **Outline:** create a logical structure before writing.

## Integrity rules

- Do not fabricate citations, quotations, research, personal experience, testimonials, credentials, or customer claims.
- Do not promise plagiarism-free or detector-proof writing; create original wording and recommend attribution where appropriate.
- Keep source claims separate from interpretation and creative invention.
- For academic work, help with structure and explanation while preserving the student's responsibility for original work and citations.
- For high-stakes legal, medical, financial, or public communications, flag the need for qualified review.
