# By format — formats-tv

The 6 formats defined in `formats-tv.md`, with every card each one can use. Built 2026-09-18 00:18. Compiled by hand from the format kits; there is no generator behind this file, so it is edited directly like any other craft file.

**Ranked in the kit** comes from the kit itself, so a card the kit ranks is listed even when it does not carry that format tag: a kit is often finer grained than a tag, and kit membership is not the same claim as tag applicability. **Also tagged** is everything else tagged as applicable but not ranked. A card id names its own lookup file **only when that id's category lives in this phase** — `char.desire_made_physical` is in [`LOOKUP-char.md`](LOOKUP-char.md) and `end.callback` is in [`LOOKUP-end.md`](LOOKUP-end.md). Ids from other phases have no lookup file in this directory: there is no LOOKUP-voice.md, LOOKUP-dial.md or LOOKUP-lyric.md beside these kits, so `voice.confiding_voice`, `dial.repetition_variation` and `lyric.congregational_lyric` cannot be resolved here. For those, and whenever you are unsure which phase an id belongs to, use [`CARD-INDEX.md`](../CARD-INDEX.md) at the package root — it lists every id in the package against the file that holds it.

Cards that apply to every format are listed in the dedicated format routers (`by-format-film.md`, `by-format-doc.md`, etc.) or the category files (`cat-*.md`) and are not repeated here.
