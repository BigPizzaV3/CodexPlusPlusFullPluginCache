# The Master Grimoire

The visual world-building canon for Mesopotamia and its neighbours. **This file is the master.**
It was converted in September 2026 from a 72-page PDF export that contained no images, only text,
so the PDF held nothing this file does not. The PDF was retired on 2026-09-13 because regenerating
from it silently overwrote hand corrections. Edit this file directly; nothing regenerates it.

Every civilisation is documented under the same eight headings, which is what makes this a lookup
rather than a book:

1. Environment, Flora & Fauna
2. Architecture & Infrastructure
3. Demographics & Physical Traits
4. Fashion & Textiles
5. Economy & Daily Life
6. Religion & Art
7. Transport & Mobility
8. The Military Machine
