## 7 — Light and Colour


### 7.1 Lighting Systems

| System | What it does | Where |
|---|---|---|
| High Key | bright, safe, shadowless | comedy, children, advertising, instruction |
| Low Key | shadow governs, danger, mystery | horror, crime, noir, thriller |
| Motivated Naturalism | a real in-scene source | drama, documentary |
| Chiaroscuro | extreme contrast, light against dark | mystery, religious, noir |
| Backlight / Rim | separates the subject, halo, mystery | the hero, epic, an arrival |
| Silhouette | concealed identity, symbolism | heritage (hidden faces), mystery, endings |
| Practicals | lamps visible inside frame | realism, night, intimacy |
| Volumetric / God Rays | visible beams in dust | temple, forest, sanctity, epic |
| Golden Hour | warmth, longing, beauty | romance, heritage, endings |
| Blue Hour | solitude, cold, transition | grief, early night |
| Moving Light | fire, candle, a passing car | tension, life |

**Prompt:** `low-key lighting, single motivated practical lamp, deep shadow filling two-thirds of the frame, volumetric haze`

---

### 7.2 Colour

| Strategy | What it does |
|---|---|
| Complementary (orange / teal) | the Hollywood default; separates subject from background |
| Monochromatic | immersion, one governing mood |
| Analogous | harmony, calm |
| Hyper-saturated | fantasy, music video, dream, children |
| Desaturated | harshness, war, realism, despair |
| Colour Accent | red in a grey frame — directs the eye and carries symbolism |
| Colour Arc | the work opens in one palette and closes in another |

**The secret:** bind each character to a colour, then swap the colours between them in Act III.
The viewer reads the reversal without anyone explaining it.
