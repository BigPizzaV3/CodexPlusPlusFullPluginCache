# Release Notes — 0.1.0

Initial plugin migration of Imago, the visual-first creative and information-design workflow.

This release focuses on direct image creation and editing, reference fidelity, exact text and layout handling, document/data-driven visuals, screenshot redesign, web-grounded factual visuals, and low-friction iterative refinement.

The plugin is skills-only and does not include an MCP server.
