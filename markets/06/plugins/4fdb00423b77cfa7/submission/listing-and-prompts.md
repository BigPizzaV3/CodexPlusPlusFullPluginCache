# Public Listing

## Name
Imago

## Subtitle
Create & edit polished visuals

## Category
Creativity

## Description
Imago is a visual-first creative and information-design copilot for generating, editing, redesigning, and transforming images directly in ChatGPT. It can turn prompts, reference images, screenshots, sketches, documents, presentations, and datasets into polished posters, infographics, diagrams, dashboards, UI concepts, social graphics, slides, maps, storyboards, product visuals, concept art, and focused image edits. It prioritizes direct visual output over prompt-writing, preserves requested reference details during edits, keeps text intentional and readable, and uses verified source data for factual or data-driven visuals instead of inventing numbers.

## Capabilities
- Generate polished visuals directly from plain-language creative briefs
- Edit existing images while preserving everything the user did not ask to change
- Use reference images for identity, product, style, composition, and layout guidance
- Turn documents, screenshots, presentations, and datasets into visual deliverables
- Create posters, infographics, diagrams, dashboards, UI concepts, slides, maps, and social graphics
- Keep requested text, spelling, hierarchy, placement, and visual branding intentional
- Choose a sensible aspect ratio from the requested output when the user does not specify one
- Research current facts before creating factual, location-based, or time-sensitive visuals
- Avoid fabricating numbers, labels, quotes, statistics, or claims in data-driven graphics
- Support iterative edits and multi-turn visual refinement while minimizing unwanted drift

## Starter prompts
1. Turn this document into a clean visual infographic.
2. Redesign this screenshot into a polished modern interface.
3. Edit this image: change only what I ask and preserve everything else.
