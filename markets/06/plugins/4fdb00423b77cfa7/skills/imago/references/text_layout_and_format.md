# Text, Layout, and Output Format

## Exact text

When the user supplies text:
- reproduce it exactly;
- preserve capitalization/punctuation unless correction is requested;
- keep names, URLs, dates, units, and numbers exact;
- do not add marketing copy by habit.

## Typography

For important text:
- keep a clear hierarchy;
- use sufficient size/contrast;
- avoid overcrowding;
- avoid placing key copy over noisy regions;
- use a small number of deliberate type styles.

## Dense information

For large information sets:
- group into sections;
- prioritize the most important facts;
- use labels and visual structure;
- split into multiple visuals when one canvas would become illegible.

## Common aspect choices

These are defaults, not rules:
- square social graphic → 1:1;
- portrait social/poster → 4:5;
- story/phone wallpaper → 9:16;
- slide/video/desktop hero → 16:9;
- print/document visual → match requested page orientation.

Honor an explicit user ratio over these defaults.

## Transparent backgrounds

When transparency is requested:
- isolate the intended object/mark;
- avoid unintended background pixels;
- keep edges clean;
- do not add a decorative backdrop.
