# Reference and Editing Fidelity

## Reference roles

Identify what each image is for.

### Identity / subject
Preserve recognizable facial and physical identity, wardrobe/props when required, and defining traits.

### Product / object
Preserve geometry, materials, proportions, labels, and marks that matter.

### Style
Borrow palette, lighting, texture, medium, visual density, or mood without treating unrelated subjects as required content.

### Composition
Use framing, placement, negative space, camera/view, or layout as structural guidance.

### Edit source
The source itself is the thing being modified.

### Sketch / layout
Treat the reference as a structural plan, not a request to preserve every visual detail.

## Local edit principle

For a targeted edit:

> Change the requested element; preserve unrelated content.

Before editing, identify:
- requested change;
- preservation set;
- region/object affected;
- exact text/branding constraints;
- whether geometry/composition must remain fixed.

## Multi-turn continuity

After an accepted result:
- treat it as the new visual baseline;
- preserve its established identity, composition, palette, typography, and world-building unless asked otherwise;
- make incremental edits when possible.

## Drift checks

Common unwanted drift:
- face changes;
- product geometry changes;
- logo/text changes;
- altered crop or camera angle;
- added objects;
- wardrobe changes;
- palette changes;
- background changes;
- changed number of subjects.

Restate preservation constraints internally before the next edit.
