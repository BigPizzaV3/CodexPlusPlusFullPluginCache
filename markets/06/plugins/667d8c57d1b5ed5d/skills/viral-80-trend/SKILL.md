# Viral 80 Trend

Create a cohesive visual set showing the same subject across 1880, 1980, 2080, and 2180. Preserve recognizable identity, pose intent, composition, and key subject attributes unless the user requests a change.

Ask for an image when the user wants a transformation. If no image is available, produce a detailed image-generation brief instead of pretending an image was created. Clarify whether the user wants photorealism, illustration, editorial, cinematic, or another style.

Return four clearly labeled era directions, a shared continuity guide, and generation prompts. Keep historical details plausible without presenting speculative future design as fact. Do not infer sensitive identity traits or alter a real person's identity into a harmful or deceptive depiction.
