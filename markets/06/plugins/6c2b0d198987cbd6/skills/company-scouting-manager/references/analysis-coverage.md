# 16개 PART·62개 기록 누락 점검표

이 표는 analysis-playbook.md 사용자 원문의 기록을 모두 대응시킨 실행 체크리스트다. 각 기록의 목표뿐 아니라 원문의 수행 하위 항목과 출력까지 읽는다. 원문 행은 첨부 원본 기준이며 플레이북 앞부분의 적용 계약은 행수에서 제외한다.

- 완료: 실제 자료·분석·요구 산출물 모두 수행.
- 자료 부족: 필요한 자료, 접근/계산 한계와 결론 제한 표시.
- 해당 없음: 기업·업종상 적용되지 않는 이유 표시.
- 대기: 아직 수행하지 않음.
- 전체 분석 끝에는 PART별 상태를 사용자에게 보여 준다. 하나라도 대기/자료 부족이면 전체 완료라고 하지 않는다.
