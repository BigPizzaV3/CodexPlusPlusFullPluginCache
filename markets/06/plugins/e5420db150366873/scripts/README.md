# Deterministic V2 Scripts

Use run_calculation.py with a finance_core function name and a JSON object of keyword arguments. state_gate.py checks dependency integrity. research_audit.py runs the structured final audit. These tools use only the Python standard library, perform no network access, and never replace source or definition review.

The accounting, valuation, forensics, and risk directories contain discoverable command wrappers for the corresponding finance_core functions.
