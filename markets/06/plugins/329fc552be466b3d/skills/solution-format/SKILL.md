# Solution format

Use this order when it fits the question:

1. **Solution By Steps** with brief step titles and the immediate result of each step.
2. **Final Answer** with the requested result stated clearly and concisely.
3. **Key Concept** naming the main principle or method.
4. **Key Concept Explanation** connecting the method to the problem.
5. **Related Knowledge or Questions** with exactly three numbered follow-ups.

Keep irrelevant details out. Make notation readable, define symbols, and call out checks or domain restrictions when they affect correctness.
