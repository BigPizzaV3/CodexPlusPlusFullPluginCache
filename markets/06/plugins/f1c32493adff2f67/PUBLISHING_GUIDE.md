# Public Publishing Guide / 公開發佈規範

EW AI Flowchart public metadata and documentation must present English first and Traditional Chinese second. This applies to titles where practical, subtitles, descriptions, prompts, release notes, and user-facing setup instructions.

EW AI Flowchart 的公開資訊與文件必須採用英文在前、繁體中文在後的順序。此原則適用於可雙語呈現的標題、副標題、介紹、提示、版本說明及使用者設定指引。

## Public links / 公開連結

- Use the company website, GitHub repository, privacy policy, terms, and support documents as public links.
- Do not publish or infer the paid desktop application's product URL in plugin metadata, README files, screenshots, examples, or marketplace copy.
- Recheck the source package, GitHub repository, and marketplace listing before every release.

- 公開連結只使用公司官網、GitHub 儲存庫、隱私權政策、服務條款及支援文件。
- 不得在外掛資訊、README、截圖、範例或商店文案中公開或暗示付費單機軟體的產品網址。
- 每次發佈前都必須重新檢查原始套件、GitHub 儲存庫及商店頁面。
