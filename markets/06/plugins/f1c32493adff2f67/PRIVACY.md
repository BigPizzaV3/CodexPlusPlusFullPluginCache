# Privacy Policy — EW AI Flowchart

Effective date: 2026-09-15  
Developer: 具象職人股份有限公司 (Embodied Worker Co., Ltd.)

EW AI Flowchart is a skills-only plugin that helps users convert supplied process descriptions and documents into validated EFD 2.1 JSON.

## Data handled

The plugin may process text, documents, workflow descriptions, organizational information, and existing EFD JSON that a user deliberately provides in a ChatGPT or Codex conversation. Users should not provide passwords, API keys, payment information, or personal data that is unnecessary for workflow modeling.

## Developer data collection

The plugin package does not contain an independent analytics service, advertising tracker, remote database, or developer-operated API endpoint. It does not ask for or store API keys. The deterministic validator reads only the file selected by the user and outputs validation diagnostics in the active execution environment.

具象職人股份有限公司 does not receive conversation content merely because this plugin is installed or used. Processing performed by ChatGPT, Codex, OpenAI services, the user's device, or a user-selected third-party service remains subject to the applicable provider's privacy terms and account settings.

## Storage and sharing

The plugin does not independently upload generated EFD JSON or source documents to a developer-operated server. Files are shared externally only when the user explicitly chooses to upload, publish, send, or connect them through another service.

## User responsibility

Users are responsible for having authority to process supplied business documents and for removing unnecessary confidential or personal information before sharing or publishing generated artifacts.
