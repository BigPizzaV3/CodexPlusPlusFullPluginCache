## Step 1: Pick the method
| Situation | Method |
|---|---|
| Existing product with history | Trend and seasonality, moving averages, growth rates |
| New product | Analogues (similar products), bottom-up funnel, adoption curve |
| Market-level view | Driver-based model (customers × adoption × spend) |
| Short-term planning | Recent run rate with seasonal index |

## Step 2: Build the model
- State the base period and data.
- Apply growth rates or drivers with each assumption labeled.
- Add seasonality indexes from past data or search seasonality.
- For new products, use a funnel: reach → interest → trial → repeat.

## Step 3: Scenarios
Give low, base and high cases, and list the events that would move results between them.

## Step 4: Output
A forecast table by period, the method in plain words, a chart description or chart if tools allow, key assumptions and a monitoring plan (which metrics to watch monthly). Forecasts are estimates; present them with ranges, not false precision.
