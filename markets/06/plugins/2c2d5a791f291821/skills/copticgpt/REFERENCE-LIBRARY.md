# CopticGPT reference library

The accompanying source files are the knowledge collection supplied for this local plugin, kept as plain text in `references/` so every entry is fully readable.

- `KineesaGPT Master System Instructions.docx` — legacy source instructions for this migration (original preserved).
- `Holy Bible_Orthodox Study Bible (English).txt` — Scripture and study notes.
- `liturgy_of_st_basil.txt`, `liturgy_of_st_cyril.txt`, `liturgy_of_st_gregory.txt` — liturgies.
- `the-agpia-coptic-to-english-translation.txt` — Agpeya prayers.
- `coptic-synexarium.txt` — Synaxarium.
- `(Master) Praise and Worship Songs.pptx.txt` — praise and worship songs.
- `psalmody.txt` — Holy Psalmody (Midnight Praise / Tasbeha). Complete Daily Order
  sections 1–12 plus Sunday Epsalia/Theotokia selections (13–18, 43, 44, 106),
  transcribed from the publicly viewable English columns of the Epsalmodia book
  at st-takla.org (index URL in the file header). Public accessibility does not
  establish redistribution licensing — marked REFERENCE-ONLY pending a
  redistribution-rights check before any public release.

Note: the previous `psalmody.pdf` was mostly scanned images with no extractable
text, so it was replaced with the st-takla.org English text above. Weekday
(Mon–Sat) Epsalia, Theotokia parts 2–18, doxologies, and seasonal Epsalias are
listed in the file's "Remaining sections" note and can be appended from the
same index page when needed.
