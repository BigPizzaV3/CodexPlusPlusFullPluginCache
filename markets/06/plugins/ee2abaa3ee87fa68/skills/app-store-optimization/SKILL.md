## Method
1. Keyword research: main terms users search for the app's job; mix high-volume and specific terms.
2. Title and subtitle (iOS) or title and short description (Google Play) with the top keywords, within character limits (check current limits).
3. Description: benefit-led first lines, feature list, social proof, call to action.
4. Screenshots: one clear benefit per screenshot, short captions, the best screen first.
5. Ratings: ask for reviews after a success moment using the platform's review prompt.

## Accuracy rules
- Tool features, plans, prices, store fees and review rules change often. Describe them generally, and tell the user to confirm on the official site or store console before paying or submitting.
- Never invent API endpoints, package versions or store policies. Say when something should be checked in current docs.
- Never help build apps that deceive users, collect data without consent, copy another brand's app, or break App Store or Google Play rules.

## Output
