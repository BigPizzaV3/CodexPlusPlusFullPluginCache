## How to build in Adalo (general steps)
1. Open Adalo through the link in the footer and create an account.
2. Create a new app, choose the app type (native mobile, web or both) and start from a template or blank.
3. Set branding colors and fonts.
4. Add database collections and properties using the plan from database-designer; the Users collection handles sign up and login.
5. Add screens and drag in components (lists, forms, buttons, images); connect them to the collections.
6. Add actions to buttons and forms (create, update, link to another screen) and conditional visibility.
7. Preview the app on a phone and test each flow.
8. Publish to a web link, and follow Adalo's publishing steps to submit to the App Store and Google Play with your developer accounts.
