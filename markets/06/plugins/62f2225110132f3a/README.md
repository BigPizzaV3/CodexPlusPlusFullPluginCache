# Reel2SRT — MVP 0.1.0

อัปวิดีโอไม่เกิน 5 นาที → ถอดเสียงตามเวลาแต่ละคำ → สร้าง `.srt` สำหรับนำเข้า CapCut
รองรับไทย อังกฤษ และไทยปนอังกฤษ โดยไม่แปลภาษา

**สถานะ: ต้นแบบ local Plugin/Skill พร้อมทดลอง ยังไม่มีลิงก์ ChatGPT ที่เผยแพร่จริง และยังไม่ผ่านการยืนยันใช้งานบนบัญชีลูกค้าภายนอก**

## ในแพ็กเกจ

- `plugin.json` — manifest แบบ portable และ `.codex-plugin/plugin.json` สำหรับ compatibility
- `skills/reel2srt/SKILL.md` — instructions สำหรับ workflow เดียว
- `skills/reel2srt/scripts/reel2srt.py` — ต้นแบบที่รับวิดีโอจริงและสร้าง SRT
- `skills/reel2srt/references/runtime.md` — setup/runtime และรูปแบบ alignment
- `tests/` — automated tests และรายการคลิปที่ต้อง benchmark
- `CAPABILITY.md` — ผลตรวจ capability/distribution พร้อมแหล่งอ้างอิง
- `TEST-REPORT.md` — ผลที่ทำจริงและข้อจำกัด

ไม่มี payment, dashboard, subscription, เว็บแอป หรือระบบควบคุมสิทธิ์ลูกค้า

## ทดลองใน ChatGPT / Codex

1. แตก ZIP เก็บโฟลเดอร์ `reel2srt` ให้ครบ รวมไฟล์ซ่อน `.codex-plugin` ไม่ใช่อัปโหลดเฉพาะ SKILL.md แล้วคาดหวังว่าสคริปต์จะตามไปด้วย
2. ใน ChatGPT Work/desktop หรือ Codex ที่เข้าถึงโฟลเดอร์นี้และมี plugin-creator ให้สั่ง:

   > ใช้ plugin-creator เพิ่ม plugin จากโฟลเดอร์ Reel2SRT ที่แนบ/ระบุนี้เข้า personal marketplace สำหรับทดสอบในเครื่อง คงไฟล์ Skill และ scripts ทั้งหมด แล้วตรวจ manifest ให้ด้วย

   ระบุ path จริงของโฟลเดอร์ที่แตก ZIP ถ้าเครื่องมือมองไม่เห็นไฟล์ ให้เปิดงานในโฟลเดอร์นั้นก่อน
3. หลังเพิ่ม personal marketplace แล้ว refresh รายการ Plugins และติดตั้ง Reel2SRT จาก local source เปิดแชตใหม่ เลือก Reel2SRT/skill ที่ติดตั้งตามเมนูที่บัญชีนั้นมี
4. ให้ agent ตรวจ Python, PyAV, faster-whisper, model cache และการสร้างไฟล์ดาวน์โหลดก่อน หากขาดให้ทำ setup ตาม `runtime.md` ใน environment ที่รองรับ ต้องเผื่อพื้นที่และเวลาสำหรับโมเดล ไม่ได้แถมมากับ ZIP
5. อัปโหลด MP4/MOV ไม่เกิน 5 นาที แล้วสั่ง “ใช้ Reel2SRT สร้างซับจากเสียงจริง คงภาษาเดิมและช่วงเงียบ”
6. ดาวน์โหลด SRT ตรวจต้นคลิป ช่วงเงียบ คำเฉพาะ ช่วงสลับภาษา และท้ายคลิปก่อนนำไปใช้งาน

ขั้นตอนนี้เป็นเส้นทางทดสอบ local ที่ต้องมี runtime รองรับ ไม่ใช่หลักฐานว่า ChatGPT web/mobile ทุกบัญชีติดตั้ง ZIP หรือรันโมเดลได้ ถ้าบัญชีไม่มีเมนู/สิทธิ์/เครื่องมือที่ต้องใช้ ให้ถือว่าไม่รองรับจนกว่าจะทดสอบผ่าน

## ทดลองตัวประมวลผลโดยตรง

จากโฟลเดอร์ `reel2srt` หลังติดตั้ง requirements และเตรียมโมเดลตาม runtime.md:

```sh
python3 skills/reel2srt/scripts/reel2srt.py --video '/path/clip.mov' --out '/path/result/clip.srt' --language th
python3 -m unittest discover -s tests -v
```

ภาษา `th` ตรงกับค่าเดิมที่ผู้ขายใช้กับคลิปไทย ส่วน `auto` เป็นค่าเริ่มต้นสำหรับสินค้าและ `en` สำหรับคลิปอังกฤษ ต้อง benchmark ไทยปนอังกฤษก่อนสรุปว่าค่าใดดีกว่า

สร้าง `.srt`, `.alignment.json`, `.report.json` ด้วยชื่อใหม่ทุกครั้ง ไม่เขียนทับงานเก่า ถ้าไม่พบเสียงพูดจะมีเฉพาะ JSON ถ้าเวลาไม่ถูกต้องจะหยุดและรายงานเหตุผล ไฟล์ที่ผ่านการตรวจโครงสร้างยังเป็น draft จนกว่าจะเทียบกับเสียงจริง

## รับโอน 199 บาทแล้วส่งลิงก์แบบ manual

**สิ่งที่ขายได้ในระยะนี้คือ Early Access ของแพ็กเกจ workflow พร้อมคู่มือและการช่วยติดตั้งตามขอบเขตที่ตกลง ไม่ใช่บริการประมวลผลไม่จำกัดหรือสิทธิ์ ChatGPT**

1. ก่อนรับเงิน ให้ลูกค้าทดลอง capability ด้วยคลิปสั้นบนบัญชี/เครื่องที่จะใช้งานจริง: เปิด plugin ได้ อ่านไฟล์ได้ ถอดเสียงพร้อมเวลาได้ และดาวน์โหลด SRT ได้ บันทึก platform/plan/version ที่ผ่าน
2. แจ้งราคา 199 บาทจ่ายครั้งเดียวสำหรับเวอร์ชันที่ซื้อ ไม่มีค่าสมาชิกรายเดือนของ Reel2SRT; ค่า ChatGPT/เครื่องประมวลผลและข้อจำกัดแพลตฟอร์มเป็นคนละส่วน คำว่า Lifetime ให้ผูกกับสิทธิ์ใช้เวอร์ชันที่ได้รับ ไม่รับประกันแพลตฟอร์มหรือบริการตลอดชีวิต
3. ผู้ขายตรวจยอดโอนเอง แล้วบันทึกชื่อ/ช่องทางติดต่อ วันที่ ยอด เวอร์ชัน และวันส่งลิงก์ในบันทึกธรรมดา ไม่ต้องสร้างระบบ payment
4. อัปโหลด `reel2srt-0.1.0.zip` ไปยังพื้นที่ที่ผู้ขายเลือก แล้วส่งลิงก์ดาวน์โหลดและ README ให้ลูกค้าเป็นรายคน ลิงก์นี้คือลิงก์รับแพ็กเกจ ไม่ใช่ลิงก์ติดตั้ง ChatGPT อัตโนมัติ ให้ผู้ขายทดสอบจากบัญชีผู้รับก่อนใช้งานจริง
5. ถ้าในบัญชีมี Share/Publish ให้ตรวจ audience ที่หน้าจอระบุ และทดลองจากบัญชีลูกค้านอก workspace ก่อนส่ง: ลิงก์ workspace ไม่เปิดให้บัญชีภายนอกโดยอัตโนมัติ การเผยแพร่สาธารณะต้องผ่านช่องทาง review/publish ของ OpenAI
6. ส่งข้อความด้านล่างพร้อมลิงก์จริงหลังตรวจโอนแล้วเท่านั้น หากติดตั้งไม่ได้ ให้ช่วยตามขอบเขตที่ตกลงหรือดำเนินการคืนเงินตามเงื่อนไขที่แจ้งไว้ก่อนซื้อ

ข้อความส่งมอบ (เติมวงเล็บก่อนส่ง):

> ได้รับยอด 199 บาทแล้วครับ นี่คือลิงก์ Reel2SRT Early Access v0.1.0: [ลิงก์รับแพ็กเกจหรือปลั๊กอินที่ทดสอบแล้ว] พร้อมคู่มือ [ลิงก์คู่มือ] ใช้กับวิดีโอไม่เกิน 5 นาที ระบบที่เราทดสอบร่วมกันคือ [ระบุบัญชี/แพลตฟอร์ม] เริ่มได้โดยติดตั้งตามคู่มือแล้วอัปคลิปเพื่อสร้าง SRT ครับ หากติดตั้งหรือสร้างไฟล์ไม่ได้ ติดต่อกลับทางช่องทางนี้ได้เลย

ผู้รับสามารถคัดลอกแพ็กเกจหรือส่งต่อลิงก์ได้ V1 ไม่มี DRM/paywall และไม่สามารถเพิกถอนสำเนาที่ดาวน์โหลดแล้ว ไม่ควรใช้ข้อความใน Skill เป็นระบบตรวจการชำระเงิน

## นำเข้า CapCut

ใช้ CapCut รุ่นที่รองรับการ import subtitle/SRT เปิดโปรเจกต์ด้วยวิดีโอต้นฉบับและนำเข้าไฟล์ SRT ผ่านเมนู subtitle/caption import ที่มีในรุ่นนั้น ตั้ง timeline เริ่มตรงกันที่ 0 ไม่เปลี่ยน speed ก่อนตรวจซับ ทดสอบภาษาไทย/อังกฤษ ต้นคลิป gap และท้ายคลิป ชื่อเมนูและความสามารถแต่ละรุ่นต้องตรวจจากตัวแอปจริง — ยังไม่ได้ทดสอบ CapCut ในงานนี้

## ก่อนเปิดขายวงกว้าง

ทำ benchmark ใน `tests/BENCHMARK.md` ด้วยคลิปจริง 30 วินาที/1/3/5 นาที และทดลองผู้รับนอก workspace อย่างน้อยหนึ่งบัญชี จนกว่าจะผ่านให้เรียกว่า prototype/Early Access และระบุระบบที่รองรับตามผลจริง
