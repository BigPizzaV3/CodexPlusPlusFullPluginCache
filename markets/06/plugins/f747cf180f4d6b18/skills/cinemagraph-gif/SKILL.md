## Steps
1. From video: use a tripod-steady clip, choose a frozen base frame, mask the area that should move, and blend the moving area from each frame over the still base.
2. From a still photo: animate one region with code (water flow, cloud drift, steam rising, light shimmer, falling snow, candle flicker, blinking lights) using gentle distortion or overlays.
3. Make the loop seamless: crossfade the end into the start.
4. Keep motion subtle and slow for an elegant, premium look.
5. Size for web or social, and optimize colors (cinemagraphs compress well since most pixels stay the same).
