2. Put the key message and call to action in the first frame, because some email apps (such as some desktop versions of Outlook) only show the first frame.
3. Formats: sale announcement, new product launch teaser, animated button, feature carousel, event promo, animated banner ad in standard sizes (300x250, 728x90, 160x600, 320x50, 300x600), website hero loop.
4. Keep file sizes light (email GIFs ideally around 1 MB or less), 3 to 6 frames of messaging, 2 to 3 seconds per message frame.
5. Use honest urgency only: real deadlines and real stock limits.
6. Provide alt text for accessibility and email clients that block images.
