# A poem about something really weird

Difficulty: ⭐️

A shampoo bottle does not seem like material for a poem. That is exactly why this works: you are going to photograph any object and see how ChatGPT finds something poetic in it. Along the way, you will practise asking it to focus on a specific visual detail.

## 📄 Instructions

1. Photograph any everyday object near you. A shampoo bottle, some keys, or a toaster will work perfectly. Before uploading it, check that the background does not show people, mailing labels, screens, account details, or other personal information you do not want to share.
2. In ChatGPT, select the `+` button or the control for attaching an image, add the photo, and write:

```text
Write a short poem inspired by this photo. Use a specific detail from what you can see.
```

3. Read the poem and identify which detail from the photo it used.
4. If you cannot find the attachment control or prefer not to use a photo, write, for example:

```text
Write a short poem about a toaster.
```

## 💡 Expected results

ChatGPT should write a short poem based on the object. If you used a photo, it should use at least one visible detail. If it interprets the object incorrectly, say so and ask for another version.

## 🚀 Optional challenge

Ask for a second version with a completely serious or completely absurd tone.

When you want to continue, write `next exercise` in this same conversation and curso.ai will check whether another compatible exercise is available.
