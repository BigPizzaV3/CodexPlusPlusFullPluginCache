# Minigame I

Difficulty: ⭐️

Usage: ⚡️⚡️

You are going to create a small game with just a few sentences. You do not need to know how to code. You will see that the assistant takes care of the rest and understands you quite well. We will use this game again in the next exercise.

## 📄 Instructions

1. Continue in this same conversation.
2. In the following text block, click the button to add it to the chat. You can also type it or copy it manually:

```text
Make a web game called "Catch the circle". When the circle is clicked, it moves and one point is added. There is a 10-second timer.
```
3. (Optional) If you see a reasoning selector and want it to finish sooner, choose a light or fast option. With more reasoning, it may spend more time and pay closer attention to the result. If the selector does not appear, you do not need to do anything.
4. Press ENTER or the ⬆️ arrow to send the message. Creating and testing the game may take several minutes. It is fine if it takes a little while, let it finish. You do not need to change any other model or option.

5. If this is your first time using this experience, it may ask for permission or prepare a safe workspace. You can allow it to create or open this game's local files. The exercise does not need passwords, access to other accounts, or permission to publish anything. If it asks for something else and you do not know why, do not accept yet and ask what it needs it for.
6. When it finishes, it will probably show you a card or a link to open the game. Open it from there. If nothing appears, write: `Open the game so I can test it`.
7. Play for a little while if you want to test it. We will use it as a base for the next exercise. If clicking a moving target is not comfortable for you, ask it to make the game work with the space bar too or to keep the circle still.

## 💡 Expected results

You should be able to play a very simple video game based on your request, with the countdown and scoring working. It may first generate an image as a draft and then create a game that looks more or less like it.

If something fails, ask it to fix it.

When you want to continue, write `next exercise` in this same conversation and curso.ai will check whether another compatible exercise is available. If you would rather keep improving the game, continue the conversation here as normal.
