# Reply using only emojis

Difficulty: ⭐️

A familiar story can be told without a single word. This exercise lets you see whether ChatGPT recognizes what matters and follows a very specific format.

## 📄 Instructions

1. Choose a film, book, or story you know well.
2. If emojis are accessible to you, write something like:

```text
Tell me The Lord of the Rings using only emojis. No words.
```

3. If you prefer a text alternative, write this instead:

```text
Describe in words which emojis you would use to tell The Lord of the Rings and explain what each one represents.
```

## 💡 Expected results

You should receive a sequence of emojis representing moments from the chosen story or, if you chose the text alternative, a clear description of those symbols. Some may be a little ambiguous.

## 🚀 Optional challenge

Ask for another version with much more detail.

Ask for another using only 3 emojis.

When you want to continue, write `next exercise` in this same conversation and curso.ai will check whether another compatible exercise is available.
