# Minigame II

Difficulty: ⭐️⭐️

Usage: ⚡️⚡️

If you have not completed "Minigame I", do it first in this same conversation.
The assistant can use its own cursor with your permission. This is very powerful because it can open web pages, help you solve an error, fill in a tedious form, and collaborate with you while showing you what it does. We will make it play your game with [@Browser](plugin://browser@openai-bundled).

## 📄 Instructions

1. If you have just completed "Minigame I" here, continue in this same conversation. If you completed it in another one, return to it from the left sidebar. If you cannot find that conversation, write `give me Minigame I` and complete it before continuing.
2. In the following text block, click the button to add it to the chat. You can also type it or copy it manually:

```text
Open my game in a way that is compatible with [@Browser](plugin://browser@openai-bundled) and play one round
```

We say "compatible" to avoid problems if the game was open as a file. This tells the assistant to open it in a local, private preview that the browser can use, without publishing it on the Internet. It will normally handle this itself, although it may ask for permission to prepare that preview.

## 💡 Expected results

If [@Browser](plugin://browser@openai-bundled) is available and you allow it, you should see it play inside the browser. A cursor different from yours may appear, although sometimes the clicks will be so fast that you will barely see it. It is also normal for it to click a few times, pause to look at what happened, and continue. At the moment, it will most likely score lower than you... for now!

[@Browser](plugin://browser@openai-bundled) lets ChatGPT Work or Codex use the built-in browser you are looking at. More advanced computer use is available through tools such as [@Computer Use](plugin://computer-use@openai-bundled), which you can allow to control applications in general. There is also [@Chrome](plugin://chrome@openai-bundled) for controlling the installed Google Chrome application, and we will look at it later.

## 🚀 Optional challenge

Play together. Continue the conversation with:

```text
Modify the game so that there are multiple targets for me to click in one color and others for you in another color. Add a scoreboard for each of us and extend the round to 20 seconds.
```

When it finishes, continue with:

```text
Let us play together. You go first.
```

You may need to coordinate a little. If it gets stuck, say so normally and try again. You will probably keep winning, although it may go into rapid-fire mode and beat you.

If the message box shows a selector with a lightning bolt, you can try turning it on for another round. It may make the assistant act faster, although this is not guaranteed. Because this uses more of your usage allowance, remember to turn the lightning bolt off when you finish. If that control does not appear, ignore this paragraph.

When you want to continue, write `next exercise` in this same conversation and curso.ai will check whether another compatible exercise is available.
