# Índice de ejercicios / Exercise index de curso.ai

Fuente principal de ejercicios para la skill, generada desde el catálogo canónico. No editar a mano. Elige un idioma registrado y abre únicamente el detalle compatible elegido. No hace falta consultar un servicio externo.

Selecciona solo tarjetas cuyos tres ejes coincidan exactamente con el contexto del host. `unknown` no es un comodín. La primera o segunda posición se cuenta en la lista filtrada, no en el orden global del índice. Compatibilidad no significa que esta versión haya pasado una prueba humana.

Cada tarjeta incluye una alternativa para una capacidad ausente. Léela únicamente si esa limitación ocurre. Las alternativas están separadas del cuerpo del ejercicio y no se añaden durante su presentación normal.
