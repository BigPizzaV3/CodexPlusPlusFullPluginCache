# Response patterns

> **Áp dụng cho học tập:** Mọi "ca", "bệnh nhân", "xử trí", "xét nghiệm" hay "decision" bên dưới chỉ là dữ kiện thuộc **tình huống hoàn toàn giả định, không có người bệnh thật**. Đọc cùng `educational-boundaries.md`; không sử dụng các gợi ý này trong chăm sóc, hồ sơ hoặc quyết định y tế thực tế.


These are patterns, not rigid templates.

## Learn mode
**Mục tiêu** → **Ladder entry** → **Must know** → **1–3 nấc phù hợp** → **Must not miss** (if meaningful) → **Should know** → **Mở rộng** (optional) → **Gate/retrieval → nấc kế tiếp**

## Q&A
**Trả lời ngắn** → **Vì sao/cơ chế** → **Ứng dụng/nhận diện** → **Dễ nhầm** → **Prerequisite repair** only if a gap is evident.

## Quiz feedback
**Đúng/Gần đúng/Chưa đúng** → **Reasoning then chốt** → **Sửa misconception** → **Nền cần ôn lại** if relevant → **Câu kế tiếp/retest**

## Case debrief
**Clues quyết định** → **Reasoning tốt/chưa tốt** → **Must not miss** → **Mechanism/discriminator** → **Reassessment** → **Transfer case**

## Exam review
**High-yield map** → **Must know** → **Must not miss** → **Should know** → **Common traps** → **Mixed retrieval** → **Error log** → **Mở rộng** only if time/objectives allow.

## File-grounded learning
**Theo tài liệu** → **Must know trong phạm vi nguồn** → **Giải thích/cơ chế** → **Bổ sung** (nếu có) → **Recall từ chính tài liệu**


## Ladder repair
**Nấc đang vướng** → **Gap cụ thể** → **Lùi về prerequisite hẹp nhất** → **Micro-review** → **Forward bridge về bài hiện tại** → **Retest bằng tình huống mới**

## Compact ladder orientation
When useful: **Entry → Next rung(s) → Repair rung if needed → Safety overlay**. Do not display all eight rungs mechanically.
