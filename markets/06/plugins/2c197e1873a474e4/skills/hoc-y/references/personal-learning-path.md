# Personal learning path

> **Áp dụng cho học tập:** Mọi "ca", "bệnh nhân", "xử trí", "xét nghiệm" hay "decision" bên dưới chỉ là dữ kiện thuộc **tình huống hoàn toàn giả định, không có người bệnh thật**. Đọc cùng `educational-boundaries.md`; không sử dụng các gợi ý này trong chăm sóc, hồ sơ hoặc quyết định y tế thực tế.


## Goal
Convert diagnostic evidence and user constraints into a small, actionable sequence.

## Inputs
Use whatever is already known:
- learner year;
- subject/topic;
- exam date or time available;
- source material/syllabus;
- diagnostic results;
- error log;
- learner preference (explain, quiz, cases, mixed).

Do not interrogate the learner for every field. Ask only what materially changes the plan.

## Default path structure
For each step:

**Objective → Why it matters → Learning activity → Retrieval/application check → Mastery criterion**

Example:

**1. Acid-base compensation**
Why: prerequisite for interpreting mixed disorders.
Activity: 8-minute mechanism review + 2 worked examples.
Check: 3 interpretation questions.
Mastery criterion: independently identifies expected compensation and explains mismatch.

## Time-aware planning

### Same-day / crash review
Prioritize:
- unresolved prerequisite gaps that block the core;
- **Must not miss** safety gaps;
- **Must know** objectives;
- retrieval;
- common discriminators;
- one mixed set;
- defer Mở rộng unless explicitly required.

### 1–2 weeks
Use cycles of:
learn/review → retrieve → apply → error repair → delayed retest → mixed practice.

### Longer horizon
Distribute topics and revisit weak objectives. Avoid fixed universal spacing claims.

## Source-constrained exam
When an uploaded lecture/syllabus defines exam scope, build the path from that source first. Label external enrichment separately.


## Content-priority rule
When several objectives compete, prefer:

**Prerequisite gap → Must not miss → Must know → recurring error → Should know → transfer/integration → Mở rộng**

If a learner is stuck on a Must know objective because of signs & symptoms, mechanism, or basic science, repair that prerequisite before adding more content.
