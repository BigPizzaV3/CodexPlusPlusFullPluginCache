# 学校・地域・行政との協働／デジタル化・生成AI

## 1. 学校との関係

- PTAと学校は目的を共有し得るが、組織としては区別して扱う。
- 「学校の下部組織」でも「学校と一心同体」でもなく、役割と責任を分けた上で協働する。
- 学校からの依頼は自動的にPTAの義務にならない。PTA側の目的、規約、予算、人的負担を踏まえて意思決定する。
- PTAが学校を支援する場合も、公的責任の代替が常態化しないよう確認する。

## 2. コミュニティ・スクール・地域学校協働との整理

PTA、学校運営協議会、地域学校協働活動は目的・権限・代表範囲が異なる。重複する活動があっても同一視せず、次の回路を意識する。
- 保護者の意見形成・自治の回路
- 学校運営への制度的参画の回路
- 地域資源・実践を接続する回路

役割重複がある場合は、誰が決めるか、誰を代表するか、誰が責任を負うかを整理する。

## 3. 教育行政・政策対話

施設、通学安全、教職員配置、ICT、特別支援、給食等、学校だけで解決しにくい課題は教育委員会・自治体との対話が必要になることがある。

PTAの要望・提言では、次の循環を基本にする。
1. 課題の把握
2. 会員・必要に応じて広い保護者層への意見聴取
3. データと自由記述の整理
4. 組織内の正式な意思決定
5. 要望・提言
6. 行政・学校からの回答
7. 会員等へのフィードバック
8. 実施状況の評価

アンケート結果を「全保護者の総意」と過大解釈せず、対象、回答率、抽出方法、設問、限界を明示する。

## 4. デジタル化

デジタル化を三層で考える。
- 業務処理：連絡、文書共有、会計、出欠、引継ぎ
- 参加・意思決定：会議、意見募集、総会、議決
- 認知・情報処理支援：生成AIによる要約、分類、文章作成、企画補助

重要度が高いほど、本人確認、権限、記録、情報保護等の統制を強める。

## 5. 参加経路の複線化と統治経路の可視化

- 紙、対面、同期オンライン、非同期オンラインを目的に応じて組み合わせる。
- デジタル利用能力やアクセス環境の差を考慮する。
- 参加の入口を増やすだけでなく、意見が誰に整理され、どこで決まり、誰が執行し、何が記録され、どう応答されたかを追跡できるようにする。

## 6. 生成AI

生成AIはPTA改革の目的ではなく補助手段である。
- 議事録下書き、文章整理、集計補助等では効率化できる。
- 個人情報、未公開情報、相談内容、児童生徒情報の入力には慎重であること。
- AI出力をそのまま総意・正式決定・法的判断として扱わない。
- 人間が最終確認し、代表性・説明責任・意思決定手続を省略しない。
