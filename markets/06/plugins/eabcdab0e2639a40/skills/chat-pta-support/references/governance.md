# 任意性・公共性・代表性・組織ガバナンス

## 1. 任意性を基礎にする

- PTAへの加入・退会・参加は、本人の意思を尊重することを出発点にする。
- 任意性を明確にすることは、会員範囲、議決権、会費、代表範囲を明確にする組織統治の基礎でもある。
- 非会員であることと子どもの学校生活を短絡的に結びつけない。

## 2. 「任意性に基礎を置く公共性」

PTAは私的な任意団体であっても、教育環境、安全、地域連携、意見形成など公共的性格を持つ活動を行い得る。公共性は、公的機関であることや全活動を全員に同一提供することとは別である。

活動を考える際は、次の観点を分ける。
- 目的の公共性：何のための活動か
- 影響の公共性：誰に影響するか
- 手続の公共性：誰の意見をどう把握し決めるか
- 責任の公共性：結果を誰に説明するか

会員内部型、選択参加型、教育公共型など、活動の性格に応じて対象・財源・受益を設計する。

## 3. 代表性と正統性

役員・会長に選ばれたことだけで、すべての保護者を当然に代表できるとは扱わない。対外的な発言では、少なくとも次を確認する。
1. 代表する範囲が明確か
2. 規約・総会・役員会等による授権があるか
3. 当事者の意見を把握しているか
4. 多様な立場・少数意見を排除していないか
5. 意見形成の過程を説明できるか
6. 結果を当事者へ返しているか
7. 異議・更新・再検討の余地があるか

「代表範囲は、授権と意見把握の範囲を超えない」を基本にする。

## 4. 組織ガバナンス

- 総会、理事会・運営委員会、役員、監事などの権限と責任を規約上で整理する。
- 権限を持つ者と責任を負う者を対応させる。
- 会計、契約、資産、個人情報等では、一人に権限を集中させず相互牽制を設ける。
- 重要な判断は、後から検証できるよう議案、根拠、議決、執行、報告を記録する。
- 利益相反が生じる場面では、申告、審議・議決からの除外、記録等を検討する。
- 組織規模・財政規模・契約額・社会的影響が大きいほど、専門性、監督、内部統制、事務局体制を強める。

## 5. PTAの再設計

PTA改革を「活動を減らすこと」だけで評価しない。次の改善につながるかで見る。
- 参加可能性
- 代表性
- 責任境界
- 意思決定の検証可能性
- 応答性
- 持続可能性

PTAという名称・組織形態の維持よりも、保護者の教育参加をどのように保障するかを上位目的に置く。
