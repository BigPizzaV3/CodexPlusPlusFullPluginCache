# 法務・会計・リスク実務の確認枠組み

この資料は法的助言そのものではない。法令・行政解釈・自治体規則・税務は変更され得るため、回答時には必要に応じて最新の公的資料を確認する。

## 1. 法的論点の確認順序

1. PTAの法人格・組織形態を確認する
2. 当該PTAの規約・細則・決議を確認する
3. 相手方（学校、自治体、業者、会員等）との法的関係を確認する
4. 適用される法令・条例・教育委員会規則・契約を確認する
5. 法的義務と推奨実務を分ける
6. 事実関係が不足する場合は条件付きで説明する

一般的なPTAを一律に同じ法的性格と断定しない。団体の実態によって評価が変わり得る。

## 2. 規約・細則

規約は最低限、目的、会員、入退会、会費、役員、機関、議決、会計、監査、改正、解散等を整合的に定める。
- 規約に反する慣行を「毎年そうしている」だけで正当化しない。
- 細則・内規は規約を補完するもので、規約を実質的に変更する内容を安易に置かない。
- 電磁的方法、書面議決、委任、オンライン出席等を用いる場合は、当該規約に照らして成立要件・議決権・本人確認・記録方法を確認する。

## 3. 個人情報

- PTAと学校を同一主体として扱わない。
- 学校保有情報をPTAが受け取る場合は、提供主体、利用目的、本人同意その他の法的根拠を確認する。
- 取得項目は必要最小限にし、利用目的を明確化する。
- 名簿公開範囲、共有先、保存期間、退任者のアクセス削除、組織アカウント化、事故時対応を設計する。
- 生成AIへ入力する場合は、個人情報・機微情報・自由記述等の入力可否を別途判断する。

## 4. 会計・財務

- 会費、寄付、学校徴収金、公費等を区別する。
- 予算・決算・支出権限・証憑・監査・口座管理を明確化する。
- 高額支出、契約、現金、振込、口座変更等では複数人チェックを基本とする。
- PTA資金を学校経費に充当する場合は、単に慣行で判断せず、学校・設置者の責任、寄付手続、教育委員会規則、会員決議等を確認する。
- 寄付は「良いこと」と一律評価せず、PTAの独立性、学校予算との関係、受入手続、物品管理、継続負担も検討する。

## 5. 人的・安全リスク

- 行事は事前に危険源、参加者属性、監督体制、救護、連絡網、保険、事故報告を確認する。
- ハラスメント・対人トラブルには、相談窓口、記録、事実確認、関係者保護、利益相反の回避、必要な外部相談を設ける。
- 有償スタッフ、外部講師、業者、謝礼等では、契約、税務、源泉徴収、労働法上の地位を個別に確認する。

## 6. 専門家への接続

次のような場合は専門家確認を優先する。
- 紛争・損害賠償・法的責任：弁護士
- 税務申告・収益事業・会計処理：税理士
- 雇用・労働時間・社会保険：社会保険労務士
- 法人登記等：司法書士
- 行政手続・申請書類：行政書士

専門家名は一般論であり、具体案件では相談範囲を確認する。
