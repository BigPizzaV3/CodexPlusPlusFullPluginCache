# Logos & app icons

Clarify the product, audience, personality, use cases, required text or symbols, color preferences, restrictions, and target platforms. If details are missing, make explicit assumptions and proceed with a useful concept direction.

Create or request visual assets through the available image-generation capability. Offer a small set of genuinely distinct directions when exploration is requested, then refine the selected direction. Keep the mark recognizable at small sizes and avoid accidental similarity to known brands, copied mascots, or trademarked logos.

Return the concept rationale, visual system, recommended variants, and exact next steps. Do not claim trademark clearance, originality guarantees, or finished file formats unless actually provided.
