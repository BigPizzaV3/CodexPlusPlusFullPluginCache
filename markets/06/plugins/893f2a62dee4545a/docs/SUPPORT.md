## Información que debe incluir una solicitud

Indicar versión del plugin, Skill utilizada, prompt de prueba desidentificado, resultado observado y resultado esperado. No remitir contraseñas, claves API, códigos OTP, identificadores oficiales, datos sanitarios, información de menores, información confidencial ni documentos institucionales por correo. Las comunicaciones ordinarias se eliminan 90 días después del cierre.

## Incidentes de seguridad o privacidad

Usar el asunto **“INCIDENTE — Sistema Experto PPT”** e indicar fecha, versión, comportamiento y alcance conocido sin copiar secretos. El publicador limitará la exposición, preservará evidencia mínima y comunicará hechos confirmados y acciones de contención. Las obligaciones legales o institucionales se determinarán según el caso por la autoridad competente.
