# Rúbrica de auditoría

Evaluar solo criterios aplicables y separar defectos de preferencias.

| Dimensión | Pregunta de control |
|---|---|
| propósito | ¿el deck permite el resultado esperado para la audiencia? |
| narrativa | ¿la secuencia y los títulos sostienen el argumento? |
| evidencia | ¿los claims materiales son verificables y proporcionales? |
| visualización | ¿la representación facilita comprensión sin inducir error? |
| accesibilidad | ¿el contenido es legible y no depende solo del color? |
| producción | ¿el archivo abre, conserva estructura y permanece editable? |
| interoperabilidad | ¿los formatos derivados conservan contenido y diseño material? |
| gobernanza | ¿se respetan confidencialidad, derechos, marca y límites de autoridad? |

Registrar cada hallazgo como `id | ubicación | criterio | evidencia | consecuencia | severidad | corrección | verificación`.

Concluir con preparación de uso, riesgos principales, fortalezas preservables y remediation priorizada. No otorgar una puntuación sin rúbrica y evidencia suficientes.
