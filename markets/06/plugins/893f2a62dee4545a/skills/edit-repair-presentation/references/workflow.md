# Editing and repair workflow

1. Resolve the authoritative input and create a working copy.
2. Inventory format, size, slide count, masters/layouts, fonts, theme, notes, media, charts, tables, links and accessibility signals.
3. Translate the request into an explicit change set with invariants, dependencies and acceptance criteria.
4. Classify defects: content/evidence, narrative, visual, production or interoperability; assign severity.
5. Apply changes in dependency order: global theme/master → structure → content/data → slide layout → notes/metadata.
6. Render all affected slides plus adjacent or globally dependent slides.
7. Check regressions, file structure and editability.
8. Deliver one clean final file and only material limitations; never expose internal diagnostic artifacts unless requested.
