# Narrativa y storyboard

Organizar la secuencia por el cambio buscado en la audiencia, no por el orden de las fuentes.

## Familias

- Decisión: contexto → evidencia → opciones → recomendación → decisión.
- Explicación: pregunta → modelo → evidencia/ejemplo → implicación → síntesis.
- Técnica: criterio → arquitectura/proceso → evidencia → brecha/riesgo → plan.
- Educativa: objetivo → concepto → ejemplo → práctica → verificación.
- Comercial legítima: problema → valor → prueba → diferenciación → siguiente paso.

## Contrato de slide

`id | función | mensaje | claims | evidencia | representación | rol del expositor | fuentes | riesgo | aceptación`

Usar únicamente los campos aplicables. Los títulos, leídos en secuencia, deben formar una historia legítima. Emplear título temático cuando no existe conclusión demostrable y título-conclusión solo cuando la evidencia lo soporta.

## Gate

Aceptar cuando mensaje central, progresión, apertura, cierre, objeciones relevantes y extensión sean coherentes con objetivo, audiencia, evidencia, modo y tiempo.
