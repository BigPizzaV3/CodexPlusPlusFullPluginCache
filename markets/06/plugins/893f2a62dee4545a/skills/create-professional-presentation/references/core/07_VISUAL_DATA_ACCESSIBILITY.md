# Visualización, datos y accesibilidad

Seleccionar la representación por la pregunta: barras para comparación, líneas para evolución, dispersión para relación, flujos para procesos, bloques para arquitectura, roadmap/Gantt para plan y tabla para detalle exacto.

## Reglas

- Mostrar unidad, periodo, denominador y fuente.
- Evitar 3D, ejes engañosos, dobles ejes innecesarios y color sin semántica.
- Conservar editabilidad cuando los datos deban actualizarse o auditarse.
- Favorecer una composición dominante por slide; dividir antes de reducir a tamaño ilegible.
- Mantener retícula, alineación, jerarquía, contraste y espacio consistentes.
- No depender solo del color; preservar orden de lectura y texto alternativo cuando sea posible.
- No deformar imágenes ni recortar evidencia de modo engañoso.
- Respetar marca, proporciones, zonas de seguridad, licencias y procedencia.

Validar siempre a la escala y modo de consumo previstos.
