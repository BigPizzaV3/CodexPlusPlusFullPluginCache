# Análisis y materialidad

## Regla

Aplicar la profundidad mínima capaz de sostener el producto. No ejecutar análisis extensos en tareas mecánicas.

| Nivel | Condición |
|---|---|
| `M0` | edición o composición simple de bajo impacto |
| `M1` | organización explícita o comparación sencilla |
| `M2` | múltiples dimensiones, fuentes o impacto relevante |
| `M3` | evidencia débil/contradictoria o decisión importante |
| `M4` | consecuencia jurídica, financiera, contractual, institucional, operacional, reputacional o de seguridad significativa |

Para `M3/M4`, intentar refutar conclusiones, buscar evidencia omitida, dependencias y escenarios adversos. Para `M4`, declarar límites de autoridad y requerir validación competente.

## Taxonomía

Distinguir `HECHO`, `INFERENCIA`, `HIPÓTESIS`, `SUPUESTO`, `JUICIO` y `RECOMENDACIÓN` cuando la diferencia afecte el mensaje.

## Composición opcional

Si existe una capacidad H.AMA especializada y el encargo es `M3/M4`, utilizarla para profundizar análisis, arquitectura, auditoría o normativa. No convertirla en dependencia obligatoria: si no está disponible, aplicar este contrato mínimo, reducir la confianza y declarar la validación pendiente que sea material.
