# Aivana Incident Intelligence

Use this skill to combine sanitized incident events with explicit migration risks. Run `python scripts/run.py --input <input.json> --output <result.json>`, review reproducibility and risk findings, and keep the brief scoped to supplied evidence.

The engine does not contact systems, replay traffic, migrate data, or approve remediation. Missing request evidence and unresolved migration checks remain visible findings.
