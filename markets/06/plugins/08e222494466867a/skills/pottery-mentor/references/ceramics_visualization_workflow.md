# Ceramics Visualization Workflow

## Purpose

Use this reference when Atelier is asked to create or edit a visual.

The visual capability supports ceramics mentorship. It should not replace technical reasoning when the user is asking for a real firing, glaze, structural, or safety diagnosis.

## 1. Classify the visual

### New concept
Create a new ceramic form, vessel, sculpture, surface, studio graphic, or teaching illustration.

### Existing-piece edit
Modify an uploaded pottery photo to preview one or more requested changes.

### Comparative study
Create multiple clear alternatives, such as:
- three handles;
- different foot proportions;
- different neck/rim treatments;
- surface-decoration options.

### Educational visual
Create:
- process diagrams;
- throwing/handbuilding illustrations;
- kiln-loading concepts;
- test-tile layouts;
- glaze-testing diagrams;
- studio-safety graphics.

## 2. Preserve the user's actual work

When editing a supplied piece, define:

**Change**
- exactly what should differ.

**Preserve**
- all unrelated aspects of the original image.

Do not improve or redesign unrelated aspects unless the user asks.

## 3. Glaze and firing previews

Treat visual glaze/firing previews as conceptual.

A rendered color or surface cannot reliably predict an actual fired result because real outcomes depend on:
- clay body;
- glaze formulation/product;
- glaze thickness;
- layering;
- firing atmosphere;
- heatwork;
- cooling;
- kiln position;
- material interactions.

Do not present a generated preview as test evidence.

## 4. Form studies

For form alternatives, keep comparisons controlled.

Example:
- same body;
- same camera/view;
- same scale;
- vary only the handle.

This makes visual comparison more useful.

## 5. Teaching diagrams

Prefer:
- clear hand/tool placement;
- staged steps;
- arrows/labels only when useful;
- minimal visual clutter;
- safe studio practices.

Do not depict unsafe kiln bypasses, unprotected dusty processes, or improvised electrical/gas work as normal technique.

## 6. Exact text

If the user asks for labels or a poster:
- preserve exact spelling;
- do not invent cone numbers, temperatures, glaze recipes, measurements, or safety claims.

## 7. After the visual

Keep commentary short unless the user asked for technical explanation.

When a visualization could be mistaken for a real process prediction, add one concise note explaining what still requires physical testing.
