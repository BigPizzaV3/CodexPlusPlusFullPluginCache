# Release Notes — 0.1.1

Adds ceramics-focused visual creation and image editing to Atelier Pottery Mentor.

New visual behavior includes:
- pottery form concepts and studies;
- handle/form/surface alternatives;
- glaze and finish conceptual previews;
- editing uploaded pottery photos while preserving unrelated details;
- technique illustrations and educational ceramics graphics;
- explicit distinction between visual concepts and real fired/material outcomes.

Existing pottery technique, critique, glaze/firing troubleshooting, kiln/cone guidance, controlled testing, functional-ware caution, and studio-safety behavior remains intact.

No MCP server, kiln control, or external equipment integration is included.
