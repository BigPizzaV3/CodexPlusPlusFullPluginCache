# Studioの複数表を読む

## 表の役割を判別する

標準は、今回の動画別、トラフィックソース別、検索語別、関連動画の流入元動画別の4表。前回の表、ブラウジング内訳、ライブ指標だけの別表なども受け取った範囲で読む。受領順やファイル名ではなく列名・日付・行の識別子で判別し、不足を理由に分析全体を止めない。

前回資料を今回と同じ連続期間に取り直させる必要はない。実際に読めた前回観測期間との比較とし、期間の重複や空白を記録する。直前の連続28日間と異なる場合は、そのように呼ばない。前回メモの転記値だけで比較するときは、原本を再集計したと扱わない。

| 内容 | 典型的な識別子 | 注意 |
| --- | --- | --- |
| 動画別 | コンテンツ、動画のタイトル、動画公開時刻、長さ | コンテンツを動画IDとして扱う。動画種別の列がない場合もある |
| ライブ指標の別表 | 同じ内訳の識別子と、ライブに属する指標列 | 通常表と期間・内訳・IDを照合して補完。重複する視聴数や合計を足さない |
| 流入元 | トラフィック ソース、視聴回数 | 流入全体の内訳。別ファイルの各詳細表はこの表の部分集合 |
| ブラウジング内訳 | SUBSCRIBER.で始まるID | トップページと登録チャンネルを区別。接頭辞だけで登録者からの流入と解釈しない |
| 検索語 | YT_SEARCH.で始まるID、ソースのタイトル | 入力された検索語。検索語と視聴された動画の対応はこの表だけでは分からない |
| 関連動画 | YT_RELATED.で始まるID、ソースのタイプがコンテンツ | 接頭辞を除いた動画IDは流入元。視聴された自動画のIDではない |

「表データ」は期間の集計。「合計」は選択した指標の日別時系列の場合があるため、ヘッダーを確認する。「グラフデータ」は選択された一部の動画・語句だけの場合がある。動画IDや語句の数、日付の数を数え、全動画の日別データだと思い込まない。

期間は日別データから開始日・終了日を得て、両端を含む暦日数と、実際のユニーク日付数・重複・欠落を照合する。ファイルが28日と呼ばれていても29日ならそのまま示す。加算可能指標の日平均を補足できるが、それは完全に同条件の28日比較ではない。日別値がある指標だけは同じ28日に切り出せる。他の指標や動画別集計まで比例配分して切り出さない。

## 全行・合計・分母を照合する

「上位 500 件の結果を表示しています」等のフッターをデータ行から除く。検索語と関連動画は500件でも全流入を網羅しない場合がある。取得行の視聴合計÷同じ表の全体合計をカバー率として示す。取得していない分は未取得として残し、他の語句や動画へ割り振らない。

動画別表の合計行、動画行の和、日別合計の和、流入元表の合計、流入元行の和を別々に比較する。一致しない場合は元値を保持し、表ごとの合計を分母にする。更新時点・集計範囲・非表示等の候補は挙げられるが、差の原因は確認なしに確定しない。

登録者増加・減少・純増のチャンネル合計は、動画に帰属する行の和と一致しない場合がある。差分を特定動画の成果や架空の「その他動画」に加えない。動画別寄与とチャンネル合計を分ける。

「視聴回数」「エンゲージ ビュー」「視聴回数（共視聴）」「ユニークリーチ」「ユニーク視聴者数」は別指標として保持する。差をShortsだけの現象と決めつけない。2026-09-18に確認した公式説明では、視聴回数は長尺・Shorts・ライブすべてで再生開始を数える。実行時の現行定義を確認する：[YouTube公式の指標説明](https://support.google.com/youtube/answer/9314486?hl=en)。変更日やアカウントへの適用日はこの説明から推測しない。

日別の視聴回数とエンゲージビューの比が途中で大きく変わるなら、動画内容だけで説明せず、計測定義・表示面・流入構成の変化も未検証候補にする。視聴回数の伸びをそのまま視聴者需要の伸び率と断定しない。

登録効率は、登録増加数／1,000視聴回数と、登録増加数／1,000エンゲージビューを明確に書き分ける。エンゲージビューを便宜上の比較軸として使う場合も「人」や個人の登録確率ではなく、独自の集計比率と記す。平均視聴時間は出力された公式値を保持し、再生時間をどちらかの視聴数で割って勝手に上書きしない。

検索語別のインプレッションが全て0でも、親の検索流入表に露出があれば「表示されていない」と結論しない。集計粒度や取得可否の違いを確認する。欠損のCTRを0％として評価しない。

## 成果と推薦を分ける

期間内に公開された動画群と既存動画群を分け、全体増加が新作の成功によるものか確認する。大きく伸びた1本の有無で結論が変わる場合は、その1本を除いた集計も補足する。新作群は観測日数が異なるので同条件の初動とは呼ばない。

関連流入元IDを手元の自動画IDと照合する。一致すれば自動画と分かるが、不一致だけで他者の動画と確定しない。期間内に視聴されていない自動画、別チャンネル、非公開化等もあり得る。チャンネル所有者を公開ページ等で確かめてから外部の参考先に分類する。

関連動画表のCTR・平均視聴時間は、その流入元を経由した自チャンネル側の成果であり、流入元動画自身のCTR・維持率・品質ではない。チャンネル集計の関連流入表だけから流入元と流入先の組を復元しない。次に見る自動画の組み合わせは内容に基づく提案として、実測の遷移と区別する。
