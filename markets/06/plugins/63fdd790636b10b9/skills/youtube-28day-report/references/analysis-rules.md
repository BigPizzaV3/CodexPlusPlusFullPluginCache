# 集計と判断

## 集計対象

各表のチャンネル・期間・種別・フィルタ・集計軸を固定する。公式合計を優先し、取得動画の和と照合する。差があれば範囲、重複、上限、欠損、丸め、更新時点を確認し、差を記録する。

再実行可能な計算で、変換・除外・集計式と元データの対応を残す。合計行を動画ランキングに含めない。

## 指標

| 指標 | 扱い |
| --- | --- |
| 視聴・再生時間・露出 | 重複しない同じ範囲の行だけ加算 |
| CTR | 同範囲の公式値を優先。再集計はインプレッション加重で、丸めによる近似と記す |
| 平均視聴時間・平均再生率 | 正しい対象視聴の分母で加重。動画ごとの率の単純平均を公式全体値にしない |
| Shorts | 現行の視聴回数とエンゲージビューを区別。平均視聴時間等の分母を公式定義で確認 |
| 全形式の視聴回数 | 長尺でもエンゲージビューと異なる場合がある。定義・期間内の計測差を確認し、差をShortsだけに帰属させない |
| 登録増加／1,000再生 | 同期間の登録増加÷対応する視聴数×1,000。純増しかなければ「登録純増」と表記 |
| 反応／1,000再生 | 分子・分母の対象を一致させ、分母も併記。満足度そのものとは呼ばない |
| ユニーク視聴者 | 動画間・日付間で足さない。チャンネルの推定値を用いる |
| 前期間比 | ゼロを基準に増加率を出さず絶対増分を使う。％と％ポイントを区別 |

欠損を0にしない。ゼロ分母は計算不能とする。インプレッション対象外の視聴があるため、全視聴数÷インプレッションはCTRではない。インプレッション×CTRは対応する露出由来の視聴の概算で、全視聴数ではない。

CTR×平均視聴時間を使うなら対象流入を確認する。全流入の平均視聴時間しかない場合は探索用の代理値とし、公式指標や推薦アルゴリズムの評価点、将来の再生予測にしない。

## 比較と解釈

月1回の直近28日運用では、前回観測期間と今回の期間に数日の空白や重複があり得る。期間をそれぞれ明記し、日付が連続する直前28日比較や暦月合計へ読み替えない。過去資料が読めなければ比較なしで完成させる。前回メモだけを使う場合は出典付きの転記値による比較とし、未読の原本を再集計したと主張しない。

長尺、Shorts、ライブを分ける。不明な種別・公開日は不明のまま残す。今期の累積貢献と、同じ公開後7日間などの初動を別の問いにする。初動データがなければ公開後の公平な優劣は判定できない。

補助的に期間内の公開済み日数で割る場合は、期間開始・公開日・終了日から日数を求める。初動の偏りや観測時間差を解消しないと明記する。生涯の再生を今回28日の成果に混ぜない。

CTR・維持率は種別、尺、公開後日数、流入が近い動画で比べ、比較群の本数と中央値や分布を示す。万能な合格ラインや最低母数を置かない。低インプレッションで高CTRなら小さい分母を示し、成功を断定しない。

露出拡大で視聴者の構成が変わる可能性を考慮し、CTRだけで良否を決めない。流入データがなければ流入構成は仮説にとどめる。相関を原因と呼ばない。

タイトル等からテーマを分類し、曖昧な分類は暫定にする。テーマ別に本数、合計成果、1本あたりの成果を分け、少数のヒットを全動画の法則にしない。未閲覧の内容や画像を批評しない。

## 改善仮説

| 観測例 | 仮説 | 確認と行動 |
| --- | --- | --- |
| 同条件で露出あり・CTR低め | タイトル・画像の約束が対象者と合わない | 実物と流入を確認し、変更や比較テストを提案 |
| クリックされるが維持が弱い | 内容や冒頭が期待と合わない | 曲線や動画を確認。平均だけで離脱秒数を作らない |
| 再生は多いが登録増加率が低い | 単発需要、既存視聴者比率、次も見たい理由の弱さ | 視聴者区分を確認し、シリーズや次への案内を試す |
| 過去動画が継続貢献 | 検索需要や関連視聴が続く | 流入を確かめ、補完企画や更新版を検討 |

この表は固定診断ではない。変更対象、変える要素、指標、比較対象、判断時期を具体化する。同じ公開後7日・28日等で確認する。単純な前後比較で因果効果を断定せず、露出、流入、季節、投稿本数の併存変化を記す。

## 公式参照先

指標の具体的な意味や取得可否は、実行時の公式説明と入力表で確かめる。

対象期間・比較期間に視聴回数等の定義変更が重なるかを毎回確認し、公式発表の適用時期、対象形式、過去データへの扱いを記録する。固定の日付や以前のレポートだけで現行定義を決めない。変更をまたぐ生の視聴回数比を、そのまま需要の増減と解釈せず、同一定義で比べられる指標と期間を優先する。変更前後を切り分けられなければ比較の限界を示す。

## 外からの流入と、チャンネル内の次の視聴

「入り口を開く・出口を自チャンネルへつなぐ」は、発見と連続視聴を増やすための目標として扱う。この状態が成長の必要十分条件、または推薦システムの既知の採点基準だとは説明しない。

| 見たいこと | 取得できる材料 | 判断できる範囲 |
| --- | --- | --- |
| 他チャンネルからの関連流入 | 関連動画内訳と、流入元動画の所有者確認 | 確認できた他者動画からの流入数・構成比。Studioの「外部」流入とは別 |
| 自動画が次の視聴を生んでいるか | 自動画と照合できた関連流入元、終了画面の要素別クリック、再生リスト内の視聴 | 各経路の利用状況。視聴後に再び自動画を見た人の割合そのものではない |
| 視聴が継続しているか | 取得できれば再生リスト開始数・1開始あたり視聴、リピーター等 | 指標ごとの継続の手がかり。セッション内の連続視聴と後日の再訪を分ける |
| 動画間の実際の経路 | 流入元と流入先の組が同時に記録された表 | 記録された範囲の遷移のみ。チャンネル集計の関連表から復元しない |

関連流入元は「自動画確認済み／他者動画確認済み／所有者未確認／明細未取得」に分ける。手元の自動画一覧にないだけでは他者動画としない。比率の分母は、関連流入全体か取得明細かを明示する。未取得分を除いて100％に正規化する場合は取得範囲内の構成比と記す。

「関連流入内の自動画割合」は流入側の構成比である。チャンネルの総視聴を起点にした継続確率ではなく、同一視聴者・同一セッションの追跡でもない。関連流入が増えても自動画割合が低下する場合があるため、割合と絶対数を併記する。

終了画面は、要素の種類、対象動画、表示数、クリック数、誘導先が分かる範囲を確認する。登録・他チャンネル・外部リンク等を含む全要素CTRを自動画への誘導成功率にしない。要素表示を分母にするCTRと、全視聴・終了画面到達を分母にした率を混同しない。取得表の項目名だけで不明なら現行の公式定義を確認する。

直接の回遊率や離脱率を計算できる分子・分母がなければ「この入力からは直接算出できない」と一度説明し、代理指標による改善案と次回の計測方法を示す。欠測を成績不良の根拠にしない。

## エンゲージメント・検索語・目標

高評価・コメント・共有・登録増加は件数と対応する1,000視聴あたりの値を示し、定義変更が疑われる場合はエンゲージビューを分母にした補助値も名称を分ける。エンゲージビューそのものを、高評価等の反応の合計や満足度と同義にしない。コメントには重複投稿や投稿者本人の返信等が含まれる可能性があり、反応件数を反応した人数としない。

反応が多い理由を考える際は、テーマ、視聴者構成、質問形式、賛否の分かれる内容も候補にする。コメント本文未読で感情や内容を断定しない。「最後に質問を1つ置く」「次回で質問に答える」等を提案する場合、どの動画で試し、反応率と視聴維持をいつ比べるかまで書く。

検索語表は、自チャンネルが実際に獲得した検索流入であり、YouTube全体の検索ボリュームではない。表記違いをまとめるときも元語句と合算方法を保持する。実測語句、関連流入から導いた問い、公開調査で確認したテーマ、未検証の拡張候補を分ける。低流入を低需要と断定せず、未制作・露出不足の可能性も残す。

登録者の目標・現在総数・確認日・期間純増を別項目にする。現在総数を確認できれば目標との差を計算できる。単月純増からの到達時期は予測として断定しない。ユーザーが求める場合のみ「この純増が続くなら」という条件付きの算術シナリオを示し、丸められた公開登録者数を用いる際は概算とする。現在総数が不明なら、期限・残数・必要倍率を算出せず、次月は純増と登録につながった動画を追う。
