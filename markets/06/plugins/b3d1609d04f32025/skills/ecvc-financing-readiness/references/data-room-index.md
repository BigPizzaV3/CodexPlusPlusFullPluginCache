# Basic data-room index

Create a practical folder plan from the assessment. Include only folders relevant to the company. Mark items as Present, Partial, Missing, Unknown, or Not applicable.

## Suggested folders

1. Corporate organization, foreign qualifications, and real estate
2. Board and owner approvals
3. Capitalization and securities
4. Employees, founders, and consultants
5. Intellectual property and digital assets
6. Financial and tax
7. Material commercial and real-estate agreements
8. User terms, privacy, regulatory, and insurance
9. Disputes and investigations

Do not create a financing-materials folder for the contemplated round. The skill is intended to operate before round-specific terms and documents are known or drafted. A pitch deck may be reviewed as optional intake context but is not a required data-room item.

This is a general starting point, not a universal diligence request list. Do not represent it as complete for a particular financing, investor, industry, or jurisdiction.

## Index columns

When creating a table or spreadsheet, use:

| Column | Purpose |
|---|---|
| Folder | Numbered folder and name. |
| Requested item | Neutral description of the record. |
| Status | Present, Partial, Missing, Unknown, or Not applicable. |
| Source file | Filename when supplied. |
| Date or version | Visible date or version. |
| Apparent observation | Factual note without a legal conclusion. |
| Priority | Now, Next, or Later. |
| Owner | Company role responsible for the follow-up. |
| Target date | Blank unless the user supplies or requests one. |
| Counsel review | Yes, No, or To be determined. |

## Naming and handling

Suggest consistent filenames such as `03.02_Cap_Table_YYYY-MM-DD.xlsx`, while preserving originals. Recommend a single owner for the index, version control, limited access, and a separate list of known exceptions. Do not instruct the user to upload confidential materials to an unapproved service.
