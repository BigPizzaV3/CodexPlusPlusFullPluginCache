# Cloudflare and Deployment Security

Check bindings, secrets, routes, preview exposure, CORS, cache behavior, Durable Object or database access, R2 uploads, service bindings, logs, environment separation, migrations, rollback, and least privilege. Treat deployment configuration as security-sensitive code.
