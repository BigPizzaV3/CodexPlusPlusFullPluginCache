# Release Notes — 0.1.0

Initial skills-only release of **Job Outreach Copilot**.

Provides:
- job opportunity triage using candidate evidence;
- Strong / Partial / Weak fit classification;
- Proceed / Qualify first / Skip next-action routing;
- recruiter, LinkedIn, email, referral, follow-up, application, and interview-stage drafting;
- recruiter-thread continuity;
- truth-safe compensation and work-authorization wording;
- privacy and suspicious-recruiting safeguards.

No MCP server, external account connection, authentication, custom UI, or write action is included in v0.1. The plugin drafts communication but does not send messages or submit applications.
