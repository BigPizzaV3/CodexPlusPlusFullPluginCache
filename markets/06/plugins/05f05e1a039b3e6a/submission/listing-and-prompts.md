# Public Listing Draft

## Plugin name
Power BI Report Copilot

## Package name
`power-bi-report-builder-copilot`

## Version
`0.1.0`

## Short description
Build and debug Power BI

## Category
Productivity

## Long description
Build, troubleshoot, and optimize Power BI Report Builder paginated reports and broader Power BI solutions. Covers RDL datasets and parameters, tablix groups, Visual Basic expressions, page layout, PDF/Excel/print rendering, subscriptions, semantic models, DAX, Power Query, Import/DirectQuery/Direct Lake architecture, incremental refresh, performance, governance, and security. Uses supplied report files, screenshots, queries, model details, and errors as evidence and does not claim to execute, refresh, export, publish, or deploy anything unless a connected tool actually performs that action.

## Starter prompts

1. Help me debug this Power BI paginated report and give exact Report Builder steps.
2. Fix this DAX or Power Query logic and explain the model issue causing the result.
3. Review this Power BI or Fabric reporting architecture and recommend the simplest sound design.

## Capabilities

- Design and debug Power BI paginated reports and RDL
- Fix datasets, parameters, tablix groups, filters, and expressions
- Troubleshoot PDF, Excel, print, pagination, and delivery behavior
- Write and debug DAX and Power Query M
- Review semantic models, relationships, grain, and star schemas
- Compare Import, DirectQuery, Direct Lake, and composite designs
- Diagnose Power BI and Fabric performance bottlenecks
- Review RLS, regulated-data handling, and secure report delivery
