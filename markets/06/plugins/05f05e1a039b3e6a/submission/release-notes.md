# Release Notes

## 0.1.0 — Initial test package

Initial skills-only release of Power BI Report Copilot.

Includes:
- Power BI Report Builder / paginated report workflows;
- RDL datasets, parameters, tablix, filters, grouping, and VB expressions;
- PDF/Excel/print/export and delivery troubleshooting;
- semantic-model, DAX, and Power Query guidance;
- Import, DirectQuery, Direct Lake, composite-model, and incremental-refresh architecture guidance;
- performance, governance, security, and regulated-data guardrails;
- current official Microsoft/OpenAI source registry;
- public-submission listing draft and 5 positive / 3 negative test cases.

No MCP server, authentication, external actions, or custom UI are included in v0.1.
