# Brain dump to actions

Read [shared preferences](../../references/preferences.md).

Read the whole input before organizing it. Preserve the meaning and uncertainty of spoken or rough text; repetitions can be merged, but do not erase a conflicting detail silently.

## Make the material usable

- Extract actual actions with a concrete verb and object. Add an owner or deadline only when supplied; mark suggestions as suggestions.
- Keep decisions or unanswered questions separate from tasks. Identify a dependency when it changes what can start.
- Keep ideas and useful reference notes without assigning them artificial due dates.
- Recognize feelings and observations as such. They do not all need to become productivity tasks.

Use only the categories that the input needs. Rank the immediate actions when priorities are evident; otherwise recommend one start and explain the assumption briefly. A larger capture list can remain complete while the immediate action list stays small.

If something is waiting on another person, say what is awaited. A proposed follow-up date is a suggestion, not a reminder that has already been scheduled.

Return the organized result in the current conversation by default. If he asks to save it, use the existing named notes or task system and preserve unrelated content. Do not create a new tracker merely to hold the result.

## Final check

Can he start one item without reinterpreting it? Are any commitments invented? Did an important worry, idea or unresolved question disappear during compression?
