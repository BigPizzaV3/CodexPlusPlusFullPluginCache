# Patrik Toolkit

Six personal skills for everyday work and communication. This is a local source package, version 0.3.0. It has not been installed or published by this build.

| Skill | Try saying |
|---|---|
| i-have-adhd | "Use ADHD mode: concise paragraphs and clear next steps." |
| patrik-writing-style | "Make this SMS sound like me, in Slovenian." |
| get-unstuck | "I'm avoiding this report. Help me start." |
| resume-work | "Where was I with this project?" |
| plan-my-day | "Here are my tasks and appointments. Help me plan today." |
| brain-dump-to-actions | "Organize this brain dump into things I can act on." |

Skill discovery depends on the host and your instructions. A plugin does not make all its rules globally active. Explicitly requested ADHD mode lasts within the current conversation; it is not an account-wide switch.

Shared defaults live in [references/preferences.md](references/preferences.md). Writing illustrations live in [examples.md](skills/patrik-writing-style/references/examples.md); they are constructed examples, not approved quotations. Preferences for replies to Patrik and text written on his behalf have separate scopes.

The local identifier is now patrik-adhd-v2, matching this directory. The earlier manifest used patrik-adhd; this is a distinct namespace, so installing it later will not silently update that older plugin. No installed copy, marketplace, automation or global memory was changed. Select a deliberate migration path if you later want to replace the older installed plugin.

The package includes only the manifest, active image assets, skills, shared preferences and this guide. Private review findings, historical messages, backup images and Serena metadata are excluded from the ZIP. The separate review folder is for local review and is not a plugin dependency.
