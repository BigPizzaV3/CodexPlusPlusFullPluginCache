# Uploaded Image Animation

Use uploaded images as the authoritative visual source. Preserve faces, products, logos, text, and key geometry unless the user asks for a change. Propose safe motion such as parallax, zoom, pan, blink, glow, particle drift, object reveal, color shift, or sequential storytelling. Call out when interpolation may distort details and offer a conservative alternative.

For a multi-image sequence, normalize orientation and canvas size, then describe ordering, crossfades, cuts, holds, and loop direction. Do not claim to have processed a file that is not available in the current context.
