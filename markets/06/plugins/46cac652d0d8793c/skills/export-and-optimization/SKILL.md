# Export and Optimization

Recommend dimensions and frame rate based on destination. Balance quality against GIF limitations: indexed color, large file sizes, transparency behavior, and inconsistent frame disposal. Specify loop count, delay, dithering, palette strategy, and optimization expectations when relevant.

Provide format guidance for GIF, animated WebP, APNG, MP4, and MOV. For GIF delivery, verify square dimensions when requested, readable text, smooth timing, transparent-background behavior, and a sensible file-size target. Never claim a successful export without an actual output artifact.
