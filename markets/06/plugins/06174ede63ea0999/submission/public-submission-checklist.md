# Public Submission Checklist

## Package
- [ ] `plugin.json` is at the ZIP root.
- [ ] `skills/seo-growth/SKILL.md` has valid YAML frontmatter.
- [ ] `agents/openai.yaml` parses and uses only in-package assets.
- [ ] Branding assets are valid, square, text-free, and production-ready.
- [ ] No private Search Console exports, analytics data, credentials, unpublished site data, or customer information are bundled.

## Listing
- [ ] Display name is at most 30 characters.
- [ ] Subtitle is at most 30 characters.
- [ ] Long description is at most 4,000 characters.
- [ ] At most 20 capabilities, each at most 120 characters.
- [ ] At most 3 starter prompts, each at most 128 characters.
- [ ] Category is `Productivity`.
- [ ] Publisher identity matches the verified OpenAI Platform identity.

## Behavior
- [ ] Test technical indexing diagnosis.
- [ ] Test Search Console performance analysis.
- [ ] Test 2026 structured-data guidance.
- [ ] Test programmatic SEO quality gates.
- [ ] Test metadata/social/internal-linking/growth measurement.
- [ ] Verify no ranking guarantees or invented keyword/Search Console data.
- [ ] Verify robots/noindex/canonical/sitemap distinctions.
- [ ] Verify outdated FAQ-rich-result and llms.txt SEO claims are rejected.

## Review
- [ ] Review five positive and three negative test cases.
- [ ] Add/update release notes.
- [ ] Complete availability and policy attestations.
- [ ] Wait for bundled-skill safety/security scans.

## Scope
Version 0.1.0 is skills-only. It can analyze user-provided websites, code, exports, screenshots, metadata, and research evidence using host capabilities, but it does not connect directly to Search Console, Analytics, crawlers, CMSs, or deployment systems by itself.
