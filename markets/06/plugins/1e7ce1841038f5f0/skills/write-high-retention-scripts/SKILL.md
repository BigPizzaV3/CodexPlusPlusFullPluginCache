# Write High-Retention Scripts
1. Define audience, platform, duration, objective, promise, evidence, voice, visuals, and CTA.
2. Build hook, context, rising value/tension, pattern changes, proof, payoff, and next action.
3. Write for spoken rhythm and simultaneous visuals; mark time, shot/visual, voice, text, and sound when useful.
4. Remove throat-clearing, repetition, unsupported claims, and open loops without payoff.
5. Create hook and ending variants for testing without changing the core promise.
6. Return final script, beat map, visual plan, variants, factual checks, and retention-risk notes.
