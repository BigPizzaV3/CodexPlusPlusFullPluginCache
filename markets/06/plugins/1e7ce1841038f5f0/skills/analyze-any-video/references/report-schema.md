# Report schema

## Coverage block

| Field | Required value |
|---|---|
| Source | File, URL, recording, transcript, screenshots, or mixed |
| Analysis level | `full-video`, `sampled-video`, or `page-context` |
| Duration | Total known duration and duration covered |
| Visual evidence | Continuous, scene-based, interval and rate, or unavailable |
| Audio evidence | Original, extracted, transcript only, or unavailable |
| Captions | Official, automatic, supplied, or unavailable |
| Missing/uncertain | Exact gaps and limitations |
| Capture/research date | Absolute date |

## Timeline

| Time | Scene/shot | Visible action and text | Speech, music, sound | Function | Finding/confidence |
|---|---|---|---|---|---|

## Finding

Use this structure for material findings:

- **Finding:** concise conclusion.
- **Evidence:** timestamps and modality.
- **Interpretation:** why it matters.
- **Confidence:** high, medium, or low.
- **Action:** concrete improvement when requested.

## Optional scorecard

Score 1–5 only when useful: clarity, opening, visual communication, audio communication, structure, credibility, CTA, accessibility, originality of mechanism, and technical execution. Explain every score; do not combine scores from unequal evidence coverage into a definitive ranking.
