## 18. Developer or coding-agent directive

- Implement only approved scope.
- Preserve listed invariants and protected areas.
- Do not add features, redesign interfaces, change architecture, or refactor unrelated code without approval.
- Surface repository/specification conflicts and blocking unknowns before proceeding.
- Run specified checks and report actual results.
- Return a change manifest, deviations, evidence, untested areas, and residual risks.
