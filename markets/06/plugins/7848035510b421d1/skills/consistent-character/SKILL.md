## Purpose
Make the character look like the same person in every image.

## Method
1. **Identity block:** a fixed, detailed description (face shape, eyes, hair, skin, marks, build, signature outfit and colors) reused word for word.
2. **Reference first:** create one clean, front-facing reference image and a turnaround before making scenes.
3. **Consistent-character tools:** tools that save a character from one image or a description and reuse it (OpenArt Characters is one) keep identity far better than prompts alone; the user can then change pose, outfit, expression and scene.
4. **Change one thing at a time:** pose or outfit or setting, not everything at once.
5. **Style lock:** keep the same style keywords and lighting in every prompt.
6. **Fix drift:** compare to the reference and correct the specific feature that drifted.

## Output
The identity block, a step-by-step consistency workflow, and a set of scene prompts that reuse it. Include a drift checklist: face, eyes, hair, colors, marks, outfit, proportions.
