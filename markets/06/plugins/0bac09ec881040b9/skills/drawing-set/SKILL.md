## Step 1: Identify the need
Reading a drawing, creating a drawing list, preparing schedules, or learning conventions.

## Step 2: Typical drawing set
| Drawing | Typical scale | Purpose |
|---|---|---|
| Site plan | 1:200–1:500 | Building position, setbacks, access, levels |
| Floor plans | 1:50–1:100 | Rooms, walls, doors, windows, dimensions |
| Roof plan | 1:100 | Slopes, drains, equipment |
| Elevations | 1:50–1:100 | Exterior appearance, heights, materials |
| Sections | 1:50–1:100 | Floor-to-floor heights, stairs, roof build-up |
| Details | 1:5–1:20 | Junctions, waterproofing, joinery |
| Schedules | n/a | Doors, windows, finishes, fixtures |

## Step 3: Schedules
Door schedule: mark, size, type, material, hardware, fire rating (if needed), location.
Window schedule: mark, size, sill height, type, glazing, frame.
Finish schedule: room, floor, walls, ceiling, skirting.

## Step 4: Reading help
Explain symbols (north arrow, section markers, level marks, door swings, window types), line types and dimension chains in plain words.

## Step 5: Output
Deliver the requested list or schedules as clean tables, and note that construction documents for permits must be prepared by licensed professionals.
