## Quick reference
| Style | Key signals |
|---|---|
| Modern / contemporary | Flat or low roofs, clean lines, large glazing, plain surfaces |
| Minimalist | Very few materials, hidden details, calm neutral palette |
| Scandinavian | Light wood, white walls, gable forms, cozy simplicity |
| Japandi | Natural wood, low furniture, muted tones, craft texture |
| Mediterranean / Spanish | Stucco walls, terracotta tiles, arches, courtyards |
| Farmhouse | Gable roofs, board-and-batten, porches, warm wood |
| Tropical | Deep eaves, raised floors, cross-ventilation, timber screens |
| Islamic / Mughal | Courtyards, arches, jali screens, domes, geometric patterns, water features |
| Colonial / Georgian | Symmetry, central entrance, columns, multi-pane windows |
| Mid-century modern | Post-and-beam, big windows, horizontal lines, indoor-outdoor flow |
| Brutalist | Exposed concrete, bold heavy forms |
| Art Deco | Geometric ornament, vertical emphasis, rich materials |

## Step 3: Apply
Give a mood description, facade and interior cues, a palette, and a render prompt in that style. When mixing styles, pick one base style and borrow only two or three elements from another.
