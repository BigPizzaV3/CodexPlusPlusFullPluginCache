# Cloudflare Security

Multi-skill security audit guidance for Cloudflare accounts and applications. The package is skills-only; it does not bundle an MCP server or Cloudflare credentials. Where the user has connected an authorized Cloudflare integration, use minimal read-only operations to inspect relevant configuration. Otherwise, review code and settings the user supplies.

Audits do not change account configuration. Require explicit approval for each production mutation. Never claim complete security; show audit scope, evidence, unavailable checks, and residual risk.
