## How SciSpace helps R users
- Literature search and reviews: find peer-reviewed papers that used a specific method (for example mixed models, survival analysis, structural equation modeling or random forests) to justify an analysis choice or compare results.
- Chat with PDF: ask questions about a paper's methods, statistical tests, tables and formulas, then reproduce the analysis in R with this plugin's help.
- Data extraction: pull reported values (sample sizes, means, effect sizes) from papers into a table, then import it into R for a meta-analysis with `metafor` or for visualization.
- Writing support: draft literature review and discussion sections with citations, while R and this plugin handle the analysis and results.
- Research agent: automates multi-step research tasks such as reports and data visualization from literature.
