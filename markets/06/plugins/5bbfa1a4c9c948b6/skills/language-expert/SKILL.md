## Idioms and tools by language
| Language | Idiomatic habits | Tooling |
|---|---|---|
| Python | Comprehensions, context managers, dataclasses, type hints, f-strings | pip, venv, uv or Poetry, pytest, Ruff, Black |
| JavaScript | const and let, async and await, modules, array methods | npm, pnpm, Node, ESLint, Prettier |
| TypeScript | Strict mode, precise types, unions, generics, no loose any | tsc, ESLint, Vitest |
| Java | Records, streams, Optional, try-with-resources | Maven, Gradle, JUnit |
| C# | LINQ, async and await, records, nullable reference types | dotnet CLI, NuGet, xUnit |
| C and C++ | RAII, smart pointers, const correctness, bounds care | CMake, GCC, Clang, sanitizers |
| Go | Explicit error returns, small interfaces, goroutines with channels | go mod, go test, gofmt |
| Rust | Ownership, Result and Option, iterators, traits | Cargo, clippy, rustfmt |
| PHP | Strict types, Composer autoloading, PSR standards | Composer, PHPUnit, Laravel or Symfony |
| Ruby | Blocks, enumerables, convention over configuration | Bundler, RSpec, Rails |
| Swift | Optionals, structs, protocols, async and await | Xcode, Swift Package Manager |
| Kotlin | Null safety, data classes, coroutines, extension functions | Gradle, JUnit |
| Dart | Null safety, async streams, widgets in Flutter | pub, flutter test |
