# Public Listing

## Name
Unix Copilot

## Subtitle
Safe shell commands & scripts

## Category
Developer Tools

## Description
Unix Copilot helps you write, understand, debug, and safely run shell commands and scripts across Linux and macOS. It can translate plain-language tasks into copy-ready commands, explain pipes and redirection, troubleshoot shell scripts, handle files and text safely, prepare CSV and delimited data, and provide OS-appropriate package and environment guidance. It distinguishes POSIX, Bash, zsh, GNU, BSD/macOS, and Linux behavior, uses dry-runs and validation for risky operations, and avoids unsafe patterns such as unverified recursive deletion, broad permission changes, secret exposure, and brittle filename parsing.

## Capabilities
- Turn plain-language tasks into safe, copy-ready Unix and shell commands
- Explain and debug Bash, zsh, POSIX shell commands, pipelines, quoting, and redirection
- Distinguish Linux, macOS/BSD, GNU, Bash, zsh, and POSIX command behavior
- Preview risky file, permission, process, package, and system changes before execution
- Write and review shell scripts with argument checks, cleanup, errors, and safe quoting
- Handle find, grep, sed, awk, xargs, sorting, and bulk file operations safely
- Work with CSV, TSV, encodings, and command-line data preparation without corrupting data
- Diagnose shell-script failures from errors, traces, exit codes, and command output
- Provide OS-appropriate package-manager, PATH, shell, and environment guidance
- Use current primary docs for shell, utility, GNU/BSD, macOS, and package-manager differences

## Starter prompts
1. Write a safe shell command for this task.
2. Explain and fix this Unix or shell command.
3. Convert this workflow into a safe Bash or zsh script.
