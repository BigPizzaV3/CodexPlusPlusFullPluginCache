# 과제와 논리 설계

2장의 용어와 분석 도구를 질문에 연결한다. 많은 도구를 쓰기보다 필요한 도구를 선택한다.

## 용어와 조사 계획

목적은 왜 하는가, 목표는 도달할 상태·수준·기한이다. 정량화가 맞지 않으면 관찰 가능한 완료 기준을 둔다. 문제는 선택한 기준과 관찰 상태 사이의 차이이며 기준의 타당성도 설명한다. 과제는 그 차이를 다루기 위해 답하거나 수행할 일이다. 원인은 발생 메커니즘, 제약은 실행을 제한하는 조건, 위험은 아직 확정되지 않은 사건과 영향으로 구별한다. ‘문제점’에 모두 뭉개지 않는다.

기획은 문제·대안 설계, 계획은 구체적인 실행에 초점을 두되 기관마다 용어가 겹칠 수 있다. 자료, 질문에 맞게 가공한 정보, 기준에 비춘 판단을 구별한다. 보고서의 전달 목적과 연구·사업 자체의 목적도 구별한다.

발생 문제에는 응급 대응과 재발 방지를, 잠재 문제에는 관찰 신호·예방·발생 시 대응을, 상향 목표에는 필요성과 비용을 검토한다. 유형은 섞일 수 있다.

핵심 질문별로 `잠정 가설 / 확인·반박할 자료 / 출처·수집 방법 / 분석 방법 / 기준 시점 / 필요 시 담당·기한`을 기록한다. 자료를 얻으면 가설과 목차를 함께 수정한다. 주장별로 `근거 위치 / 대상·단위·기간 / 사실·계산·가정·해석 / 대안 설명 / 말할 수 없는 범위`를 연결한다. 이 작업 메모를 원고에 전부 삽입할 필요는 없다.

## 질문에 따른 도구 선택

| 도구 | 질문 | 적용과 한계 |
|---|---|---|
| 5W3H | 무엇이 빠졌는가 | 주체·시점·장소·내용·이유·방법·비용·수량 점검. 모두 목차로 만들지 않는다. |
| Why–What–How | 이유, 내용, 실행이 이어지는가 | 필요성 → 해결할 내용 → 실현 방법. 실제 시급성이 있을 때만 ‘왜 지금’을 쓴다. |
| 반복 원인 질문 | 관찰된 차이는 왜 생겼는가 | 각 연결을 근거로 검토한다. 다섯 번이나 단일 근본 원인을 강제하지 않는다. |
| MECE | 분류에 중복·누락이 있는가 | 범위·분류 축·경계를 정한다. 합계 가능한지 확인한다. 분류는 인과의 증명이 아니다. |
| What/Why/How 트리 | 구성·원인·대안 중 무엇을 나누는가 | 구성 요소, 원인 가설, 해결 수단을 구별한다. 분해식에는 단위·가정을 붙인다. |
| 비교 행렬 | 같은 기준에서 어느 안이 나은가 | 대안별 기준·자료·가중치·상충 관계를 드러낸다. 결과에 유리하게 기준을 바꾸지 않는다. |
| SWOT | 목표와 환경에 맞는 행동은 무엇인가 | 내부 강·약점, 외부 기회·위협을 구별하고 실행 가능한 조합으로 연결한다. |
| 피라미드 | 하위 근거가 상위 주장을 지지하는가 | 상위 문장은 하위 내용이 지지하는 범위만 요약한다. 병렬 근거와 순차 추론을 구별한다. |

연역은 전제와 추론의 타당성을, 귀납은 대표성과 일반화 한계를, 가설 추론은 경쟁 설명과 검증 가능성을 점검한다. 두괄식·미괄식은 배치이며 추론의 타당성을 대신하지 않는다.

인과 주장은 시간 순서, 다른 영향 요인, 연구 설계와 가정을 확인한다. 부족하면 관련성 또는 가능한 설명으로 쓴다. 통제 불가능한 외부 요인도 중요한 위험이면 남기고 경감·대응을 검토한다. 페르미 추정은 가정에서 계산한 규모이지 관측값이 아니다.
