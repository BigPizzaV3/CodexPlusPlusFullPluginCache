# 원문을 적용할 때의 보정

블로그의 과정과 질문 도구를 배우되 예문의 사실과 언어 판단을 모두 정답으로 복제하지 않는다.

| 원문에서 주의할 부분 | 통합 규칙 |
|---|---|
| 권위자의 평가·사회적 합의를 사실 판단과 섞음 | 발언 사실과 평가 내용의 진실성은 별개다. |
| 상관·인과를 필요·충분조건에 단순 대응 | 시간 순서·혼란 요인·연구 설계·가정을 검토한다. |
| 연역에서 거짓 전제이면 결론도 반드시 거짓이라는 설명 | 타당한 추론과 참인 전제가 결론을 보장한다. 거짓 전제만으로 결론의 진위를 판정하지 않는다. |
| 전망을 이미 달성한 결과처럼 줄임 | 시제·확률·예상과 관측의 차이를 유지한다. |
| 접속을 맞추려고 취미·성적 등 사실을 바꾸는 교정 | 연결과 구조를 고치며 사실을 만들지 않는다. |
| 도시를 국가로 바꾸거나 없는 도시를 넣어 나열을 맞춤 | 범위를 확대하지 않는다. 문장을 나누거나 필요한 정보를 확인한다. |
| 피동·부정·‘것’·‘의’·‘적’ 일괄 제거 | 문법·분석 의미에 필요한 형태를 유지한다. 행위자를 만들지 않는다. |
| 반복 금지와 용어 일관성 충돌 | 전문 개념의 일관성이 우선이다. 수사 중복만 줄인다. |
| 두 줄·1쪽·세 갈래·글자 크기 기준 | 기관·독자·목적에 따른 예시 기준이다. |
| 고객 생각과 결론을 맞추라는 점검 | 독자의 질문에 답하되 결론은 근거에 따른다. |
| 오래된 법령·어문 규정, 과도한 의학·성과 예측 예시 | 새 보고서에 사실로 쓰려면 적합한 현행 1차 자료를 확인한다. |
| 학습 성과 공식·독서량으로 실력 향상 보장 | 반복·피드백 원리만 사용하며 실증 공식으로 쓰지 않는다. |
