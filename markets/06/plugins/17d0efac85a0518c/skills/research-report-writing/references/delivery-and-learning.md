# 편집·전달·축적

## 문서 편집

기관 서식을 따르고 제목 수준, 본문, 표·그림 설명, 참고문헌 스타일을 통일한다. 긴 보고서는 목차·장절 번호·교차참조·책갈피를 연결한다.

표에는 비교 기준, 제목·단위·대상·시점·출처를 표시하고 정렬·소수 자릿수·합계를 점검한다. 그래프는 질문에 맞춰 선택한다. 시간 추세를 방사형 그래프로 꾸미지 않는다. 축 범위·가중치로 인상을 왜곡하지 않는다. 도해는 구성·순서·인과·의존 중 어떤 관계인지 밝힌다. 화살표가 인과관계를 증명하지 않는다. 색 외에 명칭·기호로도 의미를 구별한다.

파일 요청에는 해당 형식 도구를 적용하고 실제 페이지의 표 잘림·제목 고립·수식·주석 누락·한글 깨짐을 확인한다. HWP 메뉴·단축키는 버전에 따라 확인한다. 텍스트 추출을 서식 검토로 표현하지 않는다.

## 전달 준비

최종 독자의 판단과 중간 검토자의 설명에 필요한 깊이를 구별한다. 역할·지식·시간·결정권을 파악하며 성격을 추측하지 않는다. 요약·본문·부록의 깊이가 달라도 수치와 결론은 일치해야 한다.

예상 질문은 필요성, 대안, 수치 근거, 결론이 바뀔 조건, 실행 주체에 집중한다. 근거가 없으면 확인 방법을 남긴다. 30초·1분·3분 요약은 요청된 발표 시간에 맞춘 연습이며 필수 산출물이 아니다. 사건 보고는 완전한 원인 분석을 기다리느라 알려진 사실의 전달을 지연하지 않고 미확인 원인을 명시한다.

전달문·메일 초안에는 결정 사항과 핵심 근거를 쓰고 세부 원고를 연결한다. 실제 발송·예약·공유는 사용자의 권한 부여 범위에 따른다.

## 다음 보고서에 연결하기

5장의 반복 훈련을 적용한다. 교육 요청이면 확장하고 일반 작성 요청에서는 원고 완성에 필요한 만큼만 쓴다.

1. 좋은 자료의 중심 질문, 문단 역할, 근거 연결, 조건 표현을 분석한다.
2. 같은 사안을 다르게 다룬 글에서 공통 사실, 다른 가정·가치 기준·근거를 비교한다. 사설·칼럼은 검증된 사실 자체가 아니다.
3. 원문을 덮고 자기 질문과 자료로 재작성한다. 문장 복제를 성과로 삼지 않는다.
4. 수정 전후의 개선 이유와 의미 변화를 확인한다.
5. 반복 오류가 실제로 발견되면 `문제 / 수정 원칙 / 보존 주의 / 다음 적용 조건`을 남긴다. 한 번의 취향을 보편 규칙으로 만들지 않는다.

자료는 질문별로 분류하고 제목·작성자·발행일·URL·참조 위치·활용 이유를 기록한다. 이 지침만으로 모니터링이나 매일 30분 예약을 생성하지 않는다. 새 자료·피드백이 있을 때 규칙을 갱신한다.
