# 최종 검토

모든 보고서에 긴 점검표를 붙이지 않는다. 아래 기준으로 검토하고 사용자가 알아야 할 결과만 전달한다.

## 1. 질문과 논리

- 중심 질문에 답하는가. 요청한 범위와 독자의 판단에 필요한 내용을 다뤘는가.
- 장·절의 순서는 목적에 맞는가. 예시 보고서의 구조를 필요 없이 복제하지 않았는가.
- 각 문단이 새로운 정보나 논리 단계를 더하는가. 문단의 위치를 바꾸었을 때 관계가 끊어지는 이유가 있는가. 독립적인 항목이면 목록이나 비교 구조가 적절한가.
- 결론은 실제 근거에서 도출되는가. 앞의 자료보다 강한 주장, 숨은 가정, 설명되지 않은 비약은 없는가.
- 반대 근거·대안 설명·적용 한계를 공정하게 다뤘는가.

## 2. 근거와 수치

- 중요 사실과 인용의 출처를 찾을 수 있는가. 기준 시점에 맞는 자료인가.
- 본문·표·그림·요약문이 같은 값과 정의를 사용하는가.
- 증감률, %p, 합계, 분모, 가중평균, 환산 단위가 맞는가.
- 실측·가정·모의·예시·전망을 구별했는가. 계산하지 않은 결과를 계산 결과라고 하지 않았는가.
- 이론의 전제, 모형이 제외한 항목, 비교 기준이 결론 근처에서 드러나는가.

## 3. 문장과 자연스러움

- 주체와 수식 대상, 조건과 결과가 명료한가. 문장을 나누면서 논리 관계를 잃지 않았는가.
- 전문명칭은 일관되고 필요한 설명이 있는가. 동의어 교체로 개념이 바뀌지 않았는가.
- 추상적 수사와 근거 없는 강조, 반복 결론, 기계적인 접속을 줄였는가.
- 자연스럽게 만든다며 개인 경험·수치·판단을 새로 만들지 않았는가.
- 통합 Natural writing·Avoid AI Writing 지침을 실제 적용했는가. 자동 검사와 의미 대조의 수행 범위를 구별했는가. Human Writing 미통합 상태를 실제 사용으로 표시하지 않았는가.
- 수정 전후의 부정·조건·불확실성·수치·인용을 보존했는가.

## 4. 문서 완결성

- 제목·목차·장절 번호·표그림수식 번호·교차참조가 맞는가.
- 미완성 자리표시자, 임시 메모, 다른 과제의 표지·연도·머리말이 남지 않았는가.
- 직접인용과 재서술의 구분, 참고문헌과 본문 인용의 대응이 맞는가.
- 요청된 파일 형식으로 열리는가. 페이지 렌더링을 했다면 표 잘림·제목 고립·수식 누락·한글 깨짐을 확인했는가.
- 추출 텍스트만 읽었는데 시각적 검토까지 마쳤다고 하지 않았는가.

## 수정 우선순위와 종료

먼저 결론을 바꾸는 오류, 근거 없는 사실, 수치·단위·인용 오류, 조건 누락을 고친다. 다음으로 목차·문단의 논리와 설명 누락을 고친다. 마지막으로 문법·어휘·서식을 손질한다. 사실 오류를 문체 개선으로 덮지 않는다.

의미 보존 실패는 교정 완료가 아니다. 제한된 복구 후에도 해결되지 않으면 정확한 위치와 남은 문제를 알린다. 정보 부족으로 판단할 수 없는 경우 ‘확인 필요’와 그 영향만 구체적으로 보고한다. 모든 통상적인 편집 판단을 사용자 승인 사항으로 바꾸지 않는다.

최종 전달에는 요청한 원고 또는 파일, 중요한 한계, 필요한 경우 변경 요약을 포함한다. ‘완벽히 검증’처럼 수행한 범위를 넘는 표현은 쓰지 않는다.
