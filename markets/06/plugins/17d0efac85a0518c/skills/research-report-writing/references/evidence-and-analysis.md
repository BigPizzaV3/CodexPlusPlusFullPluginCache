# 근거와 분석의 작성 기준

블로그의 정확성 원칙과 두 보고서의 분석·설명 사례를 작업 규칙으로 확장했다. 아래 항목은 과제에 해당할 때 적용한다.

## 주장과 출처

중요한 주장에는 원문 위치를 되찾을 수 있는 근거를 둔다. 긴 작업에는 다음 항목의 근거 장부를 사용하고, 짧은 글은 간단한 메모로 대신한다.

| 항목 | 내용 |
|---|---|
| 주장 | 보고서에 넣을 구체적인 문장 또는 판단 |
| 종류 | 확인된 사실 / 계산 결과 / 분석 가정 / 해석 / 제안 |
| 근거 | 기관·저자, 문서명, 발행일, 절·쪽·표, URL 또는 제공 파일 |
| 범위 | 적용 시점·지역·모집단·단위·비교 대상 |
| 확인 | 원문 확인 여부, 상충 자료, 결론에 미치는 불확실성 |

‘전문가들은’, ‘해외에서는’, ‘많은 연구가’처럼 주체 없는 권위 표현을 사용하지 않는다. 출처가 확인된 연구의 결과와 본 보고서의 해석을 나눠 쓴다. 인터뷰나 이해관계자의 주장은 그 주체의 의견으로 귀속한다.

현재의 제도·법령·시장 규칙·통계·최근 사건을 다루면 해당 시점의 공식 자료를 확인한다. 제공 자료의 연도와 발행일, 시행일, 관측 기간을 혼동하지 않는다. 전력시장 규칙이면 지역·시장 구분과 시행 여부도 함께 확인한다. 오래된 예시가 새 보고서의 사실 근거를 대신하지 않는다.

## 비교와 인과

비교표를 만들기 전에 비교 질문과 기준을 정한다. 각 대안에 같은 기준을 적용하고, 정보가 없는 칸을 ‘해당 없음’으로 바꾸지 않는다. 수치의 정의·단위·시점·포함 범위가 다르면 맞추거나 차이를 알린다.

전후 변화나 국가 간 차이만으로 제도의 인과효과를 단정하지 않는다. 동시에 변한 요인, 선택 효과, 측정 차이, 대안 설명을 검토한다. 인과 확인을 할 수 없는 분석은 관찰된 관계나 조건부 해석으로 보고한다.

평가 기준은 효율·비용·신뢰도·형평·수용성·실행 가능성 등 과제에 필요한 것을 선택한다. 기준이 충돌하면 무엇을 우선했는지 설명한다. 결론을 정당화하려고 임의의 점수나 가중치를 만들지 않는다.

## 모의·계산 결과

분석의 질문, 기준 시나리오, 바꾸는 변수, 고정하는 변수, 자료 기준일, 모형의 범위를 먼저 정리한다. 대표 시점과 시나리오 가중치를 밝혀 단일 시간 결과와 연간 효과를 혼동하지 않게 한다.

수치 해석에 영향을 주는 가정은 본문에서 결과 가까이에 둔다. 비용 항목, 운영 제약, 기동정지, 손실, 유지보수, 수요 반응, 경쟁 행태, 외생 가격 등을 과제에 맞게 확인한다. 가정을 전부 설명하는 것이 아니라 결론이 무엇에 의존하는지 설명한다.

다음 구분은 전력시장 분석에서 특히 유용하며 다른 분야에도 유사하게 적용된다.

- 시장가격, 생산비용, 총정산금, 사업자 수익, 소비자 부담, 사회후생을 서로 바꿔 부르지 않는다.
- 가격 또는 정산 방식만 바뀐 효과와 급전·소비·투자가 바뀐 효과를 분리한다. 분배 변화만으로 총후생의 증가를 주장하지 않는다.
- 가격 결정 모형과 운영 모형의 조건이 다르면 결과 차이를 제도 하나의 효과로 귀속하지 않는다.
- 부가정산금 감소나 특정 사업자의 수익 증가를 곧바로 효율 개선이라고 판단하지 않는다.
- 단순평균·가중평균, 권역·개별 지점, 대표 시간·전체 기간의 결과를 구별한다.
- 한계비용에 의한 결과에는 해당 최적화와 시장 가정이 있다. 비볼록성이나 시장지배력 등을 무시한 모형의 결론을 무조건 일반화하지 않는다.

가능한 경우 결론을 좌우하는 가정에 대해 민감도나 대안 시나리오를 확인한다. 계산을 수행하지 않았으면 예상 결과를 실제 모의 결과처럼 쓰지 않는다. 예시·시나리오 분석은 그 성격을 표시한다.

## 표·그림·수식

표와 그림은 독자가 비교하거나 관계를 이해하는 데 필요할 때 사용한다. 설명할 핵심 메시지를 먼저 정하고 그에 맞는 표현을 고른다. 본문에서 모든 값을 다시 나열하지 말고 중요한 차이, 원인 또는 해석상의 조건을 설명한다.

- 표·그림 번호, 제목, 대상·기간, 단위, 출처, 주석을 확인한다. 출처가 가공·재계산이면 그 사실을 밝힌다.
- 합계·비율·증감·순위·가중평균을 확인한다. 반올림 차이는 구분한다.
- MW와 MWh, 원/kWh와 원/MWh, 명목과 실질 가격, %와 %p를 혼동하지 않는다. 변환에는 시간과 환산 배수가 필요할 수 있다.
- 축·범례·범위·로그 축·생략 구간이 비교를 왜곡하지 않게 한다. 색상만으로 구별하지 못하는 경우 다른 표지도 사용한다.
- 수식의 기호와 단위를 정의하고 결과의 의미를 문장으로 설명한다. 수식 번호와 본문 참조를 대조한다.
- 본문·요약·표·그림에서 같은 지표는 같은 값과 정의를 사용한다.

표 제목 위·그림 제목 아래 등의 예시 관행은 제출 양식이 없을 때 선택할 수 있다. 기관의 서식이 우선이며, HWP 원본을 렌더링하지 않고 서식까지 검증했다고 하지 않는다.

## 인용과 참고문헌

요청 양식이 있으면 따른다. 없으면 저자-연도 또는 번호 방식 중 독자와 문서에 맞는 한 가지를 선택해 일관되게 쓴다. 사례 보고서의 두 방식을 섞어야 할 이유는 없다.

인용이 어느 주장에 해당하는지 가까이 배치한다. 직접인용은 원문과 쪽수를 확인한다. 재인용을 원문 확인으로 표시하지 않는다. 참고문헌의 저자·제목·연도·기관·식별정보를 대조하고, 본문 인용과 목록이 서로 연결되는지 확인한다. 웹 자료는 가능한 한 원자료의 날짜와 구체적인 문서 URL을 사용한다.

출처가 빠진 숫자, 원문을 확인하지 않은 인용, 문장으로만 존재하는 표·그림 참조는 최종본의 확인 대상이다. 조작된 참고문헌이나 임의 DOI로 빈칸을 채우지 않는다.
