# BeautyLinks 店舗サポート

BeautyLinks管理画面の操作を日本語で案内するプラグインです。予約・顧客・カルテ、営業設定、メニュー・スタッフ、販促・クーポン、店販・配送、契約・決済・権限に対応します。

## 使い方

プラグイン画面で「BeautyLinks 店舗サポート」をインストールし、新しいチャットで選択して質問してください。

- 「スタッフを追加したのに予約枠が出ない」
- 「誕生日クーポンの手動配信はどうする？」
- 「店販の注文を発送する手順を教えて」
- 「今この画面です。一つずつ教えて」

## 資料と対応範囲

2026年9月19日時点の店舗向け操作説明書93ページのテキストを17分野に整理し、FAQ32件と画面導線・権限の補足を同梱しています。図そのものや店舗固有の顧客・予約・支払いデータは含みません。資料は自動更新されません。

操作手順と確認方法を案内します。管理画面へのログイン、予約変更、LINE送信、返金などの実行機能は含みません。

## 配置・更新

`plugin.json` がポータブル形式の入口です。`.codex-plugin/plugin.json` は互換用の設定です。`skills/beautylinks-support/` に操作案内と参照資料を収録しています。外部サービスへの接続や追加の認証情報は不要です。

個人用カタログへの登録は作成環境で完了しています。別環境へ移す場合は、OpenAIの公式プラグイン作成手順に従ってこのフォルダをカタログへ登録してください。
https://developers.openai.com/plugins/build/plugins

管理画面が変更されたら、対応する参照資料と版情報を更新し、予約枠・クーポン配信・返金・権限の回答を再確認してください。
