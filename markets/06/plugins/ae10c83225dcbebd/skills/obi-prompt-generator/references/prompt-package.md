# Prompt package

Record source artifact versions, target provider and model, generation mode, aspect ratio, model-neutral master direction, provider prompt, reference mapping with intended control and priority, exclusions, provider settings, known risks, unresolved questions, and change summary.

Record `use_status` as either `working_private_draft` or `approved_provider_prompt`. A working prompt may support one-off private exploration but is not valid for formal submission, publication, or a costly batch.

The master direction should remain useful if the provider changes. Provider-specific syntax, weighting, parameters, and workaround language belong only in the provider prompt or settings.
