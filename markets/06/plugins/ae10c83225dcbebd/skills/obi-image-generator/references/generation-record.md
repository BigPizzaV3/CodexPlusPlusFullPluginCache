# Generation record

For each candidate record:

- generation ID and `use_status`: `working_private_draft` or `approved_generation`
- source composition, character, and prompt-package versions
- provider and model when known
- exact prompt, exclusions, settings, aspect ratio, seed when available, and generation time
- reference images with intended control and priority
- output identifier or durable file reference
- brief observed issues and review status

Append generations rather than overwriting earlier candidates. A generated output is private and unapproved until a person explicitly accepts it.
