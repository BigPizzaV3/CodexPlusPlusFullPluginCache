# Product overview
Audited baseline: VeTayStudio Desktop `1.0.6` on September 23, 2026.
VeTayStudio is a Windows PySide6 desktop application for a hand-drawn short-video workflow. The current main navigation labels are:
1. `Tổng quan`
2. `Dạng video`
3. `Prompt Video`
4. `Nội dung`
5. `Giọng đọc`
6. `Lịch đăng`
7. `Sản xuất Video`
8. `Bảng Điều Khiển`
9. `Thiết bị`
10. `Nhật ký`
11. `Cài đặt`
Support answers must verify the user's version before assuming labels or behavior. Current release work is in progress; do not describe `1.0.7` as publicly released.
The Desktop support bubble provides `Hỗ trợ trực tiếp qua Zalo`, `Nhóm cộng đồng Zalo`, and a pre-publication `Hỏi ChatGPT · Sắp có` state until a real public plugin URL is configured.
