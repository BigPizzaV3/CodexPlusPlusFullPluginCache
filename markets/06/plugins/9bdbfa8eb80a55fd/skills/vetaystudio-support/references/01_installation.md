# Installation
Use only an owner-provided official VeTayStudio installer or update channel. This package does not prove a public installer download URL, website URL, or public release page, so do not invent one.
Customer-safe checks:
1. Confirm Windows can open the installer and that the file came from the official owner/support route.
2. Close VeTayStudio before installing or updating.
3. Keep the user's projects and application data unless an official, version-specific recovery instruction explicitly says otherwise.
4. Do not instruct normal customers to install the source repository, Python, developer dependencies, or database tools.
5. If Windows security blocks the installer, ask for the exact Windows message and installer filename before advising.
If the installer is missing, damaged, or its origin is uncertain, escalate through the official Zalo links rather than supplying an unverified mirror.
