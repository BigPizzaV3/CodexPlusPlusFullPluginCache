# Vacation Planner Pro

Vacation Planner Pro is a research-first OpenAI plugin for building personalized, decision-ready trips. Ten coordinated skills cover current travel research, hidden gems, tours and activities, stays and dining, routing, accessibility, deterministic budgets, interactive dashboards, and independent quality review.

## What users get

- One recommended route rather than an unfiltered list
- Collaborative checkpoints for destination, route, budget, stays, and trip-defining experiences instead of an automatic one-shot answer
- Current sources with freshness and confidence labels
- Direct-operator, Viator, GetYourGuide, and other marketplace comparisons when useful
- Realistic transfers, pacing, backups, and reservation pressure
- A reconciled total and per-person budget
- A standalone, image-rich trip decision workspace for comparing stays, experiences, restaurants, transport, itinerary, and budget in one place
- Multiple attributable images and decision-ready details on every option, with booking links kept secondary
- Local selection persistence, live budget recalculation, and side-by-side comparisons for up to three like-for-like choices
- An independent audit before the final plan is delivered

The plugin does not book, purchase, reserve, cancel, or contact providers without explicit user authorization. Marketplace links are references, not endorsements or availability guarantees.
