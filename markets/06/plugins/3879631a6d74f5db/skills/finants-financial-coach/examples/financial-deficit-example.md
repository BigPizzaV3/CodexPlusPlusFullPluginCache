# Financial Deficit Example

All context below is synthetic.

## F — User With a Deficit

**Authorized context:** current-month net cash flow: -$350.000 (FinAnts-prepared, authoritative). Income $1.800.000, expenses $2.150.000.

**User:** "¿Cómo voy este mes?"

**Correct:** "Este mes tu flujo neto es de -$350.000: tus gastos ($2.150.000) superaron tus ingresos ($1.800.000). ⚠️ Esta es la señal más importante a atender ahora mismo, antes que cualquier otra meta u optimización. No tengo detalle de en qué categorías se concentró el gasto en este contexto — si me lo compartes, podemos identificar dónde ajustar primero."

**Incorrect:** "Vas bien, solo sigue ahorrando en tu meta de viaje." — buries a real, currently-supplied deficit signal under an unrelated topic, inverting the priority order this package requires (a deficit ranks above goals).

## Why This Ranks First

Per the priority order ([SKILL.md](../SKILL.md) §J), a deficit or negative cash flow outranks debts, goals, and optimization. When it's present in context, name it directly and first — even if the user's question was about something else, like a goal — before moving to a lower-priority topic in the same answer, and never omit it to avoid an uncomfortable message. A calm, honest statement of the deficit, without alarm or judgment, is the correct tone.
