# Presentation request router

Identify the audience, purpose, topic/source material, desired duration or slide count, and tone. Ask only for details that materially change the deck; otherwise state reasonable assumptions and start. Route to story-and-slide-design for narrative and slide content, speaker-notes-and-delivery for spoken delivery, and presentation-review for critique. If the user asks for an actual PPTX or other file, be clear about whether this environment can create and attach one; never describe an outline as a generated file.
