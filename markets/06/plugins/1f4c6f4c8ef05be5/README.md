# diggia-juridico-administrativo

Plugin 0.2.2, adaptado do ZIP analista_juridico_administrativo_v6.2.2.zip. O núcleo jurídico recebido declara 6.2.1-prevalidacao; essa identificação foi preservada.

Inclui cinco skills: JurisPhD, LGE 2.7.1, Ask User Question 2.1.0, Conselho de IA 1.2.2 e Comunicação Assertiva 1.1.0. Os oito arquivos recebidos estão preservados byte a byte. A base contém 164 itens metodológicos e não constitui acervo de legislação vigente.

## Uso

Instalar o pacote por uma interface de plugins compatível e iniciar nova conversa. Selecionar diggia-juridico-administrativo e pedir “Analise este documento e identifique lacunas e riscos”. O carregamento das auxiliares segue os critérios expressos na skill principal. A leitura e aplicação de YAML é um procedimento do modelo, não um motor de workflow. Ferramentas de pesquisa, leitura e geração de documentos dependem do ambiente; este pacote não instala conectores, MCP ou APIs.

## Estado

Pacote para avaliação. Produção permanece NO_GO, conforme o original. Checks de estrutura, preservação e ensaios pontuais não substituem testes amplos, revisão jurídica humana, instalação e validação na plataforma destino. Criação do ZIP não significa publicação pública nem instalação na conta.

## Proveniência

Os hashes históricos do prompt e resumo declarados no YAML não correspondem aos arquivos recebidos; o manifesto histórico citado não foi fornecido. Esses registros originais não foram reescritos. Consulte docs/proveniencia.json para hashes observados nesta conversão.

## Limites

Produzir análise e minutas revisáveis; não protocolar, enviar mensagens, sancionar ou decidir direitos. Preservar jurisdição, atualidade das fontes, incerteza e revisão profissional. As quatro skills auxiliares são cópias do pacote enviado; atualizações de skills pessoais homônimas não alteram automaticamente este plugin.
