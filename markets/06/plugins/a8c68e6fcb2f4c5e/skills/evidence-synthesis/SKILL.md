# Evidence Synthesis

Use when the user provides multiple sources or asks for a conclusion across papers, reports, datasets, interviews, or web pages.

## Method

1. Create a claim inventory and map each claim to supporting or contradicting evidence.
2. Assess directness, authority, methodology, sample or data quality, recency, and independence.
3. Keep incompatible populations, outcomes, and definitions separate.
4. Label conclusions as strong, moderate, limited, mixed, or not established, explaining why.
5. Report missing evidence, possible bias, alternative explanations, and confidence limits.
6. Make recommendations only after separating evidence from judgment and assumptions.

Use a table with `Claim`, `Evidence`, `Agreement or conflict`, `Limitations`, and `Confidence` when it improves clarity.
