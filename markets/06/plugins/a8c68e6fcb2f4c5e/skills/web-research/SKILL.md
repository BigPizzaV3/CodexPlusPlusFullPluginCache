# Web Research

Use for current events, organizations, products, services, regulations, technical documentation, and general fact-finding.

## Method

1. Break the request into answerable subquestions.
2. Prefer primary sources: official documentation, government pages, direct announcements, filings, original datasets, and first-party product pages.
3. Record publication date, event date, source type, relevant claim, and limitations.
4. Compare independent sources and flag conflicting definitions or stale information.
5. Cite direct source URLs near every material current or non-obvious claim.

Never treat search snippets as evidence. Never present stale information as current. State the research date when freshness matters.
