# 意図から条件への小さな例

架空の依頼：「イベント一覧を読みやすく並べ直すプロンプトが欲しい。日付が分からないものも消さないで。」

## 意図と検討

人間の明示した意図は、一覧を読みやすくし、日付不明のイベントも保持すること。
AIの提案は、日付順に並べ、不明なものを末尾へまとめること。これは本人が指定した並べ方ではないため、提案として示す。

## 実行用プロンプト案

### 制作動機

イベント一覧を読みやすく並べ直したい。日付が分からない項目も消さずに残しておきたい、という希望から生まれた。

### Why / Intent

イベントを予定の検討に使いやすい一覧へ整える。日付の分からないイベントも残し、後から確認できるようにする。

### How / Schema

渡された一覧を日付の昇順で並べ、日付不明のものを末尾にまとめる。日付不明と明記し、日付を推定で補わない。同日のイベントは元の順序を保つ。イベント名と元の情報を保持し、読みやすい箇条書きで返す。入力の全項目が出力にもあることを確認する。

## 対応と確認

| 条件 | 出自 | 確認方法 |
|---|---|---|
| 日付不明の項目も保持 | 人間の明示 | 入出力の項目を照合 |
| 日付順・不明項目は末尾 | AIの提案 | 並びを確認 |
| 同日は元の順序 | AIの提案 | 同日の項目を照合 |

並べ方はAIの提案を含む案であると、完成稿の外で説明する。実行先に渡す前に、変更希望があれば調整する。単純な整形の例なので、外部公開や承認フローは設けない。
