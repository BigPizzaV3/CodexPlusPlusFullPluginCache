# 会話の参加者への配慮：2026-09-16の追加改訂

## 人間の指摘と採用した変更

[参照先の範囲を選ぶ改訂](reader-reference-scope.md)の実利用では、Essayが無関係な会話を含む全体リンクを省き、制作部分だけを記事にした。利用者は、この判断を正しいと評価し、明示的な禁止なしで適切な判断を促せた理由を確かめた。

その後の対話で、読者にとって有用かと、無関係な発言まで紹介されることが会話の参加者にとって適切かは、別の問いだと指摘した。リンクを省いたという結果だけでは、参加者への配慮まで働いたとは判断できない。前の改訂は読者への資料選択を中心に書いていたため、利用者が提案した次の一文をEssayに加えた。

> チャット等の参照先を紹介する際は、読者への有用性に加え、無関係な発言まで公に届けられることが会話の参加者にとって適切かも確かめる。

Checkerにも、同じ観点を次の一文で加えた。

> チャット等を参照先として紹介している場合は、読者への有用性と、無関係な発言まで公に届けられることの会話の参加者にとっての適切さを、それぞれ確認する。

いずれも既存の参照先確認の説明への追加である。共有リンクの一律禁止や、すべての参照に承認を求める手順にはしていない。適切なものには完成を伝える方針を保つ。

## 実行結果

架空のノート検索画面の制作対話を使い、参照先の条件を3通りに変えた。各条件で追加版のEssayとCheckerを別々に実行し、全体ログの条件では追加前の現行版も比較した。計8実行は、それぞれ親の会話履歴・期待判定・他の実行結果を渡さない新しいCodexサブエージェントで行った。Checkerは事前に用意した記事をレビューし、今回のEssay出力や編集判断は渡していない。

| 参照先の条件 | 追加版Essay | 追加版Checker |
|---|---|---|
| 読者に役立つ設計議論と別件の会話を含む制作チャット。全体紹介の確認記録はない | 全体URLを省き、設計の16発言だけを番号・帰属付きの抜粋として作成し、記事を完成 | 読者への有用性を認めつつ、参加者にとっての全体紹介の適切さは確認不足と判断。必要な確認やリンク省略・抜粋への差し替えを提示 |
| 参加者が内容と記事からの紹介を確認した設計部分の抜粋 | 既存の抜粋リンクを採用し、記事を完成 | 修正不要。全体ログや追加の承認を要求しなかった |
| 雑談を含む全体公開・関連記事からの紹介に参加者が合意した公開対話 | 全体リンクを残し、記事を完成 | 修正不要。雑談があることだけを理由に削除や抜粋化を求めなかった |

全体ログの条件では、Checkerは記事中の「別件の会話も含みます」という読者への注記と、参加者にとっての紹介の適切さの確認を区別した。執筆記録の有用性確認だけで、後者も確認済みとは扱わなかった。

比較した追加前のEssayも同じ16発言の抜粋を作成し、追加前のCheckerも参加者に関する確認不足を指摘した。追加版は期待した資料選択と判定を行えたが、今回の比較から追加文による性能向上は示せていない。

## 検証の範囲

実際の原稿、リンク、抜粋、レビューと説明を照合した。新規抜粋の16発言が原資料と一致し、別件4発言と全体URLを含まないことを確認した。適切な抜粋と了承済みの公開対話では、指定のリンクが残ることも確認した。生成原稿は人間とAIの帰属、引用、未検証事項の扱いを保持した。

全体ログ用のレビュー原稿には、テスト準備時に混入した提案者の帰属誤りが一箇所あった。両版のCheckerはこれも指摘したため、この原稿全体を合格とは扱わず、参照先に関する判定を上表に分けて記載している。他の2条件には、実行前に帰属を訂正した原稿を渡した。

すべて合成資料であり、URLは架空の識別子、参照先は保存表示内容で評価した。実際のWeb閲覧の検証ではない。各条件・版・役割について一回ずつで、背景に公開経緯と確認記録の有無を明示している。手がかりが目立たない長い実対話での再現性や、反復成功率は検証していない。事後説明は内的判断過程の直接の証拠とは扱わない。

実行した追加版と反映する本文のSHA-256は一致している。

- Essay: `9d96dc556e711e65249d2a0ff058d6b037de6da8f0ba6ffa4c8f3d2e3d163c5c`
- Checker: `0d3e2fc38bdf715a82b5653a346ad535709680777cfc86b13856027d0746da21`

テスト入力・出力の全文はローカルに保存した。元の利用者の会話リンクや無関係な会話は、この公開記録には含めていない。[確認事例](../../skills/dialogue-checker/references/scenarios.md)には、今後の検証に使える3条件を追加した。
