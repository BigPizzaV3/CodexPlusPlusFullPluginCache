## Plugin name
Technical Interview Copilot

## Version

## Category
Productivity

## Short description
Prepare for tech interviews

## Long description
Role-aware technical interview preparation that adapts to the candidate profile, job description, seniority, stack, and interview stage. Build an interview map, study high-priority topics, run realistic mock interviews, practice coding and system design, deepen resume stories, and refine behavioral answers without inventing experience.

## Capabilities
- Map likely interview focus from a job description and candidate profile.
- Teach technical topics at role-appropriate depth.
- Run realistic one-question-at-a-time mock interviews.
- Practice coding, SQL, debugging, and system design.
- Deep-dive resume and project experience without inventing claims.
- Improve natural behavioral and spoken interview answers.
- Create time-boxed preparation and rapid-review plans.

## Starter prompts
1. Map this job description into the interview topics I should prepare first.
2. Run a realistic mock interview for this role, one question at a time.
3. Help me prepare my resume stories and technical follow-ups for this interview.
