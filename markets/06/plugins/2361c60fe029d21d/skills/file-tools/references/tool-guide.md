# FileStation website tool guide

Verified against published source version 43, 21 September 2026. These are website tools, not GPT API actions. Availability and plans may change.

Website: https://filestation.io

The GPT does not have account access or automatic draft synchronization. Website sign-in recovery is local to the same browser and tab, lasts up to 24 hours, and is not continuous autosave.

## Compress PDF

URL: https://filestation.io/tools/compress-pdf

Make a smaller PDF for easy sharing.

Limitations: Content-preserving mode keeps page content. Stronger image mode removes text selection, links, forms and signatures. Size targets are not guaranteed. Keep the original.

Steps:
1. Choose a PDF and select content-preserving or image compression.
2. For image compression, choose quality, resolution and an optional target size in KB.
3. Compare the before-and-after sizes, review the result and save a copy.

Will compression preserve selectable text?
The content-preserving mode keeps the existing page content without downsampling images. The stronger image mode flattens pages and removes selectable text, links, forms and signatures. Size targets are not guaranteed, and the original is retained if it is smaller.

## PDF to Word

URL: https://filestation.io/tools/pdf-word

Extract PDF text into an editable Word file.

Limitations: Text extraction only. Original layout, images and tables are not preserved. Scans need OCR first.

Steps:
1. Choose a PDF containing selectable text.
2. Run PDF to Word.
3. Download the DOCX and check paragraph order before editing.

Will the Word file look exactly like my PDF?
No. This tool extracts text rather than recreating the original design. Images, columns and table layouts are not preserved. Scanned PDFs need OCR, which is not provided by this tool.

## Merge PDF

URL: https://filestation.io/tools/merge-pdf

Bring multiple PDFs together in one file.

Steps:
1. Choose the first PDF, then use Add PDFs / Merge.
2. Drag page thumbnails into order and remove unwanted pages.
3. Choose Export PDF and save the combined document.

Can I reorder pages after merging?
Yes. Use the page organizer to drag thumbnails, rotate pages or delete unwanted pages before export. Review forms, links and signatures: the editor export may flatten or omit interactive features.

## Edit PDF

URL: https://filestation.io/tools/edit-pdf

Add text, highlights and drawings with a live preview.

Limitations: Tap a page to place content. Edit text replaces selectable words visually and flattens the affected page on export. Scanned text needs OCR.

Steps:
1. Open a PDF and select a page.
2. Choose Add text or Edit text, or open More tools for signatures, highlights, images, stamps, links, notes, search and page management.
3. Open the export centre, choose pages and format, then prepare and save your download.

Can I change the original words in a PDF?
Choose Edit text and tap a selectable text block to replace it visually. The affected page becomes an image on export, with the new text on top; other original text on that page is no longer selectable. This does not reflow surrounding content or recognize scanned text.

## Images to PDF

URL: https://filestation.io/tools/images-pdf

Turn JPG, PNG, BMP, GIF and WebP into a PDF.

Limitations: Choose A4, Letter or image-size pages, orientation and margins. Images follow the order shown. Your browser must be able to decode the selected image.

Steps:
1. Choose one or more supported images.
2. Use the ordering controls to arrange the images.
3. Create the PDF and download it.

Which image formats can I use?
JPG, PNG, WebP, BMP and GIF work when your browser can decode them. Other formats, including TIFF or HEIC, may need conversion to JPG or PNG first. Choose A4, US Letter or image dimensions; adjust margins before creating your PDF.

## PDF to JPG

URL: https://filestation.io/tools/pdf-jpg

Export PDF pages as high-quality images.

Steps:
1. Choose a PDF.
2. Choose the pages to convert and run the tool.
3. Download the JPG output and open the ZIP if multiple pages are included.

Can I edit the PDF text in the JPG output?
No. JPG is a raster image format. The visible page is rendered into pixels, so links, form fields and selectable text are not retained.

## PDF to PNG

URL: https://filestation.io/tools/pdf-png

Save crisp PNG images of your pages.

Steps:
1. Choose your PDF.
2. Choose the pages and start conversion.
3. Download the PNG output; multiple pages may be packaged in a ZIP.

When should I choose PNG instead of JPG?
PNG uses lossless image compression and can be useful for diagrams and text-heavy pages. It may produce larger files than JPG. Neither format retains PDF text selection or forms.

Will CSV conversion keep my IDs and nested objects?
