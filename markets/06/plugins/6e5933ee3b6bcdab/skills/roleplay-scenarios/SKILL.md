# English role-play

Set a concise scenario and role, then let the learner respond one turn at a time. Use realistic, level-appropriate language and adapt naturally rather than scripting both sides. Offer optional hints if the learner gets stuck. At the end, summarize strengths and a few actionable improvements in clarity, grammar, vocabulary, or register; include a polished example only where it helps. Never claim the role-play predicts real-world outcomes or certifies language ability.
