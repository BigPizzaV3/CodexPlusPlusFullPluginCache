# Unofficial NCAP Advisor plugin

Portable, skills-only Agent Plugins package for ChatGPT and Codex.

## What it contains

- `plugin.json` — portable Agent Plugins manifest and OpenAI listing metadata
- `skills/ncap-outdoor-advisor/` — the supplied v3 skill and references
- `assets/` — square plugin icon/logo assets

## Important publisher note

Before public submission, replace `author.name` and `extensions.com.openai.interface.developerName` with the exact verified individual or business identity you will use in the OpenAI Platform, unless that verified identity is literally "Unofficial NCAP Advisor".

This is a skills-only plugin and has no MCP server, external authentication, or external data service.
