# Scouting America source hierarchy and version control

Use this reference for substantive Scouting America policy/compliance questions.

## Official starting points

Begin with the current official landing page when practical, then follow its links to the currently controlling publication, circular, manual, FAQ, form, or interpretation.

- NCAP: https://www.scouting.org/outdoor-programs/camp-accreditation/
- Guide to Safe Scouting: https://www.scouting.org/health-and-safety/gss/
- Scouting Safely: https://www.scouting.org/health-and-safety/
- Outdoor Programs: https://www.scouting.org/outdoor-programs/
- Range & Target Activities: https://www.scouting.org/outdoor-programs/range-activities/
- COPE and Climbing: https://www.scouting.org/outdoor-programs/cope/
- National Camping School: https://www.scouting.org/outdoor-programs/national-camping-school/

These are starting points, not the complete source list. Follow current official links to the operative resources.

## Preferred authority

Prefer resources hosted on:

- scouting.org
- filestore.scouting.org
- another domain clearly operated by or officially linked by Scouting America

Do not use council websites, blogs, social media, forums, unofficial summaries, or obsolete BSA publications to establish current national policy when the requirement can be verified in current official Scouting America material.

## Freshness check

Before relying on a publication:

1. Check publication date, revision date, edition, or effective date.
2. Check the topic landing page for a newer edition or replacement.
3. For NCAP, check the current NCAP Standards **and** current NCAP Circulars.
4. Check official FAQs, interpretations, notices, or program webpages that may clarify the base publication.
5. Do not knowingly answer from a superseded publication.
6. If an older source is useful historically, label it historical/superseded.

## Multiple-source questions

For an NCAP camp question, normally consider as applicable:

- Current NCAP Standards
- Current NCAP Circulars
- Guide to Safe Scouting
- Current program-specific manuals/guidance
- SAFE Checklist
- National Camping School requirements
- Age-appropriate activity guidance
- Current official FAQs/interpretations
- Applicable government law/regulation

NCAP Circulars may supply controlling implementation guidance or clarification. Program-specific manuals may add requirements beyond general NCAP standards. Guide to Safe Scouting may direct leaders to program literature and applicable government regulation.

## Conflicts and overlap

When two provisions appear different:

- explain both;
- determine whether they apply to different circumstances;
- determine whether both must be satisfied;
- when both apply, explain the more restrictive practical result if appropriate;
- identify unresolved ambiguity;
- never silently discard one source.

## Citation precision

For controlling Scouting America requirements, cite the narrowest useful authority:

- publication name
- edition/revision/effective date
- standard number if applicable
- section/heading
- printed page number if available
- official URL

If PDF viewer numbering differs from printed page numbering, prefer the publication's printed page and optionally clarify the viewer page. Never invent a page number.
