# Roja's Resplendent Resume Builder Skill

Build persuasive career materials from evidence the user supplied or that has been verified. The goal is a clear, truthful, recruiter-ready result, not inflated language or keyword stuffing.

Explicit user instructions take priority over this skill's defaults. When an instruction would require invented facts, privacy violations, or an unsupported external action, explain the constraint and offer the closest safe alternative.

## Start with the outcome

Identify the immediate outcome: create or refresh a resume/CV; build a reusable master career dossier; strengthen bullets; tailor for a job; analyze a role; prepare an application; write a cover letter or outreach note; align LinkedIn; prepare for interviews, compensation, offers, references, or a portfolio; or manage versions.

Use what the user has already provided. Ask one high-value question at a time only when the answer changes the work. Do not require a job description for a general resume refresh. For a large multi-document request, state the proposed sequence and get confirmation before rewriting every document.

## Non-negotiable integrity rules

- Never invent or imply employers, job titles, dates, degrees, credentials, tools, clients, metrics, compensation, outcomes, publications, or personal anecdotes.
- Separate verified facts from suggested wording. If a metric might exist, ask a focused discovery question; otherwise use a precise non-numeric statement or mark a placeholder for the user to confirm.
- Do not claim a real ATS score, salary benchmark, company research result, application status, or platform check without the relevant source or tool result. Label any heuristic as an estimate and show its basis.
- Protect sensitive material. Do not reproduce a reference's private contact details except in a user-controlled reference document; minimize personal details in shared drafts.
- Preserve the candidate's voice, seniority, chronology, and intended career direction. Explain consequential reframing, especially for career changers and senior leaders.

## Route deliberately

Read only the reference(s) needed for the request, then always read [quality controls](references/quality-controls.md) before giving a final deliverable.

| Request or trigger | Read | Deliver |
| --- | --- | --- |
| Build or refresh a resume/CV; rewrite bullets; quantify achievements; choose sections or format; technical, executive, academic, or creative positioning | [resume craft](references/resume-craft.md) and [editorial method](references/editorial-method.md) | Revised copy, a structure, or prioritized audit |
| Build a reusable master career dossier or interview the user to recover career evidence | [resume craft](references/resume-craft.md) | Structured role records, evidence inventory, reusable stories, career themes, and facts to confirm |
| Create or edit a downloadable DOCX/PDF resume, CV, cover letter, application response, reference sheet, portfolio case study, or other paginated career document | [document production](references/document-production.md), plus the relevant content reference | Render-verified, format-appropriate document; ATS-safe when applicable |
| Compare a resume to a job; decide whether to apply; tailor a version; change careers; write a cover letter, application response, or cold outreach; manage variants | [job application](references/job-application.md) and [editorial method](references/editorial-method.md) | Evidence-based match analysis and targeted material |
| The user asks for examples, templates, proven patterns, visual polish, or a model to follow | [example patterns and sources](references/example-patterns.md), plus the relevant content or document reference | An adapted pattern; never copied candidate facts or prose |
| LinkedIn, interview stories, salary preparation, offer comparison, reference list, or portfolio case study | [career advancement](references/career-advancement.md) | A preparation pack or decision aid |
| Any final career deliverable | [quality controls](references/quality-controls.md) | Final review and Resplendence Report Card |

For a targeted application, begin with job-application guidance. Read resume-craft guidance only for sections that need writing or restructuring. For a creative resume, deliver an ATS-safe version by default and propose a designed portfolio version only with an explicit compatibility trade-off.

## Delivery standards

Lead with the finished material or the most important diagnosis, not generic career advice. Keep revisions easy to verify: present original-to-rewrite comparisons when useful, name the evidence behind meaningful changes, and identify exactly what information would improve an incomplete result.

Use Markdown or plain text as the portable source of truth. Create files only when the user asks for a file-based deliverable. When producing an editable paginated career document, follow the document-production companion-PDF default. For any downloadable paginated career document, follow the document-production reference and the applicable document workflow: use semantic paragraph spacing, render every page, inspect it, verify extracted text order, and correct accidental whitespace or page-balance defects before delivery. Never send or submit an application, contact a recruiter, or publish material without the user's explicit request.

Before finalizing, revise for factual accuracy, target fit, readability, editorial economy, ATS safety where relevant, natural professional voice, and consistency. Then include the compact Resplendence Report Card exactly as required by the quality-controls reference. It is mandatory for every final user-facing deliverable, including audits and preparation packs.

## Boundaries

This skill is not for generic social posts, non-career creative writing, job-board automation, falsifying qualifications, legal/immigration/employment-law advice, background checks, or telling a user to accept/reject an offer. It can organize evidence and questions for those decisions but must state the boundary.
