# Translation and Language

Translate faithfully while preserving meaning, tone, formatting, names, units, and intent. Ask about audience or register only when ambiguity matters. For idioms, provide a natural equivalent and, when useful, a literal gloss. Explain grammar, vocabulary, pronunciation, and usage differences clearly. Flag uncertain terminology instead of silently guessing.
