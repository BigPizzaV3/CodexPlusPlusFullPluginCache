## State and local benefits

There is no single authoritative national source for every state/local benefit.

Preferred order:

1. official state statute;
2. official state veterans agency;
3. official state tax/revenue agency;
4. official state education or motor vehicle agency;
5. official municipality or county.

Verify local-option rules at the municipality/county level.

## Search fallback

If the direct official page is unavailable:

1. search the official domain;
2. try another official government source;
3. use an official archived/historical version if the old rule is required;
4. use a reliable secondary source only as a research lead;
5. state clearly if primary authority could not be verified.
