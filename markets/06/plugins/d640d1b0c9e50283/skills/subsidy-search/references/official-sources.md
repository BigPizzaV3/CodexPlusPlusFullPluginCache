# 公式情報の探し方

入口URLは調査経路であり、制度の条件や受付状況を固定した一覧ではない。検索時点の公募ページ・要領・最新のお知らせで確認する。主な候補は現在受付中の制度とする。公募開始済み・申請受付前の制度は、公式の日程を確認したうえで別欄に分ける。終了した回は出さない。

| 探す対象 | 入口 | 確認する情報 |
|---|---|---|
| 国・自治体の横断検索 | https://www.jgrants-portal.go.jp/ | 制度名、実施主体、年度・枠・回、受付期間、公式資料 |
| 中小企業向け国の施策 | https://www.chusho.meti.go.jp/ | 制度事務局への公式リンク、公表資料 |
| 省力化投資補助金 | https://shoryokuka.smrj.go.jp/ | 一般型とカタログ注文型、公募回、最新版、対象設備 |
| 旧制度の新事業進出補助金 | https://shinjigyou-shinshutsu.smrj.go.jp/ | 公募回、要領、FAQ、締切・変更のお知らせ |
| 旧制度のものづくり補助金 | https://portal.monodukuri-hojo.jp/ | 締切回、申請枠、要領の版、特例要件 |
| 小規模事業者持続化補助金 | https://www.chusho.meti.go.jp/keiei/shokibo/ | 一般型・創業型等、商工会・商工会議所の所管、事前発行書類の期限 |
| IT・デジタル投資 | https://www.chusho.meti.go.jp/ | 当該年度の制度名称・公式事務局・登録ツール等の条件 |
| 自治体制度 | 都道府県・市区町村の公式サイトを検索 | 投資場所、予算終了、事前相談、交付決定前の契約制限 |

地域補完では「市区町村 + 用途 + 補助金 + 年度」のような一般語を使い、自治体公式サイトから公募ページへ戻る。会社名・住所番地・資料の文章・相談内容を検索語にしない。実施主体が委託した事務局の独自ドメインもあるため、省庁・自治体等の公式ページからその関係を確かめる。

利用者が「何に使えるか分からない」と言うときは、業種から想定できる用途を選択肢として提案する。実際の投資予定や予算があることを捏造しない。国の大型制度だけに偏らず、投資の規模や準備期間に合う地域制度も探す。Jグランツ0件は制度なしを意味しない。検索障害と、正常に検索して該当なしだった状態を分ける。

PDFでは、年度・枠・公募回・版を表紙と本文で確認する。検索結果の古いPDF、採択結果、以前の公募告知は現在の受付の根拠にしない。補助金の上限額・補助率・締切・事前手続きは当該回の要領と最新のお知らせで照合する。公式に訂正があれば新しい訂正を優先し、資料間の矛盾が解消できなければ推薦を保留する。

募集期間が終了しているものは表示しない。先着順・予算到達による終了、受付停止、商工会等の必須書類の発行期限にも注意する。締切の時刻を補完しない。締切当日で時刻や現在の受付を確認できないとき、あるいは「予算に達するまで」で受付継続が確認できないときは、受付中の候補に含めない。次回の公募は公式に予告されている場合だけ、受付中の候補とは別に扱う。

利用者との会話でWeb・PDFを読んで作った要約は、その利用者の会話・本人向けレポートにだけ用いる。パッケージ内の事前公募一覧は開発者が公式の公開情報だけから作成した読み取り用資料であり、利用者の会話・個社情報・回答を共有保存する場所ではない。独自の検索サーバーは使わない。

新事業進出・ものづくり商業サービス補助金など名称が似た統合・新設制度は、中小企業庁などの現行公式告知から事務局を確認する。旧制度の入口や要件を同一制度として流用しない。

事業者向けの補助金全般を対象に、国・都道府県・市区町村を確認する。創業、販路、研究開発、省エネ、雇用等も、目的に応じて所管の省庁・自治体・公的支援機関の公式ページから調べる。上表にない制度を除外しない。網羅できたとの保証や、未検索の地域に制度がないとの断定はしない。
