# 公式条件を本人の状況と照合する

現在の同じ制度・年度・枠・回の公式資料を使い、根拠のURL・資料名・版・実際の確認日時・必要なページを会話内で保持する。次の条件を「一致」「不一致」「未確認」に分ける。初回から全項目の回答を要求せず、候補の判断に関わる不足だけ聞く。

| 確認項目 | 確認する内容 |
|---|---|
| 地域 | 本店所在地と実施地の違い、自治体内の条件 |
| 業種・申請者 | 対象・除外業種、法人・個人、兼業等の例外 |
| 企業規模 | 当該要領で定義された人数・資本金、AND／ORの関係 |
| 用途・経費 | 対象経費、最低額、税込税抜、設備や登録製品の条件 |
| 発注時期 | 契約・発注・交付決定の順序、着手済みの扱い |
| 事前手続き | ID、相談、証明書等、それぞれの期限と完了状況 |
| 制度固有条件 | 賃上げ、生産性、新規性等と例外・特例 |

例えば「資本金または従業員数」の条件は、一方が不一致でも他方が不明なら対象外と断定しない。一方が一致して判断がつく場合に、他方を不要に聞き直さない。複雑な例外を都合のよい単純条件に変えない。

不明な人数・金額を0で埋めない。概算を実績や厳密な条件判定の値に変えない。事前手続きの完了は同じ手続きについてだけ使い、別制度へ流用しない。「条件がない」は公式資料で確認できた場合だけとし、未読を制限なしにしない。

確実な不一致があれば推薦から外す。主要条件が未確認なら候補としての未確認点を明示する。受付自体が未確認なら受付中の推薦表には載せない。公式資料の調査不足はAIが解消し、本人に要領の調査を丸投げしない。照合はAIによる補助であり、自動審査・申請資格の確定ではない。
