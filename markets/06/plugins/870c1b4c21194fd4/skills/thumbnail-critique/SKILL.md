## Score each 1-5 and say why
1. **Small-size readability** - does it work at 320x180
2. **Focal point** - is there exactly one, and is it big enough
3. **Text** - word count, size, contrast, does it repeat the title
4. **Color** - separation, accent discipline, survives light and dark themes
5. **Emotion** - does the face or scene carry a feeling
6. **Curiosity** - does it raise a question or answer it too early
7. **Promise match** - will the video deliver what this implies
8. **Pattern break** - does it stand out from the competing set
9. **Technical** - resolution, crop, safe zones, artifacts, file size

## Output
- **Top 3 fixes first**, each as an exact instruction ("crop to chest-up so the head fills 45% of the height", "drop 'HOW TO' and keep 'IT BROKE', set to 200 px", "darken background to #0D1017 and add a #00E5FF rim light")
- **What already works** - keep it
- **A rewritten layout spec** for the improved version
- **One alternative concept** worth testing against it
