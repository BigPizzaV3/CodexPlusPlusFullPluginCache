## What it is for
Pikzels is an AI generator built specifically for YouTube thumbnails, rather than a general image generator. That focus matters: the output tends to arrive already composed like a thumbnail, with room for a subject and text.

## Workflow that gets the best results
1. **Write the concept first** using hook-concept or youtube-thumbnail, so you prompt with a decided idea rather than a vague topic.
2. **Prompt with structure:** subject, expression, framing, lighting, background, palette, copy space side. Ask for no text in the image.
3. **Set up a persona** with clear photos of the creator's own face so the same person appears consistently across videos. Only use a face you have the rights to.
4. **Recreate or reference** a layout pattern you have studied - take the structure, not the artwork.
5. **Edit in plain language:** change the expression, the background, the lighting, the color of one element, rather than regenerating from scratch.
6. **Generate titles** alongside, then run them through title-packaging so the title and the image are not saying the same thing.

## Check before using any generated thumbnail
Hands, eyes, teeth, ears, jewellery, text artifacts, logos, and background objects that look melted. Then run mobile-check at 320x180, add your real typography in a design tool, and export per export-specs.
