## The test
View the thumbnail at 320x180, 246x138 and 168x94. Better still: squint, or blur it 4 px. What survives is what the viewer gets.

## Checklist
| Check | Pass condition |
|---|---|
| Primary text | Readable at 320x180 without effort |
| Face | Expression identifiable at 246x138 |
| Focal point | Still obvious when blurred |
| Colors | Subject separated from background when desaturated |
| Detail | No element that only exists below 320x180 |
| Light theme | Does not wash out (no white-on-white edges) |
| Dark theme | Does not merge (no black-on-black edges) |
| Timestamp zone | Bottom-right clear of key content |
| Progress bar | Bottom 8% clear of key content |
| Sidebar crop | Nothing critical near the extreme edges |

## Fixes by failure
- Text too small: cut words, then enlarge. Never shrink to fit more.
- Face unreadable: crop tighter, raise contrast on the eyes and mouth.
- Merges with theme: add a 6-10 px border or a bright rim element.
- Detail lost: delete it. If it only matters up close, it does not matter.

Report each check as pass or fail with the exact fix.
