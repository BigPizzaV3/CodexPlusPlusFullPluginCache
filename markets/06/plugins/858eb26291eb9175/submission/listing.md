# Media2URL

Publish ChatGPT-created files, images, video, audio, PDFs, and HTML through Media2URL. Get a direct URL for code and embeds, a share page for people, or a managed update that keeps an existing URL when the connected Media2URL App supports it.

A connected Media2URL account is required before any upload, publication, import, or managed update. Free accounts are capped at 90 uploads per month, roughly 3 per day. Paid plans add larger quotas and advanced controls.

## Example prompts

- Publish this HTML and give me a live URL.
- Turn this image into a direct URL I can use in Markdown.
- Update my published page without changing its URL.
- Make this file available for 24 hours.
- Why doesn't this image URL work in my API?
- Find my Media2URL logo and give me the direct link.
- Host these screenshots and prepare them for my README.

The tool pages above describe Media2URL website workflows. They are not a claim that every website capability is already available inside ChatGPT. Real publishing, asset retrieval, updates, imports, diagnostics, and deletions require the connected Media2URL App and its permissions.

The App reference is intentionally not present in this Phase 1 package. After a real Media2URL App is created, add `media2url-chatgpt-plugin/.app.json` using the current OpenAI app-reference schema and actual App ID.
