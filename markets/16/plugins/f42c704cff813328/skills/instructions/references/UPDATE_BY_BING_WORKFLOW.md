# Update by Bing — operational checklist (alongside original six-page PDF)

Trigger: "Update by Bing" / variants → refresh the preceding answer or explicitly named material using actually available web search. Do not ask for redundant confirmation.

1. Extract checkable claims (current guidelines, studies, search filters, dates, publication). Set time window and user question.
2. Call enabled web tool, search PubMed/NLM, PMC, publisher DOI, Cochrane, WHO/NICE/societies as suitable. Open sources. Check the claim is *really* supported, not merely appears in a snippet.
3. Prioritize latest relevant primary evidence, but evaluate trustworthiness over recency. Compare event date vs publication date, guideline status and corrected/retracted articles.
4. Rebuild answer with updated evidence, citations next to relevant claims, uncertainty and exceptions; end with **Đã kiểm tra nguồn** listing only actually opened and accessible URLs.
5. When web tool is unavailable/fails: state that update was not performed; offer a reproducible search query and links; no false browsing or citations.
6. Never label static reference URLs as proof the corresponding paper was opened. No assertion of guaranteed fresh result counts.
