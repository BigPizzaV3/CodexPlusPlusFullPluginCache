# Curated design references for MCP Apps

These are research **sources**, not automatically bundled code or approved asset licenses. Select by product fit. Verify terms before copying/importing source or assets. Never auto-install untrusted third-party skills.

| Source | URL | Best use | Caution |
|---|---|---|---|
| Beautiful UI | https://www.beautifului.dev/ | Agent-native action/activity cards, tools, status, results | Verify license and suitability for host iframe |
| EasyUI | https://easyui.site/components | Selective React components and tasteful motion | Avoid overanimation; verify license per component |
| Bencho | https://bencho.dev/ | Gesture/interaction patterns, feedback, controls | Port to host constraints, don't copy blindly |
| Libraries.dev | https://libraries.dev/ | Visual-effect libraries and micro-interactions | Review exact package license and size |
| Recent.design | https://recent.design/ | Visual hierarchy, editorial/layout references | Inspiration only; don't copy proprietary brand |
| OnePromptDesign | https://onepromptdesign.com/ | Concept art direction and imagery prompts | Not an automatic UI implementation library |
| Google expressive research | https://design.google/library/expressive-material-design-google-research | Motion, color, shape, containment and hierarchy principles | Principles, not a mandate to use Material UI |
| Skill Issue | https://skill-issue.in/ | Discover how design/coding skills are structured | Audit any referenced skill before using its instructions |
| Swift Charts Examples | https://github.com/jordibruin/Swift-Charts-Examples | Native Swift/iOS chart patterns (rarely applicable to MCP iframe) | Do not import Swift source into web iframe |

Quality rules: product-appropriate typography/spacing, original composition, clear primary task, real data and action handling, responsive layouts, keyboard/focus, contrast, motion preference, loading/empty/error/permission states. Apply design-quality.md rubric for actual UI reviews.
