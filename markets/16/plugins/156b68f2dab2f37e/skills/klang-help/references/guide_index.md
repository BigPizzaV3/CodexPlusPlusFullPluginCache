## Purpose

This is a navigation index for KLANG AI Help. Use the packaged KLANG knowledge files to explain KLANG; use this index to point users to relevant published ReadMe guides.

**Verification status:** These URLs were extracted from the local source documents, **not independently fetched or confirmed live** during this build. Before presenting a link as verified, check it or use a subsequently verified index. Never invent a missing URL.

## Reference selection rules

- Offer a relevant guide link proactively when walking a user through a concrete interface operation, but do not overwhelm them with links.
- Use the most specific relevant guide. If unsure of the match, describe it as a possible reference, not a verified exact procedure.
- Screenshots and videos must be explicitly indexed and verified before claiming they appear on a page.
- If ReadMe retrieval fails during future updates, retain the previous entry with an unverified/stale status rather than silently deleting it.
- Keep this index separate from the product ontology and procedural knowledge.
