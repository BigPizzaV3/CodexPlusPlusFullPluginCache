# Oracle Health Data Intelligence landing page

Reference for the Oracle Health Data Intelligence overview page bundled with this plugin.

## Overview

**Enable Workflows with Oracle Health Data Intelligence**

**Connect clinical data. Activate intelligence.**

Oracle Health Data Intelligence (HDI) brings clinical data, semantic intelligence, and agentic workflows together so healthcare teams can move from fragmented data to actionable clinical and operational intelligence.

**HDI Overview**

Explore guided capabilities across clinical workflow intelligence, cohorting and analytics, ontology mapping, care gap identification, care coordination, patient-level insight generation, and research.

## Capabilities

These descriptions explain the product capabilities shown on the overview page. This information skill does not execute those workflows.

All seven capability cards are informational. Use the Contact Oracle Health and Request a Demo buttons to open the published Oracle website.

| Capability | Published description |
| --- | --- |
| Semantic Intelligence | Use ontology-aware data services to resolve clinical terms, codes, and concepts across connected health data sources. |
| Cohorting & Analytics | Ask population-level clinical questions in natural language, such as identifying uncontrolled diabetes cohorts or surfacing population trends. |
| Care Gap & Quality Workflows | Identify missing therapies, overdue labs, open care gaps, and quality opportunities for human review before downstream action. |
| Care Coordination | Assemble timelines, medication history, open referrals, active tasks, interaction risks, and care gaps for care teams. |
| Patient-Level Insight | Generate structured, traceable patient-level insights from connected clinical data and domain-specific agents. |
| Ontology Mapping | Map FHIR, ICD-10, LOINC, SNOMED CT, RxNorm, and related source data into canonical ontology contexts. |
| Research | Explore connected clinical data for research discovery, cohort feasibility, study planning, and evidence generation workflows. |
