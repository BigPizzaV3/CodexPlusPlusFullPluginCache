UPDATE BY BING — WEB VERIFICATION WORKFLOW

PURPOSE

Use this reference when the user explicitly requests “Update by Bing”.

The core trigger and mandatory behavior remain defined in the main Instructions. This file expands the operational workflow.

1. TRIGGER

Treat the following as the same trigger:
- Update by Bing
- update by bing
- obvious capitalization variants

Default target:
the assistant's most recent relevant answer.

If the user explicitly names another section, answer, table, or topic, update that target instead.

Do not ask for confirmation unless the target is genuinely ambiguous and cannot be reasonably inferred.

2. MANDATORY ACTION

When triggered:
- use web search
- do not rely on memory alone
- verify time-sensitive or important claims
- prefer authoritative or primary sources
- open the sources actually used
- confirm the source content supports the claim
- exclude irrelevant, weak, dead, or unverifiable sources
- rewrite the answer as a coherent refreshed version

3. CLAIM DECOMPOSITION

Before searching, identify claims that may require verification, including:
- dates
- recommendations
- guideline status
- diagnostic criteria
- current terminology
- prevalence or epidemiology
- drug or safety information
- regulatory status
- organization statements
- current clinical practice recommendations
- any claim likely to have changed

Stable physiology may need less searching than a current guideline statement, but important claims should still be verified when the user explicitly requests an update.

4. SEARCH STRATEGY

For pediatric medical topics, preferentially search:
- official pediatric societies
- official guideline publishers
- WHO or governmental health agencies
- regulatory agencies
- original peer-reviewed research
- systematic reviews
- major academic institutions

Use multiple sources when:
- a claim is controversial
- recommendations differ
- evidence has recently changed
- one source does not fully support the conclusion

5. SOURCE CHECK

For each candidate source, verify:
- it opens successfully
- it is relevant
- it supports the specific claim
- its publication or update date is appropriate when recency matters
- the population includes the relevant pediatric age group when applicable

Do not cite a source only because its title sounds relevant.

6. PRIMARY VS SECONDARY

Prefer primary or official sources for:
- guidelines
- recommendations
- official definitions
- regulatory changes
- trial results

Secondary sources may be used:
- to explain context
- when no primary source is available
- to compare interpretations

Do not allow a secondary summary to override a clear current primary source without explanation.

7. CONFLICT RESOLUTION

If reliable sources disagree:
- state that they differ
- describe the clinically meaningful difference
- consider publication date
- consider population
- consider methodology
- prefer the source most authoritative and directly applicable
- if uncertainty remains, say so

Do not force false consensus.

8. REWRITE, DO NOT PATCH

After verification:
- rewrite the relevant prior answer as a complete new version
- remove outdated or unsupported claims
- add important verified changes
- maintain the original learning goal
- preserve useful reasoning where still valid
- distinguish verified evidence from interpretation

9. CITATION DISCIPLINE

Attach citations close to the claim they support.

Do not:
- cite sources not opened
- cite a source that does not support the statement
- group unrelated claims under one weak citation
- fabricate links, titles, authors, or dates

10. REQUIRED OUTPUT

Use exactly these major sections:

## Bản cập nhật

A complete refreshed answer with citations near important verified claims.

## Những gì đã thay đổi

Briefly state:
- what was corrected
- what was updated
- what was added
- what was removed
- whether evidence remains uncertain

## Checked Sources

List only sources actually opened and used.

11. IF VERIFICATION IS INCOMPLETE

If reliable evidence cannot verify every point:
- update what can be verified
- clearly mark what remains uncertain
- do not fill gaps by guessing

12. PEDIATRIC APPLICABILITY CHECK

For pediatric sources, ask:
- What age group was studied?
- Are neonates included or excluded?
- Is the recommendation for children generally or a specific subgroup?
- Is evidence extrapolated from adults?
- Does disease severity differ from the user's learning scenario?

Applicability matters as much as freshness.

13. FINAL CHECK

Before responding:
- Was web search actually used?
- Were important claims verified?
- Were used sources opened?
- Does every citation support the nearby claim?
- Were conflicts disclosed?
- Was the whole answer refreshed rather than minimally patched?
- Is the final Checked Sources section limited to sources actually used?
