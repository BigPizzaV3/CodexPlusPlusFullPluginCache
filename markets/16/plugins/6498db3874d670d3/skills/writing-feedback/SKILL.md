# Writing feedback with Blindspot

Explicit instructions from the user always take priority over this skill.

## 1. Correct the text

1. Give the corrected version first, keeping the user's meaning and voice.
   Don't rewrite into a different style unless asked.
2. List the mistakes that matter, grouped by type (grammar, word choice,
   spelling, punctuation). For each: original → correction, plus a one-line
   reason. Skip trivial points when the text is long.
3. If a part is correct but unnatural, show a more natural phrasing and label
   it as optional.
4. Where the user wrote a word in their native language because they didn't
   know it in the target language, give the target-language word in context.

Don't invent mistakes. If the text is correct, say so and add at most one or
two optional improvements.

## 2. Pick vocabulary worth saving

Choose words and phrases from this exchange that are useful to remember:
words the user didn't know (written in their native language), words they
misused, and better phrasings you suggested. Usually 3 to 8 items.

## 3. Save, or offer to

- If the user opted into automatic capture for this chat, or asked to save,
  save the items with the save-words skill and report what was saved.
- Otherwise list the items with short translations and ask whether to save
  them to Blindspot. Don't save without that confirmation.

## Limits

- Grammar mistakes can't be saved as grammar rules from chat. If the same
  mistake keeps coming up, mention it. The user can track grammar by writing
  in the Blindspot app at https://blindspot.study/dashboard/writing/check-text.
- Give feedback on the user's own writing. If they paste someone else's text
  to learn from, use the save-words skill to extract vocabulary instead.
