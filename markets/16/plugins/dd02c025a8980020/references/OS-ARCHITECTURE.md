# Brand Builder OS Architecture

The OS is modular. Route by intent and readiness; a person can enter at any stage and skip irrelevant workflows. Preserve the evidence and consent boundaries across every handoff.

| Journey capability | Workflow |
| --- | --- |
| Entry, sequencing, routing, and checkpointing | `brand-builder-orchestrator` |
| Current market, category, and competitor research | `market-research` |
| Primary customer research planning and synthesis | `customer-discovery` |
| Delivery, cost, pricing, capacity, experiment feasibility | `business-feasibility-validation` |
| Personal brand foundation | `brand-from-scratch`, `brand-strategy` |
| Company/product/service brand foundation | `business-brand-from-scratch` |
| Brand diagnosis, governance, and portable summary | `brand-audit`, `brand-management`, `executive-brand-summary` |
| Visual identity and creative direction | `visual-brand-strategy` |
| Content strategy and journey alignment | `brand-content-strategy`, `content-strategy` |
| Scripts, captions, assets, and platform drafts | `content-creation` |
| Campaigns and ongoing content operations | `campaign-planning`, `content-manager` |
| Search, platform adaptation, and performance learning | `social-intelligence-seo`, `repurposing-analytics`, `measurement-optimization` |
| Founder and customer narratives | `storytelling`, `case-study-builder` |
| Permission-based capture, qualification, and sales readiness | `lead-generation` |
| Delivery experience, feedback, retention, and referrals | `customer-experience-retention` |
| Manual process maturity and responsible automation/AI | `systems-ai-readiness` |
| Optional direct-selling/network-marketing path | `network-marketing-growth` |
| Optional regulated IUL educational content | `iul-content-tool` |
| Language detection and localization workflow | `language-workflow` |

## Cross-workflow controls

- Evidence provenance and truth labels travel with every handoff.
- A public interaction is not private-contact permission; engagement is not consent to data collection or sales follow-up.
- A designed process is not an operating process; an intended standard is not a measured outcome.
- A tested hypothesis advances only the evidence it actually tests. It does not establish market-wide demand or overall business viability.
- Optional specialist paths do not import project-specific facts into unrelated projects.
