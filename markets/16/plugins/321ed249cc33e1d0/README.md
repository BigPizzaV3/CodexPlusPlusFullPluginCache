# PBJConnect plugin

Ask questions about authorized facility aggregates from PBJConnect in ChatGPT or Codex.

Install the plugin and choose Connect in ChatGPT. Sign in on PBJConnect, select the organizations to share, and approve. The plugin honors current membership. Manage or revoke access at https://pbjconnect.com/plugin/chatgpt.

Included workflows: organization-wide historical analysis, quarter review, saved staffing forecasts, and daily census reconciliation. The remote tools perform deterministic data retrieval and calculations; the host assistant explains the result.

This release returns aggregate information only. It does not expose residents, employee rosters, arbitrary SQL, stored procedure execution, connector control, or CMS submission actions. Missing data, demonstration overlays, and distinct census sources remain labeled.

The backend is hosted at PBJConnect. No local database driver or OpenAI API key is required by this plugin. A PBJConnect account and an eligible ChatGPT or Codex environment are required. Host and PBJConnect subscription terms apply.
