# HỌC DƯỢC — v0.3.0 | Release notes

Ngày chuẩn bị: 2026-10-24 (giờ Việt Nam)

## Thay đổi từ v0.2.1
- Giữ định danh package `gpt-d1eb5355a8123bbb5f7674865f7d0fae`, biểu tượng PNG và cả hai tài liệu PDF gốc **không thay đổi byte**.
- Cập nhật Skill cho 8 chế độ học, ranh giới bệnh nhân thực và hướng dẫn không xử lý định liều trực tiếp.
- Thêm workflow: PK/PD, tính toán minh họa, interaction, ADR, PGx, EBM, MCQ, Update by Bing.
- Bổ sung tài liệu markdown về nguồn, số liệu, kỹ thuật học, chống ảo và thực thi web trung thực.
- Chỉnh metadata và 3 Conversation Starters, gắn 4 URL HLP Plugin Hub.
- Không thêm các khai báo giá hoặc phạm vi phát hành không cần thiết cho Skills-only.

## Phạm vi xác minh
Static validation và so sánh checksums được tiến hành tại chỗ; **không** thay thế đánh giá OpenAI hoặc chạy Plugin Preview. Trang HLP chưa thể được truy cập bằng công cụ web trong quá trình đóng gói, cần kiểm tra thủ công trước submit.
