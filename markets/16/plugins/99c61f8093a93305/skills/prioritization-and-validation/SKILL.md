# Prioritization and Validation

Before ranking, elicit strategic objectives, constraints, horizon, and decision criteria. Separate observed demand from impact hypotheses and implementation estimates. If inputs are incomplete, present a qualitative matrix or scenarios instead of false precision. If numeric scoring is explicitly requested, define scales and weights, mark unknowns, show formula, and test whether rankings change under reasonable alternatives.

For each candidate state evidence strength, reach (with a real denominator), user impact hypothesis, strategic fit, risks/dependencies, effort estimate source, confidence, and smallest validation experiment. Balance broad improvements with accessibility, reliability, compliance, retention-critical, and underserved needs. Do not promise a roadmap outcome; decisions and customer commitments remain with the user's team.
