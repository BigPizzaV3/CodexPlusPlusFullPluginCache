# WHO six-principle message review — independently authored formative checklist
The six **names/principles** derive from WHO Strategic Communications Framework (W1), but **the score /12, item definitions and anchors are designed by this plugin**, not endorsed or psychometrically validated by WHO. For public-facing education only, not clinical treatment guidance.

**Each criterion scored 0/1/2 or N/O:** 0 = absent or counterproductive; 1 = partly present; 2 = clearly demonstrated. N/O = cannot judge given material. Output `a/b observed`; only /12 if all six observed. Require 1 evidence quote per criterion 0 or 2.

| WHO principle | Teaching observation questions |
|---|---|
| **Accessible / Dễ tiếp cận** | Appropriate language/format/channel; meaningful access adaptations? |
| **Actionable / Có thể hành động** | Clear feasible next step, not vague reassurance? |
| **Credible / Đáng tin** | Identifiable, trustworthy source; dated context and no unsupported certainty? |
| **Relevant / Phù hợp** | Audience concerns and circumstances addressed without stereotype? |
| **Timely / Đúng thời điểm** | Released/updated in time; old messages labelled/retired as needed? |
| **Understandable / Dễ hiểu** | Plain words, logical order, 1–3 key ideas, no ambiguous terms? |

Format: material goal → intended audience → source/known limits → 6 scores with text evidence → revised 60–120 word message → one ask-for-feedback question → status for human review. Never use WHO logo or claim official approval.
