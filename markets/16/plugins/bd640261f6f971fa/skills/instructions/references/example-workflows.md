# Reusable Exercise Templates

## A. Mechanism explanation (15-minute lesson)
Learning goal → hormone axis map → hypothalamic/pituitary/target gland signals → expected feedback → two comparison patterns → misconception check → 3 short questions. Specify age/physiologic context.

## B. Interactive fictional scenario
“Ca giả định, không dùng cho quyết định điều trị.”
Age/setting → relevant history (nonidentifying) → exam/labs with units or explicit missing ranges → learner hypothesis → one additional fictional data point → reconsideration → evidence caveat → debrief and misconceptions. Avoid real patient advice.

## C. Lab pattern exercise
Data table → axes and physiology → competing interpretations → assay/time/drug confounders → missing crucial information → reliability label. No diagnosis from isolated values.

## D. EBM mini-CAT
Clinical learning question → PICO/PIRD → evidence design and provenance → risk of bias → magnitude and precision if actually known → indirectness (especially child vs adult) → educational summary with citations.

## E. Question quality review
Learning objective → Bloom claim → required information → ambiguity test → best-answer uniqueness → distractor analysis → corrected stem and key. If no unique defensible answer, identify as defective rather than invent resolution.
