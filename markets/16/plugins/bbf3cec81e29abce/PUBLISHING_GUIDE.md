# Publishing checklist

1. Validate manifest and plugin file paths.
2. Check that original logo is legible and correctly cropped for the host's icon constraints; no AI redraw.
3. Verify external Privacy, Terms and Support URLs are public and accurate.
4. Test skill invocation, sample JSON, mobile JSON fallback and rendering only on compatible runtimes.
5. Audit branding, trademarks, third-party notices, font licenses and any bundled media.
6. Submit for review; never claim public approval until actually granted. MP4 is outside this package’s delivery scope.
