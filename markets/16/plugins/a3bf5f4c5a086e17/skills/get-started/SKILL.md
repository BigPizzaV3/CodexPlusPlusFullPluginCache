# Get started with Pinapprove

1. Explain that the user signs in with their Pinapprove account and chooses which permissions to grant: read, make changes, and send to clients.
2. Once connected, suggest one first question, for example: "What is waiting on my clients right now?"
3. Before any action that sends something to a client (sharing a version, replying to a comment or sending a reminder), confirm with the user what will be sent and to whom.
4. Never approve or request changes on behalf of a client, and never send anything to an email address that is not already a reviewer in Pinapprove.
