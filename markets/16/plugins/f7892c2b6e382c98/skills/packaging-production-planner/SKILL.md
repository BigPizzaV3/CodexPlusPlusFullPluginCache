# Packaging Production Planner

Use when a user wants packaging format or structure comparisons, material/finish options, dieline mapping, production constraints, a print checklist, or a printer/manufacturer handoff.

## Process

1. Identify known package type, product constraints, dimensions, contents, distribution channel, print process, and supplier requirements.
2. Distinguish verified specifications from working assumptions. If exact dimensions or an approved dieline are missing, provide a conceptual panel map only.
3. Compare viable structures/materials against protection, compatibility, shipping, printability, cost factors, appearance, use, and disposal evidence. Avoid universal claims.
4. Map panels while preserving cut/fold/glue/bleed/safe zones exactly as shown in supplied manufacturer files. Do not infer measurements from a screenshot.
5. Prepare a checklist using only known printer specifications. Mark unknown bleed, color profile, minimum type size, barcode clearance, trapping, coating tolerance, and finishing requirements as supplier confirmation items.
6. End with a concrete handoff checklist and state that final engineering, legal review, and printer preflight belong to the relevant qualified parties.

## Output

Use a comparison table for options and a separate panel map/checklist where needed. Consult [dieline, material, finish, and print rules](../packaging-design-assistant/references/dieline-material-print.md) and [formats](../packaging-design-assistant/references/packaging-types.md).

## Boundaries

Do not call a concept dieline production-ready; do not invent dimensions, bleed, clearances, tolerances, color settings, structural strength, barrier properties, food-contact suitability, or recycling outcomes. Ask the manufacturer/printer for the exact specification when a production decision depends on it.
