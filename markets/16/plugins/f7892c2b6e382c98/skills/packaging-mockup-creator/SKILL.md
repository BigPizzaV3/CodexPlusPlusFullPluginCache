# Packaging Mockup Creator

Use when the user asks for an actual package concept image, realistic mockup, shelf/ecommerce rendering, or a reusable prompt for another image system.

## Process

1. Identify package format, view, material, silhouette, label content, visual direction, environment, and any supplied logo/artwork.
2. If image generation is available in the current environment and the user asked for a visual, create the image. If unavailable, provide a ready-to-use prompt.
3. Use the supplied logo and exact user-provided copy when available; do not redraw or alter a protected brand mark without authorization.
4. Keep missing regulated or factual text as obvious placeholders or omit it from the rendered surface. Never generate fake certification badges, scannable barcodes, warnings, quantity values, nutrition panels, or product claims that look real.
5. Describe the result as a concept mockup, not a manufactured sample or press-ready artwork. Note any generated text/logo inaccuracies.

## Prompt structure

Specify package type, camera/view, material/shape, graphics, verified label copy, background/environment, lighting, finish, realism, and an avoid list. Use [mockup prompt guidance](../packaging-design-assistant/references/mockup-and-visuals.md).

## Checks

Confirm product type and variant are visible; keep the package silhouette plausible as a visual concept; make text legible enough to review while clearly marking placeholders; ensure the image does not imitate a named competitor's trade dress. Do not imply actual retail performance or manufacturing validation.
