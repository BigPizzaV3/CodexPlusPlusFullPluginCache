# French–Vietnamese Medical Terminology
## High-risk terminology, false friends, abbreviations, and normalization rules

Use this Knowledge file for French ↔ Vietnamese medical, healthcare, scientific, academic, and professional translation. Its purpose is **not** to force a single equivalent for every term, but to reduce mistranslation in high-risk or context-dependent expressions.

## 1. CORE PRINCIPLES

1. Translate the **clinical function and meaning**, not the surface form.
2. Prefer established Vietnamese medical terminology.
3. Never strengthen or weaken certainty, severity, causality, recommendation, or obligation.
4. When a French term has several valid Vietnamese equivalents, select by:
   - specialty;
   - document type;
   - target audience;
   - France vs other Francophone usage;
   - surrounding clinical context.
5. Keep terminology consistent within the same document.
6. Do not invent expansions for abbreviations.
7. Preserve drug names, doses, routes, frequencies, concentrations, units, laboratory values, and ranges exactly in meaning.
8. When an exact Vietnamese equivalent is unavailable, use the closest accurate term and retain the French term in parentheses if this improves precision.
9. If ambiguity could change clinical meaning, flag it briefly rather than guessing.
10. A glossary entry below is a **default mapping**, not an instruction to ignore context.

## 12. ABBREVIATIONS: SAFE HANDLING

### General rule
- Preserve an abbreviation if it is standard and unambiguous for the target audience.
- At first occurrence, expand it when this improves clarity.
- If several expansions are possible, infer only when surrounding context makes one clearly correct.
- Otherwise preserve the abbreviation and flag ambiguity.

## 13. MODALITY AND DEGREE OF CERTAINTY

Preserve the exact force of the source:

| French | Typical force | Vietnamese guidance |
|---|---|---|
| peut | possibility/capability | có thể |
| pourrait | weaker/hypothetical possibility | có thể; có khả năng; có thể sẽ |
| devrait | expectation or recommendation | nên; dự kiến; có lẽ sẽ — context decides |
| doit | obligation/necessity | phải; cần |
| il faut | necessity | cần/phải |
| il convient de | formal recommendation | nên/cần |
| il est recommandé de | explicit recommendation | được khuyến cáo/nên |
| il est possible que | possibility | có thể rằng/có khả năng |
| il est probable que | probability | có khả năng cao/nhiều khả năng |
| sous réserve de | conditional qualification | với điều kiện; tùy thuộc; với lưu ý rằng |
| semble | appears | có vẻ |
| suggère | suggests | gợi ý/cho thấy |
| démontre | demonstrates | chứng minh/cho thấy rõ, only if source evidence supports it |
| associé à | association | liên quan với |
| entraîne / provoque | causal wording | gây ra/dẫn đến |

Never translate **associé à** as “gây ra” unless the source itself establishes causality.

## 14. NUMBERS, UNITS, DATES, AND TYPOGRAPHY

1. Do not change the numerical value.
2. Preserve decimal meaning when converting French comma decimals to Vietnamese/English-style conventions.
3. Keep units attached to the correct number.
4. Never silently convert mg ↔ µg, mmol/L ↔ mg/dL, mL ↔ L, or body-weight dosing.
5. Preserve ranges and inequality signs exactly.
6. Preserve:
   - mg/kg/dose;
   - mg/kg/j;
   - mL/kg/h;
   - mmol/L;
   - UI/IU;
   - percentages;
   - gestational weeks;
   - centiles/percentiles.
7. For dates, adapt format only when ambiguity is removed.
8. In French output, apply normal French spacing and punctuation conventions where possible.
9. Do not “correct” unusual laboratory units without confirming that the source contains an error.

## 15. DRUG NAMES AND PRESCRIBING LANGUAGE

- Prefer INN/DCI when the source is generic.
- Preserve brand names exactly unless the user asks for standardization.
- Do not substitute a locally available brand.
- Do not alter formulation:
  - comprimé = viên nén;
  - gélule = viên nang;
  - sirop = siro;
  - suspension buvable = hỗn dịch uống;
  - solution buvable = dung dịch uống;
  - suppositoire = thuốc đạn;
  - solution injectable = dung dịch tiêm.
- Frequency:
  - 1 fois/jour = 1 lần/ngày;
  - 2 fois/jour = 2 lần/ngày;
  - toutes les 6 heures = mỗi 6 giờ;
  - si besoin = khi cần.
- Duration:
  - pendant 5 jours = trong 5 ngày;
  - jusqu’à = cho đến khi/đến;
  - à renouveler = lặp lại/gia hạn theo ngữ cảnh.
- Never infer missing duration, route, concentration, or indication.

## 16. AUDIENCE ADAPTATION

### Healthcare-professional text
Prefer precise technical equivalents and preserve conventional abbreviations when appropriate.

### Patient-facing text
Prefer plain Vietnamese:
- “hypertension artérielle” → “tăng huyết áp”;
- “dyspnée” → “khó thở”;
- “ictère” → “vàng da”;
- “prurit” → “ngứa”;
- “voie orale” → “đường uống”.

Do not oversimplify consent, warnings, dose instructions, or red flags.

### Academic/scientific text
Preserve:
- study design;
- uncertainty;
- statistical terminology;
- association vs causation;
- outcome hierarchy;
- methodological limitations.

## 17. WHEN TO FLAG AMBIGUITY

Flag briefly when any of these could materially change meaning:
- RCP;
- mutation;
- perfusion;
- prise;
- contrôle;
- bilan;
- tolérance;
- malaise;
- sévère vs grave;
- RGO vs RGO pathologique;
- dosage vs posologie;
- “sensible” outside a clearly microbiological context;
- regional abbreviations;
- specialty-specific acronyms;
- unclear drug brand names;
- unclear units or decimal separators.

Suggested format:
> **Ambiguity:** “RCP” may mean *Résumé des caractéristiques du produit* or *Réunion de concertation pluridisciplinaire*. In this context, it most likely means … because …

Do not add an ambiguity note if context already makes the meaning clear.

## 18. QUALITY-CONTROL CHECK BEFORE FINAL OUTPUT

For high-stakes medical translation, silently verify:

- [ ] No omitted sentence, number, unit, dose, qualifier, or negation.
- [ ] No invented diagnosis, mechanism, recommendation, or explanation.
- [ ] Certainty/modality is preserved.
- [ ] Association was not converted into causation.
- [ ] Drug names and dosing are unchanged in meaning.
- [ ] Abbreviations are expanded only when justified.
- [ ] Technical terms are consistent.
- [ ] Patient-facing language remains understandable.
- [ ] French syntax has not been copied unnaturally into Vietnamese.
- [ ] False friends were checked.
- [ ] Any clinically meaningful ambiguity is clearly marked.
