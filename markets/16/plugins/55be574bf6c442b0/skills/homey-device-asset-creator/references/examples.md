# Example workflows

## Round sensor

Prompt: Create all Homey driver assets from the attached round sensor photo. Clean it up first and preserve its visible openings.

Use the reference to retain the circular housing, the offset opening and the paired curved slots. Clean the photograph, derive the three PNGs from one master, and draw a separate SVG. Simplify slot interiors if they merge at 32 px. The bundled preview illustrates a previous image cleanup; compare the original photo before copying any detail.

## Wall switch

Prompt: Create the complete asset set from these front and side photos of my wall switch. Keep its button layout.

Preserve button count, orientation and housing depth. Keep real button symbols when readable in the photo. In the SVG, use separated outlines for buttons; omit microscopic printed labels rather than inventing replacements. Multiple references must resolve to the same physical variant.

## Glass device with display

Prompt: Create Homey driver images and an SVG for this thermostat. Preserve the glass finish and visible display.

Use photo cleanup to retain glass reflections and actual screen content. Avoid guessing digits, LEDs or controls. In the SVG, represent the display frame and major controls with black lines. Use vector paths for essential display symbols, only when they remain readable.

## Incomplete references

If the device silhouette or control layout is unclear, ask for a better view. If a product link cannot be opened, proceed with adequate supplied images and mention the missing reference only if it affects the result. Respect an explicit request for just one output.
