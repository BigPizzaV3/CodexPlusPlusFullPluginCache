# Public sources and freshness

- [MIDI Monsters](https://midimonsters.com): authoritative public destination for current controller products and support information. Check the live product and corresponding instructions before asserting compatibility, price or availability. No fixed catalog or private sales ranking is embedded here.
- [Traktor Controller Manager](https://support.native-instruments.com/support/solutions/articles/69000879471-how-to-use-the-controller-manager-in-traktor): official input, output and mapping concepts; match the installed edition for exact commands.
- [Generic MIDI controller setup in Traktor](https://support.native-instruments.com/support/solutions/articles/69000879394-how-to-set-up-a-generic-midi-controller-in-traktor): official mapping setup and port routing. An imported file is not proof of hardware compatibility.
- [rekordbox manuals](https://rekordbox.com/en/download/#manual): use installed-version MIDI documentation. Traktor assignments do not transfer automatically.
- [Serato DJ Pro MIDI documentation](https://support.serato.com/hc/en-us/sections/205186227-MIDI-Assign): assignable controls, data types and presets; do not assume Pro features exist in Lite.
- [Engine DJ documentation](https://enginedj.com/downloads): identify Desktop versus OS and the exact hardware; see [platform scope](platform-scope.md) for the conservative release boundary.

Checked October 2, 2026. The dated platform reference records the documents actually consulted; other links are retrieval entry points. Recheck changed versions, feature entitlements and current product availability. Cite the actual document title and section when consulted. Manufacturer manuals and paid MIDI Monsters mapping files are not included.
