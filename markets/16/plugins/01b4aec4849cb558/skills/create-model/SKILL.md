# 3DJ model studio

Use the connected 3DJ MCP tools. Discover the actual catalogue before calling tools; the 32 deployed tools and their scopes are recorded in `references/capabilities.md`. Never invent modelling, export, checkout, or shipping tools.

1. Establish the object, intended use, overall dimensions in millimetres, and any required interfaces. Ask only for dimensions that affect function; otherwise state provisional dimensions and proceed. Distinguish decorative concept mesh generation from measured parametric CAD.
2. For decorative or organic geometry, call `list_providers`, then `generate_from_text` or `generate_from_image_url`. Image input must be a direct public HTTPS image URL; do not publish private attachments to make a URL. Generation consumes the user's allowance. Return the `modelId`, poll using `get_generation_status`, and pass through actual failures or retryable provider/quota errors truthfully. A successful start is not a finished model.
3. For measured printable meshes and parameter refinement, use `openscad_get_starters` (public) and `openscad_compile_model` (requires `models:write` scope). Adapt the supplied OpenSCAD source and declared numeric parameters. Pass the user's actual printer build volume when known (e.g. Prusa MINI: `[180,180,180]` mm); otherwise leave it unspecified. To refine a design, adjust the `parameters` or `code` and re-run `openscad_compile_model` to verify the updated bounding box, closed-manifold status, and bed fit. Compilation uses a separate validation allowance (20/hour, 100/day), not AI generation credits. This tool does not save a gallery record or return an STL download; direct the user to open the portable `.scad` source in the 3DJ OpenSCAD workbench (`https://www.3dj.app/workspace`) to preview and export an actual binary STL.
4. For measured solid B-Rep CAD, ISO 10303 STEP exports, or live Three.js configurators, call `cad_get_starters` (pass `index: true` for a lightweight starter list), adapt the returned Replicad/OpenCascade DSL and `Param.*` declarations, then call `cad_validate_script` or `cad_get_configurator`. Both build the script in the isolated OpenCascade kernel and return measured geometry and per-body `parts`; `cad_get_configurator` also returns the normalized `Param.*` schema, connectors, `placeAt` joints, BOM, and pinned CDN URLs (`@neuraldeep/3dj-runtime` and `<threedj-configurator>`) and can load a saved `modelId` from 3DJ. For a requested model file, use `cad_export_model` with the requested format and any known part selection; for a requested engineering drawing, use `cad_export_drawing` with `pdf`, `svg` or `dxf`. Both create a new file at a publicly reachable URL; make that clear before exporting if the user has not already agreed to shareable access. Use `cad_save_model` when the user asks to save. Use `cad_publish_configurator` only on an explicit request to publish a public configurator. Label its public share link separately from the workbench link. Do not retry any of these three actions blindly: each successful call creates a separate file or publication.
5. Use `list_my_models`, `cad_list_models`, and `get_model_download_url` (requires `models:read` scope) only for the authenticated user's models. Report the `format`, `downloadUrl`, and `refinementHandoff` actually returned. A GLB download is a non-parametric concept mesh, not an STL or a print-ready CAD solid.
6. Present the result with dimensions, assumptions, downloadable assets actually returned, and the next edit that would improve function. When fabrication or a print quote is requested, use the `print-production` skill.
7. To move the part into another tool, call `compose_design_brief` (public) with the `code`, `parameters` and any material / finish / colour / intended-use details. It returns a product render brief (`sketchmonkey.arguments` ready for SketchMonkey Design Studio's `render_concept` or `render_video` tools) and `handoffs` with exact import steps for Blender (GLB, or the 3DJ Studio Blender add-on), FreeCAD and Fusion 360 (STEP) and slicers (STL). Never describe a brief as a render.

Authentication: `openscad_get_starters`, `cad_get_starters`, `cad_validate_script`, `cad_render_views`, `cad_check_assembly`, `cad_compare_revisions`, `cad_get_evidence_schema`, `compose_design_brief` and `cad_get_configurator` are public (`noauth`). All other tools require an authenticated 3DJ account via **OAuth 2.1 + PKCE** (`https://www.3dj.app/.well-known/oauth-authorization-server`) or a per-user **Bearer API key** (`3dj_live_...` minted at `https://www.3dj.app/agents`). Never request an API key or token in chat, never pass credentials or `userId` in tool arguments, and never reuse a shared key across users.
