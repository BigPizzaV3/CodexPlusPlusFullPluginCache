# AuditIn72

Understand what works and what needs improving on your own business website. AuditIn72 provides evidence, understandable scores, practical next steps, and a reasoned assessment of repairs versus a broader redesign.

## Start an audit

Supply a website URL and, optionally, your main visitor goal: enquiries, bookings, sales, or finding information.

> Audit my website at https://example.com. Explain the biggest supported issues, give me practical quick wins, and help me decide whether targeted fixes are enough.

You do not need to provide a name, email address or phone number, register with SiteIn72, or request a quote to receive the findings.

## What you receive

- A plain-language summary of what works and what to improve first.
- Technical SEO, on-page SEO, performance / Core Web Vitals, accessibility, UX / mobile, conversion journeys, security hygiene, and content-quality findings.
- Weighted category scores and evidence coverage, with untested areas clearly identified.
- Evidence, severity, likely impact, confidence, effort assumptions, concrete fixes and acceptance tests.
- Quick wins, an ordered improvement plan, and an evidence-based repair/redesign decision.
- A brief you can use yourself or hand to a designer/developer, plus a workflow for rechecking completed fixes.

Completed audits carry a single neutral attribution: "This audit was provided by SiteIn72." The report contains no sales offer, paid-service referral, quote invitation, pricing, or purchase link. Attribution never changes scoring or recommendations.

## How it works

This skills-based ChatGPT plugin contains a fixed 40-check method, evidence schema, report template, and an offline standard-library Python scoring calculator. It uses the browsing and inspection tools available in the chat. It has no separate MCP server, paid API dependency, autonomous background scanner, publisher-operated lead endpoint, or client database.

Live inspection requires appropriate browsing tools. Mobile/manual accessibility testing requires a browser. Lab performance requires an actual test or report; field Core Web Vitals requires actual real-user data. Missing capabilities or evidence are marked untested. Metrics, test coverage, traffic loss, conversion lift, and security or accessibility assurances are never invented.

The optional calculator uses Python 3.10+ and performs no network calls. It scores recorded evidence; the skill collects that evidence first. When code execution is unavailable, the same documented formula may be calculated manually and labeled accordingly.

## Data and measurement limits

The plugin does not automatically send your website URL, report, or conversation to SiteIn72. It does not collect contact details to unlock an audit. ChatGPT and browsing or external tools retain their own normal data practices. If you independently visit or contact SiteIn72, that separate interaction follows the website's applicable policies.

Scores describe observed quality within the declared sample. They are not search rankings, predictions of enquiries or revenue, security certifications, or WCAG conformance certificates. A low or incomplete score does not by itself justify replacing your website. Useful findings and an improvement plan remain available in the conversation.
