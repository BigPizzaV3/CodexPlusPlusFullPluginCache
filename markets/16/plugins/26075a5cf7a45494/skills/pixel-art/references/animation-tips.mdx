## Start From the Right Image

Animation must be cohesive with the starting image.

If you want a running animation, start from a character that already looks ready to run.

Use the [Edit feature](#change-the-pose-with-edit) to change the pose of your character.

If the still image is standing straight, the model won't be able to correctly loop a running animation.

## Before You Animate

Clean the still image first.

Animation uses the current edited image in the editor. Fixing small details and outline gaps often helps create a better animation.

If you imported your own image, use genuine pixel art with a clean, consistent grid and a pose suited to the motion.

## If the animation is wrong

Go back to the still image, adjust the pose or silhouette, then generate a new animation.
