# AI creation update · 18 October 2026 · 2026-10-18.2

The live creation tool now supports native numeric, sorting, multiple-answer and ordering responseType values and private responseSettings. Numeric requires kind=numeric, expected, tolerance and unit. Sorting requires kind=sorting, groups and items with label/group. Multiple-answer also uses variant=multiple, two groups (selected first), scoring all/partial. Ordering uses variant=ordering, groups ['1','2',...], one private correct rank per labelled item and scoring all/partial. The compiler supplies prompt and marks from the question. Always include the private expectedAnswer and markingNotes too. Do not substitute prose or require post-import setup for these supported responses.

Use section.layout=section to put a complete titled section in one task space; items uses individual pages. Titles always render even without an introduction. Use descriptive question titles and avoid duplicating numbering/marks in prompts. Use empty points for blank plot-points grids; completed plotted points belong only in private answerGraph. Keep source tables read-only and answer tables separately editable.
