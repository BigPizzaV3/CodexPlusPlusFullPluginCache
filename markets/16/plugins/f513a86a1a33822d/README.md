# StrandAlert public publication package

Version 1.0.7.

This package contains the public submission materials for StrandAlert.nl.

Publisher: StrandAlert.nl
Countries: Netherlands (NL), Belgium (BE)
Languages: Dutch and German
Commerce: no purchases or payments through the plugin

The Terms of Service URL supplied by the publisher is the same public StrandAlert page used for the privacy section: https://strandalert.nl/nl/hoe-we-meten#privacy

The package is prepared for public submission. Portal attestations, review, approval and publication are separate online steps.
