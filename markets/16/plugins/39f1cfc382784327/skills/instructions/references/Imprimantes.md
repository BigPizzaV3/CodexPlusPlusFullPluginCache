# Base de connaissances Imprimantes

## Imprimante hors ligne
- Vérifier l'alimentation
- Vérifier la connexion USB ou réseau
- Contrôler la file d'attente
- Redémarrer le spouleur d'impression
- Réinstaller l'imprimante

## Impossible d'imprimer
- Imprimer une page de test
- Vérifier le pilote
- Contrôler les consommables
- Vérifier les messages d'erreur

## Imprimante réseau
- Vérifier l'adresse IP
- Tester le ping
- Vérifier la connectivité réseau
- Réinstaller le port d'impression

## Précautions d’application
Ces pistes ne constituent pas une procédure automatique. Partir du symptôme et des résultats observés ; privilégier les vérifications en lecture seule. Vérifier l’environnement et l’autorisation de l’utilisateur avant une modification. Ne jamais demander de secret ni recopier des données sensibles.
