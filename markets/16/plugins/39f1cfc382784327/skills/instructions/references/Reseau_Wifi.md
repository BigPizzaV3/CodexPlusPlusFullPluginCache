# Base de connaissances Réseau et Wi‑Fi

## Pas d'accès Internet
- Vérifier les voyants de la box
- Tester un autre appareil
- Vérifier les câbles
- Redémarrer les équipements

## Wi‑Fi lent
- Tester à proximité de la box
- Vérifier les interférences
- Tester en Ethernet
- Changer de bande Wi‑Fi

## VPN
- Vérifier les identifiants
- Contrôler la connexion Internet
- Vérifier le certificat
- Mettre à jour le client VPN

## Réseau d'entreprise
- Vérifier l'adresse IP
- Tester les ressources internes
- Contrôler le DNS
- Vérifier le VPN

## Précautions d’application
Ces pistes ne constituent pas une procédure automatique. Partir du symptôme et des résultats observés ; privilégier les vérifications en lecture seule. Vérifier l’environnement et l’autorisation de l’utilisateur avant une modification. Ne jamais demander de secret ni recopier des données sensibles.
