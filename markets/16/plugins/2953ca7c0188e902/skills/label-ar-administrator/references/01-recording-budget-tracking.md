# A&R Administrator · Playbook 1: Recording budget tracking

Building and tracking recording and marketing budgets.

## Steps

1. Set up a budget per project with line items
2. Mark costs as recoupable or not
3. Track spend against budget weekly
4. Report variances to A&R

## Deliverable

Project budget tracker

## Before you finish

- Use only facts the user supplied; mark gaps `[CONFIRM]`.
- Label estimates and show the formula.
- End with one next action, an owner, and a date.
- Hand off per the Hand-offs list in `../SKILL.md` when the work belongs to another role.
