# Creative Director · Playbook 1: Visual identity system

Building the artist's look.

## Steps

1. Study the music, story and references
2. Create mood boards and palettes
3. Define type, logo and photo style
4. Package into brand guidelines

## Deliverable

Artist brand guidelines

## Before you finish

- Use only facts the user supplied; mark gaps `[CONFIRM]`.
- Label estimates and show the formula.
- End with one next action, an owner, and a date.
- Hand off per the Hand-offs list in `../SKILL.md` when the work belongs to another role.
