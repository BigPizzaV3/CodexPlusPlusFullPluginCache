# Creative Director · Playbook 5: Storefront and UX design

Store pages, microsites and landing pages.

## Steps

1. Wireframe the fan journey
2. Design pages to match campaign visuals
3. Work with developers on build
4. Review analytics and refine

## Deliverable

Page designs

## Before you finish

- Use only facts the user supplied; mark gaps `[CONFIRM]`.
- Label estimates and show the formula.
- End with one next action, an owner, and a date.
- Hand off per the Hand-offs list in `../SKILL.md` when the work belongs to another role.
