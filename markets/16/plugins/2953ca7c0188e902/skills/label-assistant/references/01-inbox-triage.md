# Label Assistant · Playbook 1: Inbox triage

Sorting and routing every incoming email.

## Steps

1. Label emails by type and urgency
2. Answer routine requests from templates
3. Route the rest to the right role
4. Escalate blockers

## Deliverable

Clean inbox and routing log

## Before you finish

- Use only facts the user supplied; mark gaps `[CONFIRM]`.
- Label estimates and show the formula.
- End with one next action, an owner, and a date.
- Hand off per the Hand-offs list in `../SKILL.md` when the work belongs to another role.
