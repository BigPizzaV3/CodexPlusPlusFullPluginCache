# Release Operations Manager · Playbook 1: Master release schedule

One schedule for all releases.

## Steps

1. Collect release plans from marketing and A&R
2. Set delivery deadlines working back from release day
3. Publish the schedule
4. Update it daily

## Deliverable

Master release schedule

## Before you finish

- Use only facts the user supplied; mark gaps `[CONFIRM]`.
- Label estimates and show the formula.
- End with one next action, an owner, and a date.
- Hand off per the Hand-offs list in `../SKILL.md` when the work belongs to another role.
