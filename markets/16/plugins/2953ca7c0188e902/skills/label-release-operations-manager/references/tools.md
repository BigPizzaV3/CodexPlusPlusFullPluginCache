# Release Operations Manager · Tools

Software commonly used by this role in industry job postings, along with standard starter options for independent labels.

| Tool | Typical use in this role | Link |
|---|---|---|
| Airtable | Release schedule and readiness tracker | https://www.airtable.com |
| Your distributor dashboard (DistroKid, CD Baby, AWAL, The Orchard, Symphonic, etc.) | Release delivery | — |
| ISRC / UPC codes (from distributor or usisrc.org) | Codes | https://usisrc.org |
| Dropbox / Google Drive asset library | Audio and artwork | https://www.dropbox.com |
| Monday.com | Alternative project tracker | https://monday.com |
| Google Sheets | Metadata sheets | https://sheets.google.com |

## Inputs from the user

- Release plans and dates
- Masters, artwork and credits
- Contracts and clearances status

## Outputs produced

- Master release schedule
- Release setups
- QC checklists
- Readiness tracker
- Release playbook

## Starter stack

A free Airtable base or Google Sheet as the release schedule, your distributor dashboard, and Google Drive folders per release.
