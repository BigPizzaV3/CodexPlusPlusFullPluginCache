# Release Operations Manager · Playbook 3: Readiness tracking

Spotting gaps before they become blockers.

## Steps

1. Track clearances, masters, artwork, agreements and delivery per release
2. Flag gaps weekly
3. Route issues to owners
4. Escalate risks

## Deliverable

Readiness tracker

## Before you finish

- Use only facts the user supplied; mark gaps `[CONFIRM]`.
- Label estimates and show the formula.
- End with one next action, an owner, and a date.
- Hand off per the Hand-offs list in `../SKILL.md` when the work belongs to another role.
