# Playlist Pitching

> Real playlist curators, honest pitches, no pay-for-play.
> *Booking desk · Outreach · about 25 minutes*

## When to use

- A release needs playlist support.
- The artist is being approached by paid placement offers and needs a safer route.
- The artist wants a repeatable playlist routine.

## Ask first

Read the artist profile first (`artist-profile.md`, or the profile pasted in chat) and only ask for what is missing. Ask in one short batch.

- Song, genre, mood, tempo, and similar artists.
- Streaming link and release date.
- Platforms: Spotify, Apple Music, YouTube, or others.
- Time per week for outreach.
- Whether the artist already pitched through the platform's own artist tool.

## Workflow

1. Describe the song for matching: genre, mood, tempo, use-case (workout, focus, late night), language, and comparable artists.
2. Pitch editorial through the platform's official artist tool before release, where available.
3. Find independent playlists that already include similar artists; check that they are actively updated, have a real curator behind them, and fit the song. Use `directory-search` for help.
4. Collaborative playlists: only add a track if the playlist's rules and theme allow it, and never spam.
5. Write a pitch per curator type (see `playlist-outreach`) and log each in a tracker.
6. Warn against pay-for-placement, guaranteed-adds services, and bots. They can get tracks removed and accounts flagged.
7. Review results after two weeks and adjust.

## Deliverables

- Song match profile.
- Curator target list with fit reasons.
- Pitching plan and tracker.
- Safety notes on paid-placement offers.

Save each deliverable as a Markdown file if file tools are available; otherwise present it in the conversation.

## Quality checks (run before handing over)

- [ ] Each playlist was checked for activity and fit.
- [ ] No pay-for-play or guaranteed-placement tactic is recommended.
- [ ] Pitches are short and specific.
- [ ] The tracker has dates and follow-ups.

## Guardrails

- Never promise adds or streams.
- Do not recommend buying placement, followers, or plays.
- Never invent facts, numbers, credits, quotes, placements, or contacts. If the artist has not supplied something, ask or mark it `[CONFIRM]`.
- Label every estimate as an ESTIMATE and show the formula or assumption behind it.
- Never collect, solicit, or process Restricted Data: payment card data (PCI DSS), protected health information (PHI), government identifiers (Social Security numbers, ITINs, EIN digits, passport or driver's license numbers), or access credentials and authentication secrets (passwords, API keys, MFA/OTP codes, bank logins). The artist enters sensitive information directly on official sites.
- Gather only the minimum task-specific input required; never request full conversation history, raw chat transcripts, or precise user location data (street addresses or GPS coordinates).
- Do not display subscription plans, promote paid upgrades, sell digital goods/credits, or embed checkout flows.
- Draft first. Never claim anything was filed, registered, sent, posted, uploaded, or paid. The artist takes every outside action.

## Hand-offs

- `playlist-outreach`: write the curator messages
- `directory-search`: find curators
- `release-music-with-dsp`: time the pitches around release
