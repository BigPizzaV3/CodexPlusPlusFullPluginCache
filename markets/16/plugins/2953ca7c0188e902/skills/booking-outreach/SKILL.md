# Booking Outreach

> Venue and promoter outreach for the cities and dates you want.
> *Outreach desk · Outreach · about 25 minutes*

## When to use

- The artist wants to play new rooms or cities.
- A tour or show run is planned.
- The artist needs a repeatable booking process.

## Ask first

Read the artist profile first (`artist-profile.md`, or the profile pasted in chat) and only ask for what is missing. Ask in one short batch.

- Cities and date windows.
- Real draw: how many people the artist can bring, with how it is known.
- Past shows and venues the artist can name.
- Live footage, EPK, and the type of set (length, band size, tech needs).
- Offer types: headline, support, split bill, or showcase.

## Workflow

1. Build the target list: rooms whose size fits the artist's draw, programming the genre, and with a booking route that is publicly listed. Use `directory-search` if needed.
2. Rank the targets and decide the offer for each (support slot, local opener, bill share, or showcase).
3. Write the inquiry email: a specific subject, one-line pitch, proof (shows, draw, links), dates, and an easy next step. Keep it to about 120 words and attach nothing heavy; link the EPK and live video.
4. Plan follow-ups: one polite nudge after about a week and a final one after about two more.
5. Prepare for replies: availability, terms (door split, guarantee, bar), promotion expectations, and tech needs.
6. Create the tracker: venue, contact route, date sent, follow-ups, response, terms, next step.
7. After a show, send a thank-you and ask about the next date.

## Deliverables

- Ranked venue and promoter list.
- Inquiry email and follow-up drafts.
- Reply-handling guide.
- Booking tracker.

Save each deliverable as a Markdown file if file tools are available; otherwise present it in the conversation.

## Quality checks (run before handing over)

- [ ] Draw numbers are the artist's own and explained.
- [ ] Each email is personalized to the venue's programming.
- [ ] Dates and city details are correct.
- [ ] Follow-ups are limited to two.

## Guardrails

- Never invent draw numbers, past shows, or press.
- Do not send mass identical emails; each one is tailored.
- Use only publicly listed booking contacts.
- Never invent facts, numbers, credits, quotes, placements, or contacts. If the artist has not supplied something, ask or mark it `[CONFIRM]`.
- Label every estimate as an ESTIMATE and show the formula or assumption behind it.
- Never collect, solicit, or process Restricted Data: payment card data (PCI DSS), protected health information (PHI), government identifiers (Social Security numbers, ITINs, EIN digits, passport or driver's license numbers), or access credentials and authentication secrets (passwords, API keys, MFA/OTP codes, bank logins). The artist enters sensitive information directly on official sites.
- Gather only the minimum task-specific input required; never request full conversation history, raw chat transcripts, or precise user location data (street addresses or GPS coordinates).
- Do not display subscription plans, promote paid upgrades, sell digital goods/credits, or embed checkout flows.
- Draft first. Never claim anything was filed, registered, sent, posted, uploaded, or paid. The artist takes every outside action.

## Hand-offs

- `create-an-epk`: booking EPK
- `directory-search`: find the rooms
- `budget-planning`: check the tour math
