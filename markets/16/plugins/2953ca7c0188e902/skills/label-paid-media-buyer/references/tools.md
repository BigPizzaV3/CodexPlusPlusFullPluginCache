# Paid Media Buyer · Tools

Software commonly used by this role in industry job postings, along with standard starter options for independent labels.

| Tool | Typical use in this role | Link |
|---|---|---|
| Meta Ads Manager | Facebook/Instagram ads | https://www.facebook.com/business/tools/ads-manager |
| TikTok Ads Manager | TikTok ads | https://ads.tiktok.com |
| Google Ads (YouTube ads) | YouTube ads | https://ads.google.com |
| Snapchat Ads Manager | Snapchat ads | https://forbusiness.snapchat.com |
| Google Tag Manager (pixels & events) | Pixels and events | https://tagmanager.google.com |
| Google Analytics 4 | Conversion tracking | https://analytics.google.com |
| Google Sheets | Media plans and recaps | https://sheets.google.com |
| Looker Studio (free dashboards) | Ad dashboards | https://lookerstudio.google.com |

## Inputs from the user

- Campaign goals and budget
- Creative assets
- Landing pages and smart links
- Ad account access

## Outputs produced

- Media plans
- Live campaigns
- Optimization logs
- Weekly and final recaps

## Starter stack

Meta and TikTok Ads Manager with a small daily budget, Google Tag Manager and GA4, and a Google Sheets recap template.
