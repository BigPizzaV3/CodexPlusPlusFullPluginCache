# Data & Audience Insights Analyst · Tools

Software commonly used by this role in industry job postings, along with standard starter options for independent labels.

| Tool | Typical use in this role | Link |
|---|---|---|
| Spotify for Artists | Streaming and audience data | https://artists.spotify.com |
| Chartmetric | Cross-platform and market data | https://chartmetric.com |
| Luminate (consumption data) | Consumption data (enterprise) | https://luminatedata.com |
| Looker Studio (free dashboards) | Free dashboards | https://lookerstudio.google.com |
| Tableau / Power BI | Advanced dashboards | https://www.tableau.com |
| SQL (BigQuery / Snowflake / Postgres) | Querying data (optional) | https://cloud.google.com/bigquery |
| Python (pandas, notebooks) | Analysis (optional) | https://www.python.org |
| Google Analytics 4 | Website and store data | https://analytics.google.com |

## Inputs from the user

- Access to artist dashboards and store data
- Campaign data
- Questions and decisions to support

## Outputs produced

- KPI dictionary and dashboards
- Release forecasts
- Audience reports
- Campaign analyses

## Starter stack

Spotify/Apple/YouTube artist dashboards, Chartmetric free, Google Sheets, and Looker Studio for dashboards.
