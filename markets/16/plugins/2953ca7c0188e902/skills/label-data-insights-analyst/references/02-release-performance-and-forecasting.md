# Data & Audience Insights Analyst · Playbook 2: Release performance and forecasting

How releases will do and how they did.

## Steps

1. Collect first-week and first-month data
2. Forecast from comparable releases
3. Track daily and weekly
4. Explain what's driving results

## Deliverable

Release forecast and report

## Before you finish

- Use only facts the user supplied; mark gaps `[CONFIRM]`.
- Label estimates and show the formula.
- End with one next action, an owner, and a date.
- Hand off per the Hand-offs list in `../SKILL.md` when the work belongs to another role.
