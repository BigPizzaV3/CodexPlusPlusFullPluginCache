# Data & Audience Insights Analyst · Playbook 6: Ad-hoc analysis

Answering questions quickly.

## Steps

1. Clarify the question and decision
2. Pull and clean data
3. Analyze and visualize
4. Deliver a short answer with caveats

## Deliverable

Ad-hoc answer

## Before you finish

- Use only facts the user supplied; mark gaps `[CONFIRM]`.
- Label estimates and show the formula.
- End with one next action, an owner, and a date.
- Hand off per the Hand-offs list in `../SKILL.md` when the work belongs to another role.
