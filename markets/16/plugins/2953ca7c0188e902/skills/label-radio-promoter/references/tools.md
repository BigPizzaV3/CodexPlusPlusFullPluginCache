# Radio Promotions Manager · Tools

Software commonly used by this role in industry job postings, along with standard starter options for independent labels.

| Tool | Typical use in this role | Link |
|---|---|---|
| Radiomonitor (international airplay tracking) | International airplay tracking | https://www.radiomonitor.com |
| Mediabase (US airplay charts) | US airplay | https://www.mediabase.com |
| Groover (curator/radio pitching) | Radio and curator pitching | https://groover.co |
| Airtable | Radio database | https://www.airtable.com |
| Dropbox / Google Drive asset library | Servicing files | https://www.dropbox.com |
| Canva | One-sheets | https://www.canva.com |

## Inputs from the user

- Radio edits and clean versions
- Release date
- Artist story and assets

## Outputs produced

- Radio plan
- Service pack
- Radio database
- Airplay reports

## Starter stack

A Google Sheet radio database, Dropbox links for servicing, and Groover for independent and college stations.
