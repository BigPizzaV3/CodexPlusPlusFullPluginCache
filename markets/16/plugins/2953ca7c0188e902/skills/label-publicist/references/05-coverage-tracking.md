# Publicist · Playbook 5: Coverage tracking

Measuring what landed.

## Steps

1. Log all coverage with links and reach
2. Share highlights with the team
3. Compile a recap
4. Update the press kit

## Deliverable

Coverage report

## Before you finish

- Use only facts the user supplied; mark gaps `[CONFIRM]`.
- Label estimates and show the formula.
- End with one next action, an owner, and a date.
- Hand off per the Hand-offs list in `../SKILL.md` when the work belongs to another role.
