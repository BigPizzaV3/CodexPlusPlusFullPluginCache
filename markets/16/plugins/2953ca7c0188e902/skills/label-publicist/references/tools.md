# Publicist · Tools

Software commonly used by this role in industry job postings, along with standard starter options for independent labels.

| Tool | Typical use in this role | Link |
|---|---|---|
| Muck Rack (journalist database) | Finding journalists | https://muckrack.com |
| SubmitHub (blog/playlist pitching) | Blog pitching | https://www.submithub.com |
| Groover (curator/radio pitching) | Curator and media pitching | https://groover.co |
| Google Workspace (Gmail, Drive, Calendar, Docs) | Pitch emails and press kits | https://workspace.google.com |
| Airtable | Pitch and coverage tracking | https://www.airtable.com |
| Canva | Press kit layout | https://www.canva.com |

## Inputs from the user

- Artist story and interviews
- Music, photos and video
- Release timeline
- Approved talking points

## Outputs produced

- Press kit
- Media list
- Pitch tracker
- Interview briefs
- Coverage report

## Starter stack

A Google Sheet media list, Gmail templates, SubmitHub/Groover for smaller outlets, and Canva for the press kit. (Artispreneur's EPK builder also helps here.)
