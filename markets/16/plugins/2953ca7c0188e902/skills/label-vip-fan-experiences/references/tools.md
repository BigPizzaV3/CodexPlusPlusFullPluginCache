# VIP & Fan Experiences Manager · Tools

Software commonly used by this role in industry job postings, along with standard starter options for independent labels.

| Tool | Typical use in this role | Link |
|---|---|---|
| DICE / Eventbrite (ticketing) | Ticketing and add-ons | https://dice.fm |
| Google Sheets | P&L and settlements | https://sheets.google.com |
| Airtable | Event logistics | https://www.airtable.com |
| Square POS | On-site sales | https://squareup.com |
| Canva | Event materials | https://www.canva.com |

## Inputs from the user

- Tour dates and venues
- Artist comfort level and availability
- Budget

## Outputs produced

- VIP package menu
- VIP P&L
- Run-of-show
- Settlements and recaps

## Starter stack

DICE or Eventbrite for ticketing, Google Sheets for the P&L, and a partner venue for the first listening party.
