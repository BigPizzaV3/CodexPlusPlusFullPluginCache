# Distribution Manager · Tools

Software commonly used by this role in industry job postings, along with standard starter options for independent labels.

| Tool | Typical use in this role | Link |
|---|---|---|
| Your distributor dashboard (DistroKid, CD Baby, AWAL, The Orchard, Symphonic, etc.) | Delivery, catalog and reports | — |
| Spotify for Artists | Checking live releases and profile mapping | https://artists.spotify.com |
| Apple Music for Artists | Checking live releases | https://artists.apple.com |
| ISRC / UPC codes (from distributor or usisrc.org) | Codes | https://usisrc.org |
| Airtable | Catalog and issue tracking | https://www.airtable.com |
| Google Sheets | Metadata and reports | https://sheets.google.com |

## Inputs from the user

- Release setups
- Catalog list with codes
- Distributor login and contract

## Outputs produced

- Delivery logs
- Catalog change log
- Onboarding checklists
- Issue tracker
- Distributor comparison

## Starter stack

One distributor account, a Google Sheet catalog with ISRC/UPC codes, and the free artist dashboards to verify releases.
