# Distribution Manager · Playbook 4: Platform issue resolution

Mapping errors, blocks and conflicts.

## Steps

1. Diagnose the issue (metadata, mapping, rights conflict)
2. Open tickets with the distributor or DSP
3. Track to resolution
4. Inform stakeholders

## Deliverable

Issue tracker

## Before you finish

- Use only facts the user supplied; mark gaps `[CONFIRM]`.
- Label estimates and show the formula.
- End with one next action, an owner, and a date.
- Hand off per the Hand-offs list in `../SKILL.md` when the work belongs to another role.
