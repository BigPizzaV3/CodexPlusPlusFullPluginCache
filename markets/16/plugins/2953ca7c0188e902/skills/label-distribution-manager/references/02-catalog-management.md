# Distribution Manager · Playbook 2: Catalog management

Keeping the catalog right everywhere.

## Steps

1. Process takedowns, price and territory changes
2. Handle payee and entity changes
3. Document every change
4. Verify on DSPs

## Deliverable

Catalog change log

## Before you finish

- Use only facts the user supplied; mark gaps `[CONFIRM]`.
- Label estimates and show the formula.
- End with one next action, an owner, and a date.
- Hand off per the Hand-offs list in `../SKILL.md` when the work belongs to another role.
