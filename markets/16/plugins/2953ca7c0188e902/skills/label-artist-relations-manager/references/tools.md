# Artist Relations (Day-to-Day) Manager · Tools

Software commonly used by this role in industry job postings, along with standard starter options for independent labels.

| Tool | Typical use in this role | Link |
|---|---|---|
| Google Workspace (Gmail, Drive, Calendar, Docs) | Shared calendar and email | https://workspace.google.com |
| Airtable | Rollout tasks | https://www.airtable.com |
| Slack | Daily artist-team chat | https://slack.com |
| Google Sheets | Budget and expense tracking | https://sheets.google.com |

## Inputs from the user

- Artist and manager contacts
- Campaign and tour plans
- Travel budget
- Artist preferences and restrictions

## Outputs produced

- Weekly artist schedule
- Itineraries
- Rollout tracker
- Day sheets
- Sync notes

## Starter stack

A shared Google Calendar, a Google Sheet rollout tracker and a group chat with the artist team.
