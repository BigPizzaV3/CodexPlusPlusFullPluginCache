# Merch Brand Manager · Tools

Software commonly used by this role in industry job postings, along with standard starter options for independent labels.

| Tool | Typical use in this role | Link |
|---|---|---|
| Shopify | Online sales data | https://www.shopify.com |
| Printful (print-on-demand merch) | Samples and print-on-demand | https://www.printful.com |
| Google Sheets | Line sheets and P&L | https://sheets.google.com |
| Canva | Mockups and retail decks | https://www.canva.com |
| Asana | Approvals and timelines | https://asana.com |
| Adobe Photoshop / Illustrator | Mockups | https://www.adobe.com/products/photoshop.html |

## Inputs from the user

- Artist brand and approvals contact
- Release and tour calendar
- Merch budget

## Outputs produced

- Merch calendar
- Line sheets
- Approval logs
- Merch P&L
- Retail decks

## Starter stack

Printful for samples and print-on-demand, Canva for mockups, Google Sheets for line sheets and margins.
