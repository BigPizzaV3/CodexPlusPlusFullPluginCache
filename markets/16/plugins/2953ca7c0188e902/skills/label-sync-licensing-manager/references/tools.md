# Sync Licensing Manager · Tools

Software commonly used by this role in industry job postings, along with standard starter options for independent labels.

| Tool | Typical use in this role | Link |
|---|---|---|
| DISCO (sync catalog & pitching) | Sync catalog and pitching | https://www.disco.ac |
| Tunefind (who placed what song where) | Placement research | https://www.tunefind.com |
| Airtable | Requests, placements and supervisor database | https://www.airtable.com |
| DocuSign / Adobe Sign | Licenses | https://www.docusign.com |
| Dropbox / Google Drive asset library | Stems and instrumentals | https://www.dropbox.com |
| Google Sheets | Revenue tracking | https://sheets.google.com |

## Inputs from the user

- Masters, stems and instrumentals
- Ownership and split information
- Approval rules from artists

## Outputs produced

- Sync-ready catalog
- Pitch playlists
- Quotes
- Executed licenses
- Revenue reports

## Starter stack

A Google Drive sync folder with stems and instrumentals, a metadata sheet, Tunefind for research, and a license template from Business Affairs.
