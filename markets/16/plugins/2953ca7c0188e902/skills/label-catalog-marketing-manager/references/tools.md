# Catalog Marketing Manager · Tools

Software commonly used by this role in industry job postings, along with standard starter options for independent labels.

| Tool | Typical use in this role | Link |
|---|---|---|
| Chartmetric | Spotting catalog spikes | https://chartmetric.com |
| Spotify for Artists | Catalog performance | https://artists.spotify.com |
| TikTok Creative Center (trending sounds & ads) | Sound usage trends | https://ads.tiktok.com/business/creativecenter |
| Airtable | Catalog calendar | https://www.airtable.com |
| Meta Ads Manager | Catalog paid support | https://www.facebook.com/business/tools/ads-manager |
| Canva | Anniversary assets | https://www.canva.com |

## Inputs from the user

- Full catalog list with release dates
- Streaming data
- Budget for always-on campaigns

## Outputs produced

- Catalog calendar
- Campaign plans
- Catalog audit
- Product business cases

## Starter stack

A Google Sheet listing every release and date, Spotify for Artists, and TikTok Creative Center for spotting spikes.
