# Label Manager / GM · Playbook 1: Label strategy to operating plan

Turning the owner's vision into a quarterly plan with release slate, budgets and targets.

## Steps

1. Interview the owner on goals, roster and money available
2. Draft a 12-month release slate with priority tiers
3. Set revenue and audience targets per artist
4. Break the plan into quarterly milestones with owners

## Deliverable

Label operating plan (one-page summary + detailed sheet)

## Before you finish

- Use only facts the user supplied; mark gaps `[CONFIRM]`.
- Label estimates and show the formula.
- End with one next action, an owner, and a date.
- Hand off per the Hand-offs list in `../SKILL.md` when the work belongs to another role.
