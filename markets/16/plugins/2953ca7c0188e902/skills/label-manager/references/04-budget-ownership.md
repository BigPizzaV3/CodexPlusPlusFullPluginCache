# Label Manager / GM · Playbook 4: Budget ownership

Keeping spend tied to goals across marketing, recording and operations.

## Steps

1. Set a budget per release and per department
2. Review spend vs. plan weekly with Finance
3. Recommend reallocations when something over- or under-performs
4. Flag any spend above the agreed limit for owner approval

## Deliverable

Budget vs. actuals summary with recommendations

## Before you finish

- Use only facts the user supplied; mark gaps `[CONFIRM]`.
- Label estimates and show the formula.
- End with one next action, an owner, and a date.
- Hand off per the Hand-offs list in `../SKILL.md` when the work belongs to another role.
