# Label Manager / GM · Playbook 3: Weekly label meeting

Running the meeting that keeps the label honest.

## Steps

1. Collect updates from every role
2. Build an agenda ordered by risk
3. Record decisions, owners and due dates
4. Send the action list within an hour

## Deliverable

Agenda, decisions log and action list

## Before you finish

- Use only facts the user supplied; mark gaps `[CONFIRM]`.
- Label estimates and show the formula.
- End with one next action, an owner, and a date.
- Hand off per the Hand-offs list in `../SKILL.md` when the work belongs to another role.
