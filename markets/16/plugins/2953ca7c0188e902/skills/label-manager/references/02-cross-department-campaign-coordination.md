# Label Manager / GM · Playbook 2: Cross-department campaign coordination

Making sure A&R, marketing, ops, legal and finance move together on every release.

## Steps

1. Create a campaign kickoff brief for each release
2. Assign each department its deliverables and dates
3. Run a weekly status check across roles
4. Escalate blockers before they move a release date

## Deliverable

Campaign kickoff brief and status tracker

- Use only facts the user supplied; mark gaps `[CONFIRM]`.
- Label estimates and show the formula.
- End with one next action, an owner, and a date.
