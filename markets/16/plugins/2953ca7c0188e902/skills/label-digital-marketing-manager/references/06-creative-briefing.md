# Digital Marketing Manager · Playbook 6: Creative briefing

Getting platform-ready assets from creative teams.

## Steps

1. Write briefs with specs and references
2. Review drafts against goals
3. Approve final assets
4. Track which creative performs

## Deliverable

Creative brief and performance log

## Before you finish

- Use only facts the user supplied; mark gaps `[CONFIRM]`.
- Label estimates and show the formula.
- End with one next action, an owner, and a date.
- Hand off per the Hand-offs list in `../SKILL.md` when the work belongs to another role.
