# Playlist Curator Pitching

> Short, curator-friendly pitches matched to playlists in your genre.
> *Outreach desk · Outreach · about 20 minutes*

## When to use

- The artist has playlists to pitch and needs the words.
- Current pitches are too long or generic.
- A new single needs a fast pitch set.

## Ask first

Read the artist profile first (`artist-profile.md`, or the profile pasted in chat) and only ask for what is missing. Ask in one short batch.

- The song and one-line description.
- Streaming link and release date.
- Each playlist: name, curator, why it fits, and how it accepts submissions.
- Any real proof (for example a similar artist on the playlist, or sourced playlist adds).
- Preferred contact method per curator.

## Workflow

1. Write each pitch with this shape: why this playlist (specific), the song in one sentence, the link, a thank-you.
2. Keep it under about 80 words. Lead with fit, not with the artist's biography.
3. Make a form-ready short version (about 30 words) and a direct-message version.
4. Follow-up: one polite note after about a week if the curator accepts messages; otherwise move on.
5. Log each pitch and result.

## Deliverables

- One pitch per playlist.
- Short and DM versions.
- Follow-up template.
- Tracker.

Save each deliverable as a Markdown file if file tools are available; otherwise present it in the conversation.

## Quality checks (run before handing over)

- [ ] Each pitch names something specific about the playlist.
- [ ] Length stays within limits.
- [ ] The link works and is for the right track.
- [ ] No claims without proof.

## Guardrails

- No guaranteed-placement offers, payments, or incentives for adds.
- Respect each curator's submission rules.
- Never invent facts, numbers, credits, quotes, placements, or contacts. If the artist has not supplied something, ask or mark it `[CONFIRM]`.
- Label every estimate as an ESTIMATE and show the formula or assumption behind it.
- Never collect, solicit, or process Restricted Data: payment card data (PCI DSS), protected health information (PHI), government identifiers (Social Security numbers, ITINs, EIN digits, passport or driver's license numbers), or access credentials and authentication secrets (passwords, API keys, MFA/OTP codes, bank logins). The artist enters sensitive information directly on official sites.
- Gather only the minimum task-specific input required; never request full conversation history, raw chat transcripts, or precise user location data (street addresses or GPS coordinates).
- Do not display subscription plans, promote paid upgrades, sell digital goods/credits, or embed checkout flows.
- Draft first. Never claim anything was filed, registered, sent, posted, uploaded, or paid. The artist takes every outside action.

## Hand-offs

- `add-music-to-collaborative-playlist`: the strategy and target list
- `directory-search`: find more curators
- `media-outreach`: press pitching

> Write curator pitches for these playlists. Here's my song.
