# A&R Manager · Tools

Software commonly used by this role in industry job postings, along with standard starter options for independent labels.

| Tool | Typical use in this role | Link |
|---|---|---|
| Chartmetric | Spotting fast-growing artists and tracks | https://chartmetric.com |
| Songstats | Cross-platform performance checks | https://songstats.com |
| Spotify for Artists | Signed artist performance | https://artists.spotify.com |
| Airtable | A&R pipeline and recording tracker | https://www.airtable.com |
| Pro Tools / Logic / Ableton (your DAW) | Reviewing sessions and mixes | — |
| Dropbox / Google Drive asset library | Demos, stems and masters | https://www.dropbox.com |

## Inputs from the user

- Demos, links and artist submissions
- Label genre focus and roster priorities
- A&R and recording budget
- Release calendar targets

## Outputs produced

- A&R pipeline
- Signing memos
- Recording plans and budgets
- Single selections
- Split sheets

## Starter stack

Chartmetric starter tiers, Spotify for Artists, a Google Sheet or Airtable base as the pipeline, Google Drive for demos, and SubmitHub-style inbound for discovery.
