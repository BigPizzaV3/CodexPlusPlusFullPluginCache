# A&R Manager · Playbook 3: Signing recommendation

Making the case to sign (or pass) on an artist.

## Steps

1. Summarize the music, story and audience data
2. Get a valuation from the Deal Valuation role
3. Outline proposed deal shape
4. Present recommendation with risks

## Deliverable

Signing memo

## Before you finish

- Use only facts the user supplied; mark gaps `[CONFIRM]`.
- Label estimates and show the formula.
- End with one next action, an owner, and a date.
- Hand off per the Hand-offs list in `../SKILL.md` when the work belongs to another role.
