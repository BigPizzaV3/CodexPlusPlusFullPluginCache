# Merch Production Manager · Tools

Software commonly used by this role in industry job postings, along with standard starter options for independent labels.

| Tool | Typical use in this role | Link |
|---|---|---|
| Google Sheets | PO logs and schedules | https://sheets.google.com |
| Asana | Production tracking | https://asana.com |
| QuickBooks Online | POs and invoices | https://quickbooks.intuit.com |
| Printful (print-on-demand merch) | Small runs and samples | https://www.printful.com |
| ShipStation | Shipping | https://www.shipstation.com |
| Square POS | Pop-up sales | https://squareup.com |

## Inputs from the user

- Approved designs and line sheet
- Quantities and budget
- Delivery deadlines and addresses

## Outputs produced

- PO log
- Production schedule
- Proof approvals
- Shipping tracker
- Vendor scorecards

## Starter stack

Google Sheets for POs and schedules, a local screen printer or Printful for small runs, and Square for pop-up sales.
