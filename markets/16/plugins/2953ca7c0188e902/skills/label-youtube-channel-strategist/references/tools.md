# YouTube Channel Strategist · Tools

Software commonly used by this role in industry job postings, along with standard starter options for independent labels.

| Tool | Typical use in this role | Link |
|---|---|---|
| YouTube Studio | Uploads and analytics | https://studio.youtube.com |
| YouTube Content ID / Studio Content Manager | Claims and monetization | https://support.google.com/youtube/answer/2797370 |
| Canva | Thumbnails | https://www.canva.com |
| CapCut | Shorts | https://www.capcut.com |
| Google Sheets | Reporting | https://sheets.google.com |

## Inputs from the user

- Channel access
- Video assets
- Release calendar

## Outputs produced

- Upload calendar
- Channel audits
- Optimized uploads
- Weekly YouTube report

## Starter stack

YouTube Studio, Canva for thumbnails, CapCut for Shorts. Content ID access usually comes through your distributor.
