# DSP Setup

> Claim and polish your artist profiles on every streaming service.
> *Release desk · Release & DSP · about 25 minutes*

## When to use

- A release is out or about to be and profiles are unclaimed.
- Profiles show the wrong photo, bio, or mixed-up artists.
- The artist wants merch, tour, or playlist features on their profiles.

## Ask first

Read the artist profile first (`artist-profile.md`, or the profile pasted in chat) and only ask for what is missing. Ask in one short batch.

- Which platforms have claimed profiles already.
- The distributor and the first live release for each platform.
- Artist bio, high-resolution photos, and approved links.
- Preferred featured track or playlist.
- Whether the artist shares a name with other artists.

## Workflow

1. Confirm a release is live (or scheduled) on each service; most claim flows need one.
2. Claim in each platform's artist tool: Spotify for Artists, Apple Music for Artists, Amazon Music for Artists, and the YouTube Official Artist Channel flow through the distributor or YouTube Studio. Walk through each flow; the artist verifies on the platform.
3. Fix mix-ups: if another artist's releases are on the profile, collect the evidence and use the platform's support flow.
4. Complete each profile: bio (from `create-an-artist-bio`), consistent photos and header art, links, featured track, and tour, merch, and playlist features where offered. Image requirements change, so confirm them in each dashboard.
5. Write one profile-copy block the artist can reuse everywhere.
6. Set a monthly maintenance routine: update the featured content, check for mismatches, and review analytics.

## Deliverables

- Per-platform claim checklist.
- Profile copy and asset list.
- Mix-up resolution notes.
- Monthly maintenance checklist.

Save each deliverable as a Markdown file if file tools are available; otherwise present it in the conversation.

## Quality checks (run before handing over)

- [ ] Each platform has a claim status and next action.
- [ ] Profile copy is consistent across platforms.
- [ ] Image sizes were confirmed in the platform dashboards, not assumed.
- [ ] Names are spelled the same everywhere.

## Guardrails

- Do not ask for platform logins.
- Do not buy or recommend followers, streams, or paid placement; that violates platform rules.
- Never invent facts, numbers, credits, quotes, placements, or contacts. If the artist has not supplied something, ask or mark it `[CONFIRM]`.
- Label every estimate as an ESTIMATE and show the formula or assumption behind it.
- Never collect, solicit, or process Restricted Data: payment card data (PCI DSS), protected health information (PHI), government identifiers (Social Security numbers, ITINs, EIN digits, passport or driver's license numbers), or access credentials and authentication secrets (passwords, API keys, MFA/OTP codes, bank logins). The artist enters sensitive information directly on official sites.
- Gather only the minimum task-specific input required; never request full conversation history, raw chat transcripts, or precise user location data (street addresses or GPS coordinates).
- Do not display subscription plans, promote paid upgrades, sell digital goods/credits, or embed checkout flows.
- Draft first. Never claim anything was filed, registered, sent, posted, uploaded, or paid. The artist takes every outside action.
