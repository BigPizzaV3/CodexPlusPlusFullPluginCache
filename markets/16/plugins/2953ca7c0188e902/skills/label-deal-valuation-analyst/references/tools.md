# Deal & Valuation Analyst · Tools

Software commonly used by this role in industry job postings, along with standard starter options for independent labels.

| Tool | Typical use in this role | Link |
|---|---|---|
| Excel / Google Sheets (pivot tables, XLOOKUP) | Financial models | — |
| Chartmetric | Streaming history | https://chartmetric.com |
| Luminate (consumption data) | Consumption data (if available) | https://luminatedata.com |
| SQL (BigQuery / Snowflake / Postgres) | Large data pulls (optional) | https://cloud.google.com/bigquery |
| Tableau / Power BI | Deal dashboards (optional) | https://www.tableau.com |
| Google Slides / Canva decks | Deal memos | https://slides.google.com |

## Inputs from the user

- Streaming and royalty history
- Proposed terms
- Label's cost of capital or target return

## Outputs produced

- Deal models
- Valuation summaries
- Structure comparisons
- Deal memos
- Post-deal reviews

## Starter stack

Google Sheets with a simple revenue-forecast template, Chartmetric free for streaming history, and the seller's royalty statements.
