# Studio Manager · Playbook 3: Collaborator coordination

Managing outside producers, writers and engineers.

## Steps

1. Share studio rules and access details
2. Collect split sheets at the session
3. Log who attended
4. Follow up on files

## Deliverable

Session log with split sheets

## Before you finish

- Use only facts the user supplied; mark gaps `[CONFIRM]`.
- Label estimates and show the formula.
- End with one next action, an owner, and a date.
- Hand off per the Hand-offs list in `../SKILL.md` when the work belongs to another role.
