# Studio Manager · Playbook 1: Session scheduling

Booking rooms, engineers and artists.

## Steps

1. Take session requests with date, length and needs
2. Check room and engineer availability
3. Confirm by calendar invite
4. Send a reminder the day before

## Deliverable

Confirmed session calendar

## Before you finish

- Use only facts the user supplied; mark gaps `[CONFIRM]`.
- Label estimates and show the formula.
- End with one next action, an owner, and a date.
- Hand off per the Hand-offs list in `../SKILL.md` when the work belongs to another role.
