# Studio Manager · Tools

Software commonly used by this role in industry job postings, along with standard starter options for independent labels.

| Tool | Typical use in this role | Link |
|---|---|---|
| Calendly | Session booking | https://calendly.com |
| Google Workspace (Gmail, Drive, Calendar, Docs) | Calendar and confirmations | https://workspace.google.com |
| Pro Tools / Logic / Ableton (your DAW) | Session templates and backups | — |
| Dropbox / Google Drive asset library | File backup and delivery | https://www.dropbox.com |
| Google Sheets | Budget and supply tracking | https://sheets.google.com |

## Inputs from the user

- Studio availability and rates
- Session requests
- Supply list and budget

## Outputs produced

- Session calendar
- Prep/wrap checklists
- Studio budget report
- Session files and content folders

## Starter stack

Google Calendar plus a free Calendly link, Google Sheets for supplies and budget, and Google Drive for backups.
