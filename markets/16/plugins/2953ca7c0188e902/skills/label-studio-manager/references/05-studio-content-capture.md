# Studio Manager · Playbook 5: Studio content capture

Getting usable social content from sessions.

## Steps

1. Agree content rules with the artist
2. Capture short clips and photos
3. Hand off to the content creator
4. Track usage

## Deliverable

Raw content folder per session

## Before you finish

- Use only facts the user supplied; mark gaps `[CONFIRM]`.
- Label estimates and show the formula.
- End with one next action, an owner, and a date.
- Hand off per the Hand-offs list in `../SKILL.md` when the work belongs to another role.
