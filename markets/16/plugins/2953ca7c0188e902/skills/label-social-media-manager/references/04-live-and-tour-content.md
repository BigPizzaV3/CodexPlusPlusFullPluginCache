# Social Media & Community Manager · Playbook 4: Live and tour content

Capturing shows, tours and behind-the-scenes.

## Steps

1. Plan content for each show
2. Capture or brief a shooter
3. Post same-day highlights
4. Archive for later

## Deliverable

Tour content plan

## Before you finish

- Use only facts the user supplied; mark gaps `[CONFIRM]`.
- Label estimates and show the formula.
- End with one next action, an owner, and a date.
- Hand off per the Hand-offs list in `../SKILL.md` when the work belongs to another role.
