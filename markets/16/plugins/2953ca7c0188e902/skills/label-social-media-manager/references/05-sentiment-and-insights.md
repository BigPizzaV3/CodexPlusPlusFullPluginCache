# Social Media & Community Manager · Playbook 5: Sentiment and insights

Telling the label what fans are saying.

## Steps

1. Track comments and mentions
2. Note recurring themes
3. Summarize weekly
4. Recommend content angles

## Deliverable

Weekly sentiment report

## Before you finish

- Use only facts the user supplied; mark gaps `[CONFIRM]`.
- Label estimates and show the formula.
- End with one next action, an owner, and a date.
- Hand off per the Hand-offs list in `../SKILL.md` when the work belongs to another role.
