# Royalty Accountant · Tools

Software commonly used by this role in industry job postings, along with standard starter options for independent labels.

| Tool | Typical use in this role | Link |
|---|---|---|
| Curve Royalty Systems | Royalty statements | https://www.curveroyaltysystems.com |
| Excel / Google Sheets (pivot tables, XLOOKUP) | Reconciliations and calculations | — |
| Your distributor dashboard (DistroKid, CD Baby, AWAL, The Orchard, Symphonic, etc.) | Sales reports | — |
| QuickBooks Online | Payments and accruals | https://quickbooks.intuit.com |
| Airtable | Accounts and queries | https://www.airtable.com |
| Python (pandas, notebooks) | Importing large sales files (optional) | https://www.python.org |

## Inputs from the user

- Signed agreements
- Distributor and partner sales reports
- Advances and recoupable costs

## Outputs produced

- Royalty statements
- Reconciliation workbook
- Recoupment report
- Query log

## Starter stack

A Google Sheets royalty model per artist (start simple), your distributor's reports, and Curve once you have many payees.
