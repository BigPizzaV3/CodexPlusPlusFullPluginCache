# Media Pitching

> Personal pitch emails for every journalist and blog on your list.
> *Outreach desk · Outreach · about 25 minutes*

## When to use

- A target list exists and individual pitches are needed.
- A pitch template is getting no replies.
- A new release needs fresh outreach.

## Ask first

Read the artist profile first (`artist-profile.md`, or the profile pasted in chat) and only ask for what is missing. Ask in one short batch.

- The target list (name, outlet, recent articles or episodes, public contact route).
- The pitch: release, hook, and proof.
- Links: stream, EPK, press photo.
- Tone and how the artist wants to sound.
- Send window.

## Workflow

1. For each target, read two or three recent pieces and note what they like to cover.
2. Write a first line that references something real and specific from their work. If nothing specific is found, say less rather than fake it.
3. Write the pitch in about 100 to 150 words: who, what, why it fits this outlet, one proof point, one link.
4. Offer two subject lines per pitch.
5. Keep attachments out; link to the EPK and music.
6. Create the tracker and apply the follow-up rule: one follow-up after about a week, one more later with new news, then stop.
7. Log replies and learn what worked.

## Deliverables

- One tailored pitch per target.
- Subject line options.
- Tracking sheet.
- Follow-up templates.

Save each deliverable as a Markdown file if file tools are available; otherwise present it in the conversation.

## Quality checks (run before handing over)

- [ ] Each first line is specific to the recipient.
- [ ] Every claim is sourced.
- [ ] No pitch exceeds about 150 words.
- [ ] Public contact routes only.

## Guardrails

- Never fake familiarity ('I love your work') without a specific detail.
- Do not send bulk-identical messages.
- Honor opt-outs.
- Never invent facts, numbers, credits, quotes, placements, or contacts. If the artist has not supplied something, ask or mark it `[CONFIRM]`.
- Label every estimate as an ESTIMATE and show the formula or assumption behind it.
- Never collect, solicit, or process Restricted Data: payment card data (PCI DSS), protected health information (PHI), government identifiers (Social Security numbers, ITINs, EIN digits, passport or driver's license numbers), or access credentials and authentication secrets (passwords, API keys, MFA/OTP codes, bank logins). The artist enters sensitive information directly on official sites.
- Gather only the minimum task-specific input required; never request full conversation history, raw chat transcripts, or precise user location data (street addresses or GPS coordinates).
- Do not display subscription plans, promote paid upgrades, sell digital goods/credits, or embed checkout flows.
- Draft first. Never claim anything was filed, registered, sent, posted, uploaded, or paid. The artist takes every outside action.
