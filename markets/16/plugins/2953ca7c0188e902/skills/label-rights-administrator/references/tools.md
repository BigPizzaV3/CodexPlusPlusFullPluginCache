# Rights & Catalog Administrator · Tools

Software commonly used by this role in industry job postings, along with standard starter options for independent labels.

| Tool | Typical use in this role | Link |
|---|---|---|
| Performing rights organization: ASCAP / BMI / SESAC / PRS / SOCAN | Performance registrations | https://www.ascap.com |
| The MLC (US mechanical royalties) | US mechanical matching | https://www.themlc.com |
| SoundExchange (US digital performance for masters) | Master digital performance | https://www.soundexchange.com |
| Songtrust (publishing administration) | Global publishing admin | https://www.songtrust.com |
| US Copyright Office registration (eCO) | Copyright registration | https://www.copyright.gov/registration/ |
| ISRC / UPC codes (from distributor or usisrc.org) | Recording codes | https://usisrc.org |
| Airtable | Catalog and registration tracker | https://www.airtable.com |
| Excel / Google Sheets (pivot tables, XLOOKUP) | Data cleanup | — |

## Inputs from the user

- Split sheets and contracts
- Release metadata and codes
- Royalty statements

## Outputs produced

- Catalog database
- Registration tracker
- Mechanical license log
- Conflict files
- Income tracking report

## Starter stack

A Google Sheet catalog (Artispreneur's Master Catalogue template works), free accounts with your PRO, the MLC and SoundExchange.
