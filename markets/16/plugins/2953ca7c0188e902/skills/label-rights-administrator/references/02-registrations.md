# Rights & Catalog Administrator · Playbook 2: Registrations

Getting works and recordings registered everywhere.

## Steps

1. Register songs with PROs and publishing admin
2. Register recordings with SoundExchange and neighboring-rights bodies
3. Check MLC matches
4. File copyright registrations for key works

## Deliverable

Registration tracker

## Before you finish

- Use only facts the user supplied; mark gaps `[CONFIRM]`.
- Label estimates and show the formula.
- End with one next action, an owner, and a date.
- Hand off per the Hand-offs list in `../SKILL.md` when the work belongs to another role.
