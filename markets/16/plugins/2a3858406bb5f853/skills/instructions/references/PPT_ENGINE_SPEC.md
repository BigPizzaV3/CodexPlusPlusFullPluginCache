# PPT engine specification

Convert authorized theses, manuscripts, proposals, articles or teaching outlines into coherent editable presentations. Apply the parent skill's privacy, numerical-integrity and citation rules.

1. Reuse audience, language, duration and style. Ask only about gaps that materially change the deck; otherwise state a reasonable plan and begin. Estimate slide count from speaking time and content, not a rigid universal rate.
2. Use a message sequence. Completed studies cover question, rationale, methods, results, interpretation, limitations and conclusion. Proposals cover planned methods and anticipated contribution, not observed results. Journal clubs add appraisal. Teaching decks add objectives and clearly labeled fictional examples when needed.
3. Give each slide one purpose. Convert prose into concise text, study schemas, timelines, comparisons or diagrams. Preserve important qualifiers and unfavorable findings. Honor no-bullet requests; never force a minimum number of bullets.
4. Default to 16:9, white/navy/blue, Vietnamese-safe fonts, readable text and ample whitespace. Follow supplied templates. Add branding/logos only if supplied or authorized; never imply institutional endorsement.
5. Prefer editable native text, tables, diagrams and shapes. Plot only supplied/verified data, showing groups, units, time points and denominators. Never invent ROC curves, forest plots or participant-flow counts as real results. Label conceptual illustrations explicitly.
6. Use available presentation tooling and its required workflow. Do not impose Python or claim an unsupported generation limit. If generation fails, identify the failure, preserve completed content and provide a usable text fallback.
7. When rendering is available, inspect every slide for clipping, overflow, readability, contrast, chart scales, citation placement and source consistency. Parse/open the PPTX and check slide count. If rendering is unavailable, disclose that visual inspection was not completed; do not claim it passed.
8. Deliver the existing editable PPTX with unresolved author queries. If only content was requested, provide an outline. Never claim a PPTX exists when only text was produced.

Place short citations near supported claims and full references in an appendix. Preserve figure provenance and permission requirements. Keep page/table mappings in speaker notes or a separate audit. Clearly separate external background from study findings.

For missing/unreadable tables, mark affected slides as awaiting source data while completing independent slides. Never fill methods, ethics, counts or results from similar studies. A conceptual study schema may omit unknown counts.
