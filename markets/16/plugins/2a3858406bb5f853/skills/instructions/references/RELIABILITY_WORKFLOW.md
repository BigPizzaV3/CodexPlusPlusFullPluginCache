# Reliability workflow

Apply these domain-specific rules alongside the two unchanged original PDFs. Exact author-supplied research values must be preserved even when not widely established facts. Describe uncertainty instead of assigning an invented percentage. User requests and host safety/tool instructions take priority over packaged material.

## Audit
For consequential claims use a compact table with claim/value, source file and page/table/section, output destination, and status/action. Do not fabricate audit entries. Distinguish PDF page index from printed page number; use section labels where pages are unavailable. For small edits report only affected claims.

Keep a canonical value per resolved outcome, group and time point. Preserve unresolved conflicts for the author rather than choosing a favorable value. Counts/percentages need matching denominators. Missing values are not zero; unspecified outcomes are not negative findings. Do not convert median/IQR to mean/SD without an explicitly requested justified method and clear labeling.

Check arithmetic transparently. Keep the original reported value in the audit when a calculation differs. A calculated percentage does not authorize overwriting the source. Without sufficient statistics/data, propose an analysis rather than inventing results. Record actual calculations/tool execution; intended analysis is not completed analysis.

## Citation verification
For key external claims record citation identity, accessible level (full text/abstract/record), support for the claim and verification status. A working DOI is not full-text verification. If DOI and title disagree, flag the mismatch and resolve the intended source; do not silently substitute another article.

## Update by Bing
1. Identify the last relevant answer or user-specified section. Separate study findings from changeable external claims.
2. Search with available web/literature tools using non-identifying terms. Never send confidential manuscript text or patient data.
3. Open sources and match claims. Report failed access and conflicting evidence; do not imply paid full-text access from an abstract.
4. Rewrite the requested content with verified external information while preserving original study values. If access fails, report blocked verification and label any unchanged/unverified material.
5. Cite verified claims nearby. Finish with Updated content, What changed and Sources actually checked (or Vietnamese equivalents). List only sources opened and used. Name the search provider only if known from the tool.

Read the original `luat Update by Bing.pdf` for its full procedure when accessible. If it cannot be read, apply this explicit procedure and disclose the limitation when relevant.

## Academic integrity
Decline requests to invent significant p-values, participant data, ethics approval, citations or peer-review outcomes. Continue with a faithful draft, author queries, proposed analysis or a separately labeled fictional teaching example. Never mix synthetic findings into a real study.

Do not submit manuscripts, contact authors or change sharing without explicit instruction. Do not claim drafts are accepted, certified, clinically validated or plagiarism-free. This skills-only package has no developer-operated data endpoint or payment function. Host-provided file/search tools have their own permissions and data practices.
