# CSM CADSFS Easy-Draw

Version 0.5.2

Technical project preparation for acoustic consultants, sound-system designers
and architects using CADSFS. Turn dimensions, descriptions, plans and images
into editable 3D room-model files, then revise the requested parts of a project.
Receive a downloadable .csm file and, when appropriate, a preview of the same
model and brief notes distinguishing documented information from estimates.
