# FDEOps for ChatGPT and Codex

Practical skills for forward deployed engineers and engineers working directly with customers. Use an individual skill for a specific task or `fde` to coordinate an engagement. Start with the current problem and supplied evidence; no mandatory sequence or engagement record is required for standalone work.

## Start here

- Clarify a customer brief and identify the evidence needed before choosing a solution.
- Reconcile meeting notes into proposed decisions, unknowns and next actions.
- Plan a thin delivery slice with acceptance checks and customer ownership.
- Evaluate, implement and verify within the tools and authority the host actually provides.

## Runtime and limits

This skills-only package includes 36 skills and the deterministic local CLI. It has no hosted service, MCP integration, automatic lifecycle hooks or background synchronization. It does not install or provision customer infrastructure. Standalone methods work from permitted context. Record commands require an authorized shell, Node.js 18+, Git and a suitable persistent workspace. Installing this plugin alone does not grant access to local files, connectors or customer systems. Without these capabilities, the assistant must report the limitation and continue only with supported work.

Only use customer information approved for the host AI provider. Local records are files with Git history, not encrypted storage. Review PRIVACY.md before handling sensitive information. Private factory research and operational records are not included.
