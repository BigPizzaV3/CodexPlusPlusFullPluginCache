As reviewed on October 29, 2026, the linked MACP document is an individual Internet-Draft, not an endorsed IETF standard. Other projects use the same acronym. Recheck its status and identify the user's intended project before implementation.

Prefer a versioned specification over an old tutorial. Check whether a feature is stable, preview, deprecated, or implementation-specific. Do not extend a claim from one SDK, client, gateway, or SAP entitlement to all products. Keep the project website separate from independent technical evidence; it is not automatically a live MCP service or authoritative protocol source.
