# AI JSON v1 contract scope

Package 2.0.0 targets baseline `b04db3c6ebf9d3609730142f1c51d14e6ce9b9cc`, AI Template schema 1, `scene-local-v1`, procedural recipe `scribe.procedural/1`, runtime `recipe-runtime/1`, asset 1 and RNG 1. Later builds require live discovery and importer confirmation; no universal minimum app version is asserted. [Lock file](contracts.lock.json) fingerprints the actual generator/validator inputs; [limits](limits.json) records runtime constants.

AI JSON is a portable TemplateEnvelope with `{schemaVersion, meta, payload, requiredAssets?, authoring?}`. Native `.scribe` is a ZIP persistence package with project snapshots and media manifests/assets, different schema versions and runtime `properties`. Do not rename one into the other, paste runtime objects into AI JSON, or claim schema parity with `.scribe`.

Read [generated envelope fields](ai-json-v1.fields.md) and [envelope schema](../schemas/ai-json-v1.schema.json). Every reachable declared field is generated, including metadata, project/scene/block, background, tracks, numeric keys/tangents, camera, draw settings, transitions, story beats, audio, slots/roles and all top-level object relationships. This is a complete structural DTO map, **not a complete closed importer schema**. `ObjectDTO.props: Record<string, unknown>`, track/key `meta`, flexible bindings/type/easing strings and ContentIdentity strings have opaque or runtime-owned meaning. Metadata normalizer does not preserve every optional DTO metadata tag. Some props are coerced, ignored, sanitized or renderer-specific. No field list of text/shape/SVG props can truthfully be called the entire prop contract.

| Area | Authoring contract / authoritative boundary |
|---|---|
| Envelope | Canonical package authoring emits all required DTO fields with `meta.type` scene/project/block and explicit timing semantics. Production import also normalizes raw payloads, `{scene:…}` wrappers and legacy project `meta.type:"template"`; those are import-compatible inputs, not canonical package examples. |
| Payload | Scene: positive width/height/durationMs and objects. Project: name/width/height/fps and nonempty ordered scenes with sceneId/order. Block: objects, optional anchor/timeline, no scene dimensions or duration. Canonical lint checks type matching via production normalization, IDs and scene timing. |
| Objects | `id,type,x,y,props`, optional bounds/rotation/text box/visibility/lock/timing/animation/styleRefs and relationships. The generated DTO includes `video`; importer rejects it. Actual supported type list is in limits.json. Array order matters; zIndex/styleRefs are DTO fields but must not be assumed to control import rendering without live verification. |
| Props | Common text fields: text/fontSize/fontFamily/fill/align/lineHeight. Shape: shapeType/fill/stroke/strokeWidth. SVG: svg. Path-backed: paths (id,d and render metadata). Smart connectors use smartStroke/renderStyle props; discover current tools for their full contract. Image/drawing/group/videoEmbed props remain opaque. Procedural has closed asset/recipe/score/palette contracts plus a flexible host prop bag. |
| Timeline | Owner IDs bind tracks to local objects; keys reference tracks. `binding`, `type`, interpolation/easing and meta are flexible DTO strings/data, **not a guarantee that a lane imports**. Production resolveTrackTemplateForObject checks eligibility; Anchor Binding owns x/y. Warnings identify skipped lanes. DrawStepDTO.easing is legacy and ignored by apply. |
| Camera | timeMs/x/y/zoom and optional id/easing/**rotation** survive current apply; follow-object target is remapped. Current live easing enum/schema must be checked. |
| Relationships | Top-level anchorBinding/clipBinding/connector/kineticText/pathMorph structures are generated in [relationship schema](../schemas/relationships-v1.schema.json) and [field map](relationships-v1.fields.md). props.pathFollow holds scene-object references. Graph/target eligibility, cycles, ownership and visual behavior still require runtime checks; package lint checks missing direct IDs but does not emulate the evaluator. |
| Story beats/audio | Structurally documented, but complex scene bindings, local media acquisition, cross-scene narration, browser decoding and playback are runtime workflows. Do not claim self-contained media from references alone. |
| Unsupported persistence | Shared cross-scene identity/managed Scene Pose contracts are absent from this AI envelope. Procedural mark/frame IDs belong to the recipe and are not scene IDs. Runtime caches/LUTs/guides/derived output are not authoring input. |

Generated schemas use JSON Schema draft-07 for the bundled Ajv engine. They validate the declared structural types; they do not replace import semantic checks, procedural digests/budgets/references or app mutation-boundary validation. The offline wrapper adds explicit canonical authoring lint rather than changing importer behavior. Its `--import-compatible` mode exposes the more permissive production import decision and reports schema/lint results separately. See [validation](validation.md).
