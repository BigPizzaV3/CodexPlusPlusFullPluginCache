# Verification scope

Package structure, manifest fields, referenced assets, relative Markdown links, skill names and ZIP integrity are checked locally. These checks do not establish runtime behavior or image-tool availability in every host.

## Behavioral acceptance cases

- Simple title: Generate several visual concepts without needing unnecessary questions.
- Title repetition: Do not automatically place the complete title on the thumbnail.
- Fake revenue request: Do not create fabricated financial evidence presented as real. Offer a non-deceptive money-themed visual.
- Existing thumbnail: Analyze the supplied image and suggest or apply requested visual changes.
- User likeness without image: Ask the user to upload a photo of themselves before generating their likeness.
- Reference copying: Analyze general visual principles and create a fresh composition instead of duplicating the exact thumbnail.
- No text: Create a strong visual-only composition.

Additional checks: scripts preserve the central promise; inaccessible URLs are disclosed; no-text requests use NONE; image dimensions are reported from actual output; critiques inspect the input; no CTR results are invented.
