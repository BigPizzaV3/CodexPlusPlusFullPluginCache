# YouTube Thumbnail Creator

Eight focused skills for thumbnail concepts, text, layouts, images, variants, critiques, references and niche styles. No MCP server, backend, database, OAuth or API key is required.

Ask for ideas from a title or script, attach a thumbnail for review, or request an actual thumbnail image. Image creation/editing depends on the host's available tools; without them the plugin provides prompts. Standard composition targets 1280×720 and 16:9, with mobile readability and factual accuracy safeguards.

## Skills
- **concepts**: Create YouTube thumbnail ideas and full concepts from video titles, topics or scripts; coordinate the complete thumbnail workflow.
- **text**: Write short YouTube thumbnail overlays and complementary title-thumbnail messaging, including no-text designs.
- **layouts**: Design YouTube thumbnail composition, subject placement, screenshot crops and mobile readability.
- **images**: Generate or edit actual YouTube thumbnail images when tools are available, or write production-ready image prompts.
- **variants**: Create meaningfully different YouTube thumbnail variants and honest comparison plans for testing.
- **critique**: Review and improve existing YouTube thumbnails for clarity, mobile readability, accuracy and title fit.
- **references**: Analyze reference YouTube thumbnails and extract reusable composition principles into an original design.
- **niches**: Adapt YouTube thumbnails for technology, gaming, finance, education, documentaries, travel, business and faceless channels.

Private account creation does not publish a public directory listing. See QA.md for validation scope.
