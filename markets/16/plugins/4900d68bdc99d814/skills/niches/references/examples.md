# Example directions
- Technology: supplied laptop photo enlarged against a clean background, "WORTH IT?" only if the review evaluates value. Do not invent benchmark numbers.
- Gaming: authentic boss encounter crop with the player and boss forming two clear masses; no fabricated rare-item drop.
- Finance: budgeting video represented by two envelopes labeled NEEDS and WANTS; no fake balances.
- Business: supplied working app screen with one real feature enlarged; "BUILT THIS" instead of invented revenue.
- Education: large diagram of one concept, minimal labels and one highlighted relationship.
- Documentary: verified artifact beside an accurate location; label any reconstruction clearly.
- Faceless: one recognizable object against contrasting negative space, no text if requested.
