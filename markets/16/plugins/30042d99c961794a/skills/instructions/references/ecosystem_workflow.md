# HLP Medical Education Ecosystem Workflow

Creative Educator can work alongside Medical Blueprint Builder, Học Y and Luyện thi. These are complementary roles, not automatic tool calls.

## Recommended sequence

### 1. Medical Blueprint Builder — What should be taught?

Use when the starting point is a topic, syllabus, competency framework or guideline and the educator needs content prioritization, outcomes and blueprint structure.

Useful handoff into Creative Educator:

- target learner;
- competency/outcomes;
- must-know / should-know / nice-to-know content;
- content weighting;
- expected reasoning/decision level;
- assessment blueprint;
- source constraints.

### 2. Creative Educator — How should it be taught?

Convert the blueprint into:

- lesson/session plan;
- course/module sequence;
- active-learning activities;
- cases and facilitation questions;
- slide storyboard;
- assessment placement;
- faculty guide;
- implementation and evaluation plan.

### 3. Học Y — How will the learner interact with the content?

Use for learner-facing tutoring, explanation, adaptive questioning, misconception correction and guided practice.

Useful handoff from Creative Educator:

- learner level;
- learning objectives;
- prerequisite knowledge;
- teaching sequence;
- cases/tasks;
- misconceptions to probe;
- desired depth and language;
- stopping rule or mastery criterion.

### 4. Luyện thi — How will competence be practiced/tested?

Use for quiz/exam delivery, question-bank practice, scoring, remediation and deeper item QA.

Useful handoff from Creative Educator:

- exam blueprint;
- item count/types;
- cognitive level;
- difficulty intent;
- topic weighting;
- feedback policy;
- source constraints.

## Rule against duplication

If the user already provides a high-quality blueprint, do not rebuild it unless asked. If a tutoring script already exists, do not recreate it as a course plan unless needed. If a validated item bank is provided, do not rewrite items merely for style.

## Compact handoff format

**To:** [plugin/workflow]
**Goal:** ...
**Learner:** ...
**Inputs:** ...
**Required output:** ...
**Constraints:** ...
**Sources:** ...
**Success criteria:** ...
