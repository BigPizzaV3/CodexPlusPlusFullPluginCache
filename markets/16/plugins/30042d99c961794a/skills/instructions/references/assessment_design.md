# Assessment Design Reference

Use for MCQ/SBA, SAQ, OSCE, rubric, oral exam, formative assessment, summative assessment, test blueprint and item review.

## Alignment first

Start from the learning outcome and the level of performance to be assessed. Do not choose an item format before defining what evidence of learning is needed.

## SBA / MCQ

Prefer one-best-answer items with a focused problem. For clinical items, use enough context to test reasoning without irrelevant detail. Options should be homogeneous in type and plausible to the intended learner.

Avoid:

- negative stems unless necessary;
- grammatical cues;
- longest-answer clues;
- implausible distractors;
- overlapping options;
- trick wording;
- “all/none of the above” by default;
- absolute terms used as cues;
- testing trivia unrelated to the outcome.

Do not claim psychometric performance without observed item data. Distinguish expert review from empirical item analysis.

## Blueprint

For an exam or question set, map items across content domain, competency/cognitive process, difficulty intent and weighting. Avoid over-sampling easy recall simply because it is easier to write.

## OSCE / performance tasks

Specify station purpose, candidate instructions, standardized-patient/examiner setup, observable behaviors, checklist/global-rating logic, timing and debrief/use of scores. Do not invent validated cut scores.

## Rubrics

Use criteria tied to observable performance. Prefer 3–5 meaningful performance levels with behaviorally anchored descriptors. Avoid vague labels without descriptors.

## Feedback

For formative assessment, feedback should identify what was done well, what needs improvement and the next actionable step. When using retrieval practice, avoid revealing the answer before the learner commits to a response.

## Handoff to Luyện thi

If the user wants large-scale question-bank generation, adaptive quiz delivery, exam-mode practice, grading or detailed MCQ QA, create a concise handoff brief for Luyện thi containing:

- learner level;
- topic/content blueprint;
- number and format of items;
- target cognitive level;
- difficulty intent;
- feedback mode;
- source constraints;
- any prohibited content or styles.
