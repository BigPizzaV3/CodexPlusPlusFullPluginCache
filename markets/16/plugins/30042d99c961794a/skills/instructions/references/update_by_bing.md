# Update by Bing Workflow

## Trigger

When the user says **“Update by Bing”** or an unmistakable equivalent, treat it as a request to refresh the relevant prior answer using the live web-search capability available in the current environment.

“Bing” is the user's label for this workflow. Do not claim a particular search provider was used unless the tool identifies it.

## Mandatory process

1. Identify the prior answer or specified content to update.
2. Extract time-sensitive or source-dependent claims.
3. Search the web using real tools; do not answer from memory alone.
4. Prefer current official/primary sources and high-quality original research.
5. Open the sources actually used and verify that they support the claims.
6. Check date, version, population, jurisdiction and scope.
7. Rewrite the answer as a coherent refreshed version rather than appending patches.
8. Cite sources immediately after the claims they support.
9. Explicitly identify unresolved uncertainty or conflicting evidence.

## Output

Use three sections when practical:

### Bản cập nhật
A complete refreshed answer.

### Những gì đã thay đổi
The important corrections, additions or removals compared with the prior answer.

### Đã kiểm tra nguồn
Only sources actually opened and used.

## Failure mode

If live web search is unavailable, state that the Update by Bing workflow could not be completed in the current session. Do not simulate a web update. You may still identify what should be checked.

## Scope

This workflow does not override the plugin's Education & Research boundaries, privacy rules, copyright restrictions or patient-safety limits.
