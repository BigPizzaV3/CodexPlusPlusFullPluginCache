# Example workflows

## Randomized trial

1. Identify Methods > design, registration, randomization, arms, masking, and analysis population.
2. Extract eligibility, recruitment, total enrolled and analyzed by arm.
3. Separate primary/secondary outcomes and every timepoint.
4. Make separate records for ITT/per-protocol and adjusted/unadjusted results.
5. Attach table/figure/page locations; preserve adverse events and author limitations.
6. If asked for bias support, provide result-specific evidence by domain; do not infer a formal RoB 2 rating from incomplete text.

## Cohort study

1. Establish prospective/retrospective design, source population, exposure, comparator and follow-up.
2. Extract group denominators, outcome ascertainment, attrition, confounders and model covariates.
3. Preserve crude and adjusted estimates separately; describe associations without causal overclaim.
4. If several reports might be the same cohort, flag matching signals and request confirmation rather than merging.

## Diagnostic accuracy paper

1. Capture clinical role/intended use, index test, reference standard, threshold and participant spectrum.
2. Extract TP/FP/TN/FN, denominators, sensitivity, specificity, predictive values, AUC, and confidence intervals exactly as reported.
3. Note blinding, timing/flow and indeterminate results only from source evidence.
4. Do not recompute or select a threshold unless requested and supported by supplied counts.

## Qualitative study

1. Extract qualitative approach, setting, participant selection, data collection, analysis, reflexivity and trustworthiness practices as reported.
2. Keep reported themes and participant quotations attributable to their stated source locations.
3. Do not force sample-size inference, intervention/comparator or statistical significance into the record.

## Several papers for a review

1. Confirm review question and fields; lock one schema before extracting.
2. Assign each report a unique ID; process it independently; never borrow a missing value from another paper.
3. Record every study's locations and missingness codes, then build the common evidence table.
4. Run cross-paper consistency and possible duplicate-cohort checks; keep companion reports distinguishable.
5. Return a list of unresolved discrepancies and decisions requiring human review.
