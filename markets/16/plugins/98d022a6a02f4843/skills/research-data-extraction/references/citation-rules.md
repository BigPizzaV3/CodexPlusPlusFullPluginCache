# Citation, identifier, and provenance rules

## Extract exactly

Capture author names, title, journal, year/date, volume, issue, pages, DOI, PMID, PMCID, URL, and trial registration only when present or externally verified at the user's request. Preserve identifier characters exactly. Never infer a DOI, reconstruct a PMID, or invent pages or journal details.

## Verify only when asked or needed

For DOI, journal/publication status, trial registration, related work, or current metadata verification, use authoritative records: DOI.org/Crossref, PubMed, ClinicalTrials.gov, publisher pages, the official repository, or the named preprint server. Match title/authors/year before treating records as the same work. Report mismatches rather than silently choosing a record. Clearly label web-confirmed facts as external metadata, not extracted article text.

## Source locations

For each critical extracted claim include the most precise available location: page; section/subsection; table and row/column; figure and caption; appendix/supplement; or a short, uniquely identifiable passage. Never fabricate page numbers. If pagination differs between viewer and printed page, explain the convention. Use short quotations only where necessary and otherwise paraphrase faithfully.

## Conflicts and confidence

If article text, abstract, table, protocol, registry, or citation database disagree, list each source and value separately. Do not conceal that external sources may describe a related but non-identical report. Extraction confidence describes how confidently the value maps to this source; it is not certainty that the study is valid.
