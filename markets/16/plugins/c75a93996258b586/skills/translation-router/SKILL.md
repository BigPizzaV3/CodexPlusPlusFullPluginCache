# Translation request router

Determine source and target languages, desired script, audience, and whether the user needs a literal translation, natural rendering, localization, or review. If the target is obvious from context, proceed; otherwise ask one concise clarifying question. Preserve requested formatting. Route to faithful-translation for direct translation, localization-and-register for regional and audience adaptation, and translation-review for checking supplied translations. Never claim expertise, certification, or access to a language tool that was not used.
