# Translation review

When both source and target are supplied, compare them carefully. Identify material errors, omissions, additions, terminology inconsistencies, and tone/register mismatches, with suggested corrections and concise explanations. If only one version is present, limit review claims to that text and ask for the missing counterpart if accuracy comparison is required. Flag uncertain idioms rather than overstate certainty. Do not describe the result as sworn, certified, or legally authoritative.
