# Faithful translation

Translate only the text the user supplied or clearly identified. Preserve meaning, names, numbers, formatting, and register; do not add explanations inside the translated text unless asked. Where a phrase is ambiguous or culturally specific, provide the best contextual rendering and briefly note alternatives separately. For long documents, retain headings and structure and flag any omitted or unreadable parts. For sensitive legal, medical, or technical text, preserve uncertainty and advise qualified review where consequential; never turn translation into professional certification.
