[SINTAXE MERMAID v10+ - REGRAS INVIOLÁVEIS]

**PRIORIDADE MÁXIMA - ZERO ERROS ACEITOS:**

1. **Estrutura base:** `flowchart TD` (não `graph`)

2. **IDs:** Alfabéticos sequenciais MAIÚSCULOS (A, B, C, D...)
   ❌ ERRADO: INICIO, PROT1, analise
   ✅ CORRETO: A, B, C

3. **Textos:** SEMPRE entre aspas duplas dentro de colchetes `["texto"]`
   ❌ ERRADO: A[texto]
   ✅ CORRETO: A["texto"]

4. **Escape aspas internas:** Substituir `"` por `&quot;`
   ❌ ERRADO: A["Ofício "urgente""]
   ✅ CORRETO: A["Ofício &quot;urgente&quot;"]

5. **Losangos (ERRO MAIS COMUM):** APENAS chaves `{"texto"}` - SEM parênteses!
   ❌ ERRADO: D({"Aprovado?"}), D{("Aprovado?")}
   ✅ CORRETO: D{"Aprovado?"}

6. **Tipos de nós:**
   - Retângulo: `A["texto"]`
   - Arredondado: `A(["texto"])`
   - Losango: `A{"texto"}` (SEM parênteses!)
   - Círculo: `A(("texto"))`

7. **Conexões:**
   - Simples: `A --> B` (seta DUPLA, nunca simples `->`)
   - Rotulada: `A -->|"SIM"| B`

8. **Validação OBRIGATÓRIA:**
   - Testar em https://mermaid.live antes de entregar
   - Selo: `✅ Testado em mermaid.live - Parse OK`

**Exemplo perfeito (testado):**
```mermaid
flowchart TD
    A["Início<br/>Servidor solicita férias"] --> B["Preencher formulário"]
    B --> C["Enviar para chefia"]
    C --> D{"Tipo de solicitação?"}
    D -->|"Férias regulares"| E["Verificar saldo"]
    D -->|"Férias prêmio"| F["Verificar requisitos"]
    E --> G{"Possui saldo?"}
    G -->|"SIM"| H["Aprovar"]
    G -->|"NÃO"| I["Negar"]
    F --> J{"Atende requisitos?"}
    J -->|"SIM"| H
    J -->|"NÃO"| I
    H --> K["FIM"]
    I --> K
```

[TROUBLESHOOTING MERMAID]

**Erro 1:** "Parse error... Expecting 'PS', got 'DIAMOND_START'"
→ Causa: Losango com parênteses
→ Solução: D{"Decisão?"} não D({"Decisão?"})

**Erro 2:** "Lexical error on line X"
→ Causa: Aspas não-escapadas
→ Solução: Use &quot; para aspas internas

**Erro 3:** "Unexpected token"
→ Causa: ID não-alfabético ou texto sem aspas
→ Solução: IDs = A,B,C... Textos = ["..."]
