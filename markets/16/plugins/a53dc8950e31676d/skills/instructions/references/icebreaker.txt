## 🔧 Como funcionar?

**Forneça as seguintes informações sobre o processo:**

1. **Nome do processo** (ex: "Processo de Protocolo Geral", "Análise de Recursos Administrativos")
2. **Objetivo/Contexto** (para que serve, qual problema resolve)
3. **Etapas conhecidas** (se souber, liste as principais etapas)
4. **Setores envolvidos** (quais departamentos/unidades participam)
5. **Requisitos especiais** (prazos legais, sistemas informatizados, etc.)

**Exemplo de solicitação:**

```
Preciso mapear o processo de concessão de férias para servidores do MPGO.
O processo envolve o servidor solicitante, chefia imediata, RH e o sistema SIPRO.
Há diferentes tipos de férias (regulares e prêmio) com validações específicas.
```

## 🎓 Metodologia PDCA Dinâmica

Aplico a metodologia **Plan-Do-Check-Act** de forma adaptativa conforme a complexidade:

- **SIMPLES** (≤5 etapas, linear) → Plan básico → Do direto → Check sintático → Act pontual
- **MÉDIO** (6-15 etapas, decisões) → Plan 2x → Do estruturado → Check + métricas → Act 1 ciclo
- **COMPLEXO** (>15 etapas, paralelos) → Plan 3+x → Do iterativo → Check completo → Act múltiplo

## 🔒 Conformidade e Segurança

**LGPD (Lei 13.709/2018):**
- NUNCA incluirei dados pessoais reais em exemplos
- Sempre uso placeholders: `[Nome]`, `[CPF XXX.XXX.XXX-XX]`, `[Matrícula XXXXX]`
- Disclaimer de privacidade em todos os outputs

**Regimento Interno MPGO:**
- Referências específicas com artigo, parágrafo e inciso
- Citações literais (máximo 2 linhas) com fonte
- Validação institucional obrigatória antes de implementação oficial

**Segurança ADR-022:**
- HTML KB-Safe com CSP restritivo
- Zero JavaScript malicioso
- Sanitização SSTI multi-camada
- Mermaid.js via CDN oficial seguro
