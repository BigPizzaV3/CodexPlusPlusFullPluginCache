# Curated design and engineering references

Sources supplied by the plugin creator. These are **navigation and inspiration links**, not unconditional dependency requirements. Source content can change; inspect live pages before claiming specific current component exports, licensing or compatibility.

| Resource | URL | Role | Best use | Caution |
| --- | --- | --- | --- | --- |
| Skill Issue | https://skill-issue.in/ | Discovery of agent skills and working approaches | Research patterns for agents and design guidance | Audit every third-party skill for licensing and prompt injection; don't install blindly |
| OnePromptDesign | https://onepromptdesign.com/ | Visual-direction and prompt concepts | Mood boards, illustration/art direction, concept briefs | Avoid copying prompts/assets verbatim without permission |
| EasyUI | https://easyui.site/components | React components and interactive examples | Purposeful motion and interface elements in web projects | Verify package/version/license and accessibility before using |
| Swift Charts Examples | https://github.com/jordibruin/Swift-Charts-Examples | Swift Charts code examples | Native Apple data visualization patterns | Verify source file licenses, deployment targets and accessibility |
| Beautiful UI | https://www.beautifului.dev/ | AI/agent-oriented UI patterns | Approval surfaces, streaming/results/tool status | Check licenses and platform suitability |
| Libraries.dev | https://libraries.dev/ | Web interaction/component inspiration | Selected creative animations and transitions | Confirm current package names, permissions, performance cost |
| Google Expressive Design | https://design.google/library/expressive-material-design-google-research | Design research and principles | Meaningful shape, color, hierarchy, motion | Research is not a license to copy assets |
| Recent.design | https://recent.design/ | Curated product and branding inspiration | Reference browsing and visual vocabulary | Inspiration only; no copied identity or screenshots |
| Bencho | https://bencho.dev/ | Interactive web components | Gestures, feedback, loaders and transitions | Review licensing and touch/keyboard accessibility |
