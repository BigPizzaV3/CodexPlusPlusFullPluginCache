# Build Website

1. Distinguish informational sites from authenticated apps; do not wrap an app in an unnecessary marketing homepage.
2. Review `../../references/design-quality.md`, `../../references/web-and-pwa.md` and chosen design references. Preserve supplied copy, sections, branding and factual claims; ask only for blocking assets.
3. Choose an appropriate static/SSR framework based on existing project, SEO, editorial needs and content management. Avoid imposing Next.js on a simple static site.
4. Implement semantic structure, navigation, functional forms/links, responsive grids, responsive images, safe typography and sensible performance budgets. Generated visuals require asset authorization and actual generation tools.
5. Run build/lint/tests, check mobile and desktop layout and keyboard navigation, inspect hero/section continuity and interaction states. Never claim browser inspection without captured evidence.
6. Deliver runnable source, previews where available and test/visual findings. No automatic publish.
