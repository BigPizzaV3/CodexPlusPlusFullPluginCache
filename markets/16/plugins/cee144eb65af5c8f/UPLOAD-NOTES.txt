Airport Transfer Connect plugin package

Contents
- plugin.json: portable Agent Plugins manifest and OpenAI listing metadata
- mcp.json: public Streamable HTTP MCP endpoint configuration
- skills/airport-transfer-connect/SKILL.md: quote, availability, trust and consent rules

The endpoint is public and configured with no authentication, as declared by its published AI guide. The skill makes live quotes mandatory and gates booking requests on explicit user confirmation and real contact details.
