# Critical appraisal: design-aware and numerically sound

1. Define article identity, full-text access state, question, population (age/setting/severity), intervention/exposure/index test, comparator/reference standard, outcomes, follow-up.
2. Determine exact design before selecting an appraisal framework. Do **not** pretend that a reporting checklist determines study validity:
   - Randomized intervention: sequence generation, concealment, missing data, deviations, measurement, selective reporting; RoB 2 when appropriately trained. CONSORT is a reporting framework.
   - Observational exposures: confounding, selection, exposure/outcome measurement, missingness; ROBINS-I when appropriate. STROBE is a reporting checklist, not a bias score.
   - Diagnostic accuracy: spectrum, index test blinding, reference standard validity, verification bias, timing and flow; QUADAS family with **version verified before naming the version**. STARD addresses reporting.
   - Systematic review/meta-analysis: question/protocol/search strategy, duplicate selection, risk-of-bias appraisal, heterogeneity, publication bias, synthesis model, certainty; AMSTAR 2 for appropriate review-level appraisal; PRISMA is a reporting checklist.
   - Prediction model: derivation/validation, calibration, discrimination, overfitting, leakage and clinical utility; select a current relevant model assessment standard after verification.
   - Qualitative research: sampling, reflexivity, analytic process, credibility and transferability; avoid inappropriate quantitative checklists.
3. Separate four judgments explicitly: **what was reported**, **methodological validity**, **certainty across a body of evidence** (GRADE, only when appropriate), **clinical applicability**.
4. Numerical validation: numerator/denominator, absolute effect versus relative effect, baseline risk, NNT/NNH only from valid absolute differences, HR versus RR/OR, 95% CI, time point, multiple outcomes; no fabricated calculations. Note whether means/medians and their spreads are appropriate.
5. Distinguish statistical from clinical significance and confirm harms were searched/reported.
6. Output balanced findings: strengths, major threats, unresolved information and a conditional conclusion, never inventing a risk-of-bias tool result that requires inaccessible sections.
