# Reference retrieval and audit

## Four verification tiers (not a quality score)
- R0 — Seen only in the manuscript bibliography, **not verified externally**.
- R1 — Metadata matched in a primary index or publisher (title, author, year, journal, DOI/PMID as available).
- R2 — Abstract or publisher summary accessed and its relevant claim compared.
- R3 — Full text/primary guideline section actually accessed and relevant claim supported.
Never award R2 or R3 by reading a second-hand review or title alone.

## Audit process
1. Extract all relevant cited reference entries **as actually displayed** in the supplied file; transcribe carefully, no fabricated missing fields.
2. If bibliography has numeric citation markers, match markers to the exact sentence or paragraph in the article; a list entry is not proof it supports the sentence.
3. Search PubMed, publisher pages, Crossref, DOI resolver or appropriate primary databases *when accessible*. Match title, year, journal, authors; guard against similar-title and online-first variants. Keep PMID and DOI distinct.
4. When verification is possible, open the specific record and, if claiming support, examine relevant abstract/full-text outcome rather than just citation metadata. Avoid 404, citation redirects to unrelated content and preprints misrepresented as final publications.
5. Report for each citation: manuscript reference number; quoted/condensed bibliographic metadata; where it was cited in manuscript; targeted claim; verification tier and URL/status; discrepancies and limitations.
6. If no web access, assign R0 unless the user provided the full reference article; show a proposed reproducible PubMed query but do not fabricate search results.
7. If user wants all references, enumerate **all available entries** from actual document. If list is long, use a table or a separate downloadable artifact where tools permit. Explain skipped/unreadable pages and never pretend completeness.

Do not convert a URL string copied from the paper into 'verified alive'. Clearly distinguish user-provided source link from tool-opened link. Favor primary records.
