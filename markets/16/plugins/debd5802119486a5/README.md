# Landbase

Build B2B prospect lists in ChatGPT, qualify and research accounts, enrich company and contact data, find lookalike companies, and export results.

## Connect

Connect to https://mcp.landbase.com/mcp/openai using OAuth with Dynamic Client Registration. Sign in to Landbase and select the account whose data you want to use. No API key is needed.

## Workflows

Nine skills cover getting started, prospect lists, qualification, account research, contact enrichment, importing and matching, lookalikes, exports, and dataset/run management. Longer jobs return run IDs and status; continue checking the same run instead of starting it again after a timeout.

## Account usage and approvals

Operations that use credits return a quote and require your approval. Retain each tool's confirmation steps. This ChatGPT package uses the account's existing entitlements and does not guide users through plan purchases or upgrades.

## Data and scope

Requests, dataset identifiers and files you choose to upload are sent to Landbase. Results can contain business contact information. Use the account and dataset you select. This MCP toolset provides data workflows; it has no direct CRM write/deduplication or Instantly/HeyReach campaign-execution tools.
