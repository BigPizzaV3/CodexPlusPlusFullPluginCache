# 1stDibs ChatGPT plugin

This package connects ChatGPT to the public 1stDibs MCP server. It contains no
skills; catalog search, taxonomy, item details, and the item display view are
provided by the server.

The server URL is the production endpoint documented in `apps/dibs-mcp/SPEC.md`:
`https://www.1stdibs.com/soa/mcp`.
