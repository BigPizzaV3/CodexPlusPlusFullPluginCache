# checklist.gg — ChatGPT public submission package

Connects ChatGPT to the checklist.gg MCP server: https://mcp.checklist.gg/mcp

Includes listing metadata, starter prompts, five positive and three negative review test cases, commerce declaration, release notes, and an icon.

Submission notes:
- The test cases are drafted from the tool names supplied and have not been executed here.
- Add the reviewer-accessible demo recording URL before submitting for initial public review.
- Confirm the verified publisher identity in the submission portal; package metadata does not replace publisher verification.
- If authentication is required, configure reviewer access in the portal. Do not put credentials in this ZIP.
- Country targeting is omitted so it can be selected in the portal.
