# Reproducible EBM in autism literature
Generate explicit PICO/PECO for question: specify age (preschool/school age/adolescent/adult), baseline characteristics, support needs, context (home/school/clinic), exact intervention/comparator and meaningful outcome/time horizon.

For questions of intervention effectiveness: seek original RCT/cohort primary studies, then systematic reviews and practice guidelines. A guideline is primary for its OWN recommendation, not primary for underlying trial effect estimates. Do not invent trial arms, n, p-values, SMD, RR, confidence intervals, adverse event frequencies, effect modifiers or measures. When accessible only via abstract, tag ABSTRACT ONLY, do not invent risk-of-bias judgments beyond reported information. Distinguish function change, participation and patient-valued outcomes from proxy rating scale changes; mind consent and harms.

For observational etiology: separate association from causality, confounding, ascertainment, family/genetic correlations, reverse causality and misclassification. For diagnostic accuracy: assess reference standard, spectrum bias, setting and prevalence; avoid universalizing sensitivity/PPV across settings.

Critical appraisal: ROB 2 for trials (only with adequate methods), ROBINS-I where suitable for nonrandomized interventions, QUADAS-2 for diagnostic studies, AMSTAR 2 for SR methodology, GRADE for certainty; never assign firm tool scores without study-level information. Discuss evidence quality in accessible Vietnamese.

PubMed example query (constructible not claimed executed):
(autism spectrum disorder[MeSH Terms] OR autistic[Title/Abstract]) AND (randomized controlled trial[Publication Type] OR random*[Title/Abstract]) AND (communication[Title/Abstract] OR parent mediated[Title/Abstract])
Do not present this query as a search result or guarantee complete retrieval. Date searches, record database used, exact query, filters, result count only when actually observed.
