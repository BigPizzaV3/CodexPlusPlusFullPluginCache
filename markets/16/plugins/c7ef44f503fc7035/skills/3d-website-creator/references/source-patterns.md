# Patterns distilled from the supplied 3D website prompt conversation

These are optional starting points, not defaults for unrelated brands or products.

## Studio and portfolio pattern

- Journey: entry scene, brand object, service installations, project gallery, owned products, design process, studio/about scene, project inquiry.
- Page-level variations: service workshop stations; device/product bench; interface assembly; AI mechanism; landing-page display; editorial workspace; dashboard desk; searchable plugin modules; folios for writing libraries; device gallery for apps; branded product displays; project-specific case study exhibits; quiet studio; compact contact installation.
- Category motifs: paper and document displays for writing; browser and reporting objects for SEO/marketing; hardware and readable code for programming; books/reference tabs for research; color/material samples for image design; camera/timeline for media; calendar/task objects for productivity; paired documents for translation.
- Keep searchable lists, filters, navigation, direct links, and 2D fallback functional outside the renderer.

## Cinematic home and interiors pattern

- Optional story: broad celestial or landscape establishing view, atmosphere/clouds, terrain, home exterior, threshold/entry, rooms, furniture/materials, floor plan/configurator, consultation.
- Use this only when the product is architecture/interiors or the user explicitly chooses a cinematic narrative. It is not an appropriate default for general businesses.
- Favor light-mode daylight, natural materials, editorial typography, believable room proportions, useful material/furniture controls, and calm movement.
- If environmental or scientific imagery is used, keep scale and motion visually plausible. A staged sequence can appear connected through scene transitions but should not be represented as a literal continuous simulation.

## Cross-cutting requirements

- A 3D scene belongs to a page's purpose and remains compatible with readable semantic content.
- Any external portfolio preview must distinguish permitted interactive embedding, timestamped screenshots, and stale/unavailable fallback.
- Direct navigation, touch, keyboard, reduced motion, and a complete 2D experience remain available.
- Photorealism is an implementation and QA goal, not an outcome guaranteed by wording alone.
