# Doers 3D Website Creator

Skills-only plugin for designing, prompting, implementing, and reviewing immersive 3D websites. It supports distinct studio/portfolio, cinematic home/interior, and custom experiences.

## Skills

- 3d-website-creator: Route work and define scope, brief, scene matrix, and deliverables.
- site-recon-brief: Inspect supplied sites and projects, preserve verified facts and route intent.
- 3d-visual-direction: Create page-specific scene and style direction, including realistic light-mode work.
- 3d-scene-architecture: Plan a maintainable renderer, scene, content, and asset structure.
- 3d-motion-interaction: Map camera choreography, scroll, controls, and reduced-motion behavior.
- live-preview-integrity: Keep external website previews, captures, metrics, and freshness claims honest and secure.
- responsive-accessibility: Preserve mobile, keyboard, accessibility, performance, and 2D fallback behavior.
- visual-qa-handoff: Compare real pages and states, iterate on visible differences, and report evidence.

## Boundaries

The plugin contains instructions only. It does not host a website, fetch client sites, run background monitoring, connect to APIs, or deploy code by itself. Those capabilities require available authorized tools and infrastructure. It never promises literal 100% replication or photorealism, fabricates live data, guesses client URLs, or bypasses upstream embedding restrictions.

The source conversation contributed generalized design patterns: a studio/portfolio experience with different scenes for services, project work, products, libraries, studio, and contact; a separate cinematic home/interior journey; and requirements for verified public previews, responsive controls, reduced motion, and a 2D fallback. Specific company details, contact data, and client URLs from the conversation are intentionally not baked into this reusable package.
