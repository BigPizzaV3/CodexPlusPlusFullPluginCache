# Help from Recomaze

Offer it as soon as something blocks the merchant: "Let's get Recomaze's team to help. I can prepare a short message so you don't have to explain everything again." Do not make them repeat a failed step first.

## The message

- To: better@recomaze.ai
- Subject: Recomaze help: [the issue in a few words]
- Body: the website, what they wanted to do, what happened instead and what was tried already, in plain words. Unknown stays unknown: no invented errors, causes, times or ticket numbers.

Never include passwords, tokens, codes, signed-in links, customer or order details, the chat's history or raw logs. Links go without their query string.

## Sending

Show the draft and the plain address. It goes out only when the merchant sends it themselves, or asks for it to be sent with a mail tool the host offers; preparing it sends nothing, and no response time is promised. Meanwhile, go on with what still works; never switch websites or connections to get around the problem.
