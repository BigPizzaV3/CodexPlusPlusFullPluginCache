## Niche playbook
| Niche | Top formats | Key shots | Watch-outs |
|---|---|---|---|
| Skincare & makeup | routine, application demo, texture close-up, wear test | swatch, texture, application, real finish | describe feel, finish and look only; no claims of fixing skin problems |
| Fashion & accessories | try-on haul, "3 ways to style", fit check | mirror, movement, fabric close-up, fit on body | honest sizing info |
| Jewelry | unboxing, styling, gift reaction | sparkle in light, on skin, packaging | real materials only |
| Food & drink | first bite, recipe, "what I eat", pour shots | steam, crunch, pour, cut, reaction | no extreme diet messages |
| Kitchen & home | demo, before/after, "Amazon finds" style list | the product working, mess vs clean | safe use |
| Cleaning products | satisfying before/after, ASMR | the stain, the swipe, the result | same lighting before/after |
| Pets | pet reaction, routine, problem-solution | the pet using it, owner's reaction | pet safety first |
| Products for parents | parent hack, routine, honest review | the product in use, adult hands | adults speak; never film children without guardian consent; keep kids' details private |
| Tech gadgets | unboxing, setup, "things it can do", comparison | ports, screen, sound test, size in hand | real specs only |
| Travel & outdoor gear | packing, field test, POV adventure | in-use outdoors, durability test | honest conditions |
| Sports & fitness gear | gear demo, "first workout with", comparison | product in motion | performance claims only if proven; no body-change promises |
| Books & courses | "books that changed how I...", what's inside | pages, notes, reading moment | no guaranteed outcomes |
| Car accessories | install demo, before/after, POV drive | install steps, final look | never film while driving |

## Expert workflow
1. Pick 2 formats from the niche row.
2. List the **must-get shots** for that niche.
3. Write hooks in the **language that niche uses** (e.g. "finish", "fit", "crunch", "setup").
4. Apply the watch-outs.
