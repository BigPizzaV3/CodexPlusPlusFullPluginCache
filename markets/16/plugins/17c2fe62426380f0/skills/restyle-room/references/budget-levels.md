# Budget levels

The level decides how much of the room changes. It is about scope, not a currency amount; ask the user for a number only if they want cost estimates.

All three levels keep the room's permanent features exactly as they are.

## Low — styling, not shopping

- Rearrange the furniture that is already there.
- Add small things: cushions, throws, plants, a lamp, a tray, one piece of art, simple accessories.
- Do not replace any large furniture.
- The result should read as clever styling of the same room.

## Mid — the high-impact pieces

- Replace the pieces that define the room: sofa, bed, dining table, main chairs.
- Add what completes the look: rug, curtains, lighting, complementary decor.
- Keep smaller existing items when they fit the style.
- The result is a noticeably different room without a full overhaul.

## High — clear the room and start again

- Mentally empty the room, then furnish it from nothing.
- Replace everything movable: furniture, soft furnishings, lighting, decorative objects, with pieces that fully embody the style.
- Be bold and complete.
- Walls, flooring, windows, doors and built-ins still stay as they are, unless the user owns the home and asked for more.
