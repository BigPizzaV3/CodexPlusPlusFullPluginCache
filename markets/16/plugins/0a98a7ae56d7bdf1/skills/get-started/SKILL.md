# Get started with HiveRef

HiveRef runs reference checks for hiring teams. Once connected, you can ask about your organisation's reference checks without opening the dashboard.

1. Connect HiveRef and sign in with your HiveRef account. You need a HiveRef workspace (sign up at https://www.hiveref.com/sign-up).
2. On the HiveRef consent screen, tick "send reference checks" only if you want ChatGPT to be able to send checks for you. Without it, the connection is read-only.
3. Try asking:
   - "Which reference checks are still waiting on referees?"
   - "Is the report ready for the Warehouse Team Leader check?"
   - "Suggest reference questions for a Registered Nurse role." (needs sending turned on)

Reports stay in HiveRef. ChatGPT tells you when a report is ready and gives you the link to read it there; it never receives report contents or referee answers. Every send is shown to you first and only goes out after you confirm.

Help: https://www.hiveref.com/integrations/ai-assistants
