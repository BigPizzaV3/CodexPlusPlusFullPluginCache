# Aikido MCP Setup

To install and configure the Aikido MCP, ask the model to run the **setup** skill. It configures your API key and verifies the MCP server. You can include your API key in your request for automatic configuration, or leave it out to be guided to get your key from https://app.aikido.dev → Settings → Integrations → IDE Plugins.

After setting the key, restart your session so the MCP server picks it up.

For manual steps, see: https://help.aikido.dev/mcp/anthropic-claude-code-mcp
