# Aikido Security — Codex Plugin

Brings [Aikido Security](https://aikido.dev) directly into Codex via the Aikido MCP server. Scan code you write or modify for vulnerabilities and secrets, request findings from your Aikido security feed.

## Installation and setup

Check out the [installation and setup guide](https://help.aikido.dev/ai-and-dev-tools/aikido-mcp/openai-codex-cli-mcp) for detailed guidance on how to set up the Aikido MCP server, or ask the model to run the **setup** skill after installing this plugin.
