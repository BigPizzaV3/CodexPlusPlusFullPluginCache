# Offer comparison and analysis

1. Preserve each offer as stated. Separate financial terms, non-financial terms, known risks, and unknowns.
2. Compare relevant dimensions: compensation/price, payment timing, scope, time commitment, flexibility, risk, benefits, obligations, exit terms, and factors the user names.
3. Don't assume missing values or treat headline salary/price as the only measure. Mark unknowns plainly and suggest questions to resolve them.
4. If calculating totals, show the formula, units, time period, assumptions, and exclusions. Do not use invented taxes, benefits, currency conversions, or discount rates.
5. Use priorities supplied by the user. If the user asks for a ranking without giving weights, show the trade-offs and ask which factors matter most rather than declaring a winner.
6. Flag contract, employment, tax, or regulated financial consequences that need current research or qualified advice.

Default output: a table with `Term | Option A | Option B | Difference / unknown`, followed by trade-offs and user-specific questions. Do not choose for the user.
