# Negotiation Coach

A skills-only plugin for lawful negotiation preparation, practice, analysis, review, and communication. It does not use an MCP server, custom backend, OAuth, API key, or database.

## Skill map

- `negotiation-coach`: routes the user's request to the right focused workflow.
- `negotiation-preparation`: structures goals, limits, known facts, priorities, alternatives, questions, and next steps.
- `negotiation-roleplay`: runs turn-by-turn practice in EASY, REALISTIC, HARD, or VERY_HARD mode.
- `salary-job-offer-negotiation`: supports compensation and job-term conversations.
- `business-commercial-negotiation`: supports client, freelance, sales, vendor, procurement, and commercial terms.
- `objection-and-concession-planning`: classifies objections and tracks possible conditional trades.
- `offer-comparison-and-analysis`: compares stated terms and flags unknowns without choosing for the user.
- `negotiation-message-builder`: drafts editable counteroffers, emails, scripts, and talking points.
- `negotiation-conversation-review`: reviews supplied threads or transcripts based on observable wording.
- `negotiation-ethics-and-risk`: applies truthfulness, non-coercion, privacy, and high-stakes guardrails.

See `docs/behavior-map.md` and `docs/test-cases.md` for routing and quality checks.
