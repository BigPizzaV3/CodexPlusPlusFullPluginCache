# 調査と出力の型

必要なモードだけ使う。入力が少なくても利用者を長い質問票で止めない。

## 初回入力

企業名・募集URLと応募区分がともに不明、または「まず基本情報を入れたい」という依頼には、下の短い入力欄を示す。区分だけ分かっている場合は企業名・募集URLだけを尋ねる。利用者は企業名だけでも始められる。

```text
応募区分（1つ選択）：新卒 / 中途 / インターン・仕事体験 / 未定
調べたい企業名または募集URL：
任意：希望職種・分野／卒業予定年（学生）または経験職種・年数（中途）／重視条件：
```

区分が書かれていなければ冒頭でその1点を聞く。対象企業があれば同時に共通部分を調べ、区分別の募集や適合は暫定扱いにする。区分が書かれていればフォームを繰り返さない。学生のインターンなら卒業予定年や対象学年を必要に応じて確認する。中途の職歴は概要で足り、履歴書の提出は求めない。

## 短い企業研究

1. 対象：正式社名、確認できた公式URL、利用者が示した応募区分・希望職種またはインターン分野、募集状況、調査日。未提示の基本情報は推測せず `未指定` とする。
2. 「応募前の見立て」：本人の優先軸に照らした魅力と注意点を各1～2点。優先軸が未提示なら仮の優先軸を明記する。
3. 根拠カード：`論点｜分かったこと｜区分（事実/企業の説明/第三者の声/推論/未確認）｜出典・資料日付`。重要なものだけ3～5行。
4. 募集要項との照合：求人なら仕事内容・スキル・勤務条件、インターンなら対象・締切・実施内容・期間・場所・選考・費用や報酬など、応募判断に効く差や空白。
5. 企業へ確認する質問：必要な場合だけ最大3問。それぞれ「何を確かめるためか」を添える。募集がなければ募集再開時の確認事項とする。
6. 次に必要な入力：最大2点。応募区分が未提示ならそれを優先する。ほかの例は求人URL、希望職種、重視条件。

## 深掘り

必要に応じて事業モデル、顧客・競合、セグメントと財務、戦略、組織・働き方、募集職種やインターンプログラムの位置づけを掘る。各論点を `会社の主張 → 別資料で確認できる根拠 → 応募者への意味 → 未確認点` の順に並べる。上場企業の決算値では対象期・単位・連結/単体を表に明示する。市場や競合の推定はその旨を記す。

## 複数社比較

同じ職種・応募時期、または同種のインターンを前提に比較する。利用者の優先条件を上位に置き、企業ごとに出典と資料日付を残す。公開量の差は `情報不足` と表示し、劣位の証拠にしない。希望条件が分からなければ勤務地・実施場所、仕事内容・実施内容、成長機会、待遇などの候補を示して優先順を聞く。点数化する場合は利用者指定の重み、観測値、未評価項目を公開する。

## 応募時に使う研究論点

`確認された事実 → 応募者との接点 → 確認すべき点` を分ける。本人の経歴が与えられていない場合は接点を作り話で埋めない。求人票の曖昧さや資料の食い違いは丁寧に確かめられる質問へ変える。ES本文や面接回答をこの研究シートから自動作成しない。

## 前回からの更新

前回の研究シートや出典が渡された場合は、今回確認した資料との差分を `新しく確認/変化なし/訂正/確認不可` で示す。古い資料を現在も有効だと決めつけず、調査日を更新する。前回資料がなければ新規分析として扱う。

## 参照先の目安

- [金融庁 EDINET](https://disclosure2.edinet-fsa.go.jp/)：法定開示。会社・年度・書類種別を確認する。
- [JPX 上場会社情報](https://www.jpx.co.jp/listing/co-search/)：上場の同定と開示資料への導線。
- [厚労省 しょくばらぼ](https://shokuba.mhlw.go.jp/)：掲載対象の職場情報。
- [厚労省 job tag](https://shigoto.mhlw.go.jp/User/about)：職種の一般的なタスクとスキル。対象企業の実態と混同しない。
- [国税庁 法人番号公表サイト](https://www.houjin-bangou.nta.go.jp/)：法人の同定。
- [文科省・厚労省・経産省のインターンシップに関する基本的考え方](https://www.mext.go.jp/a_menu/koutou/sangaku2/20220610-mxt_ope01_01.pdf)：大学等の学生向けの類型。個別募集の実態は企業要項で確認する。

上記は調査先の入口であり、個別企業の証拠としては実際に確認したページや書類へ直接リンクする。
