# 本人素材・デザインの登録と再利用

自己紹介・終了画面・プレゼント画像・参考動画を一度登録し、次回は本人の台本と合わせて再利用するための独立モード。台本マニュアル作成・更新とは別であり、素材だけの依頼で5000文字の見本台本や5つの質問を開始しない。

## 受け取りと本人照合

1. 読める「本人設定_最新版」の医師識別と版を取得する。今回の添付・採用済み完成物・登録済み設定を照合し、既に提供・採用された内容を聞き直さない。台本の著者名だけを根拠に画像の対象医師を決めない。
2. 素材の実ファイルを確認し、自己紹介、終了画面、プレゼント等の役割を判別する。ファイル名だけでは曖昧でも画像から判別できるなら進め、複数の医師・採用品の競合など結果が変わる場合だけ短く確認する。
3. [ひな形](../assets/media-profile-template.md) に、本人、役割、参照先、素材版、寸法・透過等の確認結果、使用条件を記録する。未提供の自己紹介・終了画面は未登録のままにし、他医師の見本や架空の経歴で埋めない。

ファイルは本人専用Project等で再参照できるようにする。外付けディスクや一時添付のパスだけが分かっていても、他のチャットから読めるとは限らない。設定文に名前が載ること、元のチャットで一度開けたこと、次のWebチャットから実画像を取得できたことを区別する。ユーザーへ再入力を求める前に既存の保存先を回復する。受講生にJSONやコマンドの入力を要求しない。

原寸の縦横比・透過を保つ。元比率の自己紹介やプレゼント画像を一律に正方形・16:9へ引き伸ばさない。配置用に余白を追加した派生物は原本と分ける。終了画面・プレゼントが未登録でも、本人が不要と指定したことにはならない。今回は使わないという本人の指定と、該当するCTAがないため適用外であることは、理由を別々に記録する。

## 終了画面と複数プレゼント

終了画面は「このまま使える完成画像」と「プレゼント等を配置する元テンプレート」を分ける。テンプレートには差し替える領域と残す要素を記録し、配置済み画像には使用したプレゼントIDを記録する。完成画像と作業指示文字のあるテンプレートを取り違えない。原本は保持し、今回の合成画像を別ファイルとして保存する。

プレゼントは正式名称、画像、適用主題、対象視聴者や除外条件、採用CTA、本人提供のURL・QR、優先条件を個別に記録する。未提供のURL・QRは作らない。素材に書かれたプレゼント名を別の題名へ変えない。

今回の採用品は「今回の明示指定→本人が登録した適用条件・優先条件→台本との適合に基づく推薦」の順で決める。同等の候補やCTAとの不一致が残る場合は勝手に確定せず、候補と不足だけ示す。採用品を案件の制作メモへ記録し、途中CTAと終了画面で同じものを使う。今回の選択で個人の一覧や全員の既定を上書きしない。

## 参考動画からデザインを記録

動画URLと可能なら参考区間、好きな点を本人の既存資料から拾う。これらがそろうことを作業開始の必須条件にせず、読める画像や採用済み完成物を先に使う。

実際に確認した動画区間・フレームから、配色、見出しと本文の文字、余白、線、イラスト、素材の表示位置、切り替えや動きを観察する。URL、確認日、時刻、観察フレームの参照を残す。静止フレームしか確認していないなら、動きや切り替えの特徴は未確認とする。画面からフォント名を特定できなければ「太いゴシック体相当」等の観察にとどめ、正確なフォント名として断定しない。

URLへアクセスできても映像を確認できない場合や、文字起こし・説明文だけが読めた場合は「視覚未確認」とする。未視聴なのに「この動画の配色を踏襲した」と説明しない。本人が述べた好みは本人指定として採用できるが、映像の観察とは分ける。確認できた既存画像があればそれを使い、なければ中立的な暫定デザインで独立して進められる部分を進める。見本が必要な範囲だけ、参考画像・短いクリップ等の提供を案内する。

他者の動画は構成・見せ方の参考とし、その人のロゴ・顔・経歴・素材ファイルを本人の成果物へ自動転用しない。実際の話者位置を確認していない場合は、左／右の配置を確定せず仮案と記録する。素材デザインの好みと医学的主張の根拠は分ける。

## 保存と制作への引き継ぎ

「本人素材・デザイン設定_最新版.md」を作り、「本人設定_最新版」に参照先・版・医師識別を追記する。素材原本、完成した派生画像、設定、今回の案件データを分ける。共有Pluginには空のひな形と手順だけを収録し、個人の画像、署名入りURL、氏名、案内先や個人の確定スタイルを追加しない。

直接保存できる接続先と書込機能がある場合は、依頼の範囲で本人専用の保存先へ保存し、設定と実ファイルを読み戻して確認する。できない場合は改訂ファイルを渡してProject登録の手順を案内し、「ファイル作成済み・Project登録待ち」とする。次回の読み取り確認が済む前に、全チャットで自動的に覚えるとは約束しない。

editor-handoffへ、対象医師、本人設定版、この素材設定の版、採用候補素材の実参照、今回の環境から読み戻した結果、今回の明示指定、デザインの観察状態を渡す。未提供・参照不能は区別して不足として扱い、制作可能な素材まで止めない。本人が登録した画像を読めないからといって、AI作成の文字カードや話者映像への代替を勝手に決定しない。撮影動画がなくても台本の発話を起点に配置でき、撮影映像を受け取ったときに話者・字幕との位置を確認する。生成動画の利用条件や機能がそろわなければ、その選択肢を完成MP4として数えない。

恒常的な好みとしての採用が明示された変更は本人設定へ反映し、今回限りの色や配置は案件だけへ記録する。本人設定更新で過去の納品ZIPを一括変更せず、新案件または指定された案件から適用する。
