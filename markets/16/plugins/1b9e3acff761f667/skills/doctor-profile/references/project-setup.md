# ProjectからDr.SHI-GYOを使い続けるための初回設定

初回導入、本人設定登録、Project指示の作成・見直しでは、この手順を使う。「毎回プラグインを指定しなくてよいようにしたい」という相談も対象。方法論の全文をProjectへコピーさせず、プラグインを使う方針と本人資料の参照先を登録する。

## 初回に必ず提案する短い指示

初回案内で、次の文をそのままコピーできるコードブロックとして出す。「必要なら後で設定できます」とだけ言って省略しない。既存指示があれば内容を読み、本人の文体・素材設定などを保持して統合する。同じ指定が既にあれば重複追加しない。

```text
このProject内の情報発信に関する作業では、必ずDr.SHI-GYOプラグインの該当スキルを使ってください。各チャットで私がプラグイン名やスキル名を指定しなくても、依頼内容に合うスキルを確認して進めてください。
利用できない場合は、その旨を伝え、プラグインを選択する方法を案内してください。使っていないのに使ったと報告しないでください。
登録済みの本人設定・独自スキル・台本マニュアル・見本・素材設定は、同じ本人・今回の分野について実際に読める最新版を参照してください。未登録なら今回の会話から始め、登録済みなのに読めない場合だけ参照先を確認してください。
台本・動画素材・サムネイルの修正後は、完成見本の登録と、修正を反映した独自スキルの登録・更新を別々に提案してください。私が選んだ側を実行し、Projectへ保存・読み戻しできた場合だけ登録済みと報告してください。直接保存できなければ、追加するMarkdown実ファイルと最小限の手順を渡してください。
```

本人用の詳細な指示も求められたら [Project指示全文](../assets/project-instructions.md) を使う。そこにも必須使用の段落を残す。本人用マニュアルだけを別ファイルで更新する依頼では、そのファイルへ無関係な設定を大量に挿入しない。Project指示の作成・再出力時に利用方針が欠けないようにする。

## 保存と次のチャットでの確認

1. 初めて使う時は、導入済みのDr.SHI-GYOを選んだProject内のチャットから案内する。Project作成だけでインストールや選択が済むとは説明しない。
2. 利用者のProjectの「…」→「プロジェクト設定」→「指示」へ文を追加し、保存する手順を案内する。画面の表記が異なる時は実際の画面に合わせる。書込機能と依頼範囲がある場合は保存・読み戻しまで実行し、できなければコピー文を渡して「保存待ち」とする。
3. 同じProjectで新しいチャットを開き、毎回の手動選択をせずに、例えば「インタビューして」と送って確認する。テーマ不明ならテーマだけ一問を返す。利用可能なプラグインの該当スキルを実際に読み、その手順で進められたかを確認する。AIが「使用しました」と自己申告しただけで起動確認済みとしない。
4. スキルが利用できない、選択を求められる、方法論を参照できない場合だけ、そのチャットでDr.SHI-GYOを選択して同じ依頼を続ける。指示文を再登録したり、本人設定を入力し直したりする前に、利用できるかを確かめる。

Project指示は、以後の依頼でプラグインを使うための利用方針。未導入・無効化されたプラグインの導入、機能追加、すべてのモデルやLiveでの自動起動を保証するものではない。確認のためだけに長い説明を毎回出したり、毎回の手動指定を必須に戻したりしない。無関係な依頼にはこのプラグインを強制しない。

## 制作開始の邪魔をしない

直接「インタビューして」「素材を作って」等と頼まれた時は、担当スキルへすぐ進む。指示・本人設定・情報源が空でも開始できる。初回インタビューの最初の一問や「はいだけ」の開始待機に、この設定案内を割り込ませない。使い方・設定を尋ねられた時、または作業の区切りに案内する。本人が今回プラグインを使わないと明示した範囲では、その指定を優先する。
