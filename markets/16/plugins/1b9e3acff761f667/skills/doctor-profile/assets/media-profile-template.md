## 素材デザイン

各項目へ、本人の指定／参考資料での観察／暫定案の区別と参照IDを添える。

- 配色：背景、文字、アクセント、強調色。色コードは取得できた場合のみ。
- タイポグラフィ：読みやすさ、太さ、見出しと本文の差、文字量。フォント名は確認できた場合のみ。
- 余白・装飾：安全余白、枠、線、影、図形。
- イラスト：写実度、線、人物表現、背景、継続して使う本人提供キャラクター。
- 主な配置：正方形インサート／16:9全画面静止画／16:9全画面動画。話者・字幕の領域と、確認した撮影画面の参照。
- 生成動画：使用する場面、使わない場面、動きの程度、目安尺、音声の扱い、利用できる生成機能と本人が明示した利用条件。
