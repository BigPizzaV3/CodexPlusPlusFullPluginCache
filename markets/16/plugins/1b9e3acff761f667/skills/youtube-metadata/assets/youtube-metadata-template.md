状態：完成版／完成動画との照合待ち

## 1. 複合キーワード

（指定語、または動画内容に基づく2語の組合せを1つ。検索量の実測値とは別。）

## 2. タイトル

（動画内の内容に合うタイトル1案。キーワードを自然に前半へ含める。）

## 3. 概要欄

（本文だけで300〜500文字。タイトルや章、追加リンクは文字数に含めない。材料が短い・不足する場合は水増しせず短い暫定案を作り、確認メモに実測文字数と標準字数未達を記す。）

## 4. チャプター

（最終動画の時刻が確認できる場合のみ「確認済み時刻 見出し」の行を並べる。時刻を確認できない場合は「時刻なし章見出し案」として見出しだけを並べる。）
