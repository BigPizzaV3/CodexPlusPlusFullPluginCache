# YouTube公開用タイトル・概要欄・チャプター

音声・動画ファイルの発話が未取得なら、[添付音声の自動読み取り](../voice-script/references/audio-runtime.md)で `ingest_audio.py` を実行する。必要な処理環境の準備も行い、文字起こしの提出を最初から求めない。取得後はこのSkillの依頼を続け、動画台本の3段階フローへ自動的に切り替えない。

完成動画の実内容に合う、YouTube Studioへ貼り付けやすい公開用テキストを作る。GEM「YouTube動画からSEO対策」の4項目を継承する。検索順位や再生回数を保証せず、未確認の検索量や動画内容を作らない。

## 入力と取得範囲

動画URL・動画ファイル・時刻つき文字起こしのいずれかと、任意のターゲットキーワード（最大3語程度）を受け取る。読める既存資料は再提出させない。今回使う資料が最終編集後の動画と対応するか確認し、取得できた範囲に応じて進める。

| 取得できた内容 | できること |
| --- | --- |
| 完成動画の発話・内容と切替時刻を確認できた | 4項目を完成版として作成。チャプターを動画内の実時刻と照合する |
| 最終動画に対応する時刻つき文字起こしがある | 発話に基づく4項目。映像を見たとは言わず、字幕の時刻を根拠にする |
| 台本・時刻なし文字起こしだけ | キーワード・タイトル・概要欄の案と、**時刻なしの章見出し案**。完成動画との照合待ちと短く明記する |
| URL・タイトル等だけで内容を取得できない | 内容を見たふりで作成せず、文字起こしまたは読める動画ファイルを求める |

動画を開けたことと、音声・字幕・フレーム・時刻を取得できたことは別に扱う。文字数、推定話速、総再生時間からチャプター時刻を捏造しない。未編集の録画の時刻は、カット後の動画へ流用しない。

## 作成の流れ

1. **内容と時間軸を確認する。** 主題・対象者・動画内で言える範囲と章の切替を整理する。時刻が確認できる場合は冒頭0〜30秒を最重視し、30秒〜3分を次に重視して、動画全体で扱っている主題と突き合わせる。これはGEM由来の編集方針であり、YouTube公式のアルゴリズム規則として説明しない。時刻がない台本では「冒頭段落」を見るだけにし、秒数を推定しない。
2. **複合キーワードを決める。** 指定語があれば軸として使う。未指定なら動画内容と視聴者が探しそうな言葉から2語の組合せを1つ選ぶ。指定語が動画で扱われない場合は不一致を短く示し、内容に合う代案を出す。実測データがないのに「検索量最大」「月間○件」などと断定しない。28日分析の検索語データがある場合も、そのチャンネルへの流入実績と市場全体の検索量を区別する。
3. **タイトルを1案作る。** 選定語の意味を前半へ自然に入れる。「脂肪肝 食事」のような単語列を貼るのではなく「脂肪肝の食事法」のような文章にする。期待させる内容が動画内にあり、医学的な効果・原因・対象範囲を元動画より強めていないことを確認する。
4. **概要欄本文を300〜500文字にする。** 視聴者が得られること、扱う話題、今回の限界や対象を必要に応じて自然に述べる。キーワードの羅列や不自然な反復を避ける。文字数は概要欄本文だけを対象にし、見出し・チャプター・追加リンク・文字数表示を含めない。文字数を確認できる環境なら実測して調整する。動画・本人設定にない経歴、症例、体験談、参考文献、配布先URLを追加しない。
5. **チャプターを作る。** 実際に話題が切り替わる時刻とその内容を対応させ、時刻順・重複なし・動画の範囲内で出す。キーワードは章内容に合う自然な語として含め、すべての章へ同じ単語を押し込まない。時刻がないときは見出し案のみとする。途中までしか読めない場合は完全なチャプター表とは称さない。

提供内容が短すぎる・一部しか読めない場合、300文字へ届かせるために同じ説明を繰り返したり未収録の情報を足したりしない。忠実な短い概要欄を暫定案として出し、実際の文字数と標準の300〜500文字に未達であることを短く明示する。添付ファイルがある場合は自動処理の結果・取得範囲を先に確認し、それでも不足する場合だけ残りの資料を求め、読めた材料で作れるタイトル・章見出し等は先に返す。短い動画に合わせた分量変更の明示指定は優先する。

## 納品形式

[出力ひな形](assets/youtube-metadata-template.md) に沿い、次の4項目だけを基本にして、コピーしやすい独立したブロックで返す。

1. 選定した複合キーワード
2. タイトル：**1案**
3. 概要欄：**本文300〜500文字**。材料不足の場合は上記の短い暫定案と実測文字数。
4. チャプター：確認済み時刻つき／時刻なし章見出し案のどちらか

参照できた資料や未確認事項の説明は必要なものだけ短く、コピーブロックの外へ置く。時刻や内容の不足を隠すために「余計な解説不要」を使わない。概要欄末尾への既存CTA・リンク追加を依頼されたら本文と追加欄を分ける。採用されていないリンクを創作しない。

仕上げに、タイトルと概要欄が動画の内容を超えていないか、引用されていない数字や医学的因果を追加していないか、キーワードが自然か、概要欄の長さ、時刻の根拠と順序を確認する。論文の厳密な再評価は本Skillの主目的ではない。明らかな不整合は保留して短く伝え、根拠調査を依頼された場合にmedical-evidenceへ渡す。

台本自体の改稿はscript-improvementへ、動画素材制作はeditor-handoffへ、記事化はarticle-adaptationへ引き継ぐ。公開設定の生成だけでこれらを勝手に開始しない。ユーザーから公開操作の依頼がない限り、このSkillではYouTubeへ投稿・設定変更を行わない。
