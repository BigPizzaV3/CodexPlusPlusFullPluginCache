# 12 一本の動画企画を決める

テーマはあるけれど、誰のどんな悩みに答える動画にするかを絞りたいときに使います。まだ台本を書く前の、一本分の設計図を作ります。

## 始める前に

本人専用のProjectでDr.SHI-GYOを使います。スキル名を覚える必要はありません。下の例文の［ ］だけを自分の内容へ変えて送ってください。

## 用意するもの

- テーマ、届けたい相手、伝えたいこと。決まっているものだけで構いません。
- 本人の専門分野・経験。本人設定が登録済みなら、同じ情報の再入力は不要です。
- あれば過去の動画、参考動画URL、YouTube分析の次企画候補。分析データは必須ではありません。

## 最初に送る例文

```text
Dr.SHI-GYOで動画の企画を作りたいです。テーマは「［テーマ］」、届けたいのは［対象者］です。視聴者が見終わったときに分かることを明確にして、切り口の違う3案を出してください。私の本人設定も使ってください。まず企画までお願いします。
```

## 進め方

1. 候補3案と推奨理由を読み、自分の経験で話せる案を選びます。すでに一本を決めている場合は、その案の具体化から始められます。

2. タイトル、冒頭の問い、動画で伝える答え、章の順番、サムネイルの方向を確認します。

3. 自分の考えが違う箇所は言葉で補います。論文確認が必要な主張は、未確認のまま言い切らず調査項目に残します。

4. 確定した企画を同じチャットで台本制作へ渡します。自由に話したいなら04、調査から書きたいなら13、資料が中心なら14へ進みます。

## 出てくるもの

- 一本分の企画メモ。タイトル、冒頭の問い、核心、章順、サムネイル方向、必要な本人素材・調査項目。
- 未確定なら比較できる企画候補。再生数の予測を保証するものではありません。

## 修正・別モードの頼み方

```text
2案目を採用します。ただし視聴者は［対象］へ絞り、私が伝えたい［考え］を中心にしてください。見終わった人が何を判断できるかも書き直してください。
```

## 完成前に確認すること

- タイトルと本編で答える問いが一致している。
- 自分が話せる経験と、まだ調べるべき事実が区別されている。
- 一本の動画として話題が広がりすぎていない。

## うまく進まないとき

企画が一般的すぎる場合は「患者さんによく聞かれる質問」「自分が意外に感じたこと」を一つ加えてください。参考URLが開けないときは、必要なタイトルや内容を貼れば続けられます。

## 次回にも生かす

採用企画を案件のメモとして残します。今後すべての動画に共通する方針だけ、06の方法で本人設定へ反映します。

詳しくは「06 自分専用の作り方を育てる」を参照してください。ファイル作成とProject登録は別です。保存先で読み戻せた場合だけ、登録済みとして扱います。

明示的に選ぶときのスキル名：`video-planning`。迷ったら、作りたい成果物を普通の言葉で伝えてください。
