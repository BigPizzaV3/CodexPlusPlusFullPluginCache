07｜自分らしいプロフィールを作る

受講生向けガイド · 2026年11月4日 · 1.1.5対応版

PDFを開くMarkdownを保存

経歴に加えて、「なぜ自分が発信するのか」が伝わる自己紹介を作ります。 ChatGPTの質問に答えると、長文・中長文・短文の3種類に整えてくれます。最初から上手な文章を用意する必要はありません。

この機能は、読者に見せる自己紹介文を作るものです。完成した文を今後も使えるようにするには、最後に自分専用のプロジェクトへ保存します。

できあがるもの

形式主な使い道伝える内容
A：長文ブログの自己紹介・紹介ページ歩み、考えが生まれた理由、発信への思い
B：中長文YouTube概要欄・SNSの固定投稿誰に何を届けるか、経歴、活動内容
C：短文SNSのプロフィール欄肩書き、届ける価値、自分らしい姿勢

1種類だけ欲しいときは、「今回は短文だけ」と伝えても構いません。

1｜自分のプロジェクトで始める

Dr.SHI-GYOを使えるチャットを、自分専用のプロジェクトで開きます。すでに本人設定が登録されていれば、それを使ってもらいます。

用意できる範囲で、以前の自己紹介、経歴書、過去投稿などを添付します。何も用意できなくても、質問に答えるところから始められます。

次の文章をそのまま送ってください。

コピーして使う
私らしい公開プロフィールを作ってください。
プロジェクトの本人設定や、添付した資料があれば先に読んでください。
足りない情報は、一問ずつ質問して引き出してください。
最後に、長文・中長文・短文の3種類を作ってください。

使いたい場所：［ブログ／YouTube概要欄／SNSなど］
届けたい相手：［分かる範囲で記入。未定でも大丈夫］

うまく機能が選ばれない場合は、「自分らしい公開プロフィールのスキルを使って」と付け加えます。スキルの内部名は public-profile です。

2｜基本情報を伝える

最初に、職業や活動、経歴、発信テーマ、届けたい相手、必ず入れたい要素を整理します。すでに登録してある情報を、最初から全部入力し直す必要はありません。

文章でも、音声入力でも構いません。経歴の箇条書きしかなくても進められます。名前や肩書きの正式表記、数字を使う実績は、分かる範囲で正確に伝えましょう。

公開したくないことがあれば、先に「これは背景を理解するためだけに話します。プロフィールには載せないで」と伝えます。

3｜質問に、自分の言葉で答える

ChatGPTは、現在の立場、これまでの歩み、感じたこと、大切にする価値観、普段の小さな場面を尋ねます。一度に全部答えるのではなく、会話を進めます。

大きな成功や劇的な失敗がなくても大丈夫です。「説明するときに、この言葉は使わない」「この疑問に答えたい」のような小さなこだわりも材料になります。体験談がなければ、今の考えを伝えてください。

会話の例

以下は使い方を示す架空の入力例です。自分の経歴や体験として、そのままコピーするための文章ではありません。

利用者：「私は内科医で、忙しい方にも理解しやすい健康情報を届けたいです。難しい言葉を減らしたいと思っています。」 ChatGPT：「その方が発信を見たあと、どんなことができるようになったら嬉しいですか？」 利用者：「自分が次に何を確認すればいいか、分かるようになってほしいです。」

この回答から「健康について、次に何を確認すればよいかを分かりやすく伝えます」という姿勢を文章にできます。話していない患者さんとの会話や診療実績を足す必要はありません。

4｜3種類を読み、自分らしく直す

返ってきた文章は、声に出して読むと違和感が見つかりやすくなります。次の3点を確認してください。

  • 経歴・資格・実績は正しいか。
  • 自分が言いそうな言葉になっているか。
  • 読んだ相手に、何を届ける人かが伝わるか。

直すときは、「もっとよくして」よりも、気になる箇所と理由を伝えると早く進みます。

コピーして使う
Bのプロフィールを直してください。
「人生を変える」という表現は大きすぎます。
私は「次の一歩を自分で考えられるように伝える」と言いたいです。
この部分を直し、AとCにも同じ考えを反映してください。
経歴や実績は変えないでください。

「少し短く」「資格を最初に」「趣味は外す」「もっと普段の話し方で」でも伝わります。

5｜採用した文章を保存する

使いたい文が決まったら、次のように頼みます。

コピーして使う
このプロフィールを採用します。
公開プロフィール_最新版.md にまとめ、本人設定から参照できる形にしてください。
版と更新日を入れ、公開文と、非公開の管理メモを分けてください。
実際に保存できた場所と、私がプロジェクトへ追加するファイルを教えてください。

ファイルができたら、自分のプロジェクトへ追加します。直接登録・読み戻しまでできたとChatGPTが確認した場合を除き、「ファイル作成済み」は「プロジェクトへの登録済み」と同じではありません。 保存の詳しい手順は「06｜自分専用の作り方を育てる」を参照してください。

外部のSNS欄などへ貼り付けるときは、A・B・Cの公開する文章だけを使います。管理メモや非公開情報は貼り付けません。

次回は、こう頼めます

コピーして使う
プロジェクトの公開プロフィール最新版を読んでください。
今回は、YouTube概要欄に入れる自己紹介を短く整えてください。
経歴は変えず、今回のテーマとのつながりを一言添えてください。

経歴や発信方針が変わったときも、「この部分を更新して」と頼み、最新版を差し替えて育てていきます。

困ったとき

状況伝え方
質問が多くて疲れた「今ある内容だけで、いったん3種類の仮案を作って」
どこかで見たような文章になった「この部分は抽象的です。自分の言葉を引き出す質問を一つください」
話していない経験が入った「この経験はしていません。削除し、私が話した事実だけで組み直して」
新しいチャットで設定が伝わらない「保存した本人設定と公開プロフィールを読めるか確認して」。読めなければ最新版ファイルを添付
発信テーマから決まらない「08｜発信の軸を決める」で、誰に何を届けたいかを先に整理

プロフィールがまとまったら、「3回喋る」で台本を作る、SNSへ展開する、出版企画を考える際にも使えます。文章を毎回そのまま入れるより、対象者と大切にする姿勢を引き継ぐことが、自分らしい発信につながります。
