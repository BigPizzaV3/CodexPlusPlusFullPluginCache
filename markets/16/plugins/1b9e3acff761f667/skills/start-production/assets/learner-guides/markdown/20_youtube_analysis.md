# 20 YouTubeを28日ごとに分析する

YouTube Studioから取り出した数値を使い、次の28日間に何を作り、何を変え、何を確認するかを決めます。プラグインを入れただけで自動取得が始まるわけではありません。

## 始める前に

本人専用のProjectでDr.SHI-GYOを使います。スキル名を覚える必要はありません。下の例文の［ ］だけを自分の内容へ変えて送ってください。

## 用意するもの

- 同じ28日間の動画別、流入元別、検索語別、関連動画の流入元動画別の基本4表。CSVかExcelで渡せます。
- あれば視聴者・維持率・終了画面・再生リスト等の画面画像。表示期間は分かるようにします。
- チャンネルURLと目標、前回の分析・次月引継ぎメモ。ない項目は空欄のままで進められます。

## 最初に送る例文

```text
Dr.SHI-GYOでYouTubeの直近28日を分析したいです。初めてなので、まずスクリーンショット付きのデータ取り出しガイドをください。基本4表の準備から案内してください。
```

## 進め方

1. AIが返す入力ガイドを開き、同じ期間の基本4表を取り出します。表に余分な列があっても削除せず渡せます。

2. ファイルを添付し「この期間を分析して」と送ります。足りない項目がある場合も、読めた範囲の分析から進みます。

3. HTMLレポートを開き、冒頭の優先行動、参考チャンネル・動画、次企画、流入・反応・登録の状況を見ます。

4. 自分が実行する変更を決めます。次月は今回の引継ぎメモと、新しい28日分の資料を渡して振り返ります。

## 出てくるもの

- 全内容を読める日本語HTMLレポートと、次月へ渡すメモの2ファイル。PDF希望も指定できます。
- 参考動画の直接リンク、次企画、どの動画のどこを変えるか、次に確認する数字。

## 修正・別モードの頼み方

```text
提案のうち今月は［変更］を実行します。どの動画のどこを変えるのか、来月どの数字を見るのかを具体化し、次月引継ぎメモへ記録してください。
```

## 完成前に確認すること

- 分析期間と対象チャンネルが正しい。
- 事実、推測、次に試す変更を区別できる。
- 自分の次の行動と、翌月の確認項目が分かる。

## うまく進まないとき

資料が一部だけでも分析はできますが、ない数値は作れません。画面画像の7日間の指標を28日間の実績へ混ぜないよう、期間を確認します。他チャンネルの非公開指標も推測で補いません。

## 次回にも生かす

レポートと引継ぎメモをProjectに残します。次の一本を作るときは、採用企画だけを12へ渡せます。

詳しくは「06 自分専用の作り方を育てる」を参照してください。ファイル作成とProject登録は別です。保存先で読み戻せた場合だけ、登録済みとして扱います。

明示的に選ぶときのスキル名：`youtube-28day-report`。迷ったら、作りたい成果物を普通の言葉で伝えてください。
