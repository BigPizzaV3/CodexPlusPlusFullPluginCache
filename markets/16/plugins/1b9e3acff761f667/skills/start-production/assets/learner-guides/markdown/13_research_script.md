# 13 テーマから調べて台本を作る

テーマと方向性を決めてから、医学論文を調べて台本を作ります。「3回喋る」以外の、文章入力を中心に始める基本ルートです。

## 始める前に

本人専用のProjectでDr.SHI-GYOを使います。スキル名を覚える必要はありません。下の例文の［ ］だけを自分の内容へ変えて送ってください。

## 用意するもの

- 動画タイトル、サムネイルに出したい文字、台本の最低文字数。仮の案でも構いません。
- そのタイトルを見た視聴者へ、何を伝えたいかという方向性。
- 本人の考え・経験、参考資料。自分で仕上げた見本台本があれば1〜5本程度、本人専用Projectへ入れます。

## 最初に送る例文

```text
Dr.SHI-GYOの動画台本ゼロイチで作ってください。タイトル：［タイトル］。サムネイル文字：［文字］。最低文字数：［文字数］。方向性：［伝えたいこと］。医学知識のない視聴者向けに、私の見本台本と本人設定が登録済みなら使ってください。なければ今回の入力から進めてください。
```

## 進め方

1. 不足している必須条件があれば答えます。「お任せ」の標準は最低5000文字、「長尺」は最低10000文字です。尺と文字数の希望があるときは明示してください。

2. AIが示す方向性への助言を読み、残す・変えるを伝えます。固まっているなら「この方向性で作成してください」と送ります。

3. 医学文献の調査後、初心者への分かりやすさ・本人の文体・簡単な事実照合のレビューを経て台本が出ます。委任機能が使えない環境では、未実施の表示を確認します。

4. HTMLを開いて声に出して読み、話しにくい箇所を音声か文章で直します。修正は15、話す3段階の進め方は04を参照してください。

## 出てくるもの

- 台本全文と出典を収めたHTML。ダイジェストから本編へ移動でき、抜き出し元が太赤字で分かります。
- 医学文献の簡潔な一覧と詳しいまとめ。Markdownなど形式の希望も指定できます。

## 修正・別モードの頼み方

```text
「［該当文］」が私の言い方ではありません。私は［実際の言い方・考え］と話します。同じ構文が続く箇所も全文で見直して、根拠と意味を変えずに修正してください。
```

## 完成前に確認すること

- タイトルで約束した問いに、本編が具体的に答えている。
- 自分が言っていない経験や感情が加わっていない。
- 数字と出典、ダイジェストと本編の内容が対応している。

## うまく進まないとき

元資料が読めない、中心となる根拠が確認できない場合は草稿になります。文献名や数字を補って完成扱いにせず、確認できた部分と不足を見ます。画像・動画素材は台本制作後に05で依頼します。

## 次回にも生かす

完成稿と修正前の稿を残し、繰り返し使いたい話し方を06の方法で更新します。一回の台本修正だけでは本人用ルールの保存まで済んだとは限りません。

修正が仕上がった後は、完成版を見本にするか、今後の作り方を独自スキルへ反映するか、別々に確認します。「両方はい」「見本だけ」「独自スキルだけ」「今回は不要」で答えられます。

詳しくは「06 自分専用の作り方を育てる」を参照してください。ファイル作成とProject登録は別です。保存先で読み戻せた場合だけ、登録済みとして扱います。

明示的に選ぶときのスキル名：`research-script`。迷ったら、作りたい成果物を普通の言葉で伝えてください。
