# 22 挿入画像10枚・SNSの9マス画像

点数と形式を決めて画像を作る2つの使い方です。「動画用の独立した正方形10枚」と「SNS用の正方形1枚の中に9マス」を使い分けます。

## 始める前に

本人専用のProjectでDr.SHI-GYOを使います。スキル名を覚える必要はありません。下の例文の［ ］だけを自分の内容へ変えて送ってください。

## 用意するもの

- 動画用なら完成台本、SNS用なら元の記事または台本。
- 本人の画風・色の希望、アクセントに使いたい本人画像。指定がなくても進められます。

## 最初に送る例文

```text
この台本から、動画に挿入する正方形の画像を10点作ってください。10枚はそれぞれ独立した画像ファイルにしてください。挿入箇所の短い引用と画像の狙いも示してください。
```

## 進め方

1. 動画用では、台本の10箇所と画像の狙いが示され、独立した画像の生成へ進みます。10枚を一つのコラージュにはしません。

2. SNS用なら下の別プロンプトを使います。9枚の別ファイルではなく、1枚の中に3列×3行を作ります。

3. 出来上がった画像を開き、文字の誤り、身体構造、数字、意味の変化を確認します。

4. 「4番だけ文字を減らして」のように修正箇所を指定します。台本へ配置した編集者用一式が欲しいときは05へ進みます。

## 出てくるもの

- 動画用：1:1の独立画像10ファイルと対応する挿入箇所。
- SNS用：1:1の画像1ファイル、均等な3×3の9マス。9番は引用文献専用です。

## 修正・別モードの頼み方

```text
この文章をSNS用に、正方形1枚の中に均等な3×3・9マスの画像としてまとめてください。1〜8に内容、9には引用文献だけを置いてください。独立した9枚にはしないでください。
```

## 完成前に確認すること

- 10枚なのか、9マス入りの1枚なのかが依頼どおり。
- 文字が読め、医学的な関係を誤解させる図になっていない。
- 出典がない場合に架空の論文が追加されていない。

## うまく進まないとき

生成上限やエラーで途中停止したら、完成枚数と残りを確認して再開します。プロンプトの一覧だけでは実画像の完成ではありません。解剖の正確さが必要な部分は医師本人が確認してください。

## 次回にも生かす

実画像と、どの台本の版から作ったかを保存します。元の数値や説明を変えた場合は、対応する画像も更新します。

修正が仕上がった後は、完成版を見本にするか、今後の作り方を独自スキルへ反映するか、別々に確認します。「両方はい」「見本だけ」「独自スキルだけ」「今回は不要」で答えられます。

詳しくは「06 自分専用の作り方を育てる」を参照してください。ファイル作成とProject登録は別です。保存先で読み戻せた場合だけ、登録済みとして扱います。

明示的に選ぶときのスキル名：`visual-materials`。迷ったら、作りたい成果物を普通の言葉で伝えてください。
