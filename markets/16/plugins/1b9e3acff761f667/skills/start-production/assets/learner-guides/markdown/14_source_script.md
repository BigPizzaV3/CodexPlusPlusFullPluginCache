# 14 論文・講義資料から台本を作る

論文PDF、講義資料、書籍原稿など、すでにある内容を主軸に動画台本へ変換します。資料の意味を保ちながら、視聴者に伝わる順番と表現へ整えます。

## 始める前に

本人専用のProjectでDr.SHI-GYOを使います。スキル名を覚える必要はありません。下の例文の［ ］だけを自分の内容へ変えて送ってください。

## 用意するもの

- 元になるPDF・原稿・資料、または読めるURL。複数あっても構いません。
- 誰に向け、どの部分を伝えたいか。全体解説なのか、特定のテーマの根拠として使うのか。
- 希望文字数、話し方、追加したい自分の経験。登録済みの本人情報は再利用できます。

## 最初に送る例文

```text
添付資料を主な根拠に、［対象者］向けの動画台本を作ってください。中心テーマは［テーマ］、目安は［文字数］です。資料の結論・条件・数値を保ち、専門用語を初心者向けに説明してください。台本全文のHTMLと、どの資料を使ったか分かる対応表をください。
```

## 進め方

1. AIが読めた資料名・版・範囲を確認します。図表に大事な情報がある場合は、そのページも確認対象に含めます。

2. 構成を確認します。資料の順に読むだけでなく、視聴者の疑問に答える順番へ変えられます。

3. 不足や矛盾のある箇所だけを補足調査し、台本を作ります。元資料の著者の体験を自分の体験に変えないことも確認します。

4. 完成稿を声に出し、難しい表現や残したい意図を伝えて直します。

## 出てくるもの

- 全文台本のHTML、元資料との対応表、実際に確認できた出典。
- 必要な未確認事項。資料を読めた範囲と、根拠を別途確認した範囲が分かります。

## 修正・別モードの頼み方

```text
第［番号］節は資料の説明に寄りすぎています。結論と条件は保って、患者さんが日常で感じる疑問から始まる順番にしてください。私の経験は［本人が述べた内容］だけを使ってください。
```

## 完成前に確認すること

- 元資料の対象者・条件・数値が変わっていない。
- 補足調査した内容と、元資料の内容を区別できる。
- 自分の意見・経験と、他の著者の説明が混ざっていない。

## うまく進まないとき

URLから本文を取得できない場合は、PDFか必要部分の本文を添付します。図表が小さく読めない場合は該当ページを追加します。題名だけから内容を作らせないでください。

## 次回にも生かす

元資料と完成稿の組を案件へ保存します。次回はその資料を毎回貼り直すのではなく、同じProjectの読める情報源として使います。

修正が仕上がった後は、完成版を見本にするか、今後の作り方を独自スキルへ反映するか、別々に確認します。「両方はい」「見本だけ」「独自スキルだけ」「今回は不要」で答えられます。

詳しくは「06 自分専用の作り方を育てる」を参照してください。ファイル作成とProject登録は別です。保存先で読み戻せた場合だけ、登録済みとして扱います。

明示的に選ぶときのスキル名：`source-script`。迷ったら、作りたい成果物を普通の言葉で伝えてください。
