# ⑨ 撮影環境と配色を、自分らしく整える

Dr.SHI-GYO｜撮影環境・ブランド配色（brand-color）

「背景がごちゃごちゃする」「毎回サムネイルの色が違う」「自分の専門分野に合う雰囲気にしたい」。そんなときに使う機能です。撮影画面とチャンネルの方向性を渡すと、基本の2色、背景や服の改善案、サムネイルや動画素材への使い方まで提案します。

**一度決めた色や見せ方は、自分専用のProjectの情報源に保存して、次回から使い回しましょう。**

## 全体の流れ

**① 撮影画面を1枚添付 → ② 目指す雰囲気を伝える → ③ 配色とセット改善を選ぶ → ④ 本人設定に保存 → ⑤ 次のサムネイルや素材へ使う**

## 最初に用意するもの

| 用意するもの | 何を渡せばよいか |
| --- | --- |
| 撮影環境の画像 | いつもの動画から切り出したスクリーンショット1枚。本人と背景が一緒に見えるもの |
| チャンネルの方向性 | 誰に、何を届けているか。1〜2文で十分 |
| 残したいもの | すでに使っているブランド色、背景、白衣、大切な小物など。あれば伝える |
| パーソナルカラー | 分かる人だけ。分からなくても進められる |

動画URLだけでは画面を確認できない場合があります。最初からスクリーンショットを1枚添付すると、背景や服の色まで相談しやすくなります。

## 1. 画像を添付して、この文を送る

Dr.SHI-GYOを利用できる、自分専用のProject内のチャットで始めます。スキル名を覚える必要はありません。

```text
私のYouTubeの撮影環境とブランド配色を相談したいです。
添付した画像は、現在の撮影画面です。

専門分野：［例：整形外科］
主な視聴者：［例：膝や腰に不安がある一般の方］
目指す印象：［例：親しみやすいけれど、落ち着いて信頼できる］
残したいもの：［例：白衣と、背景にある模型］
すでに決めている色：［なければ「なし」］
パーソナルカラー：［分からなければ「不明」］

基本の2色と、背景・小物・服・照明の改善案を出してください。
まずは手元のものを使って、簡単にできる変更を優先してください。
サムネイルや動画素材での使い方も教えてください。
```

［ ］の中を書き換えて送ります。本人設定にすでにある情報は「本人設定を参照して」で構いません。機能を明示したいときは「撮影環境・ブランド配色を使って」と加えます。

## 2. 結果は、ここを見る

返ってくる主な項目は次の6つです。

| 項目 | 見るポイント |
| --- | --- |
| 基本の2色 | 自分の雰囲気に合うか。ベース色と、目を引くアクセント色が示される |
| 現状との違い | 添付した画像のどこを見て判断したか |
| 足す・減らす・配置するもの | 家具を買わなくてもできそうか。残したい物が尊重されているか |
| 照明・背景の助言 | 顔や白衣が不自然な色にならないか |
| 素材への使い方 | サムネイル、アイコン、動画内の図解へどう使うか |
| 最初に試すこと | 優先順位の高い変更を最大3つに絞ってくれる |

「HEX」は色の番号です。たとえば `#2B5B70` のような文字列です。覚える必要はなく、次の制作時にそのまま渡せば大丈夫です。

## 3. 合わなければ、普通の言葉で直す

```text
少し硬い印象です。信頼感は残しつつ、もう少し温かい雰囲気にしてください。
白衣と今の背景は変えたくありません。
まずは小物の配置とアクセント色だけで改善してください。
```

別の例です。

```text
この2色は良いです。採用します。
ただし、サムネイルの文字が読みにくそうなので、
小さく表示しても読みやすい文字色と配置を提案してください。
```

撮影セットを変えたら、変更後の画像を添付し「前の案と比べて、どこをもう少し整えるとよいですか」と聞けます。

## 4. 採用した設定を保存する

```text
今回決めた配色と撮影環境のルールを、私専用の設定としてまとめてください。
採用したものと、まだ試していない案を分けてください。
「本人専用ブランド配色_最新版.md」にして、今後のサムネイルや動画素材へ引き継げるようにしてください。
```

作成されたファイルを、自分のProjectの情報源へ追加します。すでに配色のファイルがあれば、最新版が分かるように差し替えます。ChatGPTが直接保存・読み戻しをできた場合はその案内に従います。「ファイルを作りました」と「Projectへ登録できました」は別なので、登録されていることを確認しましょう。

次の制作では、次のように依頼します。

```text
Projectの「本人専用ブランド配色_最新版」を使って、今回のサムネイルを作ってください。
作り始める前に、使うベース色とアクセント色を短く教えてください。
```

## ここまでできれば完了

- 使いたい基本の2色と、その使い分けが決まった。
- 自分の撮影環境で、次に直す点が分かった。
- 採用した設定を本人専用の情報源へ残した。
- 別のチャットでも、その設定を読み取れることを確認した。

## 困ったとき

| 困りごと | こう伝える |
| --- | --- |
| 動画URLを渡したのに背景が分からないと言われた | 動画のスクリーンショットを1枚添付する |
| パーソナルカラーを知らない | 「不明です。チャンネルの方向性を中心に提案してください」 |
| 使っているブランド色が勝手に変わった | 「この色は固定です。残したまま整えてください」 |
| 買い替えの提案ばかり出る | 「購入なしで、配置・画角・服の変更に絞ってください」 |
| 保存したはずなのに次回反映されない | Projectの情報源に最新版があるか確認し、「このファイルを読んで」と指定する |

この機能が作るのは、配色と撮影環境の提案です。サムネイルや素材の実画像まで必要なら、採用後に「この配色で実際の画像を作って」と続けて依頼します。
