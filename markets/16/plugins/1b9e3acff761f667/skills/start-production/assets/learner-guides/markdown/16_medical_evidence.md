# 16 医学論文と根拠を調べる

「この主張はどこまで言えるか」を調べ、動画・記事に使える表現へ整理します。論文の一覧だけでなく、主張と根拠の対応が成果物です。

## 始める前に

本人専用のProjectでDr.SHI-GYOを使います。スキル名を覚える必要はありません。下の例文の［ ］だけを自分の内容へ変えて送ってください。

## 用意するもの

- 調べたいテーマ、確かめたい主張、または比較したい資料。
- 対象者、比較したい方法、知りたい結果。分かる範囲の短い説明で始められます。
- あれば論文PDF、DOI、PubMed等のURL。

## 最初に送る例文

```text
［主張］について、［対象者］向けの動画でどこまで言えるか調べてください。支持する研究だけでなく、結果を限定する研究も確認し、出典・読めた範囲・使える表現・まだ分からないことをまとめてください。台本の執筆はまだ不要です。
```

## 進め方

1. 何を調べるかを短い問いにします。医学用語で研究計画を書く必要はありません。

2. AIが検索して、本文・表・抄録など実際に読めた部分を確認します。検索結果に題名が出ただけの資料は別扱いです。

3. 結論、対象、限界、数字の意味、言える表現を見ます。観察された関連と、原因だと分かったことを区別します。

4. 動画に使う主張を選び、台本や記事制作へ引き継ぎます。

## 出てくるもの

- 主張ごとの結論・条件・出典・閲覧範囲を記した根拠メモ。
- 使える表現と、避けたい言い切り、追加確認が必要な項目。

## 修正・別モードの頼み方

```text
この結論を一般の人に話すときの一文にしてください。対象者と条件は落とさず、難しい研究用語は減らしてください。全文を読めた研究と抄録だけの研究も分けてください。
```

## 完成前に確認すること

- 重要な主張と出典が結び付いている。
- 研究対象や期間、相対値の基準が分かる。
- 未確認の資料を読了・検証済みにしていない。

## うまく進まないとき

検索できない環境では、提供PDFで分かる範囲と追加調査を分けます。「見つからなかった」だけで「研究が存在しない」と結論づけないでください。

## 次回にも生かす

根拠メモは案件の資料として保存します。本人の経験や感想の記録とは分け、更新するときはどの主張が変わったか残します。

詳しくは「06 自分専用の作り方を育てる」を参照してください。ファイル作成とProject登録は別です。保存先で読み戻せた場合だけ、登録済みとして扱います。

明示的に選ぶときのスキル名：`medical-evidence`。迷ったら、作りたい成果物を普通の言葉で伝えてください。
