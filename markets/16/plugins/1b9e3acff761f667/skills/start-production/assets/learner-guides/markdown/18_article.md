# 18 動画台本をブログ・記事にする

動画台本の内容と本人の語り口を残して、検索でも見つけてもらいやすい長文記事へまとめます。短いSNS投稿への一括展開とは別の機能です。

## 始める前に

本人専用のProjectでDr.SHI-GYOを使います。スキル名を覚える必要はありません。下の例文の［ ］だけを自分の内容へ変えて送ってください。

## 用意するもの

- 動画台本。標準は2〜3本ですが、「今回は1本で」と指定できます。
- メインとなるSEOキーワード。未定なら候補5個から選びます。
- 想定読者、掲載先、文体。本人設定にある内容は引き継ぎます。

## 最初に送る例文

```text
この［本数］本の台本を、語り口と本論を保ってブログ記事にしてください。メインSEOキーワードは［キーワード］、想定読者は［対象］です。具体例や医学的な出典を落とさず、読みやすい見出しとFAQも付けてください。
```

## 進め方

1. キーワードが未定の場合はAIの5候補から一つ選びます。選ぶまでは記事本文の作成へ進みません。

2. 複合キーワード10セットと、検索する人が知りたい質問10個、タイトル3案を確認します。

3. 台本を一本の記事に再構成します。本論・根拠・具体例を残し、重複する挨拶などを整理します。

4. 記事を読み、元の台本の大切な意図が残っているか確認します。掲載は別途行います。

## 出てくるもの

- タイトル候補、120〜160字のメタディスクリプション、長文記事、FAQ3〜7個、文献。
- 内部リンク・動画との連携案、必要な場合の構造化データ案など。本文は元台本合計の80％以上を目安とし、合理的な省略や指定文字数を優先します。

## 修正・別モードの頼み方

```text
記事が要約されすぎています。元台本の［具体例・説明］を戻してください。重複した挨拶だけを減らし、本人の解釈と文献への対応を保って再構成してください。
```

## 完成前に確認すること

- 元台本の主張、具体例、引用の対応が保たれている。
- 検索キーワードのためだけの不自然な文章になっていない。
- 施設・著者・日付などに未確認の情報が追加されていない。

## うまく進まないとき

検索量や順位の実データがない場合は見込みの提案になります。検索上位や引用表示を保証する機能ではありません。短いX投稿が欲しい場合は今回の専用機能とは分けて依頼してください。

## 次回にも生かす

採用キーワード、元台本の版、記事の最新版を一緒に残します。今後の文体にしたい修正は06へ渡します。

詳しくは「06 自分専用の作り方を育てる」を参照してください。ファイル作成とProject登録は別です。保存先で読み戻せた場合だけ、登録済みとして扱います。

明示的に選ぶときのスキル名：`article-adaptation`。迷ったら、作りたい成果物を普通の言葉で伝えてください。
