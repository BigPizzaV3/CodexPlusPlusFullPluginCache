# 17 自分のメソッドを根拠から整える

自分が伝えたい「負担の少ないやり方」を、根拠・対象・条件から見直します。名前を付けるだけでなく、判定と一般向けの記事まで作る流れです。

## 始める前に

本人専用のProjectでDr.SHI-GYOを使います。スキル名を覚える必要はありません。下の例文の［ ］だけを自分の内容へ変えて送ってください。

## 用意するもの

- 役割：自分の専門・立場。
- 変化：誰に、どんな変化を届けたいか。
- 通常の方法と、それに比べて負担を減らす提案。

## 最初に送る例文

```text
Dr.SHI-GYOでメソッドを検討してください。
【役割】［専門・立場］
【変化】［対象者と目指す変化］
【凡庸メソッド】［通常の方法と負担］
【楽々最強メソッド】［提案したい方法］
根拠を確認し、妥当な対象・条件・表現へ整えて、一般向けの記事までお願いします。
```

## 進め方

1. 4項目を渡します。入力の型が欲しければ「テンプレート」とだけ送ることもできます。

2. 効果、回数や期間、続けやすさ、安全性、向く人・向かない人を調べます。

3. 「かなり妥当」「一部修正すれば妥当」「根拠が弱い」の判定と理由を読みます。調査できていないことは、根拠が弱いという判断と区別されます。

4. 魅力を残しつつ方法と表現を直し、一般向けの記事と文献を仕上げます。

## 出てくるもの

- 判定、メソッドの再定義、一般向け記事、簡潔な文献一覧、詳細な文献情報の5部。
- 原則5〜12本を目安とする文献。ただし本数を満たすための無関係な出典は加えません。

## 修正・別モードの頼み方

```text
手順はもっと続けやすくしたいです。ただし根拠のない効果は加えず、最低限残す条件と、省いてよい負担を分けて提案してください。
```

## 完成前に確認すること

- メソッドの一部分の根拠を、全体の効果証明にしていない。
- 対象・条件・限界が記事に残っている。
- 名前の「最強」を医学的優越性の保証として使っていない。

## うまく進まないとき

思い入れのある方法でも、調べた結果に合わせて修正する前提で使います。本人の経験は大切な材料ですが、万人に同じ効果がある根拠とは分けます。

## 次回にも生かす

採用した手順と表現、出典を保存します。台本へ展開するときも、その条件と留保を引き継ぎます。

詳しくは「06 自分専用の作り方を育てる」を参照してください。ファイル作成とProject登録は別です。保存先で読み戻せた場合だけ、登録済みとして扱います。

明示的に選ぶときのスキル名：`method-design`。迷ったら、作りたい成果物を普通の言葉で伝えてください。
