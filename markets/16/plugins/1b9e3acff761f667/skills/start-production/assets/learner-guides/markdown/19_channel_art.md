# 19 チャンネルアートを設計する

YouTubeチャンネル上部に使う画像の、中央の重要領域を設計します。標準で出るのは画像生成用の英語プロンプト3案です。

## 始める前に

本人専用のProjectでDr.SHI-GYOを使います。スキル名を覚える必要はありません。下の例文の［ ］だけを自分の内容へ変えて送ってください。

## 用意するもの

- 正確に表示したいチャンネル名・文字。
- 本人を入れる場合は本人写真。色・雰囲気の参考画像があれば添付します。
- 参考デザインをどの程度取り入れたいか。未定なら、その旨を伝えて相談できます。

## 最初に送る例文

```text
チャンネルアートのコア画像用プロンプトを3案作ってください。表示文字は「［文字］」。本人写真は添付、配色は本人設定を使ってください。参考画像は色と雰囲気だけ取り入れ、文字・顔・手を枠内に収めてください。
```

## 進め方

1. 必要な文字や写真を渡します。画像を添付していない場合は、名前から本人の顔を推測して作ることはありません。

2. 安全で明快なA、コントラスト重視のB、活気を加えたCの英語プロンプトを受け取ります。

3. 実画像も欲しい場合は「B案で画像も生成して」と追加で頼みます。画像生成機能が利用できることが必要です。

4. フルサイズのバナーに配置する場合は別工程として頼み、実際のYouTube表示画面で切れ方を確認します。

## 出てくるもの

- Prompt A・B・Cの3本。設計の基準は1546×423のコア領域です。
- 実画像・フルバナーは追加依頼に応じて利用可能な機能で作成します。プロンプト完成と画像完成を区別します。

## 修正・別モードの頼み方

```text
B案の文字をもっと読みやすくして、人物の顔・頭・手はすべて内側に収めてください。表示文字は変えず、参考画像の構図はコピーしないでください。
```

## 完成前に確認すること

- 表示文字が正確で、顔や手が切れない。
- 標準の成果物がプロンプトなのか、追加制作した実画像なのか分かる。
- フルバナーを作った場合は実際の表示環境で確認した。

## うまく進まないとき

中央の設計寸法は引き継いだ仕様です。全端末での見え方を自動保証しません。最新の入稿条件と実画面で確認してください。

## 次回にも生かす

採用したプロンプト、写真、配色、完成画像を本人の素材設定へ残します。動画ごとのサムネイルは03で作ります。

詳しくは「06 自分専用の作り方を育てる」を参照してください。ファイル作成とProject登録は別です。保存先で読み戻せた場合だけ、登録済みとして扱います。

明示的に選ぶときのスキル名：`channel-art`。迷ったら、作りたい成果物を普通の言葉で伝えてください。
