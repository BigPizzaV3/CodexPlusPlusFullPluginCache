TEMPLATES

使いながら育てる任意のひな形

初回の台本づくりには不要です。本人資料を残したくなったら、ご自身の内容へ書き換えて使います。

本人設定の入力ひな形 ↓名前・専門分野・視聴者・話し方などをまとめる。
Projectの指示欄へ貼る文章 ↓初回導入で保存する、プラグインの利用と本人資料の参照の案内。
本人素材の登録メモ ↓自己紹介・終了画面・プレゼント画像の用途を整理する。
TRY THE CONTROLS

素材の選択・修正を試す

台本の近くに素材が並ぶ実際の画面で、候補選択・修正メモ・依頼文の保存を練習できます。

操作練習用の短い台本と説明図です。AI生成イラスト・動画の完成品質を示す見本ではありません。
