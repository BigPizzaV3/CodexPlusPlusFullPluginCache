# 08｜発信の軸を決める

**「自分は何を発信する人か」を、6つの言葉と短い文章にまとめます。** 診療科や資格だけでなく、経験や考え、譲れないことを材料にして、発信の方向性を整理します。

検索されやすい単語を集める作業ではありません。YouTube、SNS、出版などで、**誰に何を届け、どんな姿勢を大切にするか**を決めるための対話です。

## できあがるもの

| 作るもの | 役割 |
| --- | --- |
| メインキーワード3つ | 専門性や届ける価値など、発信の柱 |
| ドライブキーワード3つ | 思い、こだわり、人柄を伝える言葉 |
| 過去・現在・未来の3行 | 自分の歩みとこれからの方向性 |
| 発信方針の短い文章 | 誰に何を届けるかを説明する文 |
| SNSで使う表現案 | YouTubeチャンネル名、冒頭の挨拶、X表示名、Xプロフィールを各5案 |

「ドライブキーワード」は、ここでは**人柄を伝える言葉**と考えてください。難しい理論を覚える必要はありません。

## 1｜まず、この一言から始める

Dr.SHI-GYOを使えるチャットを、自分専用のプロジェクトで開きます。次をコピーして送ってください。

```text
自分の発信の軸を決めたいです。
経験や得意分野、考えを引き出して、メインキーワード3つと、
人柄を伝えるドライブキーワード3つを一緒に選んでください。
プロジェクトの本人設定があれば読んで、足りないところだけ質問してください。
一度にすべて聞かず、順番に進めてください。
```

機能がうまく選ばれない場合は、「発信の軸を決める3＋3キーワードのスキルを使って」と添えます。内部名は `brand-keywords` です。

## 2｜自分について、まず20項目を出す

最初は質より量です。経歴、得意なこと、趣味、苦労したこと、よく考えること、違和感、今後やりたいことなどを、短い言葉で並べます。

整理しながら書くのが難しければ、**思いついたことを音声入力で喋る**のがおすすめです。ChatGPTに箇条書きへ整理してもらいます。もともと登録してある情報も材料にできます。

```text
20個を一度に考えるのは難しいので、一問ずつ聞いてください。
私の回答を短い項目に整理しながら、20個を目標に増やしてください。
```

すごい実績ばかりを集める必要はありません。「短く説明するのが好き」「この誤解を減らしたい」も材料です。話したくない私生活や失敗を、無理に入れる必要はありません。

途中で疲れたら「今ある材料でいったん仮案を作って」と伝えて構いません。あとから足して育てられます。

## 3｜発信の柱となる3つを選ぶ

ChatGPTが材料をもとに候補を出します。それを見て、自分の実態や続けたい方向に合うものを選びます。

見るポイントは3つです。

- 普通の人にも、どんな内容かが伝わるか。
- 自分が継続して話したい、または話せる内容か。
- 3つを組み合わせると、誰に何を届ける人かが見えるか。

「日本で自分しかいない」と証明する必要はありません。逆に、珍しさだけを優先して意味の伝わらない言葉にする必要もありません。

```text
案Bが近いです。ただ、「健康全般」だと広すぎます。
私が話した材料の中から、もう少し伝わりやすい言葉に絞って提案してください。
```

## 4｜自分の人柄を伝える3つを選ぶ

次は、同じテーマでも「自分はどんな姿勢で伝えるか」を考えます。大切にすること、避けたいこと、考えが変わった経験などを尋ねられたら、自分の言葉で答えます。

強い怒りや派手な言葉がなくても大丈夫です。穏やかさ、丁寧さ、小さく始める考え方なども、その人の特徴になります。

### 組合せの例

以下は、言葉の違いを理解するためだけの架空例です。ご自身の設定としてそのまま採用する必要はありません。

| 種類 | 例 |
| --- | --- |
| メイン3語 | 内科／忙しい人／健康情報の読み解き |
| 人柄3語 | 焦らず／自分で選ぶ／身近な言葉 |

メインの3語で「何を届けるか」、人柄の3語で「どう届けるか」が伝わります。言葉だけではしっくり来ない場合は、「この言葉が示す姿勢を短い文章にして」と頼むと確認しやすくなります。

## 5｜文章と名前の案を見て、実際に使うものを選ぶ

6つの言葉が固まると、過去・現在・未来の整理、発信方針文、SNSで使う表現案が返ってきます。

標準では、YouTubeチャンネル名・動画冒頭の挨拶・X表示名・Xプロフィールが各5案です。使う媒体が決まっている場合は「YouTube用だけ」「Xは今回は不要」と指定できます。

ここでも、**声に出して読む**のが役立ちます。言い慣れない言葉や、自分より大きく見せすぎる表現があれば直します。

```text
6つのキーワードはこれで採用します。
YouTubeの挨拶は3案目が近いですが、少し力が入りすぎています。
もっと普段の診療で話すような、落ち着いた言い方にしてください。
```

名前の候補が出ても、アカウントIDの空き確認やSNSへの変更は自動では行われません。まず文章の案として選びます。

## 6｜採用した軸を、自分のプロジェクトへ保存する

```text
この6キーワードと発信方針を、今後の制作にも使いたいです。
発信の軸_最新版.md にまとめ、本人設定から参照できるようにしてください。
採用した案と候補のままの案を分け、版・更新日を入れてください。
実際に保存できた場所と、私がプロジェクトに追加するファイルを教えてください。
```

受け取ったファイルを、自分のプロジェクトの情報源へ追加します。直接保存・読み戻しまでできたと確認された場合を除き、ファイルを作っただけでは次回のチャットで使えるようにはなりません。詳しい保存方法は「06｜自分専用の作り方を育てる」を参照してください。

## 次回は、制作の前に読み込んでもらう

```text
プロジェクトにある本人設定と「発信の軸」の最新版を読んでください。
その方向性を踏まえて、今回の動画テーマ［テーマ］の企画を考えてください。
6つの言葉を無理に本文へ入れるのではなく、対象者と伝え方に反映してください。
```

軸は固定し続けるものではありません。活動や届けたい相手が変わったら、今のファイルを使って見直せます。

```text
最近は［変化したこと］を大事にしています。
発信の軸を見直し、変えた方がよい部分と、残した方がよい部分を提案してください。
私が選んだ内容で最新版を更新してください。
```

## 困ったとき

| 状況 | 伝え方 |
| --- | --- |
| 候補が全部ありきたり | 「私の回答のどこから出した言葉か示して。具体的なこだわりをもう一つ質問して」 |
| 強い・攻撃的な言葉になる | 「穏やかな発信がしたい。同じ意味で、普段使う言葉に直して」 |
| 自分ではない人物のように感じる | 「実績を盛らず、私が話した内容だけで作り直して」 |
| やりたいことが多く、絞れない | 「今回は誰に届けたいかから、一つずつ整理して」 |
| すでに軸がある | 現行ファイルを渡し、「最初からやり直さず、この部分だけ見直して」 |
| AIが勝手に確定する | 「まだ候補です。確定したものと案を分けて」 |

発信の軸がまとまったら、「07｜自分らしいプロフィールを作る」で紹介文を整える、「3回喋る」で台本にする、SNSや出版企画へ展開する流れにつなげられます。
