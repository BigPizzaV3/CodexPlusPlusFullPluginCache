# 15 台本を診断・修正する

完成済み・作成途中の台本に対し、魅力を高める診断や、指定した修正の反映を行います。「全体を評価」と「このコメントだけ反映」は別の頼み方です。

## 始める前に

本人専用のProjectでDr.SHI-GYOを使います。スキル名を覚える必要はありません。下の例文の［ ］だけを自分の内容へ変えて送ってください。

## 用意するもの

- 最新版の台本。HTMLまたはMarkdown、文章貼り付けで渡せます。
- あればサムネイル画像。視聴者が期待する内容と台本が合うかを見ます。
- 自分の修正メモ、音声、画面録画。変更してほしくない部分も伝えます。

## 最初に送る例文

```text
この台本の魅力と自分らしさを診断してください。一次情報・体験・感情・解釈・倫理と透明性・視聴者との関係性を見て、ダイジェスト候補、タイトル、概要欄、私に聞くと良い質問まで提案してください。まず評価と提案をお願いします。
```

## 進め方

1. 全体診断では6軸の評価、5〜10のダイジェスト候補、ベスト3、タイトル10案、約500文字の概要欄などを読みます。点数は編集上の目安で、医学的な正しさや再生数を保証しません。

2. 深掘り質問は15〜20問程度から、優先する5問を選んで答えられます。全部を一度に埋める必要はありません。

3. 採用する案と自分の言葉を伝え、「全文を直してください」と依頼します。修正音声だけを渡す場合は下の例文を使います。

4. 改稿は初心者視点などのレビューと修正後の全文確認を通して返されます。意図が違えば同じ最新版に追加修正を頼めます。

## ダイジェストで選ぶのは「視聴者が続きを見たくなる短文」

「自分にも良い変化がありそう」「知らずにいると困ることがある」と具体的に伝わる文を優先します。単なる「重要です」「研究があります」や、説明を先延ばしにする文だけを抜き出しません。候補は5〜10か所、採用は3か所程度が目安です。ポジティブとネガティブの割合より、今回の動画で伝わる強さを優先します。

```text
ダイジェスト候補を、具体的なメリットや見逃したくないリスクが伝わる短文へ磨いてください。
撮影前なので、必要なら本文も改善した上で、最新本文から連続する文を抜き出してください。
根拠のない効果・数値・研究・体験は追加しないでください。
```

「1分」「この食材だけ」「劇的に」のような表現は、内容と根拠がその強さを支える場合に限ります。条件が必要なら短く意味が通る形に含め、詳しい説明は本文へ置きます。**すでに撮影済みなら、そのことを先に伝えてください。** 実際に話していない文は抜き出しにせず、追加撮影などの提案として分けます。

## 出てくるもの

- 全体診断では、6軸診断・ダイジェスト・タイトル・概要欄・深掘り質問・質問の優先順位。
- 指定修正では、修正済み全文と短い反映結果。既定はHTML、プロンプター用Markdownなども指定できます。

## 修正・別モードの頼み方

```text
添付の修正音声を、この最新版の台本に反映してください。評価一式や追加の質問票は不要です。指示を取りこぼさず、同じ問題が他にもあれば直して、修正済みの全文HTMLと変更点を返してください。
```

音声ファイルは、そのまま添付できます。AIが必要な準備と文字起こしを行い、最新稿への修正へ進めます。初回インタビューからやり直す必要はありません。画面録画の場合、音声だけ読み取れた時はその旨が示されます。選択した文が分からない箇所だけ、短い引用や画像で補ってください。

## 完成前に確認すること

- 修正メモの各指示が反映されたか分かる。
- ダイジェストの抜き出しが最新本文と一致する。
- 専門用語・構文の繰り返し・本人にない体験が残っていない。

## うまく進まないとき

意図と違う修正が起きたら「ここは戻す」「この表現は残す」と具体的に指定します。「評価のみ」の段階では本文は変更されません。短い台本で候補が少ない場合は数合わせを求めず、成立する案を使います。

## 次回にも生かす

修正版の納品後は、「完成版をProjectのソースの見本にするか」「今回の修正を独自スキルへ登録・更新するか」を別々に聞きます。「両方はい」「1だけはい」「2だけはい」「両方いいえ」で選べます。

両方はいなら、完成台本の見本Markdownと、今後の作り方を反映した動画台本生成の独自スキルMarkdownを受け取ります。既存ルールがあれば統合し、今回だけの変更を固定ルールにしません。

詳しくは[06｜自分専用の作り方を育てる](06_personal_growth.md)へ。ファイル作成とProject登録は別です。保存先で読み戻せた場合だけ登録済みとし、それ以外は「登録待ち」のファイルをソースへ追加します。

明示的に選ぶときのスキル名：`script-improvement`。迷ったら、作りたい成果物を普通の言葉で伝えてください。
