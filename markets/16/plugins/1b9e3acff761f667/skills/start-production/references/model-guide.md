# 用途別モデル案内

確認日：2026-09-26。以下は推奨候補。Dr.SHI-GYO全用途でのモデル比較試験はまだ完了していない。

基本方針は、動作確認を進めた最新世代の推論モデルを標準以上の思考設定で使うこと。軽量なモデルも最新版である場合があるので、新しいという理由だけでは選ばない。新モデルの登場時は代表例で確認してから案内を更新する。

| 用途 | 候補 |
| --- | --- |
| 普段の台本・記事・企画 | 現行の標準〜上位モデル、標準以上の思考設定 |
| 医学論文の比較・根拠確認・28日分析 | 高性能モデル、深い思考設定 |
| 誤字・短い言い換え | 軽い設定も可。新しい医学的主張を加えない |
| サムネイル・図解 | 構成を推論し、画像生成機能で実画像を作る |

公式ガイドではSolを執筆・判断を伴う日常作業、Astraを深い分析等に位置付けている。利用者が今使える表示名と設定を優先する。個別プランで選択可能なモデル・利用上限は推測しない。

ファイルを使って成果物を作る一連の作業はWorkを案内する。モデルと思考設定は画面上の選択であり、このSkillが選択状態を必ず取得・変更できるとは扱わない。

https://learn.chatgpt.com/docs/web

モデルが強くても、未接続のGoogle Driveや不足するCSV、利用できない画像生成は補えない。必要機能がないときは代替入力/出力を案内し、完成扱いと区別する。初回以外は必要が生じた項目だけ案内する。
