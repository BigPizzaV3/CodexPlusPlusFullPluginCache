# 全機能の使い方・受講生ガイド

1.1.4対応。全22冊のHTML・PDF・Markdownを同期。初回導入では、Project指示に「このProject内の情報発信に関する作業では、必ずDr.SHI-GYOプラグインの該当スキルを使ってください」を含む文を提案する。既存指示を消さずに統合し、保存後に同じProjectの新規チャットで@なしの呼び出しを確かめる。利用できない場合は@の候補から選ぶ。空のProjectでプラグインを選んで即インタビューを始める経路も保つ。

1.1.2で変更した動画台本本文の文献表示は引き続き `（引用文献挿入：1）` の形式に揃えること。編集用の目印で読み上げは不要。台本作成・改稿・素材入り台本に適用し、プロンプター稿では省く。詳細は [本文引用の統一書式](../../source-script/references/script-output.md#本文引用の統一書式) を参照する。全21スキルを22の目的別ガイドで説明する。使い方だけを聞かれたら該当するMarkdownを読み、その人が今から試せる例文と最小限の手順を案内する。全22冊を毎回読み込ませない。

ファイルが必要なら、同梱assets/learner-guides/の配布物一式をユーザーがダウンロードできる出力先へコピーしてZIPにし、index.htmlから開くよう伝える。HTML単独を配ると相対参照が失われるためフォルダー全体を保つ。個別ガイドはPDFでも渡せる。実行環境で参照・コピーできない場合はその旨を伝え、利用できる本文だけを案内する。ファイルを作っていないのに保存済みとしない。
