# 依頼と担当

| 依頼・入力 | 担当Skill |
| --- | --- |
| 初回設定・一連の制作・再開 | start-production |
| 本人設定／台本マニュアル作成・Update／動画台本 差分 アップデータ | doctor-profile（初回登録・作成・勝ちパターン更新・差分更新を区別） |
| 自己紹介・終了画面・プレゼントの登録／過去動画から素材のデザイン設定 | doctor-profile（本人素材登録。台本マニュアル作成の質問は不要） |
| 自分の経験や考えを引き出し、公開用のプロフィール文を作る | public-profile（本人設定の登録だけならdoctor-profile。確定した文章と事実を分けて引き継ぐ） |
| 発信の軸・SNSキーワード・3＋3のキーワードを決める | brand-keywords（方向性を掘り下げる対話。投稿本文の量産ではない） |
| 撮影セット、背景の小物、服装、ブランドカラーの相談／YouTubeカラー診断 | brand-color（23・31の配色相談を統合。採用配色は本人素材設定へ） |
| 28日分のCSV/Excel、分析の準備 | youtube-28day-report |
| 次に作る一本の企画・タイトル・構成 | video-planning |
| 医学的主張や論文の根拠を確認 | medical-evidence |
| インタビューして／初回音声インタビューをして／動画台本を作りたいので初回音声インタビューして／3回喋る／Liveで考えを引き出す／ボイスメモから台本／その途中再開 | voice-script（調査後の実際の第二の語りを待ち、初稿後の第三段階はscript-improvementへ） |
| テーマから論文調査を含め台本作成 | research-script |
| PDF・論文・講義・原稿を台本化 | source-script |
| 台本魅力アップ（6軸改善、A〜Fの成果物） | script-improvement |
| 初稿・完成稿への修正音声／画面録画／コメントの反映 | script-improvement（最新稿と入力を照合して改稿。未依頼のA〜F全件は追加しない） |
| 本人の方法を整理して命名・説明 | method-design |
| サムネイル画像／Nanobanana用プロンプト3案 | thumbnail-design |
| 完成台本に「素材を作って」／いつものデザインで編集者用HTML・ZIPを一式 | editor-handoff（用途に合うイラスト・図解・実動画を実制作し、全文プレビュー・ZIPまで。別案も選べる） |
| 完成台本に合う素材のおすすめだけ／先に図解・漫画・動画から種類を選ぶ | asset-planning（推薦・選択・制作指示。固定10枚ではない） |
| 挿入素材10枚／SNSの正方形1枚9マス | visual-materials（10枚生成と9マス画像を区別） |
| チャンネルアート用の英語プロンプト3本 | channel-art（原本の既定は実画像の生成ではない） |
| 一つ／複数の台本からSEO・note・ブログ記事 | article-adaptation |
| 類書調査・出版企画書・目次・出版社向け添え状 | publishing-plan（市場調査・企画選定と、選定済み企画の提出用仕上げを区別） |
| 完成動画の公開用タイトル・概要欄・チャプター／YouTube動画からSEO対策 | youtube-metadata（実時刻を確認できない台本のみの入力では時刻なし章見出し。未依頼の台本改稿は行わない） |

資料とテーマの両方がある時は、資料の変換が主ならsource-scriptへ。設定を作るdoctor-profileと原稿を直すscript-improvementを混同しない。28日分析の次企画候補は保ち、選んだ一本をvideo-planningで具体化する。

**空のProjectでの優先順位：** Dr.SHI-GYO指定＋短い「インタビューして」は、別用途が明示されていなければvoice-scriptへ直行する。初回の本人登録・見本登録・Project指示作成を挟まない。テーマ不明なら「今回は、どんなテーマの動画台本を作りたいですか？」の一問だけ、既知なら所定の患者質問から始める。Project名を取得できることを起動条件にしない。「公開プロフィール用にインタビューして」はpublic-profile、「発信の軸を引き出して」はbrand-keywords、「出版企画のために」はpublishing-planを使い、途中の工程も保持する。

添付音声の読み取りは、担当Skillにかかわらず[自動読み取り](../../voice-script/references/audio-runtime.md)の `ingest_audio.py` を使う。単独の文字起こしもこの処理で完了する。準備から実行まで進める前に、利用者へ全文の貼付を求めない。

「3回喋る」の進行はvoice-scriptが持つ。Live開始準備の「はい」だけという指定を初回説明より優先し、その後の開始発話を待つ。Live中は視聴者の疑問を軸に多角的に聞き、調査しない。調査工程はmedical-evidenceへ主張と元発話・未回答の中心疑問を渡し、結果を受講生へ示して実際の第二の語りを待つ。第二の語りと採用根拠を含む最終執筆の引き継ぎはsource-scriptで受け、voice-scriptへ戻して初回質問を繰り返さない。初稿HTMLへの第三段階の修正はscript-improvementへ渡す。音声の文字起こしだけ、完成した口述原稿の整文だけの依頼にはこの3段階を強制しない。

research-script、source-script、script-improvementの本文制作とdoctor-profileの見本台本では、[初心者視聴者レビュー](viewer-review.md) を納品前に必ず通す。受講生に別スキルの呼び出しを要求せず、医学知識のない初心者の理解を含む実レビューと統合修正を担当工程内で終える。明示省略・利用不可・同一版で実施済みの扱いは共通手順に従う。

完成台本への「素材を作って」「台本から素材も一式作って」「編集者にそのまま渡せる形」はeditor-handoffを入口にし、選択一覧や図解だけで止めない。特定画像だけや旧10枚モードを明示された場合はその範囲を尊重する。本人の画像やデザインが登録済みなら再入力を求めず、実原本を読み戻して未登録・参照不能なものだけ補う。台本本文の改稿を依頼されていなければ原文を保持する。

元GPT名で指定された場合はそのモードを優先する。「動画台本ゼロイチ」は資料が添付されていてもresearch-scriptの原文手順で受ける。「動画台本 差分 アップデータ」は完成原稿の改善ではなく、修正前後から本人マニュアルを更新するdoctor-profileの仕事。「台本マニュアル作成」はプロフィール保存だけで終えず、原本の台本作成・改善ループを経る。

【SG】動画台本から素材画像を10点作成は指示空欄だったため、挿入素材10点の手順を代替として案内する。元GPT独自の挙動を再現済みとしない。【SGt】3段階サムネイル連動画像用プロンプト作成は資料保管のみで初版には含めない。

プロフィールはpublic-profileで表現を作り、brand-keywordsで確定した発信の軸と一緒にdoctor-profileへ渡す。登録のみの依頼へ長いインタビューを強制しない。配色を相談するbrand-colorと、参考動画の観察結果・本人画像を登録するdoctor-profileも区別する。本人が採用した版・適用範囲を保ち、特定のテーマの例を恒常的な本人設定にしない。

youtube-metadataは完成動画を公開する直前の記載内容を作る。script-improvementのタイトル10案・約500文字の改善案とは別モードであり、同時に二つを起動して数量や文字数条件を混ぜない。本文や映像を未取得なら未確認の視聴内容・チャプター時刻・検索量を補わない。

SNS文章の全面展開、書籍本文の継続執筆等は1.1.0でも専用Skill範囲外。依頼された一般的な支援は可能な範囲で行い、今回保留したGEMの機能が実装済みとは案内しない。

## Project指示からの呼び出し

初回導入で「必ずDr.SHI-GYOの該当スキルを使う」というProject指示を保存済みで、本Pluginを実際に利用できる場合は、各チャットでプラグイン名を再指定させず、この対応表から担当を選ぶ。「インタビューして」はvoice-script、「サムネイルを作って」はthumbnail-design、完成台本への「素材を作って」はeditor-handoff。別用途が明示されればそれを優先する。設定文の作成・見直しはdoctor-profileの[Project設定](../../doctor-profile/references/project-setup.md)へ。利用不可なら選択を案内し、使用済みとは扱わない。
