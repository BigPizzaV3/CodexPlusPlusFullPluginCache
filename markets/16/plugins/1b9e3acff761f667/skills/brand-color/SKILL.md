# 撮影環境・ブランド配色

本人が目指す印象から配色を設計し、実際の撮影セットと発信素材へつなぐ。GEMの「YouTubeカラーアドバイス」と「YouTubeカラー診断」を統合した手順で、現状の色をそのまま理想の配色として抽出する仕事ではない。

## 最初に使う情報

登録済みの本人設定を参照し、今回のチャンネル名・専門分野・視聴者・目指す印象、維持したいブランド色、現在の撮影環境画像を確認する。パーソナルカラーは本人が分かる場合だけ申告を使う。分からなくても始められる。写真からパーソナルカラー、性格、健康状態や経歴を断定しない。

- 撮影画像または実際に開けた動画フレームがある：観察した範囲を明示して、具体的な環境改善まで進める。
- URLしかなく映像を開けない／文字起こしだけ：チャンネルの方向性に合う暫定配色は出せる。背景や肌映りを見たことにはせず、セット診断に必要なスクリーンショットを1枚求める。
- 既存ブランド色を守る依頼：その色を固定条件にする。別案へ勝手に置き換えない。

## 進め方

1. **理想の2色を先に定める。** チャンネルが伝えたい専門性・親しみやすさなどと本人の希望から、ベース色とアクセント色を、色名・HEX・選定理由つきで提案する。現状の部屋にある色に引きずられず、確定したブランド色は守る。
2. **現状との差を見る。** 画像で確認できた色、物、明るさ、画角を記録する。理想に不足する色と、視線が散る色・物を分ける。本・模型・道具は専門分野を伝える可能性のある物として扱い、写っているだけで本人の著書・受賞品・実績と決めない。本人が残したい物を、色だけでノイズと決めつけない。
3. **物理的な変更へ落とす。** 足す・減らす・移動する物、服の色、布や背景、照明の向き、画角の変更を具体化する。まず手元の物でできる変更を優先し、購入は必要な場合の候補に留める。色つき照明で肌や白衣まで染める案は、背景への光と演者への光を分けて調整する。
4. **各媒体へ展開する。** 同じ2色を、サムネイルの背景と強調文字、アイコン、チャンネルアート、動画内の図解にどう使うか示す。可読性のための白・黒・グレー等は補助色として区別する。色だけで重要度を伝えず、文字や位置でも区別できる案にする。
5. **採用した内容を残す。** 選択済み・明示された修正を反映し、[保存用テンプレート](assets/brand-color-template.md) で本人専用の設定を渡す。提案中と採用済みを混ぜない。本人設定へ保存する依頼ではdoctor-profileへ、実画像の制作ではthumbnail-design／channel-art／editor-handoffへ、採用色・用途・維持条件を引き継ぐ。

## 出力

通常は次の順で、すぐ手を動かせる改善案を返す。

1. **目指す理想のカラーパレット**：ベース色／アクセント色、各HEX、理由。
2. **現状とのギャップ**：実際に見えた内容と、未確認の内容を分ける。
3. **足し算・引き算・配置**：「変更する物や場所／変更内容／理由／手間の目安」の表。
4. **照明・背景のワンポイント**：今回の画像に即した助言。
5. **媒体ごとの使い分け**：サムネイル、アイコン、ヘッダー、動画素材の配色例。
6. **まず試す変更**：優先度の高いものを最大3つ。採用依頼があれば保存用設定も付ける。

色の面積比を示す場合はレイアウトの目安と明記する。元GEMの「メイン70％・アクセント20％」は合計90％で残りが未定義なので、そのまま完成した配色規則として使わない。比率が必要なら、補助色・余白を含め合計100％になる提案を新たに定義する。写真の色面積を測定した値とは区別し、顔・肌・白衣まで無理にその比率へ合わせない。

## 完了前の確認

画像の観察と提案を混同していないか、本人の維持条件に反していないか、HEXが有効か、選んだ色で文字を読み取れるかを確認する。配色はデザイン上の仮説であり、再生数・信頼・医学的権威の向上を保証しない。

保存先へ書き込んで読み戻せた場合だけ「登録済み」と伝える。それ以外は設定ファイルを渡してProject等の情報源への登録を案内する。共有Pluginに個人の写真・名前・確定した配色を埋め込まない。
