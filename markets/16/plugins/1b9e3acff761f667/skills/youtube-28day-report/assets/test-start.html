この分析はDr.SHI-GYOプラグインに含まれています。別の分析プラグインを追加する必要はありません。

新しく追加されたプロフィール・発信の軸・配色・公開用テキストなどの機能を使う前に、導入している版が1.1.0以降か確認してください。このガイドが手元にあるだけで、プラグインの更新が済んだことにはなりません。

1. 専用Projectから始める

Dr.SHI-GYOを利用できる環境で新しいチャットを開きます。本人設定を登録したご自身のProjectから始めると、視聴者や目標を引き継ぎやすくなります。まだ設定していなければ「初めて使います」と依頼してください。

モデルは標準〜上位の推論モデル、分析には深い思考設定を候補にします。表の読み取りとファイル生成が使える環境で進めます。使える機能は、実際のチャットで確認してください。

2. 同じ28日間の資料を用意する

画面付きのデータ準備ガイドを開く

この案内を保存・移動するときは、「00_はじめに.html」と「input-guide.html」を同じフォルダに置いてください。フォルダごと渡せば、上のリンクから準備ガイドを開けます。

  • 動画別の表
  • 流入元別の表
  • 検索語別の表
  • 関連動画の流入元動画別の表

ExcelまたはCSVを渡します。前回の次月メモや、視聴者・維持率等の画面画像があれば添えてください。不足部分があっても、分析できる範囲から進められます。

3. 分析を依頼する

添付した28日分のデータから、読みやすいHTMLレポートと次月引継ぎメモを作ってください。本人設定の視聴者と目標も参考にしてください。

全体の数値、参考にする動画、次の企画、検索・関連流入・連続視聴・反応と登録を整理します。公開ページを確認できない参考候補を、確認済みとして推薦しません。

4. 次の制作につなげる

HTMLレポートと次月メモを保存します。「この候補を一本の企画にして」「台本とサムネイルまで作って」と続けて頼めます。翌月は新しいデータと前回メモを渡してください。

Project原本の自動上書き、YouTubeの自動取得、動画の投稿、定期実行は導入だけでは設定されません。
