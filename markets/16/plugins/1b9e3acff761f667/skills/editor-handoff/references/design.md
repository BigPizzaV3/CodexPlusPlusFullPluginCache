# 見本からデザインを引き継ぐ

見本は本人の過去動画・スライド・画像を優先する。好みの第三者作品は配色や構成の参考として扱い、第三者の顔・ロゴ・肩書き・文章を本人素材として再利用しない。

動画のURLだけで映像を見たことにしない。利用可能な正規の機能で実フレームを確認し、参考にした時刻と見えた内容を記録する。文字起こし・動画説明・サムネイルだけを見た場合、動画内の配色・図解・動きを推測して「踏襲済み」としない。確認できない部分は視覚未確認とし、本人が添付したキャプチャや既知の素材から進められる部分を作る。

見る箇所は必要な代表例だけ。自己紹介、文字カード、図解、人物イメージ、終了画面等から3〜6場面を目安とし、各場面にURL/タイムコード/観察事実を残す。

## 個人設定に抽出する項目

- 背景・主色・アクセント・注意色、コントラスト。確認できたHEXは明記、推定は推定と記載。
- 日本語の見出し/本文/出典の大きさの関係、太さ、行数、余白。フォント名を識別できない場合は代替候補と区別。
- イラストの写実性、輪郭、陰影、背景、人物の描き方。医学図は装飾より正確さを優先。
- 正方形インサートの配置、字幕との重なり、全画面カードの密度。
- 動画は動く対象、カットの頻度、静止画との使い分け。不要な動きを増やさない。
- 取り入れる点・避ける点・見本の確認範囲・本人の採用状態。

同一案件の生成プロンプトへ「本人デザイン設定の版」を共通で渡す。最初に作った実素材で配色・雰囲気を確認し、明示的に先行確認を頼まれていなければ、その規則で残りの制作へ進む。AIが決めた暫定値は本人の恒常的な好みとは扱わない。

納品HTMLの背景色と図解/イラストの配色は別に記録する。HTMLのテーマ色を変えただけで、素材自体のデザインを反映したとは言わない。
