# 実案件見本：こむら返りの素材入り編集用台本

## 見本を開く

[閲覧用HTML](../assets/examples/cramps-editor-handoff.html) は、2026-10-16に本人が修正確認した台本と実素材の一体型見本。本人がこのプラグイン内の具体例として使うことを許可した。公開範囲やプラグインの共有設定を変更する許可とは区別する。

「見本を見せて」と頼まれたらこのHTMLを読み、[確認ページと修正](review-page.md) に従って本人向けの限定確認ページで提示する。ファイルを指しただけで表示確認済みとしない。全文や全画像を一部ギャラリーへ縮めない。見本は閲覧用で、変更書き出しは無効。納品済みHTMLに見本説明と操作停止を加え、件数の表記は挿入場面数と実ファイル数を区別するよう訂正した。原稿本文と素材は保持している。

過去見本に残る旧形式の引用番号は当時の原稿として保持する。新しい台本の納品では [本文引用の統一書式](../../source-script/references/script-output.md#本文引用の統一書式) に従い、`（引用文献挿入：1）` 形式を使う。

## この見本の状態と限界

静止画19点と無音動画1本を本文18場面へ配置。S05は一場面で3枚を使うため、場面数とファイル数は異なる。S00の自己紹介、S14のプレゼント、S20の終了画面は本人原本待ち。未制作の別案もproposalのままで、完全納品の見本ではない。撮影動画未提供のため、実測タイムコードや配置の左右は確定していない。

実画像の目視、原稿全文の一致、埋め込み画像の復号、元のZIPの展開と相対参照は確認済み。ブラウザー実表示・動画連続再生・受講生アカウントでの実行は未確認。確認済みの範囲を広げて説明しない。

## 新しい案件で引き継がないもの

本人の氏名、医師ID、原稿、プレゼント名、仮配色、描かれた人物、素材数、数値、原稿SHA、制作記録のpassedを新案件の初期値にしない。図の医学的主張も新しいテーマの根拠として流用せず、その案件の原稿と出典で確認する。人物は架空の説明用イラストであり、本人の肖像や実患者の記録ではない。

制作方法と見せ方を参照し、新しい原稿・本人設定・実素材から新しいcaseを作る。採用画像の実制作と内容確認が終わるまでreadyを付けない。
