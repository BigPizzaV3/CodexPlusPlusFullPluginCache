# ダイジェスト

選定は [見続ける理由が伝わるダイジェスト選定](../../source-script/references/digest-selection.md) に従う。短い原文だけで「自分が得る具体的な変化」または「避けたい具体的な不利益」が伝わり、続きを知りたくなる箇所を選ぶ。単なる章紹介、「研究があるんです」「大事です」だけの文、留保だけの文は採用しない。強い形容詞で補わず、確認済みの行動・結果・判断の具体性を優先する。

入力に既存のダイジェストがあれば保持。利用者が抜き出す文・範囲を指定したら、その原文を一意に特定し、指定順に箇条書きで置く。該当本文は太い赤字で示す。原文quoteとダイジェストの表示用displayは別フィールド。 原文は最新版本文の連続した範囲と照合する。一文全体でなく、語尾や後続説明の手前で切った指定も保持し、文法上未完という理由だけで完結文へ戻さない。新作文、語句の置換、離れた箇所の接合を切り出し扱いしない。対象・条件・否定・可能性を落として意味や主張の強さが変わる場合は、その問題を示して範囲を調整する。

例として「この言葉を??で伏せる」と指定された場合、display側だけを伏せ字へ置換する。本文の言葉・医学的主張を伏せ字で書き換えない。映像と音声のどちらを伏せるか明示指定があれば編集指示へ反映する。未指定の音声処理を完了済みとしない。

指定がない場合、通常は台本内の5〜10候補を比較し、最大3か所を冒頭へ提案する。先頭はタイトルの約束に最も合う強い一節、残りは異なる利益・不利益・発見から選ぶ。小さな行動と具体的な利益、または身近な状況と重大／高頻度の不利益が伝わるかを点検し、正負の比率は固定しない。短い原稿では成立する数に絞り、3本をそろえるため弱い候補を混ぜない。自動提案はstatus=proposedとし、採用済みと区別する。患者を怖がらせるための条件切り落としや、疑問を断定に変える編集をしない。今回の動画の特定の語・数値・テーマを共通ルールへ固定しない。

台本作成・改善の工程から5〜10か所の候補一覧が渡された場合は、位置特定用の原文引用と実際の抜き出し範囲を最新版本文へ照合して採用済みの箇所を引き継ぐ。付随メモと完成本文が違えばメモを旧版・要更新と明示し、生成時の「一致」記録をそのまま信用しない。5〜10は本文側の候補数で、すべてを冒頭に並べる意味ではない。未採用なら通常は最大3か所を提案する。伏せ字は核心に限り、対象・条件・否定語を隠して意味を変えない。

強い候補が本文にない場合は依頼範囲で分ける。本文の新規作成・改善も含む制作なら、台本担当が確認済み内容から利益や避けたい結果を具体的に本文へ書き込み、必要なレビュー後に最新版から抽出する。素材だけの依頼、撮影済み、本文変更なしの場合は本文を勝手に改稿せず、既存音声で使える抜粋と、別途の「本文差し替え・追撮が必要な案」を分けて示す。新案を既存台本のquoteや撮影済みカットとせず、未反映と明記する。新しい数字・研究・体験を作ったり、効果発現までの期間や対象を省いて短い約束にしない。

一意なquoteだけでは長すぎる/重複する場合は前後文を含めて位置を確定し、利用者が望む実際の抜き出し範囲は短く別に記録する。曖昧な一致の先頭へ勝手に置かない。 quoteを位置特定のために広げた場合、実際の連続原文の開始・終了とカット位置をnotes等の編集指示へ残し、displayには指定された短縮・伏せ字を反映する。quote全体を音声で使う指示と混同しない。

納品前に、箇条書きの各抜粋から本文へ移動できること、本文の対応原文が太赤字であること、改稿した版と引用・表示文・文献番号・編集指示が一致することを確認する。`（引用文献挿入：番号）` の番号と巻末の対応は保持し、ラベルは読み上げない。ラベルの途中をカット・伏せ字にしない。追撮案には未反映表示を付け、現状の撮影済み音声で編集可能な抜粋と混ぜない。
