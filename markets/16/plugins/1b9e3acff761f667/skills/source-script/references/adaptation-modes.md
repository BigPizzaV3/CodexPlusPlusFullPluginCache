# 対象・形式・長さの変換

ユーザーの指示と本人マニュアルを優先し、未指定の部分だけを判断する。

| 指定 | 変換方法 | 保つもの |
| --- | --- | --- |
| 一般向け | 専門語を説明し、視聴者の疑問から話す | 対象集団、条件、限界 |
| 医師向け | 研究方法や比較条件、実務上の解釈を明確にする | 元資料の事実と発信者の意見の区別 |
| ランキング・項目形式 | 共通する選定軸を示して項目を並べる | 根拠のない順位づけをしない |
| 質問回答 | 資料が答えられる疑問ごとに組み直す | 資料が答えていない問いを確定的に補わない |
| 病気解説 | 概要、疑問、仕組み、対処に関する情報を接続する | 個別の診断・治療を行ったように書かない |
| NG行動 | 問題となる条件と代替案をセットで説明する | 限定的な問題を全面的な禁止にしない |
| 論文の批判的解説 | 問い、方法、結果、限界、解釈を分ける | 元論文が実際に述べている範囲 |

## 文体と文字数

- 口調は本人設定から合わせる。見本原稿の語り手が別人なら文体と経歴・経験を切り離す。
- 強い問題提起は疑問や構成で作り、資料の結論を誇張して作らない。
- 短くするときは重複・脱線から削る。注意条件だけを除いて意味を変えない。
- 長くするときは元資料の仕組み、比較、解釈を説明する。体験、統計、引用論文を増やして文字数を埋めない。
- 文字数は台本本文を対象とし、出典・対応表・作業注記は分ける。動画尺は本人の話す速さが未確認なら目安として提示する。

## 本文の型

冒頭の疑問または今回の結論 → 視聴することで分かること → 資料から説明できる本編 → 誤解しやすい条件 → まとめ。元資料や本人の型に合わなければこの順番へ固定しない。

資料対応表は読み上げ本文の外に置く。元資料の引用と本人の解釈が区別できるよう、本文で必要な範囲の出典紹介を行う。
