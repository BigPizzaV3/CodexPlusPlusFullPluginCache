# 見続ける理由が伝わるダイジェスト選定

1.1.5から、台本の執筆・改稿と編集者への引き渡しで使う。目的は、医学を知らない視聴者が短い一節だけで「自分の困りごとが変わりそう」「この結果は避けたい。続きを知りたい」と思えること。単に重要な文章を3本並べる工程ではない。本人が指定した抜粋・数・順番は優先し、作業範囲と根拠を保つ。

## 1. 書く前に、見終わった後の変化を一つ決める

視聴者の具体的な困りごとを起点に、今回知ることで何を選べる・できる・避けられるようになるかを書く。その変化に関係する主張だけを候補にする。視聴者の病歴や悩みを創作せず、テーマ・本人設定・今回の指示で確認する。

基本は次の型。定型文を繰り返す指示ではなく、候補に必要な中身である。

- **楽々ポジティブ：** 小さな行動・身近な選択 → 具体的にうれしい変化 → 方法・条件を知りたい、という流れ。時間・回数・手軽さは確認できた範囲だけ使う。「1分」は1回の所要時間か、1回で変化するまでの時間かを混同しない。続けた結果なら継続条件を残す。
- **ネガティブ：** 自分にも関係する行動・状態 → 具体的に困る結果 → 避け方・見分け方を知りたい、という流れ。頻度の高さまたは結果の重大さで伝え、両方を無理に盛り込まない。知らないこと自体を病気の原因にしない。
- **選択が変わる発見：** よいと思っていた選択・見落としていた違い → 判断を変える具体的な発見 → 理由・選び方を知りたい、という流れ。改善効果を確認できないテーマでも、実際に得られる判断の価値を強く示せる。

「劇的」「たった」「超簡単」「寝たきり」「脳卒中」等の強い単語を入れたことを魅力と数えない。視聴者が得る変化・避ける不利益の具体性で強くする。ポジティブとネガティブの比率は固定しない。

## 2. 5〜10候補を先に落とし、残りを比較する

通常の一本分なら、本文の異なる箇所から5〜10候補を設計・抽出する。同じ利益の言い換えは一候補とする。短い原稿や情報が少ない場合は成立する数に絞る。

まず各候補を**文脈説明なしで、その抜粋だけ**読む。次のいずれかなら、そのままでは不採用。

| 不採用にする候補 | 直し方 |
| --- | --- |
| 「今回は○○を解説します」「3つのポイントがあります」等の章紹介 | その知識で変わる具体的な困りごと・判断を本文に書く |
| 「そういう研究があるんです」「効果があるんです」だけで、何がどうなるか分からない | 確認できた行動・結果を含む連続範囲を選ぶ。存在する研究を言うだけでは通さない |
| 「大切です」「一概には言えません」「相談してよいんです」等で終わり、見る利益が分からない | 本編に必要なら残し、ダイジェストは別の実質的な発見から選ぶ |
| 専門用語の羅列、指示語だけで対象不明、長い方法の説明 | 主張に必要な対象・条件を残して日常語へ改稿する。方法の細部は直後や文献メモへ移す |
| 「誰でも治る」「これを知らないと必ず重症化」等、本文・根拠より強い約束 | 主張そのものを直す。後の但し書きや画面の小文字で取り繕わない |
| 確認できない論文・効果量・因果・体験で作った魅力 | その事実を使わず、確認できた価値で作り直す。研究・体験の創作で埋めない |
| 本編に答えがない、結論と逆、撮影音声にない新作文を既存カットとして扱う | 本文を直せる範囲なら先に修正。撮影済み等なら未反映の追撮案として別に扱う |

通過候補を次の4項目で、**具体／弱い／なし**の3段階で比較する。数値は視聴率の予測ではなく、原稿内の選定にも不要。

1. **自分との関係：** どんな日常の困りごと・選択かが、初心者にもその一節で分かる。
2. **得たい変化／避けたい結果：** 見ることで得られる利益や避けたい不利益が具体的。抽象的な「健康にいい」だけでは弱い。
3. **続きへの疑問：** 「どうやるのか」「何を選ぶのか」「自分にも当てはまるか」等、一つの具体的な疑問が生まれ、本編の答えの場所を示せる。「詳しく知りたい」だけは弱い。
4. **一息で届く強さ：** 冒頭から魅力の核心が聞こえ、専門知識なしで一度聞いて追える。必要な条件を残した最短の範囲である。文字数に合わせて意味を切り落とさない。

原則として1〜3が「具体」、4に未解消の理解障害がない候補から選ぶ。候補表の解説で魅力を後付けしない。弱い候補を「3本必要だから」で採用しない。

## 3. 通常3本は、別々の理由で見たくなる組み合わせにする

最も強く、タイトル・サムネイルの約束に合うものを先頭へ。残りは別の困りごと・利益・発見を持つ候補から選ぶ。すべて同じ「危ない」「改善した」の繰り返しにしない。ポジティブ3本が最適ならそれでよく、ネガティブを作るために新しい危険を足さない。

採用3本それぞれについて、原文、具体的な利益／不利益、次に知りたいこと、本編の答えの位置、主張を支える出典・本人発言、必要な条件を短く記録する。落とした有力候補にも一行の理由を残す。これは制作メモであり、読み上げ原稿に採点や説明を混ぜない。

## 4. 弱い本文を先に改善し、それから抜き出す

- **新規執筆・実質的な改稿：** 強い候補がないならそこで止めず、確認できた事実・本人の考えから、具体的な利益や避けたい結果の伝わる一節を本文へ書き込む。前後に説明と答えを置く。修正本文をレビューした後、完成本文から連続した原文を抽出する。本人の経験や研究を足す承認の代わりにはならない。
- **既存稿から素材だけを作る／撮影済み／本文変更なし：** 最新本文の実在箇所から選ぶ。弱ければ「既存音声で使える抜粋」と「本文差し替え・追撮をすると強くなる案」を分けて提示し、未反映・追撮必要と明記する。新しい台詞を撮影済みカットとして納品せず、本人の明示した本文変更・追撮の範囲に合わせて次版へ反映する。
- **本人が箇所を指定：** 指定の原文・範囲・順番を保持する。弱いと思っても別案へ無断で交換しない。条件の脱落で意味が変わる場合だけ問題と必要な範囲を短く示す。
- **根拠が足りない：** 方法の紹介、判断が変わる発見、確認済み本人経験等の成立する価値を探す。特定の効果を保証する強い文を捏造しない。それでも不足する場合は使える本数と不足理由を本文外へ短く残す。

必要条件は一節の中へ自然に組み込み、意味に影響しない研究手法の細部や長い留保は別の場所へ移す。関連を因果へ変えたり、特定対象の結果を万人へ広げたりしない。単独の「研究があるんです」は弱いが、具体的な行動と結果に続ける自然な話し方としては使える。

## 5. 最新版・原文・編集表示を最後に一致させる

採用後の本文変更で再照合する。原文 `quote`、実際に抜く連続範囲、最後に残す語、画面用 `display`、任意のピー音・伏せ字範囲を分ける。離れた文の接合を原文引用と呼ばない。文末カットは意味が保てれば使える。

HTMLの冒頭は箇条書きとし、各項目から該当本文へ移動できるようにする。本文側は対応する原文を太赤字で示す。本文改稿を行った場合は、その完成版から引用・太赤字・編集指示をそろえて作り直す。未反映案を太赤字の既存本文や撮影済みカットに混ぜない。

`（引用文献挿入：1）` 等の本文引用形式と巻末番号を維持する。ラベルは読み上げない。ラベルの途中を抜粋・伏せ字範囲にしない。伏せ字は核心だけに使い、対象・条件・否定・比較の方向を隠さない。

## 判断例（表現をコピーするための医療情報ではない）

以下は**架空の教材用前提**。実在の研究・診療経験を示さず、本番台本へ事実として転用しない。実際の主張は今回の確認済み資料に置き換える。

| 架空の確認済み入力という前提 | 弱い候補 → 採否・修正例 |
| --- | --- |
| 膝のテーマ。提供資料では対象者が椅子を使う運動を毎日1分、6週間続け、立ち上がる際の痛みが軽くなった人がいた。効果保証はない | 「運動は大切です」→不採用。「膝が痛い方で、椅子で1日1分の運動を6週間続けて、立ち上がる痛みが軽くなった人がいるんです。」→方法を知りたい候補。「1分で膝痛が治ります」へ短縮しない |
| 薬の管理のテーマ。提供資料では、同じ成分の薬の重複使用で強い眠気が起こり得ると説明され、見分け方が本文にある | 「薬には注意が必要です」→不採用。「別の薬だと思って重ねたら、同じ成分で強い眠気が出ることがあるんです。」→何を見れば重複を避けられるか知りたい候補。「飲むと必ず倒れる」「発生率が高い」は足さない |
| 食材のテーマ。「1品足すだけで劇的に変わる」という音声だけがあり、結果を裏付ける資料がない | 「たったこの食材で劇的に変わります」→不採用。裏付けが取れるまで効果候補から外す。確認済みの比較や選び方があれば、その価値を本文で具体化する |

前二例も、本番では対象・継続・結果の意味を実資料に合わせる。架空の前提を研究や本人経験として引用しない。
