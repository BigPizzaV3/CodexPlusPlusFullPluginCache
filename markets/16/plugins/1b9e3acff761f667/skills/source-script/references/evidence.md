# 医学的主張と出典の扱い

主張ごとに claim_id を付け、内容、source_id、URL/DOI等、原文の位置、研究対象、結果、限界、許容表現、確認状態を対応させる。一次論文を可能な範囲で実際に開いて確かめ、検索結果の題名や要約だけで全文を確認したと言わない。ガイドラインやレビューを使う際は、その資料として明示する。近年の基準・承認等は利用時に現在の公式資料も確認する。

## 確認状態

- 確認済み：実在と参照した内容を照合。全文/抄録/提供された抜粋のどこまで読めたかを残す。
- 一部確認：書誌だけ確認、全文を読めない等。確認済み範囲を越える断定に使わない。
- 未確認：利用者のメモや候補。論文を実在する引用として整形せず、調査待ちと分ける。

引用欄には著者・題名・年等の確認できた情報と到達できるURLを入れる。足りない書誌、DOI、人数、数値、P値を補作しない。台本→画像→記事でも同じ出典への対応を保持する。媒体内の引用番号は各モードの規則で再採番してよく、複数台本の記事化では原文02の指定どおり記事全体で通し番号を振り直す。旧番号・新番号・source_idの対応を制作メモへ残し、数字自体の固定と出典の保持を混同しない。

## 表現の判定

相関を因果へ、代替指標を患者にとっての効果へ、動物/細胞の結果を人の治療効果へ変えない。対象集団・介入・比較・観察期間を必要な範囲で残す。相対差の数字を絶対的な改善率として使わない。研究間の相違や反証がある場合は、採用した解釈と限界を記録する。読み上げでは結論の意味を変える条件を主張へ短く組み込み、研究方法の細部は文献メモへ置く。限界を記録することと、すべてを口頭で付け加えることを同一視しない。

根拠と本人の意見・仮説・経験を区別する。患者像や臨床経験を資料から推測して本人の一人称にしない。短いタイトルや画像も台本より強い医学的意味にしない。

医療コンテンツ作成は診断・治療の代行ではない。個別患者の相談に逸れる場合は依頼を整理する。一般向けの原稿には実際に必要な受診判断等を自然に含め、一律の長い免責文で本文を置き換えない。

検索や論文閲覧が使えない場合は、渡された資料の範囲で作業し、未確認の主張・出典を別記する。公開に使える確認済みの医学台本と偽らない。新たな医学的主張が増えたときだけ該当箇所を再調査し、文体修正だけで全調査をやり直さない。

## 台本の正確さと、読み上げる情報の選択

台本制作では [読み上げ・ダイジェストの共通基準](script-quality.md) の留保・解釈・提案の判断も適用する。主張を検証した担当は、実際に原資料と違う箇所、違いの根拠、許容できる言い方、適切な配置を返す。研究に限界があるという理由だけで、各段落へ但し書きを自動追加しない。

| 状態 | 対応 |
| --- | --- |
| 対象のすり替え、因果の断定、数字や否定の不一致 | 本文の主張そのものを修正する。文献注記だけで補わない |
| 主張の成立に必要な対象・条件 | 主張の中で短く伝える。誤解を生む省略はしない |
| 主張は妥当で、研究方法の詳細を省いても視聴者の判断が変わらない | 詳細と限界は文献メモへ残す |
| 禁忌や見逃せない症状等、行動に直結する情報 | 誰が、何が起きたら、どうするかを短く話す |
| 根拠は限定的だが、解釈や選択肢を示せる | 確認した結果と推測を分け、危険性・負担に合った提案へ進める。断定や架空の経験で強めない |

根拠の弱さを隠すために「医師の意見」と呼ばず、仮説に使った観察や知見を対応づける。仮説を述べた直後に同じ不確かさをもう一度打ち消す必要はない。提案の強さは根拠と行動の負担の両方から決め、服薬変更や侵襲的治療は必要な相談内容まで具体化する。本人の見解が未確認なら既定の本人設定へ自動登録しない。

## 量を日常の単位まで説明する

量が視聴者の理解・選択を左右する場合に適用する。単なる研究紹介の全数字に換算を増やす必要はない。

1. 研究の原単位と定義を確認する。杯、食分、回などは、原著の方法・表、補足資料、使用した質問票の順に必要な範囲をたどり、容量・重量・頻度・期間と定義の掲載位置を記録する。
2. 定義できれば、研究の数値に加えてmL、g、容量を明示した容器、回数など、日常で思い浮かべられる例を示す。容器の標準容量を勝手に決めない。体重や濃度を用いる換算は式と仮定を示し、成分のmgと飲料のmLを直接置き換えない。同じ計算を容器だけ変えて何度も説明せず、判断に役立つ例に絞る。
3. 元研究に定義が見つからなければ、未確認と明記したうえで、同じ問いについて単位が明示された別の一次研究を追加で探す。量が判断に必要なのに「研究によって違います」だけで調査を終えない。追加調査は、定義または使える別根拠が得られるか、原文取得の限界と調べた範囲が明確になったところで区切る。
4. 別研究の容量を元研究の杯数・閾値へ移植しない。別研究はその対象・比較・結果と組にして説明する。分かりやすくするための仮定例は、研究の定義・結果とは明確に分ける。
5. 研究で比較した量、生活上の換算例、医学的に勧められる量を分ける。観察研究の高低群の境界を安全・危険の境界へ変えず、換算だけから推奨量を作らない。個別条件が必要な用量等はその条件を保つ。

最後まで量を確定できなければ、何が未定義で、どこまで調べ、本文で何なら言えるかを残す。未確認を架空の数字で埋めず、量に依存しない確認済みの説明・判断材料があれば示す。確認済みの定義と出典は後続の台本・レビューへ引き継ぐ。
