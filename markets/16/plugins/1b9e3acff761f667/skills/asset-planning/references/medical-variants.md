# 医学説明を選べる実画像にする

臓器・筋肉・関節などの形、位置関係、働きが理解の鍵となる主要な説明場面に適用する。通常の一括制作でも自動的に対象を選ぶ。臓器名が出るたびに適用せず、同じ説明には一つの候補セットを作る。見出し、数値カード、本人素材や、姿勢だけを示す人物イラストを一律に多案化しない。

## 同じ説明に3〜5案

既定は以下の3案を、それぞれ独立した実画像として作る。4〜5案は追加の理解を助ける時だけ作り、選んだ枚数と理由を制作前に記録する。

| style | 表示名 | 狙いと制作条件 |
| --- | --- | --- |
| anatomical | 解剖関係を重視 | 参照で確認した形・位置・接続・向きを優先。説明に必要な構造だけを描く。精密さを装う細部を増やさない。 |
| cute | かわいい概念表現 | 丸い形や柔らかい配色、必要なら表情のある臓器・筋肉で親しみやすくする。単体のキャラクター化も使える。実際の体内の位置や機能まで変えない。 |
| schematic | 要点だけの模式図 | 説明の鍵となる関係だけを残す。関係の単純化は明示し、単なる文字カードにしない。 |
| context | 全体と部位の関係 | 4案目等の候補。身体全体と局所、比較や拡大など、先の3案で伝わりにくい位置関係を補う。 |
| metaphor | たとえで理解 | 5案目等の候補。台本に沿う別の理解経路がある場合だけ使う。比喩であることを示し、その見た目を実際の解剖や作用機序として扱わない。 |

3案は色違い・同じ絵の切り抜きで済ませない。4案目・5案目にも異なる説明価値が必要で、数を埋めるための作成はしない。追加案のstyleは上の区分から目的に合うものを選べる。必須のanatomicalとcuteを含める。全案で台本の同じ主張、対象部位、対象視聴者を保つ。

「3〜5案」は一つの挿入箇所で**どれかを選ぶ候補数**。全案を連続表示する指示ではない。一案の中に発話順の画像が複数あっても候補は一案と数える。初期採用は説明目的に最も合う一案とし、解剖案を機械的に最優先しない。

## 制作と確認

1. 台本の一意な引用、伝えたい一点、必ず保持する部位・関係・動き、描かなくてよい細部を整理する。デザインは本人設定を使う。
2. 解剖案に必要な関係を、実際に読める信頼できる医学教育資料、解剖資料、学術資料、または本人提供資料で確認する。資料の題名・URL等の所在と何を確認したかを残す。検索結果や生成された図の見栄えだけで確認済みにしない。参照画像の利用はその権限の範囲で行う。
3. 各案の画像生成指示に、対象・視点・必須の関係・省く細部・案ごとの画風・表示形式を入れる。解剖案とかわいい案は正規の画像生成機能で作り、コードの文字カードへ置き換えない。既存原本を使う場合は取得・内容を確認する。合成一覧から切り出さず、各案を独立した完成ファイルにする。
4. **全候補の実画像を開く。** 対象部位、位置・接続、左右・向き、動作・矢印、ラベルと指す先、台本の主張との一致を確認する。かわいい案でもこれらの意味を逆転させない。キャラクターの顔・手足等は表情の装飾として明確にし、解剖構造との誤認を避ける。比喩や模式化が必要な場面では「概念図」「模式図」等の表示を付ける。
5. 不自然な描写は修正・再生成して再確認する。細部を確認できない場合は描く範囲を絞り、確認できた解剖関係を保つ。既知の誤りを「かわいいから」で採用しない。解剖案を確認できなければその案はpendingのままにし、完成に見せるため候補数を減らさない。
6. 制作者と別の視点でも、初心者が誤解しないか実物を点検する。サブエージェントには実画像を渡し、見ていないものを合格としない。委任が使えない環境では別工程の再確認として実施範囲を記録する。

「解剖関係を重視」は制作方針であり、医学的な完全性の保証ではない。コード検査が確認するのはファイル・制作記録・レビューとの同一性であり、解剖学的正しさを自動認定するものではない。

## 表示形式と制作範囲

候補比較は静止画を基本とする。通常の①1:1インサート、②16:9全画面静止画、③16:9全画面動画の判断を保ち、意味なく3〜5本の有料動画へ増やさない。動画が必要な場面は既存の動画工程も進める。この静止画セットだけで動画完成と扱わない。

提案だけの依頼なら候補の設計で止める。一括制作や「実画像で選びたい」の依頼では、対象セットの全3〜5案を制作してから比較できる形にする。他場面の未制作の別案まで大量生成する必要はない。利用枠や機能不足は制作待ちとして伝え、生成済みの実物と未制作を区別する。無断の契約・追加購入はしない。
