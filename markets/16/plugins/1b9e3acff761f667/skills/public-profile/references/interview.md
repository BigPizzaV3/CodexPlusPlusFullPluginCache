# 本人の言葉を引き出す5つの観点

質問は診療科・対象読者・既に受け取った話に合わせる。以下は質問例であり、全問を同時に提示するためのアンケートではない。

| 観点 | 質問例 | 使える材料 |
| --- | --- | --- |
| 立場 | 「いま、どんな人にとって、どんな存在でありたいですか？」 | 専門・活動、届けたい相手との距離感 |
| 過程 | 「その考えに至るまでに、苦労したことや考えが変わった出来事はありますか？」 | 本人が語った歩み・転機。大きな挫折である必要はない |
| 感情 | 「そのとき、何がいちばん心に残りましたか？」 | 本人の言葉で表した喜び・悔しさ・違和感など |
| 価値観 | 「発信するとき、必ず大切にしたいことや、やらないと決めていることは何ですか？」 | 判断の基準、本人が採用した姿勢 |
| 日常 | 「普段の仕事や生活で、その考えが表れる小さな場面はありますか？」 | 公開可能な生活の手触り・具体例 |

曖昧な回答には、場面や言い回しを一つだけ尋ねる。たとえば「患者さんのため」なら「発信を見た方が、どんな場面で役立ったと感じてくれたら嬉しいですか」と具体化する。AIが模範の経験談を先に書き、本人に同意を求める形にはしない。

回答の整理は次の3つを区別する。

- **本人が述べた事実・経験**：情報源と公開範囲を保持する。
- **本人が述べた考え・感情・目標**：事実や実績へ置き換えない。
- **AIの表現案・解釈**：本人が選ぶまでは案として扱う。

確認事項が残るときも、確認済みの部分で使えるプロフィールを作る。未確認の具体的な診療数や肩書きを推測で埋めない。歌島さんや教材の人物の経験は、利用者本人の経験として使わない。
