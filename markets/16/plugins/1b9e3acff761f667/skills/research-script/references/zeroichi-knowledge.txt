# 動画台本ゼロイチ　完成稿リファレンス

# この資料の役割

この資料は、動画台本の方向性確認、ダイジェスト、本文、患者さんの例、論文紹介、引用論文、引用論文まとめを作るときの見本集です。

動画台本の作成や修正を依頼されたときは、依頼内容に関係する見本と判定基準を参照します。公開用詳細指示と内容が異なる場合は、公開用詳細指示を優先します。

# 標準的な進行

## 最初に受け取る情報

次の3点を確認します。すでに受け取った情報は再質問しません。

1. 動画タイトル
2. サムネイルで使用するテキスト
3. 台本の最低文字数

不足している項目だけを尋ねます。「お任せ」は5000文字、「長尺」は10000文字として扱います。

3点がそろい、動画の方向性がまだ示されていない場合は、前置きを付けず次の文章だけを出力します。

そのタイトルとサムネイルに期待した視聴者さんを満足させる動画の方向性を箇条書きで書いてください。動画で伝えたいこと、視聴者さんが抱きやすい疑問、取り上げたい研究、医師として加えたい経験や考えを必要に応じて含めてください

## 方向性を受け取ったあと

すぐに台本を書かず、次の見出しで内容を確認します。

# 方向性へのアドバイス

## 視聴者さんがさらに知りたい情報

タイトルから生じる期待、疑問、不安、誤解のうち、現在の方向性に足りない内容と、その理由を示します。

## タイトルとサムネイルとの一致

タイトルとサムネイルで約束した内容を最後までに回収できるか確認し、必要なら修正案を示します。

## 医師として加えたい経験や考え

医師の経験や考えを加えると価値が高まる場所を示します。必要な場合だけ1〜3問尋ねます。

## 方向性の修正案

追加、削除、順番変更を示し、最後は次の文章で終えます。

以上のアドバイスに基づいて、方向性を必要に応じて修正して、修正点をコメントしてください。修正不要の場合は修正不要とコメントしてください。その後、一般向け医学教育の台本を関連文献をリサーチした上で生成します

「方向性確定」「修正不要」「この内容で作成」「アドバイス不要」と明示されたら、追加確認せず文献調査と台本作成へ進みます。

# 完成台本の固定見出し

完成稿では、次の見出しを順番どおり使います。

1. # 動画タイトル
2. # サムネイルで使用するテキスト
3. # 【ダイジェスト】
4. # 【キャッチフレーズ＋自己紹介 例）〇〇を専門に診療している〇〇科医の〇〇です】
5. # 【視聴者の悩み共感パート】
6. # 【動画を最後まで見るべき理由】
7. # 【動画本編】
8. # 【Call to Action 例）チャンネル登録、グッドボタン、コメントをぜひお願いいたします。】
9. # 引用論文
10. # 引用論文まとめ

タイトルとサムネイルは入力どおり記載します。

自己紹介とCall to Actionは、ユーザーから使用する文章を渡されていない場合、見出しだけを置きます。内容を作って補いません。

# ダイジェストの完成形

ダイジェストは本編を書き終えてから作ります。本編に実在する3フレーズを選び、箇条書きにせず、別々の段落として並べます。

3フレーズの役割は、次の組み合わせを基本にします。

1. 常識と少し違う事実
2. 理由や正体を知りたくなる疑問
3. 希望につながる変化や可能性

主要な答えやランキング第1位は明かしません。本編の核心となる語句だけを「？？」へ置き換えます。前後の文章は本編の表現を保ち、新しい煽り文句を作りません。

## ダイジェストの判定例

本編の文章

研究を読み解くと、差が出たのは回数ではなく、続ける期間でした。

避けたいダイジェスト

大切なのは、続ける期間です。

これでは答えが分かってしまい、本編を見る理由が弱くなります。

望ましいダイジェスト

研究を読み解くと、差が出たのは回数ではなく、？？でした。

本編の文章を保ちながら、答えだけが伏せられています。

## ダイジェストに入れないもの

- 答えをそのまま伝える要約
- 本編には存在しない文章
- テロップ、BGM、SE、カットなどの編集指示
- 「続きは本編で」だけの予告
- 伏せる範囲が広すぎて意味が通じない文章

# 本文の流れ

本文は次の順番を基本にします。

1. 視聴者さんが抱きやすい悩みへの共感
2. この動画で分かること
3. テーマの全体像
4. 理由や仕組みの説明
5. 研究で分かっていること
6. 理解を助ける具体例
7. 誤解しやすい点や限界
8. 希望につながるまとめ

タイトルで約束した内容を先延ばしにしません。本編に入ったら、視聴者さんが知りたい順に答えを回収します。

# 患者さんの例の見本

患者さんの例は必須ではありません。抽象的な説明を具体的にする力がある場合だけ、最大2件使います。

避けたい始め方

ここで、興味深い症例報告を紹介します。

望ましい始め方

発表年に報告された患者さんの例です。

続けて、論文に記載されている年齢、経過、変化のうち、今回の話を理解するために必要な事実だけを語ります。論文に書かれていない会話、感情、職業、家族、生活背景は補いません。

一人の経過を紹介したあとは、その一人だけの話で結論を出さず、集団を対象にした研究で分かっていることへ戻ります。

# 論文紹介の見本

論文説明は、研究方法の講義ではなく、台本の主張を支える短い根拠として使います。

本文での基本形

研究で分かったこと、引用番号、視聴者さんにとっての意味を、原則1〜2文、多くても3文で伝えます。

望ましい構造

発表年の研究では、対象となった人たちに［研究で確認された内容］が報告されています(*1)。ここから分かるのは、［今回の動画で伝えたい一般的な意味］です。

角括弧内は、その都度確認した論文の内容へ置き換え、角括弧を完成稿に残しません。

本文で長く説明しないもの

- 研究デザインの細かな分類
- 統計手法の詳細
- 評価項目の長い列挙
- 結論の理解に不要な数値
- 文献の書誌情報

研究方法や細かな数値は、結論の理解に欠かせない場合だけ本文へ残します。詳しい内容は引用論文まとめへ置きます。

# 希望を持てる着地

注意点や研究の限界だけで終わらせません。現時点で分かっていること、今後考えられる選択肢、研究で期待されていることのいずれかへつなげます。

ただし、結果を約束する言葉は使いません。「可能性があります」「考える手がかりになります」「今後さらに分かってくることが期待されます」のように、根拠の強さに合う表現を使います。

# 編集指示を混ぜない

完成台本は、出演者が読み上げる文章と文献情報だけで構成します。

次の表記は完成稿へ入れません。

- テロップ
- ナレーション
- BGM、SE
- カット、画面切り替え
- 図を表示、論文画像を表示
- 編集者への指示やメモ

# 引用論文の見本

本文の医学的な主張の直後に、(*1)、(*2)の形式で番号を付けます。同じ文献を再び使う場合は同じ番号を使います。

## 引用論文

(1) 第一著者姓, et al. 発表年. 雑誌名略称 巻:ページまたは記事番号.

## 引用論文まとめ

番号ごとに次の順で記載します。

1. 完全な書誌情報
2. DOI、PubMed、出版社ページなどの確認済みURL
3. 研究方法、対象者、主要結果、重要な限界の2〜4行要約
4. 今回のどの主張を支えるために引用したか

本文、引用論文、引用論文まとめの番号を一致させます。本文で使っていない文献は追加しません。

# 文字数の扱い

台本文字数は「【ダイジェスト】」から「【動画本編】」末尾までを数え、引用論文と引用論文まとめは含めません。

最低文字数の115〜125パーセントを目安にし、最低文字数を下回らないようにします。文字数が足りない場合は、同じ説明の言い換えではなく、未回答の疑問、誤解されやすい点、理解を助ける具体例を補います。

# 完成稿の採点基準

出力前に100点満点で確認し、90点未満なら修正してから完成稿を出します。採点結果そのものは出力しません。

1. タイトルとサムネイルの期待を回収している　20点
2. ダイジェストが答えを明かさず、本編の3フレーズになっている　20点
3. 一般の視聴者さんに伝わる自然な話し言葉になっている　15点
4. 論文説明が短く、主張と引用が一致している　20点
5. 患者さんの例を必要な場合だけ使い、内容を作っていない　10点
6. 注意点だけで終わらず、希望につながる着地がある　10点
7. 編集指示がなく、固定見出しと文字数を守っている　5点

# 完成直前の最終確認

ダイジェストだけを先に作っていないか、本編にない文章をダイジェストへ入れていないか、答えを明かしていないかを確認します。

本文では「症例」「症例報告」を読み上げていないか、論文の方法や数値を長く説明していないか、同じ結論を繰り返していないかを確認します。

最後に、本文と引用番号、引用論文、引用論文まとめを照合してから完成稿を出します。
