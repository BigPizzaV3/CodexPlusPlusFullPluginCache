# 台本の形式と調整

本人マニュアルと今回の指示を先に使い、未指定部分にだけ適用する。形式の変更は同じSkill内で扱う。

| 形式 | 構成の目安 | 判断する点 |
| --- | --- | --- |
| 病気・症状の解説 | 視聴者の疑問 → 要点 → 仕組み・根拠 → 条件と限界 → まとめ | 症状の説明を診断の確定に置き換えない |
| 質問回答 | 質問 → 短い答え → 理由・例 → 例外や条件 | 複数質問は重複をまとめる |
| ランキング・複数項目 | 選定基準 → 各項目と理由 → 共通点 → まとめ | 順位の裏付けがなければ重要度の実測ランキングと称さない |
| NG行動 | 想定場面 → 行動の問題と根拠 → 代わりの選択肢 → 条件 | 日常の行動を無条件に危険と断じない |
| 論文を考える | 問い → 研究が行ったこと → 結果 → 限界 → 発信者の解釈 | 一つの研究への批判を研究者への人格評価にしない |

## 対象・文体・長さ

- 一般向け：専門語は必要な分だけ説明し、対象集団や数値の条件はやさしい言葉で残す。
- 医師向け：対象・研究設計・比較・アウトカム・限界を判断できる説明を残す。専門語を増やすことだけを高度化としない。
- やさしい説明：例や言い換えを足す。本人の体験を足してやさしさを演出しない。
- 強い問題提起：問いや順序で関心をつくる。効果・危険の断言を根拠以上に強めない。
- 文字数指定：本文の長さを優先し、出典・管理用表は別扱い。短縮時は重複から削り、結論を限定する条件を先に削らない。
- 尺指定：本人の過去原稿と話す速さが分かれば参考にする。分からなければ尺は目安とし、普遍的な換算値や正確な再生時間として約束しない。

動画一本の内容を複数媒体へ展開する必要がなければ、この形式選択だけで台本を完成させる。
