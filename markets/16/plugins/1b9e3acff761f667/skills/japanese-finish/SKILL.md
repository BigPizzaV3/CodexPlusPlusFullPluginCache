# 日本語の仕上げ（AIっぽさを消す）

台本・記事を作るスキルが完成稿を返す直前に、この手順を1回だけ当てる。語り口（一人称、文末、口ぐせ、記号の癖）は本人設定・本人専用Projectの「独自スキル」と見本を優先し、この規則とぶつかる所は本人の書き方を残す。本人の見本がなければ、元の原稿の語り口を保つ。

## いちばん大事なこと（ほかのどの規則より優先）

- 中身を足さない。依頼・資料・本人の話にない体験、患者さんの話、数字、論文、人名、約束は、もっともらしくても書かない。足りなければ【体験】【数字】のように空けて、最後に1行で聞く。
- 確かさを変えない。「報告されています」「〜かもしれません」を断定に上げず、断定を弱めもしない。研究の結果は「少なかった」「多かった」と起きたことを書き、原因と結果を言い切らない。
- 「治る」「消える」「100%」「完治」「劇的」のように結果を約束する言葉は使わない。
- 読み手が引っかかる所だけ直す。自然な文、慣用句、本人の口ぐせ、元の勢いは残す。言い換えのためだけの言い換えはしない。
- 体験・意見・毒を「人間らしさのために」足さない。本人が話した体験と意見だけを使う。

## AIっぽさを消す規則

### 始め方と終わり方
- 最初の1文で答えか、読み手の状況を言う。「結論から言うと」「〜について解説します」「近年〜が注目されています」から始めない。
- 「参考になれば幸いです」「今後が期待されます」「〜と言えるでしょう」、段落ごとの意味づけ（これは〜を示しています）、まとめの言い直しを足さない。
- 前置きの「重要なのは」「ポイントは」「注意すべき点として」は消して、中身をそのまま書く。

### 文の形
- 物を主語にして人の動詞をさせない（データが物語る、課題が浮き彫りになる）。誰が何をしたかで書く。
- 「AではなくB」「単なるAではない」は、誤解を正す所だけに使う（健康情報の誤解を正すのは本来の使い方）。1本に2回まで。
- 説明の項目を3つにそろえない。2つなら2つ、4つなら4つ書く。
- 中身のない短い断片の重ね（「シンプル。それだけ。」）で決め台詞を作らない。
- 「〜することができます」は「〜できます」にする。
- 同じ文末を3回続けない。主語を毎文入れない。
- 保険（「一概には言えませんが」「場合によっては」）は1文に1つまで。医学的な確かさのための留保は消さない。

### 言葉
- 硬い語や飾りの語を減らす：本質的、解像度、手触り、営み、多面的、包括的、画期的、〜において、活用する、実現する。
- 横文字のたとえ（思考のOSをアップデート、習慣をインストール）は普通の日本語に戻す。戻せるカタカナ語も戻す。
- 不自然なたとえ（静かに壊れる、地味に効く）、和語の名詞の作りすぎ（確かめ、直し、版）、英語の直訳（端のケース）を使わない。
- 「専門家によると」「研究が示すように」のような出典のぼかしをしない。出典は具体的に言うか、本人の考えとして書く。
- 文の中で作った呼び名（案A）を説明なしに使わない。

### 記号と見た目
- 短い文章に太字・見出し・箇条書きを使わない。読み上げる台本では、短い列挙は本文の中でつなぐ。
- 「**ラベル:** 内容」の箇条書きにしない。飾りの絵文字を撒かない。
- 形容詞や気持ちを「」で囲まない。「」は引用、キーフレーズ、本人のセリフだけ。
- 全角ダッシュ（——、──）は使わない。本人の見本で使われている場合だけ、その頻度の範囲で残す。

## 出す前の確認（1回だけ通して読む）

- [ ] 依頼・資料・本人の話にない体験、数字、論文、人名が入っていない
- [ ] 確かさが元のまま。結果を約束する言葉がない
- [ ] 最初の1文が答えか読み手の状況。テンプレの前置きとまとめがない
- [ ] 「AではなくB」は2回まで。3つそろえの列挙を疑った
- [ ] 太字・見出し・絵文字・ダッシュが場面と本人の見本に合っている
- [ ] 本人の一人称・口ぐせ・文末を均していない
- [ ] 声に出して読んで、息が続かない所と引っかかる所がない

規則の多くは、公開されている日本語推敲スキル（nihongo、yomiyasu、natural-japanese、stop-ai-slop-jp、humanizer-ja、real-person、いずれもMIT）を読み比べ、共通する所を言い直したもの。
