# 台本改善の6軸

元GPTのA「台本診断」では、原稿の実際の引用箇所を根拠に6軸をそれぞれ0〜5点で採点し、短い理由を付ける。原本が定めるのは観点と0〜5の尺度であり、点数の厳密なアンカーは未指定。使った基準を短く説明し、主観評価を実測の視聴成果と混同しない。原本の属人性の式は6要素の関係を示す考え方として扱い、点数を掛けた合計を実測指標のように作らない。

出典や経験が未確認の場合は、原稿上の示され方についての点と、事実確認の状態を分けて記す。「未確認」を「虚偽」と断定しない。軽微な修正など現在の明示依頼が限定的な場合は、不要な採点を加えない。

| 軸 | 確認すること | 改善の方向 | 避ける補い方 |
| --- | --- | --- | --- |
| 一次情報の引用 | 主張と出典が対応し、対象・限界が保たれているか | 必要箇所を確認し、言える範囲の表現へ直す | 引用数だけを増やす、架空の論文を足す |
| 本人だけが語れる体験 | 本人に由来し、今回の話に意味がある体験か | 登録済み体験の必要部分を使う。なくても解説で成立させる | 他人の原稿・論文の症例を本人の実話にする |
| 感情表現 | 視聴者の疑問や不安を理解でき、文章が平板すぎないか | 間、問い、具体的な場面の説明を調整する | 本人が感じたと未確認の感情を断定する、恐怖を誇張する |
| 解釈力 | 結果の紹介から視聴者にとっての意味へ説明できているか | 何が分かり、何がまだ分からないかをつなぐ | 著者の結論と本人の意見を混同する |
| 倫理と透明性 | 出典、条件、不確実性、利害関係等の必要情報が伝わるか | 原稿に関係する条件と限界を明確にする | 根拠のない万能な断言、実在患者の情報の不用意な追加 |
| 視聴者との関係性 | 対象に合い、問いに答え、押しつけになっていないか | 専門語、問いかけ、まとめ方を対象へ合わせる | 不安を煽って誘導する、視聴者を見下す |

## 評価を使う際の判断

- 本人の経験を入れる必要がない論文解説もある。「体験がない」だけで欠陥にしない。
- 一次論文が利用できない状況では、確認できた資料と限界を透明に扱っているかを評価する。未確認を確認済みに変えるための形式的な引用を足さない。
- 対象視聴者や動画の目的が違えば有効な説明量も変わる。一般向け原稿へ医師向けの方法論説明を一律に追加しない。
- 全文改稿が必要なほどの問題と、局所の言い換えで足りる問題を分ける。論旨に関係しない箇所まで全面的に改変しない。
- 改善後も残る重要な未確認事項を隠さない。評価表を埋めたことを医学的検証の完了と同一視しない。
