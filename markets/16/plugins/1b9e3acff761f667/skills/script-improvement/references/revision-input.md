# 第3段階：修正を喋って台本を仕上げる

「3回喋る」の第3段階として、初稿・改稿を読んだ本人の修正点を反映する。最新の台本HTMLと修正入力を特定し、同じチャットで読める資料の再添付は要求しない。版が曖昧な場合だけ最新版を確かめる。新規制作のインタビューからやり直さない。

音声・画面録画の発話が未取得なら、最初に[自動読み取り](../../voice-script/references/audio-runtime.md)を実行する。`ingest_audio.py`が必要な準備と文字起こしを行う。環境未導入を理由に本人へ全文提出を求めない。録画の音声を取得できても映像まで確認済みとはしない。

## 入力の照合

- **画面録画**：本人の発話時刻の画面で、選択・ハイライトされている文を最新台本と照合する。発話、時刻、選択文、修正意図の対応を残す。音声だけを取得した場合は、映像の選択箇所まで見えたと報告しない。
- **音声のみ**：読み上げた文、見出し、特徴的な語を最新台本と照合する。対象が一意なら進み、結論・対象範囲を変える曖昧さだけを確認する。
- **文章・文字起こし**：同等の修正指示として扱い、音声ファイルを改めて要求しない。

利用可能な読み取り機能で実際の取得範囲を確認する。映像が読めない場合は短い引用、見出し、スクリーンショット等で対象を補う。読める部分の修正は進める。添付成功を内容取得成功と同一視せず、全受講生へ動画解析が利用可能と保証しない。

## 反映と納品

[共通の制作管理](../../source-script/references/production.md) に従い、修正対象の引用／時刻・位置／変えたいこと／理由／暫定案・撤回・最終指示・承認／対応結果を追う。同じ論点の言い直しでは文脈上の最終指示を優先する。明確な部分は一覧への再承認を求めず進める。

医学的主張を変える部分は根拠も確認し、見出し・目次・順位・冒頭・結び・ダイジェスト・文献との整合を直す。指定範囲と無関係な合意済み文章を好みで書き直さない。3役レビューと全文通読は、改稿の実質と範囲に応じた既存の手順を守る。

[共通のHTML納品仕様](../../source-script/references/script-output.md) に従い、新版の全文HTMLと、反映した点・残る確認だけを短く返す。差分のみや別形式の指定は優先する。通常の音声修正に未依頼の長い診断・タイトル10案・追加質問票を重ねない。修正は同じ第3段階で何往復でも続けられる。

本人が納得した完成HTMLは、そのまま本人専用Projectの次の見本にできる。登録操作を実際に確認していなければ登録済みとせず、単発の修正を恒久的な本人ルールや共通プラグインへ自動保存しない。
