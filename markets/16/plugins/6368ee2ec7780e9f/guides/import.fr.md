# Importer vos cartes ChatGPT dans Study Daily

1. Dans la réponse ChatGPT, cliquez sur **Télécharger le fichier APKG** avant l’expiration du lien.
2. Gardez le fichier `.apkg` sans le décompresser. Sur Mac, Windows et Android, cherchez dans **Téléchargements**. Sur iPhone/iPad, enregistrez-le dans **Fichiers**, puis retrouvez le dossier choisi (par exemple Téléchargements).
3. Ouvrez **Study Daily** sur le même appareil. Si vous ne l’avez pas encore, [téléchargez Study Daily](https://get.studydaily.app/) pour réviser avec la répétition espacée.
4. Dans **Bibliothèque**, choisissez **Importer un fichier**, puis sélectionnez le fichier `.apkg` téléchargé.
5. Dans le dialogue **Importer un paquet Anki**, confirmez avec **Importer**.
6. Attendez **Import terminé**, puis retrouvez le paquet dans **Bibliothèque**. Ouvrez-le pour commencer la révision.

L’installation de Study Daily n’est pas nécessaire pour télécharger le fichier. L’import des cartes dans l’app est manuel : ChatGPT ne modifie pas votre collection. Les cartes générées sont nouvelles et n’incluent aucun historique de révision ni média.

Si le lien cesse de fonctionner, demandez une nouvelle génération. Si le fichier est introuvable, vérifiez que vous l’avez téléchargé sur cet appareil ; un fichier enregistré sur le Mac n’apparaît pas automatiquement sur l’iPhone. Gardez les fichiers et leurs liens privés si les cartes sont personnelles. Après téléchargement, votre copie reste utilisable même quand le lien expire.

Le même fichier peut être réimporté sans doublons. Une réponse modifiée produit une nouvelle carte : elle ne remplace pas une ancienne carte. Ne supprimez pas vos anciens paquets pour effectuer ce test.
