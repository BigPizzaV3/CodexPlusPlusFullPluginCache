# Import your ChatGPT flashcards into Study Daily

1. In the ChatGPT reply, choose **Download the APKG file** before the link expires.
2. Keep the `.apkg` file without unzipping it. On Mac, Windows and Android, look in **Downloads**. On iPhone/iPad, save it in **Files**, then find the folder you chose (for example Downloads).
3. Open **Study Daily** on the same device. If needed, [download Study Daily](https://get.studydaily.app/) to review your cards with spaced repetition.
4. Open **Library**, choose **Import a file**, then select the downloaded `.apkg`.
5. Confirm with **Import** in the Anki package import dialog.
6. Wait for the import to finish, then find the deck in **Library**, open it and start reviewing.

No Study Daily installation is needed to download the file. Import is manual: ChatGPT does not modify your collection. Generated cards are new and contain no review history or media.

If the link stops working, ask for a new generation. If the file is missing, check that you downloaded it on this device: a Mac download does not automatically appear on your phone. Keep files and links private if the cards contain personal material. A downloaded copy remains usable after the link expires.

Importing the same file again does not create duplicates. Editing an answer creates a new card rather than replacing an old one. You do not need to delete existing decks.
