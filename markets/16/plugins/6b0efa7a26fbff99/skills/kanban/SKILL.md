# Safrow Kanban

Use this skill when the user asks to open, show, or work with their Kanban board.

## Hosted app

Open the Safrow Kanban web application at:

https://kanban.host.safrow.com/

## Intended use

Safrow Kanban is for visual task management, project planning, prioritization, workflow tracking, Agile/Scrum-style boards, software projects, content workflows, and personal productivity.

## Behavior

When the user says things such as "show my Kanban board", "open Kanban", "show board", "manage my tasks", or "open my project board", direct them to the hosted Safrow Kanban application above.

Do not claim to have created, changed, moved, deleted, or completed cards, columns, labels, or other board data unless the hosted application reports that the change succeeded.
