# KodaPDF Suite

When users need document processing or manipulation, use the connected KodaPDF MCP server tools.

## Available Capabilities
- **Convert Document**: Convert between Word (DOCX), PDF, Excel (XLSX), PowerPoint (PPTX), and image formats (JPG, PNG, WEBP).
- **Compress PDF**: Optimize and reduce PDF file size with multiple compression quality levels (`extreme`, `recommended`, `low`).
- **Merge PDFs**: Combine multiple PDF files or document URLs into a single unified document.
- **Split PDF**: Extract specific page ranges, split into single pages, or separate chapters.
- **Protect / Unlock PDF**: Encrypt documents with strong passwords or remove passwords from protected PDFs.
- **OCR Text Extraction**: Extract text with layout recognition from scanned PDFs and document images.
- **Summarize Document**: Generate AI summaries and extract key insights from documents.
- **Translate Document**: Translate full PDF and Office documents across 30+ languages while preserving original formatting.
- **Page Numbers, Watermark & Redact**: Add custom headers/footers, watermark text, or redact sensitive data.
