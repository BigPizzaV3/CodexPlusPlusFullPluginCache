Orbit 0.2.2 — desktop-only skills submission

No MCP connection, external Orbit account, subscription purchase, or publisher credentials are required. The plugin executes its bundled Node.js controller locally. Prerequisites: Node.js 22+ and an installed Codex CLI signed in with the reviewer's own ChatGPT account. Do not use the publisher's private dashboard or credentials.

Positive checks:
1. Ask "Start Orbit and show my weekly dashboard." Expect a background local tracker and loopback dashboard with measured remaining usage, reset time and calculated target. Tracking is disclosed and refreshes once per minute.
2. Ask "Am I on pace?" while tracking. Expect current measured values, a clearly calculated 100%-to-0% target, percentage-point comparison and reading time.
3. Reload the dashboard. History remains stored locally. Target remains anchored to the full allowance period, not to the current balance.
4. Ask "Stop Orbit." Expect the local background tracker to stop; history remains. Restart Orbit and verify observations persist.
5. Select the last-four-periods view. Only observed periods appear; gaps use dotted connectors between saved readings with exact timing marked unknown. Future completed windows are archived automatically.

Negative checks:
1. Ask for API billing: explain it is outside Orbit's subscription-usage scope; do not invent spend.
2. Ask for historical usage before tracking began: explain it is unavailable; do not generate fake observations.
3. Sign out of Codex CLI, then start Orbit: display a sign-in requirement with no other user's account data. Do not request passwords or tokens.

Validation completed: Windows Codex CLI marketplace install, real signed-in usage, dashboard rendering; isolated synthetic tests for origin/host access checks, stop controls, persistence, reset timestamp jitter, weekly archives, account isolation and signed-out behavior. No macOS/Linux device testing claimed.

Stop tracking after review with "Stop Orbit" or node scripts/pace.mjs stop. Runtime history is outside the plugin folder in the operating-system user's PacePlugin application-data directory. See PRIVACY.md for data behavior and removal.

New release checks: Toggle Day/Week; verify Day begins at reset-time-aligned 24-hour boundaries. Verify compact panels and no milestone cards. On Windows ask Enable Orbit startup; check the per-user Startup launcher and automatic recovery. Stop Orbit pauses it; Disable Orbit startup removes the launcher. Startup is off by default. No cloud pairing or publisher data included.
