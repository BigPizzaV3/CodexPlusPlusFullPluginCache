# Gameplay acceptance checklist

- [ ] Main scene loads without blocking errors.
- [ ] Core input responds consistently, including focus recovery.
- [ ] Collision and movement behave as designed.
- [ ] Goals/progression are understandable and achievable.
- [ ] Score/health/resources remain within valid state ranges.
- [ ] Win/lose state occurs at specified conditions.
- [ ] Restart restores clean initial state.
- [ ] Pause/audio/settings function where included.
- [ ] Critical assets load with readable UI.
- [ ] Mobile/gamepad behavior verified if claimed.
- [ ] Actual shipped/exported build launches if release claimed.
- [ ] Rights/attribution register is complete.
- [ ] Evidence report records passed, failed and not-run checks.
