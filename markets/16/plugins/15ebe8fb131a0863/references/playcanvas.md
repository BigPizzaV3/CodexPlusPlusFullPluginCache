# PlayCanvas browser 3D reference

Official docs: https://developer.playcanvas.com/ and https://github.com/playcanvas/engine

PlayCanvas Engine is an open-source, JavaScript/TypeScript-friendly browser 3D engine with WebGL/WebGPU support. The hosted Editor and account/workspace have a distinct integration model. Pick code-first project by default if user just wants source.

Build minimal scene first: engine app/canvas, camera, lights, environment, controlled entity, interactions, game state. Check graphics backend, component registration, material handling and event APIs for installed version.

Test on browser with representative device input, runtime console, FPS/frame times, render fallback and asset failures. Keep assets modest and geometry/colliders sensible for first slice.
