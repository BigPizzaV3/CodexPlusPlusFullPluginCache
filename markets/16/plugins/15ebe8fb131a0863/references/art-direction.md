# Game-specific visual language

Specify style pillars, palettes, silhouettes, shape vocabulary, camera, scale, sprite pixel density, tile size, animation timing, lighting and UI treatment before acquiring assets. Avoid an uncurated collage of visuals.

2D: consistent sprite resolution/line weight, tile seam rules, animation states, nearest-neighbor filtering for pixel art, coherent UI typography and effects.
3D: consistent modeling scale, world units, topology, materials, UVs, lighting, collisions, animation rigs and LOD strategy.

The interface should communicate health, progress, hazards and choices under movement and at target screen sizes. UI styles are game-specific: no generic SaaS dashboards as game HUDs.

Reference sources may be used to understand style, not to copy protected game artwork. Check license for every third-party asset. Original generated images and music should follow the host's available tools and rights rules.
