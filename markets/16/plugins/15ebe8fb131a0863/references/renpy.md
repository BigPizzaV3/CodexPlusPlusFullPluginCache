# Ren'Py visual novels

Official quickstart: https://www.renpy.org/doc/html/quickstart.html
Build distributions: https://www.renpy.org/doc/html/build.html

Preserve `.rpy` and `.rpyc` conventions; use Ren'Py script variables, conditional choices and labels consistent with installed release. Design meaningful branches, state flags, rollback behavior and endings.

Use "Check Script (Lint)" from launcher or appropriate engine lint command; build via launcher/distribution tools when installed. Verify every ending and save/load path. Preserve images/audio rights and keep readability of dialogue as a first-class UX requirement.
