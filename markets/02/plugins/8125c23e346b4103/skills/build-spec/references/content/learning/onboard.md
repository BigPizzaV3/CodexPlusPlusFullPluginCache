# Start the guided build tool

This optional path helps you shape and build a stronger hackathon project without leaving Step 3: Resources. It will help you get to a proof of concept — it won't finish the thing for you; you'll keep working on it after. If you're newer to coding with AI, it's also a good way to get practice with the more structured best practices of doing it.

Answering by voice works great here: Codex interviews you, you talk, and Codex writes the docs. Use your operating system's built-in dictation, a third-party speech-to-text app — or, in the desktop app, click the microphone icon in the input bar. Longer, rambling answers are exactly the right material.

One tip on usage: plan and specify with your most powerful model, then hand execution to cheaper models or subagents once the work is specified.

Onboarding runs in a few short rounds of batched questions: first the essentials (your idea, if you have one, and your coding background), then a round to sharpen the idea, then an optional fun round — inspirations, look and feel, tone and vibe — where you answer whichever questions spark something and skip the rest freely.

Output: learner profile notes. Next: Scope — say you're ready, or type `$build-scope`.
