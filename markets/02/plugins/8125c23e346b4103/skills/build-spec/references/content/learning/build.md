# Build with Codex

Codex will execute the checklist according to the selected mode. It will keep changes scoped, verify as it goes, and pause when participant review is needed.

### You have a proof of concept — not a finished project

When the checklist is done, what you have is your proof of concept — now it's time for you to really work on it. You're in a freeform environment from here: start a new chat, prompt this app some more, make new changes, make it your own. You're only just getting started — this is the beginning. If the planning sequence was useful, run it yourself on your next round of changes until you have the best version of your project you can imagine.

Output: working project changes and verification notes. Once the checklist is complete and your project feels ready — not before — say so, or type `$prepare-submission`.
