# Review What Needs Attention

Use the exact heading **What may need attention based on FamilyWise data**.

1. Read setup status and only the FamilyWise sources relevant to the requested dates.
2. Report missing meal rows, incomplete setup sections, open routines or reminders, and list or schedule gaps only when the returned records support them.
3. State unavailable or stale data explicitly.
4. Label any suggested next step as advice.

Do not claim that everything forgotten was found. Do not create an opaque score, background job, notification, or write. Do not infer health, medical, custody, or private household concerns.
