# Let's Church plugin

This portable Agent Plugins package connects ChatGPT and Codex to the public, anonymous, read-only Let's Church MCP server at `https://lets.church/mcp`.

The package includes listing metadata, the Let's Church site icon, one Streamable HTTP MCP server, five positive review cases, and three negative review cases. No credentials or secrets are included.

Before submitting the plugin for public review, add a reviewer-accessible video walkthrough URL to `extensions.com.openai.review.demo_recording_url` in `plugin.json`, then increment the version if you have already uploaded version 1.0.0.
