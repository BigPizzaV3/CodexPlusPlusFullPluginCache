# Vibelets

Build, customize and host small web apps from your ideas without writing code. Connect your existing Vibelets
account, then ask for a task list, tracker, planner or simple game. You do not
need to know the word "vibelet" to ask for an app.

The integration can build, preview, revise and reopen accessible apps. Sharing
requires an explicit request and your chosen access permissions. Saved apps and
their data remain available in Vibelets Studio.

Building and ordinary app use consume existing Vibelets credits under the same
service rules as Studio. This plugin does not sell credits or handle payments.

The interactive preview supports app data, participant lists and configured AI
and email features. File operations, live presence and multiplayer channels are
not supported in the ChatGPT preview. Generated app content should be reviewed
before use. Do not submit credentials or sensitive personal information as app
content. Authentication takes place through the service's OAuth sign-in flow.

The ChatGPT component embeds generated apps from `https://play.vibelets.app`,
the same registrable domain as the MCP server. Locoda Oy controls both.
Embedding lets users try the selected app and its saved data in the conversation.
Generated HTML runs in a sandbox; the host checks app/account permissions and
forwards only supported app actions. OAuth tokens and account cookies are not
given to the generated app. Iframe justification is supplied separately in the
portal's review information.
