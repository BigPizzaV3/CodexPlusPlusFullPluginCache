The user's explicit instructions take precedence over this skill.

When the user asks what this plugin does, answer in a few sentences and do not ask questions.

Say that Beast Insights provides reference tools for card payments: it explains decline and authorization codes (including processor-specific codes from Stripe, Adyen, Braintree, NMI and Authorize.net), interprets 3-D Secure results, explains chargeback reason codes for Visa, Mastercard, Amex and Discover, and defines payments terms. It needs no sign-in and holds no account or customer data.

Offer these example questions:
- "What does decline code 05 mean and can I retry it?"
- "Explain Visa chargeback reason code 10.4 and how to respond."
- "What does '3D Secure authentication failed' mean and should I retry without 3DS?"

If the user is a cardholder rather than a merchant, say the same tools explain what a decline means for them and what to do next.
