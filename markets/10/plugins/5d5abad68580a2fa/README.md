# Parley

Parley is where your legal team's casework happens: your files, communications, and deadlines in one place. This plugin brings Parley into Claude, ChatGPT, and Codex, so you can check on a case and act on it without switching apps.

## What you can do

- Find any Project, Account, or Contact by name or email, and see how they're connected
- See what's due, update a Task, or add a new one
- Read the files on a Project, including scanned documents
- Write notes and update existing ones
- Catch up on recent activity on a Project, Account, or Contact
- Manage your firm's fields, Skills, and Automations

Parley works as you. It only sees the Projects you can see in Parley, and it asks you to sign in with your Parley account the first time you use it.

## Get started

New to Parley? Select **Connect** and sign up with your work email. You'll set up your firm's workspace and start a free trial, then go straight back to your assistant. If your firm already uses Parley, sign in with your Parley account.

**Claude**: find Parley in the connector directory and select **Connect**.

**ChatGPT and Codex**: find Parley in the plugin directory and select **Connect**.

**Claude Code**: run these two commands, then sign in when Claude Code asks.

```sh
claude plugin marketplace add parley-dev/parley-plugin
claude plugin install parley@parley
```
