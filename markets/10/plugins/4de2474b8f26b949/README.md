# HasData

Collect and compare public web data in ChatGPT or Codex using your HasData account. Research Google results, business listings and reviews, products, public social profiles and videos, property listings, jobs and travel.

Connect your HasData account when prompted. Requests use your HasData credits. You do not need to paste an API key into chat.

After installation, run Set up HasData to choose a first task in chat. You can try a business shortlist, an Amazon product comparison or Google search results, or describe your own task. Setup waits for your choice before making a data request. If you already supplied a task, it starts with that task instead.

Try these requests:

- Compare Google results for web scraping API and SERP API in Austin, Texas.
- Find five coworking spaces in Austin using Google Maps and compare their website links, ratings and review counts.
- Compare five USB-C docking stations listed on Amazon.com.
- Summarize a supplied YouTube video from its returned transcript.
- Compare Zillow listings matching my location and budget.
- Read a supplied public webpage and extract the fields I need.
- Find public Indeed job listings for a role and location.
- Compare hotel offers for my dates and travelers.

Results reflect the pages and records retrieved, not a complete inventory or guaranteed availability. HasData does not send messages, edit listings, make purchases or book travel.
