# Picsel OpenAI Plugin

Public distribution package for the Picsel MCP integration.

## MCP server

- Endpoint: https://mcp.picsel.app
- Transport: Streamable HTTP
- Authentication: none

## Tools

The live Picsel MCP currently exposes:

- `search_events`
- `search_content_by_bib`
- `search_content_by_selfie`
- `add_to_cart`
- `list_carts`

The package contains metadata and the connection configuration for the hosted MCP server. It does not contain the Picsel application or MCP implementation itself.
