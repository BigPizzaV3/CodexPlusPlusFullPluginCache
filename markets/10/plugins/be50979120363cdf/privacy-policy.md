# MA Commander Privacy Policy — Draft

Last updated: 2026-09-16

MA Commander connects a user-authorized computer to compatible AI clients through MCP and an optional self-hosted relay. The service is designed to minimize data collection and does not sell personal data or use command content for advertising.

## Data processed

Depending on the tools the user invokes, MA Commander may process file paths and file contents, process and system metadata, terminal output, screenshots, WSL workspace data, device identifiers, pairing metadata, and tool request/result data.

## Where data is stored

The Windows agent stores configuration and audit information on the user's computer. A configured relay may store device registration, hashed access grants, pending pairing records, and recent job records required for delivery and recovery. Relay operators are responsible for securing and retaining their relay data appropriately.

## User control

Users choose which computer is paired, can revoke pairing grants, can disable GUI input locally, and can uninstall the agent. High-risk capabilities remain separately permission-gated.
