# MA Commander Terms of Use — Draft

Last updated: 2026-09-16

MA Commander is software for controlling computers that the user owns or is explicitly authorized to administer. Users must not use it to access systems, accounts, files, or services without authorization.

The user remains responsible for reviewing actions that can modify files, run processes, control the GUI, or invoke privileged operations. MA Commander intentionally blocks or gates classes of destructive operations, but no software can eliminate all operational risk.

The privileged broker exposes only explicit MA Commander capabilities and is not intended to provide an unrestricted administrator shell. Pairing credentials and access grants must be kept private and revoked if compromise is suspected.

The software is provided under the repository license. Public plugin distribution may add service-specific terms before submission.
