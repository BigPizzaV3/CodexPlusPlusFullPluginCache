# MA Commander Support — Draft

For installation, pairing, relay deployment, security, or plugin issues, use the MA Commander repository issue tracker or the support contact that will be published with the Directory listing.

When reporting a problem, include the MA Commander version, operating system, whether the agent and broker health checks pass, whether a direct relay is configured, and the relevant non-secret error message. Do not publish access tokens, pairing grants, passwords, API keys, private file contents, or broker credentials.

Before public submission this page must be hosted at a stable HTTPS URL and the final support contact must be added to the submission metadata.
