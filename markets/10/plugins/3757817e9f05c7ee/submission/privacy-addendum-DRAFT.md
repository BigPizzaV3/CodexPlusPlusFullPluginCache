# Draft privacy addendum: Luma Assist ChatGPT catalog plugin

For PEMF Healing LLC review and publication. This file is not a published policy. It should qualify conflicting local-only statements in the main policy for this plugin.

Luma Assist in ChatGPT uses a remote AskGenie service hosted on Render. Explicit catalog requests send a minimal catalog title or keyword, optional category and result limit; statistics requests need no search term. Link checks send an exact returned catalog URL and contact its destination at epemf.app. Network infrastructure processes connection metadata transiently to deliver requests.

The skill excludes conversation history, personal identifiers, health records, images, biometrics, credentials, and other sensitive inputs from catalog calls. It does not select programs from personal health context or provide personal readings. OpenAI processes ChatGPT conversation content under its own applicable policies and account settings, separately from AskGenie. Closing a chat does not guarantee deletion of that conversation.

The publisher has confirmed that AskGenie and its Render hosting retain no queries, IP addresses, or request logs. Confirm this continues to match configuration before publishing this statement. Identify any additional processors and accurately describe retention and handling of support correspondence in the main policy. The plugin cannot delete ChatGPT history or change OpenAI account settings.

The plugin does not process purchases. Linked websites and app-store transactions are governed by their own policies. For publisher privacy questions, contact info@epemf.app. The publisher must review how the main policy's rights, eligibility, security, and international-transfer provisions apply to this remote plugin before publishing.
