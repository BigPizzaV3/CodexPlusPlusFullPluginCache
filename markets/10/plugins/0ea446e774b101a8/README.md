# Realy Data Analytics

Read-only analysis of authorized CSV tables through the hosted MCP at https://realy-mcp.vercel.app/mcp.
Sign in with the dedicated demo account supplied in the secure platform Reviewer credentials fields.
Open the existing Recent conversations item to inspect the saved biochemistry tables. Connect the MCP using the same account and discover scope before querying.
The review cases in plugin.json match the packaged biochemistry fixtures. Local expected-result checks do not establish live MCP execution or review approval.
