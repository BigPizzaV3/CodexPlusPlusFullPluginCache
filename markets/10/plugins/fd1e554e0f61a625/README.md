# FairCare OpenAI plugin submission

Public submission package for the production FairCare MCP connector.

- MCP endpoint: `https://www.mental-faircare.de/api/mcp`
- Authentication: OAuth 2.1 with dynamic client registration and PKCE
- Publisher: Sander te Nijenhuis
- Public review demo: `https://www.mental-faircare.de/review/faircare-chatgpt-demo.mp4`
- Packaged review demo: `assets/faircare-chatgpt-demo.mp4`

The review demo shows FairCare in ChatGPT's personal plugin directory, selects
the connector in a new chat, and exercises the confirmation-gated task flow.
The recording is cropped to the relevant ChatGPT content so unrelated account
and conversation data is not included.

Reviewer credentials and sign-in instructions are intentionally not stored in
this package. Enter them only in the secure review fields in the OpenAI Plugin
Portal.
