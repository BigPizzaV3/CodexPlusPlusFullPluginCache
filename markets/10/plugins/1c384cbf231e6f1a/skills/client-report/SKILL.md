---
name: client-report
description: Use when a freelancer, consultant or agency wants a finished Sitewalk audit turned into a short client-ready SEO report for a client or a manager: the site health score, the top problems in plain English and the links to the full report, PDF and CSV.
---

Turn a finished audit into a short report a non-technical reader can act on. Do not start a new audit for this.

1. Use the `audit_id` of the audit already discussed in this chat. If there is none, ask which site, then run the audit as usual first.
2. Call `get_audit_report`.
3. Write the report in this order: one sentence on the overall state of the site, with the health score if the report returns one; the three problems to fix first, each with what it is in plain English, how many pages it affects and the fix; then a short list of the remaining issues by impact.
4. Leave jargon out. Where a technical term is needed, explain it in a few words.
5. End with the full report link and the PDF and CSV links from the report, so the reader can open or forward them.

Use only the issues, counts, score and links the report returns. Do not add issues, traffic estimates or promises about rankings.
