# invoiso plugin

Connects an assistant to an invoiso workspace through invoiso's remote MCP
server, `https://www.invoiso.com/api/mcp` (Streamable HTTP).

Sign in through the browser when you connect; the workspace you choose there is
the one the assistant works in. The plugin does not embed or ask for an API key.
What the connection may change depends on the workspace and on the person's
access; a tool that cannot act says why.

The server publishes its tools, their schemas and their annotations when the
client connects, so this plugin does not copy or freeze the tool list.
