# Allo workflows

Use Allo for business phone-system operations through its connected MCP account.

## Connection requirement
- Use the connected Allo MCP tools for all Allo data and actions. Never use Computer Use, browser automation, or another website workflow as a substitute for the Allo MCP connector.
- If the Allo MCP tools are not available in the current host or chat, say the Allo connection is not active there and stop; do not claim to have accessed or changed Allo data.

## Account context
- Use the connected Allo account and its permissions.
- Retrieve account/team context when needed before making team-scoped changes.

## Conversations and CRM
- Search conversations and conversation items before summarizing or acting on customer history.
- Use CRM search to locate contacts when a customer identity is needed.
- Use notes, tags, summaries, and team threads to organize follow-up work.

## Operations
- Analytics, dialing queues, call routing, summary templates, AI agents, and calendars are authoritative only when returned by Allo.
- For destructive or externally visible actions, confirm ambiguous intent before acting.
- Never claim an action succeeded unless Allo confirms success.
- Distinguish retrieved information, proposed changes, and completed changes.
