# Aureic Properties trust boundaries

## Authoritative

- normalized records returned by the MCP server;
- catalogue version and integrity identifier;
- public Aureic URLs;
- stored price and availability verification dates;
- explicit limitations.

## Advisory

- all `aureic_assessment` content;
- lifestyle fit and relative trade-off explanations;
- selection order among otherwise matching results.

## Unsupported

- live availability;
- unpublished addresses or owner details;
- private and off-market inventory;
- legal title, planning or permitting conclusions;
- technical condition or survey conclusions;
- tax, financing, rental-yield or appreciation guarantees;
- viewing bookings, deposits and payments;
- any claim that a submitted enquiry confirms availability, creates a viewing
  appointment or reserves a property.

## Privacy

Catalogue tools read a bounded public catalogue and need no user account. The
separate enquiry tool may send only the user's reviewed name, email, optional
phone, optional budget, short message and selected public property after
explicit privacy consent. The server record is retained for no more than 60
days. Do not ask for passports, bank details, proof of funds, API credentials
or other sensitive data.
