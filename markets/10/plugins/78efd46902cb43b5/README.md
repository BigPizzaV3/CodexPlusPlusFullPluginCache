# Le Confidant — 0.5.0 preparation draft

Source for the existing plugin update. Incomplete for submission: replacement demo, fictional Pro/Advanced reviewer access, runtime activation and host verification are pending. This package does not deploy the service.

The intended contract has five public tools: WhatsApp links, formatting, decorative Unicode styling, number normalization and a fictional Wrapped demo. Inputs are processed remotely; no WhatsApp account access or message sending occurs.

Snapshot, analysis results and disconnect require explicit authorization of an existing completed analysis. All eligible plans expose quantitative statistics. Pro and Advanced additionally expose stored semantic results as allowlisted numbers and labels, including the applicable Client Audit or Deep Dive profile. The analysis card is ui://le-confidant/paid-results-v1.html.

Names, source messages, excerpts, written report content and real-period comparisons remain unavailable. No upload, new analysis or checkout is supported. Access expires and can be revoked; previously shared results remain in the assistant conversation.

Category, icons, countries and mixed-auth endpoint are retained. Nine positive and three negative cases are drafted, not verified host results. No app bindings or credentials are included; preserve the existing plugin identity and portal-generated bindings when updating. Reviewer credentials belong only in secure portal fields.
