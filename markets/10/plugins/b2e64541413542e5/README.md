# Littlebird plugin

Version: 0.1.3

This package connects directly to Littlebird's hosted MCP server at
`https://mcp.littlebird.ai/mcp` using Streamable HTTP. Littlebird handles OAuth
sign-in through the host client. The package has no separate application server
and contains no credentials.

The included skill guides use of meetings, saved work context, routines, and
account tools, using the connected server's actual capabilities and permissions.

## Connection

After importing the package through a supported host, connect the Littlebird
server and complete the browser sign-in flow. Use an eligible Littlebird account.
Confirm the discovered tools before testing the workflows. Public plan wording
currently differs between Littlebird pages; confirm eligibility with Littlebird
rather than relying on a particular plan name in this package.

The ZIP is structurally checked against Agent Plugins 1.0 schemas. Public review
readiness is separate: see the accompanying submission guide for outstanding
publisher facts, signed-in tool verification, demo recording, and reviewer access.
