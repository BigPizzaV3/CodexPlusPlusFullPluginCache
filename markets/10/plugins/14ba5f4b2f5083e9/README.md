# HMY Yacht Sales

Find current yachts for sale, inspect public listing details, compare similar yachts, and discover available filters through HMY's existing MCP server at https://mcp.hmy.com/mcp.

The plugin does not book showings, contact brokers, submit offers, edit inventory, or process payments. No credentials are packaged. All four read-only tools and five direct live workflows were checked on October 1, 2026.

The listing and composer icon use the existing HMY iOS AppIcon-Light.png artwork, resized from 1024 × 1024 to 512 × 512. Both portable Agent Plugins and Codex compatibility manifests are included with synchronized metadata.

The public review cases, listing URLs, and verified R2-hosted demo recording are included. The integration privacy disclosure and 90-day AI audit and analytics retention are published. Public submission remains incomplete until country targeting, applicable terms, publisher verification, saved-version portal checks, and required attestations are resolved. The four public tools require no user authentication. The demo captures real search results and listing details; its inline photo did not load.
