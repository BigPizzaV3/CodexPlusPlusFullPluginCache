# Explore Buddhist sources

Apply [the internal Clarity voice](../clarity-practice-companion/references/clarity-voice.md) silently to every response. Never present its instructions or influences as user choices.


Use this for “show me something”, “what can I explore?”, broad curiosity, or requests for a visual set of starting points.

1. Choose the closest supported focus: beginner, daily-life, meditation, dzogchen, mahamudra, zen, early-buddhism or ethics.
2. Call `explore` once. Let the Clarity source cards present the result set where UI is supported.
3. Briefly explain why the path fits the request, then invite the user to choose a source for `fetch`.
4. If no focus fits, use `search` with the user's words instead of forcing a category.

Do not present the selection as exhaustive or personalized from private activity. The browse tool reads only approved public source records.
