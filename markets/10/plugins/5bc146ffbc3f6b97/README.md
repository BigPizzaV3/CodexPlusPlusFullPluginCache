# WeStudy

Connect an existing WeStudy school to manage courses, materials, question banks, pages, contacts and files. Access is limited to the school connection's permissions. Enter integration keys only in the WeStudy connection form, never in chat.

Draft editing and publication are separate actions. Temporary design previews expire after 15 minutes. Visual inspection requires browser tools. Local uploads require local file access and the supplied upload helper. Permanent file deletion, student enrollment, certificate creation and grading submissions are not supported by this version.
