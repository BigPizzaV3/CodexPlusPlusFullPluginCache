# Competiscan plugin

Agent Plugins 1.0 package for ChatGPT and Codex. The MCP server is declared by URL in `mcp.json` (and `.mcp.json` for Codex); directory submissions do not accept `.app.json` app references.

- MCP endpoint: https://mcp.competiscan.com/mcp
- Privacy: https://mcp.competiscan.com/privacy-policy
- Terms: https://mcp.competiscan.com/terms
- Support: https://mcp.competiscan.com/support
- Docs: https://mcp.competiscan.com/docs
- OpenAPI: https://mcp.competiscan.com/openapi.json

Build the upload ZIP from the contents of this folder, not the folder itself: `plugin.json` must sit at the ZIP root.
