# Gorgias reviewer access

Use these non-secret access details in the OpenAI portal's private **Review
information → Reviewer credentials** form. This document is version controlled
and included in the plugin ZIP. Passwords, tokens, and email codes must not be
added to this document or the package.

## Reviewer account

- Reviewer email: `mcp-review@theaicompany.org`
- Login URL: <https://www.gorgias.com/login>
- Tenant: `modelcontextprotocol`
- Access flow: invitation and email-based account recovery using the reviewer
  mailbox.

## Sign-in steps supplied in the portal

An invitation was sent to `mcp-review@theaicompany.org` to join the Gorgias
`modelcontextprotocol` organization. Check the inbox and spam folder, accept
the invitation, and set up a password.

If the email was not received, open the login URL and select **Forgot
password?** to request a new email for the reviewer account.

## Demo account requirements

Prepare the demo account before submission with the permissions, sample data,
and subscription access needed to connect the plugin and run its test cases.
Reviewers must not need to register or configure an account themselves.

OpenAI may use this account for plugin review and ongoing safety and quality
testing. Use sample data only, never a real user account with production data.
Keep the account's permissions, test data, and subscription access working for
future reviews.

The invitation is recorded here; acceptance, password setup, and a successful
reviewer sign-in have not been verified in this workspace.
