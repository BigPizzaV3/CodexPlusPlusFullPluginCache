# Eli OpenAI submission pack

This pack is prepared for Eli's first public, read-only MCP-backed plugin submission.

## Files
- `plugin.json` — portable Agent Plugins manifest with listing copy, prompts, review cases, and release notes.
- `mcp.json` — production Eli public MCP connection.
- `SUPPORT_PAGE_COPY.md` — copy for `/support`.
- `TERMS_PAGE_DRAFT.md` — practical Terms draft; replace the legal placeholders before publishing.
- `REVIEW_VIDEO_SCRIPT.md` — reviewer video walkthrough.
- `OPENAI_PORTAL_CHECKLIST.md` — exact execution checklist.

## Two things intentionally not embedded in plugin.json
1. Demo recording URL — add after recording.
2. Logo/app icon — use the actual Eli brand asset, not a generated replacement.

## Do not submit until
- `/support` is live.
- `/terms` is live and legal placeholders are replaced.
- business verification is complete in the OpenAI organization that will own the plugin.
- MCP tool annotations have been checked.
- the demo recording URL is available.
