# Caprail submission package

Version 0.1.10. Publisher: MAXIMILIAN LEODOLTER. Availability: all available countries. No payments or purchases through the plugin.

Analyze website traffic in chat using create_site, list_sites, traffic_explorer, tracking_status and render_analytics. The package retains the analytics and installation skills, icons, endpoint, public listing URLs, default prompt and five positive/three negative review cases. The public description contains no pricing or promotions. The category is Data & Analytics, a supported category in OpenAI’s submission error reference. The listing leads with website traffic analytics. Portal metadata checks must be rerun after upload.

Demo recording: https://www.caprail.dev/review/caprail-demo-2026-10-04.mp4

The developer-supplied recording is hosted on the Caprail website, accessible without authentication, and verified to play in a browser. It shows site discovery, zero-count traffic results, request freshness, and an unsupported visitor-identification request. It does not establish successful execution of every review case or show the new trend/comparison components. Dedicated reviewer access and seeded fixtures remain unverified.

The MCP server and interactive components are served remotely. This ZIP supplies listing metadata and instructions. Creating this archive does not upload it to the portal or submit it for review.
