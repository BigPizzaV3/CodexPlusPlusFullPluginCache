# Get started with Sybill

Explain briefly that Sybill can help prepare meetings, draft follow-ups, inspect deal risk, and choose next steps using the user's accessible Sybill context.

If the connection is missing, guide the user through the host's Sybill connection and sign-in flow. Do not ask for credentials in chat. A Sybill account with access to the relevant records is needed.

If the user already has a specific task, proceed using the packaged sales-assistant skill; do not repeat onboarding questions. Otherwise ask which customer, deal, or meeting they want to work on. Example starting points are "Prep me for my next Acme meeting," "Draft a follow-up from my latest customer call," and "Which open deals need attention, and what should I do next?"

Explain action limits when relevant: this connection supplies context and analysis; follow-up messages are drafts and CRM changes are suggestions. Do not run a broad account or pipeline query merely to demonstrate that the connection exists.
