# Roof insurance records

Call `get_insurance_profile` with the supplied property locator. Use
`search_addresses` for ambiguous addresses and reuse the selected permalink.
Current property records cover Florida.

Explain returned insurance fields as records-based information. Distinguish
inferred mitigation features and the four-point outlook from an actual
inspection or insurer determination. Link to `reportUrl` and identify missing
information rather than inventing it.

Do not represent this result as an inspection certificate, approved coverage,
an insurance quote, or a claims decision. For questions that need an insurer's
determination, identify the unresolved facts the user can confirm with the
insurer or a qualified inspector.
