# GetRoofReport submission draft

This archive is for the OpenAI Platform submission dashboard. It declares
`https://getroofreport.com/public/mcp` directly in `mcp.json` using Streamable
HTTP with no authentication. It contains no `.app.json` dependency.

The six public tools are read-only. Seven skills cover general roof planning,
the interactive cost estimator, the color visualizer, address lookup, roof
records, storm risk, and insurance context. The full cost form calculates
estimates; the MCP tool does not return a quick price. Catalog images are
examples, and house photos are uploaded inside the website visualizer.

Calculator and visualizer launches are independent of property-record coverage.
Current address records cover Florida. Records do not constitute an on-site
inspection, a diagnosis of present roof damage, or an insurance determination.

The published
support and terms pages are included, and Other is the selected category for
homeowner roof planning. Portal confirmation of category fit is still required.
When preparation is complete, upload to the existing submission draft, wait for
the MCP scan and verify that all six tools are discovered. Draft upload, public
review submission and publication are separate actions.

Five positive and three negative review cases are included in the manifest.
They are drafted expectations, not verified host test results. The server
smoke tests are separate from running these prompts in ChatGPT.

The public walkthrough is https://share.descript.com/view/2KxxTx05WCn. It was
accessible without login and reviewed, and is included in the manifest. The
recording shows real tool launches and records responses, but does not verify
final calculated prices/color renders or the three negative review cases.
Remaining work includes these host checks and the developer's dashboard
verification and attestations. All four listing URLs are in the manifest;
unknown URLs and declarations have not been invented.

Publisher confirmed availability in all supported countries and estimates/quote
requests only. These declarations are in the manifest. The domain challenge
token is installed and its public endpoint was checked against the supplied
value; click Verify domain in the portal to complete that step.
