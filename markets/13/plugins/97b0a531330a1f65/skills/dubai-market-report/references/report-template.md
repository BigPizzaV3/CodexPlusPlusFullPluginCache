# Report skeleton

Fill what the data supports; delete rows and whole sections rather than writing
"n/a" across a report. Keep the stated window identical throughout.

```
# <Scope> - Dubai market briefing
Data window: <period>   |   Prepared <date>

## Headline
<3-4 sentences: where it is, which way it is moving, the one thing that matters.>

## Activity
Sale transactions      N        <+/-X% vs prior period, +/-X% YoY>
Total value            AED X
Off-plan share         X%       <+/-X pts>
Rent contracts         N        <+/-X% YoY>

## Pricing
                       Median price     Median AED/sqft    Deals
Studio                 AED X            AED Y              N
1 bed                  AED X            AED Y              N
2 bed                  AED X            AED Y              N
3 bed+                 AED X            AED Y              N

Movement over window   <+/-X%>
Off-plan vs ready      <spread in AED/sqft, and which way>

## Rents and yield
Median annual rent     AED X            <+/-X% over window, N contracts>
Gross yield            X.X%             <direction>
<One line if prices and rents are diverging - that divergence is the story.>

## Supply
Handed over in window  N units
Pipeline next 12-24m   N units
<One line on what that pipeline does to rents and absorption.>

## Leaders
1. <Project / building or area>   N deals   AED Y/sqft   <+/-X%>
2. ...
3. ...

## Peers
                       <Scope>     <Peer 1>    <Peer 2>    <Peer 3>
Median AED/sqft        X           X           X           X
Gross yield            X.X%        X.X%        X.X%        X.X%
Volume                 N           N           N           N
Movement               +X%         +X%         +X%         +X%

## Cycle and outlook
<Where the market sits. The read, then the counter-case, then what would
change it.>

## What it means
Buyers    - <2-3 lines>
Sellers   - <2-3 lines>
Investors - <2-3 lines>
```

## Notes on filling it

- Put the deal count next to every median. Where a count is under ~20, mark the
  figure as indicative in the text.
- Percentages are always "over the stated window" unless you explicitly label a
  YoY figure as YoY.
- The peers table only works when peers are genuinely comparable. Two well-chosen
  peers beat four arbitrary ones.
- If the pipeline section is empty because nothing is scheduled, say that
  explicitly - "no significant handovers scheduled" is a finding, not a gap.
