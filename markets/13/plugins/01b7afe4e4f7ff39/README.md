# Bettership for ChatGPT and Codex

Bettership is a personal AI workspace for ambitious professionals leveling up with online learning. This plugin brings what you're learning into ChatGPT and Codex. Ask about the courses, podcasts, articles, books and notes in your Bettership Library, and use the prompts, context packs and skills you've made from them without copying or installing files.

Requires Bettership Plus or Max. Sign in to Bettership when connecting and review the requested permissions. Start a new conversation and ask: **“Show me the items I've published in Bettership.”** Ask to use an item by name.

Publish items and revisions from Bettership Studio. Each new use reads the current published version. A task already underway keeps the version it started with. Disconnect in Bettership Settings to stop future reads; disconnecting cannot remove text already received by your AI tool.

The package contains the shared Bettership entry skill and one remote connection to `https://api.bettership.ai/mcp`. It runs no scripts or hooks and includes no learner content or credentials. It cannot add, change or delete anything in Bettership. Your learner profile, Focus Areas, practice history and Bettership conversations stay in Bettership. OpenAI can request your account email and whether it is verified to check workspace restrictions; that permission is shown when you connect.
