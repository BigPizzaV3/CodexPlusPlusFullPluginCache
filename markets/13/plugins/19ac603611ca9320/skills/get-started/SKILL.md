# Get started with Fragua Data Spain

Ask in plain language about a Spanish postal code, municipality or province.

Signing in requires an existing Fragua API account (username and password); there is no
sign-up inside the plugin.

- Market: "What are the residential market KPIs for postal code 28012?"
- Trends: "Show the buy price trend for 28012 over the last three years."
- Listings: "Find residential comparables for sale in postal code 28001."
- Demographics: "What are the demographic indicators for postal code 28001?"
- Cadastre: "Which streets in Madrid contain the word Embajadores?"

Data source: Fragua by Atlas Real Estate Analytics.
