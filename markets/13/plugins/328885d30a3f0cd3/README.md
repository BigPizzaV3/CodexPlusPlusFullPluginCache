# AnswerThis

Search scholarly literature, inspect available evidence, and prepare cited research
with AnswerThis. This plugin includes literature-review and research-gap skills,
plus the remote MCP connection at `https://api.answerthis.io/mcp`.

Start with a research question and ask for a literature review, a comparison of
studies, or evidence for a research gap. Source availability varies: distinguish
metadata and abstracts from verified full text, and check the cited sources before
using conclusions. Public search is available without sign-in, subject to usage
limits. Connect an AnswerThis account through the host's OAuth sign-in flow for
account tools.

Connected accounts can read and save library papers, create and edit cited Writer
drafts, and run screening, extraction, and persistent reviews. Account permissions,
source access, and usage limits apply. Ask explicitly before saving or changing
content. Review authorization requests in the host and in AnswerThis.
