# Set up Roamdesk

Read `references/planning-contract.md` first. Start with one useful next step and a short description of the available workflows. This is preference setup, not account registration.

1. Reuse details already in the conversation. Extract destination ideas, travel dates or duration, currency and budget, remote-work schedule with IANA time zones, workspace requirements, and companions or accessibility constraints if supplied.
2. Ask at most three bundled questions only for facts that change the next result. Accept rough dates and ranges for early planning. Never request passport numbers, account logins, full address, immigration documents, medical records, or payment details.
3. Create a compact brief: supplied facts, explicit assumptions, unresolved constraints, preferred outcome. Explain that dates and named time zones are needed for precise overlap. Citizenship or residence is optional and only relevant for a requested entry-rule research task.
4. Route to `choose-base`, `plan-budget`, `coordinate-hours`, or `land-and-work` based on the job. If several apply, propose a sensible order and complete the first useful result now.
5. Keep preferences in the conversation. Save a profile only when the user asks, using available file tools and the host-workspace rules. Do not claim persistent memory without host support.

Completion: a reusable brief and a completed first step, or a narrowly scoped question for a required missing input. If the user already gave a specific task, skip onboarding questions and run that task.
