# Flywheel calculator review package 0.2.1

Six narrow calculation/access tools. Public maintenance, GOM/locks and reinvestment tools need no account. Day Two+ PLUS requires active paid PLUS or Founder; Horizons requires eligible PLUS/Founder access, including eligible trial/preview. Saved plans, provider accounts, wallets and transactions are unavailable.

Use the complete fictional-inputs.json and expected-calculations.json files. Five positive and three negative cases are imported from plugin.json. Private reviewer credentials and sign-in instructions are supplied only in the portal, never in this ZIP.
