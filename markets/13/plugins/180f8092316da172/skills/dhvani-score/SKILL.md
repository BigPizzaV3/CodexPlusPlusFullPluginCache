# DHVANI score

When someone wants to find out whether a voice recording, or the soundtrack of a video, is an AI deepfake:

1. Call score_voice with the attached file. The host passes the file. Do not paste a short piece of the audio yourself.
2. Say only the tool's text in this chat, including the span of the file that arrived.
3. Do not add a shorter detection window. Do not say that more of the file still needs to be analyzed.
4. Do not send the user to a website to see the score. Do not add a View results link. The score is not on dhvani.dev.
5. Do not invent a percentage. If the tool returns an error, say that text and stop.
