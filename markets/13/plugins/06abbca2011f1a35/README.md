# ABIS Interior

Public Korean interior planning answers, style categories and verified human consultation links.

The remote Streamable HTTP endpoint is https://abis.now/api/mcp/public. No login, API key, local runtime or lifecycle hook is required.

Tools: search_interior_answers, get_interior_answer, get_interior_styles, get_consultation_options. They read public service information only and do not access customer workspaces, photos, contact details or application records. The host AI can explain the returned material and cite its public source URLs. The separate ABIS website offers OpenAI-powered question answering and Google-authenticated photo design.

Consultation telephone: 010-5651-8804. Callback requests are submitted by the user at https://abis.now/consultation. They are reviewed by a human and do not confirm an appointment or contract.

Support: https://abis.now/support
Privacy: https://abis.now/legal/privacy
Terms: https://abis.now/legal/terms

This ZIP is a distribution package. Public OpenAI directory publication is a separate verification and review process; hosting this package does not imply directory approval.

Review walkthrough: https://abis.now/review/abis-mcp-walkthrough.mp4. The video presents captured browser states from five successful public MCP flows and three scope checks. It does not claim that a public directory review or ChatGPT installation has been completed.
