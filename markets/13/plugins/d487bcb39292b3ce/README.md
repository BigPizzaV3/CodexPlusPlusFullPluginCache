# Zopley

Navigate Zopley's public pages and manage your own rooms, media library and notification preferences through its remote MCP server.

Use the setup skill after installation. Public navigation needs no account. Private tools use the host's OAuth connection flow, scoped to your Zopley account. Never paste a password or access token into chat.

The server decides which tools your connection can use. User-requested changes follow the account's persisted approval preference, automatic by default. In manual mode, the owner confirms and executes exact changes inside the Zopley chat. Ownership, scopes, plan limits, revocation and idempotency always apply. Billing, account deletion, private data from other accounts and administrator operations are unavailable. Video playback takes place in Zopley or supported media services, not inside ChatGPT.

This package contains no executable hooks, local services, credentials or AI API calls. Installation does not establish publication or review approval.
