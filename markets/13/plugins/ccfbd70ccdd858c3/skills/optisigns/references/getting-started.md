## Set up screens

- Getting Started Guide: pair a screen, upload content, push to display — install the player (OptiStick, existing hardware, or a laptop), enter the pairing code at app.optisigns.com, upload files, then assign an asset, playlist or schedule — https://support.optisigns.com/hc/en-us/articles/18823504383891
- Use a Mac or Windows laptop as a test screen — try OptiSigns with the desktop player before deploying to real screens — https://support.optisigns.com/hc/en-us/articles/360021856013
- Full list of supported hardware and devices — OptiSigns players plus Android, Amazon Fire, Windows, macOS, Linux, Raspberry Pi, ChromeOS, BrightSign, LG webOS, Samsung and more — https://support.optisigns.com/hc/en-us/articles/360021855653
- Configure Wi-Fi on an OptiSigns Android player with the Admin app — push Wi-Fi details from your phone to a pre-configured player with no connection — https://support.optisigns.com/hc/en-us/articles/4409607912211
- Rotate a screen to portrait or landscape — set 0, 90, 180 or 270 degrees in Edit Screen or on the device; design content to match — https://support.optisigns.com/hc/en-us/articles/360016833514
- Manage screens, media and playlists from the mobile app — the OptiSigns Admin app (iOS, Android) pairs screens, assigns content, uploads files and works as a Bluetooth remote — https://support.optisigns.com/hc/en-us/articles/30003143806099
- Start a 14-day trial with Pro Plus features — sign up at app.optisigns.com for 14 days of Pro Plus with 2 screens and 1 GB; afterwards the account moves to the Free Plan unless a paid plan is chosen — https://support.optisigns.com/hc/en-us/articles/37966066335891
- Free Plan features, supported devices and limits — 3 screens, 25 apps, 1 GB, playlists, no expiry; no schedules or split screen; runs on OptiSigns players, Windows, Linux, Raspberry Pi and macOS only — https://support.optisigns.com/hc/en-us/articles/33940834613139
