# Preflight

Run this after the user approves the design, before anything is uploaded or published. Show it, then
ask for a clear yes. On yes, write the hand-off block (handoff.md) and follow optisigns-operate.

```
## Ready check
- Format: <PDF | PPTX | PNG set | web page | built-in app>, because <one line>
- Slides: "<headline>" / <seconds> s, one line per slide
- Canvas: <1920×1080 | 1080×1920>, nothing important within 5% of an edge
- Facts: all from you | assumed: <list>
- Upload: <file name> → folder <path | root>
- Screens: <names checked with optisigns_screen_search | ask>
- When: <now | schedule>
```

- A web page must fit one viewport with no scroll and open at a public https URL (web-app.md).
- Any change after this: fix it and show the check again.
