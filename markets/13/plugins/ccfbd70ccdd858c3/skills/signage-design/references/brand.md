# Brand

- Use what the user gives: pasted colors and fonts, or a PDF, PPTX, brand guide, website or logo to
  extract them from. Say what you took and from where.
- No brand given: pick a look that fits the occasion and say you did; ask once whether they have a
  logo or colors.
- Logos: only the user's own file. Never redraw, trace, stretch or recolor one. No file → no logo.
- A licensed font the tool lacks → the closest Google Font, and say so ("Gotham → Montserrat").
- There is no OptiSigns tool that stores a brand today. Don't call or name one.
- Never save the brand silently or claim it is saved. After the user approves a design, offer to keep
  it, as a short block they can paste next time:

```
# Brand card
- Primary: #0B2545   Secondary: #F26419   Accent: #F5F3EE   Background: #0B2545
- Heading font: Montserrat Bold   Body font: Open Sans
- Logo: top-left, light version on dark backgrounds
- Source: extracted from "Q3 all-hands.pptx" on 2026-11-01
```

  If the host can store it (a project, memory or design system, see host-tools.md), use that only when
  the user says yes.
