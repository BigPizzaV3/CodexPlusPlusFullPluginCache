# Uptime Academy

Practical help with AI, work and life, drawn from Uptime's learning library.
Explore ideas from books, courses and podcasts, then put them to work in your
own situation.

## Connect and start

1. Install **Uptime Academy**.
2. Choose **Set up Uptime Academy** and complete Uptime’s sign-in page.
3. Ask your learning question.

For example: “I work in marketing. How can GitHub help me review a website
change?” Or: “Show me the Uptime Hack of Atomic Habits.”

Never paste a sign-in code or password into chat. Adding a ZIP installs the
plugin; Uptime sign-in connects your account.

Your questions can be in your own language. Say **“show memory”** to see your
saved learning context, or **“clear memory”** to remove it. Opening a Hack may
depend on your Uptime membership.
