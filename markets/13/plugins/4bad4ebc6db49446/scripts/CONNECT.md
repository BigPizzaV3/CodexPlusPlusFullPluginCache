# Reconnect an account

Follow [Account connection and permissions](AUTHENTICATION.md), including its
startup Unknown tool recovery. Always give a clickable connection link and the
Settings → Plugins → Eye.Photo → Connect path. Explain
sign-in, studio approval, and returning to continue the original request.
Use CONNECTION.json only when its installed-plugin settings URL validates as
described there. Otherwise use https://chatgpt.com/settings/plugins-settings.
Never start a raw MCP/CLI login or diagnose a host lookup failure as a code defect.
