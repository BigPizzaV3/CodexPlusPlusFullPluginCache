## Long description

From first client conversation to final payment, connect MoodLens To-Do to
ChatGPT and manage client work directly from the conversation.

Review client prospects and create or update project boards, tasks, contracts,
proposals, documents, sprints, comments, subtasks, and tracked time without
manually moving information around.

Tell ChatGPT what happened with a client and it can take the next action inside
your MoodLens workspace—from preparing a proposal and contract to coordinating
the work and tracking delivery.

MoodLens is built for freelancers and agencies that want AI to do more than
answer questions. It gives ChatGPT the context and tools to help run the client
workflow.

MoodLens only accesses data available to the connected account, and every
action follows that workspace's permissions.

## Starter prompts

1. Show my open MoodLens tasks and group them by priority.
2. Summarize my active sprint and flag blocked work.
3. Create a MoodLens task from this conversation after confirming the details.

## Capability summary

Read capabilities include tasks, client prospects, documents, form responses,
team members, columns, workspaces, integration metadata, boards, sprints,
proposals, contracts, comments, and workspace information.

Write capabilities include creating and updating supported work items,
documents, boards, columns, sprints, proposals, contracts, comments, subtasks, and task
timers. The server also exposes archive, delete, publish, unpublish, reorder,
and replacement operations. Destructive and externally visible actions are
identified in each MCP tool's annotations so the host can request confirmation.
