Install or update it through the supported plugin interface and complete the
connection authorization when prompted. When replacing an uploaded version,
identify that exact copy in plugin settings; preserve separate environments.

Start with a data task, for example:
“List the Spaces I can access and let me choose one for this conversation.”

Package preparation does not establish public approval or cloud tool availability.
