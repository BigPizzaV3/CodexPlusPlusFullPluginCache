# Keep campaigns running

This team cannot run in the Kenso app for ChatGPT: its actions and proposals use agent team operations these tools do not include. Say so plainly, and do not try to do its work with other tools.

To run it, the person opens the Agent team page, https://app.ken.so/<workspace id>/demo/agent-team (it opens where the workspace has agent templates on), picks Keep campaigns running on the Templates tab and clicks Run in your own tool. That sheet connects Kenso to the tool they pick, Claude or ChatGPT, with the MCP URL and a key, and gives the starter prompt.

Here you can still read the live campaigns with the campaign and analytics tools: leads, sends, replies and sending health. Any change to a campaign's leads, volume, schedule, inboxes or copy is made in the app, and a schedule or volume change on a client's campaign needs the client's named yes.
