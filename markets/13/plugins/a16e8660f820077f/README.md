# Runpod

Manage your Runpod account from ChatGPT and Codex: check GPU and CPU types, prices and live stock, run and control Pods, deploy Serverless endpoints and run jobs, and manage templates, storage and billing.

The plugin connects to the hosted Runpod MCP server at `https://mcp.runpod.io/directory`. You sign in with your Runpod account (OAuth), so no API key is stored.

- Docs: https://docs.runpod.io/get-started/mcp-servers
- Support: https://www.runpod.io/contact
- Privacy policy: https://www.runpod.io/legal/privacy-policy
