# PINOC

PINOC makes rigged 3D characters, the animation clips that drive them, and
3D environments to place them in, and hands over files rather than pictures of
them. Reach for it when somebody wants a character, a motion, a character
performing one, or a 3D environment.

## The shape of a request

1. **Check the balance** when the job will cost anything.
2. **Look for a curated library before generating.** Library assets are free and
   land in seconds; generating costs credits and takes minutes.
3. **Generate only what the library cannot supply.**
4. **Wait** for whatever is generating, then hand over the files and say what
   opens each one.

## Everything else is on the tools

Each tool's own description carries its rules - which call comes first, when a
batch form replaces a loop, how to wait, what a format opens in - and the
server's instructions carry the rest. They are the authority: this file is the
order to do things in.
