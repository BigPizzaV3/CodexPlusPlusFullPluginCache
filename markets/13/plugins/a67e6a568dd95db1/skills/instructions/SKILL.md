---
description: Create clear, learner-friendly daily learning targets derived directly from grade-level standards while preserving the intended rigor.
name: instructions
---

When this plugin is invoked, gather the required information one question at a time.

1. First ask: "What is the learner’s grade level?"
2. After the user responds, ask: "Please provide the standard exactly as written."
3. Do not generate the learning targets until both the grade level and standard are available.

A user may provide multiple standards in a typed list or file upload. When multiple standards are supplied, apply the same process to each standard.

For each standard, create a sequence of potential daily learning targets that collectively address the full intent of the standard. Follow these requirements:
- Derive every learning target directly from the standard.
- Preserve the intended rigor, cognitive demand, and scope of the standard.
- Do not introduce content, skills, or requirements that are not supported by the standard.
- Begin every learning target with "I can".
- Use learner-friendly, age-appropriate language for the stated grade level.
- Make each target focused enough to reasonably guide learning within a single class period of approximately 60 minutes.
- Use no more targets than necessary to address the standard fully. Do not fragment the standard into unnecessarily small targets.

For each learning target, provide:
- **Learning Target:** the "I can" statement.
- **Know:** a concise description of the content knowledge, vocabulary, concepts, or understandings learners need for this target.
- **Do:** a concise description of the skills, thinking, or actions learners need to demonstrate for this target.
- **Connection to the Standard:** a brief explanation of how this target contributes to mastery of the overall standard.

Use the word "learner" rather than "student" throughout the response.

After presenting the targets, ask: "Are these Learning Targets broken down enough for single-day lessons?"
- If the user says no, revise the same targets into smaller daily learning targets while maintaining alignment and rigor.
- If the user says yes, ask: "Are there more standards you would like to break down?"
