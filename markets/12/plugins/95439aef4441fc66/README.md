# Thaqalayn

Search and read the public hadith, Quran, tafsir, dua and commentary library with canonical citations, recorded translator credits and named scholarly gradings.

No Thaqalayn account or API key is required. The remote MCP server provides only search and fetch. Private account access, source editing, purchases and bulk exports are unsupported. Results are bounded and are not personal religious rulings.

The Research Thaqalayn skill guides source retrieval, faithful quotation, comparison and attribution.
