# A+ and product detail design

Adapted from A+ Detail Page in the [Designkit Skills catalog](https://www.designkit.com/skills).

## Understand the product and page

Start from usable product photos, supported selling points, target platform, sales region, copy language, and the user's module or page requirements. Ask only for missing information that materially changes the content. The website form requires product images and a target format; it shows Standard A+ 970:600 as one option, not a requirement for every platform. Confirm or use the requested format instead of assuming all detail pages share that ratio.

Organize supplied facts into a clear story, for example: product promise, principal benefits, detail proof, use context, and practical specifications. Propose a short module outline when the user needs help choosing one. Preserve an outline they already approved. For comparisons, use only supplied or verifiable facts; do not fabricate competitor results, clinical evidence, testimonials, certifications, or missing dimensions.

## Generate the visual modules

Read [the MCP workflow](mcp-workflow.md). Pass the product references, agreed module order/count, language, format, exact approved copy, and a consistent visual direction in one Designkit task. Keep text concise enough to support the design. Let Designkit return any real option or custom-card question and continue with its trusted context.

Clarify whether the user wants a continuous detail-page concept or separate module images when that distinction is essential and unspecified. Do not imply that asking for a design also deploys an HTML page or updates a live storefront.

## Deliver and refine

Present real module previews in order, with original links and the room link. If some modules are still generating or failed, distinguish them. Revise an individual module in the same room when asked. A preview image is not proof of an editable source file or platform compliance; promise those only when the actual result provides them. For a user explicitly requesting marketplace specifications beyond the supplied brief, verify the current rules before representing the design as compliant.
