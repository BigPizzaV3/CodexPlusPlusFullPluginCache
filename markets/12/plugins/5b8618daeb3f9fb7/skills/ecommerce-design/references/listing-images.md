# Product listing images

Adapted from the Product Image Set, White Background Photos, Product Variants, and Image Remix workflows in the [Designkit Skills catalog](https://www.designkit.com/skills).

## Build a useful brief

Use product photos as the source of truth for shape, packaging, labels, and included accessories. Ask for a photo when faithful depiction of an existing product is required and none is usable. If the user explicitly wants a fictional product or concept, proceed without presenting it as a photographed real item.

Reuse supplied context. Ask only for missing details that change the design: target marketplace, image count/types, copy language, market, key selling points, or essential product facts. Suggest a sensible mix of main, feature, and lifestyle images when the user has not chosen one; respect their requested quantity. Use platform/market defaults only after stating the assumption where it affects output. The website's form offers 1:1, 3:4, 16:9, and 9:16; use the user's actual format, not a universal fixed size.

For an Amazon-style main image, request a clean product-focused treatment without invented badges, text, or accessories. Treat this as a design brief, not a guarantee of marketplace approval. Do not invent measurements, certifications, discounts, customer ratings, or performance claims. For variants, confirm which colors or configurations are real rather than creating nonexistent saleable SKUs.

## Execute one coordinated set

Read [the MCP workflow](mcp-workflow.md) before submitting or revising a task. Send one coherent brief containing the product facts, input images, ordered image roles, count, aspect ratio, copy language, and shared visual direction. Let the Designkit agent resolve its creative execution and actual follow-up questions; do not run a second competing planning interview.

For style references, transfer composition or visual direction while preserving the user's product and authorized branding. Do not promise pixel-identical recreation of a reference.

## Deliver

Show real generated images with their role labels and original links. Identify whether the requested set is complete. Offer the next relevant action, such as changing one feature frame or adapting a size, and revise the existing room when requested. Never claim to have uploaded a listing to Amazon, Shopify, or another storefront.
