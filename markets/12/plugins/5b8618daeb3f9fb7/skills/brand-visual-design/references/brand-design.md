# Brand visual design

Adapted from Brand Guidelines, Logo Design, Logo Mockups, Packaging Design, Character Design, and Sticker Pack in the [Designkit Skills catalog](https://www.designkit.com/skills).

## Establish what to preserve

Determine whether this is an existing identity, a new identity concept, packaging mockups, or a character/sticker system. Reuse the provided brand name, audience, positioning, tone, colors, logo, and requested applications. Ask only for missing choices that materially affect the result.

For existing brands, obtain the supplied logo/assets when faithful reproduction is required; the website Brand Guidelines workflow requires brand assets and offers a configurable page count. Do not invent access to a brand kit or replace an existing logo without the user requesting a redesign. For a new fictional brand or explicit new-logo request, concept generation can start from a complete text brief.

Pick the requested deliverables rather than automatically creating all of them. A brief may request logo directions, a color/type mood board, example guidelines, packaging mockups, or coordinated character poses. State page/variation counts and allowed brand changes. Describe typography direction without claiming a font license is included.

## Produce consistent concepts

Read [the MCP workflow](mcp-workflow.md). Send the brand constraints, actual assets, chosen deliverables, count, language, and application context in one coherent Designkit task. Treat professional execution and follow-up choices as Designkit's workflow. Preserve approved visual direction when the user requests further applications.

For packaging, separate a visual concept from a manufactured dieline. Ask for actual dimensions and production constraints if the user needs a specific package. Do not label an image as a vector logo, editable brand source, press-ready file, or accessible identity system unless the returned artifact and validation establish it. Do not claim trademark availability, ownership, or legal clearance.

## Present and continue

Show the actual concept previews with original links and the room link. Briefly explain the visual choices visible in the outputs, without asserting unobserved qualities. Distinguish concepts from final production assets. Apply the user's selected direction and revisions within the existing room rather than starting disconnected projects.
