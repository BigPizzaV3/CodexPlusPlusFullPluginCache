# Offera.ai

Plugin conectado ao servidor MCP público do Offera.ai para buscar cupons de desconto de lojas online brasileiras.

## Conexão

- Endpoint: https://offera.virtuesplay.us/coupons/mcp
- Transporte: MCP Streamable HTTP.
- Autenticação: sem login (No sign-in).
- Operações: somente leitura; nenhuma escrita e nenhum dado de usuário.
- Site: https://offera.ai/commerce/
- Termos: https://offera.ai/commerce/termos
- Privacidade: https://offera.ai/commerce/privacidade
- Suporte: https://offera.ai/commerce/contato

## Ferramentas

search_coupons, get_coupon, list_coupon_stores, search, fetch.

## Limites

Os cupons vêm de fontes públicas e as lojas podem encerrá-los antes do prazo.
Códigos e regras devem ser sempre confirmados na página da loja. Os links podem
levar à loja por meio de link de afiliado do Offera.
