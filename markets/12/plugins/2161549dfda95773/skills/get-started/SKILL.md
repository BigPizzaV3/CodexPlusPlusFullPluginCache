# Get started with Lucius

Lucius reads public procurement for companies that bid on public contracts.

1. Search the open tenders: give words for what you sell, and optionally countries, a source,
   a CPV code or how soon the tender closes. Each result has the buyer, country, deadline,
   value where published, a short description and a link to the buyer's own notice.
2. Open one tender for its details, or ask for tenders similar to it.
3. Ask Lucius to analyse a tender from your search, or send a public link to a tender pack
   (a PDF, Word or Excel file, a ZIP, or the notice page), to have Lucius read it. The analysis takes a few minutes; ask for it again to get the
   requirements, each tied to the page it was read on. Each analysis uses one of your
   workspace's monthly analyses, like an upload in the Lucius app.

Lucius never submits a bid, edits a tender or sends anything on your behalf.
