# Media projects

A media project is a set of different pieces of content made together for one topic or goal: a
product launch with a post, a carousel and a Reel; a week of posts for a campaign; one idea cut for
Instagram, TikTok and LinkedIn. It is what the user gets when they ask for many connected pieces at
once.

## When to make one

- **Several connected pieces for one topic or goal:** one media project. Ask for the whole set in
  one request, so the pieces come back together and fit each other.
- **One post, one carousel, one video:** just that piece, without a project around it.

## Its shape

A project groups its pieces into sections by kind. Each piece has a version per platform, such as a
Reel and a TikTok cut of the same idea. A piece Kinetik could not make yet says what the user still
has to bring.

## Coming back to it

Projects outlive the chat. When the user mentions one ("the launch pack", "last week's campaign"),
find it before changing it, and change only the piece they mean; the rest of the set stays as it is.
Show the project whole when they want to see it whole.
