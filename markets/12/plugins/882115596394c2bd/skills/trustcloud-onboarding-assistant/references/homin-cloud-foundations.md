# Homin Cloud 基礎概念

## 1. Homin Cloud は何をするサービスか

Homin Cloud は、住宅会社のイベント集客と来場予約運用を一体で進めるための運用基盤。

- 集客導線: イベント LP を使って広告/SNS 流入を受ける
- 予約転換: カレンダー枠に基づいて予約を受け付ける
- 現場運用: 開催場所、担当者、通知、予約状況を運用に接続する
- 改善: 予約状況を見ながら LP や運用設定を改善する

## 2. 主要概念

### Calendar

予約可能枠を定義する供給モデル。

- 何曜日に何時から何時まで予約を受けるか
- 特定日を休業/特別営業にするか
- 予約可能性を機械的に判定する土台

### 開催場所 (Event location)

イベントの実施場所情報。

- 住所や会場情報を管理する
- 「どの会場で開催するか」をイベントに紐づける
- 来場案内や現場運用の基準点になる

### Event

キャンペーン運用の中心単位。

- 開催期間、タイトル、説明、ステータス（下書き/公開）を持つ
- 開催場所や LP、予約導線と接続される
- 公開すると顧客向け導線として機能する

### Event LP

集客と予約転換のためのランディングページ。

- 来場メリットや訴求を伝える
- 予約行動へ誘導する
- Event と整合して運用される

## 3. どう使うと価値が出るか

公開までの初期設定を支援する場合の最小構成は次の順。

1. 開催場所を確認
2. イベント下書きを作成
3. 予約できる時間を確認
4. LP 下書きを作成
5. 公開判断 -> 公開

この流れで進めると、設定漏れを減らしつつ最短で公開まで到達できる。
