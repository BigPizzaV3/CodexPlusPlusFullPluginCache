# Подключение Sava к ChatGPT

Состояние: production-релиз активен, пройдены 66 smoke-проверок, включая
официальный MCP SDK и все семь tools. Владелец сообщил об успешных тестах ChatGPT;
агент отдельно не записывал их UI-трассу. Публичная заявка пока не отправлена.

Теперь можно выполнить реальное подключение:

1. Откройте ChatGPT → **Plugins** → **+** → **Add custom MCP server**.
2. Название: **Sava Portugal**. Описание: **New-build homes in Portugal**.
3. Выберите публичный HTTPS endpoint и вставьте **https://sava.pt/api/mcp/**.
4. Authentication: **No authentication / None**. OAuth и API key не нужны.
5. Прочитайте предупреждение, отметьте **I understand and want to continue**,
   нажмите **Create as a plugin**.
6. Проверьте обнаружение ровно семи инструментов. Установите полученный плагин
   из personal plugins кнопкой **+**.
7. Создайте новый **Work** chat, введите **@** и выберите **Sava Portugal**.
8. Выполните сценарии из `USER-TESTS.md`. Запишите выбранные tools, аргументы,
   результаты, дату, интерфейс и версию клиента. Само появление плагина в списке
   не подтверждает успешный вызов инструментов.
9. Если инструменты менялись, откройте подключение → **Refresh**, затем создайте
   новый чат. При ошибке подключения сохраните текст ошибки и время; не
   переключайте сервер на OAuth ради обхода транспортной ошибки.

Это актуальный путь из [OpenAI Docs](https://developers.openai.com/plugins/deploy/connect-chatgpt).
Если нужные пункты отсутствуют, проверьте разрешения аккаунта/workspace и доступ
к Plugins/Work; названия пунктов могут отличаться между интерфейсами.

## Публичный каталог OpenAI — отдельный шаг

Для личного UI-теста публичная публикация ZIP не требуется. Для публикации:

- В OpenAI developer dashboard выберите организацию/проект и подтверждённую
  individual/business identity. У пользователя должны быть права на управление
  плагинами. Sava — бренд; юридическое имя издателя должно соответствовать
  выбранной подтверждённой организации.
- Загрузите `sava-portugal-draft.zip`; подключите сервер через **With MCP**,
  указав тот же URL и **None**.
- Выполните domain challenge именно в той форме, которую покажет портал.
  По текущей документации это plain-text token по адресу
  `https://sava.pt/.well-known/openai-apps-challenge` либо другому разрешённому
  challenge origin. Нужен реальный токен из кабинета. Его нельзя выдумывать или
  перезаписывать токен другого плагина. Размещение challenge не входит в текущий
  PHP-релиз и выполняется после получения конкретного задания из портала.
- Дождитесь scan семи tools, откройте Issues и устраните findings. Для изменений
  сервера используйте Reconnect/Rescan по назначению.
- Подтвердите category и support/website/privacy/terms URLs. `/about/` содержит
  контактный способ обращения. `/legal/` нужно проверить и при необходимости
  дополнить правилами обработки MCP запросов/логов, сроками хранения и контактами.
- Заполните страны доступности, локализованные listing descriptions и review
  details. В manifest включены пять positive и три negative cases.
- Запишите реальный walkthrough/video и screenshots после успешного UI-теста.
  Не прикладывайте выдуманные результаты. Перед submission при необходимости
  добавьте URL видео в review details или обновлённый manifest.
- Отправьте на review; опубликуйте только после одобрения.

Источник: [OpenAI submission](https://developers.openai.com/plugins/deploy/submission).
Подтверждение домена, review и публикация не выполнены этим пакетом.
