# Find Rafmennt courses

Use `https://www.rafmennt.is/agent/courses` to find upcoming groups. Optional
query parameters are `q`, `location`, `from` and `to`; dates use `YYYY-MM-DD`.
Use Icelandic subject names when practical, such as `ljósleiðarar` or `iðntölvur`.
Broaden an empty search rather than assuming a course does not exist.

Read the selected result's canonical page through `/agent/page?path=...&format=markdown`.
Read its full pricing section before comparing fees: membership categories may
have different prices. General fees are at `/pricing.md`; the course-specific
page is the source for that course. Quote the applicable category and currency.
Do not treat general fees as a guaranteed quote for a particular course.

Equivalent MCP tools are `find_courses`, `read_public_page` and `search_public_site`.
Connect using Streamable HTTP at `https://www.rafmennt.is/mcp`; no credentials
are required. Follow the returned canonical URLs when citing sources.

Only public information is available. Do not submit registration forms, purchase
training, access the CMS or request a visitor's credentials. Let the person use
the registration link on the course page, and recheck availability before they
apply. Most source content is Icelandic; distinguish translation from quotation.
