# Find examination information

Start at `https://www.rafmennt.is/sveinsprof/llms.txt` and follow the index for
the relevant trade. The index and linked Markdown documents are public and
need no authentication. Alternatively use MCP `search_public_site` with the
Icelandic trade name and `sveinspróf`, then `read_public_page` for the result.

Distinguish the application deadline from the examination date. Use the current
published page for requirements and dates; older news articles can describe
expired periods. Include a canonical source link and identify the trade and
period when answering. If a deadline or requirement is absent, say it is not
specified and direct the person to the contact details on the public site.

This skill reads information only. Examination applications, eligibility
decisions, results and personal records are outside the public agent interface.
Do not infer an individual's eligibility or request credentials to the CMS.
