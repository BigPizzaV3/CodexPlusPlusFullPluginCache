# Zas hosted connector

Connect ChatGPT or Claude to selected Zas channels at https://zas.red/mcp using OAuth. Search item titles and filenames, read notes or files, and save results according to each channel's Read and Send permissions. Both hosts use the same server and channel browser; file handling also depends on the host.

This package contains the public listing, MCP configuration, icons and usage instructions. ChatGPT uses the supplied public OAuth client; for Claude use the [Claude setup guide](https://docs.zas.red/en/ai/claude). The local paired agent for Claude Code and Codex is a separate installation. [Setup, limits and privacy](https://docs.zas.red/en/ai/index).
