---
name: month-end-check
description: Check whether a month is ready to hand to the accountant, using what Vaultivo itself reports as open. Use when the user asks whether a month or quarter is done, what is still open before handing over, or what is missing for a period. Needs the Vaultivo MCP connector.
---

Vaultivo keeps the current procedure for this task. Before doing anything else,
call the Vaultivo tool `get_skill` with `name` set to `month-end-check`, then follow
the procedure it returns, in full.

Do not work from memory of an earlier version. If the tool is unavailable or
returns an error, say so and stop rather than improvising a procedure.
