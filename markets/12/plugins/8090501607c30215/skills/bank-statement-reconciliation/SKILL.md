---
name: bank-statement-reconciliation
description: Reconcile bank and credit-card statements archived in Vaultivo against the invoices, receipts and credit notes archived beside them, and report which transactions have a supporting document, which are ambiguous, and which are missing one. Use when the user asks to reconcile bank statements, find missing invoices for a period, check whether transactions have supporting documents, or review how complete their accounting documentation is. Needs the Vaultivo MCP connector.
---

Vaultivo keeps the current procedure for this task. Before doing anything else,
call the Vaultivo tool `get_skill` with `name` set to `bank-statement-reconciliation`, then follow
the procedure it returns, in full.

Do not work from memory of an earlier version. If the tool is unavailable or
returns an error, say so and stop rather than improvising a procedure.
