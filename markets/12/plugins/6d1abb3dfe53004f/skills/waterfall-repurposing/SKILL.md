# waterfall-repurposing

**Когда использовать:** Переработать длинное интервью, статью или видео в самостоятельные публикации для разных платформ.

**Источники:** `../../references/METHOD_CATALOG.md` методы `C06`, `C12`; маркеры `../../references/SOURCE_TRACE.md`. Общая последовательность: `../../references/OPERATING_PROTOCOL.md`, проверки `../../references/QUALITY_GATES.md`.

## Работа
Извлечь source units и точные смысловые границы; отбросить зависимые без контекста. Создать platform-native interpretations, а не автопересказ. Для каждого результата указать source locator, core message, adaptation choices, platform and readiness.

## Обязательный результат
Content mining map, multi-platform publish pack. Обозначь: данные и их provenance, выводы, неизвестное, статус `draft` или `approved`, следующие проверяемые шаги. Перед выдачей пройти gates.

## Запрет / обработка неполных данных
Нет времени в исходной расшифровке — нет «точных таймкодов». При нехватке одного критического поля уточни его; если можно работать с ограничениями — дай предварительный результат с явной пометкой гипотез. Не заявляй об исполнении внешнего действия без подтверждения инструмента.
