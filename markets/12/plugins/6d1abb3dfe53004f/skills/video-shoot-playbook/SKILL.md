# video-shoot-playbook

**Когда использовать:** Спланировать съёмку с комфортной обстановкой, скептическими проверками и прозрачным техническим заданием.

**Источники:** `../../references/METHOD_CATALOG.md` методы `C07`, `C08`; маркеры `../../references/SOURCE_TRACE.md`. Общая последовательность: `../../references/OPERATING_PROTOCOL.md`, проверки `../../references/QUALITY_GATES.md`.

## Работа
Оценить задачу/время/формат/участников. Подготовить интервью-вопросы, кадры, звук, свет, план поддержки ведущего, регулярную проверку смысла и возражений без ложной похвалы. Сформировать монтажное ТЗ, документацию source material.

## Обязательный результат
Call sheet, questions, shot list, sound checklist, transcript/index brief. Обозначь: данные и их provenance, выводы, неизвестное, статус `draft` или `approved`, следующие проверяемые шаги. Перед выдачей пройти gates.

## Запрет / обработка неполных данных
Не создавать стилизованные «документальные» кадры якобы из реальной съёмки. При нехватке одного критического поля уточни его; если можно работать с ограничениями — дай предварительный результат с явной пометкой гипотез. Не заявляй об исполнении внешнего действия без подтверждения инструмента.
