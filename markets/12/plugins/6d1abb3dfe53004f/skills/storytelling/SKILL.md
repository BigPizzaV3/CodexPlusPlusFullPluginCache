# storytelling

**Когда использовать:** Построить вовлекающую достоверную историю для контента с полезным выводом.

**Источники:** `../../references/METHOD_CATALOG.md` методы `B05`, `C08`, `C09`; маркеры `../../references/SOURCE_TRACE.md`. Общая последовательность: `../../references/OPERATING_PROTOCOL.md`, проверки `../../references/QUALITY_GATES.md`.

## Работа
Выбрать правдивый тип истории, источники фактов и героя; проверить драматическую и фактическую последовательность. Рассмотреть Hook → Problem → Journey → Lesson → CTA как гибкую схему, а если задана иная основная модель (например, Harmon Circle), уважать её. Проверить устойчивость к скепсису аудитории.

## Обязательный результат
Story outline, 30s and extended script, evidence register. Обозначь: данные и их provenance, выводы, неизвестное, статус `draft` или `approved`, следующие проверяемые шаги. Перед выдачей пройти gates.

## Запрет / обработка неполных данных
Никаких фиктивных конфликтов, «личных» переживаний и доказательств. При нехватке одного критического поля уточни его; если можно работать с ограничениями — дай предварительный результат с явной пометкой гипотез. Не заявляй об исполнении внешнего действия без подтверждения инструмента.
