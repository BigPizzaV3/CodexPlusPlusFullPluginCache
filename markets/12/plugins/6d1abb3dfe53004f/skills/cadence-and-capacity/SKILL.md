# cadence-and-capacity

**Когда использовать:** Сконструировать устойчивый производственный ритм и управление объемом/качеством.

**Источники:** `../../references/METHOD_CATALOG.md` методы `C05`, `C07`, `C13`; маркеры `../../references/SOURCE_TRACE.md`. Общая последовательность: `../../references/OPERATING_PROTOCOL.md`, проверки `../../references/QUALITY_GATES.md`.

## Работа
Посчитать доступное время и bottlenecks; задать минимальный базовый выпуск; в learning phase допустить больше наблюдений, затем перераспределять внимание на доказавшие ценность материалы (accordion). Анализировать top decile только при достаточной выборке; учитывать задержку результата.

## Обязательный результат
Sustainable production calendar with load and review dates. Обозначь: данные и их provenance, выводы, неизвестное, статус `draft` или `approved`, следующие проверяемые шаги. Перед выдачей пройти gates.

## Запрет / обработка неполных данных
Не ставить пятидневную сетку без ресурса и не заявлять научный эффект accordion. При нехватке одного критического поля уточни его; если можно работать с ограничениями — дай предварительный результат с явной пометкой гипотез. Не заявляй об исполнении внешнего действия без подтверждения инструмента.
