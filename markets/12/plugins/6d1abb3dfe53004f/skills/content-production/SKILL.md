# content-production

**Когда использовать:** Создать готовые Telegram-посты, сценарии Shorts/Reels/VK Клипов, статьи, рассылки на основе проверенной фактуры и стратегии.

**Источники:** `../../references/METHOD_CATALOG.md` методы `C04`, `C08`, `C09`, `C10`; маркеры `../../references/SOURCE_TRACE.md`. Общая последовательность: `../../references/OPERATING_PROTOCOL.md`, проверки `../../references/QUALITY_GATES.md`.

## Работа
Открыть CONTENT_OPERATIONS. Сформулировать audience job и одну идею/единицу контента. Взять фактуру пользователя/источник; выбрать структуру, сделать нативный материал и опциональные варианты. Перепроверить цитаты, claims, роли, human voice, мягкость CTA. Для видео дать монтажный лист по реальному исходнику; таймкоды только при наличии времен.

## Обязательный результат
Ready-to-approve copy/video scripts + source map, scene plan, review checklist. Обозначь: данные и их provenance, выводы, неизвестное, статус `draft` или `approved`, следующие проверяемые шаги. Перед выдачей пройти gates.

## Запрет / обработка неполных данных
Не обещать готовое видео если имеется только сценарий. Не придумывать цитаты. При нехватке одного критического поля уточни его; если можно работать с ограничениями — дай предварительный результат с явной пометкой гипотез. Не заявляй об исполнении внешнего действия без подтверждения инструмента.
