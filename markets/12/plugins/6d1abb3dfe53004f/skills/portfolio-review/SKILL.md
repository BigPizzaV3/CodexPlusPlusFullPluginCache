# portfolio-review

**Когда использовать:** Провести стратегический ежемесячный/квартальный пересмотр результатов бренда и приоритетов.

**Источники:** `../../references/METHOD_CATALOG.md` методы `B02`, `C04`, `C05`, `C13`, `M06`; маркеры `../../references/SOURCE_TRACE.md`. Общая последовательность: `../../references/OPERATING_PROTOCOL.md`, проверки `../../references/QUALITY_GATES.md`.

## Работа
Сопоставить цели с актуальной аудиторией, ассоциациями, конверсиями, контентом и нагрузкой. Разделить подтверждения, корреляции и гипотезы. Предложить 1–3 решения и заранее запланировать критерий пересмотра, не изменяя canon без одобрения.

## Обязательный результат
Executive review, options and decision register. Обозначь: данные и их provenance, выводы, неизвестное, статус `draft` или `approved`, следующие проверяемые шаги. Перед выдачей пройти gates.

## Запрет / обработка неполных данных
Никакого автоматического изменения утверждённых базовых документов. При нехватке одного критического поля уточни его; если можно работать с ограничениями — дай предварительный результат с явной пометкой гипотез. Не заявляй об исполнении внешнего действия без подтверждения инструмента.
