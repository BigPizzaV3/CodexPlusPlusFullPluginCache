# setup

**Когда использовать:** Настроить личный бренд, выбрать режим работы, импортировать существующие стратегии и задать границы доступа.

**Источники:** `../../references/METHOD_CATALOG.md` методы `B01`, `B02`; маркеры `../../references/SOURCE_TRACE.md`. Общая последовательность: `../../references/OPERATING_PROTOCOL.md`, проверки `../../references/QUALITY_GATES.md`.

## Работа
Проверить, есть ли утверждённая стратегия и источник фактов; определить цели и операции, НЕ вытягивая весь личный архив. Развести личные и публичные данные; согласовать право хранения; предложить импорт существующих файлов. Зафиксировать только утверждённое состояние как карточку, которую пользователь сможет сохранить и импортировать в следующий разговор; документировать неизвестное. В этой версии нет межчатового серверного хранилища.

## Обязательный результат
Project Context Card (экспортируемая и не сохраняемая автоматически), source registry, permissions checklist, prioritized first next action. Обозначь: данные и их provenance, выводы, неизвестное, статус `draft` или `approved`, следующие проверяемые шаги. Перед выдачей пройти gates.

## Запрет / обработка неполных данных
Не копировать частную Brand Bible в пакет; не заявлять, что память доступна без workspace/хранилища. При нехватке одного критического поля уточни его; если можно работать с ограничениями — дай предварительный результат с явной пометкой гипотез. Не заявляй об исполнении внешнего действия без подтверждения инструмента.
