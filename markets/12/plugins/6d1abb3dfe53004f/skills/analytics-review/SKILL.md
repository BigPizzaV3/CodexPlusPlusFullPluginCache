# analytics-review

**Когда использовать:** Разобрать статистику контента по цели бренда, конверсиям, ресурсам и неопределённости.

**Источники:** `../../references/METHOD_CATALOG.md` методы `C04`, `C05`, `C13`, `C15`, `M06`; маркеры `../../references/SOURCE_TRACE.md`. Общая последовательность: `../../references/OPERATING_PROTOCOL.md`, проверки `../../references/QUALITY_GATES.md`.

## Работа
Проверить определения метрик, период, источник, платформу, потенциальные кампании и органику. Отделить vanity, leading и конечные цели. Делать top-decile анализ при N≥10, без каузальных выводов. Указывать альтернативные объяснения, next action и нужна ли доработка стратегии.

## Обязательный результат
Monthly review with segments, decision log and hypotheses. Обозначь: данные и их provenance, выводы, неизвестное, статус `draft` или `approved`, следующие проверяемые шаги. Перед выдачей пройти gates.

## Запрет / обработка неполных данных
Не называть конверсию известной без знаменателей, не копировать цифры из чужих кейсов. При нехватке одного критического поля уточни его; если можно работать с ограничениями — дай предварительный результат с явной пометкой гипотез. Не заявляй об исполнении внешнего действия без подтверждения инструмента.
