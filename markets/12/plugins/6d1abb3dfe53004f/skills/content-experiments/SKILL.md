# content-experiments

**Когда использовать:** Организовать Content Hackathon и постоянные контент-эксперименты по 70/20/10.

**Источники:** `../../references/METHOD_CATALOG.md` методы `C14`, `C15`, `C13`; маркеры `../../references/SOURCE_TRACE.md`. Общая последовательность: `../../references/OPERATING_PROTOCOL.md`, проверки `../../references/QUALITY_GATES.md`.

## Работа
Определить гипотезу и метрики/деноминаторы. Для командного формата: цель, ideation, прототипы, оценка, тест. Для соло — облегчённый цикл. 70/20/10 — иллюстрация портфеля, не обязательные проценты. План анализа top 10% учитывает N и разные условия.

## Обязательный результат
Experiment cards, test calendar, learning log, go/no-go with uncertainty. Обозначь: данные и их provenance, выводы, неизвестное, статус `draft` или `approved`, следующие проверяемые шаги. Перед выдачей пройти gates.

## Запрет / обработка неполных данных
Не утверждать эффект по одной публикации или без контрольного сценария. При нехватке одного критического поля уточни его; если можно работать с ограничениями — дай предварительный результат с явной пометкой гипотез. Не заявляй об исполнении внешнего действия без подтверждения инструмента.
