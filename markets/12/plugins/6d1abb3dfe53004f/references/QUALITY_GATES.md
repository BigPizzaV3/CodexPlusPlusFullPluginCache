# Гейты качества и поведение при сбое

| Гейт | PASS | FAIL → реакция |
|---|---|---|
| Evidence | Каждый кейс и цифра имеют provenance | Не публиковать число, заменить точным ограничением или запросить доказательство |
| Role | Личный, командный и клиентский вклад различены | Переформулировать с правдивой ролью |
| Consent | Есть право раскрывать историю клиента/сотрудника | Анонимизировать с сохранением смысла либо убрать |
| Positioning | Материал соответствует бренду либо осознанное исключение | Пометить конфликт, предложить пользовательское решение |
| Outcome | Содержится применимое действие или ясно выраженная мысль | Перепроектировать материал |
| Native | Формат соответствует контексту площадки | Адаптировать заново, не просто сокращать |
| Timing | Слова читаются в требуемый хронометраж | Пробное чтение, сократить, не заявлять измеренное время без аудио |
| Commercial | Нет безосновательных гарантий, мифической срочности и обманных цифр | Переработать CTA/оффер |
| Capacity | Время/ресурсы подтверждены | Уменьшить частоту и сложность |
| Analytics | Базис метрик, период и знаменатели известны | «Данных недостаточно» вместо ложного сравнения |
| Approval | Автор утвердил публикацию / стратегическое изменение | Только черновик |
| Tool access | Реальные права и коннекторы подтверждены | Не заявлять о сборе статистики или публикации |

**Не вводить общий «балл качества 94/100» без калибровки.** Выдавать гейты, наблюдения, правки и остаточные риски; тестируемые скрипты проверяют только структуру и очевидные ошибки.

### Особые запреты
- Никаких вымышленных цитат, интервью, кейсов, причинно-следственных эффектов, личных воспоминаний.
- Никаких публикаций, рассылок, выдачи приватных данных и подключений без полномочий и явного согласия.
- Не переводить метрики автора (70/20/10; 80/20; 85/15; десятка лучших) в жёсткие законы.
- Нельзя утверждать научную доказанность результатов курса, универсальные конверсии и окупаемость.
- Не переносить обещания продажи дорогостоящего продукта на чужую аудиторию без проверки спроса.
