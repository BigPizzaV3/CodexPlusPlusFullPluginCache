# Контент-операции: единый контракт

**Входы:** цель и аудитория, голос бренда, формат/площадка, фактура, примеры/источники, выбранный topic cluster, CTA, доступное время, согласия и ограничения. **Необязательное:** текущая статистика, старая история контента.

**Процесс:** 1. Провести фактологический intake и зафиксировать thesis; 2. выбрать job-to-be-done аудитории и желаемую ассоциацию; 3. определить один полезный результат на единицу контента; 4. подобрать структуру (объяснение, разбор, история, спорный тезис, эксперимент); 5. подготовить native draft; 6. пройти skeptic/objection review; 7. провести факт-чек; 8. отредактировать на естественность, точность и отсутствие штампов; 9. для видео дополнить B-roll, субтитры, таймкоды по реальному исходнику; 10. отдать пакет на утверждение.

**Водопад / native:** длинный материал — не обязательно видео. Mining только самодостаточных мыслей; сохранять `[SOURCE: file + locator]` и не менять фактический смысл. Платформенная нативность = другая композиция, ритм, формат, логика раскрытия. Транскрипт без временных отметок — НЕ источник реальных таймкодов; указывать `TIMECODES_NEEDED`.

**Структуры:** 5-stage Storytelling (Hook/Problem/Journey/Lesson/CTA) — optional lens. Категории историй (origin/failure/success/customer/industry). Опора на реальную фактуру, корректный storyteller. Если пользователь уже утвердил собственную модель сторителлинга, она имеет приоритет для его материалов; модель Ралстона допускается как дополнительная, но не обязательная схема. Метод не должен насиловать реальную историю.

**Обработка обратной связи:** вопросы/возражения/комментарии → topics с источником и датой → микроэксперименты → оценки по целевым сигналам; воздержаться от искусственного «выживания» по одному вирусному результату.

**Выход:** Brief; key claim and provenance; готовый Telegram/short/video script; production plan; captions/CTA; quality gate report; measurement plan; `status: draft | approved`. Видео без записи — сценарий, не готовый монтаж.
