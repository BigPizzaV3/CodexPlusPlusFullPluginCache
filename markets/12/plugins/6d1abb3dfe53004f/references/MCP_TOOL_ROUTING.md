# Когда использовать удалённые инструменты MCP

MCP здесь **не является языковой моделью** и не содержит 24 метода. Каждый Skill инструктирует ChatGPT, а MCP обеспечивает независимые расчёты и структурные проверки, когда это необходимо.

| MCP | Skill-потребители | Триггер | Точная граница |
|---|---|---|---|
| `assess_brand_brief` | setup, brand-audit, brand-strategy, audience-and-positioning | Пользователь предоставил цель/аудиторию и запрашивает диагностику | Проверка наличия полей, не реального спроса |
| `audit_content_claims` | content-production, storytelling, brand-story, offer-content-bridge | Есть готовый черновик и список проверяемых утверждений | Проверка статусов, не независимый фактчек |
| `analyze_content_metrics` | analytics-review, platform-scaling, portfolio-review | Передана таблица статистики | Описательные проценты; пропуски ≠ нули; не причинный эффект |
| `design_content_experiment` | content-experiments, portfolio-review, community-listening | Есть гипотеза, контроль и измеримый KPI | План, не достоверность гипотезы |
| `design_content_distribution` | waterfall-repurposing, content-production, channel-design | Известны исходные идеи, площадки и время | Бриф адаптации, не готовые опубликованные посты |
| `validate_project_snapshot` | setup, project-context-export, brand-strategy | Пользователь утверждает или импортирует контекст | Проверяет структуру и булевский статус, не подпись/владельца |

## Нельзя делать
- Не отправляйте пользователю текст как будто он автоматически сохранён в облаке: сервер ничего не хранит.
- Не передавайте чувствительные документы, пароли, токены или личные сведения третьих лиц.
- Не вызывает MCP ради формального присутствия. Если задача решается средствами Skill, работаем в ChatGPT без сервера.
- Пустой или отключённый MCP **не блокирует** работу со Skills; честно сообщите об отсутствии инструмента, если нужны расчёты.
- Сервер общедоступный, без авторизации. Публичное использование с сохранением данных запрещено до внедрения авторизации, ограничений и согласованных документов.
