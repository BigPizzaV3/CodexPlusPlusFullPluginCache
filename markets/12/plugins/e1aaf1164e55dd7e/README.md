# BookGuard 1.1.0 MCP-enabled public submission

**Public submission copy:** This is a NEW plugin package with internal name `bookguard-mcp`, designed for initial Developer Portal upload with an MCP server. Its user-facing name remains **BookGuard**.

The earlier personal skills-only package named `bookguard` cannot gain an MCP server through an update. Do not upload this file as a version update of that existing plugin. Start from the Plugins landing page > Upload new or existing plugin, and use this new ZIP to create a new draft. Your existing private BookGuard is not changed by this package.

Includes unchanged original logo and composer icon, age-band standards, and core evidence-based spoiler-free screening workflow, plus a read-only public Open Library bibliographic lookup server at `https://bookguard-mcp.dtsaudiofile.workers.dev/mcp`.

The MCP server supports catalog identification, **not** content safety certification. Finish MCP connection, domain verification, tool scan, review cases, live demo, public privacy policy, and creator attestations before submitting for review.

Publisher identity is selected in the Developer Portal, not inferred from this package.
