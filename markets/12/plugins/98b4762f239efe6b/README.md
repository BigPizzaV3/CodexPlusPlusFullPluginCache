# APPRADIO.PRO

Plugin privado conectado ao servidor MCP público APPRADIO.PRO.

## Conexão

- Endpoint: https://virtues.top/api/v1/mcp.php
- Transporte: MCP Streamable HTTP, stateless.
- Autenticação: sem login (No sign-in).
- Operações: somente leitura, sem acesso a contas privadas.
- Documentação: https://appradio.pro/docs/mcp
- Políticas: https://appradio.pro/politicas
- Suporte: https://appradio.pro/suporte

## Ferramentas verificadas

listar_catalogo, detalhar_produto, buscar_produtos, comparar_produtos,
consultar_ajuda, buscar_radios, detalhar_radio, listar_segmentos,
consultar_programacao, consultar_agora_tocando, buscar_radios_proximas.

## Limites

Guias de instalação e FAQs cobrem o aplicativo de escuta APPRADIO.PRO;
para HubLive, Sonora e FrameLive consulte suas fichas e notas de versão.
Links de players podem ser temporários; prefira a página da rádio ao compartilhar.
Plataformas ausentes significam não informado. Programações e faixas atuais
podem não estar disponíveis. Use busca próxima somente com coordenadas
fornecidas ou explicitamente consentidas pelo usuário.

O ícone foi obtido do site APPRADIO.PRO. O servidor permanece hospedado
pelo seu provedor. A criação deste pacote não publica o plugin no diretório
público nem comprova a conexão final no ChatGPT.
