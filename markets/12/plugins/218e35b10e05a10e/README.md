# ATICA-SICE 0.4.17

Complemento independiente desarrollado y operado por ATIEMPPO S.A.S. para
consultar referencias y calcular costos operativos del transporte de carga
en Colombia, con fuentes, período, parámetros y limitaciones explícitos.
No es un servicio gubernamental oficial ni afirma afiliación o respaldo de
una autoridad pública. Las referencias SICETAC se identifican como fuentes
de datos y metodología, no como la identidad del desarrollador.

El nombre visible es ATICA-SICE. El identificador técnico del paquete y la
conexión existentes se conservan para actualizar el mismo complemento:
`sicetac-al-instante`.

Endpoint existente: `https://sicetac-al-instante-atiemppo.vercel.app/mcp`.
El archivo `mcp.json` conserva el cliente OAuth público, recurso y permisos
existentes, sin secretos. Este cambio de nombre no exige nuevas credenciales.

Se incluyen el MCP remoto, la habilidad de consulta y el logo ATICA-SICE por
ATIEMPPO, junto con los cinco casos positivos, tres negativos y enlace al
recorrido de revisión. Los nombres de las herramientas y las reglas de
cálculo no cambian. La referencia ordinaria usa `consultar_referencia`;
el modelo detallado se ejecuta únicamente bajo solicitud.

Origen, destino, configuración, carrocería, horas y período se conservan
según el contrato del servicio. El cupo efectivo se consulta en la cuenta;
el paquete no promete promociones, precios ni renovaciones nuevas.

Subir este ZIP a la ficha existente permite revisar una versión nueva.
Preparar el paquete no equivale a cargarlo, enviarlo a revisión ni aprobarlo.
