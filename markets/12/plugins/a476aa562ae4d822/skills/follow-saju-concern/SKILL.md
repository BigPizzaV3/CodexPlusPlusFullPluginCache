description: 사용자가 맡긴 사주 고민을 같은 ChatGPT 대화의 예약 작업으로 이어 살피고, 직전 계산 이후의 실제 운 변화를 확인한다. 계속 살펴달라는 요청, 이미 승인한 관찰의 실행, 변경, 종료에 사용한다. 일반 사주 풀이와 첫 시기 질문만으로 관찰을 시작하지 않는다.
---

사용자가 명시적으로 맡긴 고민과 기간을 따른다. 기본 상담과 자동 관찰 동의는 별개다. 운세냥이의 읽기 도구는 예약을 만들거나 상담 기록을 저장하지 않는다. 예약 기능과 실제 생성, 갱신, 취소 결과는 호스트에서 확인한다.

처음 맡길 때 같은 사람의 확인된 출생정보와 계산 기준, 사용자가 직접 말한 고민과 선택 기준을 이어받는다. 다른 대화, 메일, 캘린더나 운세냥이의 저장 기록을 읽지 않는다. 답을 가를 정보가 없는 경우에만 필요한 사실 하나를 묻는다.

find_saju_timing으로 현재 권한과 정본 근거를 확인한다. 현재 상담을 먼저 충분히 제공한다. 지원하는 호스트의 같은 대화 예약 기능으로 baseline.window.ends_at에 한 번 다시 살피도록 설정한다. 다음 실행 후 같은 예약을 다음 계산 경계로 갱신할 수 있어야 한다. 사용자 지정 종료일이 있으면 이를 따르고, 없으면 이번 계산의 searched_until을 종료 범위로 삼는다. 대화에서 이미 확인한 관찰을 재사용하며 동일 목적의 예약을 중복 생성하지 않는다. 일, 주 단위 반복으로 실제 절입 시점을 대체하거나 불필요한 모델 실행을 늘리지 않는다.

예약에 필요한 자료는 같은 출생정보와 계산 기준, 사용자가 맡긴 고민과 직접 확인한 조건, 마지막 성공 계산의 기준 시각, 종료 범위, 기존 예약 식별자로 한정한다. assistant의 과거 해석을 사용자 사실로 저장하지 않는다. 호스트가 저장 성공을 반환한 뒤에만 대상 대화와 다음 확인 날짜를 짧게 알려준다. 도구의 날짜만 확인했거나 호스트가 예약 생성, 갱신을 지원하지 않으면 그 상태를 밝히고 자동 관찰을 약속하지 않는다. 결제 안내나 업그레이드 유도를 붙이지 않는다.

예약 실행 시 review_saju_changes에 같은 출생정보와 마지막으로 성공한 계산 기준을 전달하고 현재 시각은 서버가 정하도록 한다. 현재까지 거친 모든 경계와 원국, 대운, 세운, 월운의 이어짐을 함께 읽는다. 조사한 범위 밖의 기간을 검토한 것처럼 말하지 않는다. 정상 반환된 searched_until을 다음 비교의 기준으로 삼는다. 호출이 실패하면 마지막 성공 기준을 유지하고 실패를 알리며 자동 관찰의 정상 작동으로 표시하지 않는다. 권한 거절 시 예약을 중지하고 정지 여부를 확인한다.

사용자의 원질문과 선택 기준에서 판단이 달라질 근거가 있는 부분만 전한다. 달라진 글자가 있다는 이유로 새 사건, 호전, 악화를 만들지 않는다. 확인된 변화가 없거나 같은 판단이 이어지면 불필요한 알림을 보내지 않도록 호스트의 지원되는 알림 제어를 따른다. 무응답을 지원하지 않으면 조용히 관찰할 수 있다고 약속하지 않는다. 실제 생활의 새 사실은 사용자가 알려준 경우에만 반영한다. 과거의 해석과 다르면 차이를 인정하고, 맞았다고 사후에 끼워 맞추지 않는다.

정상 검토 뒤 종료 범위 안의 next_check_at으로 기존 예약을 갱신하며, 마지막 성공 기준도 이번 searched_until로 함께 저장하고 성공을 확인한다. 첫 기준을 그대로 남겨 이미 알린 변화를 다음 실행마다 반복하지 않는다. 종료 범위를 넘기거나 사용자가 결정을 마쳤다고 하거나 그만 살펴달라고 하면 해당 예약도 실제로 중지한다. 취소 성공을 확인하지 못하면 중지됐다고 확정하지 않는다. 대화의 정정과 새 선택 기준은 이후 예약에도 반영하며 다른 관찰의 목적이나 기간을 바꾸지 않는다.

시각 미상에서 추정한 교운 경계는 실제 개인의 전환일로 확정하지 않는다. 추정 교운만 달라진 경우 그 사실로 개인의 상황이 바뀌었다는 알림을 만들지 않는다. 조건부와 확인 보류 근거는 계속 보존한다.
