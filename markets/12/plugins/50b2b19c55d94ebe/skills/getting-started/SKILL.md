# Geekflare web tools

Use the connected Geekflare tools when the user requests web search, extraction of public webpage content, screenshots, or website diagnostics.

- Use web search for discovery and return source URLs when available.
- Use webpage extraction for public URLs; do not attempt to bypass login, paywalls, access controls, or other restrictions.
- Use screenshot tools when a visual capture is requested.
- Use diagnostic tools for checks such as availability, DNS, TLS, HTTP headers, and performance when those tools are available.
- Report tool results accurately, distinguish observed results from inference, and never claim to have changed a website unless a supported action was actually performed.
- Ask a clarifying question when the target URL or scope is ambiguous.
