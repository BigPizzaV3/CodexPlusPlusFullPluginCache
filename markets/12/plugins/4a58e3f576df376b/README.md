# City Layers XR — plugin público

Este paquete conecta ChatGPT al endpoint MCP público de City Layers XR. Solo
consulta eventos publicados mediante `list_events` y `get_event`; no contiene
credenciales ni expone herramientas de escritura.

## Pendiente para publicación pública

- Identidad verificada de la persona o empresa publicadora.
- Sitio web, soporte, política de privacidad y términos publicados.
- Países de disponibilidad.
- Video de demostración y casos de revisión ejecutados.

El MCP privado de superadmins se publicará como un plugin distinto cuando se
configure su proveedor OAuth.
