# NEC Format — Compensation Event Notification (Clause 61.3)

Loaded at Step 6 when the contract profile (Pattern 13) names an NEC family, or the user
confirms NEC when no profile exists.

```
COMPENSATION EVENT NOTIFICATION (CLAUSE 61.3)
Project: [Name]
Contract: [NEC3/NEC4 Option X]
CE Reference: [if known, otherwise "To be assigned"]
Date: [today]

1. EVENT DESCRIPTION
   [One paragraph describing what happened, when, and where, citing diary evidence]

2. CONTRACTUAL BASIS
   This event is a compensation event under clause 60.1([X]) because [reason].

   Notification: The Contractor [became aware / should have become aware] on [date].
   This submission is [within / outside] the 8-week notification window (deadline: [date]).

   Early Warning: [EWN reference if known / "No EWN was notified prior to this event" / "An EWN should be notified concurrently"]

3. PROGRAMME IMPACT
   [Description of effect on the Accepted Programme]
   Activities affected: [list]
   Estimated time impact: [X working days / "not quantifiable from available records"]
   Delay assessment basis: planned Completion vs the Accepted Programme per clause 63.3 (NEC3) /
   63.5 (NEC4 — the Accepted Programme current at the dividing date)

4. RESOURCE IMPACT
   [Description of resource impact]
   Standing time: [X gang-shifts / X hours / "not quantifiable from available records"]
   Additional resources: [if applicable]
   Productivity loss: [if measured — reference measured-mile analysis]

5. EVIDENCE SCHEDULE
   See `evidence-schedule.md` for the shared
   table format.

6. ASSESSMENT BASIS
   The CE should be assessed as Defined Cost plus Fee in accordance with clause 63.
   [NEC4: split at the dividing date (clause 63.1) — actual Defined Cost for impact already
   incurred by the dividing date (e.g. recorded standing time from the site diaries in the
   evidence schedule) and forecast Defined Cost for the ongoing impact after it, including
   time risk allowances for matters with a significant chance of occurring. For an event the
   PM/Supervisor did not originate by a communication — such as 60.1(2) access — the dividing
   date is the date this compensation event is notified.]
   [NEC3: actual Defined Cost for work done and forecast Defined Cost for work not yet done,
   divided at the date the PM instructed or should have instructed quotations (clause 63.1),
   including risk allowances under clause 63.6.]

NOTES
- This submission is based on data recorded in Gather. It should be reviewed by the commercial manager before formal notification.
- This is not a quotation — it supports a notification under clause 61.3 with evidence. The priced quotation under clause 62 follows after the Project Manager's response to the notification.
```
