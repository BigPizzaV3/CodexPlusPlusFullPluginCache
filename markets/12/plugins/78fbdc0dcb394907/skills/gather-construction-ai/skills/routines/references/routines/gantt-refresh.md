## gantt-refresh

**Cadence:** Weekly, e.g. Sunday evenings or Monday mornings
**Surface:** Desktop
**Prerequisites:** none beyond the working folder
**Priority:** Standard

**Instructions:**
```
Run $asbuilt-programme for {{PROJECT}} covering the project to date (or the last 12
weeks if the full history call is too large — state which you used). Regenerate the interactive
HTML Gantt and save it to {{FOLDER}} with today's date in the filename, e.g.
asbuilt-gantt-2026-07-06.html.
This is a living wall chart, not an analysis — reply in one line confirming the file was saved
and naming any activity that newly started or finished since the previous file. No further
narrative needed.
```
