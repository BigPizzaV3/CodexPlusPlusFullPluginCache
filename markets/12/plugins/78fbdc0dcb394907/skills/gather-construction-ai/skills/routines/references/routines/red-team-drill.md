## red-team-drill

**Cadence:** Monthly (or fortnightly for a team in training), e.g. first Friday, 12:30 — a lunch-and-learn slot
**Surface:** Desktop
**Prerequisites:** `{{FOLDER}}/routine-state/red-team-drill/scores.md` (created on first run); a trainee or a team in the room — this routine is interactive by design
**Priority:** Standard

**Instructions:**
```
Run the Red Team agent in SPARRING MODE for the team's training session.

Read {{FOLDER}}/routine-state/red-team-drill/scores.md and pick the next UNUSED scenario from
the sparring pack (rotate; all used → start the rotation again and say so). Present the
scenario's draft ONLY — never the answer key — and collect the team's findings before
scoring FOUND / MISSED / BONUS and revealing the key with its lessons and APC tags.

Then the improvement curve: if the scores log holds 3 or more entries, close with a trend
line — average found/total over time, recurring MISSED themes (the revision list), and any
tier movement on real Review Mode entries in the log. Scores grade the records and the
findings, never the people — say so at the reveal.

Log the session (date | mode=sparring | scenario | found/total | bonus) to
routine-state/red-team-drill/scores.md. Real submissions red-teamed between drills append to
the same log automatically, so the curve reflects live work as well as training.
```
