## portfolio-benchmark

**Cadence:** Monthly, the 1st, 06:30 (or as agreed with the commercial director)
**Surface:** Cloud ☁ or Desktop
**Prerequisites:** none — `$benchmark` needs no contract or commercial profile
**Priority:** Standard

**Instructions:**
```
Run $benchmark across {{PROJECTS}} (a fixed portfolio list) for the prior calendar month
— use that explicit month, not "this month" relative to fire time. Rank by labour productivity,
resource utilisation, and progress rate; lead with the best and worst performer and the single
biggest mover since the previous month if a prior run's output is available to compare against
(pasted into this prompt, or — Desktop only — read from
{{FOLDER}}/routine-state/portfolio-benchmark/last-run.md).
This is a commercial-director view: one page, worst project first, no per-project deep dive.
If no prior comparison is available, present the full ranking once and note that this is the
baseline run.
```
