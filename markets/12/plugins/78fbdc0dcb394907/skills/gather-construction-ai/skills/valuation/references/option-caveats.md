# Step 8 — Contract-Aware Caveats by Option

| Option | Caveat applied |
|---|---|
| **A** (priced activity schedule) | Any activity **not yet complete** (cumulative actual < the profile/known total quantity, or otherwise flagged "ongoing") is still shown with its measured quantity and value, but flagged **"not payable this period under Option A — completed activities only"**. Never omit the line — flag it. |
| **B** (bill of quantities) | Standard measured qty × rate as computed in Step 5 — no additional flag. |
| **C–F** (target/cost-reimbursable) | State plainly: this output is **records-backed support for the Defined Cost application**, not the Price for Work Done to Date (PWDD) assessment itself — the PWDD/Defined Cost build-up is a separate commercial exercise this measure feeds into. |
| **Not confirmed** | State: "Contract Option not confirmed — Option-specific payment caveats cannot be applied. Run `$contract-profile` or state the Option to apply the correct caveat." |
