# Workflows, routines and profiles

Install the complete plugin using `install.md`; specialist advisers are skills in this edition.

## Workflows

Use these as repeatable command packs with clear decision points and escalation paths.

| Workflow | When to Run | Command Pack | Key Decisions | Escalate To |
|---|---|---|---|---|
| Morning Site Briefing | Daily before shift start | `$diary <project> yesterday`<br>`$access <project> today` | Diary omissions, disruption/waiting-time notes, possession constraints for planned work | Workforce & Performance Advisor when 2+ red flags appear |
| Preparing for a Commercial Review | Weekly/monthly review prep | `$commercial-report <project> <period>`<br>`$programme <project> <period>`<br>`$delay-analysis <project> <period>` | Variance hotspots, milestone slippage, delay-cause entitlement relevance | Time & Claims Advisor for entitlement risk; Commercial Director (Forecast mode) for ETC/EAC risk summary |


### 5-Minute Weekly Routine
```text
$diary <project> yesterday
$access <project> today
$commercial-report <project> <period>
$programme <project> <period>
$delay-analysis <project> <period>
```

### Building a Claim
Just describe what happened — the time-and-claims-advisor agent handles the rest:
> "We lost 3 weeks of access on the Westbury project in January
> due to late possession handovers. Build me a claim."
