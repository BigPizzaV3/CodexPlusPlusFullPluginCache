# Install or submit

For public distribution create a With MCP submission at https://platform.openai.com/plugins, supply the HTTPS endpoint from mcp.json, configure OAuth and upload this bundle in the Skills section. The portal assigns public integration identity; this archive intentionally contains no existing integration mapping.

For private development, use plugin-creator to register this folder in a personal source and, where required, map a real registered Gather connection into a private development copy. Install through the supported Plugins Directory and start a new conversation.

Official instructions: https://developers.openai.com/plugins/build/plugins and https://developers.openai.com/plugins/deploy/submission.
