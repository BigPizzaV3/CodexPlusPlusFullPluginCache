# Exam Grade Target Arithmetic

Calculates the uniform score required across remaining assessment weight to reach your chosen final target, using supplied completed scores and weights that total 100%. Shows mathematically unreachable targets and completed-course cases. No grading policy or exam outcome is inferred. Uses only adult user-controlled facts; review the result. No external lookup, storage or sending.

Standalone worksheet: https://duopore-public-tools.ch-kae88.workers.dev/tools/exam-grade-target
