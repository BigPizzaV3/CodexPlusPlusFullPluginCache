# eGrow Store Operations plugin

Portable Agent Plugins package for eGrow's hosted MCP server. Connects at `https://mcp.egrow.com/mcp` using OAuth discovery; no credentials are bundled.

The plugin exposes eGrow's supported tools for store operations. The hosted service's available tools are discovered from the live server during setup and scanning.

Before public submission, confirm publisher/developer attribution, review listing URLs, add the required review test cases and demo recording, and complete the account-specific checks in the OpenAI Plugins dashboard.
