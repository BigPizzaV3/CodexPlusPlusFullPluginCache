# Supplier quality

Read [modes](../instructions/references/modes.md). For connected work read [connection](../instructions/references/connection.md), [change control](../instructions/references/change-control.md) and [human decisions](../instructions/references/human-decisions.md). For register import use [bulk import](../bulk-import/SKILL.md) and its supplier profile.

Establish supplier, scope of supply, period and question. Standalone: review supplied evidence and draft register/evaluation material. Connected: resolve supplier ID and relevant evaluation, NCR, complaint, CAR, document and action records within permissions; disclose visibility limits.

Separate source statements from verified certification/performance. For evaluation inputs retain counts, period and definitions; do not put percentages in delivery counts. Do not infer outcomes from a score alone. Missing data is unknown, not zero.

Use [investigation research](../investigation-research/SKILL.md) for possible explanations and useful follow-up checks. Prepare supported register updates, factual evaluation inputs or related records as explicit proposals. Do not set supplier status/evaluation outcome, record supplier acknowledgement or accept/reject CAR responses. A document-issue record is evidence of an actual issue, not a request to send a document.

Example: recurring late delivery warrants period-defined data and investigation, not automatic suspension. If a supplier record is inaccessible, retain the draft; do not create a duplicate.
