# Product import policy

Require name; ordinary fields observed were code, family, description, status and owner_id. Product Assurance access is required. Describe live fields first. Retain codes as text; do not assume unique codes without verified target matching.

Use verified ID or reviewed code matching. Name-only identity is ambiguous. Show status/defaults explicitly; do not infer a default active/draft state. An imported active product is not a supported product claim. No automatic configurations, components, claims, publications or technical approvals.

Blank updates preserve fields. Unknown IDs remain unresolved. Refer to common rules for matching, clears and receipt recovery.
