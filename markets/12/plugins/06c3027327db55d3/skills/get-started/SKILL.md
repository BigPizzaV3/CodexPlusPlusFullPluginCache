# Get started with Ecommerce Leads

The Ecommerce Leads plugin looks up metrics for any ecommerce store by domain.

## How to use it

1. Ask for a store by domain. For example: "Look up the store metrics for allbirds.com".
2. Full URLs also work. For example: "Check the metrics for https://www.gymshark.com".
3. You can compare stores. For example: "Compare the revenue of nike.com and adidas.com".

## Log in for more

The free lookup needs no account. It returns store metrics and buying signals. To search the full catalog, reveal
decision-maker contacts, or manage signal sets and
watchlists, log in:

1. Ask for an action that needs an account, or connect the plugin again.
2. Your assistant opens the Ecommerce Leads login page.
3. Enter your email, then the code we send you. Pick your account if you have
   more than one.
4. Approve the connection. Then ask again.

Some actions spend credits from your account. Your assistant tells you the
cost and asks you to confirm first.

## What you get

Each lookup returns the store's estimated monthly revenue, marketing budget,
organic and paid traffic, Google and Meta ad spend, active ad counts, a
Conversion Rate Score, and links to the store's social profiles and ad
libraries.

## Limitations

- One store per lookup. The tool takes a single domain.
- Without login, the plugin returns store metrics only. Contacts, buying
  signals and other lead data need a logged-in account.
- If a store is not in the database, the plugin says so and asks you to check
  the spelling.
