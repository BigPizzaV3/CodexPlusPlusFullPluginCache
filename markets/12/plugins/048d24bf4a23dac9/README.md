# Food Diary

Food Diary is a free, invitation-only hobby service for keeping a personal food
diary through ChatGPT. It records meals, favorite foods, optional nutrition
goals, body measurements and weight plans. It is not medical advice.

## На iPhone

1. Получите личную ссылку от Даниса, откройте её в Safari и создайте ключ доступа
   (passkey). Приглашение одноразовое; не пересылайте его другим.
2. После публикации откройте карточку **Food Diary** в каталоге ChatGPT и выберите
   подключение. Страница приглашения покажет прямую ссылку, когда она настроена.
   Войдите сохранённым ключом и нажмите **Allow access**.
3. Вернитесь в ChatGPT на iPhone, начните новый чат и выберите Food Diary.
   Например: «Покажи мой дневник за сегодня».

Публичная карточка пока не настроена; публикация и доступность на конкретном
устройстве или тарифе не гарантируются. Если карточка недоступна, см.
[инструкцию](https://food-diary.zigdanis.workers.dev/setup?lang=ru).
Создание passkey не подключает ChatGPT автоматически: подключение и OAuth
требуют отдельных действий. На бесплатном тарифе проверку проведёт Данис.

## On iPhone

1. Get a personal link from Danis, open it in Safari, and create a passkey.
   Invitations are single use; do not forward yours.
2. After publication, open **Food Diary** in the ChatGPT directory and choose
   Connect. The invitation page will offer a direct link when configured.
   Sign in with your saved passkey and select **Allow access**.
3. Return to ChatGPT on iPhone, start a new chat, and select Food Diary.
   Try: “Show my food diary for today.”

The public card is not configured yet. Publication and availability on a
particular device or plan are not guaranteed. Until then, use the
[connection guide](https://food-diary.zigdanis.workers.dev/setup?lang=en).
Creating a passkey does not connect ChatGPT automatically: connection and OAuth
need separate actions. Danis will test Free account availability personally.

## Manual testing fallback

In a browser, open [Plugins](https://chatgpt.com/plugins) and, if your account
supports it, choose **Add → Add custom MCP server**. Use the name **Food Diary**,
server URL **https://food-diary.zigdanis.workers.dev/mcp**, and **OAuth**.
No client ID or secret is needed. Sign in with the passkey, allow access, and
install/connect if offered. Enable Developer mode only if requested. This is a
testing fallback, not the intended directory onboarding for relatives.

Existing manual connections may still appear as **Еда** or **Food**. Refresh
those connections and start a new chat; creating another account is unnecessary.
ZIP import is optional. A copy marked **Desktop only** requires the desktop
app and does not establish iPhone compatibility.
