# Reporting and optimization
Use `get_performance_summary`, `list_top_performers`, `get_campaign_performance`, `get_ad_performance`, `get_ad_set_performance`, `compare_platforms`, `explain_change`, `scan_for_waste` and platform-specific insights tools when available. Report account, date range, timezone, currency, attribution and sample-data flags. Missing values are not zero. Separate evidence, inference, and recommendation.

For Meta, use `analyze_meta_ad_performance`, `detect_meta_creative_fatigue`, `get_meta_ad_set_learning_status`, and catalog/funnel tools as applicable. For Google, use `analyze_google_search_terms`, `get_google_keyword_performance`, `get_google_ad_policy_violations`, `get_google_conversion_action_performance` and PMax search-term tools where supported.

Provide proposed actions and expected tradeoffs, then wait for exact approval before modifying budgets, keywords, targeting, creative, conversion goals, statuses, or assets. Never auto-apply optimization recommendations.
