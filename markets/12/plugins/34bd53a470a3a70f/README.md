# Spaced Practice Schedule

Schedules practice from an explicit anchor date using your chosen increasing day offsets, and flags dates past an optional supplied deadline. Every date is deterministic. Intervals are your plan, with no claim of a validated memory or mastery outcome. Uses only adult user-controlled facts; review the result. No external lookup, storage or sending.

Standalone worksheet: https://duopore-public-tools.ch-kae88.workers.dev/tools/spaced-practice-schedule

MCP exposes only `spaced_practice_schedule` at the scoped endpoint. Input schema and output are independently tested. Aggregate MCP requests are limited to 128 KiB and results to 256 KiB, in addition to individual schema bounds. Use smaller batches when needed. Install/login through the host platform as required; no credentials are bundled.

Prepared ZIP is not an uploaded or approved Directory listing. Publisher verification, real connected ChatGPT tests, a demo recording, exact domain challenge and review still apply. Multiple separate Directory plugins cannot assume independent domain verification on one shared host; each may need an eligible separate origin before public submission. No fake challenge tokens are included. The 95 utilities share one hosting runtime and workbench; this is not 95 independently deployed Sites.
