# Get started with Fragua Data USA

Ask in plain language about any U.S. state, county, city, ZIP code or neighbourhood.

- Market: "What does the market look like in Miami-Dade County?"
- Trends: "How have asking prices changed in Palm Beach County over three years?"
- Listings: "Find 3-bedroom homes for sale in ZIP 33139 under $1.5 million."
- Demographics: "What is the population and median age of Broward County?"

Place names are matched exactly by type (state, county, city, town, village, CDP,
ZIP code, neighbourhood). If a name is not found, Fragua Data USA will look up the
other levels or list the places inside the parent area for you.

Data source: Fragua by Atlas Real Estate Analytics.
