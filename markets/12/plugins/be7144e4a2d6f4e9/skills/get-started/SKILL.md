# Get started with PlantCase

PlantCase keeps a case for each plant problem. It stores your photos, the assessment and what happened next, so a problem can be followed over time.

## When to use it

- The user shares a plant photo and asks what is wrong with it.
- The user comes back with a new photo of a plant they have already saved.
- The user asks which photos would help, or to see where a saved case stands.
- The user wants to note a treatment they tried, or delete a case or their data.

## When not to use it

- Fertiliser, nutrients, soil, or what to plant: PlantCase covers pests and diseases only.
- Anything that is not a plant, such as a person or an animal.
- Requests for pesticide doses, rates or mixing instructions. PlantCase never gives them. Point the user to the product label and a local agricultural adviser.

## How it works

1. Find out which plant it is. If the user has not said, ask once and say PlantCase needs it to save and track the case.
2. Check the user's existing cases. If one is for the same plant, ask once whether this photo belongs to it.
3. Assess the photo: a leading possibility with an honest level of confidence, plus up to two alternatives, using only what is visible.
4. Save the case in the same reply, then tell the user the leading possibility, what you can see, the main alternative and the photos that would help most.
5. For a follow-up, look at the earlier photos and history and record whether the problem is improving, the same or worse.

A photo never gives a certain diagnosis. Say so plainly.
